# BedrockReplacer ― OP・運営ガイド { .page-op }

<span class="badge custom">自作プラグイン</span>

ワールド内の **最下層（minHeight）以外にある岩盤（Bedrock）** を、**深層岩（Deepslate）** に置き換える整地補助プラグインです。地下空間の活用や、ネザー天井の岩盤撤去などを目的としています。最下層の岩盤は地形保護のため除外されます。

## 基本情報

| 項目 | 値 |
|---|---|
| プラグイン名 | BedrockReplacer |
| バージョン | `${project.version}`（pom 由来） |
| 種別 | 自作プラグイン（単独 jar） |
| API バージョン | 26.1.2 |
| メインコマンド | `/bedrockreplacer`（別名：`/br` ・ `/bedrock`） |
| 主要権限 | `bedrockreplacer.use`（OP）／ `bedrockreplacer.world`（OP） |
| 設定ファイル | なし |
| 依存 | なし |

## 概要・典型的な用途

- 地下整地で **邪魔な岩盤をきれいに撤去** したい場合に使用します。
- 最下層（オーバーワールドは Y=-64、ネザー／エンドは Y=0）にある岩盤は **そのまま残す** ため、ワールドの底抜けを防げます。
- それ以外の高さに生成される岩盤（**ネザーの天井層・床上層** など）は深層岩に置き換わります。
- 処理は **1tick あたり 1 チャンク** ずつ進められ、負荷分散されます。10 チャンクごとに進捗メッセージが送信されます。

!!! tip "深層岩への置換である理由"
    深層岩はツルハシで採掘可能なため、置き換え後は **通常の整地・建築素材として扱える** ようになります。岩盤のままでは破壊できないため、地下空間の整備が阻害されてしまいます。

## 導入手順

1. ビルド済みの `BedrockReplacer-x.x.x.jar` を `plugins/` フォルダに配置する。
2. サーバーを再起動する。
3. OP 権限を持つプレイヤーであれば、そのまま `/br` コマンドが使用可能です。

## 設定ファイル

このプラグインに `config.yml` は **存在しません**。動作はすべてコマンド引数で制御します。

## コマンド一覧

メインコマンドは `/bedrockreplacer`。別名として `/br`・`/bedrock` が使用できます。引数なしで実行するとヘルプが表示されます。

### `/br chunk`

実行プレイヤーが立っている **現在のチャンク 1 つだけ** を処理対象とします。

- プレイヤー専用（コンソールからは実行不可）。
- 他の処理が実行中の場合は開始できません。
- 開始時に対象チャンクの座標（`X, Z`）が通知されます。

### `/br radius <半径>`

実行プレイヤーが立っているチャンクを中心に、**指定したチャンク半径**の範囲を一括処理します。

- プレイヤー専用。
- `<半径>` は **1〜20** の範囲で整数指定（範囲外や非数値はエラー）。
- 半径 `r` のとき、処理対象は `(2r+1) × (2r+1)` チャンク。
- 開始時に「半径 N チャンク（合計 ◯ チャンク）の処理を開始します...」「処理には時間がかかる場合があります。」と通知されます。
- タブ補完候補は `1` `3` `5` `10`。

!!! tip "目安"
    `radius 5` で 121 チャンク、`radius 10` で 441 チャンク、`radius 20` で 1681 チャンクが対象になります。1tick 1 チャンク処理なので、半径が大きいほど完了までの時間も比例して長くなります。

### `/br world`

ワールド全体を処理する想定のコマンドですが、**現在この機能は無効化されています**（ソース実装上、警告のみ送信され実処理は行われません）。

- プレイヤー専用、かつ `bedrockreplacer.world` 権限が必要。
- 実行すると、以下のようなメッセージが表示されるのみで実際の処理は走りません。
    - 「警告: ワールド全体の処理は非常に時間がかかります！」
    - 「現在、この機能は無効化されています。」
    - 「代わりに半径指定を複数回実行することを推奨します。」

!!! warning "ワールド全体処理は実装上未対応"
    広範囲を処理する場合は、移動しながら `/br radius <半径>` を **複数回に分けて** 実行してください。

### `/br cancel`

実行中の処理を **中断** します。

- 実行中の処理がない場合は「実行中の処理はありません。」と表示されます。
- キャンセル後は次の tick で処理ループが終了します。

### `/br status`

現在の処理状況を表示します。

- 処理中の場合： `処理中: <現在>/<総数> チャンク (xx.x%)` と、これまでに置き換えたブロック数を表示。
- 完了済みの場合： `前回の処理は完了しています。` と、処理チャンク数・置き換えブロック数を表示。
- 一度も実行していない場合： `実行中の処理はありません。` と表示。

## 処理仕様（内部動作）

- 対象ブロック： **`BEDROCK`** のみ。
- 置換後ブロック： **`DEEPSLATE`**。
- スキャン範囲： 各チャンクの **`World#getMinHeight()` 〜 `World#getMaxHeight()-1`** までの全ブロック。
- **除外条件**： Y 座標が `getMinHeight()`（= ワールド最下層）と等しい層は処理対象外。
- 処理速度： **1 tick あたり 1 チャンク**（`BukkitRunnable#runTaskTimer(plugin, 0L, 1L)`）。
- 進捗報告： 10 チャンクごとに「進捗: N/M チャンク処理完了」を送信。
- 完了時には「========== 処理完了 ==========」「処理チャンク数」「置き換えたブロック数」が送信されます。

## 権限ノード

| 権限ノード | 既定 | 説明 |
|---|---|---|
| `bedrockreplacer.use` | `op` | `/bedrockreplacer` コマンド全体の使用権限 |
| `bedrockreplacer.world` | `op` | `/br world`（ワールド全体処理）の追加権限 |

OP には既定で両方付与されます。一般プレイヤーには付与しないでください。

## 注意点・トラブルシューティング

??? warning "実行中は別の処理を開始できない"
    `chunk` / `radius` のいずれも、`currentTask` が完了するまで新規実行は受け付けられず、「既に処理が実行中です。」と表示されます。先に `/br status` で進捗を確認し、必要なら `/br cancel` で中断してください。

??? warning "大きな半径は重い"
    `radius` は最大 20 まで指定できますが、半径が大きいほど処理時間が長くなります（1 tick = 1 チャンク）。プレイヤーが多い時間帯の実行は避け、ラグが発生する場合は `/br cancel` で中断してください。

??? failure "`/br world` を実行しても処理が始まらない"
    現状の実装で **`world` サブコマンドは無効化されています**（警告メッセージのみ）。代わりに移動しながら `/br radius` を複数回実行してください。

??? failure "コンソールから実行できない"
    `chunk` / `radius` / `world` は **プレイヤー専用** です（位置情報が必要なため）。コンソールでは「このコマンドはプレイヤーのみ実行できます。」と表示されます。`cancel` / `status` はコンソールからでも実行できます。

??? question "最下層の岩盤が消えない"
    仕様です。**ワールド最下層（`getMinHeight()` と等しい Y 座標）の岩盤は意図的に保護されており、置換されません**。ワールドの底抜けを防ぐためです。

??? question "途中で岩盤が残っている／チャンク境界に岩盤が残った"
    タスクは指定されたチャンクのみを処理します。範囲外に岩盤が残っている場合は、その場所へ移動して再度 `/br chunk` または `/br radius` を実行してください。
