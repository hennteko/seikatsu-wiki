# WorldEdit ― OP・運営ガイド { .page-op }

<span class="badge done">公開プラグイン</span>

範囲を選択して、ブロックの設置・置換・コピー・整地などを一括で行える、地形編集の定番プラグインです。建築や整地、企画ワールドの造成を大幅に効率化できます。このページは **よく使うコマンド中心の実用ガイド** です。

## 基本情報

| 項目 | 値 |
|---|---|
| プラグイン名 | WorldEdit |
| バージョン | 7.4.3（worldedit-bukkit） |
| 種別 | 公開プラグイン（EngineHub 製） |
| 主なコマンド | `//`（ダブルスラッシュ）で始まるコマンド群 |
| 依存 | なし |
| 設定ファイル | `plugins/WorldEdit/config.yml` |
| 公式サイト | https://worldedit.enginehub.org |

## 導入手順

1. `worldedit-bukkit-7.4.3.jar` を `plugins/` フォルダに配置する。
2. サーバーを再起動する。
3. 設定は `plugins/WorldEdit/config.yml` で調整できる（変更後は `/we reload`）。

## WorldEdit の基本的な使い方

WorldEdit は「**① 範囲を選ぶ → ② その範囲に操作する**」の流れが基本です。

1. `//wand` を実行して **選択ツール（木の斧）** を入手する。
2. 木の斧で、範囲の角を **左クリック（地点1）** と **右クリック（地点2）** で指定する。
3. `//set stone` のように、選択範囲へのコマンドを実行する。
4. 失敗したら `//undo` で元に戻せる。

!!! tip "まずは小さい範囲で試す"
    `//set` などの編集コマンドは、選択範囲を一瞬ですべて書き換えます。実行前に `//size` で範囲とブロック数を確認する習慣をつけると安全です。

## コマンド一覧

### 範囲選択

| コマンド | 説明 |
|---|---|
| `//wand` | 選択ツール（木の斧）を入手 |
| `//pos1` ／ `//pos2` | 立っている位置を選択点1／2にする |
| `//hpos1` ／ `//hpos2` | 見ている地点を選択点1／2にする |
| `//sel <種類>` | 選択形状を変更（`cuboid`＝直方体・`poly`・`sphere`・`cyl`・`convex`） |
| `//expand <数> [方向]` | 選択範囲を広げる |
| `//contract <数> [方向]` | 選択範囲を狭める |
| `//shift <数> [方向]` | 選択範囲をずらす |
| `//size` | 選択範囲のサイズ・ブロック数を表示 |
| `//chunk` | 今いるチャンクを選択 |

### 範囲の編集

| コマンド | 説明 |
|---|---|
| `//set <ブロック>` | 選択範囲を指定ブロックで埋める |
| `//replace <置換前> <置換後>` | 範囲内のブロックを置き換える |
| `//overlay <ブロック>` | 範囲の地表の上にブロックを乗せる |
| `//walls <ブロック>` | 範囲の側面（壁）をブロックにする |
| `//hollow [厚さ] [ブロック]` | 範囲の中身をくり抜く |
| `//stack <数> [方向]` | 選択範囲を方向に連続して複製 |
| `//move <数> [方向]` | 範囲の中身を移動する |
| `//smooth [回数]` | 地形をなめらかにする |
| `//line <ブロック>` | 選択2点を結ぶ線を引く |

### コピー＆ペースト（クリップボード）

| コマンド | 説明 |
|---|---|
| `//copy` | 選択範囲をクリップボードにコピー |
| `//cut` | 選択範囲を切り取る |
| `//paste` | 貼り付ける（`-a`＝空気を無視、`-s`＝貼付先を選択） |
| `//rotate <角度>` | クリップボードを回転（90 / 180 / 270） |
| `//flip [方向]` | クリップボードを反転 |
| `//clearclipboard` | クリップボードを消去 |

### スケマティック（建築物のファイル保存）

| コマンド | 説明 |
|---|---|
| `//schem save <名前>` | クリップボードの内容をファイルに保存 |
| `//schem load <名前>` | 保存したファイルをクリップボードに読み込み |
| `//schem list` | 保存済みスケマティックの一覧 |
| `//schem delete <名前>` | スケマティックを削除 |

保存先は `plugins/WorldEdit/schematics/` です。別ワールドや別サーバーへ建築物を持ち運べます。

### 図形の生成

| コマンド | 説明 |
|---|---|
| `//sphere <ブロック> <半径>` ／ `//hsphere` | 球 ／ 中空の球を生成 |
| `//cyl <ブロック> <半径> [高さ]` ／ `//hcyl` | 円柱 ／ 中空の円柱を生成 |
| `//pyramid <ブロック> <サイズ>` ／ `//hpyramid` | ピラミッド ／ 中空のピラミッド |

### ブラシ（離れた場所を編集）

ブラシは、手に持ったアイテムを「魔法の杖」にして、右クリックで遠くの地形を編集する機能です。

| コマンド | 説明 |
|---|---|
| `//brush sphere <ブロック> <半径>` | 球ブラシを割り当てる |
| `//brush cylinder <ブロック> <半径> [高さ]` | 円柱ブラシを割り当てる |
| `//brush smooth <半径>` | 地形をならすブラシ |
| `/mask <ブロック>` | ブラシが効く対象ブロックを限定する |
| `/size <数>` | ブラシのサイズを変更 |
| `//brush none` | ブラシを解除する |

### 履歴（やり直し）

| コマンド | 説明 |
|---|---|
| `//undo [回数]` | 直前の操作を取り消す |
| `//redo [回数]` | 取り消した操作をやり直す |
| `//clearhistory` | 操作履歴を消去する |

### 移動・ナビゲーション

| コマンド | 説明 |
|---|---|
| `/ascend` ／ `/descend` | 1つ上 ／ 下の床へ移動 |
| `/up <数>` | 真上へ移動 |
| `/thru` | 目の前の壁を通り抜ける |
| `/jumpto` | 見ている地点へ瞬間移動 |
| `/unstuck` | ブロックに埋まったときに脱出する |

### 便利なユーティリティ

| コマンド | 説明 |
|---|---|
| `//drain <半径>` | 周囲の水・溶岩を除去する |
| `//fixwater <半径>` ／ `//fixlava <半径>` | 水 ／ 溶岩を整える |
| `//snow` ／ `//thaw` | 雪を積もらせる ／ 溶かす |
| `//setbiome <バイオーム>` | 選択範囲のバイオームを変更 |
| `/we reload` | 設定を再読み込み |
| `/we version` | バージョンを表示 |

!!! tip "コマンドの詳細はゲーム内ヘルプでも確認できます"
    各コマンドの引数やオプションは、ゲーム内で `//help <コマンド名>` と入力すると確認できます。本ページはよく使う機能の早見表です。

## 権限ノード

WorldEdit は地形を大きく変えられる強力なツールのため、**OP または信頼できる建築スタッフのみ** に許可することを推奨します。OP は既定ですべてのコマンドを使用できます。

スタッフへ委譲する場合は、権限管理プラグインで `worldedit.*`（全許可）や、機能グループ別のノード（`worldedit.region.*`・`worldedit.clipboard.*`・`worldedit.brush.*`・`worldedit.generation.*`・`worldedit.navigation.*` など）を付与します。

## 注意点・トラブルシューティング

??? warning "操作範囲は実行前に必ず確認"
    `//set` `//replace` などは選択範囲を一瞬で書き換えます。`//size` で範囲を確認してから実行してください。万一のときは `//undo` で戻せます。

??? failure "大きすぎる範囲を編集できない"
    config の `//limit`（1回に変更できるブロック数の上限）に達している可能性があります。OPは無制限のことが多いですが、サーバー負荷が大きいので、巨大な編集は時間帯に注意してください。

??? failure "保護された土地でコマンドが効かない"
    WorldGuard などの保護領域内では、WorldEdit の操作が制限されることがあります。対象領域の保護設定を確認してください。

??? question "誤ってワールドを壊してしまった"
    `//undo` を繰り返せば、履歴が残っている範囲で元に戻せます。重要なワールドを大きく編集する前は、ワールドのバックアップを取ることを強く推奨します。
