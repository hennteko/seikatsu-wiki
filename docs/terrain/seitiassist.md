# Seitiassist ― OP・運営ガイド { .page-op }

<span class="badge done">独自プラグイン</span>

整地作業を快適にする統合アシストプラグインです。範囲削除の杖、範囲採掘ツルハシ、流体凝固アイテム、ゴミ箱フィルタなど、運営による地形整備で頻出する操作を 1 つの jar にまとめています。多くの機能は OP 専用ですが、ゴミ箱機能 (`/sa trash`) のみ既定で全プレイヤーが利用できます。

## 基本情報

| 項目 | 値 |
|---|---|
| プラグイン名 | Seitiassist（整地アシスト） |
| バージョン | 1.2 |
| API バージョン | 26.1.2（Paper 26.1.2 想定） |
| 種別 | 独自プラグイン（生活鯖専用） |
| メインクラス | `com.example.seitiassist.Seitiassist` |
| 主なコマンド | `/sa`（エイリアス: `/seiti`） |
| 設定ファイル | `plugins/Seitiassist/config.yml` |
| データファイル | `plugins/Seitiassist/trash_data.yml`（ゴミ箱フィルタ保存先） |
| 依存 | なし |

## 概要

Seitiassist は次の 5 系統のアシスト機能を提供します。

- **範囲削除の杖（wand / clean）** ― 木の斧で 2 点を選び、ダイヤモンドをコストに直方体を一括削除。
- **範囲採掘ツルハシ（pickaxe）** ― ダイヤツルハシで 1x1 ～ 7x7 の範囲採掘。
- **超大範囲ツルハシ（megapickaxe）** ― ネザライトツルハシで 9x9 ～ 21x21 の超大範囲採掘（イベント報酬用）。
- **流体凝固アイテム（fluid）** ― 青氷をオフハンドに持って採掘すると、周囲の水・溶岩を経験値消費で丸石・黒曜石へ変換。
- **スマート・ゴミ箱（trash）** ― 拾った瞬間に指定マテリアルを消去し、代わりに経験値を得る個人別フィルタ。

岩盤 (`BEDROCK`) はすべての破壊系機能から自動的に除外されるため、ワールド境界を誤って壊す心配はありません。

## 導入手順

1. `Seitiassist-1.2.jar` を `plugins/` フォルダに配置する。
2. サーバーを起動すると `plugins/Seitiassist/config.yml` が生成される。
3. 必要に応じて config を編集し、`/sa reload` で再読み込みする。
4. 既定で `/sa trash` のみ全プレイヤーが利用可能。それ以外は OP のみ。一般スタッフへ委譲する場合は権限管理プラグインで個別ノードを付与する。

## 各機能の解説

### 範囲削除の杖（`/sa wand`, `/sa clean`）

直方体範囲をダイヤモンドコストで一括削除する機能です。

**使い方**

1. `/sa wand [プレイヤー]` で **範囲消去の杖**（木の斧、表示名「§d範囲消去の杖」）を入手する。プレイヤー名を省略すると自分自身へ付与される。
2. 杖を持って **左クリック** で地点 A、**右クリック** で地点 B を指定する（クリックしたブロックの座標が選択点になる）。座標は地点を指定するたびにチャットへ表示される。
3. `/sa clean` を実行すると、選択範囲の直方体内のブロックがすべて空気に置き換わる。

**コスト計算**

- 削除対象のブロック数を数え、`wand.blocks-per-diamond`（既定 64）で割って切り上げた個数のダイヤモンドを消費する。
- 例: 250 ブロック削除なら ⌈250 / 64⌉ = 4 個のダイヤモンドを消費。
- 空気と岩盤はカウントされず、岩盤は破壊もされない。
- ダイヤモンドが足りない場合は実行されず、必要個数がチャットに表示される。
- 異なるワールドの 2 点を指定した場合はエラーになる。
- 実行成功後は **選択が自動でリセット** されるため、続けて削除したい場合は再度 2 点を指定する。

!!! tip "杖の判別"
    杖は内部的に `seitiassist:magic_wand` の NBT タグで識別されます。見た目が同じ木の斧でも、コマンドで取り出したものでなければ範囲選択は機能しません。

### 範囲採掘ツルハシ（`/sa pickaxe`）

ダイヤツルハシによる 1x1 ～ 7x7 の範囲採掘ツールです。

**入手と特徴**

- `/sa pickaxe [プレイヤー]` で取得。既定表示名は config `pickaxe.name`（既定値 `§6Bedrock Breaker`）。
- 取得直後は **7x7 モード** で初期化される。
- 切替モードは **1x1 / 3x3 / 5x5 / 7x7** の 4 段階。

**操作**

- **右クリック**（空中・ブロックいずれも）でモードを 1 → 3 → 5 → 7 → 1 …の順に循環。アクションバーに `採掘モード: NxN` と表示。
- **スニーク中の破壊** は常に 1x1（通常採掘）として扱われ、範囲採掘は発動しない。
- **叩いた面** によって展開方向が決まる。
    - 上 / 下面 → 水平面（X × Z）に展開
    - 北 / 南面 → 垂直面（X × Y）に展開
    - 東 / 西面 → 垂直面（Z × Y）に展開
- 岩盤と空気は範囲内でもスキップされる。
- 中心ブロックも含めたドロップは、`pickup.drop-at-feet` が `true`（既定）なら **プレイヤーの足元** に拾得待ち 0 tick でドロップ。`false` なら従来通りブロック位置にドロップ。
- 幸運・シルクタッチなどのエンチャント効果はドロップ計算に反映される。

**耐久値消費**

- 破壊した周辺ブロック数 + `pickaxe.durability-cost`（既定 1）の合計に対し、**バニラと同じ耐久力（Unbreaking）抽選** が行われる（レベル L のとき各回 1/(L+1) で減少）。
- 抽選結果のダメージ合計が最大耐久値を超えるとアイテムは破壊され、アイテム破壊音が再生される。

### 超大範囲ツルハシ メガツルハシ（`/sa megapickaxe`）

イベント報酬用の超大範囲採掘ネザライトツルハシです。エイリアス `mpickaxe`, `mp` も使用可能。

**入手と特徴**

- `/sa megapickaxe [プレイヤー]` で付与。表示名は config `mega-pickaxe.name`（既定値 `§c§l✦ Mega Breaker ✦`）。
- 取得直後は **21x21 モード** で初期化される。
- 切替モードは **9 / 11 / 13 / 15 / 17 / 19 / 21** の 7 段階。

**操作・挙動**

- 右クリックでモードを循環（21 → 9 → 11 → … → 21）。アクションバーに `【MEGA】採掘モード: NxN`。
- スニーク採掘で 1x1 扱い、叩いた面で展開方向決定、岩盤スキップ、足元ドロップ等のロジックは通常ツルハシと共通。
- 耐久値消費は `mega-pickaxe.durability-cost`（既定 3）が追加で乗る。範囲が広い分、Unbreaking なしだとあっという間に壊れるため、エンチャントとセットでの配布を推奨。

!!! warning "性能に見合った配布管理を"
    21x21 モードは 1 回の破壊で最大 440 個のブロックを処理します。大量配布するとサーバー TPS と地形に深刻な影響を与えるため、イベント報酬としての限定配布にとどめてください。

### スマート・ゴミ箱（`/sa trash`） { #trash }

**唯一プレイヤーが既定で利用できる機能** です。指定したマテリアルを拾った瞬間に消滅させ、代わりに経験値を獲得します。

**使い方**

1. `/sa trash` を実行すると **27 マスの GUI**（タイトル `§4ゴミ箱設定 (閉じて保存)`）が開く。
2. ゴミとして自動処理したいアイテムを GUI 内に並べる（個数は無関係、マテリアルの種類のみが登録される）。
3. GUI を閉じるとフィルタが保存され、`§a[Seitiassist] フィルターを更新しました。` のメッセージと音 (`BLOCK_NOTE_BLOCK_PLING`) が再生される。
4. 以後、登録したマテリアルをワールド上で拾おうとした瞬間にアイテムが消え、`exp-per-item × 個数` の経験値が付与される。アクションバーに `ゴミ変換: マテリアル名 xN (+XP)` と表示。

**データ保存**

- フィルタは UUID 別に `plugins/Seitiassist/trash_data.yml` に保存され、再起動後も維持される。
- GUI の識別は `InventoryHolder`（`TrashGuiHolder`）で行われ、タイトル文字列に依存しない。

!!! note "プレイヤー権限の確認"
    `seitiassist.command.trash` は `default: true` のため、特別な設定なしに一般プレイヤーが利用できます。サーバー方針に応じて権限プラグインで制限することも可能です。

### 流体凝固アシスト（`/sa fluid`）

オフハンドに **青氷**（既定）を持ったまま採掘すると、周囲の水・溶岩を経験値コストで固体化する機能です。

**使い方**

1. `/sa fluid [プレイヤー]` で **流体凍結の氷** を入手する。既定マテリアルは config `fluid.trigger-item`（既定 `PACKED_ICE`、未指定なら `BLUE_ICE`）。
2. 入手したアイテムを **オフハンド** に装備する。
3. メインハンドで任意のブロックを採掘すると、破壊位置を中心とした半径 `fluid.radius`（既定 2）の立方体範囲をスキャン。
4. 範囲内の水・溶岩を発見するたびに `fluid.exp-cost`（既定 2）の総経験値を消費して以下に変換する。
    - 溶岩 → 黒曜石
    - 水 → 丸石
5. 経験値が足りなくなった瞬間に処理が中断され、`§c経験値が足りず凍結できません！` がアクションバーに表示される。
6. 発動時は `BLOCK_FIRE_EXTINGUISH` 音と `冷却発動: 消費経験値 N` のアクションバー表示。

!!! tip "トリガーアイテム判定"
    オフハンドのマテリアル一致のみで発動するため、コマンドで取り出した「§b流体凍結の氷」でなくとも、設定アイテムと同じマテリアルがあれば動作します。バニラの青氷を間違ってオフハンドに持つと発動するので注意してください。

## config.yml 設定項目

```yaml
# --- アイテム回収設定 (Pickup Settings) ---
pickup:
  # 足元ドロップを有効にするか
  # true: ドロップアイテムをプレイヤーの足元にドロップ（回収しやすい）
  # false: 従来通りブロックの位置にドロップ
  drop-at-feet: true

# --- 魔法の杖 (Magic Wand) ---
wand:
  # 何ブロック削除するごとにダイヤモンドを1個消費するか
  # 例: 64 = 1スタック削除につきダイヤ1個
  blocks-per-diamond: 64

# --- 範囲採掘ツルハシ (Bedrock Breaker) ---
pickaxe:
  # 名前
  name: "§6Bedrock Breaker"
  # 範囲採掘発動時に追加で消費する耐久値
  durability-cost: 1

# --- 超大範囲採掘ツルハシ (Mega Breaker) ---
# イベント報酬専用の高性能ツルハシ
mega-pickaxe:
  # 名前
  name: "§c§l✦ Mega Breaker ✦"
  # 範囲採掘発動時に追加で消費する耐久値
  # 高範囲なので高めに設定推奨
  durability-cost: 3

# --- スマート・ゴミ箱 (Auto-Trash) ---
trash:
  # ゴミを消したときに入手できる経験値量 (1 = オーブ1個分程度)
  exp-per-item: 1

# --- 流体凝固アシスト (Lava Freezer) ---
fluid:
  # 効果を発動するためのトリガーアイテム（オフハンドに持つもの）
  trigger-item: PACKED_ICE
  # 1回の発動（1ブロック変換）に消費する経験値
  exp-cost: 2
  # 効果範囲 (半径)
  radius: 2
```

| キー | 既定値 | 説明 |
|---|---|---|
| `pickup.drop-at-feet` | `true` | ツルハシ系のドロップをプレイヤー足元にまとめる |
| `wand.blocks-per-diamond` | `64` | `/sa clean` のダイヤ 1 個あたりの削除ブロック数 |
| `pickaxe.name` | `§6Bedrock Breaker` | 範囲採掘ツルハシの表示名（旧 §-カラーコード） |
| `pickaxe.durability-cost` | `1` | 範囲採掘発動時に追加で乗る耐久消費回数 |
| `mega-pickaxe.name` | `§c§l✦ Mega Breaker ✦` | メガツルハシの表示名 |
| `mega-pickaxe.durability-cost` | `3` | メガツルハシ発動時に追加で乗る耐久消費回数 |
| `trash.exp-per-item` | `1` | ゴミ 1 個あたりの獲得経験値量 |
| `fluid.trigger-item` | `PACKED_ICE` | オフハンドのトリガーマテリアル名（無効値時は `BLUE_ICE` にフォールバック） |
| `fluid.exp-cost` | `2` | 流体 1 ブロック変換あたりの経験値コスト |
| `fluid.radius` | `2` | 流体凝固の効果半径（立方体、半径 2 なら 5x5x5） |

!!! note "trigger-item の既定値"
    `plugin.yml` 同梱の `config.yml` では `trigger-item: PACKED_ICE` が既定ですが、ソース側ハンドラのフォールバック値は `BLUE_ICE` です。コマンドで配布される `§b流体凍結の氷` のマテリアルは config の `trigger-item` から生成されるため、`PACKED_ICE` のまま運用する場合は配布アイテムも梱包氷になります。

## コマンド一覧

すべて `/sa` のサブコマンドです（エイリアス `/seiti`）。`[player]` を省略すると自分自身を対象にします。プレイヤー対象が必要なサブコマンドをコンソールから引数なしで実行するとエラーになります。

| コマンド | 説明 | 権限 |
|---|---|---|
| `/sa wand [player]` | 範囲消去の杖を入手 | `seitiassist.command.wand` |
| `/sa clean` | 杖で選択した直方体範囲を削除（プレイヤー専用） | `seitiassist.command.clean` |
| `/sa pickaxe [player]` | 範囲採掘ツルハシを入手（7x7 初期） | `seitiassist.command.pickaxe` |
| `/sa megapickaxe [player]` | メガツルハシを入手（21x21 初期） | `seitiassist.command.megapickaxe` |
| `/sa mpickaxe [player]` | `megapickaxe` のエイリアス | `seitiassist.command.megapickaxe` |
| `/sa mp [player]` | `megapickaxe` のエイリアス | `seitiassist.command.megapickaxe` |
| `/sa trash` | ゴミ箱フィルタ GUI を開く（プレイヤー専用） | `seitiassist.command.trash` |
| `/sa fluid [player]` | 流体凝固アイテムを入手 | `seitiassist.command.fluid` |
| `/sa reload` | `config.yml` を再読み込み | `seitiassist.admin` |
| `/sa`（引数なし） | ヘルプを表示 | なし |

## 権限ノード

権限は機能ごとに細分化されており、`/sa trash` のみ既定で全プレイヤーが利用できます。一般スタッフへ部分委譲する場合は、権限プラグインで個別ノードを付与してください。

| 権限ノード | 既定 | 説明 |
|---|---|---|
| `seitiassist.command.wand` | `op` | 杖を取り出す権限（`/sa wand`） |
| `seitiassist.command.clean` | `op` | 範囲削除を実行する権限（`/sa clean`） |
| `seitiassist.command.pickaxe` | `op` | 範囲採掘ツルハシを取り出す権限（`/sa pickaxe`） |
| `seitiassist.command.megapickaxe` | `op` | メガツルハシを付与する権限（イベント報酬用） |
| `seitiassist.command.trash` | **`true`** | ゴミ箱設定を開く権限（全プレイヤー利用可） |
| `seitiassist.command.fluid` | `op` | 流体凝固アイテムを取り出す権限（`/sa fluid`） |
| `seitiassist.admin` | `op` | 管理者権限（`/sa reload` など） |

!!! info "プレイヤーに開放されているのは trash のみ"
    `seitiassist.command.trash` は `default: true` です。それ以外は OP 既定なので、誤って一般プレイヤーが範囲削除や範囲採掘を実行することはありません。

## トラブルシューティング

??? failure "`/sa clean` で「コストが足りません！」と表示される"
    削除対象のブロック数に対してインベントリ内のダイヤモンドが不足しています。メッセージに表示される **対象ブロック数** と **必要個数** を確認し、ダイヤを補充するか、選択範囲を狭めてから再度 `/sa clean` してください。レートは `wand.blocks-per-diamond` で調整できます。

??? failure "杖を持って木を叩いても範囲選択にならない"
    通常の木の斧では動作しません。`/sa wand` で配布された、NBT タグ `seitiassist:magic_wand` 付きの木の斧でのみ反応します。再取得して試してください。

??? failure "範囲採掘ツルハシで範囲破壊が起きない"
    次のいずれかに該当します。
    
    - スニーク状態で破壊した（仕様：1x1 採掘）
    - 現在のモードが 1x1 になっている（右クリックで切替）
    - メインハンドが Seitiassist 由来でない（コマンドで取り出した個体のみ反応）
    - 範囲内が岩盤や空気で対象が存在しなかった

??? failure "流体凝固が発動しない"
    オフハンドに `fluid.trigger-item`（既定では青氷／パック氷）と同じマテリアルが装備されているか確認してください。コマンド配布アイテムでなくても、マテリアル一致で発動します。発動時は経験値が消費されるため、経験値ゲージが空だと処理は中断します。

??? failure "ゴミ箱が動かない / 設定が消える"
    GUI を開いて何も入れずに閉じるとフィルタが空になります。再度 `/sa trash` で開き、フィルタしたいアイテムを並べ直してください。設定は `plugins/Seitiassist/trash_data.yml` に UUID 別で保存されます。手動でファイルを編集した場合は `/sa reload` ではなくサーバー再起動で再読み込みされます。

??? warning "メガツルハシを一般配布しないこと"
    21x21 モードは 1 アクションで最大 440 ブロックを処理し、足元ドロップで大量のアイテムエンティティを生成します。サーバー TPS への影響が大きいため、`seitiassist.command.megapickaxe` は OP / イベント運営者のみに限定してください。

??? question "config を変更したのに反映されない"
    `/sa reload` で再読み込みできます。ただし **既に配布済みのアイテムの表示名・耐久コスト等は再取得しないと反映されません**（PersistentData にモードのみが保存され、名前は生成時にコピーされるため）。新しい設定で配り直すか、既存アイテムを破棄して再発行してください。
