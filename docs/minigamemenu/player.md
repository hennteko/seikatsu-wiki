# MiniGameMenu（ミニゲームメニュー）― 使い方 { .page-player #minigamemenu-player }

専用アイテムやコマンドからメニューを開き、遊びたいミニゲームを選んでワンクリックで **参加・離脱・開始** できます。各ゲームのコマンドを覚える必要はありません。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 開き方 | 「生活鯖メニュー」の本を **右クリック**、または `/mgmenu` |
    | 一覧画面 | カテゴリ（チーム戦・個人戦・カジノ）ごとにゲームが並ぶ |
    | 操作 | ゲームを選ぶ → 参加 / 離脱 / 開始ボタンをクリック |
    | 便利ボタン | スポーン移動・倉庫アイテム入手などをメニューから実行 |

## メニューの開き方

メニューは2通りの方法で開けます。

- **メニューアイテムを右クリック** — 入室時に配られる **「生活鯖メニュー」** の本（既定でホットバー右端のスロット）を右クリックすると一覧GUIが開きます。
- **コマンド** — チャットで `/mgmenu` と入力しても開きます（エイリアス `/menu`・`/mgm`・`/ミニゲーム` も使えます）。

!!! tip "メニューアイテムは捨てられません"
    メニューアイテムは **ドロップやインベントリ外への移動が禁止** されています。誤って失う心配はなく、なくしても入室時に再配布されます。

## 一覧画面（第1画面）の見方

メニューを開くと、ミニゲームの一覧が表示されます。

- **左端の列** … 各 **カテゴリの見出し**（チーム戦・個人戦・カジノ）です。同じ行の右側に、そのカテゴリのゲームが並びます。
- **各ゲームのアイコン** … クリックすると、そのゲームの操作画面（第2画面）が開きます。
- **下段の便利ボタン** … スポーン移動や倉庫アイテム入手など、ワンクリックで実行できるボタンが並びます。
- **中央下の「操作ガイド」** … 操作の説明用アイテムです（クリックしても何も起きません）。
- **右下の「閉じる」** … メニューを閉じます。

## 参加・離脱・開始の操作

一覧でゲームを選ぶと、そのゲーム専用の **操作画面（第2画面）** が開きます。

- **▶ 参加する** … そのゲームに参加します。
- **◀ 離脱する** … 参加中のゲームから抜けます。
- **⚑ 開始する** … ゲームを開始します。
- **« 戻る** … 一覧画面に戻ります。

ボタンを押すと自動でメニューが閉じ、対応するコマンドが実行されます。

!!! note "ゲームによって出るボタンは変わります"
    ボタンは **設定されている操作だけ** が表示されます。たとえば「開始」コマンドを持たないゲームでは「開始する」ボタンは出ません。カジノ系の多くは「参加（入場）」のみです。

## 収録ミニゲーム

メニューには次のカテゴリ・ゲームが標準で並びます（OPの設定で変更される場合があります）。

??? question "チーム戦カテゴリ"
    LOL（MOBA）／かくれんぼ／スプラトゥーン／ドロケイ／残機制PVP／雪合戦／雪鬼／青鬼

??? question "個人戦カテゴリ"
    PVP（1v1）／TNTラン／アスレタイマー／バトルロイヤル／ボンバーマン／マリカー／人狼／釣りイベント／雪クラフト／2D宝探し

??? question "カジノ・ギャンブルカテゴリ"
    ブラックジャック／ポーカー／スロット／宝くじ／チンチロ／クイズ／競馬／育成競馬

## 便利ボタン（ユーティリティ）

一覧画面の下段には、ミニゲーム以外のよく使う操作ボタンも並びます（クリックで即実行）。

- **初期スポーン** … ワールドの初期リスポーン地点へ移動します。
- **スポーン1〜5** … 自分で登録した地点へ移動します（`/spawn set 1` などで登録）。
- **共有倉庫の棒を入手** … グローバルストレージを開く棒を受け取ります。
- **個人倉庫の本を入手** … 個人ストレージを開く本を受け取ります。

## よくある質問

??? question "メニューを開く本をなくしました"
    再入室すると自動で配り直されます。OPに `/mgmenu give` で配ってもらうこともできます。

??? question "ボタンを押しても反応しないゲームがあります"
    そのゲームに対応する操作（例: 開始）が設定されていない場合、ボタン自体が表示されません。また、対象ゲームが満員・進行中などの場合は、そのゲーム側のメッセージが表示されます。

??? question "コマンドからも開けますか？"
    はい。`/mgmenu`（または `/menu`・`/mgm`・`/ミニゲーム`）で開けます。
