# VillagerBall ― 遊び方 { .page-player #villagerball-player }

村人を専用のボールに収納して、好きな場所へ運んで解放できるプラグインです。職業・取引内容・経験値・体力・名前などの情報も一緒に保存されます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 空のボール | 既定でエンダーパール（光った状態） |
    | 村人入りボール | 既定でエンダーアイ（光った状態） |
    | 捕獲方法 | 空のボールを持って村人を右クリック |
    | 解放方法 | 村人入りボールを手に持って右クリック |
    | 保持されるデータ | 職業・レベル・タイプ・経験値・体力・名前・取引内容 |
    | 既定の成功率 | 100%（サーバー設定で変動あり） |

## どんな機能？

空の **村人ボール** を持って村人を右クリックすると、その村人がボールに収納されます。村人入りボールを別の場所で右クリックすれば、保存していた村人をそのまま解放できます。

- 取引内容・職業・経験値などをまるごと持ち運べます。
- 解放した村人には、捕獲時の取引が引き継がれます。
- 取引中（プレイヤーと取引画面を開いている）の村人は、既定では捕獲できません。

## ボールの入手

村人ボールは管理者からのみ配布されます。

- 一般プレイヤーはクラフトなどで作成できません。
- サーバーの管理者に頼んで、`/villagerball give` で配ってもらってください。
- 受け取ると「&aVillagerBallを受け取りました！」というメッセージが表示されます。

!!! note "ボールの見た目"
    既定では **空のボール = エンダーパール**、**村人入りボール = エンダーアイ** です。両方とも光ったエフェクト（エンチャント光沢）が付き、表示名は「村人ボール (空)」「村人ボール (村人入り)」になっています。

## 村人の捕獲方法

1. **空の村人ボール** をメインハンドに持つ。
2. 捕獲したい村人を **右クリック** する。
3. 成功すると、村人がその場で消え、インベントリに **村人入りボール** が追加されます。
4. インベントリが満杯の場合は、村人入りボールが足元にドロップされます。

!!! tip "捕獲が失敗したら"
    成功率は管理者の設定で 100% 未満になっている場合があります。失敗すると「&c村人の捕獲に失敗しました。」のメッセージが表示され、ボールは消費されません（村人もその場に残ります）。クールダウンが設定されている場合は失敗時にも適用されます。

!!! warning "取引中の村人は捕獲できません"
    プレイヤーが取引画面を開いている村人を捕獲しようとすると「&c取引中の村人は捕獲できません。」と表示されます（既定設定）。取引画面を閉じてから捕獲してください。

## 村人の解放方法

1. **村人入りボール** をメインハンドに持つ。
2. **空中または地面を右クリック** する（村人や他のエンティティに対してではなく）。
3. プレイヤーの向いている方向の少し前方に村人が現れます。
4. 解放後、ボールは消費され、代わりに **空のボール** が1つインベントリに追加されます（満杯の場合は足元にドロップ）。

!!! note "解放位置の決まり方"
    解放位置はプレイヤーの正面（約2ブロック前方）です。そこが空気でない場合は、空気ブロックが見つかるまで自動的に上方向に移動して安全な位置を探します。

## 保持されるデータ

サーバー設定で個別にオン／オフできますが、既定では以下のデータが **すべて保存** されます。

| データ | 内容 |
|---|---|
| 職業 | 農民・司書・防具鍛冶など、ジョブブロックで決まる職業 |
| レベル | 村人のレベル（見習い〜達人） |
| タイプ | 平原・砂漠・ジャングルなどのバイオームタイプ（見た目） |
| 経験値 | 村人の取引経験値 |
| 体力 | 捕獲した時点の体力 |
| カスタム名 | 名札などで付けられた名前 |
| 取引内容 | 売買する商品・価格・使用回数・需要・特別価格など |

!!! tip "村人入りボールのアイテム説明"
    村人入りボールにマウスを当てると、ボールに収納されている村人の **名前・職業・レベル・タイプ・経験値** が説明文（Lore）に表示されます。中身を確認してから解放したいときに便利です。

## よくある質問

??? question "村人ボールはどこで手に入りますか？"
    プレイヤーは自分では作成できません。サーバーの管理者に頼んで `/villagerball give` で配布してもらってください。

??? question "捕獲した村人の取引はそのまま使えますか？"
    使えます。職業・レベル・取引内容（使用回数や需要も含む）すべて保持されているため、解放した村人はそのまま取引相手として利用できます。

??? question "失敗するとボールが減りますか？"
    減りません。捕獲に失敗した場合、空のボールは消費されません。ただしクールダウンは適用されます（サーバー設定で有効な場合）。

??? question "村人入りボールを右クリックしても何も起きません"
    村人や他のエンティティに向かって右クリックしていませんか？ 解放は **空中または地面（ブロック）への右クリック** で発動します。また、解放権限がない、クールダウン中、村人データが破損しているなどの理由でも失敗することがあります。

??? question "解放した村人は元の村に戻りますか？"
    戻りません。解放するとプレイヤーの目の前にスポーンします。元の場所に戻りたい習性などもありません。

??? question "ゾンビ村人や略奪者は捕獲できますか？"
    できません。VillagerBall は通常の **村人（Villager）** のみを対象としています。
