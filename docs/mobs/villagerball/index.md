# VillagerBall <span class="badge custom">自作プラグイン</span>

村人を **モンスターボール** のようにアイテムへ収納できるプラグイン。空のボールを持って村人を右クリックで捕獲し、村人入りボールを右クリックで解放できます。職業・取引内容・経験値・体力・カスタム名なども保持されます。

!!! note "このプラグインについて"
    空の村人ボール（既定ではエンダーパール）を持って村人を右クリックすると、その村人がボールに収納されます。村人入りボール（既定ではエンダーアイ）を右クリックすれば、保存された取引・職業・経験値・体力・カスタム名・タイプを保ったまま村人を解放できます。
