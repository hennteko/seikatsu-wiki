# BossPlugin ― 遊び方 { .page-player #bossplugin-player }

OPが召喚する **3種類のカスタムボス** に挑むための解説ページです。各ボスは大型の見た目・専用ボスバー・3段階のフェーズ変化を持ち、HPが減るごとに攻撃が激しくなりミニオンを呼びます。加えて、複数ウェーブを殲滅していく協力型の **襲撃（WAVE）モード**（`/bossraid`）も遊べます（[こちらへジャンプ](#raid)）。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | ボスの種類 | Zombie（Giant）／ Skeleton（Wither Skeleton）／ Spider（巨大Spider） |
    | フェーズ | HP 100〜70% / 70〜30% / 30〜0% の **3段階** |
    | HPバー | ボスから半径50ブロック以内のプレイヤーに自動表示 |
    | 撃破報酬 | 経験値オーブ **150** ／召喚されたミニオンも全て消滅 |
    | 危険な仕様 | プレイヤーが付近からいなくなるとボスは **毎tick HPを自動回復** |

## 共通の挙動

- **ダメージはカスタム計算**：プレイヤーがボスを殴ると通常ダメージはキャンセルされ、プラグイン側のHP（内部値、最大1024表示）を直接削ります。ボスのバリア／矢シールドなどが有効な間はダメージが大幅に軽減されます。
- **距離制限**：半径50ブロック以内に **プレイヤーが1人もいなくなる** と、ボスは最大HPの **1%／tick** で自動回復します。離れて回復させないよう注意。
- **HPバー表示**：召喚時にボスから50ブロック以内にいたプレイヤーへ表示され、その後ログインしてきたプレイヤーも同距離以内であれば自動で追加されます。
- **撃破時**：通常のドロップは出ません。代わりに **経験値オーブ150** がドロップし、ボスが召喚していたミニオンも全て消滅します。

!!! warning "ボスはHP回復を持っています"
    一度戦闘を始めたら離れず、最後まで削り切りましょう。逃げて時間を稼ぐと自動回復で全回復してしまいます。

## ボスの種類

=== "Zombie（Explosive Boss）"

    巨大ゾンビ（Giant）の姿をした、**爆発する火球** を撒くタイプのボスです。

    **特徴・攻撃**

    - **火球（ファイヤーボール）攻撃**：空中から地表へ向けて火球を降らせます。着弾点で半径5ブロックの爆発（最大10ダメージ、地形破壊なし）を起こします。
    - **フェーズ進行で激化**：
        - **Phase 1**：火球を同時3発、攻撃間隔30tick。
        - **Phase 2**：同時6発、間隔20tick、範囲1.5倍。
        - **Phase 3**：同時9発、間隔10tick。さらに **5秒ごとに地上爆発** が3ヶ所同時発生。
    - **バリア**：30秒ごとに10秒間、被ダメージを **90%軽減** するバリアを展開（ビーコン音／TOTEMパーティクル）。
    - **ノックバック**：5ブロック以内に近づくと2.0の強さで吹き飛ばされます。
    - **ミニオン召喚**：HP75%でゾンビ、50%でスケルトン、25%でゾンビ＋スケルトンを召喚（人数 × 5体ずつ）。
    - **定期スポーン**：60秒ごとに半径10ブロック内へ ZOMBIE×3・SKELETON×2・SPIDER×1 を追加召喚。

    **戦い方のコツ**

    - 火球は **影（地面に煙のパーティクル）** が事前に表示されてから20tick後に発射されます。煙が出た位置からは離れましょう。
    - バリア中（ボス周囲にEND_RODパーティクル）は与ダメが10分の1。バリアが切れるまで攻撃を温存するのが効率的。
    - Phase 3では地上爆発で押し出されるので、ミニオンを片付けてから本体を集中攻撃。

=== "Skeleton（Skeleton Archer）"

    ウィザースケルトン姿の **アーチャー型** ボス。エンチャント付きダイヤ装備をフル装備しています。

    **特徴・攻撃**

    - **通常矢攻撃**：最寄りのプレイヤーに向け、同時16本の矢（拡散角15度・ダメージ5）を放ちます。
        - 30%の確率で **追尾矢**（5秒間プレイヤーを追跡）
        - 20%の確率で **爆発矢**（着弾で半径3、最大8ダメージ）
    - **放射攻撃**：3秒ごとに **32本の矢を360度放射**（ダメージ5）。
    - **矢の雨**：3秒ごとに、最寄りプレイヤーの上空30ブロックから **50本の矢** が半径15に降り注ぐ（ダメージ10）。
    - **連射モード**：7.5秒おきに発動、2秒間 **毎秒5本** の高速連射（ダメージ5・速度4）。
    - **スピードブースト**：5秒ごとに3秒間、移動速度が大幅上昇（青いCLOUDパーティクル）。
    - **矢シールド**：5秒ごとに5秒間、ボスの周囲を24本の矢が回転して **被ダメ50%軽減**。
    - **装備**：ダイヤ装備フルセット＋エンチャント付きの弓（パワーIII＋フレイムI）。装備はドロップしません。
    - **ミニオン召喚**：HP75%・50%でスケルトン、25%でスケルトン＋ストレイ（人数 × 5体ずつ）。

    **戦い方のコツ**

    - 矢シールド（CRITパーティクルが旋回）が出ている間は与ダメ半減。シールドが切れる5秒の間を狙いましょう。
    - 連射モードのビーコン音が鳴ったら **遮蔽物に隠れる** か散開。
    - 矢の雨は範囲攻撃なので、足元の煙パーティクルを見たら **半径15ブロックの外に逃げる** こと。

=== "Spider（Venom Broodmother）"

    通常の2倍サイズのスパイダー姿、**毒と糸** を操るボス。スポーン地点を中心とした「巣」が存在します。

    **特徴・攻撃**

    - **巣エリア**：スポーン地点から半径30ブロックを離れて5秒経つと、ボスのスポーン地点へ **強制テレポート** で引き戻されます。
    - **糸フィールド**：5秒ごとに周囲半径15ブロックにクモの巣ブロックを最大50個まで設置（移動阻害）。
    - **糸拘束（Web Shot）**：3秒ごとに15ブロック以内のプレイヤーに糸玉を投擲、命中で **移動速度低下III（5秒）**。
    - **毒噴射（Venom Spray）**：4秒ごとに正面60度の扇状（範囲10）に4ダメージ＋毒IIを付与。
    - **毒の霧（Poison Cloud）**：6秒ごとにボスの足元に5秒持続の毒の霧（半径8）。毎tick0.5ダメージ、1秒ごとに **毒レベル** が1上昇。
    - **糸引き寄せ（Web Pull）**：5秒ごとに半径20ブロック以内のプレイヤーをボス側へ引き寄せ。
    - **卵産み**：7.5秒ごとに3個のドラゴンの卵を周囲に設置、10秒後に **スパイダー or ケイブスパイダー** が孵化（Phase 3では数が2倍）。
    - **天井戦闘**：HP70%以下になると、10秒地上→5秒天井（+15ブロック）を繰り返してフロアを攻撃。
    - **怒り状態**：HP30%以下で「怒り状態」に移行、攻撃間隔40%短縮・召喚数2倍。
    - **ミニオン召喚**：HP75%でケイブスパイダー、50%でスパイダー、25%で両方（人数 × 3/4体ずつ・速度上昇II付与）。

    **毒レベル**

    毒の霧や毒噴射で被弾すると **毒レベル** が蓄積（最大5）。10秒被弾しなければレベルが1ずつ自然減少します。

    | レベル | 効果 |
    |---|---|
    | レベル1〜2 | 毒I（5秒） |
    | レベル3〜4 | 毒II（5秒） |
    | レベル5 | 毒III（5秒） |

    **戦い方のコツ**

    - 巣エリアの外に逃げても5秒で戻されるので、 **巣の内側で戦う** 前提で立ち回ること。
    - クモの巣ブロックで身動きが取れなくなりやすいので **剣（クモの巣破壊）** を持参するとよい。
    - 毒レベルが上がりきると毒IIIが付くので、被弾を抑えて自然減少を待つ立ち回りが安全。
    - Phase 3の怒り状態（ANGRY_VILLAGERパーティクル）に入ったら卵が2倍湧くので、孵化前に潰しましょう。

## 単体ボスの報酬

| 内容 | 詳細 |
|---|---|
| 経験値オーブ | **150**（撃破時に必ずドロップ） |
| 通常ドロップ | 一切なし（プラグインで強制クリア） |
| ボスの装備 | ドロップしません（Skeleton の弓・防具はドロップ率0） |
| ミニオン | ボス撃破と同時にすべて消滅 |

!!! note "報酬は経験値のみ"
    `/bossspawn` で召喚した単体ボスは、ソース上でドロップ品が明示的に追加される処理はありません。経験値150のみが確定報酬です（襲撃モードの報酬は[こちら](#raid-reward)）。

## 襲撃（WAVE）モード { #raid }

専用アリーナで、押し寄せる **雑魚（ザコ）→オオモノ→最終ボス** のウェーブを順に殲滅していく協力型コンテンツです。難易度を選んで開始し、全ウェーブを制覇すればクリア。クリア内容に応じて経験値報酬とスコア・ランキングが記録されます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | メインコマンド | `/bossraid`（別名 `/raid`） |
    | 流れ | アリーナに参加 → 難易度を選んで開始 → 全ウェーブ殲滅でクリア |
    | クリア条件 | そのウェーブの敵を全滅させる。最終ウェーブのボスを倒せばクリア |
    | 失敗条件 | 参加者全員がダウンすると **襲撃失敗** |
    | 装備 | 持ち込んだ装備で戦う。試合中は **アドベンチャーモード**（ブロック破壊不可・既定設定時） |
    | 報酬 | クリアで経験値（難易度・レーティング・ランクで変動）＋スコア／ランキング記録 |

### プレイヤー用コマンド

```text title="アリーナに参加する"
/bossraid join <アリーナ名>
```

```text title="アリーナから離脱する"
/bossraid leave
```

```text title="試合を開始する（難易度を省略すると選択GUIが開く）"
/bossraid start <アリーナ名> [難易度]
```

```text title="難易度の一覧を見る"
/bossraid difficulties
```

```text title="アリーナや自分の設定状況を確認する"
/bossraid status [アリーナ名]
```

```text title="スコア上位ランキングを見る（上位10名）"
/bossraid ranking
```

```text title="自分の襲撃記録（クリア回数・最高スコア・最高難易度）を見る"
/bossraid record
```

!!! tip "難易度はGUIでも選べる"
    `/bossraid start <アリーナ名>` と難易度を省略して実行すると、難易度＆レーティングを選ぶ **選択GUI** が開きます。アイテムをクリックして難易度を選び、レーティング（掛け金）を増減し、「この設定で開始」を押すとそのまま試合が始まります。参加していない人でも、アリーナ内に設置された **看板** をクリックして参加・離脱・開始ができます。

### ゲームの流れ

1. **参加**：`/bossraid join <アリーナ名>`（または参加看板）でアリーナに入ると、ロビーへ移動しアドベンチャーモードになります（既定設定時）。最低1人から開始できます。
2. **開始**：誰かが `/bossraid start`（または開始看板／GUIの開始ボタン）を押すと、選んだ難易度で試合がスタート。全員がゲームスポーンへ移動します。
3. **ウェーブ進行**：各ウェーブの敵を全滅させると、**5秒のインターバル** を挟んで次のウェーブへ。ウェーブ数や敵の強さは難易度で変わります。
4. **最終ウェーブ**：最後はボス枠。難易度に応じて複数体（最大3体）出現することもあります。これを倒せば **襲撃クリア**。
5. **失敗**：参加者が全員ダウンすると襲撃失敗で終了します。

### ダウンと復帰

- 試合中に倒されると **ダウン** 状態になり、リスポーン後は **観戦（スペクテイター）モード** でゲームスポーンに留まります。試合が終わるまで戦線復帰はできません。
- 倒れても **持ち物・経験値レベルは保持** されます（ドロップしません）。安心して持ち込み装備で挑めます。
- ダウン回数はクリア評価ランクに影響します（後述）。

!!! warning "全員ダウンで即失敗"
    参加者全員がダウンすると、その場で襲撃失敗となります。無理な突撃は避け、オオモノの弱点を素早く処理して手数を維持しましょう。

### 特殊イベント

ウェーブによっては開始時に **特殊イベント** が発生し、戦況が一変します。

| イベント | 効果 |
|---|---|
| 濃霧（fog） | 参加者全員に **暗闇** 効果。視界が大幅に悪化します。 |
| 大量発生（rush） | そのウェーブの敵総数と湧きペースが **2倍**。一気に押し寄せます。 |
| 間欠泉（geyser） | 数秒ごとに誰かの足元から噴出。予兆表示の後、範囲内にいるとダメージ＋打ち上げ。 |
| 巨大竜巻（tornado） | フィールドを徘徊する竜巻。範囲内に入ると吹き飛ばされ、ダメージを受けます。 |

### オオモノ（弱点持ちの強敵）

雑魚に混じって出現する大型の敵「オオモノ」は、**特定の弱点しかダメージが通りません**。やみくもに殴っても無効なので、弱点を狙いましょう。

| オオモノ | 弱点・攻略 |
|---|---|
| バクダン（Steelhead） | **頭の上の光る弱点パーツ** だけ有効。胴体への攻撃は通りません。一定間隔で周囲に範囲爆撃を行います。 |
| テッパン（Scrapper） | **正面は装甲で無効**（殴ると弾き返される）。**背後・側面** に回り込んで攻撃します。 |
| タワー（Stinger） | 縦に積まれた段の **最上段（光っている段）だけ** 破壊可能。上から順に崩していきます。一定間隔で最寄りを狙撃します。 |

!!! info "業火の巨王（Blaze King）"
    最終ウェーブのボス枠には、3種のカスタムボスに加えて **業火の巨王（Blaze King）** が抽選で出現することがあります。ブレイズ型の大型ボスで、一定間隔で周囲に火炎の波（範囲ダメージ＋着火）を放つ純粋な火力勝負のボスです。

### 変異（ミューテーター）

高難易度・高レーティングでは、その試合の敵に **変異** が付与され、特性が強化されます（試合開始時にアナウンス）。

| 変異 | 効果 |
|---|---|
| 俊足 | 敵の移動速度が上昇。 |
| 鉄壁 | 敵の実効HPが増加（タフになる）。 |
| 怒り | 敵の攻撃力と移動速度が上昇。 |
| 再生 | 敵が毎秒わずかに自己回復。 |
| 遺言爆発 | 撃破時に周囲へ範囲ダメージ。倒した直後の位置に注意。 |

### スコアとランク

クリア時、内容に応じてスコアが集計され、評価 **ランク（S/A/B）** が決まります。

- スコアは、雑魚・オオモノ・ボスの撃破、ウェーブクリア、完全クリアの各ボーナスで加算されます。
- ランクは **ダウン（誰かが倒れた）回数** で決まります：**0回＝S** ／ **2回以下＝A** ／ **3回以上＝B**。ランクが高いほど報酬倍率が上がります。
- 記録は `/bossraid record`（個人）と `/bossraid ranking`（上位）で確認できます。

### 報酬 { #raid-reward }

| 内容 | 詳細 |
|---|---|
| クリア経験値 | `基礎値（既定100）× 難易度の報酬倍率 × ランク倍率` を全員に付与 |
| ランク倍率 | S=2.0 ／ A=1.5 ／ B=1.0（既定値） |
| 記録 | クリア回数・最高スコア・最高難易度・最高レーティングが保存される |

!!! note "報酬は経験値（＋ランキング）"
    襲撃モードのクリア報酬は経験値です。レーティング（掛け金）を上げるほど敵は強くなりますが、報酬倍率も上がります。金イクラのような専用通貨は使いません。

## よくある質問

??? question "ボスを攻撃してもダメージが入りません"
    バリア／矢シールド／毒霧などの **無敵時間に近い軽減状態** に入っている可能性があります。エフェクトが切れるのを待ちましょう。Spiderの天井戦闘中は遠距離武器が必要です。

??? question "ボスのHPが勝手に回復しています"
    ボスから半径50ブロック以内に **プレイヤーが1人もいない** と毎tickHPが回復します（最大HPの1%/tick）。離れすぎないように。

??? question "ボス本体に近づけません"
    Zombieボスは5ブロック以内に入ったプレイヤーを強くノックバック、Spiderボスは糸引き寄せ／クモの巣で行動を阻害してきます。複数人で囲むか、遠距離攻撃を活用しましょう。

??? question "ボスのHPバーが見えません"
    召喚時または途中参加時に **ボスから50ブロック以上離れている** とHPバーは追加されません。一度近づけば自動で表示されます。

??? question "ミニオンを倒すと何かもらえますか？"
    ミニオン自体は通常モブと同じ扱いで、特別な報酬はありません。ボス本体撃破時に経験値150がまとめてドロップします。

??? question "（襲撃）オオモノを殴ってもダメージが入りません"
    オオモノは弱点しか有効でない仕様です。バクダンは **頭の光る弱点**、テッパンは **背後・側面**（正面は装甲）、タワーは **最上段（光っている段）** だけを攻撃してください。攻撃時に画面下に攻略ヒントが表示されます。

??? question "（襲撃）倒れたら復活できますか？"
    ダウンするとその試合の間は **観戦モード** で待機となり、戦線復帰はできません。参加者全員がダウンすると襲撃失敗です。持ち物は保持されるので、次の試合に向けて装備は失いません。

??? question "（襲撃）難易度はどう選びますか？"
    `/bossraid start <アリーナ名>` を難易度なしで実行すると選択GUIが開きます。GUIで難易度とレーティング（掛け金）を選んで開始できます。難易度の一覧は `/bossraid difficulties` で確認できます。
