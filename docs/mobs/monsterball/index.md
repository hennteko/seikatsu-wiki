# Monsterball <span class="badge done">公開中</span>

村人を **モンスターボール（スライムボール）** に閉じ込めて持ち運び、別の場所で解放できる小型プラグインです。職業・取引レシピ・経験値・カスタム名・バイオームタイプを保存し、解放後に専用コマンドで取引データを復元できます。

!!! note "似たプラグインとの違い"
    同サーバーには **VillagerBall** という似た目的のプラグインもあります。Monsterball は **取引レシピ・経験値までを JSON で保存し、解放後に `/monsterball restore` で復元する** 方式が特徴です。アイテムは **スライムボール** を流用し、Persistent Data Container（PDC）にデータを格納します。
