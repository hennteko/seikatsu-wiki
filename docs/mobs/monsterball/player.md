# Monsterball ― 遊び方 { .page-player #monsterball-player }

**モンスターボール** は、村人を一時的にボールに閉じ込めて持ち運ぶための道具です。職業や取引内容を保存できるので、村人の引っ越しや交易拠点の再編成に便利です。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 入手方法 | OPからの配布（`/monsterball give`） |
    | 対象モブ | 村人（Villager）のみ |
    | 捕獲方法 | 空のボールを持って村人を **右クリック** |
    | 解放方法 | 村人入りボールを **右クリック**（地面・空中どちらでも可） |
    | 容量 | 1個のボールにつき 1体まで |

## モンスターボールとは

見た目は **スライムボール** ですが、表示名とロアが付いています。

| 状態 | 表示名 | ロア（説明） |
|---|---|---|
| 空のボール | `モンスターボール (空)` | `村人に右クリックで捕獲` |
| 捕獲済み | `モンスターボール: <村人名>` | `右クリックで <村人名> を放出` |

## ボールの入手

ボールは OP が `/monsterball give` で配布します。プレイヤーは自分では取得できないので、運営に依頼してください。

## 村人を捕獲する

1. **空のモンスターボール** をメインハンドに持つ。
2. 捕獲したい村人を **右クリック** する。
3. エンダーマンのテレポート音と共に村人が消え、インベントリの空ボールが **捕獲済みボール** に変わります。

!!! warning "捕獲できないケース"
    - 村人 **以外** のモブ（牛・羊・敵対モブなど）は対象外です。クリックしても何も起きません。
    - すでにデータの入ったボールでは新たに捕獲できません。「このモンスターボールは既にデータが入っています！」と表示されます。

## 村人を解放する

1. **捕獲済みのモンスターボール** をメインハンドに持つ。
2. 設置したい場所（ブロック）またはその付近の空中を **右クリック** する。
3. ブロックを右クリックした場合はその上、空中なら自分の前 1.5 ブロック先に村人が出現します。
4. ボールは **空のモンスターボール** に戻ります（同じ枠／インベントリ）。
5. 解放直後、チャットに復元手順のヒントが表示されます。

!!! tip "解放後の復元コマンド（重要）"
    解放した直後の村人は、**取引リスト・経験値・職業データを内部の一時データから完全には自動復元できません**。Minecraft が解放時にデフォルトの取引を再生成してしまうためです。完全に復元するには、解放した村人を **5ブロック以内でターゲット** して `/monsterball restore` を実行してください（OP権限が必要です）。

## 保持されるデータ

捕獲時にボールへ保存される情報は次のとおりです。

| 区分 | 保存内容 |
|---|---|
| 基本 | カスタム名（表示名）、村人タイプ（平原／砂漠／タイガなどのバイオーム外見） |
| 職業 | 職業（Profession）と職業レベル（Lv1〜Lv5 など） |
| 取引 | 取引レシピ全件（材料・結果・最大使用回数・現在使用回数・経験値報酬有無・需要値・価格乗数など） |
| 経験値 | 村人としての累積経験値 |

!!! note "保存できない／保存範囲外のもの"
    プレイヤーの **インベントリ内の所持アイテム**（村人がピックアップした作物など）は保存対象外です。装備品や個別の AI 状態（職業ブロックとの紐付けなど）も復元されません。

## プレイヤー用コマンド

| コマンド | 権限 | 説明 |
|---|---|---|
| `/monsterball` | 全員（実行のみ） | 簡易ヘルプ（give / restore）を表示 |
| `/monsterball give` | OP | 空のモンスターボールを 1 個取得 |
| `/monsterball restore` | OP | ターゲットしている村人（5ブロック以内）の取引データを復元 |

!!! info "OP権限について"
    `give` と `restore` は **OP 限定** です。一般プレイヤーが実行すると「権限がありません。」と表示されます。

## よくある質問

??? question "敵対モブやペットも捕獲できますか？"
    できません。Monsterball の捕獲対象は **村人（Villager）のみ** です。

??? question "解放した村人の取引内容が初期化されてしまいました"
    解放直後は Minecraft 側でデフォルトの取引が再生成される仕様です。**5ブロック以内で村人を直視**しながら `/monsterball restore`（OP のみ）を実行すると、捕獲時の取引・経験値・レベルが復元されます。

??? question "ボールを複数スタックできますか？"
    空のボールはスタックできますが、**捕獲済みのボールは個別の村人データを持つため別アイテム**となり、それぞれ 1 個ずつ扱う必要があります。

??? question "ボールが壊れたり消えたりしますか？"
    捕獲・解放のたびに 1 個ずつ消費／生成されます（持っていたスタックが 1 減り、別の枠に空ボールが追加されます）。ドロップや死亡で失うと中の村人ごと失われるので注意してください。

??? question "村人以外を右クリックしてしまいました"
    そのエンティティに対する通常の右クリック動作（ドアを開けるなど）も発生しません（イベントはキャンセルされませんが、捕獲処理がスキップされます）。
