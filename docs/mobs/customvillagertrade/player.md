# CustomVillagerTrade ― 遊び方 { .page-player #customvillagertrade-player }

サーバー上に配置された **カスタム村人** から、運営が独自に設定した取引内容で買い物ができるシステムです。バニラの村人と同じように **右クリック** で取引画面を開けます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 取引方法 | カスタム村人を **右クリック** |
    | 見分け方 | 名前が **金色** で表示され、その場から動かない |
    | 必要権限 | `customvillagertrade.use`（既定で全員に許可） |
    | 取引画面 | 通常のMinecraftの取引画面（バニラと同じUI） |
    | 統合版（Bedrock/Geyser） | 対応（取引画面はクライアントが自動で開きます） |

## カスタム村人とは

CustomVillagerTrade で登録された村人は、運営が **取引内容・職業・レベル** を自由に設定したNPCです。次のような特徴があります。

- 名前が **金色（§6）** で表示される。
- その場から **動かない**（AIが無効化されています）。
- 取引内容は運営が決めたもの。バニラの「在庫切れ」ロック挙動は無効化され、何度でも取引できる設定です。

## カスタム村人との取引方法

1. カスタム村人に近づき、**右クリック** します。
2. 通常の村人取引画面が開きます。
3. 左側に必要な材料（材料1・材料2）を置き、右側の結果アイテムを受け取ります。
4. 必要な材料がインベントリにあれば、何度でも繰り返し取引できます。

!!! tip "材料2について"
    取引によっては材料1だけのもの（例: 小麦20個 → エメラルド1個）と、材料1＋材料2の両方が必要なもの（例: エメラルド＋本 → エンチャント本）があります。画面に表示された材料スロットに従って素材を投入してください。

!!! note "CasinoPlugin 連携時の支払い"
    サーバーで CasinoPlugin が稼働している場合、運営の設定によっては **エメラルド残高（EmeraldAPI）** から自動で支払いが行われる取引が用意されていることがあります。残高が不足していると取引に失敗するメッセージが表示されます。詳細はサーバー運営にご確認ください。

## よくある質問

??? question "普通の村人とどう違うの？"
    名前が **金色** で表示され、その場から **動かない** 村人がカスタム村人です。取引内容は運営が手動で設定したもので、バニラの職業ごとの自動取引とは異なります。

??? question "取引画面が開きません"
    通常の村人と同じく **右クリック** で開きます。統合版（Bedrock/Geyser）ではクライアントが自動的に取引画面を開く設計のため、サーバーラグなどで遅延することがあります。一度離れて再度試してみてください。

??? question "取引回数に上限はありますか？"
    カスタム村人の取引は **取引ごとの最大回数（既定 999 回）** が設定されています。実用上はほぼ無制限と考えて問題ありませんが、運営が制限している場合は途中で取引できなくなることがあります。

??? question "エメラルド残高で支払う取引があると聞きました"
    CasinoPlugin が導入されている場合に限り、運営の設定で **エメラルド残高（EmeraldAPI）** を使った取引が利用可能になることがあります。残高が足りないと「エメラルドバンクの残高が不足しています。」と表示されます。

??? question "カスタム村人を倒したり連れて行ったりできますか？"
    カスタム村人は運営が登録した重要なNPCです。ダメージを与えたり連れ去ったりはせず、取引の利用のみに使ってください（仕様や保護設定はサーバーによって異なります）。
