# MobBall ― 遊び方 { .page-player #mobball-player }

MobBall は、生物をボールに収納して持ち歩ける統合プラグインです。**村人ボール（villager モジュール）** と **モンスターボール（monster モジュール）** の 2 種類のボールが入っていて、それぞれ別の見た目・別の使い方で動きます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | モジュール構成 | villager（村人ボール）／ monster（モンスターボール） |
    | 共通の対象 | 村人（Villager） |
    | ボールの入手 | OP からの配布のみ（`/villagerball give`、`/monsterball give`） |
    | 捕獲方法 | 空のボールを持って村人を右クリック |
    | 解放方法 | 中身入りボールで地面・空中を右クリック |
    | 既存配布済みのボール | 旧 VillagerBall / Monsterball のボールも **そのまま動作** します |

## どんなプラグイン？

MobBall は **2 つのモジュール** を 1 つの jar にまとめた統合プラグインです。それぞれ独立して動くので、用途に合わせて使い分けます。

| モジュール | 一言で言うと | 既定のボール素材 | 取引データの扱い |
|---|---|---|---|
| **villager** | 村人をボール化して持ち歩く（旧 VillagerBall） | 空＝エンダーパール／村人入り＝エンダーアイ | 捕獲時に **取引内容を JSON で保存** → 解放時に自動復元 |
| **monster** | 村人をボール化して持ち歩く（旧 Monsterball） | スライムボール（空・捕獲済みとも） | 捕獲時に取引データを保存 → 解放後 `/monsterball restore` で復元 |

!!! tip "どっちを使えばいい？"
    どちらも「村人を箱詰めして運ぶ」という用途は同じです。**取引データを自動で戻したいなら villager モジュール**、運営が手動で復元する運用なら monster モジュールが向いています。サーバーの運営方針に従って配布されたものを使ってください。

## ボールの入手

どちらのモジュールのボールも、**プレイヤーは自分では作れません**。OP から配布してもらう形になります。

| 欲しいもの | 依頼するコマンド |
|---|---|
| 村人ボール（空・エンダーパール風） | `/villagerball give`（OP のみ実行可） |
| モンスターボール（空・スライムボール風） | `/monsterball give`（OP のみ実行可） |

!!! note "見た目で見分ける"
    - **村人ボール**：空はエンダーパール、村人入りはエンダーアイ（どちらも光ったエフェクト＋「村人ボール」表記）。
    - **モンスターボール**：空も捕獲済みもスライムボール。表示名が「モンスターボール (空)」「モンスターボール: \<村人名\>」になります。

## 村人の捕獲方法（共通）

1. 空のボール（村人ボール or モンスターボール）をメインハンドに持つ。
2. 捕獲したい村人を **右クリック** する。
3. 成功すると、村人がその場で消え、インベントリのボールが **村人入り** に変わります。

!!! warning "捕獲できないケース"
    - 対象が **村人（Villager）以外** だと捕獲できません。MobBall の捕獲対象は基本的に村人のみです。
    - すでにデータの入ったモンスターボールでは新たに捕獲できません。
    - villager モジュールでは、既定で **取引画面を開いている村人は捕獲不可** です（「&c取引中の村人は捕獲できません。」と表示）。
    - 村人ボールには **捕獲成功率の設定** があり、運営が 100% 未満にしている場合は失敗することもあります。失敗時はボールは消費されません。

## 村人の解放方法（共通）

1. 中身入りのボールをメインハンドに持つ。
2. **空中またはブロック** を右クリックする（村人や他のエンティティに対してではなく）。
3. プレイヤーの正面に村人がスポーンします。
4. ボールは **空のボール** に戻ります。

!!! tip "解放後の取引データの扱い"
    - **村人ボール（villager）** ：解放と同時に取引・職業・レベル・経験値・体力・カスタム名・タイプが自動で復元されます。プレイヤー側で追加コマンドを叩く必要はありません。
    - **モンスターボール（monster）** ：解放直後は Minecraft 側でデフォルトの取引が再生成されるため、**OP に `/monsterball restore` を実行してもらう** ことで完全復元できます（解放した村人を 5 ブロック以内でターゲットする必要あり）。

## 保持されるデータ

両モジュールとも、村人の取引内容や職業を **ボールの中に保存** しています。

| データ | villager モジュール | monster モジュール |
|---|---|---|
| 職業（Profession） | ✅（設定で個別 OFF 可） | ✅ |
| 村人レベル（Lv1〜5） | ✅ | ✅ |
| バイオームタイプ（平原・砂漠など） | ✅ | ✅ |
| 経験値 | ✅ | ✅ |
| 体力 | ✅ | ― |
| カスタム名 | ✅ | ✅ |
| 取引内容（レシピ全件） | ✅ | ✅（要 `/monsterball restore` で復元） |

!!! warning "保存範囲外のもの（共通）"
    村人がピックアップした作物などの **インベントリ内アイテム**、装備品、職業ブロックとの紐付けは保存されません。また villager モジュールでは、**取引材料はエンチャント本などのカスタム NBT を含まない** 形で保存されます（材料の Material と数量のみ）。

## プレイヤー用コマンド

| コマンド | 権限 | モジュール | 説明 |
|---|---|---|---|
| `/villagerball` | なし（help のみ） | villager | ヘルプを表示（`give` / `reload` は OP のみ） |
| `/villagerball give [プレイヤー] [個数]` | `villagerball.admin` | villager | 空の村人ボールを配布 |
| `/villagerball reload` | `villagerball.admin` | villager | villager モジュールの設定をリロード |
| `/monsterball` | なし（ヘルプのみ） | monster | ヘルプを表示 |
| `/monsterball give` | `monsterball.admin` | monster | 空のモンスターボールを 1 個取得 |
| `/monsterball restore` | `monsterball.admin` | monster | ターゲットしている村人（5 ブロック以内）の取引データを復元 |

!!! info "統合管理コマンド `/mobball`（`/mb`）について"
    管理者向けに `/mobball modules`（モジュール一覧）・`/mobball reload`（メイン config リロード）・`/mobball version`（バージョン表示）が用意されています。プレイヤー側で叩く機会は通常ありません。

## よくある質問

??? question "村人ボールとモンスターボール、どちらを使えばいいですか？"
    どちらも村人を運ぶ用途は同じです。**取引を自動で戻したいなら村人ボール（villager）**、運営が `/monsterball restore` で手動復元する運用ならモンスターボール（monster）です。サーバーで配布されたものを使えば OK です。

??? question "ボールはクラフトで作れますか？"
    どちらも **作れません**。OP に `/villagerball give` または `/monsterball give` で配布してもらってください。

??? question "捕獲が失敗するとボールは減りますか？"
    減りません。村人ボールは「成功率に外れた」ときに空のボールがそのまま残ります（クールダウンだけ適用される場合あり）。モンスターボールは「すでにデータ入りだった」「対象が村人でない」場合はそもそも捕獲処理が走らずボールは無傷です。

??? question "ゾンビ村人や行商人、敵対モブは捕獲できますか？"
    できません。MobBall の対象は **通常の村人（Villager）のみ** です。

??? question "村人入りボールを右クリックしても解放されません"
    村人や他のエンティティに向かって右クリックしていませんか？ 解放は **空中またはブロックへの右クリック** で発動します。それでも反応しない場合は、`villagerball.release` 権限・クールダウン・モジュールの有効状態を運営に確認してください。

??? question "以前 VillagerBall / Monsterball で配布されたボールは使えますか？"
    **はい、そのまま使えます**。MobBall は旧プラグインの PDC（NamespacedKey）を互換読み込みするように作られているので、既存配布済みのボールアイテムは捕獲・解放ともそのまま動作します。

??? question "あるボールのコマンドが「不明なコマンド」と出ます"
    そのモジュールが運営側で無効化されている可能性があります。MobBall はモジュール式で、運営がモジュール単位で ON / OFF できる仕組みです。運営にお問い合わせください。
