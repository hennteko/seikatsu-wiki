# MobBall ― 遊び方 { .page-player #mobball-player }

MobBall は、あらゆるモブをボールに収納して持ち歩ける統合プラグインです。**捕獲ボール（capture モジュール）** という 1 種類のボールで、村人から動物・モンスターまで幅広く捕まえて、好きな場所で解放できます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | モジュール構成 | capture（捕獲ボール）1 種のみ |
    | 対象モブ | あらゆるモブ（Mob）― 村人・動物・モンスターなど（ボス・プレイヤーは除く） |
    | ボールの入手 | OP からの配布のみ（`/mobball give`、`/mb give`） |
    | 捕獲方法 | 空の捕獲ボールを持ってモブを右クリック |
    | 解放方法 | 中身入りボールで地面・空中を右クリック |
    | 保持されるデータ | 捕獲時にモブの全データ（取引・装備・体力・名前など）をそのまま保存 |

## どんなプラグイン？

MobBall は **1 種類の捕獲ボール** で、あらゆるモブを「箱詰め」して持ち運べるプラグインです。空のボールと中身入りボールは **同じ素材（エンダーパール風）** で、表示名で見分けます。

| ボールの状態 | 見た目 | できること |
|---|---|---|
| **空ボール** | エンダーパール（光ったエフェクト＋「捕獲ボール (空)」表記） | モブを右クリックで捕獲 |
| **中身入りボール** | エンダーパール（「捕獲ボール: 〈モブ名〉」表記） | 空中・ブロックを右クリックで解放 |

!!! tip "全データがそのまま保存される"
    捕獲ボールは、捕まえたモブの **全 NBT データ** を保存します。村人の取引内容・職業・レベル、動物の年齢や体力、カスタム名などが、解放したときにそのまま復元されます。追加コマンドを叩く必要はありません。

## ボールの入手

捕獲ボールは、**プレイヤーは自分では作れません**（クラフトレシピはありません）。OP から配布してもらう形になります。

```text title="捕獲ボールの入手を依頼するコマンド（OP のみ実行可）"
/mobball give [プレイヤー] [個数]
```

!!! note "見た目で見分ける"
    - **空ボール**：エンダーパールに光ったエフェクト。表示名は「捕獲ボール (空)」。
    - **中身入りボール**：同じエンダーパール。表示名が「捕獲ボール: 〈捕まえたモブ名〉」になります。

## モブの捕獲方法

1. 空の捕獲ボールをメインハンドに持つ。
2. 捕獲したいモブを **右クリック** する。
3. 成功すると、モブがその場で消え、手持ちの空ボールが 1 個消費されて **中身入りボール** がインベントリに追加されます。

!!! warning "捕獲できないケース"
    - 対象が **モブ（Mob）以外**（プレイヤー・防具立て・アイテムフレーム・トロッコなど）だと捕獲できません。これらに右クリックしても何も起きず、通常の操作がそのまま通ります。
    - **ボス**（エンダードラゴン・ウィザーなど）は既定で捕獲できません（「&cボスは捕獲できません。」と表示）。
    - 既定では **取引画面を開いている村人は捕獲不可** です（「&c取引中の村人は捕獲できません。」と表示）。
    - 運営が **捕獲成功率** を 100% 未満に設定している場合は失敗することもあります。失敗してもボールは消費されません。

## モブの解放方法

1. 中身入りのボールをメインハンドに持つ。
2. **空中またはブロック** を右クリックする（モブや他のエンティティに対してではなく）。
3. クリックしたブロックの上、または自分の正面にモブがスポーンします。
4. 中身入りボールが 1 個消費され、**空のボール** が手に入ります。

!!! tip "解放後のデータ"
    解放したモブは、捕獲時のデータ（村人の取引・職業・レベル・経験値、動物の年齢、体力、カスタム名など）をそのまま保持した状態でスポーンします。村人の取引を手動で戻すような作業は不要です。

## 保持されるデータ

捕獲ボールは、モブの状態を **エンティティの全 NBT** としてボールの中に保存します。そのため、おおむね次のようなデータがそのまま復元されます。

| データ | 保存 |
|---|---|
| 村人の取引内容（レシピ全件） | ✅ |
| 村人の職業・レベル・バイオームタイプ・経験値 | ✅ |
| 体力 | ✅ |
| 装備・手持ちアイテム | ✅ |
| カスタム名 | ✅ |
| 年齢（子供／大人）・繁殖クールダウン等 | ✅ |

!!! note "UUID は再生成されます"
    解放されたモブは元の個体そのものではなく、保存データから復元された新しい個体です（内部 UUID は付け直されます）。見た目・能力・取引などのデータは引き継がれますが、UUID で個体を管理している別プラグインがある場合はご注意ください。

## プレイヤー用コマンド

```text title="ヘルプを表示（引数なし）"
/mobball
```

```text title="捕獲ボールを付与（OP のみ・mobball.give 権限）"
/mobball give [プレイヤー] [個数]
```

!!! info "統合管理コマンド `/mobball`（`/mb`）について"
    `/mobball` には管理者向けに `modules`（モジュール一覧）・`reload`（config リロード）・`version`（バージョン表示）も用意されています。プレイヤー側で叩く機会は通常ありません。詳細は OP・運営向けページを参照してください。

## よくある質問

??? question "どんなモブを捕まえられますか？"
    村人・動物・モンスターなど、ほぼすべての **モブ（Mob）** を捕まえられます。ただし **ボス**（エンダードラゴン・ウィザーなど）は既定で除外され、**プレイヤー・防具立て・アイテムフレーム・トロッコ** などモブ以外は対象外です。

??? question "ボールはクラフトで作れますか？"
    作れません。OP に `/mobball give` で配布してもらってください。

??? question "捕獲が失敗するとボールは減りますか？"
    減りません。成功率に外れた場合や、対象がモブでなかった場合は、空のボールがそのまま残ります（クールダウンが有効な設定では、失敗時にクールダウンだけ適用される場合があります）。

??? question "村人の取引は解放後もそのまま残りますか？"
    残ります。捕獲ボールはモブの全データを保存するため、村人の取引内容・職業・レベルなどは解放時にそのまま復元されます。旧 Monsterball のような手動の復元コマンドは不要です。

??? question "中身入りボールを右クリックしても解放されません"
    モブや他のエンティティに向かって右クリックしていませんか？ 解放は **空中またはブロックへの右クリック** で発動します。それでも反応しない場合は、`mobball.release` 権限・クールダウン・モジュールの有効状態を運営に確認してください。

??? question "捕獲ボールを投げても飛んでいきません"
    仕様です。素材はエンダーパールですが、MobBall が **投擲（テレポート）を無効化** しています。右クリックは捕獲・解放のためだけに使われます。

??? question "コマンドが「不明なコマンド」と出ます"
    capture モジュールが運営側で無効化されている可能性があります。MobBall はモジュール式で、運営がモジュール単位で ON / OFF できる仕組みです。運営にお問い合わせください。
