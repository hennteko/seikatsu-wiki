# Ranking ― 遊び方 { .page-player #ranking-player }

採掘や釣りなど、あなたの行動が自動でカウントされ、**ランキング** に反映されます。さらに、一定回数の行動を達成するたびに **エメラルド報酬** が自動で支払われます。特別な操作は不要で、いつも通りプレイするだけです。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | カウントされる統計 | 採掘・釣り・設置・食事・討伐・レベル・与ダメージ（7種） |
    | できること | 自分の統計確認・ランキング表示 |
    | 報酬 | 一定回数の行動ごとにエメラルドが自動で入る |
    | リセット | 毎月1日に統計が自動リセット |
    | メインコマンド | `/ranking`（エイリアス `/rank` ほか） |

## カウントされる統計の種類

Ranking は次の7種類の統計を自動でカウントします。

| 統計 | 内容 | 数え方 |
|---|---|---|
| ⛏ 採掘 | ブロックを破壊した数 | ブロック |
| 🎣 釣り | 釣りで魚（アイテム）を釣り上げた回数 | 回 |
| 🧱 設置 | ブロックを設置した数 | ブロック |
| 🍖 食事 | 食べ物を食べた回数 | 個 |
| ⚔ 討伐 | モンスターなどを倒した数 | 体 |
| ⭐ レベル | 現在の経験値レベル | Lv |
| 💥 与ダメージ | エンティティに与えたダメージの合計 | ダメージ |

!!! note "カウントされないケース"
    クリエイティブモードでの採掘・設置はカウントされません。釣りは魚やアイテムを釣り上げた成功時のみカウントされます。食事はポーションなどではなく「食べられるアイテム」のみが対象です。討伐・与ダメージは **対プレイヤー（PvP）は対象外** で、モンスターなどへの行動だけがカウントされます。

## 自分の統計を見る

`/ranking` を引数なしで実行すると、自分のすべての統計がチャットに表示されます。

- 各統計の累計と、報酬が有効な統計では「次の報酬まであと何回」かが表示されます。
- 採掘順位（自分が採掘で何位か）も表示されます。
- 「よく掘るブロック TOP5」「よく討伐するMob TOP5」も合わせて表示されます。

| コマンド | 説明 |
|---|---|
| `/ranking` | 自分の全統計を表示 |
| `/ranking stats` | 同上（自分の統計を表示） |

## ランキングを見る

統計の種類ごとに、サーバー内の上位プレイヤーをランキング表示できます。

| コマンド | 説明 |
|---|---|
| `/ranking ranking [種類] [人数]` | 指定した統計のランキングを表示 |
| `/ranking top [種類] [人数]` | 同上（`ranking` と同じ動作） |

- 種類を省略すると **採掘** のランキングになります。
- 種類に指定できるのは `mining` `fishing` `placing` `eating` `killing` `level` `damage` です。
- 例：`/ranking ranking fishing 10` で釣りランキングの上位10人を表示します。
- `ranking` は人数を1～100の範囲で指定できます（省略時は10人）。
- 1位は金色、2位は灰色、3位は青色で強調表示されます。

!!! tip "ランキング看板"
    運営がサーバー内に **ランキング看板** を設置している場合があります。看板には統計ごとの上位プレイヤーが表示され、一定間隔で自動更新されます。コマンドを打たなくても、看板を見るだけで順位を確認できます。

## 月次リセットと報酬

### 月次リセット

統計データは **毎月1日（日本時間）に自動でリセット** されます。

- リセット時、前月のランキングは運営側のフォルダにアーカイブ（保存）されます。
- リセットが実行されると、全体チャットに月次リセットのお知らせが流れます。
- リセット後は全員の統計が0からの再スタートになります。毎月ランキング上位を狙えます。

### エメラルド報酬

報酬が有効な統計では、**一定回数の行動ごとにエメラルドが自動で支払われます**。報酬は CasinoPlugin の銀行口座（残高）に直接入ります。

- 例（初期設定）：採掘は20ブロックごとに1エメラルド、釣りは30回ごとに1エメラルド、討伐は50体ごとに2エメラルド。
- 報酬を受け取ると、チャットにメッセージが表示され、効果音が鳴ります。
- どの統計に報酬が付くか、何回ごとにいくら貰えるかは **サーバーの設定によって変わります**。詳しくは運営にご確認ください。

!!! warning "報酬が受け取れないとき"
    報酬は CasinoPlugin（EmeraldAPI）を経由して支払われます。CasinoPlugin が停止しているなどで利用できない場合、報酬は支払われず、その旨のメッセージが表示されることがあります。その際は運営にご連絡ください。

## プレイヤー用コマンド一覧

| コマンド | 説明 |
|---|---|
| `/ranking` | 自分の全統計を表示 |
| `/ranking stats` | 自分の統計を表示 |
| `/ranking ranking [種類] [人数]` | ランキングを表示 |
| `/ranking top [種類] [人数]` | ランキングを表示（`ranking` と同じ） |
| `/ranking help` | ヘルプを表示 |

!!! note "コマンドのエイリアス"
    `/ranking` は `/rank` `/miningrank` `/mrank` `/digcount` でも実行できます。どれを使っても動作は同じです。

## よくある質問

??? question "統計が増えていません"
    クリエイティブモードでの採掘・設置はカウントされません。サバイバル（またはアドベンチャー）モードでプレイしているか確認してください。釣りは魚やアイテムを釣り上げた成功時のみ、食事は「食べられるアイテム」のみがカウント対象です。

??? question "エメラルド報酬が入りません"
    報酬はすべての統計に付くわけではありません。サーバーの設定で報酬が無効になっている統計（設置・食事・レベル・与ダメージなど）では報酬は支払われません。また、報酬は CasinoPlugin の口座へ入金されるため、CasinoPlugin が動作している必要があります。

??? question "ランキングがリセットされました"
    統計は毎月1日に自動でリセットされる仕様です。前月の記録は運営側に保存されています。毎月新しい気持ちで上位を目指せます。

??? question "他のプレイヤーの統計を見たいです"
    `/ranking stats <プレイヤー名>` で他人の統計を見られますが、これには専用の権限が必要で、通常は運営スタッフのみが使用できます。

??? question "PvPで倒した相手は討伐数に入りますか？"
    入りません。討伐数・与ダメージは対モンスターなどの行動のみがカウントされ、プレイヤー同士の戦闘（PvP）は対象外です。
