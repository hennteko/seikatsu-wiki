# EmeraldBank ― 使い方 { .page-player #emeraldbank-player }

エメラルドを銀行口座に **預け入れ・引き出し・送金** できる経済プラグインです。手元のエメラルドを口座に預けておけば、インベントリを圧迫せず安全に管理できます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 通貨 | エメラルド（1個 = 1 E） |
    | できること | 預け入れ・引き出し・送金・残高確認・ランキング |
    | 便利アイテム | エメラルドウォレット / エメラルド通帳 |
    | メインコマンド | `/emerald`（エイリアス `/eb`） |

## 銀行のしくみ

あなたの口座残高はサーバー側に保存されます。インベントリにあるエメラルドを **預け入れ** ると残高が増え、**引き出す** とエメラルドアイテムが手元に戻ります。残高はアイテムとして失う心配がなく、`/eb send` で他のプレイヤーへ送ることもできます。

!!! note "1 E = エメラルド1個"
    残高の単位「E」は通常のエメラルドアイテム1個に対応します。預け入れ・引き出し・送金はすべて **1以上の整数** で指定します。

## エメラルドを預け入れる

インベントリにあるエメラルドを口座に預けます。

| コマンド | 説明 |
|---|---|
| `/eb deposit <数字>` | 指定した数のエメラルドを預け入れる |
| `/ed <数字>` | 上と同じ（短縮コマンド） |

- 例：`/eb deposit 64` または `/ed 64` で64個を預け入れます。
- インベントリ内のエメラルドが足りない場合は、預けられる最大数が表示されます。

!!! warning "細工されたエメラルドは預けられません"
    名前・説明文（Lore）・エンチャント・カスタムモデルが付いた **細工済みエメラルド** は預け入れできません。預け入れたいときはインベントリから取り除いてください。通常のエメラルドのみが対象です。

## エメラルドを引き出す

口座残高からエメラルドアイテムを取り出します。

| コマンド | 説明 |
|---|---|
| `/eb withdraw <数字>` | 指定した数のエメラルドを引き出す |
| `/ew <数字>` | 上と同じ（短縮コマンド） |

!!! tip "インベントリが満杯でも安心"
    引き出した分がインベントリに入りきらない場合、あふれた分は **足元に自動でドロップ** され、その旨がチャットに表示されます。アイテムが消失することはありません。

## 残高を確認する

| コマンド | 説明 |
|---|---|
| `/eb money` | 自分のエメラルド残高をチャットに表示 |

通帳やウォレットを持っている場合は、それらを使っても残高を確認できます（後述）。

## エメラルドを送金する

他のプレイヤーへエメラルドを送れます。相手がオフラインでも送金可能です。

| コマンド | 説明 |
|---|---|
| `/eb send <数字> <プレイヤー名>` | 指定プレイヤーへエメラルドを送金 |

- 例：`/eb send 100 Steve` で Steve に100 E を送金します。
- 自分の残高が足りない場合は送金できません。
- 自分自身への送金はできません。
- 相手がオンラインのときは、受け取った旨が相手にも通知されます。

## 残高ランキング

サーバー内の残高ランキングを確認できます。

| コマンド | 説明 |
|---|---|
| `/eb list` | 全プレイヤーの残高一覧をチャットに表示 |
| `/eb ranking` | エメラルドバンク残高ランキング（トップ10）を表示 |

- `/eb ranking` は **トップ10** を、1位🥇・2位🥈・3位🥉のメダル付きで表示します。
- `/eb list` は登録されている全プレイヤーの残高を順位付きで表示します。

## エメラルドウォレット

`/eb wallet` で入手できる、**残高がリアルタイムに表示されるアイテム**（金インゴット）です。

- 持ち替える（手に持つ）たびに、表示されている残高が最新の値に更新されます。
- ウォレットを **右クリック** すると、そのままバンクGUIが開きます。
- ウォレットには所有者が記録されており、他人のウォレットは使用できません。

## エメラルド通帳

`/eb book` で入手できる、残高を確認できるアイテム（紙）です。

- 通帳を **右クリック** すると、そのときの残高がチャットに表示されます。
- 持ち替えたときや、預け入れ・引き出し・送金をしたときに表示が自動更新されます。

## バンクGUI

ボタンを押すだけでエメラルドを出し入れできる画面です。

- 開き方：`/eb gui` コマンド、または **ウォレットを右クリック**。
- **緑のボタン**（預け入れ）… 1個 / 10個 / 64個 / 全額。
- **赤のボタン**（引き出し）… 1個 / 10個 / 64個 / 全額。
- 中央のダイヤモンドに現在の残高が表示されます。
- バリア（閉じる）ボタンでGUIを閉じられます。

## プレイヤー用コマンド一覧

| コマンド | エイリアス | 説明 |
|---|---|---|
| `/eb book` | `/emerald book` | エメラルド通帳を入手 |
| `/eb wallet` | `/emerald wallet` | エメラルドウォレットを入手 |
| `/eb gui` | `/emerald gui` | バンクGUIを開く |
| `/eb money` | `/emerald money` | 残高をチャットで確認 |
| `/eb deposit <数字>` | `/ed <数字>` | エメラルドを預け入れ |
| `/eb withdraw <数字>` | `/ew <数字>` | エメラルドを引き出し |
| `/eb send <数字> <プレイヤー>` | `/emerald send ...` | エメラルドを送金 |
| `/eb list` | `/emerald list` | 全プレイヤーの残高一覧を表示 |
| `/eb ranking` | `/emerald ranking` | 残高ランキング（トップ10）を表示 |

!!! note "`/eb` と `/emerald` は同じコマンド"
    `/eb` は `/emerald` のエイリアスです。どちらで実行しても動作は同じです。`/ed` と `/ew` はそれぞれ `/eb deposit` と `/eb withdraw` の専用ショートカットです。

## よくある質問

??? question "預け入れようとしても「細工されたエメラルド」と言われます"
    名前・説明文・エンチャント・カスタムモデルなどが付いた特殊なエメラルドはインベントリにあると預け入れがブロックされます。それらを別の場所に移してから、通常のエメラルドだけで預け入れてください。

??? question "全額引き出したらアイテムが地面に落ちました"
    インベントリに入りきらなかった分は消えずに足元へドロップされます。拾い直せば問題ありません。チャットにもドロップ個数が表示されます。

??? question "オフラインのプレイヤーに送金できますか？"
    できます。`/eb send` はオフラインのプレイヤーにも送金可能です。相手は次回ログイン時に残高が増えています。

??? question "残高がマイナスになっています"
    EmeraldBank はマイナス残高（借金）に対応した設計です。送金や他プラグインの処理によって残高がマイナスになる場合があります。詳細は運営にご確認ください。

??? question "他人のウォレットを右クリックしたら使えませんでした"
    ウォレットと通帳には所有者が登録されています。自分名義のもの以外は使用できません。`/eb wallet` で自分用のウォレットを発行してください。
