# EmeraldBank <span class="badge done">公開中</span>

エメラルドを **預け入れ・引き出し・送金** できる、生活鯖の経済の基盤となる **銀行プラグイン** です。所持エメラルドを口座に預けてアイテムとして持ち歩く必要をなくし、ウォレットや通帳、ランキング看板などの便利機能も備えています。

!!! info "サーバーでの稼働形態について"
    EmeraldBank は単体プラグインとしても存在しますが、生活鯖で実際に稼働しているのは統合版 **CasinoPlugin に内包された銀行モジュール** です。サーバー経済の通貨（エメラルド残高）を一元管理する基盤として動作し、他のプラグインもこの口座データを参照します。挙動は本ページで説明する EmeraldBank の仕様に準じます。
