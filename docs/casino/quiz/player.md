# クイズ ― 遊び方 { .page-player #quiz-player }

4択クイズに答えてエメラルドを稼ぐゲームです。1日1回挑戦できる **デイリークイズ** と、全100階を登り続ける **クイズタワー** の2つのモードがあり、正解率や到達階のランキングも用意されています。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | モード | デイリークイズ（毎日5問）／クイズタワー（全100階） |
    | 回答方法 | GUI（インベントリ画面）で4択から1つをクリック |
    | デイリーの報酬 | 1問正解ごとに 5E、全問正解で +25E、連続参加ボーナスあり |
    | タワーの参加費 | 100E（クリア・撤退で報酬。失敗すると没収） |
    | 報酬通貨 | エメラルド（銀行の口座残高） |
    | 必要なもの | `quiz.use` 権限（遊べないときは運営に相談） |

## どんなゲーム？

クイズは **4択問題に答えるゲーム** です。問題はインベントリのような GUI 画面に表示され、A・B・C・D の選択肢ブロックをクリックして回答します。

- **デイリークイズ** … 毎日5問。気軽に挑戦できて、正解数に応じてエメラルドがもらえます。
- **クイズタワー** … 参加費を払って全100階を登り続ける挑戦モード。上の階ほど問題が難しくなります。

どちらのモードも、正解・不正解はチャットに表示され、約2秒後に次の問題へ進みます。

!!! note "遊ぶには権限が必要です"
    クイズの利用には `quiz.use` 権限が必要です（既定では付与されていません）。コマンドを使っても「権限がありません」と表示される場合は、運営に権限の付与を相談してください。

## デイリークイズの遊び方

`/qd`（または `/quiz daily`）でデイリークイズを開始します。NPC が設置されている場合は、デイリー用 NPC を右クリックしても始められます。

- **毎日5問** が出題されます。GUI に問題文（本アイテム）と A〜D の選択肢が表示されます。
- 選択肢ブロックをクリックして回答します。正解なら「✓ 正解！」、不正解なら正解の選択肢が表示されます。
- 5問すべて回答すると結果が表示され、報酬のエメラルドが口座に入ります。
- **挑戦は1日1回のみ** です。同じ日に再挑戦することはできません。

!!! tip "デイリークイズの報酬"
    | 報酬 | 内容 |
    |---|---|
    | 基本報酬 | 1問正解ごとに **5E** |
    | 全問正解ボーナス | 5問すべて正解で **+25E**（合計 50E） |
    | 連続参加ボーナス | 連続して参加した日数に応じて加算（下記参照） |

### 連続参加ボーナス

デイリークイズを毎日続けて挑戦すると、連続日数に応じたボーナスエメラルドがもらえます。

| 連続日数 | ボーナス |
|---|---|
| 3日連続 | +15E |
| 7日連続 | +50E |
| 14日連続 | +150E |
| 30日連続 | +500E |

## クイズタワーの遊び方

`/qt`（または `/quiz tower`）でクイズタワーを開始します。タワー用 NPC を右クリックしても始められます。

- 開始時に **参加費 100E** が口座から引かれます（残高不足だと挑戦できません）。
- 1階からスタートし、問題に正解するたびに1階ずつ上へ進みます。
- 階が上がるほど問題は難しくなります（1〜30階＝やさしい、31〜60階＝中級、61〜90階＝上級、91〜100階＝最難関）。
- 不正解になると **ライフが1つ減ります**。ライフは10あり、**10回失敗するとゲームオーバー** です。
- ゲームオーバーになると、その時点までの **参加費は没収** されます（報酬はありません）。
- **100階に到達するとタワー完全制覇** です。所要時間が記録されます。
- 挑戦の途中で GUI を閉じても、次に `/qt` を実行すると **同じ階から再開** できます。

!!! note "10階ごとのチェックポイントと撤退"
    10の倍数の階（10・20・30…）は **チェックポイント** です。チェックポイントに到達すると、その階の GUI に「撤退する」ボタンが表示されます。撤退を選ぶと、それ以上挑戦せずに報酬を受け取って終了できます。

### タワーの報酬

| 報酬 | 内容 |
|---|---|
| 撤退報酬 | チェックポイントで撤退すると **参加費 × 到達階 ÷ 10** のエメラルド（例: 50階で撤退 = 100 × 50 ÷ 10 = 500E） |
| 100階制覇報酬 | クイズタワーを完全制覇すると **1000E**（既定値。サーバー設定により変わる場合あり） |
| ゲームオーバー時 | 報酬なし。参加費 100E も戻りません |

!!! warning "失敗すると参加費は戻りません"
    クイズタワーでライフを使い切ってゲームオーバーになると、参加費の 100E は没収されます。自信がないときは、チェックポイントで「撤退」して報酬を確保するのも有効な戦略です。

## ランキング

クイズには3種類のランキングがあります。`/quiz ranking <種類>` で表示できます。

| ランキング | コマンド | 内容 |
|---|---|---|
| 正解率 | `/quiz ranking accuracy` | 正解率の高い順（10問以上回答した人が対象） |
| 総正解数 | `/quiz ranking total` | 正解した問題数の多い順 |
| クイズタワー | `/quiz ranking tower` | 100階制覇者はクリアタイムの速い順、未制覇者は到達階の高い順 |

サーバーに **ランキング看板** が設置されている場合は、その看板でデイリー正解数やタワー到達階の上位プレイヤーを確認できます（看板は数分ごとに自動更新されます）。

## プレイヤー用コマンド

| コマンド | エイリアス | 説明 |
|---|---|---|
| `/quiz` | `/q` | クイズのヘルプを表示 |
| `/quiz daily` / `/qd` | ― | デイリークイズに挑戦 |
| `/quiz tower` / `/qt` | ― | クイズタワーに挑戦 |
| `/quiz ranking <accuracy\|total\|tower>` | ― | ランキングを表示 |

## よくある質問

??? question "デイリークイズは1日に何回でも遊べますか？"
    いいえ、デイリークイズは **1日1回のみ** です。一度挑戦すると、その日のうちは再挑戦できません。次の日になると、また挑戦できるようになります。

??? question "クイズタワーで途中でやめたらどうなりますか？"
    GUI を閉じただけなら挑戦は中断状態で残り、次に `/qt` を実行すると同じ階から再開できます。10の倍数の階（チェックポイント）にいるときに「撤退する」ボタンを押すと、報酬を受け取って正式に終了できます。

??? question "クイズタワーの参加費は必ず戻ってきますか？"
    いいえ。クリアやチェックポイントでの撤退をした場合は報酬を受け取れますが、**ライフを使い切ってゲームオーバーになると参加費 100E は没収** されます。

??? question "正解の報酬はどこに入りますか？"
    エメラルドは銀行の **口座残高** に入ります。受け取った報酬は、CasinoPlugin の他のゲームでもそのまま使えます。

??? question "クイズのコマンドが「権限がありません」と出ます"
    クイズの利用には `quiz.use` 権限が必要で、既定では付与されていません。運営に権限の付与を相談してください。

??? question "問題が難しすぎます / 同じ問題ばかり出ます"
    クイズタワーは階が上がるほど難易度が上がります。問題は直近に出たものを避けて選ばれますが、問題数によっては似た問題が出ることがあります。問題の追加は運営が行います。
