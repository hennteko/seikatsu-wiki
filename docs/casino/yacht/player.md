# ヨット（ヤッツィー） ― 遊び方 { .page-player #yacht-player }

5個のサイコロを振って役を作るサイコロ賭博です。賭け金・配当はすべてエメラルド銀行の残高でやり取りされます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | クイックヨット（1人用GUI）＋役比べ（マルチ2〜4人）＋ジャックポット |
    | 通貨 | エメラルド（銀行残高） |
    | 賭け金 | 既定100〜10,000（候補から選択） |
    | 参加方法 | `[Yacht]` 看板、または `/yacht quick [金額]` |

## 遊び方（クイックヨット）

1. `/yacht quick [金額]`（または看板）でGUIを開き、賭け金を選びます。
2. サイコロ5個を振ります。**振り直しは既定2投**（残したいサイコロをキープして振り直す）。
3. できた役に応じて配当が払い戻されます。役なしなら賭け金は没収です。
4. **ヨット（5個ゾロ目）** を達成すると、貯まっている **ジャックポット** を獲得できます。

## 役と配当（既定・2投ルール）

配当は「総返還倍率（賭け金込み）」です。例：ヨットに100賭けて達成すると 100×15＝1,500 が戻ります。

| 役 | 内容 | 返還倍率 |
|---|---|---|
| ヨット（YACHT） | 5個すべて同じ目 | ×15.0＋ジャックポット |
| フォーカード | 4個同じ目 | ×3.0 |
| ラージストレート | 5個連続（例：2-3-4-5-6） | ×3.0 |
| フルハウス | 3個＋2個の組 | ×1.5 |
| スモールストレート | 4個連続 | ×0.5 |
| スリーカード／ツーペア／役なし | ― | ×0.0（没収） |

!!! note "配当はサーバー設定で変わります"
    上記は既定の2投ルールの倍率です。サーバーが3投ルールに設定している場合や、倍率を調整している場合は配当が異なります。実際の倍率はGUIの表示を確認してください。

## ジャックポット

各ゲームの賭け金の一部が **ジャックポット** に積み立てられ、**ヨット（5個ゾロ目）を達成した人が総取り** します。誰かが当てると全体に告知され、その後はまた初期値から積み上がっていきます。

## 役比べ（マルチ・2〜4人）

複数人で順番にサイコロを振り、できた役の強さを比べて勝敗を決めるモードです。

1. `[Yacht]` 参加看板、または `/yacht join` でロビーに参加します（定員 2〜4人）。
2. 全員そろったら `/yacht start` で開始します（自動では始まりません・全員可）。開始時に **参加費**（既定 500E。範囲 100〜10,000E）が全員から預かられます。
3. 順番に 1 手番ずつサイコロを振って役を作ります。1手番で振れる回数はサーバー設定（既定3投）。手番には **制限時間30秒** があり、過ぎると今の出目で自動確定します。
4. 全員の手番が終わると役を比べ、**いちばん強い役の人がポットを獲得** します。ポットからは **ハウス手数料（既定5%）** が引かれます。
5. 自分の手番の画面を閉じてしまったら `/yacht action` で開き直せます。

!!! note "役の強さ"
    強い順に **ヨット ＞ フォーカード ＞ フルハウス ＞ ラージストレート ＞ スモールストレート ＞ スリーカード ＞ ツーペア ＞ ノーハンド**。同じ役どうしは **出目の合計が大きい方** の勝ち、それも同じなら **山分け**（端数はハウス）です。

!!! warning "途中離脱は脱落・参加費没収"
    ゲーム中に `/yacht leave` で抜けたり切断したりすると **脱落** となり、預けた参加費は戻りません。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/yacht` / `/yacht quick [金額]` | クイックヨットのGUIを開く（全員可） |
| `/yacht join` | 役比べ（マルチ）のロビーに参加（全員可） |
| `/yacht leave` | 役比べのロビーを退出。試合中は脱落・参加費没収（全員可） |
| `/yacht start` | 役比べを開始（全員可。自動では始まらない） |
| `/yacht action` | 自分の手番の画面／閉じたクイックを開き直す（全員可） |
| `/yacht jackpot` | 現在のジャックポット額を確認（全員可） |
| `/yacht status` | 看板の登録状況・ジャックポット額を確認（全員可） |

## よくある質問

??? question "役なしだとどうなりますか？"
    賭け金は没収されます。スモールストレート以上で払い戻しがあり、役が強いほど倍率が上がります。

??? question "ジャックポットはどうやって当てるの？"
    サイコロ5個すべてを同じ目（ヨット）にそろえると獲得できます。難しいぶん配当も大きく、積み立て分を総取りできます。

??? question "賭けたエメラルドはどこから？"
    エメラルド銀行の残高から引かれ、配当も残高に入ります。他のカジノゲームと残高は共通です。
