# スロット ― 遊び方 { .page-player #slot-player }

エメラルドを賭けて、3つのリールを回すスロットマシンです。リールは自分で1つずつ止められる **目押し** 方式。3つとも同じ絵柄でそろえば、賭け金 × 倍率のエメラルドを獲得できます。ダイヤをそろえると当選しやすくなる **確変モード** に突入します。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 通貨 | エメラルド（銀行の口座残高） |
    | 賭け金 | 1・5・10・20・50 E から選択 |
    | 遊び方 | GUIで賭け金を選び、リールを回して1つずつ止める |
    | 勝利条件 | 3つのリールを同じ絵柄でそろえる |
    | 最高配当 | ダイヤ3つで賭け金の10倍＋確変モード |
    | 必要なもの | 特になし（口座に残高があれば全員遊べます） |

## どんなゲーム？

`/slot` を実行すると **賭け金選択GUI** が開きます。賭け金を選ぶとその場でエメラルドが口座から引き落とされ、**スロット盤面GUI** に切り替わります。「スロットを回す」ボタンで3つのリールが回り始めるので、**第1→第2→第3リールの順** に「止める」ボタンを押して止めていきます。

3つのリールがすべて同じ絵柄でそろえば当選。賭け金に絵柄ごとの倍率をかけたエメラルドが口座に入ります。そろわなければハズレで、賭け金は戻りません。

!!! note "賭け金は先に引き落とされます"
    賭け金は「スロットを回す」前、賭け金を選んだ時点で口座から即時に引き落とされます。当選すると配当が口座に加算されます。借金（残高がマイナス）の状態ではスロットを利用できません。

## 遊び方の流れ

1. **コマンドを実行** — `/slot` で賭け金選択GUIを開きます。
2. **賭け金を選ぶ** — エメラルドのアイコン（1・5・10・20・50 E）をクリック。選んだ金額が即時に引き落とされます。
3. **スロットを回す** — 盤面GUIで中央の「スロットを回す」（エメラルドブロック）をクリックすると、3つのリールが回転を始めます。
4. **目押しで止める** — 「止める」ボタン（レバー）を **第1→第2→第3リールの順** にクリックして、1つずつ止めます。
5. **結果** — 3つそろえば当選、賭け金 × 倍率を獲得。そろわなければハズレです。
6. **もう一度遊ぶ** — 結果が出ると中央が「再抽選する」ボタンに変わります。クリックすると同じ賭け金で再度引き落とし、もう一度回せます。

## 賭け方

賭け金選択GUIには **1・5・10・20・50 E** の5種類が並んでいます。クリックした金額がそのまま賭け金になり、即時に口座から引き落とされます。残高が足りない金額を選ぶと「残高が不足しています」と表示され、GUIが閉じます。

## 配当（絵柄と倍率）

リールには5種類の絵柄があります。3つとも **同じ絵柄** でそろったときだけ配当が出ます。獲得額は「賭け金 × 倍率」です。

| 絵柄 | 倍率 | 例：10 E 賭けたとき |
|---|---|---|
| 💎 ダイヤ | ×10 | 100 E 獲得＋確変モード突入 |
| 🟨 金 | ×5 | 50 E 獲得 |
| ⬜ 鉄 | ×3 | 30 E 獲得 |
| ⬛ 石炭 | ×0.5 | 5 E 獲得（賭け金より少ない） |
| 🚫 ハズレ | ×0 | 配当なし |

!!! warning "石炭3つは賭け金割れ"
    石炭でそろった場合の倍率は ×0.5 です。揃ってはいても獲得額は賭け金の半分なので、結果的にマイナスになります。「ハズレ」の絵柄は3つそろっても配当0です。

## 目押しのしくみ

リール回転中、「止める」ボタンを押しても **その瞬間にピタッとは止まりません**。停止を要求してから設定された数コマぶん「滑って」から停止します（既定では1コマ）。狙った絵柄の少し手前でボタンを押すのがコツです。

- 「止める」ボタンは **第1リールから順番に** しか押せません。第1を止めるまで第2は、第2を止めるまで第3は止められません。
- 滑りのコマ数はサーバーの設定（`slot.yml`）によって変わります。何度か回して、自分のサーバーの滑り具合に慣れましょう。

## 確変モード

**ダイヤを3つそろえる** と「確変モード」に突入します。確変モード中は当選確率が大幅にアップし、ダイヤや金などの当たり絵柄が出やすくなります。

- ダイヤをそろえると、設定された回転数（既定100回転）ぶんの確変が付与されます。
- 確変は **1回転ごとに1つ消費** されます。賭け金を入れて回すたびに残り回転数が減っていきます。
- 確変中に賭けると「★ 確変モード発動中! (残り ○回) ★」と表示されます。
- 確変中にさらにダイヤをそろえると、回転数が上乗せされます。

!!! tip "確変中に積極的に回そう"
    確変モードは1回転ごとに消費されるため、突入したらどんどん回すのがお得です。当選確率が高い間にしっかり稼ぎましょう。

## GUI操作

| 場所 | アイコン | 操作 |
|---|---|---|
| 賭け金選択GUI | エメラルド（1〜50 E） | クリックして賭け金を決定 |
| 盤面GUI 中央 | エメラルドブロック「スロットを回す」 | クリックでリール回転開始 |
| 盤面GUI 中央 | 金ブロック「再抽選する」 | 結果後に表示。クリックで同じ賭け金で再挑戦 |
| 盤面GUI 下段 | レバー「止める」 | 回転中、第1→第2→第3の順にクリックして停止 |

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/slot` | 賭け金選択GUIを開く |
| `/slot remote` | スロット起動ロッドを入手する（権限が必要） |

!!! note "スロット起動ロッド"
    `/slot remote` で手に入る「スロット起動ロッド」（ブレイズロッド）は、**右クリックするだけでスロットの賭け金選択GUIを開ける** アイテムです。離れた場所からでもスロットを起動できます。入手には専用の権限が必要なため、使えない場合は運営にお問い合わせください。

## よくある質問

??? question "賭け金は戻ってきますか？"
    いいえ。賭け金は賭け金を選んだ時点で口座から引き落とされ、ハズレても戻りません。3つの絵柄がそろったときだけ「賭け金 × 倍率」の配当を獲得できます。

??? question "リールがボタンを押した瞬間に止まりません"
    仕様です。停止を要求してから設定された数コマぶん「滑って」から止まります。狙った絵柄の少し手前でボタンを押すと、ちょうど狙いの絵柄で止めやすくなります。

??? question "「止める」ボタンが反応しません"
    リールは第1→第2→第3の順にしか止められません。第1リールを止めるまで第2リール、第2リールを止めるまで第3リールのボタンは効きません。順番に押してください。

??? question "確変モードとは何ですか？"
    ダイヤを3つそろえると突入する、当選確率が大幅にアップするモードです。設定回転数（既定100回転）ぶん有効で、1回転ごとに消費されます。突入したら積極的に回しましょう。

??? question "石炭でそろったのにエメラルドが減りました"
    石炭の倍率は ×0.5 です。3つそろっても獲得額は賭け金の半分なので、賭け金より少ない配当になり、結果としてマイナスです。

??? question "もう一度遊ぶには？"
    結果が出ると中央のボタンが「再抽選する」に変わります。クリックすると同じ賭け金が再度引き落とされ、もう一度回せます。GUIを閉じた場合は `/slot` でやり直してください。

??? question "スロットが利用できないと言われます"
    口座残高がマイナス（借金）の状態ではスロットを利用できません。先に銀行で残高を補充してください。また、運営側で slot モジュールが無効化されている場合もあります。
