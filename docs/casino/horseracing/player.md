# 競馬 ― 遊び方 { .page-player #horseracing-player }

OP がレースを開始すると、能力のちがう馬が複数頭そろってスタートラインに並びます。ベット期間のあいだに馬券を買い、レース結果を予想しましょう。的中すればオッズ倍率に応じたエメラルドの配当を受け取れます。賭け金も配当も、すべてエメラルド銀行の口座残高でやり取りされます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 通貨 | エメラルド（銀行の口座残高） |
    | 馬券の種類 | 7種類（単勝・複勝・馬連・馬単・ワイド・3連複・3連単） |
    | ベット方法 | **競馬ベット券（紙アイテム）を右クリック**（`/horseracing` コマンドは原則 OP 専用） |
    | ベットできる時間 | OP がレースを開始してから「レース発走」までの **ベット期間** のみ |
    | 配当 | パリミュチュエル方式（買われ方でオッズが変動） |
    | 馬の能力 | 脚力・スタミナ・賢さの3ステータスがレースごとに自動生成 |

## どんなゲーム？

競馬は「出走馬の能力を見て、レース結果を予想して馬券を買う」ギャンブルです。レースのたびに各馬へ **脚力・スタミナ・賢さ** のステータスがランダムで割り当てられ、その能力をもとにオッズ（配当倍率）が決まります。能力の高い馬は人気が出てオッズが低く、能力の低い馬は当たれば高配当になります。

馬は自動で走り、プレイヤーが操作することはありません。プレイヤーがやるのは **どの馬券を、どの馬に、いくら賭けるか** を決めることだけです。

!!! note "馬の能力（ステータス）"
    各馬には3つのステータスがあり、馬選択画面で確認できます。

    - **脚力** … 馬の速さに最も大きく影響する基本能力。
    - **スタミナ** … レース後半まで速度を保つための持久力。
    - **賢さ** … 走りの安定感に関わる能力。

    馬券画面に表示されるオッズは「脚力 ×3 ＋ スタミナ ×2 ＋ 賢さ ×1」で算出した能力スコアをもとに決まります。能力スコアが高い馬ほどオッズは低く（堅い本命）、低い馬ほどオッズは高く（穴馬）なります。

## 馬券の種類

買える馬券は7種類です。下にいくほど当てる条件が難しく、そのぶん配当（オッズ）が高くなります。

| 馬券 | 難易度 | 的中条件 | オッズの目安 |
|---|---|---|---|
| 単勝 | ★☆☆☆☆ | 1着になる馬を当てる | 約 1.2〜2.5 倍 |
| 複勝 | ★☆☆☆☆ | 選んだ馬が3着以内に入る | 約 1.1〜1.5 倍 |
| 馬連 | ★★☆☆☆ | 1着・2着の2頭を当てる（順不同） | 約 1.5〜5 倍 |
| ワイド | ★★☆☆☆ | 3着以内に入る2頭を当てる（順不同） | 約 1.3〜3 倍 |
| 馬単 | ★★★☆☆ | 1着・2着を着順どおりに当てる | 約 3〜15 倍 |
| 3連複 | ★★★★☆ | 3着以内に入る3頭を当てる（順不同） | 約 3〜10 倍 |
| 3連単 | ★★★★★ | 1着・2着・3着を着順どおりに当てる | 約 8〜30 倍 |

!!! tip "迷ったら単勝・複勝から"
    単勝・複勝は1頭を選ぶだけで、複勝は3着以内なら的中なので当たりやすい馬券です。慣れてきたら馬連・ワイドで2頭、さらに馬単・3連複・3連単で高配当を狙うとよいでしょう。

## 馬券の買い方

ベットは GUI（画面）で行います。手順は次のとおりです。

1. **ベット画面を開く** — `[HorseRacing] getitem` 看板を右クリック（または OP から配布）して受け取った **競馬ベット券**（紙アイテム）を手に持って **右クリック** します。
2. **馬券タイプを選ぶ** — 「馬券タイプ選択」画面で、買いたい馬券（単勝〜3連単）をクリックします。各馬券のアイコンには選択頭数・難易度・説明が表示されます。
3. **馬を選ぶ** — 「馬を選択」画面で、予想する馬をクリックします。選ぶと馬のマスが緑色（✓付き）に変わります。もう一度クリックすると選択を解除できます。
4. **必要頭数を満たす** — 馬券タイプごとに選ぶ頭数が決まっています（単勝・複勝＝1頭、馬連・馬単・ワイド＝2頭、3連複・3連単＝3頭）。必要数を選ぶと「✓ 選択完了!」と表示されます。
5. **選択を確定する** — 必要数を選ぶと出てくる「✓ 選択を確定」（エメラルドブロック）をクリックします。
6. **賭け金を入力する** — 賭けたいエメラルドの数を **チャットに入力** します。やめたいときは `cancel` と入力します。
7. **完了** — 残高が足りていればベットが成立し、賭け金が口座から引かれます。「ベット完了」のメッセージが表示されます。

!!! note "馬単・3連単は着順あり"
    馬連・ワイド・3連複は順不同（順番が違っても的中）ですが、**馬単と3連単は着順どおり** に当てる必要があります。馬を選ぶ順番にも気をつけましょう。

!!! warning "ベットはレース発走前まで"
    馬券を買えるのは OP がレースを開始してから **発走（レーススタート）まで** のベット期間だけです。レースが始まると受付は締め切られ、選択途中のベット画面も閉じられます。早めに買いましょう。

## レースの流れ

1. **レース準備** — OP が `/horseracing start` を実行すると馬が召喚され、ベット期間が始まります。
2. **ベット期間** — この間に馬券を購入します。スコアボードに馬の情報が表示されます。
3. **発走** — OP が再度 `/horseracing start` を実行するとレースがスタートし、ベット受付は締め切られます。
4. **レース** — 馬がコースを自動で走ります。
5. **結果発表** — 全馬がゴールすると、1〜3着の馬番号・オッズ、馬単（2連単）・3連単の結果がチャットに表示されます。
6. **配当** — 的中した馬券の配当がエメラルド口座へ自動で入金され、的中メッセージが届きます。

!!! note "レースが中止されたら"
    OP が緊急停止した場合、購入済みの馬券の賭け金はすべて全額返金されます。

## オッズと配当の仕組み

このゲームの配当は **パリミュチュエル方式** です。賭け金は馬券タイプごとのプールに集められ、的中者でそのプールを分け合うイメージです。同じ組み合わせに多く賭けが集まるほどオッズ（配当倍率）は下がり、賭けが少ない組み合わせほどオッズは高くなります。

- オッズは馬券タイプごとに **最小・最大の範囲** が決まっています（前掲の表の「オッズの目安」）。
- 配当額は「**賭け金 × 的中時のオッズ**」で計算されます。
- 少人数でもオッズが極端にならないよう、内部的に仮想のベット（プール）が加えられています。

!!! tip "人気馬は堅実、穴馬は一発"
    能力が高く人気の馬はオッズが低めで的中しても配当は控えめ、能力が低い穴馬は的中しにくいぶん高配当です。馬のステータスとオッズを見比べて、自分のスタイルに合う買い方を見つけましょう。

## プレイヤー用コマンド

プレイヤーが直接実行できる `/horseracing` サブコマンドはありません。`/horseracing` 系のコマンドは原則 OP 専用で、プレイヤーは以下の看板と馬券アイテムを使用します。

| 看板の種類（2行目） | 右クリックでできること |
|---|---|
| `lobby` | 競馬会場（ロビー）へ移動 |
| `leave` | 会場の外（スポーン地点）へ移動 |
| `getitem` | 競馬ベット券（紙アイテム）を1枚受け取る |

馬券アイテムを手に持って右クリックすればベット画面が開きます。

## よくある質問

??? question "馬券はどうやって買いますか？"
    手に持った **競馬ベット券**（紙アイテム）を右クリックするとベット画面が開きます。馬券タイプ → 馬 → 賭け金（チャット入力）の順に選んで確定します。

??? question "ベット券を持っていません"
    会場に設置された `[HorseRacing] getitem` 看板を右クリックすると競馬ベット券を1枚受け取れます。看板がない場合は OP から配布してもらってください（プレイヤーは `/horseracing` コマンドを実行できません）。

??? question "何頭の馬を選べばいいですか？"
    馬券タイプによって決まっています。単勝・複勝は1頭、馬連・馬単・ワイドは2頭、3連複・3連単は3頭です。必要数を選ぶと「選択完了」と表示され、確定ボタンが出ます。

??? question "馬連と馬単、3連複と3連単の違いは？"
    馬連・3連複は **順不同**（順番が違っても当たり）、馬単・3連単は **着順どおり** に当てる必要があります。着順を当てるぶん、馬単・3連単のほうが高配当です。

??? question "ベットしたあとレースが中止されました"
    OP がレースを緊急停止した場合、購入済みの馬券の賭け金は全額返金され、メッセージで通知されます。

??? question "オッズはどうやって決まりますか？"
    パリミュチュエル方式で、馬の能力と賭けの集まり具合によって変動します。多く買われた組み合わせほどオッズは下がり、買われていない組み合わせほど高くなります。馬券タイプごとに最小・最大の範囲が決まっています。

??? question "レースが始まったあとに馬券を買えますか？"
    買えません。馬券を購入できるのは発走前のベット期間だけです。レースが始まると受付は締め切られます。
