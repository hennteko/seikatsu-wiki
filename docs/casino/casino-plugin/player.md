# CasinoPlugin ― 遊び方 { .page-player #casino-plugin-player }

CasinoPlugin は、生活鯖の **カジノ・レース・クイズをまとめて動かしている基盤プラグイン** です。銀行に預けたエメラルドを共通の通貨にして、8つのゲームを1つの口座で遊べます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 共通通貨 | エメラルド（銀行の口座で管理） |
    | 遊べるゲーム | カジノ系・レース系・クイズの全8種類 |
    | 必要なもの | 特になし（サーバーに入れば全員遊べます） |
    | 各ゲームの詳細 | それぞれの個別ページを参照 |

## どんなプラグイン？

CasinoPlugin には **銀行** と **8つのゲーム** が入っています。

- まず **銀行** でエメラルドを口座に預けます。これがすべてのゲームの共通通貨です。
- あとは遊びたいゲームのコマンドや看板から、各ゲームに参加するだけ。
- 賭け金や配当はすべて銀行の口座を通じてやり取りされるので、ゲームをまたいでも残高は1つです。

!!! tip "各ゲームの遊び方は個別ページにあります"
    このページは「どんなゲームがあるか」を一覧で見るための案内ページです。各ゲームの細かいルール・配当・コツは、下の表のゲーム名に対応する **個別ページ** をご覧ください。

## 銀行（エメラルド）の基本

すべてのゲームの通貨は **エメラルド** です。エメラルドは銀行の口座（残高）として管理されます。

| やりたいこと | 操作 |
|---|---|
| 残高ランキング表示 | `/eb list` または `/eb ranking`（プレイヤー可） |
| 預け入れ・引き出し・送金・残高確認 | **`[EmeraldBank]` 看板の右クリック**、または OP が発行したウォレット/通帳の右クリック |

!!! info "銀行の詳細は個別ページへ"
    通帳（Book）・ウォレット（リアルタイム残高表示）・GUI・ランキング看板・送金などの詳しい使い方は、**エメラルド銀行の個別ページ** にまとめています。`/emerald` 系コマンドは原則 OP 専用ですが、プレイヤーは ATM 看板やウォレット／通帳アイテムから同じ機能を使えます。

## よくある質問

??? question "どのゲームから遊べばいいですか？"
    まず銀行でエメラルドを口座に預けてから、好きなゲームに行きましょう。各ゲームの遊び方は、上の一覧表に対応する個別ページに詳しく書いてあります。

??? question "ゲームごとに口座（お金）は別ですか？"
    いいえ。エメラルドの残高は1つで、すべてのゲームで共通です。ポーカーで勝ったエメラルドをそのままスロットや競馬に使えます。

??? question "遊ぶのに権限の申請は必要ですか？"
    銀行・カジノ・レース系のゲームは、基本的にサーバーに入っていれば全員遊べます。クイズだけは権限の設定によって遊べる範囲が変わる場合があるため、遊べないときは運営に相談してください。

??? question "あるゲームのコマンドが「不明なコマンド」と出ます"
    そのゲームのモジュールが運営側で無効化されている可能性があります。CasinoPlugin はモジュール式で、運営がゲーム単位で ON / OFF できる仕組みです。運営にお問い合わせください。

??? question "各ゲームの配当やルールが知りたいです"
    このページでは深掘りしていません。一覧表のゲーム名に対応する **個別ページ** に、ルール・配当・コツがまとめられています。
