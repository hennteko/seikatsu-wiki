# チンチロ ― 遊び方 { .page-player #tintiro-player }

チンチロは、3つのサイコロを振って **役（やく）の強さ** を競う日本式のサイコロ賭博です。1人の **親** と複数の **子** に分かれ、親と子が1対1で出目を比べて勝負します。賭け金はエメラルドで、役の差が大きいほど大きく動きます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 通貨 | エメラルド（銀行の口座残高） |
    | 人数 | 親1人＋子（看板からの参加は最大6人） |
    | サイコロ | 3つ。1人あたり最大3回まで振り直し可能 |
    | 賭け方 | ロビー全員のベット額をまとめて設定 |
    | 参加方法 | **チンチロ看板の右クリック**（`/tintiro` コマンドは原則 OP 専用） |

## どんなゲーム？

チンチロは「親 対 子」の対戦ギャンブルです。

- 参加者は **ロビー** に集まり、賭け金（ベット額）を決めます。
- ゲームが始まると1人が **親**、残りが **子** になります。
- 各プレイヤーは自分の番にサイコロ3つを振り、出た **役** を確定させます。
- 全員が振り終わると、**親と子それぞれが1対1** で役を比べ、勝った側が負けた側からエメラルドを受け取ります。

## 遊び方の流れ

1. **ロビーに参加** — チンチロ会場の `lobby` 看板を右クリックしてロビーに入ります。
2. **ベット額を決める** — 金額看板（例: `100E`）を右クリックすると、ロビー全員のベット額がその金額に設定されます。
3. **ゲーム開始** — 親役の OP（または会場管理者）がゲームを開始します。一般プレイヤーが `start` する操作はありません。
4. **サイコロを振る** — 自分の番が来たら **`open` 看板** を右クリックする（または `/tintiro open` を許可されている場合はそのコマンド）でサイコロGUIを開き、サイコロを振ります。最大3回まで振り直せます。
5. **目を確定（スタンド）** — 良い役が出たら「スタンド」で確定します。役が出なければ振り直し、回数を使い切ると自動で確定します。
6. **結果発表** — 全員が振り終わると最終結果が全体に発表され、勝敗に応じてエメラルドが清算されます。

!!! note "ゲーム中はアドベンチャーモードになります"
    ゲームが始まると、ロビーの参加者は全員アドベンチャーモードに切り替わります。ゲームが終わると設定されたロビー地点へ戻されます。

## 役一覧と強さ

3つのサイコロの出目で「役」が決まります。役には強さの順位があり、強い役ほど勝ちやすく、配当も大きくなります。

| 役 | 出目 | 強さ | 内容 |
|---|---|---|---|
| ピンゾロ | 1・1・1 | 最強 | 1のゾロ目。最も強い役 |
| ゾロ目（アラシ） | 同じ目3つ（111以外） | 強い | 2-2-2 〜 6-6-6 のゾロ目 |
| シゴロ | 4・5・6 | やや強い | 4-5-6 のストレート |
| 通常の目（目1〜6） | 2つ同じ＋1つ違う | 普通 | 残り1つの目（1〜6）が「目」になる。目が大きいほど強い |
| 役なし（メなし） | 上記いずれでもない | 弱い | 役が成立しない出目 |
| ヒフミ | 1・2・3 | 負け役 | 1-2-3 のストレート。出すと負け扱い |
| ションベン | サイコロが場外（0扱い） | 最弱 | サイコロ目が 0 になる。出ると即確定 |

!!! tip "勝敗は「役の強さ」で決まります"
    勝負は親と子で **役の強さ** を比べます。同じ役どうしの場合は、振り直しの残り回数が多いほうが勝ちになります（残り回数も同じなら引き分け）。ヒフミ・ションベンは負け役なので、出てしまったらその時点で目が確定します。

## 配当のしくみ

賭け金（ベット額）を基準に、**役の格差が大きいほど大きな金額** が動きます。

- 親が勝てば子から、子が勝てば親から、エメラルドを受け取ります。
- 配当は **役のランク差** に応じて倍率が変わります。役の差が大きいほど受け取り（支払い）額が増えます。
- 同じ役（引き分け扱いの強さ）でも振り直し回数で勝敗がついた場合は、ベット額ぶんがそのまま動きます。
- 役が完全に同じ強さで振り直し回数も同じなら **引き分け**（やり取りなし）です。

!!! warning "ゲーム開始には残高が必要です"
    ゲーム開始時、各プレイヤーは **ベット額の最大支払額ぶん** の残高を持っている必要があります。残高が不足していると、そのプレイヤーはロビーから自動的に退出させられます。大きく賭けるときは、あらかじめ銀行の口座に十分なエメラルドを預けておきましょう。

!!! danger "未スタンド・途中退出は負け扱い"
    自分の番でサイコロを振らずに終わったり、ゲーム中にサーバーから退出したりすると **未スタンド扱い** になり、親に対してベット額を支払うことになります。自分の番が来たら必ず `/tintiro open` でサイコロを振りましょう。

## 参加方法

プレイヤーは **チンチロ看板** から参加・離脱・ベット・サイコロ操作を行います。`/tintiro` コマンドは原則 OP 専用のため、看板の右クリックを使ってください。

| 看板の種類（2行目） | 右クリックでできること |
|---|---|
| `lobby` 看板 | チンチロロビーに参加（ロビー地点へ転送） |
| `leave` 看板 | チンチロロビーから離脱（スポーン地点へ転送） |
| `open` 看板 | 自分の番にサイコロGUIを開く |
| 金額看板（例: `100E`） | ロビー全員のベット額をその金額に設定 |

!!! warning "/tintiro コマンドは原則 OP 専用"
    `/tintiro bet` `/tintiro start` `/tintiro stop` `/tintiro open` などのコマンドは、OP でないと「OP専用です」と拒否されます。プレイヤーは上の看板から操作してください。なお `/tintiro join` ・ `/tintiro leave` は **自分自身の参加・離脱に限り一般プレイヤーでも実行できます**（他プレイヤーを指定して参加/離脱させる場合のみ OP が必要）。

## よくある質問

??? question "親と子はどうやって決まりますか？"
    `/tintiro start` を実行した人が親になります。残りのロビー参加者は全員子になります。ゲーム開始には、親以外に最低1人の子が必要です。

??? question "サイコロは何回振れますか？"
    1人あたり最大3回まで振り直せます。良い役が出たら「スタンド」で確定し、回数を使い切ると最後の出目で自動的に確定します。

??? question "「ションベン」とは何ですか？"
    サイコロが場の外に出てしまった状態を再現した役で、出目が 0 になります。出ると即その時点で目が確定し、最も弱い役として扱われます。

??? question "ベット額は1人ずつ違う額にできますか？"
    `/tintiro bet` や金額看板は **ロビー全員のベット額をまとめて設定** します。設定した時点でロビーにいる全員が同じ額になります。

??? question "自分の番を飛ばしてしまうとどうなりますか？"
    サイコロを振らずに番が終わると未スタンド扱いになり、親にベット額を支払うことになります。自分の番が来たら必ず `/tintiro open` でサイコロを振ってください。

??? question "コマンドが「不明なコマンド」と表示されます"
    チンチロ（tintiro モジュール）が運営側で無効化されている可能性があります。CasinoPlugin はモジュール式で、運営がゲーム単位で ON / OFF できます。運営にお問い合わせください。
