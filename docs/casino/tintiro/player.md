# チンチロ ― 遊び方 { .page-player #tintiro-player }

チンチロは、3つのサイコロを振って **役（やく）の強さ** を競う日本式のサイコロ賭博です。1人の **親** と複数の **子** に分かれ、親と子が1対1で出目を比べて勝負します。賭け金はエメラルドで、配当は勝った側の役の倍率で支払われます。1人で遊べる CPU 対戦の **ソロモード** もあります。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 通貨 | エメラルド（銀行の口座残高） |
    | 人数 | 最大6人（親を含む／看板からの参加）。ソロは1人＋CPU 1〜5体 |
    | サイコロ | 3つ。1手番で最大3回振れる（＝振り直し2回まで） |
    | 賭け方 | ロビー全員のベット額をまとめて設定 |
    | 参加方法 | **チンチロ看板の右クリック** または `/tintiro`（join/start/bet などは一般プレイヤーも実行可） |

## どんなゲーム？

チンチロは「親 対 子」の対戦ギャンブルです。

- 参加者は **ロビー** に集まり、賭け金（ベット額）を決めます。
- ゲームが始まると1人が **親**、残りが **子** になります。
- 各プレイヤーは自分の番にサイコロ3つを振り、出た **役** を確定させます。
- 全員が振り終わると、**親と子それぞれが1対1** で役を比べ、勝った側が負けた側からエメラルドを受け取ります。

## 遊び方の流れ

1. **ロビーに参加** — チンチロ会場の `lobby` 看板を右クリックしてロビーに入ります。
2. **ベット額を決める** — 金額看板（例: `100E`）を右クリックするとロビー全員のベット額がその金額に設定されます。`bet` 看板を右クリックした場合は掛け金変更GUIが開き、一覧から金額を選べます。
3. **ゲーム開始** — ロビーに2人以上そろったら `start` 看板をクリックしてゲームを開始します。**クリックした人が親**になり、残りの参加者が子になります（`/tintiro start` コマンドも一般プレイヤーが実行でき、実行者が親になります）。
4. **サイコロを振る** — 自分の番が来たら **`action` 看板** を右クリックする（または `/tintiro action` コマンド）でサイコロGUIを開き、サイコロを振ります。1手番で最大3回振れます（最初の1投＋振り直し2回）。
5. **目を確定（スタンド）** — 良い役が出たら「スタンド」で確定します。役が出なければ振り直し、回数を使い切ると自動で確定します。
6. **結果発表** — 全員が振り終わると最終結果が全体に発表され、勝敗に応じてエメラルドが清算されます。

!!! note "ゲーム中はアドベンチャーモードになります"
    ゲームが始まると、ロビーの参加者は全員アドベンチャーモードに切り替わります。ゲームが終わると設定されたロビー地点へ戻されます。

## 役一覧と強さ

3つのサイコロの出目で「役」が決まります。役には強さの順位があり、強い役ほど勝ちやすく、配当も大きくなります。

| 役 | 出目 | 強さ | 倍率 | 内容 |
|---|---|---|---|---|
| ピンゾロ | 1・1・1 | 最強 | 5倍 | 1のゾロ目。最も強い役 |
| ゾロ目（アラシ） | 同じ目3つ（111以外） | 強い | 3倍 | 2-2-2 〜 6-6-6 のゾロ目 |
| シゴロ | 4・5・6 | やや強い | 2倍 | 4-5-6 のストレート |
| 通常の目（目1〜6） | 2つ同じ＋1つ違う | 普通 | 1倍 | 残り1つの目（1〜6）が「目」になる。目が大きいほど強い |
| 役なし（メなし） | 上記いずれでもない | 弱い | 1倍 | 役が成立しない出目 |
| ションベン | サイコロが場外（0扱い） | 負け役 | 1倍を払う | サイコロ目が 0 になる。役なしより弱く、出ると即確定 |
| ヒフミ | 1・2・3 | 最弱 | 2倍を払う | 1-2-3 のストレート。最も弱い負け役（ションベンよりさらに弱い） |

!!! tip "勝敗は「役の強さ」で決まります"
    勝負は親と子で **役の強さ** を比べます。同じ役どうしの場合は、振り直しの残り回数が多いほうが勝ちになります（残り回数も同じなら引き分け）。ヒフミ・ションベンは負け役なので、出てしまったらその時点で目が確定します。

## 配当のしくみ

配当は **勝った側の役の倍率** で決まります（役のランク差で決まる旧仕様ではありません）。

- 親が勝てば子から、子が勝てば親から、エメラルドを受け取ります。
- 倍率は **勝った側の役** で決まります。通常の目・役なし=1倍、シゴロ=2倍、ゾロ目=3倍、ピンゾロ=5倍。受け取り額は「ベット額 × この倍率」です。
- 負けた側がヒフミ（2倍）・ションベン（1倍）を出していたときは、その **罰倍率** と勝った側の役の倍率を比べ、**大きいほうの倍率** で支払います。
- 同じ役（同点）どうしは、振り直しの残り回数が多いほうが勝ち（1倍）。それも同じなら **引き分け**（やり取りなし）です。

!!! warning "ゲーム開始には残高が必要です"
    ゲーム開始時、各プレイヤーは **ベット額の最大支払額（ベット額の5倍＝最強役ピンゾロの倍率）ぶん** の残高を持っている必要があります（親は子のベット合計の5倍）。残高が不足していると、そのプレイヤーはロビーから自動的に退出させられます。大きく賭けるときは、あらかじめ銀行の口座に十分なエメラルドを預けておきましょう。

!!! danger "未スタンド・途中退出は負け扱い"
    自分の番でサイコロを振らずに終わったり、ゲーム中にサーバーから退出したりすると **棄権扱い** になり、親に対してベット額を支払うことになります。自分の番が来たら必ず `/tintiro action` でサイコロを振りましょう。

## ソロモード（CPU 対戦）

相手がいなくても、1人＋CPU（1〜5体）でチンチロを遊べます。ソロ看板を右クリックするか `/tintiro solo` でメニューが開き、**役割（親 / 子）・CPU の人数・ベット額** を選んで「開始」します。全員が1回ずつ手番を行い、精算後にメニューへ戻ります。

- 役・倍率はマルチと共通です（通常1 / シゴロ2 / ゾロ目3 / ピンゾロ5、ヒフミ2・ションベン1は罰倍率）。
- 親を選ぶと CPU の子それぞれと、子を選ぶと CPU の親と勝負します。
- ベット額は **10〜5000エメラルド** の範囲です。
- 勝ったゲームは **純利益でダブルアップ**（賞金を倍にするか勝負）に挑戦できます。
- 戦績は `/tintiro solo stats [名前]`、収支ランキングは `/tintiro solo ranking`（`rank` でも可）で確認できます。

```text title="ソロチンチロのメニューを開く"
/tintiro solo
```

## 参加方法

プレイヤーは **チンチロ看板** から参加・離脱・ベット・サイコロ操作を行えます。`/tintiro` の `join` / `leave` / `start` / `bet` / `action` / `status` / `solo` は一般プレイヤーでも実行できるので、看板とコマンドのどちらを使ってもかまいません。

| 看板の種類（2行目） | 右クリックでできること |
|---|---|
| `lobby` 看板 | チンチロロビーに参加（ロビー地点へ転送） |
| `leave` 看板 | チンチロロビーから離脱（スポーン地点へ転送） |
| `action` 看板 | 自分の番にサイコロGUIを開く |
| `bet` 看板 | 掛け金変更GUIを開き、一覧から選んだ金額をロビー全員のベット額に設定 |
| 金額看板（例: `100E`） | ロビー全員のベット額をその金額に直接設定 |
| `start` 看板 | ゲームを開始する（クリックした人が親になる） |

!!! info "一般プレイヤーが使えるコマンド"
    `/tintiro join` ・ `/tintiro leave` ・ `/tintiro start`（開始・実行者が親）・ `/tintiro bet <金額>`（ロビー在籍者が全員のベット額を設定）・ `/tintiro action`（サイコロGUI）・ `/tintiro status`（状況確認）・ `/tintiro solo`（ソロ）は一般プレイヤーでも実行できます。OP 専用なのは `stop` と各セットアップ系（`setsign` / `setlobby` / `setstartspawn` / `setfield` / `setsolospawn` など）、および他プレイヤーを指定した `join` / `leave` / `bet` です。

## よくある質問

??? question "親と子はどうやって決まりますか？"
    `start` 看板をクリックした人（または `/tintiro start` を実行した人）が親になります。残りのロビー参加者は全員子になります。ゲーム開始には、親以外に最低1人の子が必要です。

??? question "サイコロは何回振れますか？"
    1人あたり最大3回まで振り直せます。良い役が出たら「スタンド」で確定し、回数を使い切ると最後の出目で自動的に確定します。

??? question "「ションベン」とは何ですか？"
    サイコロが場の外に出てしまった状態を再現した役で、出目が 0 になります。出ると即その時点で目が確定し、役なしより弱い負け役として扱われます（1-2-3 のヒフミだけはさらに弱く、最弱です）。

??? question "ベット額は1人ずつ違う額にできますか？"
    `/tintiro bet` や金額看板は **ロビー全員のベット額をまとめて設定** します。設定した時点でロビーにいる全員が同じ額になります。

??? question "自分の番を飛ばしてしまうとどうなりますか？"
    サイコロを振らずに番が終わると棄権扱いになり、親にベット額を支払うことになります。自分の番が来たら必ず `/tintiro action` でサイコロを振ってください。

??? question "コマンドが「不明なコマンド」と表示されます"
    チンチロ（tintiro モジュール）が運営側で無効化されている可能性があります。CasinoPlugin はモジュール式で、運営がゲーム単位で ON / OFF できます。運営にお問い合わせください。
