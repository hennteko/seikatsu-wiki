# ポーカー ― 遊び方 { .page-player #poker-player }

トランプの定番ゲーム **テキサスホールデム** です。配られた2枚の手札と、テーブル中央に公開される5枚のカードを組み合わせて、一番強い5枚の役を作ります。最後まで残った人、または役が一番強い人が、テーブルの賭け金（ポット）をすべて獲得します。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 2〜6人（最少2人で開始できます） |
    | 通貨 | エメラルド（銀行の口座残高） |
    | 参加方法 | `[Poker]` 看板を右クリック |
    | 手札 | 紙アイテムで配られる秘密の2枚 |
    | アクション | 棒アイテムの CALL / RAISE / FOLD から選ぶ |
    | 勝利条件 | 最後まで残る、または役の強さで勝つ |

## どんなゲーム？

ポーカーは、手元の2枚（手札）と、全員が共有する公開カード5枚を合わせた **7枚の中から一番強い5枚の組み合わせ（役）** を作るゲームです。

ゲームは「賭け（ベット）」と「カード公開」を交互に繰り返しながら進みます。自分の役に自信があれば賭け金を増やし（RAISE）、勝てそうにないと思えば降りる（FOLD）こともできます。**最後まで降りずに残った人が1人だけ** になればその人の勝ち、複数人が残ったまま最後まで進んだ場合は **役が一番強い人** の勝ちです。

勝った人は、そのゲームでテーブルに集まった賭け金（ポット）をすべて受け取ります。引き分けの場合はポットを均等に分けます。

## 参加方法

ポーカーは **専用の看板** から参加します。

1. ポーカー会場にある `[Poker]`（クリックで参加）と書かれた看板を **右クリック** します。
2. 参加登録されると、自動でポーカーロビーへ移動します。
3. 看板には現在の参加人数（例: `2/6人`）が表示されます。**最大6人** まで参加できます。
4. 運営または対象コマンドでゲームが開始されると、ゲームエリアへ転送され、手札が配られます。

参加をやめたいときは、`[Poker]`（クリックで離脱）の **離脱看板を右クリック** します。

!!! note "ゲーム開始には2人以上が必要です"
    ポーカーは最少2人から開始できます。1人しか待機していないと開始できません。ゲームが進行中のあいだは新しく参加登録できないので、次のゲームを待ってください。

## ゲームの流れ

テキサスホールデムは、次の順番でカードが公開されながら進みます。各段階のあいだに「ベット（賭けの回し合い）」があります。

1. **手札配布（プリフロップ）** — 全員に秘密の手札が2枚配られます。スモールブラインド・ビッグブラインドの2人が、最初の賭け金を自動で支払います。
2. **フロップ** — 公開カードが3枚オープンされます。
3. **ターン** — 公開カードがもう1枚（合計4枚）オープンされます。
4. **リバー** — 公開カードがもう1枚（合計5枚）オープンされます。
5. **ショーダウン** — 残ったプレイヤーの手札を見せ合い、役の強さで勝者を決めます。

途中で自分以外の全員が FOLD（降り）すれば、その時点で勝利が確定します。

!!! note "ブラインド（最初の強制ベット）"
    各ゲームの開始時、2人のプレイヤーが「ブラインド」と呼ばれる賭け金を自動で支払います。スモールブラインド（SB）は基準額、ビッグブラインド（BB）はその2倍です。基準額は運営が `/poker bet` で設定します。

## 手札と公開カード

- **手札（紙アイテム）** — ゲーム開始時、紙のアイテムとして秘密の2枚が配られます。アイテムの説明文（lore）にスートと数字が書かれており、自分にしか見えません。
- **公開カード（看板）** — フロップ・ターン・リバーで公開されるカードは、テーブル周辺の **公開札看板（sign1〜sign5）** に表示されます。チャットにも「公開カード: …」として流れます。

## アクション（CALL / RAISE / FOLD）

自分のターンになると、3種類の **棒アイテム** がインベントリに配られます。アイテムを持って使う（右クリック）ことでアクションを選びます。

| アクション | アイテム名 | 効果 |
|---|---|---|
| CALL / CHECK | 【 CALL / CHECK 】 | 現在の最高ベット額に合わせて支払う。追加で支払う額が無ければ「チェック」となり、賭けずにターンを回す |
| RAISE | 【 RAISE 】 | 賭け金を増額する。使用後、チャットに **合計ベット額（数字）** を入力する |
| FOLD / STAND | 【 FOLD / STAND 】 | このゲームから降りる。それまでに賭けた分はポットに残る |

RAISE を選んだあとは、**チャットに増額後の合計ベット額を数字で入力** します。入力した額は、現在の最高ベット額より大きく、運営が設定したレイズ上限以下である必要があります。

!!! tip "残高が足りないときは FOLD を"
    CALL や RAISE で支払う額がエメラルドの残高を超えていると、そのアクションは失敗します。支払えないときは FOLD を選んでゲームから降りましょう。賭け金やレイズ上限は、ゲームの状況によって運営が調整します。

## 役の強さ

ショーダウンでは、7枚（手札2枚＋公開5枚）から作れる最強の5枚の役を比べます。下にいくほど強い役です。

| 役 | 名前 |
|---|---|
| ハイカード | 役なし。一番強いカードで勝負 |
| ワンペア | 同じ数字が2枚 |
| ツーペア | ワンペアが2組 |
| スリーカード | 同じ数字が3枚 |
| ストレート | 数字が5枚連続 |
| フラッシュ | 同じスートが5枚 |
| フルハウス | スリーカード＋ワンペア |
| フォーカード | 同じ数字が4枚 |
| ストレートフラッシュ | 同じスートで数字が5枚連続 |
| ロイヤルストレートフラッシュ | 10・J・Q・K・A の同じスートのストレートフラッシュ |

役が同じ強さで並んだ場合は、その中のカードの強さで優劣が決まります。完全に同じ強さなら引き分けとなり、ポットを均等に分け合います。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/poker money` | 現在のポット（テーブルの賭け金総額）を確認する |
| `/poker getraisemoney` | 現在のレイズ上限額を確認する |
| `/poker status` | 会場の設定状況・待機人数・ゲーム状態を確認する |

!!! note "コマンドのエイリアス"
    `/poker` は `/pk` でも実行できます。参加・離脱・アクションは基本的に **看板とアイテム** で行うため、プレイヤーがコマンドを覚える必要はほとんどありません。

## よくある質問

??? question "どうやってポーカーに参加しますか？"
    ポーカー会場の `[Poker]` 看板を右クリックすると参加登録され、ロビーへ移動します。最大6人まで参加でき、運営または対象コマンドでゲームが始まると手札が配られます。

??? question "手札はどこにありますか？"
    ゲーム開始時、紙のアイテムとして手札2枚がインベントリに入ります。アイテムの説明文にスートと数字が書かれており、あなたにしか見えません。

??? question "自分のターンで何をすればいいですか？"
    ターンが回ってくると、CALL / RAISE / FOLD の3つの棒アイテムが配られます。アイテムを使って（右クリック）アクションを選びます。RAISE を選んだ場合は、続けてチャットに合計ベット額を数字で入力してください。

??? question "RAISE の金額はどう入力しますか？"
    RAISE アイテムを使うと「チャットに合計ベット額を入力してください」と表示されます。増額後の **合計ベット額** を数字でチャット送信してください。現在の最高ベット額より大きく、レイズ上限以下である必要があります。

??? question "チェックとコールの違いは？"
    どちらも同じ CALL アイテムで行います。追加で支払う額があるときは「コール（その額を支払う）」、支払う額が無いときは「チェック（賭けずにターンを回す）」として扱われます。

??? question "賭け金が足りなくなったらどうなりますか？"
    残高が足りないと CALL・RAISE は失敗します。その場合は FOLD を選んでゲームから降りてください。それまでに賭けた分はポットに残ります。

??? question "ゲームの途中で抜けられますか？"
    離脱看板を右クリックすれば途中でも抜けられます。ただし途中離脱は自動的に FOLD 扱いとなり、賭けた分は戻りません。なお、ゲーム中に接続が切れた場合も自動でフォールドされます。

??? question "勝つとどれくらいもらえますか？"
    そのゲームでテーブルに集まった賭け金（ポット）をすべて受け取ります。複数人が同じ強さで引き分けた場合は、ポットを均等に分け合います。
