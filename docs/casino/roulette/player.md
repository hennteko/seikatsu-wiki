# ルーレット ― 遊び方 { .page-player #roulette-player }

0〜36のヨーロピアン盤で回す定番のカジノゲームです。数字や色などに賭け、玉が止まったマスで勝敗が決まります。賭け金・配当はすべてエメラルド銀行の残高でやり取りされます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 盤面 | ヨーロピアン（0〜36・37マス） |
    | 通貨 | エメラルド（銀行残高） |
    | 遊び方 | ソロ（1人用GUI）／マルチ卓（みんなで1つの盤） |
    | 最小ベット | 10（既定）／1スピンの合計上限 1,000,000（既定） |
    | 参加方法 | `[Roulette]` 参加看板、または `/roulette play`・`/roulette join` |

## 遊び方

### ソロ（1人用GUI）

`/roulette play`（`/rl play`）で **自分専用のルーレットGUI** を開きます。賭けの種類と金額を選んでスピンすると、すぐに結果が出ます。サクッと1人で遊びたいときに向いています。

### マルチ卓（みんなで1つの盤）

`[Roulette]` 参加看板か `/roulette join` で卓に着きます。**ベット受付時間（既定30秒）** のあいだに各自が賭けを置き、時間になると **1つの盤が回って全員の勝敗が同時に決まります**。OPが設置した疑似ホイール（表示エンティティ）が回転する演出を全員で見られます。`/roulette leave` で卓を離れます。

## 賭けの種類と配当

配当は「純倍率 x:1」表記です。当たると **賭け金 ×（倍率＋1）** が払い戻されます（例：ストレートに100賭けて当たると 100×36＝3,600）。

| 賭け | 内容 | 配当（x:1） |
|---|---|---|
| ストレート | 1つの数字にピンポイント | 35 |
| 赤／黒 | 赤か黒か | 1 |
| 奇数／偶数 | 奇数か偶数か | 1 |
| ハイ／ロー | ハイ(19-36)かロー(1-18)か | 1 |
| ダース | 12個ずつの3グループのどれか | 2 |
| コラム | 縦3列のどれか | 2 |

!!! note "0（ゼロ）について"
    ヨーロピアン盤には 0 があります。0 が出ると、赤黒・奇偶・ハイロー・ダース・コラムなどの「数字グループ」系の賭けは外れになります（0 をストレートで当てた場合のみ的中）。

## 参加方法

1. `[Roulette]` 参加看板をクリック、または `/roulette join`（マルチ卓）／`/roulette play`（ソロGUI）。
2. GUIで **賭けの種類と金額** を選びます（金額は候補ボタンから選択）。
3. マルチ卓はベット受付時間内に賭けを置くと、時間になって自動でスピン。ソロは自分でスピンします。
4. 当たっていれば配当が銀行残高に払い戻されます。

!!! note "残高が足りないとき"
    1スピンの合計ベットが残高を超える場合、そのスピンは受け付けられません（マイナス残高は作られません）。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/roulette play` | ソロ（1人用）ルーレットGUIを開く（全員可） |
| `/roulette join` | マルチ卓に参加する（全員可） |
| `/roulette leave` | マルチ卓から離れる（全員可） |
| `/roulette status` | 現在の状況を確認する（全員可） |

!!! note "コマンドの短縮形"
    `/roulette` は `/rl` と短縮できます。

## よくある質問

??? question "ソロとマルチの違いは？"
    ソロは自分専用のGUIで即結果が出ます。マルチ卓は同じ盤をみんなで囲み、ベット受付時間のあとに1回のスピンで全員の勝敗が決まります。

??? question "配当はどのくらい？"
    ストレート（単一数字）が最も高く 35:1。赤黒・奇偶・ハイローは 1:1、ダース・コラムは 2:1 です。当たると賭け金＋配当が戻ります。

??? question "賭けたエメラルドはどこから？"
    エメラルド銀行の残高から引かれ、配当も残高に入ります。他のカジノゲームと残高は共通です。
