# ブラックジャック ― 遊び方 { .page-player #blackjack-player }

ブラックジャックは、配られたトランプの合計を **21 に近づける** ことを目指すカードゲームです。エメラルドを賭けてロビーに参加し、ゲームが始まったら手札のカードを「もう1枚引く（ヒット）」か「ここで止める（スタンド）」かを選びます。21 を超える（バースト）と負け。バーストしなかったプレイヤーの中で **最も合計が大きい人** が、全員の賭け金を集めたポットを丸ごと受け取ります。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 通貨 | エメラルド（銀行の口座残高） |
    | 人数 | 1人から。看板から参加する場合は最大6人 |
    | 賭け方 | ロビー参加後にベット額を設定 |
    | 勝利条件 | バーストせず、参加者中で最も高いスコアを出す |
    | 配当 | 勝者が全員の賭け金（ポット）を総取り。同点は山分け |
    | 操作 | HIT 棒 / STAND 棒のアイテムを右クリック |

## どんなゲーム？

ブラックジャックは「プレイヤー同士でポットを奪い合う」形式のカードゲームです。

- 参加者は全員、同じ額をエメラルドで賭けます。賭け金はすべて1つの **ポット** に集められます。
- ゲームが始まると、各プレイヤーに **カードが2枚ずつ** 配られます。
- 自分の番に「もう1枚引く（ヒット）」か「止める（スタンド）」かを選び、合計を 21 に近づけます。
- 21 を超えたら **バースト（負け）** です。
- 全員が手を止めたら勝敗判定。バーストしなかった人の中で **合計が最も大きいプレイヤー** がポットを総取りします。

!!! note "ディーラーはサーバー（ハウス）"
    賭け金はいったんサーバー（ハウス）の口座に集められ、ゲーム終了時に勝者へ支払われます。ディーラー自身が手札を持って勝負するわけではなく、勝負するのは **参加プレイヤー同士** です。

## カードの数え方

手札のカードの合計（スコア）は、次のように計算します。

| カード | スコア |
|---|---|
| 2 〜 10 | 数字どおり（2〜10） |
| J・Q・K（絵札） | すべて 10 |
| A（エース） | 通常は 11。ただし合計が 21 を超えるときは自動的に 1 として数える |

!!! tip "エースは自動でいい方に計算されます"
    A は「11」または「1」のどちらか有利な方で自動計算されます。たとえば手札が「A・8」なら合計19、ここに「5」を引いて24になりそうなときは、A が自動的に1に切り替わって合計14として扱われます。自分で切り替える操作は不要です。

## ルール

- 開始時、各プレイヤーに **カード2枚** が配られます。
- 合計を **21 に近づける** のが目標です。21 ちょうどが最強です。
- 合計が **21 を超えたらバースト**。その時点でその人の勝負は終了（負け）です。
- 全員が手を止めると勝敗判定に入ります。
- バーストしなかったプレイヤーの中で、**合計が最も大きい人が勝者** です。
- スコアが同点の場合は、**より少ない枚数で** その点を作った人が勝ちます。それも同じなら **山分け** です。
- 全員がバーストした場合、勝者なし。ポットはサーバーに返還されます。

## 賭け方・配当

| 項目 | 内容 |
|---|---|
| 賭け金 | ロビー参加後に **ベット額** をエメラルドで設定 |
| ベットのタイミング | ゲーム開始前のみ。ゲーム中は変更不可 |
| 賭け金の徴収 | ゲーム開始時に口座から自動で引き落とし |
| 配当 | 勝者が **ポット（全員の賭け金の合計）を総取り** |
| 同点時 | 勝者でポットを **均等に山分け**（端数はサーバー側に残る） |

!!! warning "残高が足りないと参加できません"
    ゲーム開始時に、設定したベット額が口座残高より多いと **自動的にロビーから外されます**。先に銀行（`/ed <金額>` など）で口座にエメラルドを十分に預けておいてください。ベット額が未設定のままでもゲーム開始時にロビーから外れます。

## 参加方法

プレイヤーは会場に設置された **`[BlackJack]` 看板** からゲームに参加します。`/blackjack` コマンドは原則 OP 専用です。

| 看板 | 操作 | はたらき |
|---|---|---|
| `[BlackJack] lobby` | 右クリック | ロビーに参加。ロビー地点へテレポートします |
| `[BlackJack] bet` | 右クリック | **掛け金変更GUI** を開き、選んだ額を **ロビー参加者全員の** ベット額に設定 |
| `[BlackJack] leave` | 右クリック | ロビーから退出。スポーン地点へテレポートします |

!!! note "看板での参加の流れ"
    まず `lobby` 看板をクリックしてロビーに入り、次に `bet` 看板をクリックして開く **掛け金変更GUI** から金額を選んでベット額を決めます。看板から参加できる人数は **最大6人** です。ロビーが満員のときは参加できません。

!!! warning "/blackjack コマンドは原則 OP 専用"
    `/blackjack join` `/blackjack leave` `/blackjack bet` などのサブコマンドは、すべて OP 権限（`blackjack.start` / `blackjack.stop` / `blackjack.setup` のいずれか）でないと「OP専用です」と拒否されます。プレイヤーは上の看板から参加してください。

!!! tip "ベットは全員ぶんまとめて設定されます"
    `bet` 看板をクリックして開く掛け金変更GUIで金額を選ぶと、**そのときロビーにいる参加者全員** のベット額が同じ金額に揃えられます。卓の参加者は全員同額を賭けて勝負する形式です。

## ゲームの流れ

1. **ロビーに参加** — `lobby` 看板を右クリックしてロビーに入ります。
2. **ベット額を決める** — `bet` 看板を右クリックして賭け金を設定します。
3. **ゲーム開始** — 運営が開始すると、賭け金が口座から引き落とされ、各自にカードが2枚配られます。
4. **ヒット / スタンド** — 配られた **HIT 棒 / STAND 棒** を使って、引くか止めるかを選びます。
5. **勝敗判定** — 全員が手を止めると、最も高いスコアのプレイヤーが勝者に。
6. **配当** — 勝者にポットが支払われます。終了後はロビー地点へ戻されます。

## 操作（ヒット / スタンド）

ゲームが始まると、手札のカード（紙アイテム）と一緒に、操作用の **棒（スティック）** が2本配られます。

| アイテム | 操作 | 効果 |
|---|---|---|
| **HIT**（緑色の棒） | 手に持って右クリック | カードを1枚引く。引いた後も続けてヒットできます |
| **STAND**（赤色の棒） | 手に持って右クリック | カードを確定し、自分のターンを終了します |

- **HIT** を使うとカードが1枚増え、現在のスコアがチャットに表示されます。
- 21 を超えると **バースト** となり、その時点で自動的にターン終了です。
- **STAND** を使うと、その時点の手札で勝負が確定します。
- 全員のターンが終わると、自動で勝敗判定に進みます。

!!! note "ロビーのスコアボード表示"
    画面サイドに「[BlackJack Lobby]」のスコアボードが表示され、参加者一覧・各自のベット額・ポット金額・プレイ状況が確認できます。

## プレイヤー用コマンド

プレイヤーが直接実行できる `/blackjack` サブコマンドはありません。看板操作と、ゲーム中に配布される HIT / STAND 棒の右クリックですべての操作が完結します。

!!! info "ゲーム中の途中離脱"
    ゲーム中に切断したり `leave` 看板を押したりすると、その手札は **その場で確定（強制スタンド）** され、勝敗判定の対象になります。

## よくある質問

??? question "ブラックジャックを始めるには何が必要ですか？"
    銀行の口座にエメラルドを預けておくことだけです。あとは `lobby` 看板でロビーに参加し、`bet` 看板でベット額を設定すれば準備完了です。ゲームの開始は運営（OP）が行います。

??? question "カードはどうやって引くのですか？"
    ゲームが始まると、手札のカードと一緒に **HIT 棒（緑）** と **STAND 棒（赤）** が配られます。HIT 棒を持って右クリックすればカードが1枚増え、STAND 棒を右クリックすればその手札で勝負を確定できます。

??? question "21 を超えてしまいました"
    合計が 21 を超えると **バースト** で、その時点で負け（自動的にターン終了）です。バーストしないギリギリのところで STAND するのがコツです。A は超えそうになると自動で 1 として数えられます。

??? question "勝つとどれくらいもらえますか？"
    バーストせず最も高いスコアを出した勝者が、**参加者全員の賭け金（ポット）を総取り** します。同じスコアの人が複数いる場合は、ポットを山分けします（より少ない枚数で作った人が優先されます）。

??? question "ベット額を自分だけ変えられますか？"
    `bet` 看板や `/blackjack bet` でのベット設定は、**ロビー参加者全員が同じ額** に揃います。卓の全員が同額を賭けて勝負する形式です。ゲームが始まった後はベット額を変更できません。

??? question "ゲーム中に抜けるとどうなりますか？"
    ゲーム中に退出・切断すると、その時点の手札で **強制的にスタンド** 扱いになり、勝敗判定に含まれます。賭け金は戻りません。

??? question "「不明なコマンド」と表示されます"
    ブラックジャック（blackjack モジュール）が運営側で無効化されている可能性があります。CasinoPlugin はゲーム単位で ON / OFF できる仕組みなので、運営にお問い合わせください。
