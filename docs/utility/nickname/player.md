# Nickname ― 遊び方 { .page-player #nickname-player }

`/nick` で **あだ名** を付けると、チャット・Tab リスト・頭の上の名前があだ名になります。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 付け方 | チャットに `/nick あだ名` |
    | 文字数 | **10文字まで**（色コードは数えません） |
    | 色 | 使える（例: `/nick &bまったり`） |
    | 費用 | **最初の1回は無料**、2回目からは **500E** |
    | 戻し方 | `/nick reset`（無料） |

## あだ名の付け方

1. チャットに **`/nick あだ名`** と入力します（統合版も日本語で入力できます）。
2. 2回目以降は費用の確認が出るので、**`/nick confirm`** で確定します（やめるときは `/nick cancel`）。
3. チャット・Tab・頭の上の名前が、あだ名に変わります。

## 色の付け方

`&` と英数字1文字で色を付けられます。途中で色を変えることもできます。

| コード | 色 | コード | 色 |
|---|---|---|---|
| `&0` | 黒 | `&8` | 濃い灰色 |
| `&1` | 紺 | `&9` | 青 |
| `&2` | 緑 | `&a` | 黄緑 |
| `&3` | 青緑 | `&b` | 水色 |
| `&4` | 赤 | `&c` | 明るい赤 |
| `&5` | 紫 | `&d` | ピンク |
| `&6` | 金 | `&e` | 黄 |
| `&7` | 灰色 | `&f` | 白 |
| `&l` | **太字** | `&o` | *斜め* |
| `&n` | 下線 | `&m` | 取り消し線 |

例: `/nick &bまったり` → 水色の「まったり」、`/nick &6&lへんりー` → 金色の太字

## 守ること

- **10文字まで**（色コードは数えません）。スペースは使えません。
- **ほかの人の ID と同じあだ名は使えません**（なりすまし防止）。あだ名同士が同じなのは OK です。
- 誰か分からなくなったときは、`/nick list` で **あだ名と ID の一覧** を見られます。Java 版は、チャットの名前にカーソルを合わせると ID が出ます。

## コマンド一覧

| コマンド | できること |
|---|---|
| `/nick あだ名` | あだ名を変える |
| `/nick confirm` | 有料の変更を確定する |
| `/nick cancel` | 変更をやめる |
| `/nick reset` | あだ名を外して ID に戻す（無料） |
| `/nick info` | 今のあだ名と、次の変更の費用を見る |
| `/nick list` | 今いる人のあだ名と ID の一覧 |

## よくある質問

??? question "ミニゲーム中に ID に戻った"
    ほぼすべてのミニゲーム（50種類以上）で、ゲーム中もチャット・Tab・お知らせの名前があだ名になります。頭の上の名前だけはゲーム中は ID です。未対応のゲームでは、ゲーム中は ID で表示されます。ゲーム中にあだ名を変えた場合は、次にゲームに参加したときから反映されます。

??? question "コマンドで人を指定するときは？"
    `/msg` などのコマンドでは **ID** を使います（あだ名では指定できません）。ID は `/nick list` で確認できます。

??? question "ID に戻すのにお金はかかる？"
    かかりません。`/nick reset` は無料です。ただし、そのあとにもう一度あだ名を付けるときは 500E かかります。
