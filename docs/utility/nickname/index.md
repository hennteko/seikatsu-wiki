# Nickname（あだ名） <span class="badge done">公開中</span>

サーバーの中で **あだ名** を使えるようにするプラグインです。チャット・Tab リスト・**頭の上の名前** が、ID の代わりにあだ名になります。あだ名には色も付けられます。

!!! info "ミニゲーム中の表示"
    ほぼすべてのミニゲーム（BedWars・スプラ・DBD・人狼RPG・オセロ・UNO・マリカーなど50種類以上。一覧は OP ページ）で、ゲーム中もチャット・Tab・お知らせの名前があだ名になります。頭の上の名前だけはゲーム中は ID のままです（チーム分けの仕組みのため）。未対応のゲームでは、ゲーム中は ID で表示されます。
