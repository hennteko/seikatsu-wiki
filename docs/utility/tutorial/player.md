# Tutorial ― 遊び方 { .page-player #tutorial-player }

ミニゲームサーバーに初めて入ると、**チュートリアル** が自動で始まります。道を進みながら遊び方を覚えて、最後にミニゲームを1回遊んだら完了です。終わったあとも、ミッションやログインボーナスで **E（エメラルド残高）** がもらえます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 始まり方 | 初めてサーバーに入ると自動で開始（前から遊んでいる人は `/tutorial start`） |
    | かかる時間 | 数分（最後にミニゲームを1回遊びます） |
    | 報酬 | 完了で **100E**。ほかにミッション・ログボ・Discord 連携の報酬あり |
    | 進み具合を見る | `/tutorial`（メニューが開きます） |

## チュートリアルの流れ

画面の上（タイトル）とアクションバーに「今やること」が出ます。地点を目指すときは、あと何 m かも表示されます。

| 手順 | やること | 覚えること |
|---|---|---|
| 1 | 道を進んで **ロビー** へ行く | 看板を **右クリック（統合版はタップ）** でゲームに参加。終わると自動でロビーに戻る |
| 2 | チャットに **`/mgmenu`** と入力する | ミニゲームメニュー。遊びたいゲームを選ぶと会場へ移動できる |
| 3 | 次の案内板へ進む | お金は **E（エメラルド残高）**。報酬は E で受け取り、カジノで使える |
| 4 | 次の案内板へ進む | MattariMinecraft には **ミニゲーム / MMO / サバイバル** の3つのサーバーがある |
| 5 | **ミニゲームを1回遊ぶ** | 看板か `/mgmenu` から参加。**1人でも遊べるゲーム** もあります |

最後のミニゲームを遊び終わると完了です。**100E** がもらえます。

!!! tip "途中で抜けても大丈夫"
    進み具合は保存されます。次に入ったときに続きから始まります。今やることを忘れたら `/tutorial goal` で表示できます。

!!! note "スキップしたいとき"
    前のサーバーから遊んでいる人など、説明がいらない人は `/tutorial skip` → `/tutorial skip confirm` でスキップできます。**スキップすると完了報酬（100E）はもらえません。**

## ミッション

チュートリアルのあとも続けられる目標です。`/tutorial` のメニューで進み具合を見られます。

| ミッション | 報酬 | 達成のしかた |
|---|---|---|
| ミニゲームを **3種類** 遊ぶ | **200E** | 違うゲームを3つ遊ぶ。参加してすぐ抜けたときは数えません（目安：ゲームを最後まで遊ぶ） |
| Discord と連携する | **1,000E** | 下の「Discord 連携」を参照 |

新しいゲームを遊ぶたびに「ミッション 1/3」のように表示されます。

## ログインボーナス

その日はじめてサーバーに入ると、**毎日** E がもらえます。続けて入るほど増えます（日付は日本時間の0時で変わります）。

| 連続日数 | もらえる E |
|---|---|
| 1日目 | 100E |
| 2日目 | 250E |
| 3日目 | 300E |
| 4日目 | 350E |
| 5日目 | 400E |
| 6日目 | 450E |
| 7日目以降 | **500E（ずっと）** |

1日でも入らない日があると、1日目に戻ります。

## Discord 連携

マイクラのアカウントと Discord のアカウントをつなぐと **1,000E**。さらに、連携した人は **Discord の VC に5分いると 500E**（1日1回）もらえます。

1. マイクラで **`/tutorial link`**（またはメニューの「Discord 連携」）を押す
2. 6桁のコードが表示されます（10分有効）
3. Discord のチャット欄に **`/link 123456`**（自分のコード）と入力する。連携チャンネルの **連携する** ボタンを押してコードを入れても OK
4. 「連携しました」と表示されたら完了。マイクラでも 1,000E が入ります

!!! info "VC 報酬の条件"
    - **連携してから** 数え始めます
    - **自分以外にもう1人以上**（Bot を除く）いる VC で数えます
    - **スピーカーミュート中** と **AFK チャンネル** は数えません（マイクミュートの聞き専は OK）
    - マイクラにいないときに受け取った分は、次に入ったときにお知らせします

連携を外すときは `/tutorial unlink` です（連携の報酬は1回だけなので、もう一度連携してももらえません）。

## コマンド一覧

| コマンド | できること |
|---|---|
| `/tutorial` | メニューを開く（チュートリアル・ミッション・ログボ・Discord） |
| `/tutorial start` | チュートリアルを始める（前から遊んでいる人向け） |
| `/tutorial goal` | 今やることをもう一度表示 |
| `/tutorial skip` | チュートリアルをスキップ（報酬なし） |
| `/tutorial link` | Discord 連携のコードを表示 |
| `/tutorial unlink` | Discord 連携を外す |
| `/tutorial status` | 自分の進み具合をチャットに表示 |

## よくある質問

??? question "前から遊んでいるけど、チュートリアルの報酬はもらえる？"
    もらえます。`/tutorial start` で始めて最後まで進めると 100E もらえます（1人1回）。

??? question "ミニゲームを遊んだのにミッションが進まない"
    参加してすぐに抜けた場合は数えません。ゲームを最後まで遊んでみてください。同じゲームは何回遊んでも1種類です。カジノのゲームは数えません。

??? question "Discord で /link が出てこない"
    連携チャンネルの **連携する** ボタンを押して、コードを入力してください。

??? question "人狼RPG で連携したことがある"
    人狼RPG の連携はそのまま引き継がれます（連携報酬の 1,000E もお渡しします）。もう一度連携する必要はありません。`/wajinro link` と `/tutorial link` は同じ連携です。

??? question "コードが違うと言われる"
    コードは10分で切れて、1回使うと無効になります。マイクラでもう一度 `/tutorial link` と入力して、新しいコードを使ってください。

??? question "E はどこで確認できる？"
    カジノの銀行（エメラルドバンク）で確認できます。詳しくは [CasinoPlugin](../../casino/casino-plugin/index.md) のページを見てください。
