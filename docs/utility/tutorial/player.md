# Tutorial2 ― 遊び方 { .page-player #tutorial-player }

サーバーに初めて参加したときに表示される **チュートリアル** の進め方を解説します。配布された紙やルールブックを使いながら、サーバーの基本ルール・基本操作・基本クラフトを一通り体験できます。完了するとサーバーで自由に遊べるようになります。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 開始方法 | サーバーへ **初回ログイン** で自動開始（紙が配布される） |
    | ステップ数 | 全21ステップ（紙の使用 → ルールブック → S1移動 → クラフト各種 → パスワード） |
    | 報酬 | 各ステップ完了でエメラルド（5〜10個）／ステップ7到達時にボーナスとしてパン64個 |
    | 進行の保存 | プレイヤーごとに自動保存（再ログイン・再起動後も継続） |
    | メインコマンド | `/tutorial <サブコマンド>` |

## 始め方

1. サーバーへ **初めてログイン** すると自動的にチュートリアルが始まり、`チュートリアル開始` と書かれた **金色の紙** が配布されます。
2. 配布された紙を手に持ち、**右クリック**（統合版の場合はブロック設置ボタン）してください。
3. 以降は画面に表示される「現在の目標」に従って進めます。

!!! tip "紙やルールブックを失くしたとき"
    - 紙を失くした、または捨ててしまった場合は運営に依頼して `/tutorial paper`（OP のみ）で再発行してもらいます。
    - 紙を右クリックしたあとに進められなくなった場合は `/tutorial open` を実行すれば現在の目標が再表示されます（最初のステップにいる場合はルールブックが再配布されます）。

## チュートリアルの流れ

進行は以下の順で行われ、各ステップを達成すると次の目標が自動表示され、エメラルドが報酬として渡されます。

| # | 目標 | 達成条件 | 報酬 |
|---|---|---|---|
| 1 | チュートリアル開始 | 配布された紙を **右クリック** | 〜 |
| 2 | ルールブックを読む | 配布された「サーバールールブック」を **右クリック** | エメラルド5 |
| 3 | S1（資源ワールド）へ移動 | ワールド名 `S1` に入る | エメラルド5 |
| 4 | 共有倉庫を入手 | `/gs give` を実行 | エメラルド5 |
| 5 | スポーン地点に戻る | `/spawn` を実行 | エメラルド5 |
| 6 | 原木を入手 | 任意の `_LOG` ブロックを破壊または拾得 | エメラルド5 + **パン64個ボーナス** |
| 7 | 作業台をクラフト | クラフト結果が `CRAFTING_TABLE` | エメラルド5 |
| 8 | 棒をクラフト | クラフト結果が `STICK` | エメラルド5 |
| 9 | 木のツルハシをクラフト | クラフト結果が `WOODEN_PICKAXE` | エメラルド5 |
| 10 | 丸石を入手 | 石を破壊、または丸石を拾得 | エメラルド5 |
| 11 | 石のツルハシをクラフト | クラフト結果が `STONE_PICKAXE` | エメラルド5 |
| 12 | 石の剣をクラフト | クラフト結果が `STONE_SWORD` | エメラルド5 |
| 13 | かまどをクラフト | クラフト結果が `FURNACE` | エメラルド5 |
| 14 | 鉄鉱石（原鉄）を入手 | 鉄鉱石／深層鉄鉱石を破壊、または原鉄／鉄鉱石を拾得 | エメラルド5 |
| 15 | 鉄インゴットを入手 | かまどから鉄インゴットを取り出す | エメラルド5 |
| 16 | 鉄のツルハシをクラフト | クラフト結果が `IRON_PICKAXE` | エメラルド5 |
| 17 | 鉄装備一式をクラフト | **ヘルメット → チェストプレート → レギンス → ブーツ** の順 | 各エメラルド5 |
| 18 | 盾をクラフト | クラフト結果が `SHIELD` | エメラルド5 |
| 19 | ダイヤモンドを入手 | ダイヤ鉱石／深層ダイヤ鉱石を破壊、またはダイヤを拾得 | エメラルド10 |
| 20 | ダイヤのツルハシをクラフト | クラフト結果が `DIAMOND_PICKAXE` | エメラルド10 |
| 21 | パスワードを入力 | `/tutorial password <パスワード>` を実行 | エメラルド10 |

!!! note "鉄装備は順番が決まっています"
    17の鉄装備パートは **ヘルメット → チェストプレート → レギンス → ブーツ** の順に作る必要があります。順番を飛ばすと次のステップに進めません。ブーツを作り終えると「鉄装備一式完了！」と表示され、盾のクラフトへ進みます。

!!! warning "パスワードはVCメンバーに確認"
    最後のステップ21は **VC（ボイスチャット）メンバーから直接パスワードを聞いて入力** する仕組みです。コマンドは `/tutorial password <パスワード>` の形式で、誤入力すると「パスワードが違います」と表示されます。

## コマンド一覧

| コマンド | 権限 | 説明 |
|---|---|---|
| `/tutorial open` | 全員 | 配布された紙の代わりに、現在の目標を表示／最初のステップなら次へ進める |
| `/tutorial password <パスワード>` | 全員 | 最終ステップでパスワードを入力する |
| `/tutorial paper` | **OP のみ**（`tutorial.admin`） | 「チュートリアル開始」の紙を再発行（紛失時は運営に依頼） |

!!! note "`/tutorial open` の挙動"
    - 最初のステップ（紙の使用待ち）で実行すると、紙を右クリックしたのと同じ扱いになり、ルールブックが配布されて次に進みます。
    - 途中のステップで実行すると、現在の目標がチャットに再表示されます。
    - 既に完了している場合は「現在はチュートリアルの対象外、または既に完了しています。」と表示されます。

## 切断・再ログイン時の挙動

途中でログアウトして再接続した場合、チャットに以下が表示されます。

- `お帰りなさい！ チュートリアルの途中です。`
- `現在の目標: …`（現在のステップに応じた指示）
- `※内容がわからない場合は、配布された紙をもう一度使ってください。`

紙を失くしていても、運営に依頼すれば `/tutorial paper`（OP のみ）で再発行してもらえます。

## よくある質問

??? question "チュートリアルが始まりません"
    Tutorial2 は **初回ログイン時（過去にこのサーバーに入ったことがない状態）にのみ** 自動開始します。一度でも参加歴があるアカウントでは自動開始しません。再度始めたい場合は運営に相談してください（OPが `/tutorial skip` などで進行を補助できます）。

??? question "紙を捨ててしまいました"
    `/tutorial paper` は **OP のみ実行可能**（`tutorial.admin` が必要）です。運営に依頼して紙を再発行してもらってください。紙を右クリックすると、現在のステップが最初の段階ならルールブックが配布され、それ以外なら現在の目標が表示されます。

??? question "ルールブックを失くしました"
    最初のステップ（紙の使用待ち）に戻れる場合は、`/tutorial open` を実行するとルールブックが再配布されます。既に先のステップに進んでいる場合は、運営にご相談ください。

??? question "クラフト系のステップが進みません"
    クラフト系のステップは **クラフト結果として該当アイテムが作成された瞬間** に判定されます。クラフト結果のスロットでアイテムを実際に受け取った（取り出した）か、`Shift+クリック` で取得したかを確認してください。順序が決まっているステップ（鉄装備一式など）は順番にも注意してください。

??? question "S1に入ったのに進みません"
    判定はワールド名が **`S1`** であることが条件です。資源ワールドのワールド名・ゲート名が異なる場合は、運営にご相談ください。

??? question "報酬のエメラルドがインベントリに入りません"
    インベントリが満杯の場合、報酬は **足元にドロップ** され、「インベントリがいっぱいのため、アイテムを足元に落としました。」とチャットに表示されます。拾い直してください。

??? question "パスワードがわかりません"
    最終ステップのパスワードは **VC（ボイスチャット）メンバーに直接確認** する仕様です。配布物などには記載されていません。VCに参加してメンバーから教えてもらってください。
