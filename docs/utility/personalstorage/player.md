# PersonalStorage（個人ストレージ）― 使い方 { .page-player #personalstorage-player }

自分専用の大容量倉庫です。配布された **「個人ストレージ」の本** から開き、アイテムを種類ごとに上限なく保管できます。

## 倉庫の開き方

運営から配布された **「個人ストレージ」という名前の本**（紫色の表示名・ロア「右クリックで自分専用の倉庫を開く」）を手に持ち、**右クリック** すると倉庫GUIが開きます。中身は **自分だけ** のもので、他のプレイヤーには見えません。

!!! note "アクセスは本のみ"
    プレイヤーが使えるコマンドはありません。倉庫を開く手段は **本の右クリック** のみです（本を無くした場合は運営に再配布を依頼してください）。一部のワールドでは運営設定により本が使えないことがあります（「このワールドでは使用できません。」と表示）。

## 画面の見方

倉庫GUIは6段（54マス）です。

- **上段（45マス）** … 保管中のアイテム一覧。種類ごとに並び、各アイテムのロアに「数量: N」が表示されます。
- **左下（前のページ）** … 2ページ目以降で表示。前のページへ戻ります。
- **中央下（本のアイコン）** … 保管種類数・現在のページ／総ページ・操作説明を表示します。
- **右下（次のページ）** … 次のページがある場合に表示。次のページへ進みます。

1ページに **45種類** まで表示され、種類が増えると自動でページが追加されます。**1種類あたりの数量は実質無制限**（通常のスタック上限を超えて保管できます）。

## 預け入れ（収納）

次のいずれかの方法で収納できます。

- 自分のインベントリのアイテムを **Shift＋クリック** で倉庫へ収納。
- カーソルにアイテムを持った状態で、倉庫の上段スロットを **クリック**（統合版・スマホ向けの操作）。

収納に成功すると「✓ 収納: 数量x アイテム名」と表示され、音が鳴ります。なお **「個人ストレージ」の本そのものは収納できません**。

## 取り出し

倉庫の上段にある保管アイテムをクリックして取り出します。

| 操作 | 取り出す量 |
|---|---|
| 左クリック | 1スタック |
| 右クリック | 1個 |
| Shift＋クリック | インベントリが満杯になるまで充填 |

インベントリに空きが無いと取り出せません。数量が0になった種類は一覧から消えます。

## よくある質問

??? question "倉庫はどうやって開きますか？"
    運営から配られる「個人ストレージ」の本を手に持って右クリックしてください。コマンドでは開けません（プレイヤー用コマンドはありません）。

??? question "他の人に中身を見られますか？"
    見られません。倉庫はプレイヤーごとに完全に分かれており、自分専用です。

??? question "どれくらい貯められますか？"
    1種類あたり事実上無制限に貯められます（通常のスタック上限を超えて保管できます）。種類が多いときはページ送りで切り替えます。

??? question "本を無くしました"
    運営（OP）に再配布を依頼してください。本は何度でも配布できます。
