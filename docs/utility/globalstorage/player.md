# GlobalStorage2 ― 遊び方 { .page-player #globalstorage-player }

サーバー全体で共有できる **共有倉庫** に、アイテムを **個数制限なく** 預けたり取り出したりできます。専用の **GS スティック** や `/gs` のサブコマンドから倉庫 GUI を開き、収納・取り出し・カテゴリ絞り込み・ページ送りが可能です。さらに、拾った特定アイテムを倉庫へ自動で送る **自動転送フィルター** にも対応しています。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | できること | 共有倉庫への収納・取り出し・カテゴリ閲覧・自動転送 |
    | スタック上限 | **なし**（同種アイテムは無限にスタック） |
    | メインコマンド | `/gs`（エイリアス `/globalstorage`） |
    | 倉庫を開く道具 | GS スティック（`/gs give`） |

## 共有倉庫のしくみ

倉庫の中身は **サーバー全体で共有** です。誰かが預けたアイテムは他の全員が取り出せます。アイテムは種類ごとに 1 つのエントリにまとめられ、上限なくスタックされます（例: 丸石 100,000 個など）。倉庫の中身は JSON ファイルに自動保存されます。

!!! note "メタデータも保持されます"
    エンチャント本・名前付きアイテム・染色した革防具など、メタデータ付きのアイテムも別アイテムとして個別に保存されます（中身が違えば別エントリ）。

## GS スティックを入手する

倉庫を素早く開ける専用アイテム「**Global Storage Stick**」（見た目は棒）を取得します。

| コマンド | 説明 |
|---|---|
| `/gs give` | 自分の手元に GS スティックを 1 本配布 |

- スティックを **右クリック** すると共有倉庫 GUI が開きます。
- スティック自体は倉庫に収納できません（誤って収納される事故を防止）。
- 運営から禁止指定されたワールドではスティックを使用できません。

## 倉庫 GUI の操作

GUI は 6 行 54 スロットで、上 5 行（45 スロット）にアイテム、最下行に操作ボタンが並びます。

### アイテムの取り出し

倉庫内のアイテムをクリックして取り出します。

| クリック | 動作 |
|---|---|
| **左クリック** | そのアイテムを **1 スタック** 取り出す |
| **右クリック** | そのアイテムを **1 個だけ** 取り出す |
| **Shift + クリック** | インベントリが満杯になるまで一気に **充填** |

- インベントリに入りきらなかった分は倉庫に残ります。
- 倉庫内のアイテム残数が 0 になると、自動的に一覧から消えます。

### アイテムの収納

自分のインベントリ（GUI 下半分）から倉庫へ送ります。

- **Shift + クリック** … インベントリにあるアイテムを倉庫へ収納します。
- 統合版（Geyser）プレイヤー向けに、カーソルにアイテムを持った状態で倉庫エリア（上部 45 マス）をクリックしても収納できます。
- **GS スティックは収納できません**（収納しようとするとエラーが表示されます）。

### カテゴリで絞り込む

最下行のアイコンでカテゴリ別に表示を絞り込めます。

| スロット | アイコン | 左クリック | 右クリック |
|---|---|---|---|
| 46 | レンガ（建築/天然） | 建築ブロック | 天然ブロック |
| 47 | 白色羊毛（色付/機能） | 色付きブロック | 機能的ブロック |
| 48 | 鉄インゴット（材料/RS） | 材料 | レッドストーン |
| 49 | 鉄ピッケル（道具/戦闘） | 道具と実用品 | 戦闘 |
| 50 | リンゴ（食べ物） | 食べ物と飲み物 | — |
| 51 | バリア（その他） | その他 | — |

### ナビゲーション・その他のボタン

| スロット | 表示 | 動作 |
|---|---|---|
| 45 | 矢印「前のページ」 | 前のページへ |
| 51 | バリア「その他」 | その他カテゴリ＋現在の表示状態と件数情報 |
| 52 | ホッパー「ソート」 / バリア「リセット」 | 全表示中は **アルファベット順にソート**、カテゴリ表示中は **全表示に戻る** |
| 53 | 矢印「次のページ」 | 次のページへ |

!!! tip "アイテム数の確認"
    スロット 51（その他）にマウスを乗せると、ロアに **現在のカテゴリ・種類数・ページ番号** が表示されます。

## 自動転送フィルター（tensou）

拾ったアイテムを **倉庫へ自動転送** するフィルターを、自分専用に設定できます。フィルターはプレイヤーごとに保存され、ログアウト後も残ります。

| コマンド | 説明 |
|---|---|
| `/gs tensou` | 自動転送フィルター設定 GUI を開く |

### 設定 GUI の使い方

`/gs tensou` で開く GUI には、共有倉庫に **すでに入っているアイテムの種類** が一覧表示されます。

- **アイテムをクリック** … 自動転送 ON/OFF を切り替え（ON のアイテムには緑色の表示とエンチャント光沢が付きます）。
- **スロット 48（バリア「全て解除」）** … 自分のフィルターを全解除。
- **スロット 49（書「フィルター情報」）** … 現在の登録数を確認。
- **矢印（スロット 45 / 53）** … ページ送り。

### 動作

フィルターに登録した素材（Material 名）に該当するアイテムを **地面から拾った瞬間**、

1. ピックアップがキャンセルされる（インベントリに入らない）
2. その分が **共有倉庫に直接追加** される
3. チャットに「自動転送: 〇x 〇〇 → 共有倉庫」と通知される

!!! note "フィルターは Material 単位"
    自動転送の判定は素材名（`COBBLESTONE` などの内部名）で行われます。同じ素材なら名前やエンチャントが付いていても自動転送の対象になります。

## サブコマンド一覧（プレイヤー用）

| コマンド | 説明 |
|---|---|
| `/gs give [プレイヤー名]` | GS スティックを入手。プレイヤー名を省略すると自分に配布 |
| `/gs tensou` | 自動転送フィルター設定 GUI を開く |
| `/gs sort` | 倉庫の表示をアルファベット順にソート |

!!! note "`/globalstorage` は `/gs` のエイリアス"
    `/globalstorage` でも同じ動作になります。タブ補完で `/gs give / tensou / sort` などのサブコマンドが表示されます。

## よくある質問

??? question "倉庫を開こうとしたら「このワールドでは使用できません」と表示された"
    そのワールドは運営によって GS の利用が禁止されています。利用可能なワールドへ移動してから再度試してください。

??? question "GS スティックをなくしました"
    `/gs give` で何度でも再発行できます。スティック自体は誰でも複製できる前提の道具で、紛失しても問題ありません。

??? question "GS スティックを倉庫に入れようとしたら拒否された"
    仕様です。スティック自体は倉庫に収納できません（収納事故防止のため）。

??? question "倉庫から取り出したいアイテムが見つかりません"
    最下行のカテゴリボタンでフィルター中の可能性があります。**スロット 52 のバリア（リセット）** をクリックすると全表示に戻ります。

??? question "拾ったアイテムが勝手に倉庫に送られます"
    自動転送フィルターに登録されたアイテムです。`/gs tensou` を開き、対象アイテムをクリックして OFF にするか、スロット 48 の「全て解除」で一括解除できます。

??? question "誰かが倉庫からアイテムを抜きました"
    倉庫は **サーバー全体で共有** されており、`gs.use` 権限のあるプレイヤーであれば誰でも取り出せます。大切なアイテムは個人のエンダーチェストや保護されたチェストで管理してください。

??? question "倉庫の中身は消えませんか？"
    5 分ごとの自動保存と、サーバーシャットダウン時の保存に対応しています。通常運用ではアイテムが消えることはありません。
