# LWC（チェスト保護） ― 使い方 { .page-player #lwc-player }

チェストなどのブロックに **ロック（保護）** をかけて、他のプレイヤーに中身を取られないようにできます。チェストは **置いた瞬間に自動で自分専用にロック** されるので、基本は何もしなくて大丈夫です。フレンドに開けてもらいたいときだけコマンドを使います。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | できること | チェスト・かまど・ドアなどのロック、フレンド共有、パスワード保護 |
    | 自動保護 | チェストは設置した時点で自動的に自分専用（private）になる |
    | 共有方法 | `/cmodify <フレンド名>` で相手を追加 |
    | 確認方法 | `/cinfo` を実行してからブロックを左クリック |

## 自動ロックのしくみ

チェストを置くと、自動で **自分だけが開けられる状態（private）** になります。看板も道具も不要です。

- 自分のチェストは今まで通り開けられます。他人のチェストは開けられません。
- 保護されたブロックは **本人（と運営）以外は破壊もできません**。
- 自動ロックをやめたい場合は `/cnolock` を実行してから設置します（もう一度実行で元に戻る）。

!!! note "コマンドの使い方"
    LWC のコマンドは、**コマンドを実行 → 対象のブロックをクリック** という流れで使います。例えば `/cinfo` と打ってからチェストを左クリックすると、そのチェストの保護情報が表示されます。

## 保護タイプ

| コマンド | タイプ | 説明 |
|---|---|---|
| `/cprivate` | プライベート | 自分（と追加した人）だけが使える。**設置時の自動保護はこれ** |
| `/cpublic` | パブリック | 誰でも使えるが、保護の解除・変更は所有者のみ。「誰にも乗っ取られたくない共用チェスト」に |
| `/cpassword <パスワード>` | パスワード | パスワードを知っている人だけ使える。開けるときは `/cunlock <パスワード>` |
| `/cdonation` | 寄付 | 誰でも入れられるが、取り出せるのは所有者のみ。アイテム回収ボックスに便利 |
| `/cdisplay` | 展示 | 誰でも中身を見られるが、出し入れはできない |

タイプを変えたいときは、一度 `/cremove` で保護を外してから付け直します。

## フレンドと共有する

`/cprivate` のままで、開けられる人を追加できます。

| コマンド | 説明 |
|---|---|
| `/cmodify <名前>` | そのプレイヤーがアクセスできるようになる |
| `/cmodify -<名前>` | アクセス権を取り消す（名前の前に `-`） |
| `/cmodify @<名前>` | 管理者として追加（その人もメンバーの追加・削除ができるようになる） |

- 複数人を一度に指定できます: `/cmodify Alice Bob`
- 保護を作るときに最初から指定もできます: `/cprivate Alice @Bob`

## 保護の管理

| コマンド | 説明 |
|---|---|
| `/cinfo` | 保護の所有者・タイプを確認 |
| `/cremove` | 保護を解除（所有者のみ） |
| `/climits` | 自分が作れる保護の上限と現在数を確認 |
| `/cunlock <パスワード>` | パスワード保護を開錠（ログインごとに必要） |

## 便利なフラグ・モード

### フラグ（保護ごとの設定）

コマンド実行後に対象ブロックをクリックして ON/OFF を切り替えます。

| コマンド | 説明 |
|---|---|
| `/credstone` | レッドストーンでの開閉を許可するか（保護ドア等で使用） |
| `/cmagnet` | 近くのドロップアイテムを自動で吸い込む |
| `/cautoclose` | 保護したドアを数秒後に自動で閉める |
| `/chopper` | ホッパーでの搬入・搬出を許可するか |

### モード（自分ごとの設定）

| コマンド | 説明 |
|---|---|
| `/cpersist` | 連続モード。同じコマンドを連打せずに複数ブロックへ続けて適用できる（もう一度実行で解除） |
| `/cnolock` | 自動ロックを一時停止 |
| `/cnospam` | 保護作成時のメッセージを非表示 |

## FAQ

??? question "チェストを壊したいのに壊せない"
    自分の保護付きチェストなら、先に `/cremove` で保護を外してから壊してください。他人のものは壊せません。

??? question "ダブルチェストにしたら片方だけ保護された？"
    ダブルチェストは 1 つの保護として扱われます。保護済みチェストに連結した場合も保護が引き継がれます。

??? question "ホッパーでアイテムが搬出されない"
    保護されたチェストは既定でホッパー搬出がブロックされます。自動仕分け装置などに使う場合は `/chopper on` を実行して対象チェストをクリックしてください。

??? question "パスワード保護なのに毎回パスワードを聞かれる"
    仕様です。ログインし直すたびに `/cunlock <パスワード>` が必要になります。

??? question "引退した人のチェストが邪魔"
    プレイヤー自身では解除できません。OP・運営に相談してください。
