# CustomEnchants <span class="badge done">公開中</span>

防具に付与できる **6種類の独自エンチャント** を追加するプラグイン。エンチャント本を村人取引で入手し、金床で防具に適用することで、移動速度・ジャンプ力・経験値倍率などの効果を装備中に自動発動できます。

  <div class="quick-card"><span class="label">適用方法</span><span class="value">金床で防具に付与</span></div>
</div>

!!! note "このプラグインについて"
    CustomEnchants は Paper の Attribute / PotionEffect / イベント を組み合わせた独自エンチャントシステムです。エンチャント情報はアイテムの PersistentDataContainer（PDC）に保存され、防具を装備するだけで効果が自動的に適用されます。バニラのエンチャントと併用できます。
