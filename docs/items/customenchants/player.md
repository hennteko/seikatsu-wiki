# CustomEnchants ― 遊び方 { .page-player #customenchants-player }

バニラには存在しない **6種類の独自エンチャント** を防具に付与できるシステムです。エンチャント村人からエンチャント本を購入し、**金床** で防具に適用すると、装備中に効果が自動的に発動します。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 独自エンチャント | 6種類（移動・防御・採掘・経験値） |
    | エンチャント本の入手 | エンチャント村人（エメラルド64個 ＋ 本1冊 → エンチャント本 Lv1） |
    | 適用方法 | 金床に「防具 ＋ エンチャント本」を置く |
    | 効果の発動 | 防具を装備するだけで自動適用 |
    | 効果の合算 | 同じエンチャントを複数部位に付けるとレベルが合算 |
    | バニラとの併用 | 可能 |

## どんな機能？

CustomEnchants は、独自エンチャントが付いた **エンチャント本** を防具に付与するプラグインです。

1. **エンチャント村人** からエンチャント本（レベル1）を購入する。
2. **金床** で防具にエンチャント本を適用する。
3. 強化された防具を **装備すると効果が自動的に発動** する。

エンチャント本同士・防具同士を金床で統合してレベルを上げたり、1つの防具に複数の効果を重ねがけしたりできます。

## エンチャント本の入手

エンチャント本は、サーバー上に配置された **エンチャント村人**（取引が設定された司書）から購入します。

- **取引内容** … エメラルド64個 ＋ 本1冊 → カスタムエンチャント本（レベル1）
- **取引可能種類** … 6種類すべて（有効になっているもののみ）
- **取引回数** … 実質無制限（在庫が補充されます）
- **場所** … サーバー管理者に配置場所を確認してください。

!!! note "高レベルの本を作るには"
    村人で買えるのはレベル1の本だけです。レベルを上げるには、同じエンチャントの本を複数枚買い、**金床で統合** します（同じレベル同士の統合でレベル +1）。

## 金床での適用方法

CustomEnchants は **バニラの金床** を使います。専用 GUI はありません。

### 適用パターン

| 左スロット | 右スロット | 結果 |
|---|---|---|
| 防具 | カスタムエンチャント本 | エンチャント付き防具 |
| カスタムエンチャント本 | 防具 | エンチャント付き防具（左右逆でも可） |
| 同じ部位の防具 | 同じ部位の防具 | カスタムエンチャントを統合した防具 |

### レベルアップのルール

エンチャント本を防具に適用したり、同じ防具同士を統合すると、レベルが次のように変化します。

- **同じレベル同士** → レベル +1
    - 例: 移動速度上昇 II ＋ 移動速度上昇 II ＝ 移動速度上昇 III
- **異なるレベル同士** → 高い方のレベルが残る（防具に本を適用するとき）／高い方 +1（防具同士を統合するとき）

1つの防具に違う種類のエンチャント本を順番に適用していけば、複数の効果を重ねがけできます。

!!! tip "Lore（説明文）が自動で追加されます"
    エンチャント付き防具には「カスタムエンチャント:」の見出しと、付与されたエンチャント名・レベルが Lore に自動で表示されます。

## 効果の発動

エンチャント付き防具を **装備するだけ** で効果が自動的に発動します。

- 装備を外すと効果も自動で解除されます。
- ログイン・リスポーン・防具スロットの変更・防具のドロップ／拾得 などのタイミングで、効果が再計算されます。
- 同じエンチャントを複数の部位に付けると、**レベルが合算** されて効果値が大きくなります（例: ヘルメットに II、ブーツに III を付けると合計 V として計算）。

## 独自エンチャント一覧

全6種類です。`ID` は `/customenchants give` などで使う識別名、`効果値（Lv1あたり）` は config の `base_value`、`最大Lv` は config の `max_level`（既定値）です。

| 名前 | ID | 効果（レベル × 基礎値） | Lv1あたり | 最大Lv | おすすめ部位 |
|---|---|---|---|---|---|
| 移動速度上昇 | `movement_speed` | 移動速度がパーセンテージで上昇 | +2.0% | 5 | ブーツ |
| ノックバック耐性 | `knockback_resistance` | ノックバックを軽減（最大100%） | +1.0% | 5 | チェスト |
| 段差上限解除 | `step_height` | 登れる段差が高くなる | +0.1ブロック | 5 | ブーツ |
| ジャンプ力上昇 | `jump_boost` | ジャンプ高度が増加（ポーション効果で実装） | +0.1ブロック相当 | 5 | ブーツ |
| ブロック探索範囲 | `block_range` | ブロックの設置・破壊可能距離が伸びる | +0.1ブロック | 5 | ヘルメット |
| 経験値取得倍率 | `experience_multiplier` | 獲得経験値が増加（経験値オーブ・モブ討伐・採掘・釣り） | +5.0% | 5 | 全部位 |

!!! note "効果の合算と上限について"
    - **合算される**: 同じエンチャントを複数部位に付けると、各部位のレベルが足され、その合計値で `base_value × 合計レベル` が計算されます。
    - **ノックバック耐性** は計算結果が 100% を超えると 100% にクランプされます。
    - **ジャンプ力上昇** は内部的にバニラの「ジャンプ力上昇」ポーション効果で実装されています。装備中はアイコンが表示されます。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/customenchants list`（`/cenchants list`） | エンチャント一覧と状態を表示 |
| `/customenchants help`（`/cenchants help`） | コマンドのヘルプを表示 |

!!! note "`list` と `help` は権限不要"
    `list` と `help` は誰でも実行できます。`reload` と `give` は管理者専用（`customenchants.admin` 権限）です。

## よくある質問

??? question "エンチャント本はどこで手に入りますか？"
    サーバー上の **エンチャント村人** から購入できます。エメラルド64個と本1冊で、6種類のエンチャント本（レベル1）と交換できます。配置場所は管理者に確認してください。

??? question "1つの防具に複数のエンチャントを付けられますか？"
    付けられます。金床で防具に1種類目を付けたあと、同じ防具に別のエンチャント本を順番に適用していけば、複数の効果を重ねがけできます。

??? question "バニラのエンチャントと併用できますか？"
    できます。耐久力や落下耐性など、通常のエンチャントが付いた防具にカスタムエンチャントを追加してもどちらも有効です。

??? question "効果が発動しません"
    まずエンチャント本のままでは効果がありません。金床で **防具に適用** したうえで **装備** してください。それでも反映されない場合は、一度装備を外して付け直してみてください。ログイン直後や防具入れ替え直後に少し遅延があります。

??? question "同じエンチャントを複数の部位に付けると強くなりますか？"
    強くなります。CustomEnchants の効果は **部位ごとのレベルが合算** されて計算されます。例えば、移動速度上昇 II（ヘルメット）＋ 移動速度上昇 III（ブーツ）＝ 合計 V として効果が出ます。

??? question "ジャンプ力上昇のアイコンが画面に表示されます"
    仕様です。CustomEnchants の「ジャンプ力上昇」はバニラのポーション効果で実装されているため、効果中はアイコンが表示されます。装備を外せば消えます。

??? question "経験値取得倍率はどんな経験値に効きますか？"
    経験値オーブ拾得（自然消費）・モブ討伐・ブロック破壊（鉱石など）・釣りでの経験値ドロップに対して倍率がかかります。Lv5 を装備していれば 1.25 倍になります。
