# EnchantPlus <span class="badge done">公開中</span>

カスタム金床GUIと **19種類の独自エンチャント** を追加するプラグイン。エメラルドで本を買い、専用の金床で防具に付与・統合して、移動速度・暗視・自動修理などの強化を楽しめます。

!!! note "このプラグインについて"
    EnchantPlus は独自の金床GUIで防具を強化するシステムです。バニラのエンチャントと併用でき、付与した効果は防具を装備するだけで自動的に発動します。エンチャント本はサーバー上の **エンチャント商人** から購入できます。
