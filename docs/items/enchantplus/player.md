# EnchantPlus ― 使い方 { .page-player #enchantplus-player }

通常のMinecraftにはない **19種類の独自エンチャント** を防具に付けて、自分だけの強化装備を作れるシステムです。エンチャント本を入手し、専用の **カスタム金床** で防具に適用しましょう。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 独自エンチャント | 19種類（移動・採掘・戦闘・特殊など） |
    | エンチャント本の入手 | エンチャント商人（エメラルド64個＋本1冊） |
    | 適用方法 | カスタム金床GUI（`/enchantplus`） |
    | 効果の発動 | 防具を装備するだけで自動適用 |
    | バニラとの併用 | 可能（通常のエンチャントと共存） |

## どんな機能？

EnchantPlus は、独自エンチャントが付いた **エンチャント本** を防具に付与するプラグインです。

1. **エンチャント商人** からエンチャント本を購入する。
2. **カスタム金床GUI** で防具に本を適用する。
3. 強化された防具を **装備すると効果が自動的に発動** する。

エンチャント本同士を統合してレベルを上げたり、1つの防具に複数の効果を重ねがけしたりできます。バニラのエンチャント（耐久力・落下耐性など）とも併用可能です。

## カスタム金床の使い方

### 金床GUIの開き方

カスタム金床GUIは次の **3つの方法** で開けます。

| 方法 | 操作 |
|---|---|
| コマンド | `/enchantplus`（`/ep`・`/eanvil` でも可） |
| 金床を右クリック | 設置された金床ブロックを右クリック |
| ポータブル金床 | 専用アイテムを手に持って右クリック（管理者から付与） |

!!! tip "バニラの金床を使いたいとき"
    金床ブロックを **スニーク（Shift）しながら右クリック** すると、通常（バニラ）の金床GUIが開きます。修理や名前変更はこちらで行えます。

### エンチャントの適用手順

1. `/enchantplus` などでカスタム金床GUIを開く。
2. **左スロット** に防具、**右スロット** にエンチャント本を置く。
3. **中央のスロット** にエンチャント付き防具が表示される。
4. 必要な経験値レベルを確認し、中央のアイテムをクリックして受け取る。

受け取ると **左右のアイテムと経験値レベルが消費** されます。経験値レベルが足りないと受け取れません。

!!! note "経験値コストについて"
    カスタム金床は受け取り時に経験値レベルを消費します（コストはランダムに変動します）。コストが高いと感じたら、一度GUIを閉じて開き直すと変わることがあります。

### 統合パターン

カスタム金床は、左右に置いたアイテムの組み合わせで動作が変わります。

| 左スロット | 右スロット | 結果 |
|---|---|---|
| エンチャント本 | エンチャント本 | レベルを統合した本 |
| 防具 | エンチャント本 | エンチャント付き防具 |
| 防具 | 防具（同じ部位） | 両方の効果を統合した防具 |
| 防具 | 防具（違う部位） | 統合不可 |

### レベルアップのルール

エンチャント本を統合するとレベルが変化します。

- **同じレベル同士** → レベル +1
    - 例: 移動速度上昇 V ＋ 移動速度上昇 V ＝ 移動速度上昇 VI
- **異なるレベル同士** → 高い方のレベルが残る
    - 例: 移動速度上昇 V ＋ 移動速度上昇 III ＝ 移動速度上昇 V

1つの防具に違う種類のエンチャントを順番に付けていけば、複数の効果を重ねがけできます。

## 独自エンチャント一覧

全19種類です。`ID` は `/enchant give` などで使う識別名、`統合版` はGeyser/統合版での対応状況です。

=== "移動・探索系"

    | 名前 | ID | 効果 | おすすめ部位 | 統合版 |
    |---|---|---|---|---|
    | 移動速度上昇 | `movement_speed` | 移動速度がレベルに応じて上昇 | ブーツ | ✅ |
    | ジャンプ力上昇 | `jump_boost` | ジャンプ力が上昇 | ブーツ | ✅ |
    | 落下ダメージ無効 | `slow_falling` | 落下ダメージを受けなくなる | ブーツ | ✅ |
    | 段差上限解除 | `step_height` | 高い段差を登れるようになる | ブーツ | ❌ Java版のみ |
    | 暗視能力 | `night_vision` | 暗闇でも明るく見える | ヘルメット | ✅ |
    | 水中呼吸延長 | `water_breathing` | 水中で酸素が減らなくなる | ヘルメット | ✅ |

=== "採掘・収集系"

    | 名前 | ID | 効果 | おすすめ部位 | 統合版 |
    |---|---|---|---|---|
    | 採掘速度上昇 | `mining_speed` | ブロックの破壊速度が上がる | ヘルメット | ✅ |
    | ブロック探索範囲 | `block_range` | ブロックの設置・破壊範囲が広がる | ヘルメット | ❌ Java版のみ |
    | 幸運の祝福 | `luck` | ドロップ率が上がる（Luck効果） | 全部位 | ✅ |
    | 経験値取得倍率 | `experience_multiplier` | 獲得経験値が増加（部位ごとに合算） | 全部位 | ✅ |

=== "戦闘・防御系"

    | 名前 | ID | 効果 | おすすめ部位 | 統合版 |
    |---|---|---|---|---|
    | ノックバック耐性 | `knockback_resistance` | 攻撃を受けてもノックバックされにくい | チェスト | ✅ |
    | 炎耐性上昇 | `fire_resistance` | 火炎・溶岩ダメージを無効化 | チェスト | ✅ |
    | 再生能力 | `regeneration` | 体力が自動で回復する | チェスト | ✅ |
    | 吸収シールド | `absorption` | 黄色いハート（追加体力）が付く | チェスト | ✅ |

=== "特殊能力系"

    | 名前 | ID | 効果 | おすすめ部位 | 統合版 |
    |---|---|---|---|---|
    | アイテム修理 | `item_repair` | 装備の耐久値が自動回復（20秒ごと） | 全部位 | ✅ |
    | 透明化 | `invisibility` | プレイヤーが透明になる（防具は見える） | ヘルメット | ✅ |
    | 満腹度維持 | `saturation` | 空腹ゲージが減りにくくなる | チェスト | ✅ |

!!! tip "効果が合算されるエンチャント"
    一部のエンチャントは複数の部位に付けると効果が合算されます（経験値取得倍率・棘の鎧強化・防御力強化・吸収シールド・幸運の祝福など）。移動速度上昇などポーション効果系のエンチャントは、最も高いレベルのみが適用され合算されません。

## エンチャント商人

エンチャント本は、サーバー上にいる **エンチャント商人** から購入します。

- **見た目** … 司書（金色で太字の「エンチャント商人」という名前）。その場に固定されて動きません。
- **取引内容** … エメラルド64個 ＋ 本1冊 → エンチャント本（レベル1）。
- **取引方法** … 商人を右クリックし、取引画面で19種類のエンチャント本から選んで購入します。
- **場所** … サーバーの管理者に配置場所を確認してください。

!!! note "高レベルの本を作るには"
    商人で買えるのはレベル1の本です。レベルを上げるには、同じ本を2冊買ってカスタム金床で統合します（同じレベル同士の統合でレベル +1）。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/enchantplus`（`/ep`・`/eanvil`） | カスタム金床GUIを開く |
| `/enchant list` | 独自エンチャントの一覧を表示する |
| `/enchant help` | コマンドのヘルプを表示する |

!!! note "エンチャント商人の召喚について"
    エンチャント商人を呼び出す `/enchantvillager` は管理者向けコマンドです。一般プレイヤーは、すでに配置されている商人から購入してください。

## よくある質問

??? question "エンチャント本はどこで手に入りますか？"
    サーバー上の **エンチャント商人**（金色の名前の司書）から購入できます。エメラルド64個と本1冊で、好きなエンチャント本（レベル1）と交換できます。配置場所は管理者に確認してください。

??? question "1つの防具に複数のエンチャントを付けられますか？"
    付けられます。カスタム金床で防具に1種類目を付けたあと、同じ防具に別のエンチャント本を統合していくことで、複数の効果を重ねがけできます。

??? question "バニラのエンチャントと併用できますか？"
    できます。耐久力や落下耐性などの通常エンチャントが付いた防具に、独自エンチャントを追加してもどちらも有効です。

??? question "効果が発動しません"
    エンチャント本のままでは効果がありません。必ずカスタム金床で **防具に適用** し、その防具を **装備** してください。それでも反映されない場合は装備し直してみてください。

??? question "同じエンチャントを複数の部位に付けると強くなりますか？"
    エンチャントによります。経験値取得倍率・棘の鎧強化・防御力強化・吸収シールド・幸運の祝福などは効果が合算されます。移動速度上昇などポーション効果系は最も高いレベルのみが適用されます。

??? question "レベルの上限はいくつですか？"
    既定では各エンチャントの最大レベルは25です。`/enchant list` で各エンチャントの最大レベルを確認できます（サーバー設定により異なる場合があります）。
