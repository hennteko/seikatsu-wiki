# EnchantPack ― 遊び方 { .page-player #enchantpack-player }

EnchantPack は、旧 **EnchantPlus**（カスタム金床GUI ＋ 19種の独自エンチャント）と旧 **CustomEnchants**（村人取引で配布される6種の別系統エンチャント）を1つのプラグインにまとめた拡張エンチャントパックです。両方の独自エンチャントを同時に使えます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 構成 | 2モジュール（enchantplus / customenchants） |
    | 独自エンチャント | EnchantPlus 19種 ＋ CustomEnchants 6種 |
    | 入手方法 | エンチャント商人（EnchantPlus）／エンチャント村人（CustomEnchants） |
    | 適用方法 | カスタム金床GUI（EnchantPlus）／バニラの金床（CustomEnchants） |
    | 効果の発動 | 防具を装備するだけで自動適用 |
    | バニラとの併用 | 両モジュールとも可能（通常のエンチャントと共存） |

## 2モジュールの概要

EnchantPack は **2つの独立したエンチャント系モジュール** を持ちます。どちらも独自のエンチャント本を防具に適用する形式ですが、入手方法・金床の使い方・効果一覧が異なります。

| モジュール | エンチャント数 | 入手方法 | 適用に使う金床 | コマンド入口 |
|---|---|---|---|---|
| **EnchantPlus** | 19種（移動・採掘・戦闘・特殊） | エンチャント商人（エメラルド64個 ＋ 本 → エンチャント本 Lv1） | カスタム金床GUI（`/enchantplus` または金床右クリック） | `/enchantplus`、`/enchant` |
| **CustomEnchants** | 6種（移動速度UP・ノックバック耐性・ステップ高さ・ジャンプ力・ブロック探索範囲・経験値倍率） | エンチャント村人（取引が設定された司書） | バニラの金床（GUIは無し） | `/customenchants`（`/cenchants`） |

!!! tip "どちらのエンチャント？"
    エンチャント本の Lore（説明文）を見ると区別できます。CustomEnchants の本には「**カスタムエンチャント**」の見出しが付き、EnchantPlus の本はカスタム金床GUI 経由でないと統合・適用ができません。両モジュールのエンチャントは別系統なので、1つの防具に両方を重ねがけすることもできます。

## EnchantPlus モジュール（19種）

カスタム金床GUI で防具に付与する独自エンチャントです。

### エンチャント本の入手

- **エンチャント商人**（金色で太字の「エンチャント商人」という名前の司書）から購入します。
- **取引内容**: エメラルド64個 ＋ 本1冊 → エンチャント本（レベル1）
- 商人はその場に固定されて動きません。配置場所は管理者に確認してください。

### 適用方法（カスタム金床GUI）

カスタム金床GUIは次の3つの方法で開けます。

| 方法 | 操作 | 一般プレイヤーへの公開 |
|---|---|---|
| コマンド | `/enchantplus`（`/eanvil` でも可） | **OPのみ**（権限 `enchantplus.command.gui` 既定で OP） |
| 金床を右クリック | 設置された金床ブロックを右クリック | 全員可（`enchantplus.gui.use` 既定で `true`） |
| ポータブル金床 | 専用アイテムを手に持って右クリック（管理者から付与） | 全員可（同上） |

!!! tip "プレイヤーは金床の右クリックでOK"
    `/enchantplus` 系コマンドは原則 OP 専用です。一般プレイヤーは設置された **金床ブロックを右クリック** すればカスタム金床GUIが開きます（スニーク中はバニラ金床になります）。

GUI 内の操作:

1. **左スロット** に防具、**右スロット** にエンチャント本を置く。
2. **中央のスロット** にエンチャント付き防具が表示される。
3. 経験値レベルを確認し、中央のアイテムをクリックして受け取る。

!!! tip "バニラの金床を使いたいとき"
    金床ブロックを **スニーク（Shift）しながら右クリック** すると、通常（バニラ）の金床GUIが開きます。修理や名前変更はこちらで行えます。

### 19種類のエンチャント

=== "移動・探索系"

    | 名前 | ID | 効果 | おすすめ部位 |
    |---|---|---|---|
    | 移動速度上昇 | `movement_speed` | 移動速度がレベルに応じて上昇 | ブーツ |
    | ジャンプ力上昇 | `jump_boost` | ジャンプ力が上昇 | ブーツ |
    | 落下ダメージ無効 | `slow_falling` | 落下ダメージを受けなくなる | ブーツ |
    | 段差上限解除 | `step_height` | 高い段差を登れるようになる | ブーツ |
    | 暗視能力 | `night_vision` | 暗闇でも明るく見える | ヘルメット |
    | 水中呼吸延長 | `water_breathing` | 水中で酸素が減らなくなる | ヘルメット |

=== "採掘・収集系"

    | 名前 | ID | 効果 | おすすめ部位 |
    |---|---|---|---|
    | 採掘速度上昇 | `mining_speed` | ブロックの破壊速度が上がる | ヘルメット |
    | ブロック探索範囲 | `block_range` | ブロックの設置・破壊範囲が広がる | ヘルメット |
    | 幸運の祝福 | `luck` | ドロップ率が上がる（Luck効果） | 全部位 |
    | 経験値取得倍率 | `experience_multiplier` | 獲得経験値が増加（部位ごとに合算） | 全部位 |

=== "戦闘・防御系"

    | 名前 | ID | 効果 | おすすめ部位 |
    |---|---|---|---|
    | ノックバック耐性 | `knockback_resistance` | 攻撃を受けてもノックバックされにくい | チェスト |
    | 炎耐性上昇 | `fire_resistance` | 火炎・溶岩ダメージを無効化 | チェスト |
    | 再生能力 | `regeneration` | 体力が自動で回復する | チェスト |
    | 吸収シールド | `absorption` | 黄色いハート（追加体力）が付く | チェスト |
    | 防御力強化 | `armor_toughness` | 防御力／防御強度が上がる | チェスト |
    | 棘の鎧強化 | `thorns` | 攻撃してきた相手にダメージを反射 | 全部位 |

=== "特殊能力系"

    | 名前 | ID | 効果 | おすすめ部位 |
    |---|---|---|---|
    | アイテム修理 | `item_repair` | 装備の耐久値が自動回復（20秒ごと） | 全部位 |
    | 透明化 | `invisibility` | プレイヤーが透明になる（防具は見える） | ヘルメット |
    | 満腹度維持 | `saturation` | 空腹ゲージが減りにくくなる | チェスト |

!!! note "高レベル本の作成"
    商人で買えるのはレベル1の本です。レベルを上げるには、同じ本を2冊買ってカスタム金床で統合します（同じレベル同士の統合でレベル +1）。

## CustomEnchants モジュール（6種）

別系統の独自エンチャントです。**バニラの金床** を使って適用します。

### エンチャント本の入手

- **エンチャント村人**（取引が設定された司書）から購入します。
- **取引内容**: エメラルド64個 ＋ 本1冊 → カスタムエンチャント本（レベル1）
- 取引可能種類: 6種類すべて（有効になっているもののみ）
- 取引回数は実質無制限。配置場所は管理者に確認してください。

### 適用方法（バニラの金床）

CustomEnchants は **バニラの金床** を使います。専用 GUI はありません。

| 左スロット | 右スロット | 結果 |
|---|---|---|
| 防具 | カスタムエンチャント本 | エンチャント付き防具 |
| カスタムエンチャント本 | 防具 | エンチャント付き防具（左右逆でも可） |
| 同じ部位の防具 | 同じ部位の防具 | カスタムエンチャントを統合した防具 |

### 6種類のエンチャント

| 名前 | ID | 効果（Lv1あたり） | 最大Lv | おすすめ部位 |
|---|---|---|---|---|
| 移動速度上昇 | `movement_speed` | 移動速度 +2.0% | 5 | ブーツ |
| ノックバック耐性 | `knockback_resistance` | ノックバック軽減 +1.0%（最大100%） | 5 | チェスト |
| 段差上限解除 | `step_height` | 段差 +0.1ブロック | 5 | ブーツ |
| ジャンプ力上昇 | `jump_boost` | ジャンプ高度 +0.1ブロック相当 | 5 | ブーツ |
| ブロック探索範囲 | `block_range` | 設置・破壊距離 +0.1ブロック | 5 | ヘルメット |
| 経験値取得倍率 | `experience_multiplier` | 獲得経験値 +5.0% | 5 | 全部位 |

!!! note "効果の合算"
    CustomEnchants の効果は **部位ごとのレベルが合算** されて計算されます（例: ヘルメット II ＋ ブーツ III = 合計 V）。EnchantPlus の効果合算ルールとは別管理です。

## プレイヤー用コマンド（参考）

以下のコマンドは plugin.yml で OP 限定（`default: op`）に設定されているため、**一般プレイヤーは通常使用できません**。プレイヤー向けの利用導線は「金床右クリック」「エンチャント商人／村人との取引」です。

| コマンド | エイリアス | モジュール | 公開範囲 | 説明 |
|---|---|---|---|---|
| `/enchantplus` | `/eanvil` | EnchantPlus | OPのみ | カスタム金床GUIをコマンドから開く |
| `/enchant list` | `/customenchant list` | EnchantPlus | OPのみ | 独自エンチャントの一覧を表示する |
| `/enchant help` | `/customenchant help` | EnchantPlus | OPのみ | コマンドのヘルプを表示する |
| `/customenchants list` | `/cenchants list` | CustomEnchants | OPのみ | 6種類のエンチャント状態を表示 |
| `/customenchants help` | `/cenchants help` | CustomEnchants | OPのみ | コマンドヘルプを表示 |

!!! warning "`/ce` エイリアスは廃止されています"
    旧 CustomEnchants の `/ce` エイリアスは、同サーバーの **CaveEraser** プラグインと衝突するため、統合に伴って削除されました。CustomEnchants 側は `/customenchants` または `/cenchants` を使ってください。

## よくある質問

??? question "EnchantPlus と CustomEnchants はどう違いますか？"
    どちらも防具に独自エンチャントを付与する点は同じですが、**入手方法（商人 / 村人）・適用に使う金床（カスタム金床GUI / バニラ金床）・効果一覧** が異なります。EnchantPack ではどちらも同時に使えるため、1つの防具に両方のエンチャントを重ねがけできます。

??? question "1つの防具に EnchantPlus と CustomEnchants の両方を付けられますか？"
    付けられます。両モジュールは別系統で動作するため、互いに干渉しません。例えば「ブーツに EnchantPlus の移動速度上昇 V ＋ CustomEnchants の段差上限解除 III」を同時に付与できます。

??? question "前のサーバーで持っていたエンチャント本／防具はそのまま使えますか？"
    使えます。EnchantPack は旧 EnchantPlus / CustomEnchants の NamespacedKey（`enchantplus:` / `customenchants:`）を維持しているため、**既存配布済みのエンチャント本・防具はすべてそのまま認識・動作します**。

??? question "効果が発動しません"
    エンチャント本のままでは効果がありません。必ず金床（EnchantPlus はカスタム金床GUI、CustomEnchants はバニラ金床）で **防具に適用** し、その防具を **装備** してください。それでも反映されない場合は装備し直してみてください。

??? question "コマンドが「不明なコマンド」と出ます"
    そのモジュールが運営側で無効化されている可能性があります（`config.yml` の `modules.<id>.enabled: false`）。あるいは権限が不足している可能性もあります。運営にお問い合わせください。

??? question "ジャンプ力上昇のアイコンが画面に表示されます"
    仕様です。CustomEnchants の「ジャンプ力上昇」はバニラのポーション効果で実装されているため、効果中はアイコンが表示されます。装備を外せば消えます。
