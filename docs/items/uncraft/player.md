# Uncraft2 ― 遊び方 { .page-player #uncraft-player }

クラフト済みのアイテムを **元の素材に戻せる** プラグインです。`/uncraft` で専用GUIを開き、戻したいアイテムを入れるだけで自動的にレシピを検索して素材を返してくれます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | コマンド | `/uncraft`（権限 `uncraft.use` 既定で全員可） |
    | GUIサイズ | 1段（9スロット） |
    | 投入スロット | 左端（スロット 0） |
    | 結果／実行スロット | 中央（スロット 2、クリックで分解実行） |
    | レシピ切替 | 矢印ボタン（スロット 4 = 前 / スロット 5 = 次） |
    | 対応レシピ | Shaped レシピ・Shapeless レシピ |
    | アンクラフトステーション | 右クリックで `/uncraft` と同じGUIを開く作業台アイテム（管理者から付与） |

## どんな機能？

Uncraft2 は、サーバーに登録されているクラフトレシピを **動的に検索** して、その逆算で素材を返却するプラグインです。

1. `/uncraft` でGUIを開く。
2. 左端のスロットに **戻したいアイテム** を入れる。
3. 中央スロットにレシピ候補が表示されるので、必要なら矢印で別レシピに切り替える。
4. 中央スロットを **クリックして分解実行**。素材がインベントリに返却される。

GUIを閉じても、スロットに残ったアイテムは自動でインベントリに戻ります（インベントリが満杯なら足元にドロップします）。

## `/uncraft` の使い方

| コマンド | 説明 |
|---|---|
| `/uncraft` | アンクラフトGUIを開く（プレイヤー専用） |

コンソールから実行した場合は「このコマンドはプレイヤーのみ実行できます。」と表示されます。

## GUI「アンクラフトステーション」の操作

GUIは横1列・9スロット構成です。スロットの役割は次のとおりです。

| スロット | 役割 | 表示 |
|---|---|---|
| 0（左端） | **投入スロット** | 戻したいアイテムをここへ |
| 1 | 装飾（灰色ガラス板） | 操作不可 |
| 2（中央） | **結果／実行スロット** | レシピ情報を表示、クリックで分解実行 |
| 3 | 装飾（灰色ガラス板） | 操作不可 |
| 4 | **前のレシピへ**（矢印） | 別レシピへ切り替え |
| 5 | **次のレシピへ**（矢印） | 別レシピへ切り替え |
| 6・7・8 | 装飾（灰色ガラス板） | 操作不可 |

### 操作の流れ

1. 左端（スロット 0）に戻したいアイテムを置く。シフトクリックでも投入できます。
2. 中央（スロット 2）に **レシピ情報** が表示されます。lore には次の項目が並びます。
    - 選択中レシピ番号（例：`選択: 1/3`）
    - クラフト結果数量
    - 分解時の最小消費数
    - 必要素材（マテリアル名と個数）
3. 複数レシピがある場合は、矢印ボタン（スロット 4 / 5）で **前後のレシピに切り替え** できます（クリック音つき）。
4. 中央スロットをクリックすると **分解実行**。成功すると次のメッセージが表示されます。

    ```
    [アンクラフト成功]
    消費: ○個 → 素材: ○個
    ```

5. アンビル音と経験値オーブの音が鳴り、素材がインベントリに入ります（入りきらない分はその場にドロップします）。

### 分解できる「最小数量」のルール

分解はレシピ単位で行われます。**レシピの結果アイテム数（=クラフト時にできる数）の倍数** ぶんだけ消費されます。

- 例：丸石→石の階段は1回のクラフトで4個できるため、階段は **4個単位** でしか戻せません（4個なら4個消費／7個なら4個だけ消費、残り3個はそのまま残る）。
- 必要数に満たないとき：

    ```
    アンクラフトにはこのアイテムが少なくとも ○個 必要です。
    現在: ○個
    ```

    と表示され、村人の「無理」音が鳴ります。

### レシピが見つからないとき

入力スロットに置いたアイテムにクラフトレシピが見つからない場合、結果スロットに **赤いバリアブロックで「レシピが見つかりません」** と表示されます。

## アンクラフト可能／不可なアイテム

Uncraft2 は **サーバーの登録レシピを走査** し、次の条件を満たすレシピのみを対象にします。

### 対象になるレシピ

- **Shaped レシピ**（並びが決まっているクラフト：階段・剣・かまど など）
- **Shapeless レシピ**（並び順を問わないクラフト：花染料・本＋革→本と羽 など）

複数レシピを持つアイテム（例：板材は丸太4種ぶん登録されている）では、矢印で順に切り替えられます。Uncraft2 は内部で次のように **優先順** を決めています。

1. Shaped レシピを Shapeless より優先
2. 結果数量が多いレシピを優先

### 対象にならないもの

| 種類 | 例 | 理由 |
|---|---|---|
| かまど系レシピ | 鉄インゴット（鉄鉱石を焼く） | Furnace / Smoker / Blast Furnace は対象外 |
| 焚き火 | 焼き肉類 | Campfire レシピは対象外 |
| 醸造（ポーション） | スプラッシュポーション | 対象外 |
| 鍛冶台・石切台のレシピ | ネザライト装備のアップグレード | Smithing / Stonecutter は対象外 |
| そもそもレシピが存在しないアイテム | スポーンエッグ など | 「レシピが見つかりません」と表示 |
| 結果が空 / AIR / 数量0 のレシピ | プラグイン側で除外 | 安全のため非対応 |

### 素材表示の注意

- 結果スロットの lore に表示される素材は、**マテリアル単位** にまとめて表示されます（同じ素材が複数マスにある場合は合算）。
- 一部の素材は日本語表示にマッピングされています（オークの板材・トウヒの板材・シラカバの板材・ジャングルの板材・アカシアの板材・ダークオークの板材・棒・丸石・石・鉄インゴット・金インゴット・ダイヤモンド・糸・革・レッドストーン）。それ以外の素材は、マテリアル名がそのまま小文字＋半角スペース表記で表示されます。
- 「いずれかの素材で良い」レシピ（例：丸石でも他の石材でも作れる類）の場合、Uncraft2 は **最初の候補マテリアル** を返却素材として使用します。

## アンクラフトステーションを使う

管理者から **「アンクラフトステーション」** という名前の作業台（CRAFTING_TABLE）を受け取った場合、それを **手に持って右クリック** するだけで `/uncraft` と同じGUIが開きます。

- 見た目：金色＋太字＋下線で「アンクラフトステーション」と書かれた作業台。
- lore：
    - 右クリックでアンクラフト画面を開く
    - アイテムを素材に戻すことができます
    - ※ 何度でも使用可能
- 操作：手に持って **右クリック（空中／ブロック）**。チェストを開く音が鳴り、GUIが開きます。
- 設置：右クリック時にイベントがキャンセルされるため、**ブロックとして設置することはできません**。アイテムのまま持ち歩いて使います。
- 受け取り時：チャットに次のメッセージが流れます。

    ```
    [アンクラフト] アンクラフトステーション x○ を受け取りました！
    ```

!!! tip "コマンドが使えない場合の代替"
    `uncraft.use` 権限が剥奪されている／コマンドUIを使いたくない、といった場合でも、アンクラフトステーションを持っていれば右クリックでGUIを開けます（コマンド権限のチェックは右クリック側では行われません）。

## よくある質問

??? question "戻したいアイテムが「レシピが見つかりません」になります"
    Uncraft2 が対象にするのは **クラフト台で作れる Shaped / Shapeless レシピ** だけです。かまどで焼く・醸造する・鍛冶台でアップグレードする…といった作り方のアイテムは対象外なので「レシピが見つかりません」と表示されます。

??? question "7個持っているのに「4個必要」と言われます"
    レシピの結果数（クラフト1回でできる数）の倍数でしか分解できません。例えば階段は4個単位なので、7個あっても **4個ぶんだけ** 分解され、残り3個はそのまま残ります。表示は「最低でも4個必要」という意味合いです。

??? question "返ってきた素材の種類が違う気がします"
    1つの素材スロットに複数のマテリアル候補があるレシピ（例：板材ならどの種類でも可）の場合、Uncraft2 は **最初の候補マテリアル** を返却します。狙ったマテリアルが戻ってほしい場合は、対応するレシピを矢印ボタンで選び直してください。

??? question "GUIを閉じたらアイテムが消えました"
    投入スロットに残ったアイテムは GUI を閉じたタイミングで **自動的にインベントリに返却** されます。インベントリが満杯だった場合は **その場にドロップ** します（紛失ではないので、ドロップを拾ってください）。

??? question "アンクラフトステーションを地面に置きたい"
    仕様上、右クリック時にブロック設置がキャンセルされるため設置はできません。アイテムのまま使う想定の道具です。

??? question "経験値や手数料はかかりますか？"
    かかりません。Uncraft2 はアイテムの消費だけで素材を返却します。
