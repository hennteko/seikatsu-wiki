# ゴッドフィールド（GodField） ― 遊び方 { .page-player #godfield-player }

毎ターン神器（カード）を授かり、武器・奇跡・雑貨で殴り合うターン制カードバトルです。HPが0になると昇天。最後まで生き残った人（チーム戦なら最後まで残ったチーム）が勝ちます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | 個人戦（ffa） / チーム戦（team） / CPU入り（ffa-cpu・team-cpu） |
    | 人数 | 2〜9人（1人のときは CPU 入りで） |
    | 最初の持ち物 | HP 40・MP 10・¥20・手札9枚（武器1・防具1を保証） |
    | 自分の番 | 神器を授かる → 攻撃・奇跡・雑貨・祈る のどれか1つ（既定40秒） |
    | 防御 | 攻撃されたら制限時間内に防具を選ぶ（既定15秒） |
    | 勝利条件 | 最後の1人（チーム戦は最後の1チーム）。最大ラウンド到達時はHPの多い方 |
    | 参加方法 | ロビーの参加看板、または `/gf join` |
    | 画面を開く | 「手札を開く」本を右クリック／タップ、または `/gf hand` |

## どんなゲーム？

全員が **HP・MP・¥（お金）** を持ってスタートします。順番に手番が回り、自分の番では **神器を授かって** から、次のどれか1つの行動を取ります。

- **攻撃** … 武器（＋強化）で相手のHPを削る。
- **奇跡** … MPを使って攻撃・回復・妨害などを起こす（起こした奇跡は手札に残り、MPがある限り何度でも使える）。
- **雑貨** … 回復や¥のやり取り、相手の神器を盗む・交換するなど。
- **祈る** … 何もせず神器を1つ多く授かって番を終える。

攻撃された人は、制限時間内に **防具** を選んで受けます。HPが0になると **昇天**（卓に残って観戦）。最後まで生き残った人が勝ちです。

## 自分の番の流れ

1. **病の効果** … 病（風邪など）にかかっていると番の始めに効果が出て、一定の確率で1段階悪化します。
2. **神器を授かる** … 番の始めに神器を1つ授かります（終末の時以降は悪魔などが現れることも）。
3. **行動（既定40秒）** … 攻撃・奇跡・雑貨・祈る のどれか1つを選びます。時間切れになると自動で「祈る」扱いです。
4. **次の人へ** … 行動のあと少し間（既定1秒）を置いて、次の人の番になります。

全員の番が一周すると1ラウンド進みます。**捨てる（ささげる）** は番に関係なく、防御中・取引中でなければいつでも行えます。

## HP・MP・¥

| 値 | 初期値 | 上限 | 役割 |
|---|---|---|---|
| HP | 40 | 99 | 0になると昇天 |
| MP | 10 | 99 | 奇跡を起こすのに使う |
| ¥（お金） | 20 | 99 | 買う・売るなどの取引に使う |

**両替商の天秤**（雑貨）を使うと、HP・MP・¥をその場でお互いに交換できます（1回の合計は既定30まで、HPは0にできません）。

## 神器（カード）の種類

| 種類 | はたらき |
|---|---|
| 武器 | 攻撃に使う。使うとなくなる。捨てられない |
| 強化 | 武器や攻撃の奇跡に **上乗せ** して威力・属性を足す |
| 防具 | 攻撃されたときに選んで受ける。無属性の攻撃を防げるほか、属性相性がある |
| 奇跡 | MPを使って起こす。攻撃・回復・妨害・取引など。**起こした奇跡は手札に残る** |
| 雑貨 | 回復・取引・妨害など。使うとなくなる |

神器は毎回ランダムに授かります（山札は無限）。サーバーにどんな神器があるかは `/gf cards` で一覧を確認できます。

## 属性と相性

神器には属性があり、攻撃を防げるかどうかが変わります。

- **無属性** … どの防具でも防げる。
- **火 → 水の防具だけ / 水 → 火の防具だけ / 木 → 土の防具だけ / 土 → 木の防具だけ** で防げる。
- **光の防具** … 火・水・木・土の防具の代わりになれる（光の攻撃は防げない）。
- **光の攻撃** … 防げない（反射・無効化も効かない）。
- **闇の攻撃** … ふつうに防げるが、**防ぎきれずにダメージを受けるとHPが0になる**。
- 違う属性の神器を一緒に使うと **無属性** になります。

!!! tip "防具の特別な効果"
    **鏡の盾** は攻撃をそのまま相手へ跳ね返し、**身代わり人形** は攻撃を1回まるごと無効にします（どちらも光の攻撃には効きません）。奇跡の **壁** は無属性の武器の攻撃を、**乱気流** は奇跡の攻撃をはじけます。

## 攻撃と防御

- **攻撃する** … 武器（または攻撃の奇跡）を選び、必要なら強化を一緒に選んで、相手を指定します。全体攻撃は敵全員が対象です。％の付いた攻撃は1人ずつ命中判定をします。
- **防御する** … 攻撃されたら制限時間内（既定15秒）に防具を選びます。選んだ防具の守備力の合計が攻撃力を上回れば防ぎきれます。時間切れのときは、その時点で選んでいた防具で受けます。
- **閃光** になっていると、防御に神器を1つしか使えません。

## 奇跡・雑貨でできること

- **回復**（HP・MP・¥を増やす）、**浄化**（災いを消す）
- **妨害** … 相手に病・霧・閃光・夢・暗雲をかける、MPを奪う
- **取引** … 相手の手札を1つ買う、手札を相手に売りつける（足りない¥はHPで払わせる）、質に入れて¥を得る
- **奪う・交換** … ¥を奪う、神器をランダムに盗む・交換する、相手の神器をはじき捨てる
- **復活** … 太陽のお守りを持っていると、HPが0になったとき一度だけ復活する

## 災い（状態異常）

| 災い | 効果 |
|---|---|
| 風邪／熱病／地獄病／天国病 | 病。番の始めにHPが変化し、一定確率で1段階悪化。**天国病が悪化するとHPが0**。病に病を重ねると悪化 |
| 霧 | 相手が見えず、使う相手が無作為になる（数ターンで消える） |
| 閃光 | 防御に神器を1つしか使えない（数ターンで消える） |
| 夢 | 授かる神器が半々の確率で別物に見える（数ターンで消える） |
| 暗雲 | 全体攻撃を必ず受ける（数ターンで消える） |

## 終末の時

既定の **20ラウンド** を過ぎると「終末の時」が訪れ、「捨てる」が **ささげる**（代わりに神器を1つ授かる）に変わります。さらに神器を授かるたびに、**小悪魔・中悪魔・大悪魔**（ダメージ）、**イタズラマン**（手札を盗む）、**めぐみの妖精**（HP・MP・¥のどれかが増える）のどれかが現れることがあります。

## 形式（個人戦・チーム戦・CPU戦）

| 形式 | 識別子 | 内容 |
|---|---|---|
| 個人戦 | `ffa` | 全員が敵。最後の1人が勝ち |
| チーム戦 | `team` | 2〜3チームに分かれて戦う。最後まで残ったチームが勝ち |
| 個人戦（CPU入り） | `ffa-cpu` | 人数が足りないぶんをCPUで補う個人戦 |
| チーム戦（CPU入り） | `team-cpu` | CPUを交えたチーム戦 |

チーム戦は既定で **味方を攻撃できません**。1人で遊ぶときは `ffa-cpu` か `team-cpu` で開始してください。最大ラウンド（既定30）に達すると、HPの多い人（チームは合計HP）の勝ちになります。

## 参加方法

1. ロビーの **参加看板** をクリック、または `/gf join`。
2. 人数がそろったら **開始看板** をクリック、または `/gf start [形式]`（全員可）で開始。形式を省略するとサーバー既定の形式になります。
3. 自分の番になったら、ホットバーの **「手札を開く」本**（右クリック／タップ）または `/gf hand` で画面を開いて行動します。

出場できるのは参加順に最大9人まで。あふれた人はロビーで観戦し、次の試合から出場できます。離脱は **離脱看板** か `/gf leave`（試合中に離脱すると昇天扱い）です。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/gf join` | ロビーに参加する（参加看板と同等） |
| `/gf leave` | ロビーから離脱する（離脱看板と同等。試合中は昇天扱い） |
| `/gf start [ffa\|team\|ffa-cpu\|team-cpu]` | 試合を開始する（開始看板と同等・全員可。省略時は既定の形式） |
| `/gf hand` | 手札・防御の画面を開く（「手札を開く」本と同じ） |
| `/gf status` | 設定・状況を確認する（全員可） |
| `/gf cards` | サーバーにある神器（カード）の一覧を見る |

## よくある質問

??? question "起こした奇跡はなくなりますか？"
    いいえ。奇跡は **MPを払うだけで手札に残り**、MPがある限り何度でも使えます。ただし一度起こした奇跡は、売る・買う・夜空のホウキ（はじき捨て）の対象にはなりません。

??? question "1人でも遊べますか？"
    はい。`ffa-cpu` か `team-cpu` で開始すると、人数が足りないぶんを **CPU** が埋めます。対人戦（`ffa`・`team`）には2人以上が必要です。

??? question "HPが0になったら退場ですか？"
    昇天しますが、**卓に残って観戦** できます。太陽のお守りを持っていれば、HPが0になったとき一度だけ復活します。

??? question "光と闇の攻撃の違いは？"
    光は **防げません**（反射・無効化も効かない）。闇は防具で防げますが、**防ぎきれずにダメージを受けるとHPが0** になります。

??? question "決着がつかないまま長くなったら？"
    最大ラウンド（既定30）に達すると、そのとき **HPの多い人（チームは合計HP）の勝ち** になります。同点なら引き分けです。
