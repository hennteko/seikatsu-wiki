# 大富豪（Daifugo） ― 遊び方 { .page-player #daifugo-player }

テーブルの席について遊ぶトランプの大富豪です。場より強いカードを出していき、手札を先に0枚にした人から上がって階級が決まります。1試合は3ラウンドで、合計点で最終順位を決めます。3〜6人の対人戦とCPU練習を遊べます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 使うカード | トランプ52枚＋ジョーカー（既定1枚） |
    | 強さ | 3 < 4 < 5 < … < K < A < 2 < ジョーカー（マークの差はなし） |
    | 出し方 | 1枚出し / 同じ数字の複数枚出し / 階段（同じマークの連番3枚以上） |
    | 上がり | 手札が0枚になったら上がり。順に大富豪〜大貧民 |
    | ラウンド | 1試合3ラウンド（既定）。合計点で最終順位 |
    | 形式 | 対人戦（normal・3人〜）/ CPU練習（cpu・1人〜） |
    | 参加方法 | 参加看板、または `/dfg join` |
    | 画面を開く | 「手札を開く」の本を右クリック／タップ、または `/dfg hand` |

## 参加・開始・離脱

1. **参加看板** を右クリック（統合版はタップ）でロビーへ。`/dfg join` でも参加できます。
2. **開始看板**（対人戦／CPU練習）を押すと試合が始まります。`/dfg start normal`・`/dfg start cpu` でも開始できます。
3. 抜けるときは **離脱看板** か `/dfg leave`。

- 参加中は名前が「【大富豪】名前」になり、持ち物は預かられます（離脱すると元に戻ります）。
- 1試合に出場できるのは参加順に最大6人。ほかの人はロビーで待って次の試合に出ます。試合中に参加した人は、次の試合から出場します。
- 対人戦は3人から。1〜2人で遊ぶときは **CPU練習** を選んでください。コマンドは `/daifugo` でも同じです。

## 基本ルール

- トランプ52枚とジョーカー（既定1枚）を、全員にできるだけ同じ枚数ずつ配ります。
- カードの強さは **3 < 4 < 5 < … < K < A < 2 < ジョーカー** です（マークによる強さの違いはありません）。
- 出し方は3種類です。
    - **1枚出し**
    - **同じ数字の複数枚出し**（2〜4枚。ジョーカーはどの数字の代わりにもなります）
    - **階段** … 同じマークで数字が続く3枚以上（例：♥5 ♥6 ♥7。ジョーカーで1枚分を埋められます）
- 場にカードがあるときは、**同じ出し方・同じ枚数で、もっと強いカード** だけ出せます。
- 出せない・出したくないときは **パス**。パスした人は、場が流れるまで出せません。
- 自分以外の全員がパスしたら **場が流れ**、最後に出した人が「親」になって好きなカードを出せます（親はパスできません）。最後に出した人がもう上がっていたら、その次の人が親になります。
- 手札が0枚になったら **上がり**。最後に1人残ったらラウンド終了です。
- 最初の親は、1ラウンド目は **♦3を持っている人**、2ラウンド目からは **前のラウンドの大貧民** です。
- **ジョーカー1枚出し** に勝てるのは **♠3の1枚出し** だけです（スペ3返し）。

## ローカルルール

サーバーの設定で ON/OFF が変わることがあります。今の設定は `/dfg status` の「ローカルルール」で確認できます（試合開始時にも表示されます）。

| ルール | 内容 | 既定 |
|---|---|---|
| 革命 | 同じ数字4枚以上（または階段5枚以上）を出すと、強さが逆転（3が一番強く、2が一番弱い）。もう一度起きると元に戻る。ラウンドの終わりまで続く | ON |
| 8切り | 8を含む出し方をすると、その場で場が流れ、出した人がもう一度親になる | ON |
| 縛り | 直前と同じマークのカードが続けて出たら、場が流れるまでそのマークしか出せない（ジョーカーは代わりに使える） | ON |
| 階段 | 同じマークで連続する3枚以上を出せる。K-A-2 はつながるが、A-2-3 はつながらない | ON |
| スペ3返し | ジョーカー1枚出しに♠3の1枚出しで勝てる。勝つと場が流れる | ON |
| 都落ち | 前のラウンドの大富豪が1位で上がれなかったら、その時点で最下位（大貧民）になる | ON |
| 反則上がり | 最後の1手に **ジョーカー・2（革命中は3）・8・スペ3返しの♠3** を使って上がると、最下位になる | ON |
| イレブンバック | J を出すと、場が流れるまで強さが逆転する | OFF |
| 5飛び | 5を出すと、出した枚数だけ次の人を飛ばす | OFF |

- 縛りは、直前の手がジョーカー入りのときは始まりません。

## 階級・カード交換・点数

上がった順に階級がつきます。

| 人数 | 1位 | 2位 | 間 | 最下位の1つ上 | 最下位 |
|---|---|---|---|---|---|
| 3人 | 大富豪 | 平民 | － | － | 大貧民 |
| 4人 | 大富豪 | 富豪 | － | 貧民 | 大貧民 |
| 5〜6人 | 大富豪 | 富豪 | 平民 | 貧民 | 大貧民 |

- **2ラウンド目から、配ったあとにカード交換** があります。
    - 大貧民 → 大富豪：一番強いカード2枚（自動）／大富豪 → 大貧民：好きなカード2枚（自分で選ぶ）
    - 貧民 → 富豪：一番強いカード1枚（自動）／富豪 → 貧民：好きなカード1枚（自分で選ぶ。3人のときは無し）
    - 選ぶ時間は既定30秒です。時間切れのときは一番弱いカードを自動で渡します。
- 1ラウンドごとに点数が入ります：**大富豪5点・富豪4点・平民3点・貧民2点・大貧民1点**（3人のときは5・3・1点）。
- 最後のラウンドが終わったら **合計点** で最終順位が決まります。同点のときは最後のラウンドの順位が上の人が上です。最終順位はサーバー全体に流れます。

## 試合の流れ

- 開始すると自分の **席** に移動します。試合中は席から動けません。
- 席の上の表示・卓の中央の表示・右のサイドバー・上のボスバーで、試合の様子が分かります。
    - **席の上** … 名前・残り枚数（`▶` は今の手番、`パス` はパスした人、上がった人は順位と階級）
    - **卓の中央** … 今の場のカードと、革命中・縛り中などの状態
    - **サイドバー** … 全員の合計点と残り枚数
    - **ボスバー** … ラウンド数・誰の番か・残り時間
- 自分の番になると、**手札の画面** が自動で開きます。
- 手番の制限時間は既定60秒です。時間切れのときは、場があれば **パス**、場が空なら **一番弱いカードを1枚** 自動で出します。

### 手札の開き方

- ホットバーの **「手札を開く」の本** を右クリック（統合版はタップ。届かないときは空中タップでもOK）。
- `/dfg hand` でも開けます。
- 画面を閉じてしまっても、本か `/dfg hand` で開き直せます。自分の番でなくても開いて見られます。

### 画面の見方・出し方

| 場所 | 内容 |
|---|---|
| 1段目 | 今の場のカード（左端は場の説明） |
| 2段目 | 出場者。アイテムの **個数 = 残り枚数**（上がった人は緑の染料で個数 = 順位）。右側は場の状態（革命・縛り）とラウンド・残り時間 |
| 3〜5段目 | 自分の手札（強さ順。並べ替えボタンでマーク順にもできる） |
| 6段目 | 出す・パス・選択を外す・並べ替え・自分の情報 |

1. 出したいカードをタップして選びます（選んだカードは光り、名前の前に ✔ が付きます。もう一度タップで外せます）。
2. 6段目の **「出す」ボタン** に、出せるかどうかが表示されます。
    - **緑** … そのまま出せます（ボタンの名前に出すカードが表示されます）
    - **オレンジ** … 出せません（理由がボタンの名前に表示されます。例：「場は2枚出しです」「♥縛り中です」）
    - **紫** … 出せますが、反則上がりになって最下位になります
3. 出せないときや出したくないときは **「パス」**。

- カード交換のときは、画面のタイトルが「交換」になり、「出す」の代わりに **「渡す」** ボタンになります。渡す枚数ちょうどを選んで押してください。
- カードの **マークはアイテムの色**、**数字はアイテムの個数** です（A=1、J=11、Q=12、K=13）。

| マーク | アイテム |
|---|---|
| ♠ スペード | 黒の染料 |
| ♥ ハート | 赤の染料 |
| ♦ ダイヤ | 青の染料 |
| ♣ クラブ | 緑の染料 |
| ★ ジョーカー | くり抜かれたカボチャ |

## 途中で抜けたとき

- 試合中の leave・切断は **脱落** です。再ログインしても試合には戻れません（持ち物は復元され初期地点へ）。
- 脱落した人は、そのラウンドは **最下位** になり、手札は捨てられます。次のラウンドからは出場しません。
- 上がった後に抜けた場合は、そのラウンドの順位はそのまま残ります。
- 出場者が1人になったとき、新しいラウンドを始めるときに3人未満のとき、CPU練習で人間が全員抜けたときは、その時点で試合が終わります（それまでの合計点で順位を出します）。

## 観戦について

- 上がった人は **席に残ったまま** ラウンドの終わりまで見ます（スペクテイターにはなりません）。手札の画面で場の様子も見られます。
- 試合に出ていない在籍者はロビーで待機します。サイドバーとボスバーで試合の様子が見えます。

## 形式（対人戦・CPU練習）

| 形式 | 識別子 | 内容 |
|---|---|---|
| 対人戦 | `normal` | プレイヤー同士で遊ぶ。3〜6人 |
| CPU練習 | `cpu` | 1人から遊べる。足りない分をCPUで埋める（既定は合計4人） |

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/dfg join` | ロビーに参加する（参加看板と同等・全員可） |
| `/dfg leave` | ロビーから離脱する（離脱看板と同等。試合中は脱落扱い・全員可） |
| `/dfg start [normal\|cpu]` | 試合を開始する（開始看板と同等・全員可。省略時は既定の形式） |
| `/dfg hand` | 手札の画面を開く（「手札を開く」の本と同じ） |
| `/dfg status` | 設定・状況を確認する（全員可。ローカルルールの ON/OFF も表示） |

## よくある質問

??? question "1〜2人でも遊べますか？"
    対人戦（`normal`）は3人からです。1〜2人のときは `cpu`（CPU練習）で開始すると、足りない分をCPUが埋めます（既定は合計4人）。

??? question "手札の画面を閉じてしまいました。"
    ホットバーの「手札を開く」の本を右クリック（タップ）するか、`/dfg hand` で開き直せます。自分の番でなくても開いて場を見られます。

??? question "ジョーカーに勝てるカードはありますか？"
    スペ3返しが ON なら、**♠3の1枚出し** だけがジョーカーの1枚出しに勝てます。勝つと場が流れます。

??? question "統合版でカードの中身が見えにくいです。"
    カードの **マークはアイテムの色、数字はアイテムの個数** で見分けられます。選んだカードは光と名前の前の ✔ で分かり、出せない理由は「出す」ボタンの名前に表示されます。
