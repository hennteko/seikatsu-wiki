# 大富豪（Daifugo） <span class="badge done">公開中</span>

テーブルの席について遊ぶ、おなじみのトランプ **大富豪** です。トランプ52枚＋ジョーカーを配り、場より **強いカードを出していき**、手札を先に0枚にした人から上がって階級が決まります。1試合は **3ラウンド** で、2ラウンド目からはカード交換あり。合計点で優勝が決まります。**革命・8切り・縛り・階段・スペ3返し・都落ち** などのローカルルール入り（OPが ON/OFF 可）。**3〜6人** の対人戦と **CPU練習** を遊べます。

!!! note "ゲームの特徴"
    席につくと手札が配られ、場に出ているカードより **強いカードを出していきます**。出せない・出したくないときは **パス**。全員がパスしたら場が流れ、最後に出した人（親）から再開します。手札が0枚になったら **上がり**。上がった順に大富豪・富豪・平民・貧民・大貧民の階級が付きます。1試合は3ラウンドで、2ラウンド目からは大富豪と大貧民でカード交換があり、合計点で優勝を決めます。革命・8切り・縛り・階段・スペ3返し・都落ち・反則上がりなどのローカルルールをOPが ON/OFF でき、人数が足りないときは **CPU** を入れて練習できます。手札はチェストGUIで操作し、統合版でもカードのマーク（色）と数字（個数）で見分けられます。
