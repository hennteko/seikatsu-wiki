# ステップダンス（StepDance） ― 遊び方 { .page-player #stepdance-player }

座席に座って、壁を流れてくる **4色のノーツ** が一番下の光る判定ラインに来た瞬間に **ホットバーの 1〜4 番** を押すリズムゲームです。タイミングの正確さで点数が入り、曲が終わったときの合計点を競います。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | リズムゲーム（スコアアタック・最大4人） |
    | 操作 | ホットバーの **1・2・3・4 番キー**（レーン＝赤・青・黄緑・黄） |
    | 判定 | PERFECT / GREAT / GOOD / MISS（空押しは減点） |
    | 勝利条件 | 曲が終わったときの合計点が高い人が上位 |
    | 参加方法 | 参加看板、または `/sdance join [識別子]` |
    | 開始 | 開始看板、または `/sdance start [識別子] [曲ID]`（全員可） |
    | 曲 | サーバーに入っている `.nbs` から自動で譜面生成（おまかせ選択も可） |

## どんなゲーム？

参加すると **ロビー** に入り、開始すると空いている **ブース（座席）** に座ります。目の前の壁を、上から **4本のレーン**（左から 赤・青・黄緑・黄）のノーツが流れてきます。ノーツが一番下の **判定ライン**（光っている列）に重なった瞬間に、そのレーンに対応する **ホットバー 1〜4 番** を押します。タイミングのずれが小さいほど高い判定・高い点数になります。

- ブースは最大 **4つ**。参加者が多いときは参加順に入り、入れなかった人は **次の曲** から（遊んだ人は列の後ろへ回ります）。
- 曲が終わると **点数ランキング** と判定の内訳が表示されます。

## 操作（1〜4キー）

!!! tip "基本はホットバーのキーを押すだけ"
    座ると、ホットバーに **レーンのアイテム（1〜4 番）** と **待機（9 番）** が配られ、最初は 9 番が選ばれています。ノーツが判定ラインに来たら、押したいレーンの **番号キーを押す** だけです。押すとすぐ 9 番（待機）へ自動で戻るので、**同じレーンを続けて** 押せます。

| キー | レーン | 色 |
|---|---|---|
| `1` | 1レーン | 赤 |
| `2` | 2レーン | 青 |
| `3` | 3レーン | 黄緑 |
| `4` | 4レーン | 黄 |
| `9` | 待機 | 押したあとに自動で戻る枠 |

- マウスホイールでスロットを変えても入力になりますが、**番号キーで押すほうが確実** です。
- 統合版（スマホ・スイッチなど）でもホットバーの番号選択で同じように遊べます。

## 判定と点数

ノーツが判定ラインに重なるタイミングにどれだけ近いかで判定が決まります（1tick = 0.05秒）。

| 判定 | タイミングのずれ（既定） | 点数（既定） |
|---|---|---|
| PERFECT | ±1tick 以内 | 100点 |
| GREAT | ±2tick 以内 | 70点 |
| GOOD | ±3tick 以内 | 40点 |
| MISS | ±3tick を過ぎても押さなかった | 0点 |

- 判定が出ると、画面下（アクションバー）に判定・コンボ数と、`FAST`（早押し）／`SLOW`（遅押し）の目安が出ます。
- **空押し**（判定の範囲にノーツが無いのに押した）をすると、1回ごとに点が引かれます（既定 −20点）。連打で稼げない仕組みです。

!!! note "通信の遅れは自動で補正されます"
    入力は ping（往復の通信時間）の分だけ早めて判定されるため、多少 ping が大きくても不利になりにくいようになっています（既定で上限6tick）。ping の大きい参加者がいるときは、同じレーンの連打が詰まりすぎないよう、その曲だけ譜面の間隔が自動で少し広がることがあります。

## 譜面と難易度

- 曲は `.nbs`（Note Block Studio の曲）から、**音の高さでレーン分け** して自動で譜面が作られます。曲ごとに同じ譜面になります。
- 難易度は **EASY / NORMAL / HARD** の3段階で、難しいほどノーツが詰まります（最小間隔が狭くなります）。どの難易度で遊ぶかはサーバー側の設定で決まります。
- 開始時に曲を選べます（`/sdance start [識別子] [曲ID]`）。曲を指定しなければ **おまかせ（ランダム）** です。入っている曲は `/sdance songs` で確認できます。

## 結果の見方

曲が終わると、順位・点数と判定の内訳（PERFECT / GREAT / GOOD / MISS の数と最大コンボ）が表示されます。

- **FULL COMBO** … 一度も MISS せずに最後まで叩けた。
- **ALL PERFECT** … すべてのノーツが PERFECT。

結果を少し表示したあと、自動でロビーへ戻ります。続けて次の曲を遊べます。

## 参加・離脱

1. ロビーの **参加看板** をクリック、または `/sdance join [識別子]`（アリーナが1つなら識別子は省略可）。
2. **開始看板** のクリック、または `/sdance start`（全員可）で開始。カウントダウンのあと曲が始まります。
3. 離脱は **離脱看板** か `/sdance leave`。

曲の途中で離脱・切断すると、その曲は脱落（順位から除外）になります。ロビーに入るとき元の持ち物は安全に預かられ、離脱すると元どおり戻ります。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/sdance join [識別子]` | ロビーに参加する（参加看板と同等・全員可） |
| `/sdance leave` | ロビーから離脱する（離脱看板と同等・全員可） |
| `/sdance start [識別子] [曲ID]` | 曲を開始する（開始看板と同等・全員可） |
| `/sdance status` | 現在の設定・状況を確認する（全員可・読み取り専用） |
| `/sdance songs` | 入っている曲の一覧を見る（全員可） |

!!! note "コマンドの別名"
    メインコマンドは `/stepdance` ですが、短い `/sdance` でも同じように使えます。

## よくある質問

??? question "どのキーを押せばいいですか？"
    壁のノーツと同じ色のレーンの **番号キー（1〜4）** を、ノーツが一番下の光る判定ラインに重なった瞬間に押します。押すと自動で9番（待機）に戻るので、同じレーンも続けて押せます。

??? question "自分で用意した道具は使えますか？"
    いいえ。曲中の手持ちは配られたレーンのアイテムと待機アイテムだけです。ロビーに入った時点で元の持ち物は安全に預かられ、離脱すると元どおり戻ります。

??? question "1人でも遊べますか？"
    はい。1人でもスコアアタックとして遊べます（サーバーの設定で最低人数が1人のとき）。

??? question "連打すれば点が稼げますか？"
    いいえ。ノーツが無いのに押す「空押し」は1回ごとに減点されます。きちんとタイミングを合わせて押しましょう。

??? question "難易度や曲は自分で選べますか？"
    曲は開始時に選べます（指定しなければおまかせ）。難易度はサーバー側の設定で決まります。
