# Zinro <span class="badge done">公開中</span>

Minecraft上で本格的な **人狼ゲーム** が遊べるミニゲームプラグインです。昼夜のサイクルの中で議論・投票・特殊能力を駆使し、人狼陣営と村人陣営、そして第三陣営が勝利を争います。

!!! note "ゲームの特徴"
    昼は議論と投票、夜はPvPと特殊能力でプレイする昼夜サイクル制の人狼ゲームです。2〜20人に対応し、人数に応じて役職が自動で割り振られます。参加・退出はゲート看板のクリックで行い、占いは専用の看板に占いアイテムを使って判定します。
