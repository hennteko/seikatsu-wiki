# Zinro ― 遊び方 { .page-player #zinro-player }

Minecraft上で人狼ゲームを遊ぶミニゲームです。昼は議論と投票で人狼を探し、夜は襲撃や特殊能力で動きます。自分の陣営の勝利条件を満たすことを目指しましょう。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 2〜20人（2・3人はテスト用、推奨は7〜10人） |
    | 1試合の長さ | 昼夜サイクル制（昼・夜とも既定60秒） |
    | 勝利条件 | 役職の陣営ごとに異なる（下記参照） |
    | 参加方法 | ロビーの **ゲート看板** をクリック |

## どんなゲーム？

参加者にはゲーム開始時に役職が割り振られます。役職は **村人陣営 / 人狼陣営 / 第三陣営** に分かれ、それぞれ勝利条件が異なります。

ゲームは **昼** と **夜** が交互に繰り返される昼夜サイクル制です。

- **昼（既定60秒）** — 議論と投票の時間。PvPは **無効**。投票で追放者を決めます。
- **夜（既定60秒）** — PvPが **有効** になり、人狼の襲撃や各役職の特殊能力が使えます。10秒ごとに「エメラルドの番人」（スケルトン）が出現します。

## 参加と退出

参加・退出は **ゲート看板** を右クリックして行います。`/zinro join` のようなコマンドでは参加できません。

- **参加用看板** … `[Zinro]` / `lobby` と書かれた看板。右クリックでロビーに参加します。
- **退出用看板** … `[Zinro]` / `退出` と書かれた看板。右クリックでロビーから退出します。

!!! note "テレポートについて"
    ゲート看板で参加すると、参加直前の位置が保存されロビーへテレポートされます。ゲーム中に退出した場合は参加前の位置に戻り、サバイバルモードに戻ります。ゲーム中に死亡したプレイヤーはロビーに移動し、観戦（スペクテイター）になります。

## ゲームの流れ

1. **参加する** — ロビーのゲート看板をクリックしてロビーに加わります。
2. **開始を待つ** — 管理者がゲームを開始するのを待ちます（最低2人必要）。
3. **役職が割り振られる** — 人数に応じて各プレイヤーへ役職が自動で配られます。役職と陣営はチャットに表示されます。
4. **フィールドへ移動** — 全員がゲームフィールドにテレポートされます。
5. **昼（議論・投票）** — 配られる **投票用紙** を右クリックして投票GUIを開き、追放したい人へ投票します。
6. **夜（行動）** — PvPが有効になり、人狼の襲撃や特殊能力を使います。スケルトンを倒してエメラルドを稼ぎます。
7. **繰り返し** — 勝利条件が満たされるまで昼夜を繰り返します。
8. **ゲーム終了** — 勝敗が決まると約10秒後に全員がロビーへ戻ります。

## 役職とルール

人数に応じて登場する役職が変わります（下の配役表を参照）。

=== "村人陣営"

    | 役職 | 能力 |
    |---|---|
    | 村人 | 特殊能力はありません。推理で人狼を見つけ出しましょう。 |
    | 狼付き | 占われると「人狼」と判定されますが、中身は人間（村人陣営）です。 |

    占いの心・騎士の加護・霊媒の遺灰などのショップアイテムを使えば、村人でも占い・守り・霊媒の役割を担えます。

=== "人狼陣営"

    | 役職 | 能力 |
    |---|---|
    | 人狼 | 夜に他のプレイヤーを襲撃できます。専用武器「人狼の斧」を購入可能。複数いる場合は仲間を認識できます。 |
    | 狂人 | 人狼の勝利が自身の勝利になります。占いでは「村人」と判定されます。「共犯者の目」で人狼を知れます。 |

=== "第三陣営"

    | 役職 | 能力 |
    |---|---|
    | 吸血鬼 | 最後まで生き残ることで勝利します。十字架でのみ討伐されます。 |
    | キューピット | ゲーム開始時に2人を恋人にします。選んだ2人が生き残れば勝利します。 |

!!! info "勝利条件"
    - **村人陣営** … 人狼をすべて追放・討伐する。
    - **人狼陣営** … 村人陣営の人数を上回る（村人を全滅させる）。
    - **吸血鬼** … 最後まで生き残る。
    - **キューピットの恋人** … 選ばれた恋人2人が生き残る。

## 投票のしくみ

昼の時間に **投票用紙**（紙アイテム）を右クリックすると投票GUIが開きます。

- 生存者の頭（スカル）が並ぶので、追放したい人をクリックして投票します。
- 昼の間は何度でも投票先を変更できます。
- **生存者の半数を超える票** が同じ1人に集まった場合のみ、その人が追放されます。
  - 例: 生存10人なら6票以上、生存5人なら3票以上で追放。
- 過半数の票を得た人がいない場合は「追放なし」となります。

## エメラルドの稼ぎ方

エメラルドはショップでアイテムを買うための通貨です。

- **夜の時間** に10秒ごとに「エメラルドの番人」（スケルトン）が、生存者数と同じ数だけ出現します。
- 番人を倒すと **1体につきエメラルド1個** を獲得できます。

## ショップ（`/zinro shop`）

ゲーム中に `/zinro shop` でショップGUIを開けます（ロビー状態では使えません）。配られる **ショップの杖** を右クリックしても開けます。

| アイテム | 価格 | 効果 |
|---|---|---|
| 人狼の斧 | 3E | 人狼専用。一撃でプレイヤーを倒す。使用後消滅。 |
| 共犯者の目 | 3E | 狂人専用。夜間に使用し、ランダムな人狼を1人知る。 |
| ステーキ | 1E | 食料（10個セット）。 |
| 狩人の弓 | 2E | 特殊な矢とセットで使用。一度撃つと壊れる。 |
| 特殊な矢 | 2E | 狩人の弓専用の矢。 |
| スタングレネード | 3E | 命中した相手を盲目＋鈍足にする（3秒）。雪玉のように投げる。 |
| 透明ポーション | 4E | 透明化（20秒）。 |
| 占いの心 | 6E | 占い看板に使うと、その看板のプレイヤーの役職を特定できる。 |
| 騎士の加護 | 3E | 占い看板に使用。人狼の斧／弓矢の攻撃を1回防ぐ。 |
| 霊媒の遺灰 | 3E | 死亡したプレイヤーの役職を確認できる。 |
| 呪符 | 2E | 自分が占いの心で占われたかどうかを確認できる。 |
| 十字架 | 2E | 吸血鬼のみを討伐できる。使用後消滅。 |

!!! tip "占いアイテムの使い方"
    占いの心・騎士の加護は、設置された **占い看板** に向かって右クリックして使います。看板にはゲーム開始時に各プレイヤーの名前が割り当てられています。占いの心は夜間のみ・基本的に1夜1回までの使用が想定されています。

!!! info "占いの判定結果"
    占いの心で役職を調べると、次のように表示されます。

    - **狂人** → 「村人」と表示（偽装される）
    - **狼付き** → 「人狼」と表示（誤判定される）
    - その他 → 正しい役職が表示される

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/zinro` | コマンドのヘルプを表示 |
| `/zinro shop` | ショップを開く（ゲーム中のみ） |

!!! note "参加・投票はコマンドではありません"
    参加・退出は **ゲート看板** のクリック、投票は **投票用紙** のGUIで行います。`/zinro join` や `/zinro vote` といったコマンドはありません。

## よくある質問

??? question "どうやってゲームに参加しますか？"
    ロビーにある参加用のゲート看板（`[Zinro]` / `lobby`）を右クリックします。コマンドでの参加はできません。

??? question "投票はどうやってしますか？"
    昼の時間に、配られる投票用紙（紙）を右クリックすると投票GUIが開きます。追放したい人をクリックしてください。

??? question "ショップが開けません"
    ショップはゲーム進行中（昼・夜）のみ利用できます。ロビーで待機中は開けません。`/zinro shop` か、配られるショップの杖を右クリックしてください。

??? question "エメラルドが貯まりません"
    エメラルドは夜の時間に出現する「エメラルドの番人」（スケルトン）を倒すと手に入ります。昼の間は出現しません。

??? question "ゲーム中に抜けるとどうなりますか？"
    ゲーム中に退出看板を使うと、参加前の位置に戻りサバイバルモードになります。途中退出は脱落扱いになります。
