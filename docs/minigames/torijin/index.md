# 鳥人間コンテスト（ToriJin） <span class="badge done">公開中</span>

**2人1組で挑む打ち上げ飛距離ゲーム** です。片方が「打ち担当」、もう片方がエリトラを着た「受け担当」になり、ストライクゾーンで滑空する受け担当を打ち担当がバットで叩いて打ち出します。遠くまで飛ぶほど高記録。ペアで既定3回挑戦し、いちばん遠い飛距離がランキングに残ります。

!!! note "ゲームの特徴"
    受け担当はエリトラを着てストライクゾーンで上を向いて滑空し、打ち担当はタイミングよくバットで叩きます。有効な打撃が通ると、受け担当がバニラのノックバックで一気に打ち出され、着地点までの **飛距離** が記録されます。ペアで既定3回挑戦し、横ずれが大きいとファウル、コース後方・壁への衝突・空振りは記録なし。コースの端（既定5000m）まで届くと「場外」です。打ち担当・受け担当それぞれ **列に並んで** 順番を待ち、先頭どうしがペアになって挑戦する仕組みで、1アリーナ同時1ペアです。
