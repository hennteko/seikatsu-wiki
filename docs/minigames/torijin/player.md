# 鳥人間コンテスト ― 遊び方 { .page-player #torijin-player }

2人1組で挑む打ち上げ飛距離ゲームです。エリトラを着た受け担当がストライクゾーンで滑空し、打ち担当がバットで叩いて打ち出します。できるだけ遠くへ飛ばしましょう。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | 2人1組のペア（協力プレイ） |
    | 役割 | 打ち担当（バットで叩く）／受け担当（エリトラで飛ぶ） |
    | 目標 | できるだけ遠くへ飛ぶ。ペアの最高飛距離がランキングに残る |
    | 挑戦回数 | 1ペア 既定3回 |
    | 並び方 | 役職ごとの列に並び、打ち・受けの先頭どうしがペアになる |
    | 参加方法 | 参加看板、または `/tori join [アリーナ]` → `/tori role <uchi\|uke>` |
    | 記録 | ペアの飛距離ランキング（`/tori top`） |

## どんなゲーム？

受け担当は **エリトラ** を着て、ストライクゾーンの中で **上を向いて滑空** します。打ち担当は立ち位置から **バット** でタイミングよく叩きます。有効な打撃が通ると、受け担当が勢いよく打ち出され、着地点までの **飛距離** が決まります。遠ければ遠いほど高記録です。

役職は **打ち担当（uchi）** と **受け担当（uke）** の2つ。それぞれ列に並んで順番を待ち、**両方の列の先頭どうしがペア** になって挑戦します。1つのアリーナで同時に挑戦するのは1ペアだけです。

## 役職と列

1. 参加後に `/tori role uchi`（打ち担当）か `/tori role uke`（受け担当）、または **役職看板** で列に並びます。
2. 両方の列に1人以上そろうと、先頭どうしが呼ばれてペアになります。
3. ペアで既定3回挑戦したら、2人ともロビーへ戻ります（在籍は続くので、もう一度列に並べます）。
4. 役職をやめて列から外れるには `/tori role none`。

!!! tip "swap-roles（役割交代）"
    サーバー設定で「役割交代」がオンのときは、偶数回ごとに打ち担当と受け担当が入れ替わります。オフなら最初に選んだ役職のまま3回挑戦します。

## 1回の流れ

各回は次の順で進みます。

1. **カウントダウン（既定3秒）** … 打ち担当は立ち位置、受け担当は開始位置に着きます。
2. **GO！（打撃待ち）** … 受け担当はストライクゾーンへ入って **上を向いて滑空** し、打ち担当は **バットで叩き** ます。既定では、受付時間（既定30秒）の間ならいつでも打てます。
3. **HIT！（飛行中）** … 有効な打撃が通ると受け担当が打ち出されます。ボスバーに飛距離と横ずれが表示されます。
4. **結果** … 着地すると飛距離が判定され、タイトルで表示されます。少し待って次の回へ進みます。

受付時間内に有効な打撃がないと **空振り（記録なし）** になります。

## 打撃のコツ

- **受け担当** … GO のあとストライクゾーンへ入り、**上を向いて（ピッチを上げて）滑空** します。ゾーンから大きく離れると開始位置へ戻されます。
- **打ち担当** … 立ち位置から離れられません（離れると戻されます）。受け担当がゾーンで滑空しているタイミングで **バットで叩き** ます。狙う向きがコースに対してどれだけずれているかがアクションバーに表示されるので、まっすぐを狙いましょう。
- 無効な打撃（まだ打てない・空振り条件など）のときは「✖」と理由が表示され、打ち出されません。

!!! note "打ち出しの向きと飛距離"
    受け担当は、打ち担当が向いていた方向へ打ち出されます（1人テストはコース方向へまっすぐ）。コースに対して狙いがずれていると横に流れ、横ずれが大きいとファウルになります。仰角（打ち出しの角度）と初速も結果に表示されます。

## 飛距離の判定

着地した地点で、次のように判定されます。

| 判定 | 内容 |
|---|---|
| 記録 | コース内に正しく着地（飛距離が記録される） |
| 場外 | コースの端（既定5000m）まで届いた |
| ファウル | 横ずれが大きすぎた（記録なし） |
| 記録なし（後方） | コースの後ろ側に着地した |
| 記録なし（衝突） | 飛行中に壁などへぶつかった |
| 空振り | 受付時間内に有効な打撃がなかった |

横ずれが警告ライン（既定15m）を超えると、音とアクションバーで知らせます。着地点にはしばらくパーティクルの柱が立ちます。水・溶岩に落ちた場合や、はしご・つるに引っかかって一定時間（既定120秒）飛び続けた場合も、そのときの位置で判定されます。

## 記録とランキング

- ペアが出した **いちばん遠い飛距離** がランキングに残ります。
- ランキング入り・自己ベスト更新はサーバー全体に告知されます。
- `/tori top [アリーナ]` で、そのアリーナのランキングを確認できます（打ち担当・受け担当の名前と飛距離・場外表示付き）。
- ロビーの **ランキング看板** でも上位を確認できます。
- 受け担当が統合版のときは記録に印（既定「[統]」）が付きます。

## 参加方法

1. **参加看板** をクリック、または `/tori join [アリーナ]`。ロビーへ移動し、元の持ち物は安全に預かられます。
2. **役職看板**、または `/tori role uchi` / `/tori role uke` で列に並びます。
3. 両方の列がそろうと自動でペアになって挑戦が始まります（**開始看板** や `/tori start` で進行を開始している必要があります）。
4. 離脱は **離脱看板** か `/tori leave`。挑戦中に離脱すると、その回は無効になり、相方は列の先頭に戻ります。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/tori join [アリーナ]` | ロビーに参加する（参加看板と同等・全員可） |
| `/tori leave` | ロビーから離脱する（離脱看板と同等・全員可） |
| `/tori role <uchi\|uke\|none>` | 役職の列に並ぶ／外れる |
| `/tori start [アリーナ]` | 進行を開始する（開始看板と同等・全員可） |
| `/tori status` | 現在の設定・状況を確認する（全員可・読み取り専用） |
| `/tori top [アリーナ]` | ランキングを見る |

!!! note "別名コマンド"
    `/tori` は `/torijin` でも実行できます。

## よくある質問

??? question "1人でも遊べますか？"
    通常の記録は2人1組です。1人で試したい場合はOPの `/tori test` による1人テスト（記録なし）があります。遊ぶときは打ち担当・受け担当がそろう必要があります。

??? question "なかなか打ち出されません。"
    受け担当は、ストライクゾーンの中で、少し高さを取りつつ上を向いて滑空しているか確認してください。打ち担当は専用のバットを持ち、受付時間（既定30秒）の間に叩きます。条件を満たさない打撃は「✖」と理由が出て無効になります。

??? question "まっすぐ飛ばすには？"
    打ち担当の向きがそのまま打ち出す方向になります。狙いがコースに対してずれていると横に流れてファウルになりやすいので、アクションバーの「狙い」表示が「まっすぐ」に近づくように向きを合わせてください。

??? question "自分で用意した装備は使えますか？"
    いいえ。ロビーに入った時点で元の持ち物は安全に預かられ、挑戦中の装備は配られたバット・エリトラだけです。離脱すると元どおり戻ります。
