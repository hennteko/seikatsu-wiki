# オセロ（Othello） ― 遊び方 { .page-player #othello-player }

ブロックで作られた実物大のオセロ盤で対局します。マスをクリックして石を置き、相手の石をはさんでひっくり返しながら、盤面の石を多くした方が勝ちです。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | 対人戦（1対1・勝ち残り）／CPU戦（3段階） |
    | 1手の制限時間 | 既定30秒（時間切れはランダム着手または負け・運営設定） |
    | 石の置き方 | 盤を見て置きたいマスをクリック（既定32ブロック以内） |
    | 参加方法 | `[Othello]` 参加看板、または `/othello join`（`/oth join`） |

## 遊び方

1. ロビーの参加看板か `/othello join` で参加します（出場者以外は観戦）。
2. 対局が始まると、黒（先手）・白（後手）に分かれて盤の前に立ちます。
3. 自分の手番になったら、**置けるマス（自分にだけ緑の粒で表示）** を見て、そのマスを **クリック** します。
4. はさんだ相手の石が自動でめくれます。直前に置かれた石は光ります。
5. 置ける場所が無い手番はパスになります。両者とも置けなくなったら終局です。
6. 盤上の石が **多い方が勝ち**。同数なら引き分けです。

!!! tip "操作のコツ"
    石は盤に触れなくても、**離れた位置（既定32ブロック以内）からマスをクリック** すれば置けます。緑の粒が出ているマスが合法手です。制限時間（既定30秒）に注意しましょう。

## 対戦モード

開始時にモードを選びます（開始看板またはコマンド）。

| モード | 内容 |
|---|---|
| 対人戦（classic） | プレイヤー同士の1対1。**勝者は次の対局にも続けて出場**（勝ち残り） |
| CPU戦・かんたん（cpu-easy） | 弱いCPUと対局 |
| CPU戦・ふつう（cpu-normal） | 標準的なCPUと対局 |
| CPU戦・むずかしい（cpu-hard） | 強いCPUと対局 |

## 勝敗と成績

終局時に石が多い方の勝ちです。**投了**（`/othello resign`）すると負けになります。勝利数などの成績はランキングに記録され、`/othello top`（ランキング）・`/othello stats`（自分の成績）で確認できます。

## 参加方法

1. `[Othello]` 参加看板をクリック、または `/othello join`。
2. 開始看板のクリックまたは `/othello start <classic|cpu-easy|cpu-normal|cpu-hard>`（全員可）で対局開始。
3. ロビーが混んでいるときは、出場者以外は観戦になります（対人戦は勝ち残り式で順に出場）。

離脱は `/othello leave` です。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/othello join` | ロビーに参加する（参加看板と同等・全員可） |
| `/othello leave` | ロビーから離脱する（全員可） |
| `/othello start <classic\|cpu-easy\|cpu-normal\|cpu-hard>` | 対局を開始する（開始看板と同等・全員可） |
| `/othello resign` | 投了する（負け） |
| `/othello status` | 現在の設定・状況を確認する（全員可） |
| `/othello top` | 勝利数などのランキングを表示 |
| `/othello stats` | 自分の成績を表示 |

!!! note "コマンドの短縮形"
    `/othello` は `/oth` と短縮できます。

## よくある質問

??? question "石はどうやって置くの？"
    自分の手番のとき、置けるマス（緑の粒が表示される合法手）を見てクリックします。盤に乗る必要はなく、少し離れた位置（既定32ブロック以内）からでも置けます。

??? question "置ける場所が無いときは？"
    その手番はパスになり、相手の番になります。両者とも置けなくなったら終局です。

??? question "CPUと1人で遊べますか？"
    はい。開始時に `cpu-easy` / `cpu-normal` / `cpu-hard` を選ぶとCPUと対局できます。

??? question "対人戦で自分の番が来ません"
    対人戦は勝ち残り式です。すでに対局中の場合は、空くまで待つか観戦になります（運営の設定によります）。
