# オセロ（Othello） ― 遊び方 { .page-player #othello-player }

ブロックで作られた実物大のオセロ盤で対局します。マスをクリックして石を置き、相手の石をはさんでひっくり返しながら、盤面の石を多くした方が勝ちです。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | 対人戦（1対1・勝ち残り）／**ソロ：CPU段位戦**（1人・8段階を勝ち抜き） |
    | 1手の制限時間 | 既定30秒（時間切れはランダム着手または負け・運営設定） |
    | 石の置き方 | 盤を見て置きたいマスをクリック（既定32ブロック以内） |
    | 参加方法 | 対人戦：参加看板／`/othello join`　ソロ：ソロ看板／`/othello solo`（`/oth` でも可） |

## 遊び方

1. ロビーの参加看板か `/othello join` で参加します（出場者以外は観戦）。
2. 対局が始まると、黒（先手）・白（後手）に分かれて盤の前に立ちます。
3. 自分の手番になったら、**置けるマス（自分にだけ緑の粒で表示）** を見て、そのマスを **クリック** します。
4. はさんだ相手の石が自動でめくれます。直前に置かれた石は光ります。
5. 置ける場所が無い手番はパスになります。両者とも置けなくなったら終局です。
6. 盤上の石が **多い方が勝ち**。同数なら引き分けです。

!!! tip "操作のコツ"
    石は盤に触れなくても、**離れた位置（既定32ブロック以内）からマスをクリック** すれば置けます。緑の粒が出ているマスが合法手です。制限時間（既定30秒）に注意しましょう。

## 対戦モード

| モード | 内容 |
|---|---|
| 対人戦（classic） | プレイヤー同士の1対1。**勝者は次の対局にも続けて出場**（勝ち残り） |
| ソロ：CPU段位戦 | 1人で CPU と対局。**5級から順に勝ち抜き**、何段まで行けるかを競う（下の章） |
| ソロ：練習1局 | 好きな段位の CPU と1局だけ（段位戦の記録には残らない） |

!!! note "今までの CPU戦（cpu-easy / cpu-normal / cpu-hard）"
    CPU の開始看板・`/othello start cpu-○○` は、押した人の **練習1局** になりました（ロビーに入っていなくても始められます）。
    強さは今までと同じで、それぞれ **5級・4級・1級** の CPU です。

## CPU段位戦（ソロモード）

**CPU に何段まで勝ち抜けるか** を競うモードです。

1. **ソロ看板** をクリック、または `/othello solo` → ロビーに入り、**ソロメニュー** が開きます。
2. ソロメニューの **「段位戦スタート」** を押すと、5級の CPU との対局が始まります。
3. 勝ったら、ロビーに戻って数秒後にソロメニューが開きます。**「次の対局」** を押すと1段上の CPU と対局します。
4. **負けたら挑戦終了**（引き分け・投了・時間切れの負けも同じ）。1回の挑戦で突破した一番上の段位が **あなたの段位** になります。
5. 三段まで突破すると **完全制覇** です。

- 途中でやめたいときは、ソロメニューの **「ここでやめる」**。そこまで突破した段位で記録されます。
- メニューを閉じてもロビーにいるままです。ホットバーの **ネザースター（ソロメニュー）** を右クリック／タップで開き直せます。
- 盤面は対人戦と共用です。だれかが対局中は始められません（空くとメニューのボタンが戻ります）。

### 段位と CPU の強さ

| 段位 | CPU の強さ |
|---|---|
| 5級 | 置ける場所からランダム（角は半分くらいの確率で取る） |
| 4級 | 1手先だけを見る |
| 3級 | 2手先まで読む（ときどきミスをする） |
| 2級 | 3手先まで読む |
| 1級 | 5手先まで読む（今までの「むずかしい」と同じ） |
| 初段 | 4手先まで読み、盤面の見方が上手になる。終盤は最後まで読み切る |
| 二段 | 5手先まで読む（上手な見方）。終盤の読み切りが早い |
| 三段 | 6手先まで読む（上手な見方）。終盤の読み切りがさらに早い |

上の段位ほど強くなります（となりの段位どうしで対局させて、上の段位が7割くらい勝つように調整しています）。

### 結果の扱い

| 状況 | 段位戦 |
|---|---|
| 勝ち | その段位を突破 → 次の段位へ |
| 負け・引き分け・投了・時間切れの負け | 挑戦終了。突破した段位で記録 |
| 対局中に `/othello leave`・切断 | その対局は負け。突破した段位で記録 |
| 対局の合間にロビーを出る・切断 | 突破した段位で記録 |
| OP が対局を止めた（`/othello stop`） | その対局は無かったことになり、**同じ段位からやり直せる** |

- 5級で負けたときは「段位なし」です（挑戦回数だけ数えます）。
- 同じ段位の人どうしは、**突破した対局の石差の合計 → 対局時間の短さ** で順位が決まります。
- 挑戦が終わると、サーバー全体に結果が流れます（1段も突破できなかったときは流れません）。

### 練習1局

ソロメニューの下の段に段位が並んでいます。**自分の段位の1つ上まで** を選んで1局だけ対局できます（段位戦の記録には残りません。段位ごとの勝敗には数えます）。段位戦の挑戦中は練習できません。

### ソロメニュー

| ボタン | 内容 |
|---|---|
| ダイヤの剣 | 段位戦スタート／次の対局 |
| 赤いベッド | ここでやめる（挑戦中だけ） |
| 下の段のブロック | 練習：その段位と1局（灰色はまだ選べない段位） |
| 本 | ルール |
| 紙 | 前回の結果 |
| 金ブロック | ランキング上位5人と自分の順位 |
| ガラス板 | 盤面の状況（空き／使用中） |
| プレイヤーの頭 | あなたの段位と段位ごとの勝敗 |
| ドア | ロビー退出（持ち物が戻ります） |

!!! info "統合版（スマホ・Switch など）で遊ぶとき"
    - ソロメニューはチェストの画面で表示され、タップで操作できます。
    - ネザースターを持って **空中をタップ** するか、**持ってスニーク** してもメニューが開きます。
    - ランキングでは統合版で出した記録に `[BE]` の印が付きます（記録は Java 版と同じランキングです）。

## 勝敗と成績

終局時に石が多い方の勝ちです。**投了**（`/othello resign`）すると負けになります。対人戦の勝利数は `/othello top`、CPU段位戦のランキングは `/othello ranking dan` で確認できます。`/othello stats` では自分の成績（対人戦・段位・段位ごとの勝敗）を表示します。

## 参加方法

1. `[Othello]` 参加看板をクリック、または `/othello join`。
2. 開始看板のクリックまたは `/othello start classic`（全員可）で対人戦を開始。
   1人で遊ぶときは、ソロ看板か `/othello solo` で CPU段位戦へ。
3. ロビーが混んでいるときは、出場者以外は観戦になります（対人戦は勝ち残り式で順に出場）。

離脱は `/othello leave` です。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/othello join` | ロビーに参加する（参加看板と同等・全員可） |
| `/othello leave` | ロビーから離脱する（全員可） |
| `/othello start classic` | 対人戦を開始する（開始看板と同等・全員可） |
| `/othello start <cpu-easy\|cpu-normal\|cpu-hard>` | CPU と練習1局（5級／4級／1級） |
| `/othello solo` | ソロ（CPU段位戦）で参加してソロメニューを開く |
| `/othello solo dan` | メニューを通さずに段位戦を始める（挑戦中なら次の対局） |
| `/othello solo <段位>` | メニューを通さずに練習1局（例：`/othello solo kyu3`） |
| `/othello ranking dan` | CPU段位戦のランキングと自分の記録 |
| `/othello resign` | 投了する（負け） |
| `/othello status` | 現在の設定・状況を確認する（全員可） |
| `/othello top` | 勝利数などのランキングを表示 |
| `/othello stats` | 自分の成績を表示 |

!!! note "コマンドの短縮形"
    `/othello` は `/oth` と短縮できます。

## よくある質問

??? question "石はどうやって置くの？"
    自分の手番のとき、置けるマス（緑の粒が表示される合法手）を見てクリックします。盤に乗る必要はなく、少し離れた位置（既定32ブロック以内）からでも置けます。

??? question "置ける場所が無いときは？"
    その手番はパスになり、相手の番になります。両者とも置けなくなったら終局です。

??? question "CPUと1人で遊べますか？"
    はい。ソロ看板か `/othello solo` で **CPU段位戦** が遊べます。5級から順に勝ち抜いて、自分の段位を上げていきましょう。1局だけ遊びたいときは、ソロメニューの「練習」から段位を選べます。

??? question "段位戦の途中でやめたら記録はどうなる？"
    そこまで突破した段位で記録されます。対局中にロビーを出たり切断したりした場合は、その対局は負けになります。

??? question "ソロ在籍から対人戦に戻るには？"
    参加看板か `/othello join` を使うと、通常の在籍（対人戦に出場する側）に切り替わります。段位戦の挑戦中なら、そこまでで記録されます。

??? question "対人戦で自分の番が来ません"
    対人戦は勝ち残り式です。すでに対局中の場合は、空くまで待つか観戦になります（運営の設定によります）。
