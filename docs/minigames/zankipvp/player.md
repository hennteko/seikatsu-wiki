# Zankipvp ― 遊び方 { .page-player #zankipvp-player }

残機（ライフ）制のチームPvPミニゲームです。チームに分かれて戦い、残機を使い切るまで何度でも復活します。最後まで残ったチームが勝ちです。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 2〜16人（既定。OPの設定で変更されることがあります） |
    | チーム | 赤・青・黄・緑の最大4チーム |
    | 初期残機 | 3（既定。OPの設定で変更されることがあります） |
    | 勝利条件 | 生き残っているチームが自分たちだけになる |
    | リスポーン | あり（残機がある限り、死亡から約5秒後に自動復活） |

## どんなゲーム？

参加者は赤・青・黄・緑の4チームに振り分けられ、それぞれのスポーン地点から戦います。倒されると **残機が1減り**、残機が残っていれば数秒後に自動でリスポーンします。

残機を使い切ったプレイヤーは **脱落** し、観戦モードでゲームを見守ります。チームのメンバー全員が脱落すると、そのチームは敗退です。最後に生き残ったチームが勝利します。

## 残機（ライフ）システム

- ゲーム開始時、全員に同じ数の残機（既定は3）が配られます。
- 倒されるたびに残機が1ずつ減ります。
- 残機が残っていれば、死亡から **約5秒後** に自分のチームスポーンへ自動で復活します。
- 復活までの待機中は画面に「リスポーンまで ◯秒」のカウントダウンが表示されます。
- 残機が **0** になると脱落となり、観戦モードに切り替わります。

!!! tip "リスポーン保護"
    復活した直後は一定時間（既定10秒）、**すべてのダメージが無効化** されます（軽減ではなく完全な無敵）。この間は体が発光して見分けがつきます。復活直後の不利を減らせるので、この間に体勢を立て直しましょう。

## チーム

- チームは **赤・青・黄・緑** の4色です。
- 参加者はゲーム開始時に各チームへ自動で振り分けられます（人数が均等になるよう配分されます）。
- **味方への攻撃は無効** です。同じチームのプレイヤーは攻撃してもダメージを与えられません。
- 名前の色でチームが判別できます。

## 勝利条件

生き残っているチームが **1つだけ** になった時点で、そのチームの勝利です。勝利チーム名が全員の画面にタイトル表示されます。

!!! note "引き分け"
    全チームが同時に脱落するなどして生存チームがいなくなった場合は「引き分け」となります。

## 参加方法

参加・退出・開始は **ロビーの看板** または **コマンド** で行えます。

- **参加看板**（`[ZankiPvP]` / `lobby` と表示）／`/zankipvp join` … 参加できます。看板には現在の参加人数 `◯/◯人` が表示されます。
- **退出看板**（`[ZankiPvP]` / `leave` と表示）／`/zankipvp leave` … ゲームから抜けられます。
- **開始看板**／`/zankipvp start` … ゲームを開始します。
- ゲーム待機中に参加すると、受付ロビーへ移動します。
- ゲームがすでに進行中の場合は **途中参加** が可能で、空いているチームに加わってすぐ戦闘に参加できます。

!!! note "看板でもコマンドでもOK"
    参加・退出・開始は **看板のクリック** と **`/zankipvp join` / `leave` / `start` コマンド**（全員実行可能）のどちらでも行えます。`start` も誰でも実行できるので、人数がそろったら自分たちで開始できます。

## ゲームの流れ

1. **参加する** — ロビーの参加看板をクリックして受付ロビーに入る。
2. **開始を待つ** — 2人以上が集まると、運営がゲームを開始します。
3. **チーム分け** — 赤・青・黄・緑へ自動で振り分けられ、チームスポーンへ移動します。
4. **装備を受け取る** — 木の剣（ノックバックI）・弓・矢・特殊ポーション・パン・盾が自動で配られます。
5. **戦う** — 敵チームのプレイヤーを倒します。倒されても残機があれば数秒後に復活。
6. **脱落** — 残機が0になると観戦モードへ。
7. **決着** — 生き残ったチームが1つになったら、そのチームの勝利！

## 配られる装備

リスポーンや参加のたびに、以下の固定キットが自動で配られます（自分で用意する必要はありません）。

| アイテム | 数量 | 用途 |
|---|---|---|
| 木の剣（ノックバックI） | 1 | 近接武器（敵を押し出せる） |
| 弓 | 1 | 遠距離武器 |
| 矢 | 64 | 弓の弾薬 |
| 特殊ポーション（スプラッシュ） | 1 | 右クリックで自分に各種バフ（即時回復・再生・耐性・俊敏・攻撃力上昇） |
| パン | 64 | 空腹の回復 |
| 盾 | 1 | 防御（オフハンド） |

!!! note "ドロップについて"
    死亡してもアイテムはドロップしません。次のリスポーン時に同じ装備が配り直されます。

## プレイヤー用コマンド

参加・退出・開始は看板のほか、コマンドでも行えます（いずれも全員実行可能）。

| コマンド | 説明 |
|---|---|
| `/zankipvp join` | ゲームに参加する（参加看板と同等） |
| `/zankipvp leave` | ゲームから退出する（退出看板と同等） |
| `/zankipvp start` | ゲームを開始する（開始看板と同等） |
| `/zankipvp` | コマンド一覧（ヘルプ）を表示する。エイリアス `/zpvp`・`/zanki` |

!!! note "管理用コマンドについて"
    上記以外（設定・残機/保護/人数の変更・強制終了など）は運営（OP）専用です。詳しくは OP・運営向けページをご覧ください。

## よくある質問

??? question "倒されたらすぐ終わりですか？"
    いいえ。残機がある限り、約5秒後に自動でリスポーンします。残機が0になって初めて脱落（観戦モード）になります。

??? question "味方を攻撃してしまいました"
    同じチームのプレイヤーへの攻撃は無効化されるため、ダメージは入りません。安心して乱戦に参加してください。

??? question "リスポーン直後に倒されてしまいます"
    復活直後はリスポーン保護で一定時間すべてのダメージが無効になります（体が発光します）。保護が切れる前に安全な位置取りをしましょう。

??? question "ゲームの途中から参加できますか？"
    できます。進行中のゲームでは参加看板をクリックすると、空いているチームに途中参加できます。

??? question "脱落したらどうなりますか？"
    観戦モードになり、ゲームの様子を見られます。ゲームが終わると自動でロビーへ戻ります。
