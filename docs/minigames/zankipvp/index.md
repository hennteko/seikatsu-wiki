# Zankipvp <span class="badge done">公開中</span>

残機（ライフ）制の **チームPvPミニゲーム** です。最大4チームに分かれ、決められた残機を使い切るまで戦い、最後まで生き残ったチームが勝利します。倒されても残機がある限り自動でリスポーンするため、初心者でも気軽に乱戦を楽しめます。

!!! note "ゲームの特徴"
    各プレイヤーに与えられた残機を使い切ると脱落（観戦モード）になります。生き残っているチームが1つになった時点でそのチームの勝利です。参加・退出はロビーに設置された看板のクリックで行い、装備は固定キットが自動で配られます。
