# ライアーズテーブル（LiarsTable） <span class="badge done">公開中</span>

はったりカードを **伏せて出し**、怪しいと思ったら「ライアー！」で **めくって** 嘘を見破る、2〜4人用のテーブルゲームです。嘘を見破られた人、または疑いが外れた人が **ゾギー（歯のあるモブ）** の歯を1本抜き、ハズレの歯を抜くと噛まれます。**2回噛まれると脱落**、最後まで残った1人が勝ちです。操作はすべてチェスト画面で、Java版・統合版で共通です。

!!! note "ゲームの特徴（はったりカード × ゾギーの歯抜き）"
    ラウンドの最初に「テーブルカード」（Q・K・A のどれか）が決まります。自分の番では、手札から1〜3枚を伏せて出し「テーブルカードです」と言い張る（嘘でもよい）か、前の人の出したカードを「**ライアー！**」でめくるかを選びます。めくったカードにテーブルカードでもジョーカーでもないものが1枚でもあれば、出した人が嘘つき。嘘つき（全部正しければ疑った人）が **ゾギー** の歯を1本抜きます。歯は全員で共有するので、前の人が抜くほど次が危険に。ハズレを抜くと噛まれ、**2回**（既定）で脱落します。現在のモードは **デッキモード**（Q・K・A 各6枚＋ジョーカー2枚）です。
