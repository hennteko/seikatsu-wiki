# ライアーズテーブル（LiarsTable） ― 遊び方 { .page-player #liarstable-player }

カードを伏せて出し「テーブルカードです」と言い張り、怪しければ「ライアー！」でめくって嘘を見破るはったりゲームです。見破られた人（または疑いを外した人）が **ゾギー** の歯を抜き、ハズレを引くと噛まれます。2回噛まれると脱落、最後まで残った1人が勝ちです。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 1テーブル 2〜4人 |
    | 勝利条件 | 最後まで脱落せずに残った1人 |
    | 脱落 | ゾギーに2回噛まれる（既定） |
    | 手番の制限時間 | 30秒（既定・時間切れはランダムに1枚出す） |
    | 歯選びの制限時間 | 15秒（既定・時間切れはランダムな歯） |
    | 操作 | すべてチェスト画面（Java版・統合版共通） |
    | 参加方法 | ロビーの参加看板、または `/lt join` |

## 参加と離脱

1. 参加看板をクリック、または `/lt join` でロビーに入ります。持ち物は預かられ、離脱すると元に戻ります。
2. 離脱看板をクリック、または `/lt leave` で抜けます。
3. 開始看板をクリック、または `/lt start`（全員可）で試合が始まります（2人以上）。人数がそろっても自動では始まりません。
4. 1つのテーブルに座れるのは最大4人です。席に入れなかった人はロビーで次の試合を待ちます。

## ルール（デッキモード）

- カードは **Q・K・A が6枚ずつと、ジョーカー2枚の計20枚**（既定）。全員に5枚ずつ配ります。
- ラウンドの最初に「**テーブルカード**」（Q・K・A のどれか）が決まります。ジョーカーは何にでもなります。
- 自分の番では、次のどちらかを選びます。
    - **出す** … 手札から1〜3枚を伏せて出し、「テーブルカードです」と言い張ります（嘘でもかまいません）。
    - **ライアー！** … 前の人が出したカードをめくります。ラウンドの最初の人は押せません。
- めくったカードに、テーブルカードでもジョーカーでもないものが **1枚でもあれば、出した人が嘘つき** です。嘘つきがゾギーの歯を抜きます。全部正しければ、疑った人が歯を抜きます。
- 手札が無くなった人の番は飛ばされます。手札が残っているのが自分だけになったら、「ライアー！」しか選べません。
- 罰が終わると、全員に配り直して次のラウンドです。罰を受けた人から始めます。

!!! tip "はったりのコツ"
    テーブルカードが手元に少なくても、堂々と複数枚出して言い張れます。相手が「ライアー！」を押さなければそのまま通ります。逆に、残り手札が少ない相手の大量出しは怪しいサインです。

## ゾギーの歯抜き

- ゾギーの歯は **6本**（既定）で、そのうち1本がハズレです。歯はテーブル全員で共有しているので、前の人が抜くほど次の人が危なくなります。
- 普通の歯ならセーフです。ハズレを抜くと噛まれ、歯は全部生え戻ります。
- **2回噛まれたら脱落**（既定）です。最後まで残った1人の勝ち。全員いなくなったら引き分けです。
- ゾギーの頭上に残りの歯の本数、右のサイドバーに全員の手札の枚数と噛まれた回数が出ます。

## 操作

- 自分の番になると手札の画面が自動で開きます。閉じても、ホットバーの「手札を見る」（本）か `/lt hand` で開き直せます。
- 手札をクリックして選び（選んだカードは光ります）、「出す」を押します。「ライアー！」はボタンを押すだけです。
- 手番は30秒（既定）です。時間切れになると、手札からランダムに1枚出します（「ライアー！」しか選べないときは自動でライアー！）。
- 歯を選ぶ画面では、骨（歯）を1本クリックします。15秒（既定）で時間切れになり、ランダムな歯を抜きます。
- 試合中は席から降りられません。

## 途中で抜けたとき

- 試合中に `/lt leave` やログアウトをすると脱落扱いになり、ロビーからも抜けます。再ログインしても試合には戻れません（持ち物は戻ります）。
- 試合中に参加した人は、次の試合から参加できます（観戦はできません）。
- 歯を抜く途中の人が抜けたときは、その罰はなかったことにして次のラウンドへ進みます。

## 観戦（脱落したとき）

- 脱落すると観戦になり、生き残っている人の視点で試合を見られます。スニークで見る人を切り替えます。自由に動き回ることはできません。
- 手札はその人の画面にしか出ないため、観戦中に他の人の手札は見えません。
- 試合が終わると、全員ロビーへ戻ります。続けて次の試合に参加できます。

## 統合版での見え方

!!! note "統合版のプレイヤーへ"
    - 操作はすべてチェスト画面なので、Java版と同じ操作で遊べます。カードの意味はアイテムの名前（1行目）で分かります。
    - 「手札を見る」は空中タップ（腕振り）でも開けます。
    - **観戦** は、観戦モードの視点固定が効かないため、透明になって見ている人の後ろへ一定間隔で移動する方式になります（スニークで切り替え）。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/lt join` | ロビーに参加する（参加看板と同等・全員可） |
| `/lt leave` | ロビーから離脱する（離脱看板と同等。試合中は脱落扱い・全員可） |
| `/lt start [アリーナ]` | ゲームを開始する（開始看板と同等・全員可） |
| `/lt hand` | 手札の画面を開き直す（全員可） |
| `/lt status` | 現在の設定・状況を確認する（全員可・読み取り専用） |

## よくある質問

??? question "嘘をついてもいいのですか？"
    はい。それがこのゲームの核心です。テーブルカードを持っていなくても「テーブルカードです」と言い張って伏せて出せます。相手が「ライアー！」でめくらなければ、そのまま通ります。

??? question "「ライアー！」が押せません。"
    ラウンドの最初の人（まだ誰も出していないとき）は押せません。また、手札が残っているのが自分だけになると「ライアー！」しか選べなくなります。

??? question "必ず歯を抜かないといけませんか？"
    はい。見破られた人、または疑いが外れた人は必ず歯を1本抜きます。歯は全員で共有しているので、前の人が普通の歯を抜くほど、残りの歯でハズレを引く確率が上がります。

??? question "噛まれたら手札はどうなりますか？"
    罰のあとは全員に配り直して次のラウンドになります。歯も全部生え戻ります。噛まれた回数だけが積み重なり、2回（既定）で脱落です。
