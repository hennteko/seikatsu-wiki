# Kakurenbo（かくれんぼ）― 遊び方 { .page-player #kakurenbo-player }

ブロックに化けて隠れる「擬態かくれんぼ」です。鬼に **雪玉** を当てられると鬼側に転向（増え鬼）。制限時間まで1人でも隠れ残れば隠れ側の勝ちです。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 2〜16人 |
    | 1試合の長さ | 既定5分（300秒）＋隠れ時間30秒 |
    | 役割 | 鬼（探す）／隠れる側（ブロックに擬態） |
    | 勝利条件 | 隠れ側：時間まで1人以上生存／鬼：全員捕獲 |
    | 捕獲 | 鬼が **雪玉** を擬態ブロックに当てる → 数秒後に鬼へ転向 |

## どんなゲーム？

参加者は開始時に **鬼（SEEKER）** と **隠れる側（HIDER）** に分かれます。鬼の人数は参加人数に応じて自動で決まり（既定で8人につき1人）、残りが隠れる側です。

隠れる側は **透明化してブロックに化け**、フィールドのどこかに紛れて隠れます。鬼は時間内に隠れ側を全員見つけ出せば勝ち、隠れ側は **1人でも時間切れまで隠れ残れば** 勝ちです。捕まった隠れ側は退場せず、**鬼に転向して一緒に探す側** になります。

!!! tip "鬼に立候補できます"
    OPが **鬼立候補看板** を設置していれば、ロビーでクリックして **鬼への立候補** ができます（もう一度クリックで取り消し）。開始時は立候補者から優先的に鬼が選ばれ、不足分はランダムで補われます。

## ゲームの流れ

1. **参加する** — ロビーの参加看板をクリック、または `/kakurenbo join`。
2. **カウントダウン** — 開始すると約10秒のカウント後にスタート。
3. **役割発表** — 「鬼」「隠れる側」がタイトルで表示されます。
4. **隠れ時間（約30秒）** — 隠れ側はブロックに化けて隠れます。鬼は待機ステージに隔離され、その場で **足止め**（動けない）。
5. **探索（約5分）** — 鬼が鬼スポーンへ解き放たれて動き出します。残り時間・隠れ人数・鬼人数がアクションバーに表示されます。
6. **捕獲と増え鬼** — 鬼が **雪玉** を化けた隠れ側に当てると捕獲。捕まった人は数秒後に鬼になります。
7. **終盤の公開** — 残り時間が少なくなると（既定で残り60秒）、隠れ側の **擬態ブロックが発光・パーティクル** で鬼に見つかりやすくなり、膠着を防ぎます。
8. **決着** — 全員捕まれば鬼の勝ち、時間切れまで誰か残れば隠れ側の勝ち。終了後は結果発表（既定10秒）のあとロビーへ戻り、参加状態は維持されます（連戦可）。

## 隠れる側の操作（擬態）

- **化ける** — 隠れ側になると配られる **擬態ステッキを持ち、化けたいブロックを見て右クリック**（または直接そのブロックを右クリック）すると、そのブロックに化けます。
- **化けるブロックを選ぶ** — OPが設置した **ブロック選択看板を右クリック** するとGUIが開き、パレットから好きなブロックを選べます（擬態中のみ使用可）。
- **静止で同化** — 擬態ブロックは常に **升目（ブロックマス）にスナップ** しています。その場で静止していれば本物のブロックと完全に同化して見分けがつきません。
- **動くと気配** — 移動すると擬態ブロックがマス単位でカクカク追従し、鬼に気づかれやすくなります。止まる勇気が大事です。
- **擬態を解く** — **スニーク（しゃがみ）を約1秒長押し** すると擬態が解除されます（再度ブロックを見て右クリックで再擬態）。
- **花火を打ち上げる** — ホットバーの **2番目に配られる花火**（擬態中はそのスロットを選ぶだけ・通常時は右クリック）で花火を打ち上げられます。消費せず何度でも使え、演出や合図に使えますが、位置が鬼にバレるリスクもあります。また一定時間ごとに **隠れ側全員の花火が自動で一斉に打ち上がる** 瞬間があります。
- 名前は表示されず、姿も透明になります。フィールドの外には出られません。

## 鬼の探索・捕獲

- 鬼は通常の姿（特別な装備や発光はありません）。怪しいブロックを探します。
- **捕獲は雪玉を当てるだけ** — 配られる **雪玉を化けた隠れ側に当てる** と捕獲成功（雪玉は投げても自動補充され無制限）。殴ってもダメージは入りません。捕まった相手は擬態が解けて **発光** し、数秒後に鬼スポーンへ移動して鬼に転向します。
- ゲーム中はダメージ・空腹・落下などは無効で、捕獲は雪玉による専用処理として扱われます（HPは関係ありません）。

## ソロモード「見つけて」（1人用）

**CPU が化けたブロックを、制限時間内に叩いて探し出す** モードです。1人で遊べます。

!!! abstract "ソロのクイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 1人 |
    | 入口 | ソロ看板をクリック／`/kakurenbo solo` |
    | 探し方 | 怪しいブロックを **左クリックで叩く**（統合版は見つけ棒を持ってタップでも可） |
    | 終了 | 全員見つける（クリア）／時間切れ |
    | 記録 | 難易度ごとの最高スコアとランキング |

### 遊び方

1. **ソロ看板をクリック**、または `/kakurenbo solo`。ロビーに入り、**ソロメニュー** が開きます。
2. メニューで **難易度** を選ぶと、スタート地点へ移動します。
3. **CPU が隠れる5秒間** はその場から動けません。
4. スタート！ フィールドのどこかに、CPU が **パレットのブロックに化けて** 隠れています。怪しいブロックを **叩いて** 探しましょう。
5. 全員見つけるか時間切れで終了。スコア・自己ベスト・順位が表示され、ロビーへ戻って **3秒後にメニューが開きます**。そのまま再挑戦できます。

- メニューを閉じてもロビーにいるままです。ホットバーの **ネザースター（ソロメニュー）を右クリック** で開き直せます（統合版は **持ってスニーク** でも開きます）。
- `/kakurenbo solo easy` のように難易度を付けると、メニューを通さずすぐ始まります（`easy` / `normal` / `hard`）。
- やめるときはメニューの **ロビー退出** か `/kakurenbo leave`（持ち物が戻り、初期地点へ）。

### スコア

| 項目 | 点数 |
|---|---|
| CPU を1体見つけた | **+100** |
| 全員見つけた（クリア） | 残り秒数 × 2 を加算 |
| お手つき（CPU ではないブロックを叩いた） | 難易度の値だけ減点（かんたん・ふつう −20、むずかしい −30） |

- スコアは0点より下がりません。お手つきは **0.5秒に1回まで** しか数えません。
- 空（何もない所）を叩いても何も起きません。フィールドの外のブロックもお手つきになりません。

### 難易度

| | かんたん | ふつう | むずかしい |
|---|---|---|---|
| CPU の数 | 3 | 5 | 7 |
| 制限時間 | 3分 | 3分 | 4分 |
| CPU の化け方 | ランダム（周りから浮きやすい） | 周りにあるブロックに合わせる | 同じブロックに囲まれた場所だけ |
| 隠れる場所 | 床の上 | 床の上 | 床の上＋壁のくぼみ |
| ヒントの花火 | 30秒ごと | 45秒ごと | 60秒ごと |
| 終盤に光る | 残り60秒から | 残り30秒から | なし |

- **ヒントの花火** … 一定時間ごとに、見つかっていない CPU の1体の所から花火が上がります。
- **終盤に光る** … 残り時間が少なくなると、見つかっていない CPU が光ります（統合版は赤いブロックと交互に点滅）。

### ホットバー（挑戦中）

| スロット | アイテム | 使い方 |
|---|---|---|
| 1番 | **見つけ棒** | 左クリックで叩く（素手でも叩けます）。統合版はタップでも叩けます |
| 9番 | **ギブアップ**（バリア） | 右クリックで中断してロビーへ戻る（記録は残りません） |

### 記録が残らない場合

ギブアップ・`/kakurenbo leave`・切断・OP による強制停止のときは、記録が残りません。

### 通常戦との関係

- ソロと通常戦は同じフィールドを使います。**通常戦の試合中（カウントダウン・結果発表を含む）や、ほかの人のソロ挑戦中は始められません**。メニューのボタンがバリアになり、理由が表示されます。空くと「アリーナが空きました」と知らせが来ます。
- ソロで在籍中に参加看板（または `/kakurenbo join`）を使うと、通常戦の参加に切り替わります。逆に通常戦の待機中にソロ看板を使うとソロに切り替わります。
- ランキングは `/kakurenbo ranking`（3つの難易度の上位3人）、`/kakurenbo ranking solo normal`（ふつうの上位10人）で見られます。統合版で出した記録には **[BE]** が付きます（ランキングは共通）。

!!! warning "統合版（スマホ・Switch など）の注意"
    - 叩く判定はサーバー側で「視線の先」を調べています。統合版は Java 版より遠くのブロックに触れることがありますが、**約5ブロックより遠いと反応しません**。近づいて叩いてください。
    - タップで反応しにくいときは、**見つけ棒を持ってタップ（右クリック）** でも叩けます。
    - 終盤の「光る」は、統合版では発光の代わりに **赤いブロックと交互に点滅** します。
    - ソロメニュー（チェスト画面）の文字の見え方は Java 版と少し違うことがあります。

## 参加方法

参加・退出・開始は **看板** または **コマンド** で行えます（いずれも全員可）。

- 参加看板をクリック／`/kakurenbo join`
- 離脱看板をクリック／`/kakurenbo leave`
- 開始看板をクリック／`/kakurenbo start`
- ソロで遊ぶ：ソロ看板をクリック／`/kakurenbo solo`
- （任意）鬼立候補看板をクリックして鬼に立候補
- 設定状況は `/kakurenbo status` で誰でも確認できます

満員のときは参加できません。**試合中に参加した場合はロビーで待機し、次の試合から参加** します（進行中の試合には途中から入れません）。

## よくある質問

??? question "捕まったらどうなりますか？"
    退場ではなく、数秒後に **鬼になって一緒に探す側** に回ります（増え鬼）。最後まで参加し続けられます。

??? question "どうやってブロックに化けますか？"
    隠れる側になると自動でブロックに擬態します。化ける種類は **ブロック選択看板** を右クリックして開くGUIから変更できます。擬態ブロックは常に升目にスナップしており、**止まっていれば同化**し、動くとマス単位で動いてバレやすくなります。

??? question "鬼はどうやって捕まえますか？"
    配られる **雪玉を化けた隠れ側に当てる** だけです。当たると相手が発光して鬼に転向します。雪玉は投げても自動で補充されます。

??? question "ソロで「お手つき」になったのに、叩いた所に何もなかった"
    叩いた瞬間の **視線の先にある本物のブロック** で判定しています。CPU より手前に本物のブロックがあると、そちらを叩いたことになります。CPU の真正面に回り込んで叩いてください。

??? question "ソロの CPU の上に乗れますか？"
    乗れます（見た目は普通のブロックです）。ただし乗っているだけでは見つけたことにならないので、叩いてください。

??? question "役割は選べますか？"
    基本はランダムで、人数に応じて鬼の数も自動で決まります。ただし **鬼立候補看板** があれば鬼に立候補でき、開始時は立候補者から優先的に鬼が選ばれます（不足分はランダム）。
