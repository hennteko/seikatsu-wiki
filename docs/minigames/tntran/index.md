# Tntran <span class="badge done">公開中</span>

足元のブロックが次々と消滅していくフィールドを走り続け、最後まで落ちずに生き残ることを目指す **TNT Run 系のサバイバルミニゲーム** です。プレイヤーが乗ったカラフルなウールの足場は一定時間後に消滅し、落下した人から脱落。最後の1人になれば勝利です。

!!! note "ゲームの特徴"
    乗った足場のブロックが約1秒後に消えていく、シンプルで白熱するミニゲームです。ロビーシステムを備え、参加・退出は看板のクリックで行います。多層のウール足場で構成されたエリアを走り回り、落下を回避し続けましょう。
