# Tntran ― 遊び方 { .page-player #tntran-player }

足元のブロックが消えていくフィールドを走り続け、最後の1人まで生き残れば勝ちのサバイバルミニゲームです。乗った場所のウールが消滅するので、止まらず走り回りましょう。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 最大6人（サーバー設定で変更される場合あり） |
    | 勝利条件 | 最後の1人まで生き残る |
    | 足場の消滅時間 | 乗ってから約1秒後（既定 20 tick） |
    | 参加・退出 | ロビーの看板をクリック |
    | ゲームモード | アドベンチャーモード（脱落するとスペクテイター） |

## どんなゲーム？

色違いのウールブロックで作られた、複数の階層からなるフィールドが舞台です。ゲームが始まると、**プレイヤーが乗った足場のブロックは約1秒後に消滅** します。

足場が消えれば下の層へ落ち、最下層も走り抜けてしまえば落下死――そのまま脱落です。止まればすぐ足元が抜けるので、常に走り続けて生き残りましょう。最後まで残った1人が勝者です。

## ルール

- 乗ったウールブロックは一定時間後（既定で約1秒）に消滅します。
- 足場が消えると下の層へ落ちます。フィールドより十分下まで落ちると **脱落** です。
- ゲーム中はアドベンチャーモードになり、ブロックの設置・破壊やダメージはありません（落下死のみが脱落条件）。
- 脱落するとスペクテイター（観戦）モードになり、試合の様子を見学できます。

## 勝利条件

生き残っているプレイヤーが **1人だけ** になった時点で、その人が勝者です。全員が同時に脱落した場合は勝者なしで終了します。

## 参加方法

!!! note "参加はロビーの看板から"
    参加は基本的に **ロビーに設置された参加看板**（`[Tntran]` / `lobby` と書かれた看板）をクリックして行います。看板をクリックするとロビーへテレポートし、参加人数にカウントされます。

- **参加看板** … クリックするとゲームに参加し、ロビーへテレポートします。看板には現在の参加人数が表示されます。
- **退出看板** … `[Tntran]` / `leave` と表示された看板をクリックすると離脱できます。
- **開始看板** … `[Tntran]` / `start` / `▶クリックで開始` と表示された看板をクリックすると、ゲームを開始できます（設置されている場合。開始条件を満たしていないときは開始されません）。
- 満員のとき、またはゲーム進行中は新たに参加できません。
- `/tntran join` / `/tntran leave` コマンドでも参加・離脱が可能です。

## ゲームの流れ

1. **参加する** — ロビーの参加看板をクリックして加わります。ロビーへテレポートします。
2. **開始を待つ** — 運営（OP）の `/tntran start`、または **開始看板** のクリックでゲームが始まります。
3. **カウントダウン** — フィールドのマップが生成され、参加者がエリア上空へ転送されます。5秒のカウントダウンの後にスタート。
4. **走り続ける** — 「ゲームスタート！足場が崩れます！」の合図で足場の消滅が始まります。止まらず走りましょう。
5. **脱落・生き残り** — 落下した人から脱落（スペクテイターに）。最後の1人になれば **勝利！**

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/tntran join [対象]` | ゲームに参加する（対象を省略すると自分） |
| `/tntran leave [対象]` | ゲームから離脱する（対象を省略すると自分） |

!!! tip "看板での参加がおすすめ"
    参加・退出はロビーの看板クリックが基本です。コマンドでも操作できますが、看板なら参加人数の表示もあって分かりやすいです。

## よくある質問

??? question "途中で動きを止めても大丈夫ですか？"
    いいえ。止まっているとすぐに足元のウールが消えて落下します。常に走り回って生き残りましょう。

??? question "落ちたらすぐにゲームオーバーですか？"
    足場が消えても、まだ下の層が残っていれば落ちた先で走り続けられます。フィールドより十分下まで落下した時点で脱落です。

??? question "脱落した後はどうなりますか？"
    スペクテイター（観戦）モードになり、試合の続きを見学できます。試合が終わるとロビーへ戻されます。

??? question "ゲーム中に参加できますか？"
    できません。参加は待機中（ゲーム開始前）のみ可能です。次の試合まで待ちましょう。

??? question "ゲーム中に攻撃でやられることはありますか？"
    ありません。ゲーム中はダメージが無効化されており、脱落の条件は落下のみです。
