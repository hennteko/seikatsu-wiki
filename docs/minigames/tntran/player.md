# Tntran ― 遊び方 { .page-player #tntran-player }

足元のブロックが消えていくフィールドを走り続け、最後の1人まで生き残れば勝ちのサバイバルミニゲームです。乗った場所のウールが消滅するので、止まらず走り回りましょう。
1人で **何秒落ちずにいられるか** に挑む **ソロモード（生存タイムアタック）** もあります。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 通常戦：最大6人（サーバー設定で変わる場合あり）／ソロ：1人 |
    | 勝利条件 | 通常戦：最後の1人まで生き残る／ソロ：生存時間の記録に挑戦 |
    | 足場の消滅時間 | 通常戦：乗ってから約1秒後／ソロ：1.0秒から20秒ごとに速くなる |
    | 参加・退出 | ロビーの看板をクリック、またはコマンド |
    | 会場 | 複数あるときは、空いている会場が自動で選ばれる |

## どんなゲーム？

色違いのウールブロックで作られた、複数の階層からなるフィールドが舞台です。ゲームが始まると、**プレイヤーが乗った足場のブロックは約1秒後に消滅** します。

足場が消えれば下の層へ落ち、最下層も走り抜けてしまえば落下死――そのまま脱落です。止まればすぐ足元が抜けるので、常に走り続けて生き残りましょう。最後まで残った1人が勝者です。

## ルール（通常戦）

- 乗ったウールブロックは一定時間後（既定で約1秒）に消滅します。
- 足場が消えると下の層へ落ちます。フィールドより十分下まで落ちる、または **フィールドの外に出る** と **脱落** です。
- ゲーム中はアドベンチャーモードになり、ブロックの設置・破壊やダメージはありません。満腹度も減りません。
- 脱落すると観戦になり、フィールドの上空から試合の様子を見学できます。

## 勝利条件（通常戦）

生き残っているプレイヤーが **1人だけ** になった時点で、その人が勝者です。全員が同時に脱落した場合は勝者なしで終了します。
試合中に離脱・切断した人は脱落扱いです。

## 参加方法

- **参加看板** … クリックすると通常戦に参加し、ロビーへテレポートします。看板には待機人数が表示されます。
- **離脱看板** … クリックすると離脱し、持ち物が戻って元の場所へ移動します。
- **開始看板** … クリックすると、待機している人で通常戦を始めます。会場は空いているところが自動で選ばれます。
- **ソロ看板** … クリックするとソロモードのメニューが開きます（下の「ソロモード」）。
- 満員のときは参加できません。
- 試合中でも参加できます。ロビーで待ち、**次の試合から** 参加します。
- `/tntran join` / `/tntran leave` コマンドでも参加・離脱が可能です。

## ゲームの流れ（通常戦）

1. **参加する** — ロビーの参加看板をクリックして加わります。ロビーへテレポートします。
2. **開始する** — **開始看板** のクリック、または `/tntran start` でゲームが始まります（だれでも押せます）。
3. **カウントダウン** — 空いている会場に足場が作られ、参加者が上空へ転送されます。5秒のカウントダウンの後にスタート。
4. **走り続ける** — 「ゲームスタート！足場が崩れます！」の合図で足場の消滅が始まります。
5. **脱落・生き残り** — 落下した人から脱落（観戦に）。最後の1人になれば **勝利！** 試合後はロビーに戻り、続けて次の試合に参加できます。

## 会場が複数あるとき

- 会場が2つ以上あるサーバーでは、**開始したときに空いている会場が自動で選ばれます**。
  会場1が使用中なら「会場1は使用中のため、会場2で始めます」と表示され、会場2で試合になります。
- 会場1で試合をしている間にロビーへ来た人たちは、次に開始を押すと別の会場で遊べます。
- すべての会場が使用中のときは開始できません。会場が空くと「会場2が空きました」とお知らせが届きます。
- ロビーに **会場の状況看板** がある場合は、会場ごとに「空き」「通常戦」「ソロ挑戦中」などが表示されます。
- 会場が指定された開始看板もあります。その会場が使用中なら、空いている別の会場で始まります。

## ソロモード（生存タイムアタック）

1人で **何秒落ちずにいられるか** に挑戦するモードです。生存時間が記録になり、自己ベストとランキングが残ります。

### 始め方

1. ソロ看板をクリック、または `/tntran solo` → ロビーへ移動して **ソロメニュー** が開きます（持ち物は預かられます）。
2. メニューの **「生存タイムアタック」**（赤い羊毛）を押すと、空いている会場で **3秒後** にスタートします。
3. 落ちたら終了。記録が表示され、ロビーへ戻って **3秒後にソロメニューがもう一度開きます**。続けて挑戦できます。
4. やめるときはメニューの **「ロビー退出」**（ドア）か `/tntran leave`。持ち物が戻ります。

- メニューは閉じても大丈夫です。ホットバーの **ネザースター（ソロメニュー）** を右クリックすると開き直せます。統合版は **ネザースターを持ってスニーク** でも開きます。
- `/tntran solo survival` で、メニューを通さずにすぐ始められます。
- ソロで入った人は、通常戦の開始には参加しません。通常戦に移るときは `/tntran join`（参加看板）を使います。

### ルール

- スタート地点は会場の中央・最上層です。
- 乗った足場が消えるまでの時間が、**20秒ごとに0.1秒ずつ短く** なります。

| 経過 | Lv | 消えるまで |
|---|---|---|
| 0秒〜 | 1 | 1.0秒 |
| 20秒〜 | 2 | 0.9秒 |
| 40秒〜 | 3 | 0.8秒 |
| 60秒〜 | 4 | 0.7秒 |
| 80秒〜 | 5 | 0.6秒 |
| 100秒〜 | 6 | 0.5秒 |
| 120秒〜 | 7 | 0.4秒 |
| 140秒〜 | 8 | 0.3秒 |
| 160秒〜 | 9（最大） | 0.2秒 |

- 次のどれかで終了し、そこまでの時間が記録になります。
    - 最下層より下に落ちる
    - フィールドの外に出る
    - **足場以外のブロック（壁や柱など）に3秒立ち続ける**（立ち止まって時間を稼げないようにするため）
- 途中で `leave`・切断した場合は **中断** で、記録は残りません。

### 画面の表示

- 画面上の **ボスバー**：会場名・経過時間・自己ベスト。自己ベストを超えると **金色** になります。
- 画面下の **アクションバー**：今の消える速さ（Lv）と、次のスピードアップまでの秒数。
- スピードアップのたびにタイトルと音でお知らせします。

### 記録とランキング

- 記録は **プレイヤーごとの最長生存時間** です。0.1秒単位で残ります。同じ時間なら先に出した人が上です。
- 結果はサーバー全体に1行で流れます（自己ベスト・順位を添えます）。
- `/tntran ranking solo` で上位10人と自分の記録を表示します。
- 記録はどの会場で出しても同じランキングに入ります。統合版で出した記録には **[統合版]** の印が付きます。

### ソロメニュー

| 場所 | 内容 |
|---|---|
| 上段中央 | **生存タイムアタック開始**。自己ベスト・順位・挑戦回数と、使う会場が出ます。始められないときはバリアになり理由が出ます |
| 中段左（本） | ルール |
| 中段中央（紙） | 前回の結果 |
| 中段右（金ブロック） | ランキング上位5人と自分の順位 |
| 下段左（コンクリート） | 会場の状況（緑＝空きあり／赤＝空きなし） |
| 下段右端（ドア） | ロビー退出 |

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/tntran join` | 通常戦に参加する（参加看板と同じ）。ソロで在籍中なら通常戦の待機に切り替え |
| `/tntran leave` | 離脱する（離脱看板と同じ） |
| `/tntran start [会場]` | 通常戦を開始する（開始看板と同じ）。会場を省略すると空いている会場 |
| `/tntran solo` | ソロで参加し、ソロメニューを開く（ソロ看板と同じ） |
| `/tntran solo survival` | 生存タイムアタックをすぐ始める |
| `/tntran ranking solo` | ソロのランキングと自分の記録 |
| `/tntran status` | 現在の設定・会場の状況を確認する |

!!! note "これらのコマンドは権限不要"
    上の表のコマンドは誰でも実行できます。参加・離脱・開始・ソロは看板でも同じことができます。

## 統合版（スマホ・Switch など）で遊ぶ場合

- ソロメニューは普通のチェスト画面として開き、タップで操作できます。アイテムの説明（lore）の改行や色は、Java 版と見え方が少し違う場合があります。
- ネザースター（ソロメニュー）は、タップに加えて **持ってスニーク** でも開けます。
- ボスバー・アクションバー・タイトルは表示されます。
- ソロの後半（0.3秒・0.2秒で消える段階）は、通信の遅れの分だけ Java 版より難しく感じることがあります。
- 脱落後の観戦は、統合版では透明な状態で飛び回る方式（ゴースト観戦）になります。

## よくある質問

??? question "途中で動きを止めても大丈夫ですか？"
    いいえ。止まっているとすぐに足元のウールが消えて落下します。常に走り回って生き残りましょう。ソロで壁や柱の上に逃げても、3秒で終了になります。

??? question "落ちたらすぐにゲームオーバーですか？"
    足場が消えても、まだ下の層が残っていれば落ちた先で走り続けられます。フィールドより十分下まで落下した時点で脱落です。

??? question "脱落した後はどうなりますか？"
    観戦になり、試合の続きを見学できます。試合が終わるとロビーへ戻されます。

??? question "ゲーム中に参加できますか？"
    参加はできます。ロビーで待ち、次の試合から加わります。別の会場が空いていれば、すぐに開始することもできます。

??? question "ソロの途中でやめたら記録は残りますか？"
    残りません。`leave`・切断・運営の停止は「中断」で、記録は付きません。

??? question "ゲーム中に攻撃でやられることはありますか？"
    ありません。ゲーム中はダメージが無効化されており、脱落の条件は落下（とフィールドの外に出ること）だけです。
