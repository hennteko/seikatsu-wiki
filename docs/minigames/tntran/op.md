# Tntran ― OP・運営ガイド { .page-op #tntran-op }

Tntran の導入・設定ツール・会場のセットアップ（複数会場を含む）・ソロモード・config・権限・管理コマンドをまとめます。地点・会場・看板は設定ツール（`/tntran wand`）かコマンドで登録すると自動保存されます。

## 基本情報

| 項目 | 値 |
|---|---|
| プラグイン名 | Tntran |
| バージョン | 1.3 |
| api-version | 26.1.2 |
| メインコマンド | `/tntran` |
| 依存プラグイン | なし（floodgate / Geyser-Spigot は任意） |
| 設定ファイル | `plugins/Tntran/config.yml` |
| 記録ファイル | `plugins/Tntran/solo-records.yml`（ソロの記録） |

## 導入手順

1. ビルドした `Tntran` の jar をサーバーの `plugins/` フォルダに配置する。
2. サーバーを起動すると `plugins/Tntran/config.yml` が自動生成される。
3. `/tntran wand` で設定ツールを受け取り、初期スポーン・ロビー・会場（フィールド）を設定する（コマンドでも可）。
4. ロビーに参加・離脱・開始・ソロの看板を設置する。
5. `/tntran status` で設定状況を確認する。

!!! note "旧バージョンからの更新（config の作り直しは不要）"
    起動時に `config.yml` が自動で更新されます。

    - 足りない項目（`config-version`・`arena`・`solo`・`solo-modes` など）を追記し、設定済みの値はそのまま引き継ぎます。旧ファイルは `config.yml.bak-日時` に退避されます。コンソールに「config.yml に N 項目を追加しました」と出ます。
    - **今までのフィールド（`locations.area`）は会場 `room1`（表示名「会場1」）に自動で移ります**。移したあと `locations.area` は削除されます。コンソールに「旧形式のフィールド（locations.area）を会場 room1 に移行しました」と出ます。
    - 看板・ロビー・初期スポーンの設定もそのまま使えます。

## 設定ツール（`/tntran wand`）

異能バトル・一本柱PvP・スナイパーバトロワの設定ツールと同じ操作で、見ている場所へ直接セットアップできます（ブレイズロッド・OP専用）。非OPが手に入れても使えません。**TNTRANに参加中（ロビー在籍中）は受け取れない** ので、先に `/tntran leave` してください。

```text title="OP用の設定ツール（ブレイズロッド）を受け取る"
/tntran wand
```

```text title="設定メニュー（GUI）を開く"
/tntran menu
```

| 操作 | 動作 |
|---|---|
| 左クリック（ブロック） | **選択中の会場** のフィールド角1を設定（会場が無ければ作る） |
| 右クリック（ブロック） | 選択中の会場のフィールド角2を設定 |
| 右クリック（看板） | 選択中の看板モードを適用（参加／離脱／開始／会場固定の開始／ソロ／状況／解除）。モードなしなら登録内容を表示 |
| 右クリック（空中） | 設定状況の要約を表示 |
| しゃがみ＋左クリック | 範囲を10秒表示（橙＝フィールド／水色＝足場の層／赤＝落下判定（最下層の10ブロック下）／灰＝ほかの会場） |
| しゃがみ＋右クリック | **設定メニュー（GUI）を開く**（`/tntran menu` でも開ける） |

- 会場の設定は **選択中の会場** に対して行います。会場はメニュー上段の矢印・「会場の選択」で切り替えます（ツールの説明欄に選択中の会場が出ます）。
- 会場が1つも無いときに角を設定すると `room1`（会場1）が作られます。2つ目以降はメニューの **「新しい会場を作る」** で `room2`, `room3` … を作って選び、そのまま角1・角2をクリックします。
- ほかの会場と重なる・近すぎる位置、試合中の会場は、コマンドと同じく拒否されます。

### 設定メニューでできること

| 場所 | 内容 |
|---|---|
| 上段 | 新しい会場を作る／前・次の会場／会場の選択（大きさ・用途・優先度・最大人数・状態）／設定状況 |
| 2段目 | 初期スポーン・ロビー（共通）・この会場の戻り先の設定と解除／フィールドの説明／範囲を表示／用途（両方→通常戦→ソロ）／休止 |
| 3段目 | 看板モード（参加・離脱・開始（自動）・開始（会場固定）・ソロ・状況・解除）、登録済みの看板の数 |
| 4・5段目 | 全体の最大人数・この会場の最大人数（0＝全体の値）・この会場の優先度を −／＋ で変更、ソロの有効／無効 |
| 下段 | 通常戦を開始（選択中の会場。使用中なら空いている会場へ）／この会場を強制停止／全会場を強制停止／閉じる／設定ツールを回収 |

変更はすぐ保存され、次の試合から反映されます。会場の削除と表示名の変更はコマンド（`delarena`・`setdisplay`）で行います。

!!! note "統合版での操作"
    統合版はブレイズロッドで空中を右クリックしても届かないため、**しゃがまずに空中をタップすると設定状況の要約** が出ます。しゃがみ＋空中タップでメニューが開かないことがあるので、そのときは `/tntran menu` を使ってください。長押しで角を設定したときにブロックが壊れたように見えることがありますが、すぐ元の表示に戻ります（実際には壊れていません）。

## 会場の考え方

- **会場** ＝ フィールド1つ分です。会場ごとに試合を1つ持ち、**複数の会場で同時に試合できます**（通常戦とソロ、ソロ同士なども同時に可）。
- **ロビー・参加看板・離脱看板・ソロ看板は全会場で共通** です。プレイヤーは会場を選ばずにロビーへ入ります。
- **会場は開始したときに自動で割り当てます**。1つ目が使用中なら2つ目へ回します。
    - ソロ：ソロメニューの開始ボタンを押したとき。
    - 通常戦：開始看板／`/tntran start` を押したとき。待機中の通常参加者をまとめて空いている会場へ送ります。
- 会場が空くと、ロビーの待機者に「○○が空きました」と知らせます（自動では始めません）。

### 会場ごとの設定

| 設定 | 既定 | コマンド | 内容 |
|---|---|---|---|
| フィールド | なし | `setfield [会場] <1\|2>` | 足場を作る範囲（直方体） |
| 表示名 | room2 → 会場2 | `setdisplay <会場> <表示名>` | メッセージ・看板・メニューに出る名前（15文字まで） |
| 用途 | both | `setuse [会場] <both\|normal\|solo>` | both＝通常戦・ソロ両方／normal＝通常戦だけ／solo＝ソロだけ |
| 優先度 | 作った順 | `setpriority [会場] <数>` | 小さいほど先に使う |
| 最大人数 | 0（全体の値） | `setmax <会場> <数>` | その会場で通常戦をする最大人数 |
| 戻り先 | なし（共通ロビー） | `setlobby <会場>` | 試合後に戻す場所。会場が離れた場所にあるときだけ設定（`setlobby <会場> clear` で解除） |
| 休止 | off | `pause <会場> <on\|off>` | on で割り当てない（建て替え・点検用。進行中の試合は最後まで続く） |

### 割り当ての順番

1. 休止中・フィールド未設定・試合中の会場を除く。
2. 用途が合わない会場を除く（ソロなら solo／both、通常戦なら normal／both）。
3. 通常戦は、会場の最大人数が待機人数以上のものだけにする（どの会場にも入りきらないときは、一番大きい空き会場の定員分だけ先に始め、残りは次の試合に回す）。
4. **専用の会場を先に使う**（ソロなら solo、通常戦なら normal を both より先に）。両方に使える会場がなるべく空いたまま残ります。
5. 同じ条件なら優先度が小さい順。

!!! warning "会場を作るときの注意"
    - **会場どうしは2ブロック以上離し、下の落下判定（最下層の10ブロック下まで）にも別の会場を入れないでください**。近すぎる位置で `setfield` すると拒否されます。
    - **ソロに使う会場は同じ大きさ・同じ層数にしてください**。ソロの記録は会場を区別せずに比べるためです。そろっていないと `/tntran status` と `setfield` で警告が出ます。大きさの違う会場は、用途を `normal` にすれば使えます。
    - 会場名は英数字・`_`・`-` の24文字以内です。**数字だけの名前（`1`・`2` など）と `all` は使えません**（`room2` のようにしてください）。
    - 試合中の会場は、フィールドの変更・削除ができません。

## セットアップ手順

OP権限で、**設定したい場所に立って** 実行します（実行位置が座標として保存されます）。

```text title="初期リスポーン地点（途中抜け時の戻り先）"
/tntran setstartspawn
```

```text title="ロビー（全会場で共通）"
/tntran setlobby
```

### 1つ目の会場

会場が1つも無いときは、会場名を省略すると `room1`（会場1）が作られます。

```text title="角1に立って実行"
/tntran setfield 1
```

```text title="対角の角2に立って実行"
/tntran setfield 2
```

!!! tip "フィールド（setfield）の作り方"
    角1〜角2で囲んだ直方体が、ゲーム開始時に **ウールの足場が自動生成される範囲** です。Y 座標の差をもとに、下から **5ブロック間隔・最大6層** の足場が作られます（赤・橙・黄・黄緑・緑・水色）。十分な高さ（26ブロックほど）を取ってください。フィールドの外に出たプレイヤーは脱落になります。

### 2つ目以降の会場を追加する

1. 会場1と2ブロック以上離れた場所に、同じ大きさの会場を建てる（ソロにも使うなら層数もそろえる）。
2. 角1に立って実行（会場 room2 ができる）。

```text title="会場2の角1"
/tntran setfield room2 1
```

3. 対角の角2に立って実行。

```text title="会場2の角2"
/tntran setfield room2 2
```

4. 用途を決める（両方に使うなら不要。既定は both）。

```text title="会場2をソロ専用にする"
/tntran setuse room2 solo
```

5. 表示名を変えたいとき（既定は room2 → 会場2）。

```text title="会場2の表示名"
/tntran setdisplay room2 会場2
```

6. 設定を確認する。

```text title="設定状況の確認"
/tntran status
```

!!! note "会場を2つ以上にしたあとの会場名の省略"
    会場が1つだけのときは `setfield 1` のように会場名を省略できます。2つ以上あるときに省略すると、実行せずに会場の一覧を出して指定を求めます（`setuse`・`setpriority` も同じ）。

### 運用例

| 構成 | 設定 | 動き |
|---|---|---|
| 2会場・どちらも両用 | room1・room2 とも `both` | 先に始めた方が会場1、次が会場2 |
| ソロ専用を1つ用意 | room1=`both`、room2=`solo` | ソロはまず会場2、会場2が使用中なら会場1。通常戦は会場1だけ |
| 大人数用の大きい会場 | room3=`normal`、`setmax room3 16` | 待機が多いときは会場3に入る。会場3はソロに使わないので大きさが違ってよい |

### 会場を一時的に止める・削除する

```text title="会場2を休止（建て替え・点検）"
/tntran pause room2 on
```

```text title="会場2を再開"
/tntran pause room2 off
```

```text title="会場2を削除（会場固定の開始看板・状況看板も解除）"
/tntran delarena room2
```

## 看板の設置

看板を見ながら（5ブロック以内）実行します。看板の文字はプラグインが書き込み、人数や会場の状況に合わせて自動で更新します。

```text title="参加看板（クリックで通常戦に参加・ロビーへTP。待機人数を表示）"
/tntran setsign join
```

```text title="離脱看板（クリックで離脱。持ち物が戻り初期地点へ）"
/tntran setsign leave
```

```text title="開始看板（会場は自動。空き会場数を表示）"
/tntran setsign start
```

```text title="ソロ看板（クリックでソロメニュー。ソロに使える空き会場数を表示）"
/tntran setsign solo
```

```text title="会場固定の開始看板（使用中なら空いている会場へ回す）"
/tntran setsign start room1
```

```text title="会場の状況看板（空き／通常戦／ソロ挑戦中などを表示。クリックしても何も起きない）"
/tntran setsign arena room1
```

```text title="視線先の看板の登録を解除（種類を自動判別）"
/tntran setsign delete
```

```text title="最大参加人数（待機の上限・会場の既定値）"
/tntran setmax <数>
```

!!! tip "開始看板はプレイヤーも押せます"
    開始看板・ソロ看板のクリックに権限は不要です。登録看板は OP 以外は壊せません（OP が壊すと登録解除）。

## ソロモード（生存タイムアタック）

1人で何秒落ちずにいられるかを競うモードです（共通ルール14章の GUI ロビー方式）。遊び方の詳細は [プレイヤー向けページ](player.md) を見てください。

- 入口は `/tntran solo` かソロ看板。ソロで入った人は通常戦の開始に巻き込まれません（`/tntran join` で通常戦の待機に切り替え）。
- 消える速さは 1.0秒から20秒ごとに0.1秒ずつ速くなり、160秒で最速の0.2秒になります（`solo-modes` で変更可）。
- 終了：落下・フィールドの外・足場以外に3秒立ち続ける。`leave`・切断・`stop` は中断（記録なし）。
- 記録は `solo-records.yml` に **プレイヤー × モードごとの最長時間** を保存します。結果はサーバー全体に1行流れます（`solo.broadcast-result`）。
- `/tntran stop` でソロを止めると、挑戦者はロビーに戻ってソロメニューが開きます。

```text title="ソロの記録を1人分消す"
/tntran ranking reset <プレイヤー>
```

```text title="ソロの記録を全部消す（会場を作り直したときなど）"
/tntran ranking reset all
```

```text title="指定した人をソロへ送る（コンソール・コマンドブロックからも可）"
/tntran solo <プレイヤー>
```

## config.yml 設定項目

| キー | 既定値 | 説明 |
|---|---|---|
| `config-version` | 2 | 設定ファイルの版（移行用。手で変えない） |
| `decay-delay-ticks` | 20 | 通常戦で、足場に乗ってから消えるまで（tick。20 = 1秒） |
| `max-players` | 6 | 通常戦の待機人数の上限。会場の最大人数を 0 にした会場の既定値（`/tntran setmax <数>`） |
| `locations.spawn` | 未設定 | 初期リスポーン地点（`/tntran setstartspawn`） |
| `locations.lobby` | 未設定 | ロビー（全会場で共通。`/tntran setlobby`） |
| `arena.redirect-fixed` | true | 会場固定の開始看板・`start <会場>` で、その会場が使えないとき空いている会場へ回す（false なら断る） |
| `arena.notify-free` | true | 会場が空いたとき、ロビーの待機者に知らせる |
| `arenas.<会場>.*` | なし | 会場の設定（コマンドで保存。手で書かなくてよい） |
| `solo.enabled` | true | false でソロを無効にする |
| `solo.menu-delay` | 3 | ソロが終わってからメニューを開くまで（秒） |
| `solo.countdown` | 3 | ソロ開始前のカウントダウン（秒） |
| `solo.idle-limit` | 3 | 足場以外のブロックに立ち続けたら終了するまで（秒） |
| `solo.max-seconds` | 0 | 上限時間（秒）。到達すると完走。0 で上限なし |
| `solo.block-when-lobby-waiting` | false | 通常戦の待機者がいる間はソロを始めない |
| `solo.broadcast-result` | true | ソロの結果をサーバー全体に1行流す |
| `solo.ranking-size` | 10 | `/tntran ranking solo` の表示人数 |
| `solo-modes.<モード>.display` | 生存タイムアタック | ソロメニューのボタン名 |
| `solo-modes.<モード>.icon` | RED_WOOL | ボタンのアイテム |
| `solo-modes.<モード>.speed.start-ticks` | 20 | 開始時の「乗ってから消えるまで」（tick） |
| `solo-modes.<モード>.speed.step-seconds` | 20 | 何秒ごとに速くなるか |
| `solo-modes.<モード>.speed.step-ticks` | 2 | 1段階で縮める tick |
| `solo-modes.<モード>.speed.min-ticks` | 4 | 最速（tick） |
| `signs.*` | `[]` / `{}` | 看板の位置（`/tntran setsign ...` で自動保存） |

!!! note "モードを増やすとき"
    `solo-modes` に項目を足すと、ソロメニューの上段にボタンが並びます。記録とランキングはモードごとに分かれます。`survival` を消したり名前を変えたりしても、自動更新で戻されることはありません。

## 管理コマンド

| コマンド | 権限 | 説明 |
|---|---|---|
| `/tntran join` / `leave` | なし | 通常戦に参加／離脱 |
| `/tntran start [会場]` | なし | 通常戦を開始（会場を省略すると空いている会場。コンソール・コマンドブロックも可） |
| `/tntran solo [モード]` | なし | ソロメニューを開く／モードを付けるとすぐ開始 |
| `/tntran ranking solo [モード]` | なし | ソロのランキング |
| `/tntran status` | なし | 設定・会場の状況を確認（読み取り専用） |
| `/tntran wand` | `tntran.admin` | OP用の設定ツール（ブレイズロッド）を受け取る |
| `/tntran menu` | `tntran.admin` | 設定メニュー（GUI）を開く |
| `/tntran stop [会場\|all]` | `tntran.admin` | 強制停止（勝敗なし）。試合中の会場が1つなら省略可、2つ以上なら会場を指定 |
| `/tntran setstartspawn` | `tntran.admin` | 初期リスポーン地点 |
| `/tntran setlobby` | `tntran.admin` | ロビー（共通） |
| `/tntran setlobby <会場> [clear]` | `tntran.admin` | 会場の試合後の戻り先（clear で解除） |
| `/tntran setfield [会場] <1\|2>` | `tntran.admin` | 会場のフィールドの角（会場が無ければ作る） |
| `/tntran delarena <会場>` | `tntran.admin` | 会場を削除 |
| `/tntran setuse [会場] <both\|normal\|solo>` | `tntran.admin` | 会場の用途 |
| `/tntran setpriority [会場] <数>` | `tntran.admin` | 会場の優先度 |
| `/tntran setmax <数>` | `tntran.admin` | 最大参加人数（全体） |
| `/tntran setmax <会場> <数>` | `tntran.admin` | 会場ごとの最大人数（0 で全体の値） |
| `/tntran setdisplay <会場> <表示名>` | `tntran.admin` | 会場の表示名 |
| `/tntran pause <会場> <on\|off>` | `tntran.admin` | 会場の休止 |
| `/tntran setsign <join\|leave\|start [会場]\|solo\|arena <会場>\|delete>` | `tntran.admin` | 看板の登録／解除 |
| `/tntran solo <プレイヤー> [モード]` | `tntran.admin` | 指定した人をソロへ（コンソール・コマンドブロックも可） |
| `/tntran ranking reset <プレイヤー\|all> [モード\|all]` | `tntran.admin` | ソロの記録を消す（コンソールも可） |
| `/tntran reload` | `tntran.admin` | config.yml を再読み込み |
| `/tntran lobbyfix <プレイヤー> [force]` | `tntran.admin` | 持ち物が戻らないときの復旧 |

## 権限ノード

| 権限 | 既定 | 用途 |
|---|---|---|
| `tntran.admin` | OP | 設定ツール（wand）・設定メニュー（menu）・セットアップ・会場・看板・`stop`・`solo <プレイヤー>`・`ranking reset`・`reload`・`lobbyfix`。join / leave / start / status / solo / ranking solo は権限不要 |

## 統合版（Geyser）での違い

- ソロメニューはチェスト画面として表示・操作できます。アイテムの説明（lore）の見え方は Java 版と少し違う場合があります。
- ネザースター（ソロメニュー）は、統合版向けに「持ってスニーク」でも開けます。
- ソロの高速段階（0.3秒・0.2秒）は、通信の遅れで統合版が不利になりやすいです。記録は分けずに同じランキングに入れ、統合版の記録には **[統合版]** の印を付けています。
- 脱落後の観戦は、`bedrock.spectator-style: AUTO` のとき統合版だけゴースト観戦（透明で飛行）になります。
- 看板は統合版でタップしたときに編集画面が開かないよう、自動で蝋引きします（`bedrock.wax-signs`）。

## トラブルシューティング

??? failure "ゲームが開始できない（使える会場がありません）"
    `/tntran status` で会場を確認してください。フィールドの角が両方設定されていない・ワールドが読み込まれていない・休止中・用途が合わない（ソロ専用の会場では通常戦はできない）と使えません。

??? failure "setfield で「重なるか近すぎるため設定できません」と出る"
    会場どうしは2ブロック以上離し、下の落下判定（最下層の10ブロック下まで）にも別の会場が入らないようにしてください。

??? failure "参加看板をクリックしても参加できない"
    `/tntran setsign join` で登録されているか確認してください（座標一致で判定するため手書きは機能しません）。会場が1つも設定されていないと参加できません。待機人数が `max-players` に達しているときも参加できません。

??? failure "ソロの記録の比べ方がおかしい"
    ソロに使う会場の大きさがそろっているか `/tntran status` で確認してください。会場の大きさを変えた場合は `/tntran ranking reset all` で記録を消すことも検討してください。

??? failure "足場が生成されない／層が少ない"
    足場はフィールドの Y 座標の範囲をもとに **5ブロック間隔で最大6層** 生成されます。角1と角2の高低差が小さいと層数が減ります。

??? failure "config の変更が反映されない"
    `config.yml` を編集したら `/tntran reload` を実行してください。会場を config から消した場合、その会場で進行中の試合は `/tntran stop all` で止めてください。
