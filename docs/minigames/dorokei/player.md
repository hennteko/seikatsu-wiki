# DorokeiGame ― 遊び方 { .page-player #dorokei-player }

泥棒（市民）と警察（警官）に分かれて遊ぶ鬼ごっこゲームです。市民は制限時間まで逃げ切れば勝ち、警官は全市民を捕まえれば勝ちです。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 2〜20人（最低2人で開始可能／ロビーの既定上限は20人） |
    | 1試合の長さ | 既定8分（480秒）＋逃走準備30秒 |
    | 勝利条件 | 市民：時間切れまで逃げ切る／警官：全市民を捕獲する |
    | 役割分担 | 人数に応じて警官の人数が自動で決まる |
    | 牢獄 | 捕まると牢獄に送られる（仲間が救出可能） |

## どんなゲーム？

参加者は **警官（警察）** と **市民（泥棒）** に自動で振り分けられます。警官の人数は参加人数に応じて自動決定され、残り全員が市民になります。

ゲームが始まると、まず **逃走準備時間（既定30秒）** があります。この間、市民は自由に逃げ回れますが、警官はその場から動けず視界も奪われています。準備時間が終わると警官の追跡が始まります。

警官は **警棒** で市民を叩いて捕まえ、牢獄に送り込みます。市民は捕まらないように逃げつつ、捕まった仲間を助け出すこともできます。

## ゲームの流れ

1. **参加する** — ロビーに設置された参加看板をクリックするか、`/dorokei join <ロビーID>` でロビーに参加します。
2. **開始を待つ** — 運営がゲームを開始すると、3カウントのカウントダウンの後にゲームが始まります。
3. **役割が決まる** — 「あなたは警官！」「あなたは市民！」のタイトルが表示され、装備が配られます。
4. **逃走準備（既定30秒）** — 市民は逃げ回ります。警官は移動できず盲目状態で待機します。
5. **追跡開始** — 準備時間が終わると「追跡開始！」が表示され、警官が動き出します。
6. **捕獲と救出** — 警官は市民を捕まえ、市民は逃げつつ仲間を救出します。
7. **決着** — 全市民が牢獄に入れば警官の勝利、時間切れまで市民が1人でも逃げ切れば市民の勝利です。
8. **ロビーへ帰還** — 終了から5秒後に自動でロビーへ戻り、再び同じロビーに参加した状態になります。

## ルール・仕様

!!! info "ゲームエリアから出られません"
    ゲーム中はマップの **ゲームエリア（設定範囲）外には出られません**。境界を越えようとすると押し戻され「ゲームエリア外には出られません！」と表示されます。

- ゲーム中は **空腹（満腹度の減少）が無効** になります。
- 警官には常時 **移動速度上昇** が付与されています。
- 残り時間はボスバーと、画面右側の **サイドバー（スコアボード）** に表示されます。サイドバーには次が表示されます。
    - **残り時間**（mm:ss）
    - **逃走中**（自由に動ける市民の人数）
    - **捕獲済**（牢獄に入っている市民の人数）
    - **救出**（救出された累計人数）
    - **役割**（警官／市民）
- 残り30秒を切ると毎秒の警告音が鳴ります。
- 牢獄に送られた市民は牢獄の範囲（半径3ブロック）から出られず、移動速度低下と暗視がかかります。

## 役割と装備

=== "👮 警官（警察）"

    市民を捕まえて牢獄に送り込むのが役目です。

    | 配布アイテム | 説明 |
    |---|---|
    | ダイヤのヘルメット | 警官の目印として頭に装着 |
    | 警棒（棒） | これを持って市民を叩くと捕獲できる |
    | スプリントブースト（羽根） | 右クリックで3秒間移動速度が大幅UP（CD60秒） |
    | ネット投擲（クモの巣） | 右クリックで投げ、当てた市民を3秒間スロー（CD45秒） |

    準備時間中は盲目・移動不可ですが、追跡開始とともに解除され速度上昇が付きます。最寄りの市民の方向・距離・高低差がアクションバーに表示され、心臓の鼓動音や追跡パーティクルで市民の位置を探れます。

=== "🏃 市民（泥棒）"

    制限時間まで逃げ切るのが役目です。

    | 配布アイテム | 説明 |
    |---|---|
    | コンパス | 最寄りの警官の方向を指す |
    | 煙幕玉（火薬） | 右クリックで使用。周囲5m以内の警官を3秒間盲目に、自分を5秒間透明化（CD60秒） |
    | ダッシュブーツ（革のブーツ） | 右クリックで使用。5秒間移動速度が大幅UP（CD45秒） |

    捕まった仲間に近づいて叩く（攻撃する）と救出できます。救出された仲間は一時的に速度上昇のバフを得ます。

## 捕獲・牢獄・救出

- **捕獲** — 警官が **警棒を手に持って** 市民を攻撃すると、市民は牢獄へテレポートされます。
- **牢獄** — 牢獄に送られた市民はその場から出られず、移動速度低下と暗視がかかります。20秒ごとに「助けを求めています！」というメッセージが他の市民へ届きます。
- **救出** — 牢獄にいる市民を、まだ捕まっていない市民が攻撃（叩く）と救出成功。救出された市民は再び自由に動けるようになります。

## 勝利条件

!!! tip "勝ち方のポイント"
    - **市民** … 制限時間まで逃げ切れば勝ち。1人でも逃げ切れば市民陣営の勝利です。煙幕玉やダッシュブーツを温存し、ピンチで使いましょう。
    - **警官** … 制限時間内に **全市民を牢獄に閉じ込めれば勝ち**。救出されると捕獲数が減るので、牢獄を見張るのも有効です。

| 結果 | 条件 |
|---|---|
| 警官の勝利 | 全市民が牢獄に捕まった／市民が全員ログアウトした |
| 市民の勝利 | 制限時間が切れた／警官が全員ログアウトした |

## 参加方法

ゲームへの参加は次の2通りです。

- **参加看板をクリック** … ロビーに設置された「[ドロケイ]」看板を右クリックすると、そのロビーに参加できます。
- **コマンドで参加** … `/dorokei join <ロビーID>` でロビーに参加します。`/dorokei join` だけ打つと利用可能なロビー一覧が表示されます。

参加するとロビー地点へテレポートされます。ゲーム開始を待ちましょう。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/dorokei join <ロビーID>` | 指定したロビーに参加する |
| `/dorokei leave` | ロビーから退出して元の位置に戻る |
| `/dorokei list` | ロビー・ゲームエリアの一覧を表示する |

`/dorokei` はエイリアス `/dk` でも実行できます。

!!! note "ゲーム中は退出できません"
    `/dorokei leave` で退出できるのは **ロビー待機中のみ** です。ゲーム開始後は退出できません。どうしても抜けたい場合はログアウトすると、次回ログイン時に元の位置へ戻されます。

## よくある質問

??? question "警官と市民は選べますか？"
    選べません。役割はゲーム開始時にランダムで割り振られます。警官の人数は参加人数に応じて自動で決まります（例：2〜4人で警官1人、5〜6人で2人など）。

??? question "捕まったらもう何もできませんか？"
    牢獄からは出られませんが、まだ捕まっていない仲間の市民が助けに来てくれれば復帰できます。20秒ごとに仲間へ救援メッセージが届くので、待ちましょう。

??? question "ゲームエリアの外に逃げられますか？"
    逃げられません。設定されたゲームエリアの外に出ようとすると自動的に押し戻されます。

??? question "ゲームが終わったらどうなりますか？"
    終了から5秒後に自動でロビーへ戻され、同じロビーへ自動で再参加した状態になります。続けて遊べます。

??? question "途中でログアウトしたらどうなりますか？"
    ゲーム／ロビーから離脱し、次回ログイン時に参加前の位置へ戻されます。残った人数によってはゲームが続行されますが、警官または市民が全員いなくなった場合はそこでゲームが終了します。
