# ナンプレ（Sudoku） ― 遊び方 { .page-player #sudoku-player }

床に敷かれた 9×9 の盤面を歩きながら、ホットバーの数字を持ち替えてマスを埋めていくナンプレ（数独）です。各行・各列・各 3×3 ブロックに 1〜9 を1つずつ入れればクリア。ソロ・対戦・協力・陣取りの4モードを遊べます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 盤面 | 床に敷かれた実物大 9×9（上を歩いて操作） |
    | 入れる | 数字を持って **マスを右クリック / タップ**（左クリックは使いません） |
    | メモ | スニークしながら右クリックで小さな数字を付け外し（自分だけに見える） |
    | モード | ソロ（1人）/ 対戦（早解き）/ 協力（みんなで1面）/ 陣取り（取り合い） |
    | 難易度 | 初級・中級・上級（毎回自動生成・答えは1つ） |
    | 参加方法 | 参加看板、または `/sudoku join` |
    | ソロ | ソロ看板、または `/sudoku solo`（難易度を選んですぐ挑戦） |

## どんなゲーム？

床に 9×9 の盤面が敷かれています。試合が始まると、ホットバーの 1〜9 に **数字** が配られます（アイテムの個数がそのまま数字）。数字を持ってマスを **右クリック（統合版はタップ）** すると、その数字が入ります。正解ならそのまま確定、不正解なら赤く表示されてミスです。各行・各列・各 3×3 ブロックに 1〜9 を1つずつ入れればクリア。問題は毎回自動で作られ、答えは必ず1つに決まります。

## 操作

盤面の上を歩いて、近く（約4ブロック以内）のマスを操作します。

| 操作 | 動き |
|---|---|
| 数字を持ってマスを右クリック | その数字を入れる。正解なら確定、不正解なら赤く1秒表示されてミス |
| スニークしながら右クリック | メモ（小さな数字）の付け外し。メモは **自分にだけ** 見える |
| 数字を持っているだけ | 盤面の同じ数字のマスが黄色く光る（置ける場所を探しやすく） |

- 画面下（アクションバー）に **残り時間・ミス数・空きマス数** が出ます。右のサイドバーには順位も出ます。
- 数字を9個そろえて使い切ると、その数字はホットバーから消えます（協力・陣取りは同じ盤面の全員で共有）。最初から9個そろっている数字は配られません。
- 入れた数字が地図に表示されるまで、最大0.5秒ほどかかることがあります。
- 完成すると、盤面が上の行から順に緑に光ります。

!!! tip "メモを活用しよう"
    どの数字が入るか迷うマスには、スニーク＋右クリックで候補をメモしておけます。メモは自分だけに見え、何度付け外ししてもミスになりません。

### マスの見分け方

| 見た目 | 意味 |
|---|---|
| 灰色の背景に黒い数字（床は石英） | 最初からある数字 |
| 白い背景に青い数字 | 正解して確定した数字 |
| 赤い背景に赤い数字（1秒） | 不正解（ミス） |
| 小さな灰色の数字 | 自分のメモ |
| 薄い色の背景（陣取り） | そのマスを取った人の色 |

## モード

| モード | 人数 | 勝ち | 負け・脱落 |
|---|---|---|---|
| ソロ | 1人 | 完成させたらクリア。タイムが自己ベストに残る | ミス3回で失格（記録なし） |
| 対戦 | 2人〜盤面の数 | いちばん先に完成させた人（生き残りが1人になったらその人） | ミス3回で脱落して観戦 |
| 協力 | 2〜8人 | 時間内に完成させたら全員の勝ち | チーム合計ミス5回、または時間切れで全員の負け |
| 陣取り | 2〜8人 | 正解して取ったマスがいちばん多い人 | ミス3回で脱落して観戦（取ったマスは残る） |

!!! note "ミス回数・制限時間・難易度について"
    上の表は既定値です。ミスの上限・制限時間・難易度はOPの設定で変わることがあります。

### 細かいルール

- **対戦** … 全員が同じ問題を、自分の盤面で解きます。自分の盤面にしか入力できません。終わり方は2通りで、OPが切り替えます。
    - **1位で終了** … 最初に完成した人が出た時点で終わり。2位以下は正解マス数の多い順。完成した人は盤面の上で待ちます。
    - **全員完成まで** … 全員が完成・失格するか時間切れまで続きます。完成した人は完成タイム順、まだの人はその後ろに正解マス数の順。
    - 時間切れは正解マス数（同じならミスが少ない順）で順位をつけます。
- **協力** … 誰が入れてもかまいません。正解したマスはその場で確定し、誰も変えられません。ミスはチームで数えます。結果には人ごとの正解マス数も出ます。
- **陣取り** … 先に正解した人がそのマスを取ります。入力には **0.5秒のクールダウン**（当てずっぽうの連打を防ぐため）があります。終わるのは、盤面が完成したとき・時間切れ・生き残りが1人以下になったとき。同じマス数なら、ミスが少ない人 → 最後に正解したのが早い人が上です。
- 試合中に離脱・切断すると、その場で脱落になります。ログインし直しても試合には戻れません（持ち物は戻ります）。
- 試合中に参加した人は、次の試合から参加します。

## ソロをすぐ遊ぶ

ソロ看板か `/sudoku solo` で難易度の選択画面が開きます。**初級・中級・上級** のボタンを押すと、空いている盤面へ移動して3秒後に始まります（ロビーに参加していなければ自動で参加します）。ボタンには自己ベストも表示されます。

- ロビーで待っている間は **ネザースター** を持っています。右クリック（統合版はタップ）でソロメニューを開けます。
- ソロが終わってロビーに戻ると、ソロメニューが自動で開きます。
- ソロ中はインベントリ上段に **ギブアップ（バリアブロック）** があります。右クリックでやめてメニューに戻れます。失格・ギブアップは記録に残りません。

## 観戦（脱落した人）

- 対戦・陣取りで脱落すると、生き残っている人の視点で観戦します。
- **スニーク** で見る相手を切り替えられます（生き残っている人だけ）。自由に飛び回ることはできません。
- 協力は脱落がないので観戦はありません。ソロは失格するとそのままロビーへ戻ります。

## ランキング（ソロ）

ソロをクリアすると、難易度ごとのランキングに自己ベストが残ります。順位はタイムが速い順で、同じタイムならミスが少ない人、それも同じなら先に出した人が上です。

| コマンド | 内容 |
|---|---|
| `/sudoku top` | 初級・中級・上級の上位3人ずつ |
| `/sudoku top easy`（`normal` / `hard`） | その難易度の上位10人と、自分の順位 |

- クリアすると、自分の順位がチャットに出ます。**1位を更新すると、サーバー全体にお知らせ** が流れます。
- ソロメニューのボタンにも、自己ベスト・自分の順位・1位のタイムが出ます。
- 失格・ギブアップは記録されません。報酬はありません。

## 参加方法

1. ロビーの **参加看板** をクリック、または `/sudoku join`。持ち物は預かられ、離脱すると元に戻ります。
2. **開始看板** をクリック、または `/sudoku start <モード>`（全員可）で、そのモードの試合が始まります。人数が揃っても自動では始まりません。
3. 試合が終わるとロビーへ戻り、続けて遊べます。

離脱は **離脱看板** か `/sudoku leave` です。試合中に離脱すると脱落扱いになります。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/sudoku join` | ロビーに参加する（参加看板と同等・全員可） |
| `/sudoku leave` | ロビーから離脱する（離脱看板と同等。試合中は脱落扱い・全員可） |
| `/sudoku start <versus\|coop\|territory> [easy\|normal\|hard]` | ゲームを開始する（開始看板と同等・全員可。難易度省略時はモードの既定難易度） |
| `/sudoku solo` | ソロの難易度選択画面を開く（ソロ看板と同等） |
| `/sudoku top [easy\|normal\|hard]` | ソロのランキング（省略時は3難易度の上位3人ずつ） |
| `/sudoku refresh` | 近くの盤面（試合中は自分の盤面）の表示を送り直す（統合版でマスが出ないとき用） |
| `/sudoku status` | 現在の設定・状況を確認する（全員可・読み取り専用） |

## よくある質問

??? question "数字はどうやって入れますか？"
    ホットバーに配られた 1〜9 の数字を、数字キーやスクロールで持ち替え、入れたいマスを **右クリック（統合版はタップ）** します。左クリックは使いません。数字を持っている間は、盤面の同じ数字のマスが黄色く光ります。

??? question "メモ（候補）は相手に見えますか？"
    いいえ。メモは **自分にだけ** 見えます。スニークしながら右クリックで付け外しでき、何度付け外ししてもミスにはなりません。

??? question "1人でも遊べますか？"
    はい。ソロ看板か `/sudoku solo` で、難易度を選んでタイムアタックに挑戦できます。自己ベストが難易度ごとのランキングに残ります。

??? question "統合版で一部のマスがオレンジのアイコンのままです。"
    額縁の地図がうまく届かなかった可能性があります。試合開始の数秒後に自動で送り直しますが、直らないときは盤面のそばで `/sudoku refresh` を実行してください。

??? question "数字のマークが横向き・逆さに見えます。"
    盤面の向きの問題です。OPに連絡してください（config の盤面の向き補正で直せます）。
