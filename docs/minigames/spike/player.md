# SPIKE ― 遊び方 { .page-player #spike-player }

攻撃側と防衛側に分かれ、スパイク（爆弾）の **設置** と **解除** を競うチーム対戦です。ラウンドごとに攻守が入れ替わり、先に5ラウンド取ったチームが勝ちます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | チーム対戦（赤チーム vs 青チーム） |
    | 役割 | 攻撃側＝スパイク設置 / 防衛側＝スパイク解除（ラウンドごとに交代） |
    | 勝利条件 | 先に5ラウンド先取（延長なし） |
    | ラウンドの流れ | 購入フェーズ（既定15秒）→ 戦闘フェーズ（既定100秒） |
    | スパイク | 設置 既定4秒 / 解除 既定7秒（半分の3.5秒まで進めば中断しても次回継続） |
    | 参加方法 | ロビーの参加看板、または `/spike join` |

## どんなゲーム？

試合が始まると全員が **赤チーム / 青チーム** のどちらかに分かれ、片方が攻撃側・片方が防衛側になります。各ラウンドはまず **購入フェーズ**、続いて **戦闘フェーズ** の順で進みます。

- **攻撃側** は、マップに置かれた **スパイク** を拾って運び、**設置サイト（A・B など）の中** で設置します。設置後、爆発するまで守り切れば勝ちです。
- **防衛側** は、攻撃側を倒して設置を防ぐか、設置された **スパイクを解除** すれば勝ちです。

ラウンドが決着すると攻守が入れ替わり、先に **5ラウンド** 取ったチームが試合に勝利します（延長はありません）。

## ラウンドの流れ

1. **購入フェーズ（既定15秒）** … 自分のスポーンエリアの中で、ショップ（エメラルド）を右クリックしてアーマーを買えます。このフェーズ中は **購入境界の外へ出られません**。
2. **戦闘フェーズ（既定100秒）** … 境界が開き、戦闘開始。攻撃側はスパイクの設置を、防衛側はその阻止を狙います。時間切れになった場合は **防衛側の勝ち** です。
3. **設置後（爆発タイマー 既定30秒）** … スパイクが設置されると爆発タイマーが動きます。防衛側が解除すれば防衛側の勝ち、時間切れで爆発すれば攻撃側の勝ちです。爆発の **範囲内（既定8ブロック）にいる生存者は、敵味方問わず即死** します（ブロックは壊れません）。
4. 決着後は短いインターバル（既定5秒）をはさみ、攻守を入れ替えて次のラウンドへ進みます。

## スパイクの設置・解除

- **拾う／運ぶ** … スパイクは攻撃側だけが拾えます（生存中・購入/戦闘フェーズ）。固定スロットに入り、`Q` キーで落として味方に渡せます。
- **設置（攻撃側）** … 設置サイトの中でスパイクを持ち、**スニークし続ける** と設置ゲージが進みます（既定4秒）。スニークを離す・移動する・アイテムを持ち替える・サイトの外に出ると中断し、ゲージは0に戻ります。
- **解除（防衛側）** … **解除用ハサミ** を持ち、設置されたスパイクの近く（既定1.2ブロック以内）で **スニークし続ける** と解除ゲージが進みます（既定7秒）。同時に解除できるのは1人だけです。
- **ハーフ解除** … 解除が **半分（既定3.5秒）** まで進んでいれば、中断してもそこまでの進捗が保存され、次回はその地点から再開できます。

## ショップ（購入フェーズ）

購入フェーズ中、生存していればショップ（エメラルド）を右クリックで開けます。買えるのは **アーマー3種** で、追加の黄色いハート（衝撃吸収）が付きます。**購入の取り消し・返金はできません**。

| アーマー | 価格 | 効果 |
|---|---|---|
| ライトアーマー | 40 | 追加ハート +5 |
| 回復アーマー | 65 | 追加ハート +5／しばらくダメージを受けないとアーマーが回復（1ラウンド合計5ハートまで） |
| ヘヴィアーマー | 100 | 追加ハート +10 |

!!! note "クレジットの増え方"
    クレジットは試合開始時に80、各ラウンドで増えます。**ラウンド勝利で +100**、**敗北でも連敗に応じて +60 → +80 → +100**、**キルで +10**、スパイク設置で **攻撃側全員に +10**（死亡中を含む）。所持上限は900です。アーマーは死亡すると失い、ライト/ヘヴィは次のラウンドに持ち越せません。

## ロール（役職）

編成看板や `/spike` の役職選択から、4つのロールを選べます（**全員が選ぶまで試合は始まりません**。同じロールを何人でも選べます）。

| ロール | タイプ |
|---|---|
| デュエリスト | ジェット型 |
| イニシエーター | ソーヴァ型 |
| コントローラー | ブリムストーン型 |
| センチネル | セージ型 |

各ロールには無料スキル・購入スキル・ULT が用意されています（ULT はキル・設置・解除・被撃破などでポイントが貯まり、既定5ポイントで使用可能）。

## 戦闘（弓・剣）

- **弓** … 長押しで引き絞り、離して発射。装弾数は既定10発で、撃ち切ると自動リロード（既定2秒・リロード中は移動が遅くなります）。左クリックで手動リロードもできます。残弾はレベル表示に出ます。
- **木の剣** … 持っている間だけ移動速度が少し上がります（既定 +10%）。1撃のダメージは既定4（2ハート）。
- 味方への弓・剣は当たりません（ノックバックも無し）。自然回復はなく、満腹度も減りません。

## 死亡と観戦

- 倒されたラウンドは脱落し、**味方の視点を観戦** します（スニークで観戦対象を切り替え）。次のラウンドの購入フェーズから復帰します。
- キルは、直接倒した相手のほか、**最後にダメージを与えた敵**（既定10秒以内）にも記録されます。

## 参加方法

1. ロビーの **参加看板** をクリック、または `/spike join`。
2. **編成看板** から役職を選ぶ（全員が選ぶまで開始できません）。
3. **開始看板** のクリック、または `/spike start`（全員可）で開始。自由選択モードではチーム選択の時間（既定20秒）があります。

離脱は **離脱看板** か `/spike leave` です。試合中に離脱すると脱落（死亡）扱いになり、戻れません。試合が進行中のときに参加した場合は、次の試合から参加できます。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/spike join` | ロビーに参加する（参加看板と同等・全員可） |
| `/spike leave` | ロビーから離脱する（離脱看板と同等。試合中は脱落扱い・全員可） |
| `/spike start [マップ] [random\|select]` | ゲームを開始する（開始看板と同等・全員可） |
| `/spike status` | 現在の設定・状況を確認する（全員可・読み取り専用） |

## よくある質問

??? question "攻撃側と防衛側は固定ですか？"
    いいえ。ラウンドごとに攻守が入れ替わります。片方の役割だけを担当し続けることはありません。

??? question "自分で用意した装備は使えますか？"
    いいえ。試合中の手持ちは配られた弓・剣・ショップ（と防衛側のハサミ・攻撃側のスパイク）だけです。ロビーに入った時点で元の持ち物は安全に預かられ、離脱すると元どおり戻ります。

??? question "買ったアーマーは次のラウンドも残りますか？"
    ライトアーマーとヘヴィアーマーは、そのラウンドで使い切らなかった分も **次のラウンドには持ち越せません**。死亡してもアーマーは失います。毎ラウンドの購入フェーズで買い直してください。

??? question "設置／解除がなかなか進みません。"
    設置はサイトの中で、解除はスパイクのすぐ近くで、どちらも **スニークし続ける** 必要があります。移動したり、アイテムを持ち替えたりすると中断します。解除は半分まで進んでいれば進捗が保存されます。

??? question "スパイクが爆発したらどうなりますか？"
    攻撃側の勝ちです。さらに爆心地の周囲（既定8ブロック）にいる生存者は敵味方問わず即死しますが、ブロックは壊れません。
