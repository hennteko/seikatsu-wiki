# SPIKE <span class="badge done">公開中</span>

**攻撃側 vs 防衛側** に分かれ、攻撃側は **スパイク（爆弾）を設置**、防衛側は **設置されたスパイクを解除** して競う、Valorant 風のチーム対戦ミニゲームです。ラウンドごとに攻守が入れ替わり、**5ラウンド先取** で勝利。購入フェーズに貯めたクレジットでアーマーを買い、弓と剣で撃ち合います。

!!! note "ゲームの特徴"
    各ラウンドは **購入フェーズ → 戦闘フェーズ** の順に進みます。攻撃側はマップに置かれた **スパイク** を拾い、設置サイト（A/B など）の中でスニークし続けて設置します。設置後は爆発タイマーが動きだし、防衛側が **解除用ハサミ** で解除すれば防衛側の勝ち、時間切れ・爆発すれば攻撃側の勝ちです。戦闘は **弓（残弾・リロードあり）** と **木の剣** で行い、死亡したラウンドは味方を観戦して次のラウンドから復帰します。ラウンドごとに攻守が入れ替わり、先に **5ラウンド** 取ったチームが勝利します。
