# シノビ鬼（ShinobiOni） ― OP・運営ガイド { .page-op #shinobioni-op }

シノビ鬼の導入・会場づくり・地点と看板の設定・管理ツール・config・権限・管理コマンドをまとめます。地点・看板はコマンドで登録すると即 config に自動保存されます。

## 基本情報

| 項目 | 値 |
|---|---|
| プラグイン名 | ShinobiOni |
| バージョン | `${project.version}`（ビルド時に決定） |
| メインコマンド | `/shinobi`（エイリアス `/shinobioni`） |
| api-version | 26.2 |
| softdepend | `floodgate`（統合版の判定に使用） |
| 設定ファイル | `plugins/ShinobiOni/config.yml`（数値・地点・看板） |
| 文言ファイル | `plugins/ShinobiOni/messages.yml` |
| 忍術ファイル | `plugins/ShinobiOni/skills.yml` |
| 権限ノード | `shinobioni.admin`（既定OP） |

!!! info "設定ファイルの自動更新"
    プラグインを更新すると、起動時に config.yml・messages.yml・skills.yml の **足りない項目だけ** が追記されます（今の値は変わりません）。変更があったときは `config.yml.bak` などに更新前のファイルが残ります。地点・看板などのデータ領域は補完対象外です。

## 導入手順

1. `ShinobiOni-<版>.jar` をサーバーの `plugins/` フォルダに置いてサーバーを起動する。
2. 起動すると `config.yml`・`messages.yml`・`skills.yml` が自動生成される（数値は初期値で動作）。
3. 下の「セットアップ手順」で地点と看板を設定する。
4. `/shinobi status` で「開始できます」と出れば準備完了。

!!! note "試合に必須の設定"
    1試合を開始可能にするには、**ロビー・フィールド範囲（角1/角2）・シノビ開始地点（1か所以上）・オニ開始地点（1か所以上）・参加/開始看板** が必要です。初期スポーン（離脱・切断時の戻り先）も設定しておきます。未設定の項目は `/shinobi status` に表示されます。

!!! info "PvP 設定は不要"
    捕獲は攻撃の直前のイベントで判定するため、会場のワールドが PvP 無効でも捕獲できます。ダメージはプラグインがすべて無効にします。

## 会場づくりの目安

- オニは **約10ブロック**（既定）まで跳べます。11ブロック以上の高所を作る場合は、オニが登れる階段や足場を必ず用意してください（シノビの安全地帯になってしまうため）。
- 壁キックで登れる **狭い路地** と、天井が低くオニの高ジャンプが生きない **屋内** を混ぜると、シノビにも逃げ道ができます。
- フィールド範囲の外には出られません（高さも含めて判定し、出たら直前の位置へ戻します）。角1と角2の高さの差が3ブロック未満のときは、上はワールドの高さ上限まで有効になります。高さも制限したい場合は、角2を天井の高さで設定してください。外周にバリアを使う必要はありません（バリアブロックは壁キックの対象外）。
- 試合中はアドベンチャーモードです。ブロックの破壊・設置はできません。
- 参加中（ロビー待機を含む）は、コンテナを開けず、落ちているアイテムも拾えません（持ち物復元で消えてしまうため）。
- 奈落に落ちた参加者は、試合中なら会場内へ、それ以外はロビーへ戻されます。

## セットアップ手順（コマンド）

OP権限（`shinobioni.admin`）で、設定したい場所に **立って** 実行します。すべて config.yml に即保存されます。看板系は看板を **見ながら**（5ブロック以内）実行します。管理メニューのボタンでも同じ設定ができます。

```text title="初期スポーン（離脱・切断時の戻り先／その場に立って実行）"
/shinobi setstartspawn
```

```text title="ロビー（その場に立って実行）"
/shinobi setlobby
```

```text title="フィールド範囲 角1（その場に立って実行）"
/shinobi setfield 1
```

```text title="フィールド範囲 角2（その場に立って実行）"
/shinobi setfield 2
```

```text title="シノビの開始地点を追加（何か所でも。ランダムに散らばる）"
/shinobi setspawn shinobi
```

```text title="オニの開始地点を追加（1か所以上）"
/shinobi setspawn oni
```

```text title="シノビ開始地点を全消去（5秒以内に2回）"
/shinobi clearspawn shinobi
```

```text title="オニ開始地点を全消去（5秒以内に2回）"
/shinobi clearspawn oni
```

```text title="参加看板を登録（看板を見て実行）"
/shinobi setsign join
```

```text title="離脱看板を登録（看板を見て実行）"
/shinobi setsign leave
```

```text title="開始看板を登録（看板を見て実行）"
/shinobi setsign start
```

```text title="視線先の看板の登録を解除"
/shinobi setsign delete
```

```text title="設定状況を確認"
/shinobi status
```

!!! note "看板について"
    看板の文字はプラグインが書き込みます（人数・状態を自動で更新）。登録した看板は OP 以外は壊せません。OP が壊すと登録も解除されます。開始地点を消すときは同じ `clearspawn` を5秒以内に2回実行します。

## 管理ツール・管理メニュー（コマンドを打たない設定）

`/shinobi wand` で管理ツール（ブレイズロッド）を受け取り、**右クリック（統合版はタップ/長押し）** で管理メニューを開きます。`/shinobi menu` でも開けます。どちらも `shinobioni.admin` 権限が必要です。

```text title="管理ツール（ブレイズロッド）を受け取る"
/shinobi wand
```

```text title="管理メニュー（GUI）を開く"
/shinobi menu
```

- **数値（1ページ目）** … ＋/−ボタンで最低開始人数・最大参加人数・オニの人数・本編／百鬼夜行の時間・出血タイマー（1回目／2回目／3回目以降）・出血停止の半径／上限・オニの移動速度／跳躍のレベル・シノビの移動速度のレベルを変更（即保存）。
- **地点（2ページ目）** … ボタンを押すと立ち位置に設定（ロビー／初期スポーン／フィールド角1・2／シノビ開始地点を追加／オニ開始地点を追加）。
- **看板（2ページ目）** … 看板を見ながら（5ブロック以内）押すと参加／離脱／開始看板を登録、ハサミで登録解除。
- **運用（2ページ目）** … 開始・設定状況・リロード・強制停止・百鬼夜行へ移行（テスト用）・開始地点の全消去（強制停止・百鬼夜行へ移行・全消去は5秒以内に2回押し）。

!!! note "管理ツールの注意"
    ロビーで待機している間も受け取れます（試合中・観戦中は受け取れません）。試合が始まると持ち物と一緒に回収され、ロビー待機中に受け取った場合はロビーから抜けたときに自動で手元に戻ります。捨てると消えるので、再度 `/shinobi wand` で取得します。統合版はチェストGUIで操作でき、数値は＋/−の別ボタンで増減します。

## config.yml 設定項目

コマンドで登録する地点・看板（`default-spawn`・`lobby-spawn`・各 `*-sign`・`arena`）は自動保存されます。手書き不要です。先頭の `config-version` は設定ファイルの版で、**手で変えないでください**。以下は数値などの設定項目です。

### 人数・進行

| キー | 既定値 | 説明 |
|---|---|---|
| `min-players` | 4 | 最低開始人数（2まで下げられる） |
| `max-players` | 16 | 最大参加人数 |
| `oni-count` | 0 | オニの人数（0＝人数から自動：4〜6人→1、7〜11人→2、12人以上→3） |
| `start-countdown` | 10 | 開始操作の後のカウントダウン（秒） |
| `skill-select-time` | 15 | 忍術を選ぶ時間（秒） |
| `oni-release-delay` | 10 | 開始時にオニが待機する時間（秒・盲目と移動不可） |
| `main-time` | 300 | 本編の時間（秒） |
| `hyakki-time` | 60 | 百鬼夜行の時間（秒） |
| `result-seconds` | 8 | 結果発表からロビーへ戻るまで（秒） |

### 捕獲・救助・出血（`capture`/`rescue`/`bleed`）

| キー | 既定値 | 説明 |
|---|---|---|
| `capture-grace` | 3 | 捕獲直後に救助を始められない時間（秒） |
| `rescue-radius` | 2.0 | 救助できる距離（マス） |
| `rescue-time` | 3 | 1人で救助にかかる時間（秒。2人で1.5倍、3人以上で2倍の速さ） |
| `rescue-decay` | 33 | 範囲に誰もいないとき1秒で減る救助の進行度（%） |
| `rescue-invincible` | 3 | 救助直後に捕獲されない時間（秒） |
| `bleed-time.first` / `second` / `after` | 30 / 20 / 10 | 捕獲回数ごとの出血タイマー（秒） |
| `bleed-pause.radius` / `height` / `max` | 8.0 / 4.0 / 20 | 出血停止の水平距離・高さの差（マス）・1回の上限（秒） |

### オニ・シノビ（`oni`/`shinobi`）

| キー | 既定値 | 説明 |
|---|---|---|
| `oni.speed-level` | 3 | オニの移動速度上昇のレベル（常時） |
| `oni.jump-level` | 9 | オニの跳躍上昇のレベル（9で約10ブロック） |
| `oni.hit-cooldown` | 1.0 | 捕獲後に次を捕まえられない時間（秒） |
| `oni.promote-delay` | 3 | 昇格したオニの待機時間（秒） |
| `shinobi.speed-level` | 1 | シノビの移動速度上昇のレベル（0で無し） |

### 壁キック（`wallkick`）

| キー | 既定値 | 説明 |
|---|---|---|
| `wallkick.trigger` | SNEAK | 発動入力（SNEAK＝空中スニーク / JUMP＝空中ジャンプ / BOTH） |
| `wallkick.horizontal` | 0.45 | 壁から離れる速さ |
| `wallkick.vertical` | 0.75 | 上向きの速さ（2回目は×0.85） |
| `wallkick.max-chain` | 2 | 1回の空中で使える回数（着地でリセット） |
| `wallkick.cooldown-ticks` | 6 | 連続入力防止（tick） |

### 忍術（`nawabiki`／数値は skills.yml）

| キー | 既定値 | 説明 |
|---|---|---|
| `nawabiki.block-radius` | 6.0 | 自分の周りこの距離にオニがいると縄引きを使えない（マス） |

忍術そのものの名前・アイテム・クールダウン・説明文、1つの忍術を選べる人数の割合（`limit-ratio`、既定0.5）は `skills.yml` で変更します。既定の忍術は **空蝉（FEATHER・CD60秒）** と **縄引き（LEAD・CD60秒）** です。

### 百鬼夜行・最後の1人（`hyakki`/`last-one`）

| キー | 既定値 | 説明 |
|---|---|---|
| `hyakki.oni-speed-level` | 4 | 百鬼夜行中のオニの移動速度上昇レベル |
| `hyakki.oni-hit-cooldown` | 0.5 | 百鬼夜行中の捕獲クールダウン（秒） |
| `hyakki.glowing` | true | シノビに発光を付ける（Java版向け。統合版は輪郭が出ない） |
| `hyakki.beacon-interval` | 2 | シノビの位置を知らせるパーティクル柱の間隔（秒） |
| `hyakki.bleed-multiplier` | 2.0 | 百鬼夜行中に出血タイマーが減る速さの倍率 |
| `last-one.beacon-interval` | 4 | 最後の1人のときの柱の間隔（秒） |
| `last-one.cooldown-multiplier` | 0.5 | 最後の1人のときの忍術クールダウン倍率 |

### 情報・観戦（`heartbeat`/`oni-hint`/`idle`/`spectate`）

| キー | 既定値 | 説明 |
|---|---|---|
| `heartbeat.radius` | 16.0 | オニがこの距離に入ったシノビに心音を鳴らす（マス。0で無効） |
| `oni-hint.interval` | 120 | オニに最も近いシノビの方角を出す間隔（秒。0で無効） |
| `idle.seconds` / `radius` | 30 / 3.0 | 同じ場所にこの秒数いると足元から煙（秒・マス。0で無効） |
| `spectate.bedrock-follow-teleport` | true | 統合版の観戦者を TP で追いかける方式にする |
| `display-name` | `&5【シノビ鬼】` | 参加中の名前の【】部分 |
| `debug` | false | 壁キック・救助・出血停止をログに出す |

## 権限ノード

| 権限ノード | 既定 | 用途 |
|---|---|---|
| `shinobioni.admin` | OP | セットアップ・看板・管理ツール・管理メニュー・`clearspawn`・`setfield`・`hyakki`・`stop`・`reload`・`lobbyfix` など管理系すべて |

!!! info "権限不要で全員が使えるコマンド"
    `/shinobi join`・`/shinobi leave`・`/shinobi start`・`/shinobi status` は権限チェックがなく、全プレイヤーが使えます。`start` はコンソール・コマンドブロックからも実行できます。

## 決着と途中離脱（運営向けの補足）

- **シノビの勝ち** … 百鬼夜行の終了時に動けるシノビが1人以上いる／オニが全員抜けて昇格させられるシノビがいない（不戦勝）。
- **オニの勝ち** … 動けるシノビが0人（全員が捕獲中か脱落）。
- オニが0人になったら、動けるシノビから1人をオニに昇格させて続けます（待機 既定3秒）。
- 試合中の leave・切断は脱落扱い。持ち物を戻して初期地点へ送り、試合には戻しません。
- `/shinobi stop` は勝敗をつけずに止め、在籍者全員をロビーへ戻します（在籍は維持）。
- 百鬼夜行の夜は在籍者だけに付きます。ワールドの時刻は変えません。

## トラブルシューティング

??? failure "ゲームが開始できない"
    `/shinobi status` を確認してください。ロビー・フィールド範囲・シノビ/オニの開始地点がすべて設定済みで、ロビーに最低開始人数以上いる必要があります。

??? failure "ロビーに入る前の持ち物が戻らない"
    参加中にサーバーが落ちた場合は、次回ログイン時に自動で戻ります。戻らない場合は対象がオンラインで参加していないときに `/shinobi lobbyfix <プレイヤー>` で復旧できます。どうしても戻らない場合のみ `force` を付けると退避データを破棄して参加中フラグだけ外します（最終手段）。

## 全ゲーム共通の改修

全ミニゲーム共通のコード（`MinigameCommon`）が組み込まれており、本ゲームにも適用されています。

- **名前表示** … 参加中はチャット名・Tabリスト名・頭上の名札が「【シノビ鬼】名前」になり、離脱で元に戻ります（`display-name` で変更）。
- **参加/離脱の全体告知** … 参加・離脱時にサーバー全体へ通知します（文言は `messages.join-broadcast` / `leave-broadcast`）。
- **同時参加は1ゲームまで** … 他ミニゲームに参加中は参加が拒否されます（「○○ に参加中です」）。サーバー共通のスコアボードタグで所有権を管理します。
- **持ち物のファイル退避** … ロビー入場時に所持品を `plugins/ShinobiOni/vault/<UUID>.yml` に退避し、**サーバークラッシュ後の再ログインでも復元** します（参加中だけ存在）。異常時はOPが `/shinobi lobbyfix <プレイヤー> [force]` で復旧します。
- **config の自動追記（ConfigUpdater）** … 起動時に不足項目を既定値＋コメント付きで自動追記します（既存の値は変更せず、更新時は旧ファイルを `.bak` に退避）。地点・看板などのデータ領域は補完対象外です。
- **統合版対応** … Floodgate 経由の統合版プレイヤーに対応します（壁キック・忍術・観戦の挙動を統合版向けに切り替え）。Floodgate 未導入時は名前の接頭辞で統合版と見なします。
- **観戦** … 脱落者は生存シノビの視点を観戦します（スニークで対象切り替え）。統合版は `spectate.bedrock-follow-teleport` で追従TP方式に切り替えます。
