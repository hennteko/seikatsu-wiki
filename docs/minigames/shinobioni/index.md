# シノビ鬼（ShinobiOni） <span class="badge done">公開中</span>

逃げる **シノビ** と追う **オニ** に分かれる **非対称の鬼ごっこ** です。シノビは **壁キック** で高所へ逃げ、捕まった仲間を **救助** し、**忍術（空蝉・縄引き）** で仲間のもとへ駆けつけながら最後まで生き残ることを目指します。本編のタイマーが0になると最終局面 **百鬼夜行** に入り、オニが強くなってシノビの位置がばれやすくなります。

!!! note "ゲームの特徴（壁キック × 救助 × 忍術 × 百鬼夜行）"
    オニは **移動速度上昇III** と **約10ブロックの高ジャンプ** で追いかけ、素手で叩いてシノビを **捕獲** します。シノビは **移動速度上昇I** に加え、**壁キック**（空中で壁に接してスニークすると跳ね上がる）と **忍術** で振り切ります。捕まったシノビはその場で動けなくなり、仲間が近くに立てば **救助**、救助されないまま出血タイマーが0になると **脱落** です。本編の時間が切れると **百鬼夜行** が始まり、オニの速度が上がりシノビの位置がパーティクルの柱でばれやすくなります。百鬼夜行の終了まで1人でも生き残ればシノビの勝ち、シノビ全員を同時に「捕獲中・脱落」にできればオニの勝ちです。
