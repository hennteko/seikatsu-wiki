# シノビ鬼（ShinobiOni） ― 遊び方 { .page-player #shinobioni-player }

逃げる **シノビ** と追う **オニ** に分かれる鬼ごっこです。百鬼夜行の終了まで1人でも捕まらずに残ればシノビの勝ち、シノビ全員を同時に「捕獲中・脱落」にできればオニの勝ちです。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 4〜16人（推奨8〜12人） |
    | 1試合の長さ | 本編5分 → 百鬼夜行1分（既定） |
    | 役割 | オニ（追う）／シノビ（逃げる） |
    | 勝利条件 | シノビ：百鬼夜行の終了まで動けるシノビが1人以上／オニ：シノビ全員を同時に捕獲中・脱落にする |
    | 捕獲 | オニがシノビを素手で叩く（ダメージはなし） |
    | 参加方法 | ロビーの参加看板、または `/shinobi join` |

## どんなゲーム？

シノビ（逃げる側）とオニ（追う側）に分かれます。オニは足が速く高く跳べますが、シノビは **壁キック** と **忍術** を駆使して逃げ回り、捕まった仲間を **救助** しながら生き残ります。ゲーム中は落下を含むすべてのダメージが無効で、空腹にもなりません。

## ゲームの流れ

1. **参加する** … 参加看板をクリック、または `/shinobi join`。持ち物は預かられ、離脱時に戻ります。
2. **開始** … 開始看板か `/shinobi start`。人数がそろっても自動では始まりません。開始操作のあと約10秒（既定）のカウントダウンがあります。
3. **役割発表** … オニの人数は参加人数で決まります（4〜6人→1人、7〜11人→2人、12人以上→3人）。直前の試合でオニだった人は選ばれにくくなっています。
4. **準備（既定15秒）** … シノビは忍術と、忍術の対象にする味方を選びます。選ばなかった人には自動で割り当てられます。ネザースターを右クリックすると選び直せます。
5. **本編（既定5分）** … シノビは会場に散らばります。オニは最初の既定10秒間、目隠しされて動けません。
6. **百鬼夜行（既定1分）** … 本編のタイマーが0になると突入します。
7. **決着** … 結果発表のあとロビーへ戻ります。参加状態は続くので、そのまま次の試合に出られます。

## 移動能力

| 陣営 | 移動速度 | ジャンプ | 特技 |
|---|---|---|---|
| オニ | 移動速度上昇III（百鬼夜行ではIV） | 約10ブロックの高ジャンプ | — |
| シノビ | 移動速度上昇I | 通常 | 壁キック・忍術 |

- 直線ではオニのほうが速いので、シノビは **壁キック・忍術・曲がり角** で振り切ります。天井の低い屋内では、オニの高ジャンプは役に立ちません。
- 落下ダメージを含め、ゲーム中のダメージはすべて無効です。空腹にもなりません。

### 壁キック（シノビのみ）

**空中で壁に接しているときにスニーク** すると、壁と反対向き・上向きに跳ね上がります。

- 1回の空中で **2回まで**（既定）使えます。地面に着くとリセットされます。
- フェンス・ガラス板・階段も「壁」として蹴れます。バリアブロックは蹴れません。

## 捕獲と救助

### 捕まると

- オニに叩かれると「捕獲中」になり、その場から動けません（向きは変えられます）。空中で捕まると、真下の足場に下ろされます。
- 頭上に **炎のパーティクル** が出て、仲間に居場所が分かります。
- アクションバーに **出血タイマー**（脱落までの残り時間）が出ます。**1回目30秒、2回目20秒、3回目以降10秒**（既定）と、捕まるたびに短くなります。
- 捕獲中は忍術を使えません。

### オニが近くにいると出血タイマーが止まる

- 捕獲中の人の近く（既定で水平8マス以内・高さの差4マス以内）にオニがいる間は、出血タイマーが止まります。このときパーティクルは **煙** に変わります。
- 止まるのは **1回の捕獲につき合計20秒まで**（既定）です。それを過ぎると、オニが近くにいてもタイマーは進みます。

### 救助する

- 捕獲中の仲間の **2マス以内（既定）に立ち続ける** と救助できます（1人なら既定3秒）。2人なら1.5倍、3人以上なら2倍の速さになります。
- 捕まった直後の **3秒間（既定）** は救助を始められません。
- 範囲から出ても進行度はすぐには消えず、少しずつ減ります。救助していた人が捕まったときだけ0に戻ります。
- 救助された人は、その後 **3秒間（既定）** 捕まりません。

### 脱落すると

- 出血タイマーが0になると脱落し、残っているシノビの **視点で観戦** します。**スニークで次のシノビに切り替え** られます。
- 自由に飛び回ることはできません。オニの視点にもできません。

## 忍術

準備時間に1つ選びます。1つの忍術を選べるのは **シノビの人数の半分まで**（既定）です。

| 忍術 | 効果 | クールダウン |
|---|---|---|
| 空蝉（羽根） | 対象の味方の場所へテレポート。元の場所に煙を残す | 既定60秒 |
| 縄引き（リード） | 対象の味方を自分の場所へ引き寄せる | 既定60秒 |

- **右クリック** で、いま選んでいる味方に発動します。
- **スニーク＋右クリック** で、対象の味方を選び直す画面が開きます。
- 捕獲中の味方には使えません。対象が捕まっていたら選び直してください。
- 移動した直後の1秒間は捕まりません。ただし、その間は救助も始められません。
- **縄引き** は、自分の周り6マス以内（既定）にオニがいると使えません。引き寄せられる側には1秒前に予告が出て、その間に **スニークすると拒否** できます。拒否されると、使った人のクールダウンは半分になります。

## 百鬼夜行（最終局面）

- 空が夜になり、オニの移動速度が上昇IV（既定）になります。
- シノビの頭上から **上空へ伸びるパーティクルの柱** が2秒ごと（既定）に出て、位置がばれます（Java版は発光も付きます）。
- 出血タイマーが減る速さが2倍（既定）になります。
- 最後まで逃げ切ればシノビの勝ちです。

## 情報と救済

- **心音** … オニが16マス以内（既定）に近づくと、シノビにだけ心音が聞こえます。近いほど速くなります。
- **方角ヒント（オニ）** … 本編中は2分ごと（既定）に、オニへ最も近いシノビの方角（北東など）が表示されます。
- **隠れすぎ** … シノビが同じ場所（半径3マス・既定）に30秒以上いると、足元から煙が出て位置がばれます。
- **最後の1人** … 動けるシノビが1人だけになると、忍術のクールダウンが半分になり、百鬼夜行の柱の間隔も4秒（既定）に延びます。

## 途中参加・離脱

- 試合中に参加した人はロビーで待機し、次の試合から参加します。
- 試合中に `/shinobi leave` やログアウトをすると、脱落扱いになります。持ち物は戻り、初期地点へ移動します。再ログインしても試合には戻れません。
- オニが全員抜けると、動けるシノビの中から1人が **オニに昇格** して試合が続きます。動けるシノビが1人以下ならシノビの不戦勝です。

## 参加方法

1. ロビーの **参加看板** をクリック、または `/shinobi join`。
2. **開始看板** のクリック、または `/shinobi start`（全員可）で開始。
3. シノビは準備時間に忍術と対象の味方を選ぶ。

離脱は **離脱看板** か `/shinobi leave` です。試合中に離脱すると脱落扱いになり、戻れません。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/shinobi join` | ロビーに参加する（参加看板と同等・全員可） |
| `/shinobi leave` | ロビーから離脱する（離脱看板と同等。試合中は脱落扱い・全員可） |
| `/shinobi start` | ゲームを開始する（開始看板と同等・全員可） |
| `/shinobi status` | 現在の設定・状況を確認する（全員可・読み取り専用） |

## 統合版（スマホ・Switch など）での違い

!!! note "統合版のプレイヤーへ"
    - **壁キック** はスニークで出します。スニークを「タップで切り替え」にしている人は、着地後もしゃがんだままになるので、もう一度タップして立ってください。
    - **忍術** はアイテムを長押し（使用）で発動します。対象の選び直しは「しゃがんだまま長押し」です。
    - **味方を選ぶ画面** で頭の見た目が出ないことがあります。アイテム名にプレイヤー名が出ているので、名前で選んでください。
    - **発光** の輪郭は表示されません。百鬼夜行ではパーティクルの柱で位置が分かります。
    - アイテムのクールダウン表示が出ないことがあります。残り秒数はアクションバーで確認できます。
    - **観戦** は、見ているシノビの背後に1秒ごとに移動して追いかける形になります。スニークで次のシノビに切り替えられます。

## よくある質問

??? question "オニとシノビはどうやって決まりますか？"
    参加人数からオニの人数が自動で決まり（4〜6人→1人、7〜11人→2人、12人以上→3人）、ランダムに選ばれます。直前の試合でオニだった人は選ばれにくくなっています。config で人数を固定することもできます。

??? question "捕まったらもう終わりですか？"
    いいえ。捕まると「捕獲中」になりその場で動けなくなりますが、仲間が2マス以内に立ち続けると救助され、復帰できます。出血タイマーが0になるまでに救助されれば大丈夫です。

??? question "オニに攻撃されるとダメージを受けますか？"
    受けません。捕獲は「叩く」操作で判定するだけで、落下を含めてゲーム中のダメージはすべて無効です。

??? question "縄引きを使おうとしても発動しません。"
    自分の周り6マス以内（既定）にオニがいると縄引きは使えません。また、引き寄せる相手が捕獲中だと使えないので、スニーク＋右クリックで対象を選び直してください。
