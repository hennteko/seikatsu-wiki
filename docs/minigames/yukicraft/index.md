# Yukicraft <span class="badge done">公開中</span>

雪ブロックを掘って相手を **最下層へ落とす** サバイバル系のミニゲームプラグインです。プレイヤーは雪のフィールドに立ち、足元の雪をシャベルで掘りながら、自分は落ちないように立ち回って最後の1人を目指します。

!!! note "ゲームの特徴"
    雪が複数の層に重なったフィールドで、足元の雪を掘って落とし合うバトルロイヤルです。掘れるのは雪ブロックだけで、落下ダメージは無効。Y座標0未満まで落ちると脱落します。さらに定期的にクリーパーが出現し、雪フィールドを崩していきます。参加・退出はコマンドのほか、専用看板のクリックでも行えます。
