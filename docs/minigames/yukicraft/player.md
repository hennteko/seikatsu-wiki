# Yukicraft ― 遊び方 { .page-player #yukicraft-player }

雪ブロックを掘って相手を下へ落とすバトルロイヤルです。足元の雪をシャベルで掘り、自分は落ちないように立ち回って最後の1人を目指しましょう。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 最大16人（既定。サーバー設定により変動） |
    | 勝利条件 | 最後の1人になる |
    | 脱落条件 | Y座標0未満まで落下する／クリーパー爆発などで死亡する |
    | 落下ダメージ | 無効（落ちても痛くない、落下＝脱落） |
    | 装備 | 開始時にダイヤのシャベルが1本配られます |

## どんなゲーム？

雪が複数の層に重なった専用フィールドで戦うバトルロイヤルです。

開始するとゲームフィールドの上空地点へテレポートし、ダイヤのシャベルが1本渡されます。足元やまわりの **雪ブロック** を掘って相手を下の層へ落とし、自分だけ生き残れば勝ちです。落ちて **Y座標0未満** まで到達したプレイヤーは脱落となり、観戦モードになります。

## ルール

- 掘れる・置けるのは **雪ブロックだけ** です。それ以外のブロックは破壊・設置できません。
- **落下ダメージは無効** です。下の層へ落ちてもダメージは受けません。あくまで「最下層（Y0未満）まで落ちる」と脱落です。
- ゲーム中はサバイバルモードになります。脱落すると観戦モードに切り替わります。
- 定期的に **クリーパー** が出現し、雪フィールドを崩していきます。爆発に巻き込まれて死亡しても脱落です。

!!! tip "落とし合いのコツ"
    自分の足場を残しつつ、相手の足元の雪を掘るのが基本です。下の層にも雪はありますが、層と層の間は空洞なので、うまく落とせば一気に最下層まで突き落とせます。

## 勝利条件

生き残っているプレイヤーが **1人だけ** になった時点で、その人が勝者です。勝者には「VICTORY!」のタイトルが表示されます。全員が同時に脱落した場合は勝者なしで終了します。

## 参加方法

参加・退出・開始は、ロビーの看板のクリックまたはコマンド（全員可）で行えます。

| 操作 | 方法 |
|---|---|
| 参加 | `[Yukicraft]` 参加看板をクリック／`/yukicraft join` |
| 離脱 | 離脱看板をクリック／`/yukicraft leave` |
| 開始 | 開始看板をクリック／`/yukicraft start` |

参加するとロビー地点へテレポートし、サイドバーに参加人数などが表示されます。ゲーム開始を待ちましょう。

!!! note "参加できないとき"
    ゲームがすでに進行中の場合や、参加人数が上限に達している場合は参加できません。次のゲームが始まるまで待ちましょう。

## ゲームの流れ

1. **参加する** — 参加看板のクリックでロビーに加わります。
2. **開始する／待つ** — 人数が集まったら誰かが `/yukicraft start` か開始看板で開始でき、全員が雪フィールド上空のスタート地点へテレポートします。
3. **シャベルを受け取る** — 開始時にダイヤのシャベルが配られます。これで雪を掘ります。
4. **掘って落とす** — 相手の足元の雪を掘って下へ落とし、自分は落ちないように立ち回ります。
5. **クリーパーに注意** — 一定間隔でクリーパーが出現します。爆発に巻き込まれないように動きましょう。
6. **生き残る** — Y0未満まで落ちる／死亡すると脱落（観戦モード）です。
7. **勝者決定** — 最後の1人になれば **勝利！** 一定秒数後にロビーへ戻ります。

## プレイヤー用コマンド

参加・退出・開始は看板のほか、コマンド（全員可）でも行えます：`/yukicraft join`・`/yukicraft leave`・`/yukicraft start`。

## よくある質問

??? question "雪以外のブロックが掘れません"
    仕様です。Yukicraft では **雪ブロック以外は破壊・設置できません**。掘れるのは雪だけです。

??? question "下の層に落ちてしまいました。脱落ですか？"
    すぐに脱落ではありません。脱落になるのは **Y座標0未満（最下層より下）** まで落ちたときです。下の層にも雪があるので、まだ生き残れる可能性があります。

??? question "落下でダメージを受けますか？"
    いいえ。ゲーム中の落下ダメージは無効化されています。怖がらず動いて大丈夫です。

??? question "クリーパーは何のためにいますか？"
    時間経過とともに雪フィールドを崩し、決着を早めるための仕掛けです。爆発に巻き込まれると死亡＝脱落になるので注意しましょう。

??? question "脱落したあとは何ができますか？"
    観戦モードになり、ゲームの様子を見られます。ゲーム終了後はロビーへ戻されます。
