# Yukicraft ― 遊び方 { .page-player #yukicraft-player }

雪ブロックを掘って相手を下へ落とすバトルロイヤルです。足元の雪をシャベルで掘り、自分は落ちないように立ち回って最後の1人を目指しましょう。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 最大16人（既定。サーバー設定により変動）／ソロ：1人 |
    | 勝利条件 | 最後の1人になる |
    | 脱落条件 | Y座標0未満まで落下する／クリーパー爆発などで死亡する |
    | 落下ダメージ | 無効（落ちても痛くない、落下＝脱落） |
    | 装備 | 開始時にダイヤのシャベルが1本配られます |

## どんなゲーム？

雪が複数の層に重なった専用フィールドで戦うバトルロイヤルです。

開始するとゲームフィールドの上空地点へテレポートし、ダイヤのシャベルが1本渡されます。足元やまわりの **雪ブロック** を掘って相手を下の層へ落とし、自分だけ生き残れば勝ちです。落ちて **Y座標0未満** まで到達したプレイヤーは脱落となり、観戦モードになります。

## ルール

- 掘れる・置けるのは **雪ブロックだけ** です。それ以外のブロックは破壊・設置できません。
- **落下ダメージは無効** です。下の層へ落ちてもダメージは受けません。あくまで「最下層（Y0未満）まで落ちる」と脱落です。
- ゲーム中はサバイバルモードになります。脱落すると観戦モードに切り替わります。
- 定期的に **クリーパー** が出現し、雪フィールドを崩していきます。爆発に巻き込まれて死亡しても脱落です。

!!! tip "落とし合いのコツ"
    自分の足場を残しつつ、相手の足元の雪を掘るのが基本です。下の層にも雪はありますが、層と層の間は空洞なので、うまく落とせば一気に最下層まで突き落とせます。

## 勝利条件

生き残っているプレイヤーが **1人だけ** になった時点で、その人が勝者です。勝者には「VICTORY!」のタイトルが表示されます。全員が同時に脱落した場合は勝者なしで終了します。

## 参加方法

参加・退出・開始は、ロビーの看板のクリックまたはコマンド（全員可）で行えます。

| 操作 | 方法 |
|---|---|
| 参加 | `[Yukicraft]` 参加看板をクリック／`/yukicraft join` |
| 離脱 | 離脱看板をクリック／`/yukicraft leave` |
| 開始 | 開始看板をクリック／`/yukicraft start` |

参加するとロビー地点へテレポートし、サイドバーに参加人数などが表示されます。ゲーム開始を待ちましょう。

!!! note "試合中に参加したとき"
    ゲームがすでに進行中でも参加（ロビー入り）できます。その試合には加わらず、**次の試合から** 参加になります。参加人数が上限に達している場合は参加できません。

## ゲームの流れ

1. **参加する** — 参加看板のクリックでロビーに加わります。
2. **開始する／待つ** — 人数が集まったら誰かが `/yukicraft start` か開始看板で開始でき、全員が雪フィールド上空のスタート地点へテレポートします。
3. **シャベルを受け取る** — 開始時にダイヤのシャベルが配られます。これで雪を掘ります。
4. **掘って落とす** — 相手の足元の雪を掘って下へ落とし、自分は落ちないように立ち回ります。
5. **クリーパーに注意** — 一定間隔でクリーパーが出現します。爆発に巻き込まれないように動きましょう。
6. **生き残る** — Y0未満まで落ちる／死亡すると脱落（観戦モード）です。
7. **勝者決定** — 最後の1人になれば **勝利！** 一定秒数後にロビーへ戻ります。

## ソロモード（ソロ掘削スコア）

1人で、**制限時間（既定120秒）内に雪ブロックを何個掘れるか** を競うモードです。クリーパーが近くに乱入してくる中で、どれだけ掘れるかに挑戦します。自己ベストとランキングが残ります。

### 遊び方

1. **ソロ看板** をクリック、または `/yukicraft solo` でロビーに入ると、**ソロメニュー** が開きます。
2. メニューの **「掘削スコア」** を押すと、雪フィールドへ移動して3秒のカウントダウン（その間は動けません）のあとスタートします。
3. 時間切れ・落下・クリーパーで終了し、スコアが表示されます。
4. 3秒後にソロメニューがまた開くので、そのまま再挑戦できます。
5. やめるときはメニューの **「ロビー退出」** か `/yukicraft leave`（持ち物が戻り、初期地点へ移動します）。

- メニューを閉じてもロビーにいるままです。ホットバーの **ネザースター（ソロメニュー）** を右クリック（タップ）すると開き直せます。持ったまま **スニーク** しても開けます。
- `/yukicraft solo dig` で、メニューを通さずにすぐ始められます。

### ルール

| 項目 | 内容 |
|---|---|
| スコア | 自分で掘った雪ブロック1個につき1点。クリーパーの爆発で壊れた雪は数えません |
| 雪の設置 | ソロでは **置けません** |
| 雪玉 | ソロでは掘っても **落ちません**（通常戦では今まで通り落ちます） |
| 落下ダメージ | 無効。満腹度も減りません |
| 100個ごと | 音とメッセージでお知らせ |

### クリーパーの乱入（既定）

開始10秒後から **15秒ごと** に、あなたから5〜10ブロック離れた **今いる層** の雪の上にクリーパーが出ます。数は時間とともに増えます。

| 経過 | 1回に出る数 |
|---|---|
| 0〜39秒 | 1体 |
| 40〜79秒 | 2体 |
| 80秒〜 | 3体 |

### 終了と記録

| 状況 | 記録 |
|---|---|
| 制限時間になった（完走） | 残る |
| 最下層から落ちた（Y座標0未満） | 残る（それまでのスコア） |
| クリーパーなどで倒れた | 残る（それまでのスコア） |
| `/yukicraft leave`・切断・OP による停止 | **残らない** |

!!! tip "掘り方のコツ"
    足元ばかり掘ると下の層へ落ち、最後の層を掘り抜くとそこで終了です。同じ層を横に掘り進めるのが基本です。クリーパーが近づいたら少し離れてから掘りましょう。

### 画面の見方

- **画面上（ボスバー）**：残り時間と自己ベスト。残り10秒で赤くなります。
- **画面下（アクションバー）**：掘った数と、次のクリーパーまでの秒数・体数。自己ベストを超えると数字が金色になります。
- 結果はタイトルとチャットに表示され、サーバー全体にも1行だけお知らせされます。

### ソロメニュー

| ボタン | 内容 |
|---|---|
| ダイヤのシャベル | 掘削スコアを開始（自己ベスト・順位・挑戦回数も表示）。始められないときはバリアになり、理由が出ます |
| 本 | ルール |
| 紙 | 前回の結果 |
| 金ブロック | ランキング上位5人と自分の順位 |
| コンクリート | アリーナの状況（黄緑＝空き／赤＝使用中） |
| ドア | ロビー退出 |

!!! note "始められないとき"
    アリーナは通常戦と共用で1つだけです。誰かがソロ挑戦中、または通常戦の試合中は始められません。空くと開始ボタンが戻ります（最長でも制限時間＋数秒です）。

### ランキング

`/yukicraft ranking solo` で上位10人と自分の順位を確認できます。統合版で出した記録には **[統]** の印が付きます（ランキングは Java 版と共通です）。

!!! warning "統合版のプレイヤーへ"
    ソロメニュー（チェスト画面）はタップで操作できます。雪は統合版でも一瞬で掘れますが、通信の遅れで連続して掘る速さが落ちやすく、Java 版よりスコアが伸びにくいことがあります。

## プレイヤー用コマンド

参加・退出・開始は看板のほか、コマンド（全員可）でも行えます：`/yukicraft join`・`/yukicraft leave`・`/yukicraft start`。

| 操作 | 方法 |
|---|---|
| 参加 | `[Yukicraft]` 参加看板をクリックする |
| 離脱 | 離脱看板をクリックする |
| ソロ | ソロ看板をクリックする／`/yukicraft solo` |

## よくある質問

??? question "雪以外のブロックが掘れません"
    仕様です。Yukicraft では **雪ブロック以外は破壊・設置できません**。掘れるのは雪だけです。

??? question "下の層に落ちてしまいました。脱落ですか？"
    すぐに脱落ではありません。脱落になるのは **Y座標0未満（最下層より下）** まで落ちたときです。下の層にも雪があるので、まだ生き残れる可能性があります。

??? question "落下でダメージを受けますか？"
    いいえ。ゲーム中の落下ダメージは無効化されています。怖がらず動いて大丈夫です。

??? question "クリーパーは何のためにいますか？"
    時間経過とともに雪フィールドを崩し、決着を早めるための仕掛けです。爆発に巻き込まれると死亡＝脱落になるので注意しましょう。

??? question "脱落したあとは何ができますか？"
    観戦モードになり、ゲームの様子を見られます。ゲーム終了後はロビーへ戻されます。
