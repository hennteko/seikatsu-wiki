# Yukigassen <span class="badge done">公開中</span>

雪玉を投げ合って戦う、2チーム対抗の **雪合戦ミニゲーム** です。赤チームと青チームに分かれ、相手チームのプレイヤーを雪玉で全員リタイアさせたチームが勝利します。

!!! note "ゲームの特徴"
    雪玉を投げ合うシンプルなチーム対戦ミニゲームです。プレイヤーには残機があり、雪玉に当たると残機が減ります。残機がゼロになるとリタイア（観戦モード）となり、相手チームを全員リタイアさせたチームが優勝します。参加・退出は看板のクリックでも行えます。
