# Yukigassen ― 遊び方 { .page-player #yukigassen-player }

雪玉を投げ合うチーム対戦ミニゲームです。赤チームと青チームに分かれ、相手チームのプレイヤーを雪玉で全員リタイアさせれば勝ちです。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 2チーム制（赤チーム vs 青チーム） |
    | 装備 | ダイヤのシャベル ＋ 雪玉16個 |
    | 勝利条件 | 相手チームのプレイヤーを全員リタイアさせる |
    | 残機 | 既定3（運営の設定で変動） |
    | リスポーン | あり（残機が残っていれば自チームのスポーンに復活） |

## どんなゲーム？

赤チームと青チームに分かれて雪玉を投げ合います。相手チームのプレイヤーに雪玉を当てると、相手の残機が1つ減ります。残機がゼロになったプレイヤーはリタイアし、観戦モードになります。

相手チームのプレイヤーを **全員リタイアさせた** チームの勝利です。両チームが同時に全滅した場合は引き分け（ゲーム終了）となります。

## チーム

- チームは **赤チーム** と **青チーム** の2つです。
- ゲーム開始時、チーム未所属のプレイヤーは自動で赤・青に振り分けられます（人数が均等になるように割り振られます）。
- 同じチームのプレイヤーには雪玉を当てても **ダメージになりません**（同士討ちなし）。

!!! info "CPUチーム戦"
    運営が CPU チーム戦を有効にしていると、人数が足りないチームは **CPU（スノーゴーレムの砲台・スケルトンの歩兵）** で補充されます。CPU も雪玉を投げてくるので、人間と同じように倒せます。

## 参加方法

参加・退出・開始は、ロビーの看板のクリックまたはコマンド（全員可）で行えます。

| 操作 | 方法 |
|---|---|
| 参加 | 参加看板をクリック／`/yukigassen join` |
| 退出 | 退出看板をクリック／`/yukigassen leave` |
| 開始 | 開始看板をクリック／`/yukigassen start` |

参加すると受付ロビーへテレポートします。

!!! note "ゲーム中の途中参加"
    ゲームが進行中でも参加できます。途中参加した場合は人数の少ないチームへ振り分けられ、その場で雪合戦に加わります。

## ゲームの流れ

1. **参加する** — 参加看板をクリックしてロビーに参加します。
2. **ゲーム開始を待つ** — 運営がゲームを開始します。
3. **チーム分け** — 赤・青チームに自動で振り分けられ、自チームのスポーン地点へテレポートします。
4. **装備を受け取る** — ダイヤのシャベルと雪玉16個が配られます。
5. **雪玉を投げる** — 相手チームのプレイヤーに雪玉を当てて残機を削ります。
6. **雪を掘って補充** — 雪玉が切れたら、シャベルで雪を掘って雪玉を集められます。
7. **勝敗** — 相手チームを全員リタイアさせれば優勝です。

## ルール

- 雪玉に当たると残機が1つ減ります。残機がゼロになるとリタイア（観戦モード）です。
- 残機が残っているうちは、当たっても自チームのスポーン地点に復活します。
- リスポーン直後は **無敵時間（既定3秒）** があり、スポーンキルを防ぎます。自分が雪玉を投げると無敵は即解除されます。
- **シャベルで掘れるのは雪だけ** です（雪・雪ブロック・粉雪）。それ以外のブロックは掘れません。
- ゲーム中は **エリアの外に出られません**。エリア外へ移動しようとすると押し戻されます。
- 雪玉以外でのプレイヤー攻撃（殴り合いなど）は無効です。

!!! tip "雪玉を切らさないように"
    雪玉は16個配られますが、撃ち合いが続くとすぐ無くなります。物陰でシャベルを使って雪を掘り、こまめに雪玉を補充しましょう。

## ソロモード（1人で CPU と戦う）

通常のチーム戦のほかに、1人で CPU を相手に戦う **ソロモード** があります。ソロ看板をクリックするか `/yukigassen solo` でソロロビーに入り、メニューからモードと難易度を選んで挑戦します。アリーナが通常戦・他のソロで使用中のときは挑戦できません。離脱は通常戦と同じ `/yukigassen leave`（またはソロ看板）です。

| モード | 内容 | 終了条件・記録 |
|---|---|---|
| 殲滅タイムアタック | 決まった数の CPU を全滅させるまでのタイムを競う | 被弾上限か時間切れで失敗（記録なし）。タイムが記録 |
| ウェーブ防衛 | 波ごとに CPU が増える。5波ごとに隊長が出る | 被弾上限で終了。到達ウェーブが記録 |
| 雪だるま防衛 | 自陣の雪だるまを CPU から守る | 被弾上限で一時凍結。雪だるまが壊れたら終了。生存時間が記録 |

難易度は **かんたん／ふつう／むずかしい** から選べます（運営が増減している場合があります）。難易度が上がると CPU の数・射撃間隔・狙いの精度・体力が強化されます。被弾が規定回数（既定5回）に達すると終了（雪だるま防衛では一時凍結）です。

- `/yukigassen solo` … ソロロビーに入ってメニューを開く
- `/yukigassen solo <モード> [難易度]` … 選択を省略してすぐ開始（例: `/yukigassen solo wave hard`）
- `/yukigassen ranking solo <モード> [難易度]` … そのモード・難易度のランキングを見る

!!! tip "自己ベスト"
    モード・難易度ごとに自己ベストが保存されます。自己ベストを更新するとサーバー全体に告知されます。

## プレイヤー用コマンド

参加・退出・開始は **看板のクリック** または **コマンド** で行えます。`/yukigassen join`・`/yukigassen leave`・`/yukigassen start`・`/yukigassen solo`・`/yukigassen ranking`・`/yukigassen status`・`/yukigassen stats` は全プレイヤーが使えます（看板と同等）。

| コマンド | 説明 |
|---|---|
| `/yukigassen join` | ゲームに参加する（参加看板と同等） |
| `/yukigassen leave` | ゲームから離脱する（退出看板と同等。ソロも共通） |
| `/yukigassen start` | ゲームを開始する（開始看板と同等） |
| `/yukigassen solo [モード] [難易度]` | ソロモードに参加する／メニューを開く（ソロ看板と同等） |
| `/yukigassen ranking solo <モード> [難易度]` | ソロのランキングを確認する |
| `/yukigassen status` | 設定状況・ゲーム状態を確認する |
| `/yukigassen stats [名前]` | 自分または指定プレイヤーの成績（キル/デス/勝利/試合数）を確認する |

## よくある質問

??? question "残機がゼロになるとどうなりますか？"
    観戦モード（スペクテイター）になり、そのゲームからはリタイアとなります。自分のチームが勝てば勝利チームの一員です。

??? question "味方に雪玉が当たってしまいました"
    同じチームのプレイヤー同士はダメージになりません。安心して撃ち合えます。

??? question "雪玉がなくなりました"
    シャベルで雪（雪・雪ブロック・粉雪）を掘ると雪玉を集められます。雪以外のブロックは掘れません。

??? question "ゲームの途中から参加できますか？"
    できます。進行中に参加すると、人数の少ないチームへ自動で振り分けられ、すぐに雪合戦へ加わります。

??? question "エリアの外に出られません"
    仕様です。ゲーム中はゲームエリア外へ移動できないよう制限されています。
