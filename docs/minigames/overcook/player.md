# Overcook ― 遊び方 { .page-player #overcook-player }

みんなで協力して注文をさばくオーバークック風の調理ゲームです。食材を切って・焼いて・盛り付けて、制限時間内にできるだけ多くの注文を提供しましょう。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | 協力（全員で1つのキッチン） |
    | 人数 | 最大8人（サーバー設定により変更されることがあります） |
    | 勝利条件 | 制限時間内に目標スコアを達成（星1〜3の評価） |
    | 参加方法 | `[Overcook]` 参加看板、または `/overcook join` |

## どんなゲーム？

参加者全員で1つのキッチンを回します。時間ごとに **注文** が入るので、料理を作って **提供口** に出すとスコアが入ります。制限時間内の合計スコアで **星1〜3** の評価が決まり、パーティごとのハイスコアに記録されます。期限切れや間違った料理の提供は減点なので、手分けして手早くさばくのがコツです。

## 調理の流れ

1. **食材を取る** … 食材チェストを操作して食材を手に入れます。
2. **切る** … 切る必要がある食材は、まな板の上で **右クリックを数回**（既定5回）繰り返して切ります。
3. **焼く** … 焼く食材はコンロに置いて焼きます（既定8秒）。**焼き上がったら放置すると焦げる**（既定さらに10秒）ので注意。
4. **盛り付ける** … 皿を用意し、作業台で必要な食材を組み合わせて料理を完成させます。
5. **提供する** … 完成した料理を提供口に出すと、注文と一致していればスコアになります。
6. **捨てる** … 失敗した食材はゴミ箱で捨てられます。

!!! tip "コンボを狙おう"
    注文を連続で正しく提供すると **コンボ倍率** が上がり（2回ごとに+1・最大x3）、得点が増えます。期限が近い注文から優先し、誤納品と期限切れを避けましょう。

## ステーション（設備）

| ステーション | 役割 |
|---|---|
| 食材チェスト | 食材を取り出す |
| まな板 | 食材を切る（右クリックを数回） |
| コンロ | 食材を焼く（焼き過ぎると焦げる） |
| 皿置き場 | 皿を取る／置く |
| 作業台 | 食材を組み合わせて料理を完成させる |
| 提供口 | 完成した料理を提供する（注文と一致で得点） |
| ゴミ箱 | いらない食材・失敗作を捨てる |

## 料理と食材（既定）

サーバーの `recipes.yml` で自由に変更・追加できます。既定では次のとおりです。

| 食材 | 下ごしらえ |
|---|---|
| 牛肉 | 焼く |
| レタス | 切る |
| トマト | 切る |
| 魚 | 切ってから焼く |

| 料理 | 必要な食材 | 目安点 |
|---|---|---|
| サラダ | 切ったレタス＋切ったトマト | 100 |
| ステーキ | 焼いた牛肉 | 120 |
| 焼き魚 | 切って焼いた魚 | 150 |
| ステーキ定食 | 焼いた牛肉＋切ったレタス＋切ったトマト | 250 |

## 参加方法

1. `[Overcook]` 参加看板をクリック、または `/overcook join` でロビーに入ります。
2. 開始看板のクリックまたは `/overcook start <ステージ>`（全員可）でゲーム開始。
3. カウントダウン後、キッチンで協力して注文をさばきます。
4. 制限時間が終わると結果（スコアと星評価）が表示され、ロビーへ戻ります。

離脱は `[Overcook]` 離脱看板か `/overcook leave` です。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/overcook join` | ロビーに参加する（参加看板と同等・全員可） |
| `/overcook leave` | ロビーから離脱する（離脱看板と同等・全員可） |
| `/overcook start <ステージ>` | ゲームを開始する（開始看板と同等・全員可） |
| `/overcook status` | 現在の設定・状況を確認する（全員可） |
| `/overcook ranking <ステージ>` | ステージのハイスコア（パーティ別）を表示 |

## よくある質問

??? question "食材が切れません／焼けません"
    切るのはまな板の上で右クリックを数回（既定5回）。焼くのはコンロです。食材によって「切る／焼く／切ってから焼く」が決まっています（例：魚は切ってから焼く）。

??? question "焼いた料理が焦げました"
    コンロで焼き上がったあと放置すると焦げます（既定10秒の猶予）。焼き上がったら早めに取り出しましょう。焦げた食材はゴミ箱へ。

??? question "スコアが伸びません"
    期限が近い注文を優先し、誤納品（注文にない料理の提供）と期限切れを避けましょう。連続提供でコンボ倍率（最大x3）が上がり、残り時間ボーナスも入ります。
