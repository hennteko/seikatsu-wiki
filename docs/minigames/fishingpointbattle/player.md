# FishingPointBattle ― 遊び方 { .page-player #fishingpointbattle-player }

制限時間内に魚を釣ってポイントを競う釣りミニゲームです。釣れば釣るほどポイントが貯まり、コンボやゴールデンタイムを活かしてハイスコアを狙います。ゲーム終了時にもっともポイントが高かった人が優勝です。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 1人以上（既定。運営の設定で変更可） |
    | 1試合の長さ | 既定5分（運営の設定で1〜60分） |
    | 勝利条件 | 制限時間終了時にもっともポイントが高い |
    | 参加方法 | ロビーの参加看板をクリック／`/fpb join` |
    | 1人で遊ぶ | ソロ看板／`/fpb solo`（毎日の「今日の大物」） |
    | 使う道具 | 開始時に配られる専用釣り竿 |

## どんなゲーム？

ロビーに集まったプレイヤー全員で、制限時間内にひたすら魚を釣ってポイントを稼ぎます。魚の種類によってポイントが異なり、レアアイテムを釣り上げると高得点になります。

連続して釣ると **コンボ倍率**、ゲーム中盤にはポイント2倍の **ゴールデンタイム** が発生します。さらに釣りの途中で手に入る **特殊アイテム** を使えば、ライバルを妨害したり自分を有利にしたりできます。制限時間が終わったときにもっともポイントが高かった人が優勝です。

## ゲームの流れ

1. **参加する** — ロビーにある参加看板（`[釣り大会]` ／ `▶クリックで参加`）をクリックしてロビーに入ります。参加・退出・開始の看板は複数の場所に設置できるので、どの看板からでも操作できます。
2. **待機する** — 開始まで待ちます。参加すると自動でロビーへテレポートします。
3. **カウントダウン** — 誰かが `/fpb start` か開始操作を行うと、5秒のカウントダウン後にスタートします。
4. **釣り竿を受け取る** — 開始と同時にエリアへ移動し、専用釣り竿が配られます。
5. **魚を釣る** — 制限時間いっぱい魚を釣ってポイントを稼ぎます。
6. **ゴールデンタイム** — ゲーム中盤にポイント2倍のゴールデンタイムが発生します。ここで一気に稼ぎましょう。
7. **結果発表** — 制限時間終了でランキングが発表され、上位3名に報酬が配られます。

## ルール

- ゲームはロビーの参加人数が **最小参加人数（既定1人。運営が変更可能）** に達すると開始できます。
- 開始時に配られる **専用釣り竿** で釣りをします（壊れません。ゲーム終了時に回収されます）。
- ゲーム中に途中退出して参加者が1人以下になると、その時点でゲームが終了します。
- ゲーム進行中・カウントダウン中は新しく参加できません。

## 釣果とポイント

釣れた魚の種類によって基本ポイントが決まります。

| 釣れたもの | 基本ポイント |
|---|---|
| タラ（COD） | 1 |
| サケ（SALMON） | 2 |
| フグ（PUFFERFISH） | 3 |
| 熱帯魚（TROPICAL_FISH） | 5 |
| 海洋の心（HEART_OF_THE_SEA） | 15 |
| エンチャント本（ENCHANTED_BOOK） | 15 |

!!! tip "レアアイテムは全体にアナウンス"
    **海洋の心** と **エンチャント本** はレアアイテム扱いです。釣り上げると全プレイヤーにアナウンスが流れ、専用のサウンドが鳴ります。

!!! note "ゴミアイテムはポイントなし"
    上記以外のもの（長靴・木の棒など）にはポイントが付きません。ただしゴミを釣ったときは、代わりに特殊アイテムが手に入ることがあります。

## ポイントを伸ばす倍率要素

基本ポイントは、次の倍率がかけ合わさって最終ポイントになります。

| 倍率要素 | 内容 |
|---|---|
| コンボ | 短時間に連続で釣るとコンボが繋がり倍率アップ |
| ゴールデンタイム | ゲーム中盤に発生。ポイント2倍 |
| 釣りスポット | 運営が設定した高ポイントゾーンで釣ると1.5倍 |
| 魚寄せビーコン | ビーコン設置場所の近くで釣ると1.3倍 |

### コンボ倍率

前回の釣りから一定時間（既定10秒）以内に次の魚を釣るとコンボが繋がります。コンボ数に応じて倍率が上がります。

| コンボ数 | 倍率 |
|---|---|
| 3コンボ | 1.2倍 |
| 5コンボ | 1.5倍 |
| 7コンボ | 1.8倍 |
| 10コンボ | 2.0倍 |

!!! tip "コンボを切らさない"
    コンボが繋がっている間にゴールデンタイムや釣りスポットの倍率が重なると、一度の釣りで大量のポイントが入ります。テンポよく釣り続けましょう。

## 特殊アイテム

ゴミを釣ったときや、魚を釣ったときに低確率で特殊アイテムが手に入ります。手に入れたら **右クリック** で使用できます。

| アイテム | 種類 | 効果 |
|---|---|---|
| イカスミ爆弾 | 妨害 | 投げて当てた相手に盲目を付与（既定3秒） |
| 凍結弾 | 妨害 | 投げて当てた相手を凍結＝移動不能に（既定2秒） |
| 釣り糸カッター | 妨害 | 近くで釣り中のプレイヤーの次の釣りを失敗させる |
| 幸運の餌 | 強化 | 次の1回の釣りでレアアイテムが確定 |
| 加速エサ | 強化 | 一定時間（既定30秒）釣りやすくなる（LUCK効果） |
| トラップ浮き | 設置 | 地面に設置。踏んだ相手にスロー効果 |
| 魚寄せビーコン | 設置 | 設置場所の周囲（既定で半径3ブロック）で釣るとポイント+30%ボーナス |

!!! warning "妨害アイテムに注意"
    他プレイヤーはイカスミ爆弾・凍結弾・トラップ浮きであなたを妨害してきます。盲目や凍結を受けても落ち着いて、効果が切れたら釣りを再開しましょう。

## ソロモード「今日の大物」

**1人で遊べるデイリーチャレンジ** です。毎日1種類の魚が「今日の大物」として出題され、その日いちばん大きいサイズ（cm）を釣った人が1位になります。

1. **ソロ看板**（`[釣り大会]` ／ `ソロ：今日の大物`）をクリック、または `/fpb solo` → ロビーに入り、**ソロメニュー** が開きます。
2. ソロメニューの **「大物に挑戦」** を押すと、3秒のカウントダウンの後、釣り場で **3分間** の挑戦が始まります。
3. 配られた **大会用釣り竿** で釣るたびに、一定の確率で **今日の大物** がかかり、サイズが決まります（はずれのときは記録になりません）。
4. 時間が来ると結果が表示され、ロビーに戻って数秒後にソロメニューが開きます。
5. **1日3回** まで挑戦できます。その日いちばん大きいサイズがあなたの記録です。

- 今日の大物は **毎日0:00（日本時間）** に変わります。全員同じ魚です（前日と同じ魚は出ません）。
- **大物ライン** 以上のサイズを釣ると「大物！」になります。
- 同じサイズのときは、先に釣った人が上の順位です。
- 早めに終えたいときは、スロット9の **時計（挑戦を終える）** を **3秒以内に2回** 使います（長押しでは終わりません）。
- メニューを閉じてもロビーにいるままです。ホットバーの **ネザースター（ソロメニュー）** を右クリック／タップで開き直せます。
- 大会のポイント・コンボ・ゴールデンタイム・特殊アイテムは、ソロにはありません。

### 今日の大物になる魚（既定）

| 魚 | サイズ | 大物ライン | 出やすさ |
|---|---|---|---|
| タラ | 30〜120cm | 100cm | よく出る |
| サケ | 40〜150cm | 130cm | よく出る |
| フグ | 10〜60cm | 50cm | ふつう |
| 熱帯魚 | 5〜40cm | 35cm | たまに |

大きいサイズほど出にくくなっています。魚の種類やサイズは運営が変えることがあります。ソロメニューの「大物に挑戦」に今日の値が出ます。

### 報酬（1日1回ずつ）

| 条件 | 報酬（既定） |
|---|---|
| その日初めて大物を釣った | エメラルド ×1 |
| その日初めて大物ライン以上を釣った | ダイヤモンド ×1 |

報酬は **ロビーを出て持ち物が戻った後** に受け取れます。釣った魚そのものは試合用アイテムなので、挑戦が終わると回収されます。

### 結果の扱い

| 状況 | 釣った記録 | 挑戦回数 |
|---|---|---|
| 時間切れ・「挑戦を終える」 | 残る | 1回使う |
| 挑戦中に `/fpb leave`・切断 | 残る | 1回使う |
| OP が挑戦を止めた（`/fpb stop`）・サーバー停止 | 残る | **戻る** |

- 今日の1位が入れ替わると、サーバー全体にお知らせが流れます。
- 挑戦中に倒れても、釣り場で復活して続けられます。

### ソロメニュー

| ボタン | 内容 |
|---|---|
| 今日の魚のアイコン | **大物に挑戦**（サイズの範囲・大物ライン・残り回数を表示。挑戦できないときはバリアになり、理由が出ます） |
| 時計 | 日付と、次の出題までの時間 |
| 本 | ルールと報酬 |
| 金ブロック | 今日のランキング上位5人とあなたの順位 |
| プレイヤーの頭 | 今日のあなた（ベスト・匹数・挑戦回数・報酬の受け取り状況） |
| ガラス板 | 釣り場の状況（空き／満員／大会中） |
| 紙 | あなたの記録（魚ごとの最大サイズ・クリアした日数・連続クリア日数） |
| ドア | ロビー退出（持ち物が戻ります） |

!!! note "大会との関係"
    釣り場は大会と同じ場所を使います。**大会中はソロを始められず、ソロ挑戦中の人がいると大会を始められません**（ソロは1回3分なので、長くても3分待てば始められます）。ソロは最大4人まで同時に挑戦できます。ソロで入ったあと `/fpb join` を使うと大会の待機に、大会の待機中に `/fpb solo` を使うとソロに切り替わります。

!!! info "統合版（スマホ・Switch など）で遊ぶとき"
    - ソロメニューはチェストの画面で表示され、タップで操作できます。
    - ネザースター・時計は、持って **空中をタップ** しても使えます。ネザースターは **持ってスニーク** でも開きます。
    - ランキングでは統合版で出した記録に `[BE]` の印が付きます（ランキングは Java 版と共通です）。

## 勝利条件

制限時間が終わった時点で **もっともポイントが高いプレイヤーが優勝** です。結果発表でランキングが表示され、上位3名に報酬（運営の設定により既定はエメラルド）が配られます。

## プレイヤー用コマンド

ゲームへの参加・退出・開始は、ロビーの看板のクリックまたはコマンド（全員可）で行えます。

| 操作 | 方法 |
|---|---|
| ゲームに参加 | 参加看板（`[釣り大会]` ／ `▶クリックで参加`）を右クリック／`/fpb join` |
| ロビーから退出 | 退出看板（`[釣り大会]` ／ `▶クリックで退出`）を右クリック／`/fpb leave` |
| ゲーム開始 | `/fpb start [分]`（人数が集まれば誰でも開始可。分は省略可） |
| ヘルプ表示 | `/fpb help` |
| 状態を確認 | `/fpb status`（現在の進行状況・参加人数を表示） |
| ソロ「今日の大物」 | ソロ看板を右クリック／`/fpb solo`（ソロメニューを開く） |
| ソロをすぐ始める | `/fpb solo start`（メニューを通さずに挑戦） |
| 今日のランキング | `/fpb solo top` |

!!! note "参加・退出・開始について"
    `/fpb join`・`leave`・`start`・`help`・`status` は **全プレイヤーが使えます**（看板と同等。`start` は最小人数を満たせば誰でも開始可）。会場設定・`stop`・`reload` などの管理コマンドは運営（`fpb.admin`）専用です。

## よくある質問

??? question "どうやってゲームに参加しますか？"
    ロビーの参加看板（`[釣り大会]` ／ `▶クリックで参加`）を右クリック、または `/fpb join` コマンドで参加できます（どちらも全員可）。

??? question "自分の釣り竿で釣ってもいいですか？"
    ゲーム開始時に専用の「大会用釣り竿」が配られます。これで釣りをしてください。専用釣り竿は壊れず、ゲーム終了時に自動で回収されます。

??? question "ゴミばかり釣れてポイントが入りません"
    長靴や木の棒などのゴミにはポイントが付きません。ただしゴミを釣ったときは特殊アイテムが手に入ることがあるので無駄ではありません。釣りスポットやビーコンの近くで釣ると効率が上がります。

??? question "ゴールデンタイムはいつ来ますか？"
    ゲーム中盤にランダムなタイミングで一度だけ発生します。発生するとボスバーとタイトルで告知され、その間ポイントが2倍になります。

??? question "盲目や凍結になってしまいました"
    他プレイヤーの妨害アイテム（イカスミ爆弾・凍結弾）を受けています。効果は数秒で切れるので、切れたら釣りを再開しましょう。

??? question "1人でも遊べますか？"
    ソロモード「今日の大物」があります。ソロ看板か `/fpb solo` で始められます。1日3回まで挑戦でき、その日いちばん大きいサイズで順位を競います。

??? question "ソロの「大物に挑戦」がバリアになっていて押せません"
    アイコンの説明に理由が出ています。今日の挑戦回数を使い切った（翌日0:00に戻ります）、大会中、釣り場が満員（4人）のどれかです。大会や他の人の挑戦が終わると、画面が自動で更新されます。

??? question "途中で抜けたらどうなりますか？"
    退出看板を使うかサーバーから切断すると離脱します。離脱して参加者が1人以下になると、その時点でゲームが終了します。
