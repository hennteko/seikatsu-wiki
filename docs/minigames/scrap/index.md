# SCRAP -回収屋- <span class="badge done">公開中</span>

暗闇の廃墟に潜り、散らばった **回収物** をそっと運んで搬出カートに納品し、ノルマ金額を稼いで生還する **協力型ホラー回収ゲーム** です（R.E.P.O. 風）。怪異（かいい）は倒せません。逃げる・隠れる・静かに歩く・仲間を運ぶ——チームで協力して3ラウンドを生き延びれば勝ちです。

!!! note "ゲームの特徴"
    完全協力型のホラーゲームです。視界は常に暗く、ランタンはチームに数個だけ。回収物は **担ぐと遅くなり、落とす・ぶつける・被弾するたびに価値が減り**、0になると砕けます。**大型品は2人で運搬**。倒れた仲間は「頭」になり、担いでカートに納品すると復活します。ラウンドごとに **ノルマ金額（既定 1,000→2,500→5,000）** があり、**未達なら即ゲームオーバー**。超過分だけがチーム資金になり、ラウンド間のショップで装備を買えます。怪異は **聞き耳・見つめ返す者・擬態・徘徊者・督促者** の5種で、どれも倒せません（気絶させて逃げるだけ）。
