# SCRAP -回収屋- ― 遊び方 { .page-player #scrap-player }

暗闇の廃墟から回収物をそっと運び出し、ノルマ金額を稼いで生還する協力ホラーゲームです。怪異は倒せません。チームで音を立てず、助け合って生き延びましょう。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | 完全協力型（全員で1チーム） |
    | 人数 | 4〜8人想定（サーバー設定により変更されることがあります） |
    | 勝利条件 | 3ラウンドすべてのノルマを達成して生還する |
    | 失敗条件 | ラウンドのノルマ未達、または全員が倒れる |
    | 復活 | 倒れると「頭」になる。仲間が担いでカートに納品すると復活 |
    | 参加方法 | ロビーの参加看板（`[SCRAP]` / `参加`）をクリック、または `/scrap join` |

## どんなゲーム？

チーム全員で暗い廃墟（エリア）に潜入し、各地に散らばった **回収物** を搬出カートまで運んで納品します。ラウンドごとに **ノルマ金額** が決まっていて、制限時間内に達成できないと **即ゲームオーバー**。3ラウンドすべて達成できれば生還（クリア）です。

怪異は **倒せません**。物音を頼りに、あるいは視線で寄ってくるので、静かに動いて隠れながら運ぶのが基本です。倒れた仲間は「頭」になり、担いでカートに納品すると復活します。

## 回収物を運ぶ

回収物は **右クリックで担ぎ**、もう一度右クリックか `/scrap drop` で置きます。担ぐと遅くなり、サイズによって制限があります。

| サイズ | 価値の目安 | 運搬制限 |
|---|---|---|
| 小 | 約150 | 移動速度 −15%。ジャンプOK |
| 中 | 約500 | 移動速度 −40%。ジャンプ不可・スプリント不可 |
| 大 | 約1,500 | **2人**で同時に担ぐ（速度−40%・ジャンプ不可）。※参加者が1人のときは1人でも可 |
| 頭（仲間） | 0 | 中と同じ制限。壊れない |

!!! warning "価値は減る・0で砕ける"
    回収物は雑に扱うと価値が減ります。**落下（2ブロック以上）・怪異からの被弾・2人運搬で離れすぎ**などで減額し、**水没・溶岩で即砕けます**。価値が0になると壊れてしまうので、静かに丁寧に運びましょう。担いでいる間は攻撃・アイテム使用ができません（ランタンの点灯切替のみ可）。大型品は2人の距離が離れすぎると両者が強制的に手放します。

## 音のルール（重要）

怪異の多くは **音** に反応します。行動によって出る音の大きさ（届く範囲）が違います。

| 行動 | 音の大きさ |
|---|---|
| スニーク移動 | **無音** |
| 歩行（非スニーク） | 小（半径4） |
| スプリント | 大（半径12） |
| ジャンプ着地 | 中（半径10） |
| 扉・フェンスゲートの開閉 | 中（半径10） |
| 回収物の価値が減る | 特大（半径20） |
| ランタン点灯中 | 小（半径6・毎秒） |
| チャットで叫ぶ（`!`始まり） | 特大（半径30） |

!!! tip "静かに動く"
    急ぐと音で怪異を引き寄せます。基本は **スニーク（無音）** で移動し、危険なときだけ走りましょう。チャットは近く（既定15ブロック）の味方にだけ届き、先頭に `!` を付けると2倍の範囲に届きますが大きな音が出ます。

## 怪異（かいい）

怪異は5種類。**どれも倒せません**（スタンバットで一時的に気絶させて逃げるだけ）。

| 怪異 | 特徴 |
|---|---|
| 聞き耳（LISTENER） | 目が見えず、**音にだけ反応**して寄ってくる。スニークなら気づかれにくい |
| 見つめ返す者（WATCHER） | **誰かに見られている間は完全に静止**。目を離すと速く動く |
| 擬態（MIMIC） | 回収物に化けている。担ごうとすると変形して数秒追ってくる。価値表示が微妙にズレている（末尾が7など）のがヒント |
| 徘徊者（WANDERER） | 遅いが、見つけると追う。**閉じた扉で足止め**できる（ただし約10秒で突破） |
| 督促者（COLLECTOR） | 残り時間が少なくなると出現する最速の怪異。カートの中には入れない |

!!! danger "怪異に触れると"
    怪異の攻撃を受けると大ダメージ（既定8＝3回で倒れる）。倒されると「頭」になり観戦状態になります。カートの範囲内は安全地帯で、怪異は入ってきません。

## 死亡と復活

倒れると、その場に **自分の頭** が落ちて観戦状態になります。仲間がその頭を担いで **カートに納品** すると、カート内で復活します（HP10）。ラウンドをまたいで未回収でも、次ラウンド開始時にカート内で自動復活します。**全員が同時に倒れるとゲームオーバー** です。

## ランタンと装備

視界は常に暗く、**ランタン**（ソウルランタン）を右クリックで点灯すると周囲が明るくなります。ただし点灯中は **怪異に見つかりやすくなり（視認範囲2倍）、小さな音も出ます**。ランタンはチームに数個だけ配られ、エリア内でも拾えます。

ラウンド間のショップでは、チーム資金で装備を購入できます。

| 装備 | 効果 |
|---|---|
| ランタン | 光源。点灯中は怪異に見つかりやすい |
| おとり | 投げると着地点で10秒間、大きな音を出し続ける（怪異を引き寄せる） |
| フレア | 投げると着地点に20秒間の強い光を置く |
| 消音ブーツ | 装備中はスプリント・ジャンプの音を出さない |
| 運搬ハーネス | 装備中は運搬の速度低下を半減、中型品のジャンプ禁止を解除 |
| 医療キット | 使うとHP全回復（1回） |
| スタンバット | 怪異を殴ると気絶（既定8秒）。3回で壊れる |

## 勝利条件

各ラウンドの **制限時間内にノルマ金額を達成** し、生存者全員がカートに乗ると出発（早期終了）できます。時間切れでもノルマ達成なら出発、**未達なら即ゲームオーバー**。3ラウンドすべて達成して最終ラウンドのカートが出発すれば **生還（クリア）** です。ノルマの超過分だけがチーム資金になり、次のショップで使えます。

## ゲームの流れ

1. **ロビーに参加** — 参加看板をクリック、または `/scrap join`。
2. **潜入開始** — 開始看板のクリックまたは `/scrap start <エリア>`（全員可）で、カウントダウン後にラウンド1が始まります。
3. **回収** — 静かに動いて回収物を探し、カートまで運んで納品。ノルマ達成を目指します。
4. **出発** — ノルマ達成後、生存者全員がカートに入ると出発。またはラウンド終了で判定。
5. **ショップ** — ラウンド間（既定60秒）にチーム資金で装備を購入。
6. **クリア** — 3ラウンド達成でカートが脱出し、生還です。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/scrap join` | ロビーに参加する（参加看板と同等・全員可） |
| `/scrap leave` | ロビーから退出する（離脱看板と同等・全員可） |
| `/scrap start <エリア>` | ゲームを開始する（開始看板と同等・全員可） |
| `/scrap status` | 現在の設定・状況を確認する（全員可） |
| `/scrap drop` | 担いでいる物をその場に置く（右クリックと同じ・保険用） |
| `/scrap shop` | ショップを開く（ラウンド間のショップ時間のみ・全員可） |

!!! note "コマンドの短縮形"
    `/scrap` は `/sc` と短縮できます。

## よくある質問

??? question "怪異は倒せますか？"
    倒せません。ショップの **スタンバット** で一時的に気絶させて逃げることはできますが、完全には倒せません。基本は隠れて・静かに動いてやり過ごします。

??? question "回収物の価値が減ってしまいます"
    落下・被弾・2人運搬での離れすぎで減ります。段差を飛び降りず、怪異に当たらないように、大型品は2人で距離を保って運びましょう。水・溶岩に落とすと即砕けます。

??? question "倒されたら終わりですか？"
    いいえ。頭になって観戦になりますが、仲間が頭をカートに納品すれば復活します。ただし **全員が同時に倒れるとゲームオーバー** です。

??? question "ノルマに届かなそうです"
    ノルマ未達は即ゲームオーバーです。無理せず、価値の高い物を優先し、確実に納品できる範囲で回収しましょう。
