# 一本柱PvP ― 遊び方 { .page-player #pillarpvp-player }

細い柱の上で、一定間隔で配られるランダムアイテムだけを使って戦う個人戦バトロワです。落ちたら脱落。最後の1人を目指します。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | 個人戦（FFA・全員が敵） |
    | 人数 | 2〜16人（サーバー設定により変更されることがあります） |
    | 勝利条件 | 最後の1人、または時間切れ時に最多キルの生存者 |
    | 制限時間 | 既定300秒 |
    | アイテム | 既定3秒ごとにランダムアイテムが1個ずつ配られる |
    | 参加方法 | ロビーの参加看板、または `/pillar join`（`/ipp join`） |

## どんなゲーム？

参加人数ぶんの **細い1マスの柱** がフィールド中心のまわりに自動生成され、全員が自分の柱の頂上からスタートします。カウントダウンのあいだは柱から動けず、カウントが終わると試合開始です。

開始後は **一定間隔（既定3秒）** ごとに、生存者全員にそれぞれ別々の **ランダムアイテム** が1個ずつ配られます。手持ちは配られたアイテムだけ。それらを駆使して相手を **柱から落とす・倒す** と撃破です。自分が柱から落ちる（落下ラインより下、またはフィールドの外に出る）と脱落になり、観戦モードで試合を見守ります。

## ランダムアイテム

- 開始時とその後 **一定間隔（既定3秒）** ごとに、ランダムなアイテムが1個配られます。全アイテムが等確率です。
- 配布対象から **スポーンエッグ**（既定）や、コマンドブロック・バリア・デバッグ棒などの管理者向けアイテム、サーバーで除外設定されたアイテムは外れています。
- アクションバーに「**次のアイテムまで N秒**」が表示されます（サーバー設定で非表示の場合あり）。
- インベントリが満杯のときは、その回の配布はスキップされます。
- 配られた試合アイテムは **その場に捨てられません**（サーバー設定で許可されることがあります）。エンダーチェストも試合中は使えません。

## 柱と落下・積み上げ

- スタートの柱は **1マスの細い柱**（既定の高さ20ブロック）です。柱そのものは壊せません。
- **落下ラインより下**、またはフィールド範囲の外に出ると脱落します。
- ブロックは **柱の頂上から一定の高さ（既定 +15ブロック）** まで積めます。それより高くは積めません。
- ブロックや水・溶岩を置けるのは **フィールド範囲の内側だけ** です。エンダーパールなどでフィールドの外へは出られません。

## キル・脱落の判定

- 相手を直接倒すと撃破です。直接の攻撃でなくても、**最後に攻撃してきた人** がいれば、その人の落下キルとして記録されます（既定10秒以内）。
- 誰の攻撃もなく自分から落ちた場合は、キルの付かない「落下」になります。
- 脱落すると観戦モードになり、試合をそのまま見られます。

## 勝利条件

- 生存者が **1人だけ** になった時点でその人の勝利です。
- **制限時間（既定300秒）** 切れ時に複数人が生き残っていれば、生存者の中で **最多キル** の人が勝者です（同数なら引き分け）。

## 参加方法

1. ロビーの **参加看板** をクリック、または `/pillar join`。
2. **開始看板** のクリックまたは `/pillar start`（全員可）でゲーム開始。
3. フィールドに柱が生成され、各自の柱の頂上に配置されます。カウントダウン後に戦闘開始です。

離脱は **離脱看板** か `/pillar leave` です。試合中に進行中のロビーへ参加した場合は、観戦で待機し、次の試合から参加できます。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/pillar join` | ロビーに参加する（参加看板と同等・全員可） |
| `/pillar leave` | ロビーから離脱する（離脱看板と同等・全員可） |
| `/pillar start` | ゲームを開始する（開始看板と同等・全員可） |
| `/pillar status` | 現在の設定・状況を確認する（全員可） |
| `/pillar stats [名前]` | 成績（キル・デス・勝利・試合数）を確認する（全員可・読み取り専用） |

!!! note "コマンドの短縮形"
    `/pillar` は `/ipp` と短縮できます。

## よくある質問

??? question "どんなアイテムが配られますか？"
    毎回ランダムで、全アイテムが等確率です。武器や防具が来ることも、建材やまったく戦えないものが来ることもあります。スポーンエッグや管理者向けアイテムは配られません。

??? question "自分で用意した装備は使えますか？"
    いいえ。試合中の手持ちは、配られたランダムアイテムだけです。ロビーに入った時点で元の持ち物は安全に預かられ、離脱すると元どおり戻ります。

??? question "柱は壊したり積み増したりできますか？"
    スタートの柱そのものは壊せません。ブロックは柱の頂上から一定の高さ（既定 +15ブロック）まで、フィールド内にかぎり積めます。

??? question "落ちたらすぐ終わりですか？"
    その試合では脱落（観戦）です。試合が終わると自動的にロビーへ戻るので、次の試合にそのまま参加できます。
