# アモアス ― 遊び方 { .page-player #impostor-player }

宇宙船を舞台にした人狼系の推理ゲーム（Among Us 風）です。多くの **クルー** の中に隠れた少数の **インポスター** を、話し合いと投票で見つけ出しましょう。クルーはタスクを、インポスターはキルとサボタージュを狙います。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | 隠れ役職の推理（4〜15人） |
    | 役職 | クルー（多数）／ インポスター（少数・既定1〜3人の自動調整） |
    | クルーの勝利 | 全員でタスクを全部終える、またはインポスターを全員追放 |
    | インポスターの勝利 | クルーの人数と並ぶまで減らす、または原子炉の妨害を通す |
    | キル | 既定クールタイム25秒・射程3マス |
    | 会議 | 死体を通報、または緊急ボタン（既定1回まで）→ 話し合い30秒 → 投票60秒 |
    | 参加方法 | 参加看板、または `/imp join` |

## 役職

試合開始時に、全員が次のどちらかになります（偽物の数は人数で自動調整。既定で〜7人:1人、8〜11人:2人、12人〜:3人）。

- **クルー（船員）** … マップ各所の **タスク** を全部終わらせるのが目標。誰がインポスターかを推理し、会議で追放を目指します。
- **インポスター（偽物）** … クルーのふりをしながら **キル** でこっそり人数を減らし、クルーと同数まで並べば勝ち。**サボタージュ** と **ベント移動** で妨害・逃走できます。インポスターが複数のときは、仲間が誰かを最初に知らされます。

## クルーの遊び方：タスク

マップには、あなた専用に配られた **タスク** の場所がいくつかあります。その場所の装置を使うとタスクが進みます。タスクには次のような種類があります。

- **チェスト画面の作業（GUI）** … 画面が開き、「1から順に押す」「全部クリックして消す」「同じ色をつなぐ」などを行います。
- **しゃがみ続ける作業（HOLD）** … 装置の前で一定時間しゃがんだままにします（医務室のスキャンなど）。
- **右クリックするだけ（CLICK）** … バルブを開ける・電力を分配するなど、その場で押すだけのもの。

複数の手順があるタスクは、配られた場所を順番に回って進めます。画面上部の **タスクバー** で全体の進み具合が分かります（設定で「随時／会議のときだけ／表示しない」が切り替わります）。**全員のタスクが全部終わればクルーの勝ち** です。

!!! tip "インポスターはタスクができない"
    インポスターはタスクを進められません（ふりはできます）。タスクバーが進むのは本物のクルーが作業したときだけなので、怪しい動きを見極める材料になります。

## インポスターの遊び方：キル・サボタージュ・ベント

- **キル** … 近く（既定3マス）のクルーを、キルアイテムで倒します。倒すと **クールタイム**（既定25秒）があり、連続では倒せません。倒れた相手はその場に **死体** を残します。
- **サボタージュ** … サボタージュアイテムから、妨害を起こせます（クールタイム既定30秒）。
    - **停電（lights）** … あたりを暗くして視界を奪います。クルーが電気パネルを直すと復旧します。
    - **原子炉（reactor・重大）** … 制限時間（既定45秒）内に、クルーが **2か所** を同時に押さえて直さないと、**インポスターの勝ち** になります。
    - **ドア封鎖（doors）** … 指定した部屋のドアを一定時間（既定10秒）閉じ込めます。
- **ベント（通気口）** … 通気口に入って、同じグループの別の通気口へ素早く移動できます（クルーからは姿が見えなくなります）。追われたときの逃走や、不意のキルに使えます。
- **暗視** … 設定で有効なら、停電中もインポスターは視界が確保されます。

## 通報・緊急ボタン・会議

怪しい動きや死体を見つけたら、会議を開いてみんなで話し合います。会議は2通りの開き方があります。

1. **死体を通報** … 死体の近く（既定3マス）で通報アイテムを使うと会議が始まります。
2. **緊急ボタン** … マップの緊急ボタンから会議を招集します（1人が押せる回数は既定1回、試合開始・前回の会議からクールタイム既定15秒）。

会議が始まると全員が会議席に集まり、次の流れで進みます。

| フェーズ | 既定時間 | 内容 |
|---|---|---|
| 話し合い | 30秒 | 情報を出し合う（この間は投票できません） |
| 投票 | 60秒 | 怪しい人、または「スキップ」に投票する |

- 投票は **投票アイテム（GUI）** から、または `/imp vote <色>`／`/imp vote skip` で行います。
- 最多票の人が **追放** されます。同数・スキップ多数のときは誰も追放されません。
- 設定で「追放者の役職を発表」が有効なら、追放された人がインポスターだったかが分かります。
- 設定で「匿名投票」が有効なら、誰が誰に入れたかは伏せられます。
- 会議・投票が終わると、またそれぞれの持ち場に戻ります。

!!! note "死んでもタスクはできる"
    クルーは倒されても **幽霊** として残り、タスクを続けられます（勝利に貢献できます）。幽霊はキルや投票はできません。

## 勝敗

- **クルーの勝ち** … 全員でタスクを全部終える、またはインポスターを全員追放したとき。
- **インポスターの勝ち** … キルや追放でクルーがインポスターと同数まで減ったとき、または原子炉のサボタージュを時間内に直されなかったとき。

## 参加方法

1. ロビーの **参加看板** をクリック、または `/imp join`。
2. 人数（最低4人）が集まったら **開始看板** をクリック、または `/imp start [マップ]` で開始（カウントダウン既定10秒）。
3. 離脱は **離脱看板** か `/imp leave`。試合中に離脱すると脱落（死亡）扱いになります。

試合中、参加者どうしのチャットは **会議中だけ** 全体に出ます（設定による）。

## プレイヤー用コマンド

`/impostor` でも実行できます。

| コマンド | 説明 |
|---|---|
| `/imp join` | ロビーに参加する（参加看板と同等） |
| `/imp leave` | ロビーから離脱する（離脱看板と同等。試合中は脱落扱い） |
| `/imp start [マップ]` | ゲームを開始する（開始看板と同等・全員可） |
| `/imp status` | 現在の設定・状況を確認する（読み取り専用） |
| `/imp vote [色\|skip]` | 会議中に投票する（引数なしで投票画面を開く） |
| `/imp stats [プレイヤー]` | 自分または指定プレイヤーの記録を見る |

## よくある質問

??? question "インポスターは何人になりますか？"
    既定では人数で自動調整され、〜7人で1人、8〜11人で2人、12人以上で3人です（運営が固定することもできます）。

??? question "インポスターもタスクをやるのですか？"
    タスクを進めることはできません。ただし「やっているふり」はできます。タスクバーが進むのは本物のクルーが作業したときだけです。

??? question "倒されたら何もできませんか？"
    クルーは幽霊として残り、タスクは続けられます（勝利に貢献できます）。キルや投票、通報はできません。

??? question "投票はどうやりますか？"
    会議の投票フェーズに、投票アイテム（GUI）から選ぶか、`/imp vote <色>` で入れます。誰も怪しくなければ `/imp vote skip` でスキップできます。

??? question "ベントは誰でも使えますか？"
    いいえ。通気口（ベント）に入って移動できるのはインポスターだけです。クルーからは、ベントに入っている間は姿が見えません。
