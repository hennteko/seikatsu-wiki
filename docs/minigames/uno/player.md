# UNO ― 遊び方 { .page-player #uno-player }

カードの **色・数字・記号** を場札に合わせて出していき、**先に手札を0枚にした人** が勝ちのカードゲームです。手札はチェスト型の画面で見て、カードをクリック（タップ）して出します。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 2〜8人（人間＋CPU。足りない分はCPUが補充） |
    | 勝利条件 | 先に手札を0枚にする |
    | 最初の手札 | 7枚（既定） |
    | 参加方法 | 卓の参加看板、または `/uno join [卓名]` |
    | 手札を開く | ホットバーの **手札を見る本**、または `/uno hand` |
    | 制限時間 | 1ターン既定30秒（時間切れは1枚引いてパス） |

## どんなゲーム？

席に座って始めると、全員に **7枚** のカードが配られ、中央に最初の場札が1枚めくられます。自分の番が来たら、**場札に合うカード** を1枚出します。出せるカードが無ければ山札から1枚引き、それが出せればそのまま出せます（出せなければパス）。これを繰り返し、**手札を先に0枚にした人が勝ち** です。

- 出せるのは、場札と **同じ色** ／ **同じ数字** ／ **同じ記号** のカード、または **ワイルド（色を選べる）** ／ **ワイルドドロー4** です。
- 手札が **残り1枚になる前（＝2枚のとき）** に **UNO! を宣言** しないと、あとで指摘されてカードを引かされます。

## 手札の画面

ホットバーの **手札を見る本**（右クリック／タップ）か `/uno hand` で、チェスト型の手札画面が開きます。

- **上段** … 場札・今の色・場の向き（時計回り／反時計回り）・累積（ドロー2/4 の重ね枚数）・今の手番と残り時間・次の人・山札の残り・自分の枚数が並びます。
- **手札** … 自分のカードが並び、**今出せるカードは光り**、出せないカードは名前の先頭に「×」が付きます。光っているカードをクリック（タップ）で出します。多いときはページで切り替わります。
- **下段のボタン** … 「引く／N枚引く」「パス」「チャレンジ」「UNO!」「指摘」「並べ替え（色順／数字順）」「閉じる」。状況に応じて押せるボタンだけ表示されます。

!!! note "ホットバーのアイテム"
    席に座ると、**手札を見る本**・**UNO!**（ベル）・**指摘**（羽根）の3つがホットバーに入ります。画面を開かずに、UNO! や指摘はホットバーからも使えます（統合版は空中タップでも使えます）。

## カードの出し方

1. 自分の番になったら、手札の画面を開きます（本やお知らせで分かります）。
2. **光っているカード** をクリック（タップ）して出します。
3. **ワイルド／ワイルドドロー4** を出したときは、続けて **色を選ぶ画面** が出るので、次の色を選びます（時間切れのときは手札に一番多い色になります）。
4. 出せるカードが無ければ **「引く」** で1枚引きます。引いたカードが出せればそのまま出せます（出さないなら **「パス」**）。

## 記号カード

| カード | はたらき |
|---|---|
| 数字（0〜9） | 同じ色・同じ数字の上に出せる |
| スキップ | 次の人の番を飛ばす |
| リバース | 場の向きを逆にする（2人のときはスキップと同じ） |
| ドロー2 | 次の人が2枚引く（重ねられる＝下記） |
| ワイルド | 好きな色に変える（いつでも出せる） |
| ワイルドドロー4 | 好きな色に変えて、次の人が4枚引く（いつでも出せる・チャレンジの対象） |

## ドロー2／ドロー4 の重ね（スタック）

ドロー2・ドロー4 を出されたとき、自分も同じ系統のカードを持っていれば **重ねて次の人へ回せます**（累積して、受けた人がまとめて引きます）。重ねられなければ、累積した枚数をまとめて引いて、その番は飛ばされます。

- ドロー2 には **ドロー4 を重ねられます**（既定）。
- ドロー4 に **ドロー2 を重ねられるか** は設定しだい（既定では重ねられません）。

!!! note "重ねのルールは卓の設定しだい"
    ドロー2/4 の重ねそのものを無効にしているサーバーもあります。重ねられるかどうかは、手札画面でボタンが押せるかで分かります。

## ドロー4のチャレンジ

ワイルドドロー4 は、本来 **「場の色のカードを持っていないとき」** にしか出せません。出された人は、相手がズルをしたと思ったら **チャレンジ** できます。

- **チャレンジ成功**（相手が場の色を持っていた）… 出した本人が4枚引きます。
- **チャレンジ失敗**（相手は場の色を持っていなかった）… チャレンジした人が **さらに2枚足して** 引きます。
- チャレンジしないときは、そのまま4枚引きます。

## UNO! 宣言と指摘

- **UNO! 宣言** … 手札が **2枚のとき**、カードを出して残り1枚になる前に **UNO! を押して** おきます（画面のベル、またはホットバーのベル）。準備しておくと、次に出したとき宣言済みになります。
- **指摘** … 誰かが **UNO! を言わずに残り1枚** になったら、受付時間内（既定3秒）に **指摘** を押すと、その人がペナルティで引きます（既定2枚）。
- UNO! 宣言のルール自体を無効にしているサーバーもあります。

## 制限時間

ターンには制限時間があります（既定30秒。色選び・チャレンジ選択・引いたカードを出すかは別途10秒など）。残りわずかになると効果音で知らせます。時間切れになると、**1枚引いてパス**（累積中なら累積分を引く）、色選びは **手札に一番多い色**、チャレンジ選択は **受ける** が自動で選ばれます。

## CPU（1人でも遊べる）

参加人数が足りないときは **CPU** が入ります。人間が1人のときでもCPUが相手になるので、1人で練習できます。CPUの人数と強さ（**かんたん／ふつう／むずかしい**）は卓ごとに運営が設定します。

## 参加方法

1. 卓の **参加看板** をクリック、または `/uno join [卓名]`（卓が1つなら卓名は省略できます）。
2. 席に座って待ちます。持ち物はロビーに入った時点で安全に預かられます。
3. **開始看板** のクリック、または `/uno start [卓名]`（全員可）で開始。全員ぶんのカウントダウンのあと試合が始まります。

離脱は **離脱看板** か `/uno leave` です。試合中に離脱すると脱落扱いになります。試合が進行中のときに参加した場合は、次の試合から入れます。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/uno join [卓名]` | 卓に参加する（参加看板と同等。卓が1つなら卓名は省略可・全員可） |
| `/uno leave` | 卓から離脱する（離脱看板と同等。試合中は脱落扱い・全員可） |
| `/uno start [卓名]` | 試合を開始する（開始看板と同等・全員可） |
| `/uno hand` | 手札の画面を開く |
| `/uno status [卓名]` | 設定・状況を確認する（全員可・読み取り専用） |

## よくある質問

??? question "出せるカードがどれか分かりません。"
    手札画面で **光っているカード** が今出せるカードです。出せないカードは名前の先頭に「×」が付きます。自分の番でないときは、どのカードも出せません。

??? question "UNO! を押すタイミングは？"
    手札が **2枚のとき**、カードを出して残り1枚になる前に押します。準備しておけば、次に出したときに宣言済みになります。言い忘れると、ほかの人に指摘されて引かされます。

??? question "ワイルドドロー4を出したのにチャレンジされました。"
    ワイルドドロー4 は、本来 **場の色のカードを持っていないとき** にしか出せないルールです。場の色を持っていたのに出すと、チャレンジが成功して自分が4枚引きます。

??? question "自分の持ち物はどうなりますか？"
    卓に入った時点で安全に預かられ、離脱すると元どおり戻ります。試合中の手持ちは、手札を見る本・UNO!・指摘の3つだけです。
