# UNO <span class="badge done">公開中</span>

おなじみの **UNO** を、席に座ってチェスト型の手札画面で遊ぶカードゲームです。手札の色・数字・記号を場札に合わせて出し、**早く手札を0枚にした人** が勝ち。2〜8人で遊べ、人が足りないときは **CPU** が入るので1人でも練習できます。1つのサーバーに **複数の卓** を置けます。

!!! note "ゲームの特徴"
    席に座ると **手札を見る本** が配られ、チェスト型の画面で遊びます。自分の番に、場札と **同じ色・同じ数字・同じ記号** のカードか、**ワイルド（色変え）・ワイルドドロー4** を出せます。スキップ・リバース・ドロー2 などの記号カードや、**ドロー2／ドロー4 の重ね（スタック）**、**ドロー4のチャレンジ**、手札が2枚になったら押す **UNO! 宣言** と宣言忘れの **指摘** など、本家に近いルールに対応。人数が足りないときは **CPU（かんたん／ふつう／むずかしい）** が補充され、1人でも遊べます。
