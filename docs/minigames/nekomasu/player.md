# ネコマス（Nekomasu） ― 遊び方 { .page-player #nekomasu-player }

色分けされた床の盤面に、ルールを守ってネコを置いていくロジックパズルです。N×N の盤面に N 匹のネコを3つのルールを全部守って置けばクリア。答えは必ず1つに決まります。ソロ・対戦・協力を遊べます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 目的 | N×N の盤面に N 匹のネコをルール通りに置く |
    | ルール | ①1色エリアに1匹 ②1行1列に1匹 ③ネコ同士は隣り合わない（周囲8マス） |
    | ライフ | 既定3（間違えると1減り、0で失格） |
    | ヒント | 既定3回（正解のネコを1匹置く） |
    | 置く | ネコを持って **マスを右クリック / タップ**（左クリックは使いません） |
    | モード | ソロ（1人・レベル制）/ 対戦（2〜4人・早解き）/ 協力（1〜4人・共有） |
    | 参加方法 | 参加看板、または `/nekomasu join` |

## ルール

N×N の盤面は N 個の色エリアに分かれています。N 匹のネコを、次の3つを全部守って置けばクリアです。

1. **1つの色エリアにネコは1匹**
2. **1つの行・1つの列にネコは1匹**
3. **ネコ同士は隣り合わない**（斜めも含めた周囲8マス）

- 答えは必ず1つだけです。
- 間違ったマスにネコを置くと **即ミス** になり、ライフ（既定3）が1つ減ります。間違えたマスには自動で×が付きます。ライフが0になると失格です。
- ×印はメモ用です。何度付けたり外したりしてもミスになりません。
- 置いたネコは正解なので動かせません。

## 遊び方

1. 参加看板を右クリック（または `/nekomasu join`）でロビーに入ります。持ち物は預かり、抜けるときに全部戻ります。
2. 遊びたいモードを選びます。
    - **ソロ** … ホットバーのネザースター（ソロメニュー）を右クリック、またはソロ看板。
    - **対戦・協力** … 開始看板を右クリック（ロビーにいる人全員で始まります）。
3. 抜けるときは赤い染料（退出）を右クリック、離脱看板、または `/nekomasu leave`。

盤面の上を歩きながら、足元や少し先のマス（既定6ブロック先まで）を見て右クリックします。

## 道具

| スロット | 道具 | 右クリック（統合版はタップ） |
|---|---|---|
| 1 | ネコを置く（ネコのスポーンエッグ） | 見ているマスにネコを置く |
| 2 | ×ペン（羽根） | 見ているマスの×を付け外し |
| 3 | ヒント（ランタン） | 正解のネコを1匹自動で置く（既定3回） |
| 4 | 自動×（緑＝ON／灰＝OFF） | ON にすると、ネコを置いたとき同じ行・列・色・周囲8マスに×が付く |
| 9 | 退出（赤い染料） | ネコマスから抜ける（試合中は脱落扱い） |

!!! tip "自動×を使いこなそう"
    スロット4の「自動×」を ON にしておくと、ネコを正しく置くたびに、その行・列・色エリア・周囲8マスへ自動で×が付きます。置けないマスがひと目で分かるので、特に大きい盤面で便利です。初期値はOPの設定（`game.auto-mark-default`）で決まり、各自で ON/OFF を切り替えられます。

## モード

| モード | 人数 | 内容 |
|---|---|---|
| ソロ | 1人 | レベルを順番に解く（全15レベル。クリアするとその先は自動生成のエンドレス）。難易度を選んで1問だけ遊ぶこともできる。タイムとベストを記録 |
| 対戦 | 2〜4人 | 全員が同じ問題を自分の盤面で解く早解き勝負 |
| 協力 | 1〜4人 | 1つの盤面をみんなで解く。ライフとヒントは全員で共有 |

難易度：**かんたん 5×5 ／ ふつう 6×6〜7×7 ／ むずかしい 8×8 ／ 鬼 9×9**

### 対戦の決着

- 終わり方は2種類あります（管理者が切り替え）。
    - **1位で終了** … 最初に完成させた人の勝ち。
    - **全員完成まで** … 全員が完成・失格するまで続け、完成した順に順位が付きます。
- 自分以外が全員失格・離脱したら、残った人の勝ちです。全員失格なら引き分け。
- 制限時間（既定10分）になったら、**完成した人 → 置けたネコが多い人 → ミスが少ない人 → 最後に置いた時刻が早い人** の順で順位を付けます。

### 協力の決着

- 完成したらクリア。共有ライフが0、または制限時間（既定15分）で失敗です。

## ソロ（レベル制）

- 全15レベルを順番に解きます。すべてクリアすると、その先は **自動生成のエンドレス**（3レベルごとに大きくなり、9×9 まで）に進みます。
- ソロメニューから **難易度を選んで1問だけ** 遊ぶこともできます。
- 到達レベル・ベストタイムが記録されます。ソロが終わってロビーに戻ると、少し待ってソロメニューが自動で開き直します。

## 途中参加・離脱・切断

- 試合中に参加した人は、次の試合から参加します（今の試合の観戦はしません）。
- 試合中に抜ける・切断すると脱落扱いになり、ロビーからも抜けます。持ち物は戻り、初期地点へ移動します。再ログインしても試合には戻れません。
- 試合が終わってもロビーには残るので、続けて次の試合に参加できます。

## 観戦（対戦で失格した人）

- 対戦でライフが0になった人は、まだ解いている人の視点で観戦します。自由には動けません。
- **スニーク** で、まだ解いている別の人に切り替えます。
- 解いている人がいなくなったらロビーに戻ります。協力は脱落がないので観戦はありません。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/nekomasu join` | 参加する（ロビーへ・全員可） |
| `/nekomasu leave` | 離脱する（初期地点へ。試合中は脱落・全員可） |
| `/nekomasu solo` | ソロメニューを開く |
| `/nekomasu start <versus\|coop> [難易度]` | 対戦・協力を開始する（全員可） |
| `/nekomasu status` | 設定・状況を確認する（全員可） |

## よくある質問

??? question "ネコはどうやって置きますか？"
    ホットバーのスロット1（ネコのスポーンエッグ）を持ち、置きたいマスを **右クリック（統合版はタップ）** します。左クリックは使いません。正しい位置なら置け、間違っているとミスになります。

??? question "×印を付けるとミスになりますか？"
    いいえ。×印（スロット2の×ペン）はメモ用で、何度付け外ししてもミスにはなりません。置けないマスに印を付けて、残りを絞り込むのに使います。

??? question "1人でも遊べますか？"
    はい。ソロ看板かソロメニューから遊べます。全15レベルを順に解き、クリア後は自動生成のエンドレスに進みます。難易度を選んで1問だけ遊ぶこともできます。

??? question "答えが複数ある問題は出ますか？"
    いいえ。出題される問題は **答えが必ず1つ** に決まるものだけです。
