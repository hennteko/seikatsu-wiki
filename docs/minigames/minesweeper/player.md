# マインスイーパー ― 遊び方 { .page-player #minesweeper-player }

地面に敷かれた **実物大のマインスイーパー** を、シャベルで開き・旗を立てて攻略します。地雷を踏まないよう、数字を手がかりに安全マスを読み解きましょう。ソロのタイムアタックから、対戦・協力・交代制まで遊べます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | ソロ / 対戦 / 協力 / 交代制（ステージごとにモードが決まっている） |
    | 操作 | シャベル＝マスを開く（コード開きも）／ 旗＝旗を立てる・外す |
    | 開け方 | マスを見て右クリック（統合版はタップ） |
    | 初手 | 最初に開けたマスは必ず安全（周囲も空く） |
    | 難易度 | 初級 9×9・地雷10 ／ 中級 16×16・地雷40 ／ 上級 30×16・地雷99 |
    | 勝利条件 | 安全マスを全部開けたら成功。地雷を踏むと失敗・脱落 |
    | 参加方法 | 参加看板・`/minesweeper join`、ソロは `/minesweeper solo` |

## どんなゲーム？

床のマス目が1マスずつのブロックになっていて、これが丸ごとマインスイーパーの盤面です。

- **開く** … **シャベル** を持ってマスを見て右クリック（統合版はタップ）すると、そのマスを開きます。
- **数字** … 開いたマスには、**周囲8マスにある地雷の数** が色ブロックと数字で表示されます。
- **連鎖** … 周囲に地雷が1つもない（`0`）マスを開くと、まわりの `0` マスが波紋のように連鎖して自動で開いていきます。
- **旗** … 地雷だと思うマスには **旗** を立てて目印にします（開けなくなるので誤操作防止にも）。

!!! tip "最初の一手は安全"
    最初に開けるマスは、そのマスと **周囲が必ず安全** になるよう地雷が配置されます。いきなり地雷を踏むことはないので、まず真ん中あたりを開いて手がかりを広げましょう。

## 操作（シャベルと旗）

ホットバーには **シャベル（開く）** と **旗（赤い旗）** が入っています。どちらも **マスを見て右クリック／タップ** で使います。

| 道具 | 操作 | はたらき |
|---|---|---|
| シャベル | 未開封マスを見て右クリック/タップ | そのマスを開く |
| シャベル | 数字マスを見て右クリック/タップ | **コード開き**（下記） |
| 旗 | 未開封マスを見て右クリック/タップ | 旗を立てる／外す |

!!! note "コード開き"
    すでに開いた **数字マス** をシャベルで押すと、その周りに立てた **旗の数が数字と同じ** なら、残りの未開封マスを一括で開きます。安全確認ができたマスをまとめて素早く開けますが、旗を立て間違えていると地雷を開いてしまうので注意してください。

同じマスへの連続操作や、操作の連打には短いクールタイムがあります（誤爆防止）。マスを操作できるのは一定の距離（既定6ブロック）までです。

## モード（4種類）

1つのステージ＝1つのモードです。看板や `/minesweeper start` で選んだステージのモードで遊びます。

| モード | 人数 | 内容 | 勝敗 |
|---|---|---|---|
| **ソロ** | 1人 | 1つの盤面を自分だけで攻略 | 安全マスを全部開けたらクリア（タイムを記録） |
| **対戦** | 2〜4人 | 1人1つずつ **別々の同じ盤面** を同時に攻略 | 先に全部開けた人の勝ち。地雷を踏むと脱落 |
| **協力** | 2〜8人 | **1つの盤面をみんなで** 開ける | 全員で全部開けたらクリア。地雷を踏むと **チームのライフ** が減り、0でゲームオーバー |
| **交代制** | 2〜6人 | 1つの盤面を **順番に1マスずつ** 開ける | 地雷を踏んだ人から脱落。最後まで残った人が勝ち |

- **対戦** は全員の盤面が同じ配置なので、純粋な速さ勝負になります。
- **協力** はライフ（既定1）を共有します。相談しながら慎重に進めましょう。
- **交代制** は自分の番だけ操作でき、1手ごとに制限時間（既定20秒）があります。

## 難易度

難易度は盤面の大きさと地雷の数で決まります（ステージごとに設定）。

| 難易度 | 盤面 | 地雷 | 制限時間（既定） |
|---|---|---|---|
| 初級 | 9×9 | 10 | 5分 |
| 中級 | 16×16 | 40 | 10分 |
| 上級 | 30×16 | 99 | 20分 |

## ソロですぐ遊ぶ

- `/minesweeper solo` で **ソロメニュー** が開き、難易度を選んですぐ挑戦できます。
- ロビーで待っているときは、ホットバーの **ネザースター** を右クリック/タップでもソロメニューを開けます。
- ソロの試合が終わってロビーに戻ると、もう一度ソロメニューが自動で開きます（続けて遊べます）。
- クリアタイムは難易度ごとに記録され、`/minesweeper top [難易度]` でランキングを確認できます。

## 参加方法

1. **ソロ** … `/minesweeper solo`、またはロビーのネザースターから。すぐ難易度を選んで挑戦できます。
2. **対戦・協力・交代制** … ロビーの **参加看板** をクリック、または `/minesweeper join`。人数が集まったら **開始看板** か `/minesweeper start [ステージ]` で開始します（カウントダウン既定5秒）。
3. 離脱は **離脱看板** か `/minesweeper leave`。試合中に離脱すると脱落扱いになります。

## プレイヤー用コマンド

`/msw` でも実行できます。

| コマンド | 説明 |
|---|---|
| `/minesweeper join` | ロビーに参加する（参加看板と同等） |
| `/minesweeper leave` | ロビーから離脱する（離脱看板と同等。試合中は脱落扱い） |
| `/minesweeper start [ステージ]` | ゲームを開始する（開始看板と同等・全員可） |
| `/minesweeper solo` | ソロの難易度を選んですぐ開始（メニュー） |
| `/minesweeper status` | 現在の設定・状況を確認する（読み取り専用） |
| `/minesweeper top [easy\|normal\|hard]` | ソロのクリアタイムランキングを見る |

## よくある質問

??? question "最初の一手でいきなり地雷を踏むことはありますか？"
    ありません。最初に開けるマスとその周囲は必ず安全になるよう地雷が配置されます。まず盤面の内側を開いて、数字から読み進めましょう。

??? question "旗を立てたマスは開けますか？"
    旗を立てている間は、そのマスをシャベルで開けません（誤爆防止）。もう一度旗で押すと旗を外せます。

??? question "数字マスを押しても何も起きません。"
    コード開きは「周りの旗の数が、そのマスの数字と同じ」ときだけ残りを開きます。旗が足りない・多いと作動しません。旗の数を数字に合わせてから押してください。

??? question "協力モードで地雷を踏んだらすぐ負けですか？"
    いいえ。協力はチームでライフ（既定1）を共有します。ライフが残っていれば続行でき、0になるとゲームオーバーです。

??? question "対戦でみんな同じ盤面なのですか？"
    はい。対戦は全員が同じ配置の盤面を別々に解く速さ勝負です。先に安全マスを全部開けた人が勝ちで、地雷を踏むと脱落します。
