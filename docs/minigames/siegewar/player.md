# 攻城戦（SiegeWar） ― 遊び方 { .page-player #siegewar-player }

攻撃側と防御側に分かれて戦うチーム対戦です。攻撃側は城門や城壁を破って城の奥にある **コア** を壊せば勝ち、防御側は制限時間までコアを守りきれば勝ちです。試合中は自由に建築・破壊ができ、試合が終わるとステージ（城）は試合前の状態に戻ります。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | チーム対戦（攻撃側 vs 防御側） |
    | 勝利条件 | 攻撃側＝コアの HP を0に / 防御側＝制限時間まで防衛 |
    | チーム分け | 自動（攻撃 6 : 防御 4 の比率） |
    | フェーズ | 準備フェーズ（既定2分）→ 攻城フェーズ（既定15分） |
    | コア | HP 既定300。殴り続けて0.5秒ごとに1ダメージ |
    | 参加方法 | ロビーの参加看板、または `/siege join` |
    | 開始 | 開始看板、または `/siege start`（人数がそろっても自動では始まらない） |

## どんなゲーム？

試合が始まると参加者は **攻撃側 / 防御側** のどちらかに自動で分かれます（既定で攻撃 6 : 防御 4 の比率）。

- **攻撃側** は、城門や城壁を破って城の奥へ進み、**コア** を殴って HP を0にすれば勝ちです。
- **防御側** は、城にこもってコアを守り、**制限時間まで守りきれば** 勝ちです。

試合は **準備フェーズ → 攻城フェーズ** の順に進み、決着すると結果が表示されて数秒後にロビーへ戻ります。そのまま続けて次の試合に参加できます。

## 試合の流れ

1. 参加看板をクリック/タップするか、`/siege join` でロビーへ入ります。持ち物は預かられ、ロビーでは空になります。
2. 開始看板をクリック/タップするか `/siege start` で開始します（人数がそろっても自動では始まりません）。カウントダウン（既定10秒）の後、陣営が自動で決まります。
3. **準備フェーズ（既定2分）** … 防御側は城の中で建築して守りを固めます。攻撃側は出撃地点から出られません。この間に役職を選びます。
4. **攻城フェーズ（既定15分）** … 攻撃側が出撃します。城門や城壁を破ってコアを目指します。
5. 決着すると結果が表示され、数秒後にロビーへ戻ります。
6. やめるときは離脱看板か `/siege leave` を使います。持ち物が戻り、元の場所へ移動します。

!!! note "途中参加・途中離脱について"
    - 試合中に参加した人は、次の試合から参加します（進行中の試合には入れません。観戦もありません）。
    - 試合中に `/siege leave` したり切断したりすると、その試合からは抜けます。再ログインしても試合には戻れません。

## 勝敗

| 勝ち | 条件 |
| --- | --- |
| 攻撃側 | コアの HP を0にする |
| 防御側 | 制限時間が終わるまでコアを守る |
| 不戦勝 | 相手の陣営が全員 leave・切断でいなくなった（両方0人なら勝敗なし） |

### 延長戦

制限時間が終わった瞬間に、攻撃側の誰かがコアを殴っていると **延長戦** になります（既定で有効）。

- コアを殴っている攻撃側が **2秒続けて0人** になったら、防御側の勝ちです。
- 延長は最大30秒です。それまでにコアを壊せなければ防御側の勝ちです。

## コア

- コアはビーコン（設定で変わります）のブロックで、ボスバーに HP が出ます。
- 攻撃側がコアを **左クリック（統合版は長押し）し続けている間**、0.5秒ごとに1ダメージが入ります。連打しても押しっぱなしでも速さは同じです。手を離したり、コアから目線を外したり、離れたりすると止まります。
- コアのブロック自体は壊れません。
- **防衛ボーナス** … 防御側がコアの近く（既定5ブロック以内）にいる間は、ダメージが半分になります。このときボスバーが青くなり「防衛中」と出ます。
- HP が 50%・25% を切ると知らせが出ます。
- コアのまわり（既定3ブロック以内）にはブロックを置けません。

## 建築・破壊

- 自分や相手が **置いたブロック** は、どちらの陣営でも壊せます。
- **城にもとからあるブロック** は、城門・柵・ドア・木材など決められた種類だけ壊せます。城壁などは壊せません。
- 壊したブロックはアイテムになりません。ブロックは役職の装備に入っていて、リスポーンのたびに補充されます。
- 陣営スポーンのまわりと、コアのまわりにはブロックを置けません。
- ステージの範囲の外には出られず、建築もできません。高さにも上限があり、それより上には置けず、登ることもできません。
- 城のチェストなどのコンテナ、作業台などは使えません。ドア・トラップドア・フェンスゲート・レバー・ボタンは使えます。
- 同じ陣営どうしの攻撃は当たりません。準備フェーズ中は誰とも戦えません。
- 城のハーフブロックに重ねる、ろうそくを足すなど、城のブロックに重ねて置くことはできません。
- 試合中はクラフトできません。満腹度も減りません。

!!! note "置けないもの・使えないもの"
    - **置けないブロック** … 水・溶岩・TNT・火・砂や砂利・チェストなどのコンテナ・ピストン・ドアやベッドなど2マスのブロック など。
    - **使えないアイテム** … エンダーパール・エリトラ・ウィンドチャージ・トライデント・バケツ など（壁越えの移動手段を禁止）。

## 役職（キット）

| 陣営 | 役職 | 特徴 |
| --- | --- | --- |
| 攻撃 | 剣士 | 鉄の剣と鉄の防具。体力が多い（最大24＝12ハート） |
| 攻撃 | 弓兵 | 弓と矢64本。チェインの防具 |
| 攻撃 | 工兵 | 採掘速度上昇（HASTE）。はしごと建築ブロックを多く持ち、城門を速く壊せる |
| 防御 | 守備兵 | 盾と鉄の剣・鉄の防具 |
| 防御 | 弓兵 | 弓と矢64本。城壁の上から撃つ |
| 防御 | 修理兵 | 修理ハンマーを持ち、壊された城門を元に戻せる |

- ホットバー右端の **本（役職を選ぶ）** を右クリック/タップすると、役職を選べます。本を持てるのは **準備フェーズ中** と **リスポーン待ちの間** だけです。
- 準備フェーズ中は、まだブロックを置いていなければすぐに装備が替わります。ブロックを置いた後や、リスポーン待ちの間に選んだ役職は、次の出撃のときに装備されます。
- 準備フェーズ中にブロックを置いた後で倒れた場合、出撃時に建築ブロックは補充されません（攻城フェーズで倒れたときは補充されます）。
- 放った矢は拾えません（リスポーンで補充されます）。

### 修理ハンマー（修理兵）

- 壊された城門などの **元の場所** を右クリック/タップすると、元のブロックを置き直します（ドアは上下まとめて直ります）。
- 使える回数は5回で、30秒ごとに1回回復します。ハンマーの個数が残り回数です。
- その場所に人が立っていると直せません。直したブロックは、また壊すことができます。

## 死亡とリスポーン

- 倒れても持ち物は落ちません。すぐにリスポーンして、自分の陣営のスポーンで待ちます。
- 待っている間は動けず、目の前が暗くなり、攻撃も受けません（向きは変えられます）。アクションバーに「次の出撃まで ○秒」と出ます。
- **防御側** … 既定5秒で出撃します。
- **攻撃側** … 攻城フェーズ中は **一斉出撃** です。攻城フェーズの開始から15秒ごとに、待っている攻撃側がまとめて出撃します（最低5秒は待ちます。長いと約20秒）。
- 出撃すると装備が補充され、3秒間は攻撃を受けません（自分から攻撃すると解除されます）。

## 表示

- **サイドバー** … フェーズ・残り時間・コア HP・陣営ごとの人数とキル数
- **ボスバー** … コア HP（防衛ボーナス中は青）
- 決着後、勝敗と MVP（最多キル・コアへのダメージ・最多修理）がチャットに出ます。試合結果はサーバー全体にも流れます。

## 統合版（スマホ・Switch など）

- 統合版でも遊べます。看板はタップ、本・ハンマーはタップで使えます。本は空中をタップしても開きます。
- コアへの攻撃は **ブロックを長押し** し続けてください。統合版はブロックを掘る操作の送られ方が Java 版と違うため、ダメージが途中で止まりやすい場合があります（止まったら長押しし直してください）。
- サイドバーの文字は短くしてありますが、画面の大きさによっては切れることがあります。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/siege join` | 参加（ロビーへ。参加看板と同等・全員可） |
| `/siege leave` | 離脱（持ち物が戻り、元の場所へ。離脱看板と同等・全員可） |
| `/siege start` | 開始（開始看板と同等・全員可。コンソール/コマンドブロックも可） |
| `/siege status` | 設定・状況を確認（全員可・読み取り専用） |

## よくある質問

??? question "攻撃側と防御側は自分で選べますか？"
    いいえ。陣営は開始時に自動で割り振られます（既定で攻撃 6 : 防御 4 の比率）。ただし陣営の中の **役職** は、準備フェーズ中とリスポーン待ちの間に本から選べます。

??? question "自分で用意した装備は使えますか？"
    いいえ。試合中の手持ちは役職ごとに配られた装備だけです。ロビーに入った時点で元の持ち物は安全に預かられ、離脱すると元どおり戻ります。

??? question "城を壊してしまって大丈夫ですか？"
    大丈夫です。試合中に変化したブロックはすべて記録され、試合が終わると城は試合前の状態へ自動で戻ります。思い切り攻めて・守って構いません。

??? question "コアがなかなか壊せません。"
    コアは **左クリック（統合版は長押し）し続けている間** だけダメージが入ります。連打では速くなりません。また防御側がコアの近くにいると防衛ボーナスでダメージが半分になります（ボスバーが青）。コアから目線を外したり離れたりすると止まります。

??? question "倒されたらそこで終わりですか？"
    いいえ。倒れても持ち物は落ちず、すぐにリスポーンして自分の陣営のスポーンで待機します。防御側は約5秒、攻撃側は攻城フェーズ中の一斉出撃のタイミングで出撃します。脱落はありません。
