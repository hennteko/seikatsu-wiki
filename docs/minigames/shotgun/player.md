# ショットガンルーレット ― 遊び方 { .page-player #shotgun-player }

実弾と空砲を混ぜて装填した1丁のショットガンを順番に回す、ターン制の心理戦です。自分か他人を撃ち、アイテムで情報と順番を操作しながら最後の1人を目指します。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 2〜4人（サーバー設定により変更されることがあります） |
    | 勝利条件 | 最後の1人になる（モードにより異なる） |
    | 残機 | 仮想値（実HPは使わない）。既定3・0で脱落 |
    | 手番タイマー | 既定30秒。時間切れ＝自分を撃つ |
    | 参加方法 | ロビーの参加看板（`[Shotgun]` / `参加`）をクリック、または `/sg join` |

## どんなゲーム？

円卓に着席し、順番に手番を回します。装填時には「実弾◯発・空砲◯発」だけが全員に公開され、**弾の順序は誰にも分かりません**。手番では自分か他人を撃ちます。空砲で自分を撃てば **手番が続き**、実弾を受けると残機が減ります。残機が0になると脱落し、最後の1人が勝ちです。

弾を撃ち切ると再装填され、アイテムが再配布されます（残機は引き継ぎ）。

## 操作方法

着席すると銃（クロスボウ）とアイテムがホットバーに入ります。席からは降りられません。

1. **他人を撃つ** … 銃を持って **視線を相手に向けて右クリック**。
2. **自分を撃つ** … 銃を持って **スニーク＋右クリック**。空砲なら手番継続。
3. **アイテムを使う** … 対象なしのアイテムは右クリックで即発動。対象ありのアイテム（鎖・エンダーパール・盗賊の手）は **チェストGUIで相手を選択**。アイテムは **自分の手番中のみ** 使えます。

!!! warning "時間切れに注意"
    手番タイマー（既定30秒）が切れると、**自動的に自分を撃ちます**。空砲を祈るか、その前に行動しましょう。

## アイテム

再装填のたびに、生存者へアイテムが配られます（人数や装填回数で内容・数が変わります）。

| アイテム | 対象 | 効果 |
|---|---|---|
| 望遠鏡 | なし | 次の1発が実弾か空砲かを **自分だけ** が見る |
| ホッパー | なし | 次の1発を排出して **全員に公開**（弾切れなら再装填） |
| 金リンゴ | なし | 残機+1（上限あり）。サドンデス以降は配られない |
| 鎖 | 選択 | 相手の次の手番をスキップ（スキップ中の相手・自分・同一相手連続は不可） |
| 火薬 | なし | 次の1発が実弾ならダメージ2倍。発砲・排出で解除 |
| 反転ポーション | なし | 次の1発の実弾⇔空砲を反転（重ねがけで再反転） |
| コンパス | なし | 次弾以外のランダムな1発の位置と種類を自分だけが見る |
| 盗賊の手 | 選択×2 | 相手の所持アイテム1つを奪って **その場で自分が使う**（盗賊の手自体は盗めない） |
| エンダーパール | 選択 | 相手と席（＝手番順）を入れ替える。現在の手番はそのまま継続 |
| 盾 | なし | 自分を狙った次の1発を、手番の向き側の隣の人へ逸らす（逸らし先がいなければ自分に当たる） |
| 不死のトーテム | なし | 残機0になった瞬間に残機1で復活（1回） |
| ベル | なし | 手番の向きを反転（時計回り⇔反時計回り）。全員に通知 |

!!! tip "アイテムは自分の手番だけ"
    アイテムは自分の手番中にのみ使えます。所持できるのはホットバーの1〜8番（銃は0番）まで。上限を超えた分は配られません。

## モード

開始時に選ぶモードで勝利条件が変わります。

- **バトルロイヤル（br）** … 全員が敵。最後の1人が勝ち。
- **ディーラー戦（dealer）** … プレイヤー対ディーラー。ディーラーは残機が多め（既定5）。
- **チーム戦（team・2v2）** … 2人1組で戦い、相手チームを全滅させたチームの勝ち。

## 勝利条件

残機が0になると脱落（観戦）になります。**バトルロイヤルは最後の1人**、チーム戦は相手チームの全滅、ディーラー戦はディーラーを倒せば勝ちです。結果画面では順位と「誰が誰を何発撃ったか・自撃ち成功数」が表示されます。

## 観戦者の予想

脱落者・観戦者は、**次の1発が実弾か空砲かを予想**できます。`/sg bet live`（実弾）／`/sg bet blank`（空砲）、またはチャットのクリックで予想でき、正解数がチャットに表示されます。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/sg join` | ロビーに参加する（参加看板と同等・全員可） |
| `/sg leave` | ロビーから退出する（試合中の参加者は脱落・全員可） |
| `/sg start <br\|dealer\|team>` | ゲームを開始する（開始看板と同等・全員可） |
| `/sg status` | 現在の設定・状況を確認する（全員可） |
| `/sg bet <live\|blank>` | 観戦者の次弾予想（実弾／空砲） |

!!! note "コマンドの短縮形"
    `/shotgun` は `/sg` と短縮できます。

## よくある質問

??? question "自分を撃つメリットは？"
    空砲だと分かっている（または賭ける）ときに自分を撃つと、**手番がもう一度回ってきます**。連続で行動でき、有利に進められます。

??? question "残機やHPはどうなっていますか？"
    残機は仮想値で、実際のHPバーとは別です。実弾を受けると残機が1（火薬中は2）減り、0で脱落します。金リンゴやトーテムで粘れます。

??? question "撃たれた後すぐ撃ち返せません"
    実弾で撃たれると **次の手番を1回スキップ** します（集中砲火の緩和）。

??? question "切断したらどうなりますか？"
    試合中に切断・離脱すると **即脱落・復帰不可** です。
