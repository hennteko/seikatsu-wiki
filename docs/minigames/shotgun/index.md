# ショットガンルーレット <span class="badge done">公開中</span>

円卓に着いた2〜4人が、実弾と空砲を混ぜて装填された1丁のショットガンを順番に回す、**ターン制の心理戦ミニゲーム**です（Buckshot Roulette 風）。装填時に「実弾が何発・空砲が何発」だけが公開され、順序は誰にも分かりません。自分か他人を撃ち、アイテムで情報と順番を操作しながら、最後の1人になるまで生き残ります。

!!! note "ゲームの特徴"
    残機は仮想値（実HPは使いません）。手番では **自分か他人を撃ち**、空砲で自分を撃てば手番が続き、実弾なら残機が減ります。**望遠鏡**で次弾を覗く、**ホッパー**で弾を捨てる、**鎖**で相手の手番を飛ばす、**火薬**で威力を倍にする——など多彩なアイテムで読み合います。**エンダーパール（席替え）・盾（隣へ逸らす）・ベル（手番の向き反転）** で4人戦の駆け引きが増えます。**バトルロイヤル／ディーラー戦／チーム戦(2v2)** の3モードに対応。観戦者は次の1発を予想して楽しめます。
