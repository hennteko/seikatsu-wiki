# 1vs1 ― 遊び方 { .page-player #pvp1vs1-player }

エメラルドを賭けて1対1で戦うPvPミニゲームです。`[PvP参加]` 看板を右クリックして待機キューに並び、相手を倒せば賞金とランクアップが手に入ります。観戦者は `[PvP賭け]` 看板から選手にエメラルドを賭けることもできます。

!!! info "操作はすべて看板から行います"
    このプラグインのプレイヤー操作は **すべて専用看板** で行います。`/pvp` コマンドはOP専用です（プレイヤーが入力しても権限エラーになります）。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 対戦は2人（観戦・賭けは人数制限なし） |
    | 勝利条件 | 相手を倒す（1本勝負） |
    | 入場料 | バトルパスランク × 10 エメラルド |
    | 通貨 | エメラルド |
    | 初期ランク | R3（ランクは1〜10） |

## どんなゲーム？

`[PvP参加]` 看板を右クリックして待機キューに並び、もう1人が並ぶとキューが満員になります。`[PvP開始]` 看板（またはOPの `/pvp start`）で試合を始めると、2人はそれぞれの開始地点へテレポートされ、PvP対戦がスタートします。先に相手を倒したほうが勝ちの **1本勝負** です。

勝者は賞金エメラルドとバトルパスランクのアップを獲得し、敗者はランクが1つ下がります。観戦しているプレイヤーは、好きな選手にエメラルドを賭けて配当を狙えます。

## 参加方法

1. **エメラルドを用意する** — 入場料として `バトルパスランク × 10` 個のエメラルドが必要です（初期ランクR3なら30個）。エメラルドはインベントリに持っているだけでOKです。
2. **`[PvP参加]` 看板を右クリック** — 待機キューに入ります。エメラルドが足りないと参加できません。
3. **対戦相手を待つ** — もう1人が `[PvP参加]` 看板を押すとキューが満員（2人）になります。
4. **試合を開始する** — キューが満員になったら、誰でも `[PvP開始]` 看板を右クリックして試合を始められます（OPは `/pvp start` でも可）。
5. **対戦開始** — 2人は開始地点へテレポートされ、対戦がスタートします。

!!! note "キューの定員は2人です"
    待機キューが満員（2人）のときは `[PvP参加]` 看板を押せません。試合が始まってキューが空くのを待ちましょう。

## ゲームの流れ

1. **入場料を払って参加** — `[PvP参加]` 看板でキューに入る（入場料はこの時点で消費されます）。
2. **試合開始を待つ** — 2人そろうとアナウンスが流れます。誰かが `[PvP開始]` 看板を押すか、OPが `/pvp start` で試合を始めます。
3. **対戦地点へテレポート** — 試合開始時、2人は別々の開始地点へ飛ばされます。
4. **戦う** — 相手を倒したほうが勝利です。
5. **結果発表** — 勝者に賞金とランクアップ、敗者にランクダウンが反映されます。
6. **元の場所へ帰還** — 試合が終わると、参加前にいた場所へ自動で戻されます。

## 賞金とバトルパスランク

このゲームには **バトルパスランク（R1〜R10）** があり、勝つと上がり、負けると下がります。新規プレイヤーの初期ランクは **R3** です。

| 結果 | ランクの変化 | 獲得エメラルド |
|---|---|---|
| 勝利（通常） | ランク +1（最大R10） | 新ランク × 20 |
| 勝利（相手より2ランク以上格上） | 変化なし | 現ランク × 12 |
| 敗北 | ランク −1（最小R1） | なし |

!!! tip "格下狩りには注意"
    自分の方が相手より **2ランク以上高い** 状態で勝っても、ランクは上がらず賞金も少なめ（ランク×12）になります。実力の近い相手と戦うほうがランクも賞金も伸びやすい仕組みです。

入場料はランクが上がるほど高くなります（ランク × 10 エメラルド）。ランクを上げると賞金も増えますが、参加コストも上がる点に注意しましょう。

## 賭けの仕組み（観戦者向け）

試合に参加していないプレイヤーは、対戦中の選手にエメラルドを賭けられます。

- **賭け方** … `[PvP賭け]` 看板を右クリックすると賭けGUIが開きます。GUIには両選手の頭・ランク・配当倍率が表示され、賭け金は **1 / 5 / 10 / 32 / 64 個** の固定ボタンから選びます。クリックした時点でエメラルドが消費されます。
- **賭けられる相手** … 現在進行中の試合に参加している選手のみです。
- **賭け直し** … 同じ試合中にもう一度賭けると **前の賭けは上書き** されます（前の賭け金は返却され、新しい賭け金が引かれます）。
- **的中したとき** … 賭けた選手が勝つと、`賭け金 × 配当倍率` のエメラルドを獲得します（端数切り捨て）。
- **外れたとき** … 賭けた選手が負けると、賭け金は戻ってきません。
- **試合が強制終了されたとき** … OPが `/pvp stop` で試合を打ち切った場合、賭け金は全額払い戻されます。

GUI右下の本アイテム「現在の状況」で、待機キューの人数・対戦の有無・自分の現在の賭けを確認できます。

### 配当倍率

配当倍率は、賭けた選手と相手選手のランク差で決まります。

| 賭けた選手の立場 | 配当倍率 |
|---|---|
| 相手と同ランク | 2.0 倍 |
| 相手より格下（ランクが低い） | 2.0 + ランク差 × 0.1 倍 |
| 相手より格上（ランクが高い） | 2.0 − ランク差 × 0.1 倍 |

!!! tip "番狂わせを狙うと配当が大きい"
    格下の選手に賭けて勝てば、ランク差が大きいほど高い配当（最大で2倍以上）が手に入ります。逆に格上の選手は勝っても配当倍率が下がります。

## ランキング

各プレイヤーのバトルパスランクはサーバーに保存され、ログアウトしても引き継がれます。ランク一覧の確認はOP向けのコマンドです（プレイヤーは自分の現在ランクを試合開始時のアナウンスなどで確認できます）。

## プレイヤー用の看板

| 看板タグ | 操作 | 動作 |
|---|---|---|
| `[PvP参加]` | 右クリック | 待機キューに参加する（入場料が必要） |
| `[PvP賭け]` | 右クリック | 賭けGUIを開く（試合中のみ操作可能） |
| `[PvP開始]` | 右クリック | キューが2人そろっているとき試合を開始する |
| `[PvP観戦]` | 右クリック | 観戦場所へテレポートする |
| `[ロビー]` | 右クリック | ロビーへテレポートする |

!!! tip "看板の2行目は状態表示です"
    各看板の2行目には現在の状態が自動表示されます。`[PvP参加]` は「待機: 1/2」のようなキュー人数、`[PvP開始]` は「開始可能／人数不足」、`[PvP賭け]` は「対戦待ち／対戦中」が表示され、状況が変わると自動更新されます。

!!! note "対戦中はテレポートできません"
    `[PvP観戦]`・`[ロビー]` 看板は、自分が対戦中のときは使えません。

!!! note "プレイヤー向けコマンドはありません"
    `/pvp` および `/1v1` はOP専用コマンドです。プレイヤーが入力すると権限エラーになります。参加・賭け・開始はすべて上記の看板から行います。

## よくある質問

??? question "参加にいくらエメラルドが必要ですか？"
    入場料は `バトルパスランク × 10` エメラルドです。初期ランクR3なら30個、R5なら50個必要です。インベントリにその数のエメラルドを持った状態で `[PvP参加]` 看板を右クリックしてください。

??? question "参加したのに試合が始まりません"
    試合は自動では始まりません。キューが2人そろったら、誰かが `[PvP開始]` 看板を右クリックする（またはOPが `/pvp start` を実行する）必要があります。

??? question "負けたらどうなりますか？"
    バトルパスランクが1つ下がります（最小R1）。賞金はありません。なお、試合終了後は参加前にいた場所へ自動で戻されます。

??? question "賭けたエメラルドは戻ってきますか？"
    賭けた選手が勝てば `賭け金 × 配当倍率` を獲得できますが、負けた場合は賭け金は戻りません。

??? question "観戦中でも試合に参加できますか？"
    観戦と賭けは試合に参加していないプレイヤー専用です。自分が選手として戦うには、次の試合で `[PvP参加]` 看板を右クリックしてキューに並んでください。
