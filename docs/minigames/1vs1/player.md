# 1vs1 ― 遊び方 { .page-player #pvp1vs1-player }

エメラルドを賭けて1対1で戦うPvPミニゲームです。待機キューに並んで対戦相手を待ち、相手を倒せば賞金とランクアップが手に入ります。観戦者として選手にエメラルドを賭けることもできます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 対戦は2人（観戦・賭けは人数制限なし） |
    | 勝利条件 | 相手を倒す（1本勝負） |
    | 入場料 | バトルパスランク × 10 エメラルド |
    | 通貨 | エメラルド |
    | 初期ランク | R3（ランクは1〜10） |

## どんなゲーム？

`/pvp join` で待機キューに並び、もう1人が並ぶとキューが満員になります。OPが試合を開始すると、2人はそれぞれの開始地点へテレポートされ、PvP対戦がスタートします。先に相手を倒したほうが勝ちの **1本勝負** です。

勝者は賞金エメラルドとバトルパスランクのアップを獲得し、敗者はランクが1つ下がります。観戦しているプレイヤーは、好きな選手にエメラルドを賭けて配当を狙えます。

## 参加方法

1. **エメラルドを用意する** — 入場料として `バトルパスランク × 10` 個のエメラルドが必要です（初期ランクR3なら30個）。エメラルドはインベントリに持っているだけでOKです。
2. **`/pvp join` を実行する** — 待機キューに入ります。エメラルドが足りないと参加できません。
3. **対戦相手を待つ** — もう1人が `/pvp join` するとキューが満員（2人）になります。
4. **OPが試合を開始する** — キューが満員になったら、OPが `/pvp start` で試合を始めます。
5. **対戦開始** — 2人は開始地点へテレポートされ、対戦がスタートします。

!!! note "キューの定員は2人です"
    待機キューが満員（2人）のときは `/pvp join` できません。試合が始まってキューが空くのを待ちましょう。

## ゲームの流れ

1. **入場料を払って参加** — `/pvp join` でキューに入る（入場料はこの時点で消費されます）。
2. **試合開始を待つ** — 2人そろうとアナウンスが流れ、OPが試合を開始します。
3. **対戦地点へテレポート** — 試合開始時、2人は別々の開始地点へ飛ばされます。
4. **戦う** — 相手を倒したほうが勝利です。
5. **結果発表** — 勝者に賞金とランクアップ、敗者にランクダウンが反映されます。
6. **元の場所へ帰還** — 試合が終わると、参加前にいた場所へ自動で戻されます。

## 賞金とバトルパスランク

このゲームには **バトルパスランク（R1〜R10）** があり、勝つと上がり、負けると下がります。新規プレイヤーの初期ランクは **R3** です。

| 結果 | ランクの変化 | 獲得エメラルド |
|---|---|---|
| 勝利（通常） | ランク +1（最大R10） | 新ランク × 20 |
| 勝利（相手より2ランク以上格上） | 変化なし | 現ランク × 12 |
| 敗北 | ランク −1（最小R1） | なし |

!!! tip "格下狩りには注意"
    自分の方が相手より **2ランク以上高い** 状態で勝っても、ランクは上がらず賞金も少なめ（ランク×12）になります。実力の近い相手と戦うほうがランクも賞金も伸びやすい仕組みです。

入場料はランクが上がるほど高くなります（ランク × 10 エメラルド）。ランクを上げると賞金も増えますが、参加コストも上がる点に注意しましょう。

## 賭けの仕組み（観戦者向け）

試合に参加していないプレイヤーは、対戦中の選手にエメラルドを賭けられます。

- **賭け方** … `/pvp bet <選手名> <エメラルドの量>` を実行します。賭けたエメラルドはその場で消費されます。
- **賭けられる相手** … 現在進行中の試合に参加している選手のみです。
- **的中したとき** … 賭けた選手が勝つと、`賭け金 × 配当倍率` のエメラルドを獲得します。
- **外れたとき** … 賭けた選手が負けると、賭け金は戻ってきません。

### 配当倍率

配当倍率は、賭けた選手と相手選手のランク差で決まります。

| 賭けた選手の立場 | 配当倍率 |
|---|---|
| 相手と同ランク | 2.0 倍 |
| 相手より格下（ランクが低い） | 2.0 + ランク差 × 0.1 倍 |
| 相手より格上（ランクが高い） | 2.0 − ランク差 × 0.1 倍 |

!!! tip "番狂わせを狙うと配当が大きい"
    格下の選手に賭けて勝てば、ランク差が大きいほど高い配当（最大で2倍以上）が手に入ります。逆に格上の選手は勝っても配当倍率が下がります。

## ランキング

各プレイヤーのバトルパスランクはサーバーに保存され、ログアウトしても引き継がれます。ランク一覧の確認はOP向けのコマンドです（プレイヤーは自分の現在ランクを試合開始時のアナウンスなどで確認できます）。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/pvp join` | 待機キューに参加する（入場料が必要） |
| `/pvp bet <選手名> <量>` | 進行中の試合の選手にエメラルドを賭ける |
| `/pvp list` | 待機キューに並んでいるプレイヤーを表示する |

!!! note "`/1v1` でも使えます"
    `/pvp` の代わりに `/1v1` と入力しても同じコマンドが使えます（例: `/1v1 join`）。

## よくある質問

??? question "参加にいくらエメラルドが必要ですか？"
    入場料は `バトルパスランク × 10` エメラルドです。初期ランクR3なら30個、R5なら50個必要です。インベントリにその数のエメラルドを持った状態で `/pvp join` してください。

??? question "`/pvp join` したのに試合が始まりません"
    試合の開始はOPが `/pvp start` で行います。キューが2人そろっても自動では始まりません。OPに声をかけましょう。

??? question "負けたらどうなりますか？"
    バトルパスランクが1つ下がります（最小R1）。賞金はありません。なお、試合終了後は参加前にいた場所へ自動で戻されます。

??? question "賭けたエメラルドは戻ってきますか？"
    賭けた選手が勝てば `賭け金 × 配当倍率` を獲得できますが、負けた場合は賭け金は戻りません。

??? question "観戦中でも試合に参加できますか？"
    観戦と賭けは試合に参加していないプレイヤー専用です。自分が選手として戦うには、次の試合で `/pvp join` してキューに並んでください。
