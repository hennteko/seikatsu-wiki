# どうぶつ積みバトル ― 遊び方 { .page-player #tsumibattle-player }

順番に動物のかたちのピースを土台へ積み上げ、自分の番にタワーを崩したり、ピースを落としたりしたら負けです。最後まで残った1人が勝ちます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | 2〜4人の手番制（順番に1手ずつ積む） |
    | 勝敗 | タワーを崩す・ピースを下まで落とした人が負け。最後の1人が勝ち |
    | 引き分け | タワーが高さの上限に届いたとき |
    | 1手の操作 | ← 左へ / → 右へ / ⟳ 回転 / ▼ 落とす（操作アイテムを右クリック） |
    | 持ち時間 | 1手 既定20秒（過ぎるとその位置で自動的に落下） |
    | 参加方法 | ロビーの参加看板、または `/tsumi join` |
    | 記録 | 勝ち・負け・引き分け・最高タワー高さ（`/tsumi stats` / `/tsumi top`） |

## どんなゲーム？

試合が始まると全員が観戦席に座り、1人ずつ順番に手番が回ってきます。手番になると **動物のピースが1つ** 配られ、タワーの一番上の少し上から出現します。操作アイテムで位置と向きを決めて落とすだけの、かんたんだけど奥の深い積み上げゲームです。

- 自分が落としたピースで **タワーが崩れたら負け**。
- 自分のピースが土台に乗らず **下まで落ちてしまっても負け**。
- 負けた人は抜け、残りのメンバーで続行します。**最後まで残った1人が勝ち** です。
- タワーが **高さの上限** に届いたら、そこまで残っていた全員が引き分けになります。

## 手番の流れ

1. **自分の番** になると「あなたの番です」と表示され、ホットバーに操作アイテムが配られます。配られたピースがタワーの上に出現します。
2. **← 左へ／→ 右へ／⟳ 回転** で位置と向きを調整します。
3. **▼ 落とす** で真下へ落とします。ほかのピースか土台に着地すると、その場に固定されます。
4. 着地すると **安定判定** が働きます。タワーが安定していれば次の人の番へ、崩れたら・落ちたら、その人の負けです。
5. **持ち時間（既定20秒）** を過ぎると「時間切れ！」となり、その位置で自動的に落ちます。残り5秒を切ると音で知らせます。

## 操作アイテム

自分の番になると、ホットバーに次のアイテムが並びます。**右クリック（統合版はタップ／長押し）** で操作します。

| スロット | アイテム | 操作 |
|---|---|---|
| 1 | &nbsp;← 左へ（矢） | ピースを1マス左へ |
| 2 | → 右へ（スペクトル矢） | ピースを1マス右へ |
| 3 | ⟳ 回転（時計） | ピースを90°回す |
| 4 | ▼ 落とす（金床） | ピースを真下へ落とす |
| 9 | ⓘ ルール（本） | 遊び方を表示 |

自分の番ではないときは、1〜4が灰色の「待機中」になり操作できません。壁や他のピースにぶつかって動かせないときは低い音が鳴ります。

!!! tip "回転のコツ"
    回転したときに周りにぶつかる場合、プラグインが自動で少し左右にずらして置ける位置を探します（最大2マスまで）。それでも置けないときは回転できず、音で知らせます。

## ピースの種類

動物をかたどったピースが、重み付きのランダムで配られます。既定では次のピースが用意されています（サーバーによって追加・変更されている場合があります）。

| ピース | ピース | ピース | ピース |
|---|---|---|---|
| カメ | ウシ | ラマ | ニワトリ |
| ウーパールーパー | イカ | キツネ | ウサギ |
| ヒツジ | ブタ | スライム | パンダ |

!!! note "同じピースの連続"
    同じピースばかりが続かないよう、直前に出たピースが一定回数（既定2回）続くと、次は別のピースが選ばれやすくなります。ピースごとに大きさ・形・出やすさが違います。

## 勝敗と引き分け

- **崩れた** … 着地したピースのせいでタワーの重心が崩れると「くずれた！」と表示され、崩れたピースが吹き飛びます。崩した人の負けです。
- **おちた** … 自分のピースが土台に乗らず、土台から規定マス（既定6マス）より下まで落ちると「おちた！」と表示され、その人の負けです。
- **最後の1人** … 負けが続き残り1人になると、その人の勝ちです。
- **引き分け** … タワーが高さの上限（アリーナごとの設定）に届いたときは、残っていた全員が引き分けになります。
- 試合中に **離脱・切断** すると、その人は負け扱いになります。

## 記録とランキング

試合の結果は記録され、サーバー全体にも結果が告知されます。

- `/tsumi stats [プレイヤー]` … 勝ち・負け・引き分け・プレイ回数・勝率・最高タワー高さを表示します（省略すると自分）。
- `/tsumi top` … 勝ち数ランキングを表示します。
- ロビーの **ランキング看板** でも上位を確認できます。

## 参加方法

1. ロビーの **参加看板** をクリック、または `/tsumi join`。ロビーへ移動し、元の持ち物は安全に預かられます。
2. **開始看板** をクリック、または `/tsumi start [アリーナ]`（全員可）で開始します。開始には最低人数（既定2人）が必要です。
3. 離脱は **離脱看板** か `/tsumi leave`。試合中に離脱すると負け扱いになります。

試合が進行中のときに参加した場合は、次の試合から参加できます。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/tsumi join` | ロビーに参加する（参加看板と同等・全員可） |
| `/tsumi leave` | ロビーから離脱する（離脱看板と同等。試合中は負け扱い・全員可） |
| `/tsumi start [アリーナ]` | 試合を開始する（開始看板と同等・全員可） |
| `/tsumi status` | 現在の設定・状況を確認する（全員可・読み取り専用） |
| `/tsumi stats [プレイヤー]` | 自分または指定した人の記録を見る |
| `/tsumi top` | 勝ち数ランキングを見る |

## よくある質問

??? question "ピースの位置はどこまで動かせますか？"
    プレイ面の幅の中だけです。左右の端や、すでに積まれたピースにぶつかる位置へは動かせません（低い音で知らせます）。

??? question "持ち時間を過ぎたらどうなりますか？"
    「時間切れ！」と表示され、そのときの位置でピースが自動的に落とされます。持ち時間はサーバー設定によっては無制限になっている場合もあります。

??? question "自分のピースで崩れていないのに負けになりました。"
    崩れは「そのピースを置いた人」の責任になります。前のピースのせいでギリギリだったタワーでも、あなたのピースが着地した瞬間に崩れたら、あなたの負けです。慎重に位置を選びましょう。

??? question "自分で用意した持ち物は使えますか？"
    いいえ。ロビーに入った時点で元の持ち物は安全に預かられ、試合中の手持ちは操作アイテムだけです。離脱すると元どおり戻ります。
