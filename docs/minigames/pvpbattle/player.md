# PvPバトル ― 遊び方 { .page-player #pvpbattle-player }

ロビーに集まり、**FFA・チーム戦・大将戦** の3モードから選んで戦う PvP ミニゲームです。装備は自動で配られ、自分の持ち物は参加中だけ安全に預かられます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | モード | FFA（全員対戦）／チーム戦（赤 vs 青）／大将戦（勝ち抜き） |
    | 人数 | 最低2人〜最大24人（運営の設定で変更可） |
    | 装備 | モードごとに自動配布（FFAは鉄、チーム戦・大将戦はダイヤ） |
    | 勝敗 | FFA＝制限時間内のキル数 / チーム戦＝先取ラウンド / 大将戦＝相手を全員倒し切る |
    | 参加方法 | ロビーの参加看板、または `/pvpbattle join` |

## 全体の流れ

1. **参加看板** をクリック、または `/pvpbattle join` でロビーに入ります。入った瞬間に元の持ち物・装備は安全に預かられ、アドベンチャーモードでロビーに移動します。
2. 人数が集まったら、**開始看板**（FFA／チーム／大将のいずれか）をクリック、または `/pvpbattle start <ffa|team|taisho>` で開始します（開始は全員が実行できます）。
3. カウントダウンの後に試合が始まり、モードごとの装備が配られます。
4. 決着すると結果が表示され、しばらくしてロビーへ戻ります。次の試合をそのまま待てます。
5. やめるときは **退出看板** か `/pvpbattle leave`。預けていた持ち物・体力・経験値が元どおり戻ります。

!!! note "途中参加は次の試合から"
    試合が進行中のときに参加すると、その試合はいったん観戦になり、**次の試合から** 参加できます。

## FFA（全員対戦）

全員が敵の個人戦デスマッチです。

- 開始すると **フィールド内のランダムな地点** にスポーンし、鉄フル装備・鉄剣・鉄斧・盾・弓・矢・パンが配られます。
- 倒されても制限時間内は **何度でもリスポーン** します。リスポーン直後は短い **無敵時間**（既定3秒・発光で表示）があります。
- **制限時間（既定5分）** 内の成績で勝敗が決まります。順位は **キル数が多い順、同じならデス数が少ない順**。
- 時間切れのときに **トップが1人** ならその人の勝ち。**同率トップが複数** いる場合は **サドンデス** に入ります。

!!! tip "サドンデス"
    同率トップの人だけが生き残り、ほかは観戦になります。**次に1キルした人が即勝利**（ゴールデンゴール）です。

## チーム戦（赤 vs 青）

赤チームと青チームに分かれ、ラウンドを取り合う先取制です。

- 装備はダイヤフル装備・ダイヤ剣・鉄斧・盾・弓・矢・パン・金リンゴ。各ラウンド開始時に自チームのスポーンから全回復＆装備再配布で始まります。
- **各ラウンドはリスポーンなし**。倒されるとそのラウンドは観戦になり、次のラウンドから復帰します。
- **相手チームを全滅させた側がそのラウンドの勝ち**。両チーム同時に全滅した場合は引き分けで、そのラウンドを再戦します。
- 先に **先取ラウンド数（既定3本）** に達したチームが勝利です。
- チーム分けは運営の設定により **ランダム / 手動（OPが割り当て） / ドラフト（大将が交互に指名）** のいずれかで行われます。

## 大将戦（勝ち抜き）

各チームが並べた出場順どおりに、**1対1** で順番に戦う勝ち抜き戦です。仕組みが独特なので、流れを順に見てください。

**準備（開始を押した人＝OPがGUIで進めます）**

1. **大将を2人決める** … 各チームの大将（＝勝ち抜き戦の最後に出る人）を2人選びます。ランダムでも、GUIで指名でも決められます。
2. **メンバーを振り分ける** … 残りの参加者を赤・青に振り分けます（ランダム、またはGUIで手動）。大将はそれぞれのチームに固定されます。
3. **出場順を決める** … 赤→青の順に、各チームの大将が自チームメンバーの **出場順** をGUIで決めます。**大将は必ず最後（最終鋒）** に回ります。メンバーが大将1人だけのチームは順番決めを飛ばします。

**対戦**

1. 全員がいったん観戦状態になり、両チームの **先頭の2人** がそれぞれのスポーンに出撃して1対1で戦います。装備はチーム戦と同じダイヤ装備です。出撃直後は短い無敵時間があります。
2. 負けた側は **次の出場者** が出撃します。**勝った側はそのまま** 体力・持ち物を引き継いで連戦します（回復・補充はありません。削られた体力のまま次の相手と戦います）。
3. これを繰り返し、**片方のチームの出場者（最後の大将まで）を全員倒し切った** チームの勝ちです。

!!! tip "大将戦は『連勝するほど不利になる』勝ち抜き戦"
    勝った人は回復しないまま次の相手に挑むので、1人で何人も倒すほど体力が削れていきます。誰を先鋒にし、大将の手前に誰を置くか（出場順）が勝敗を分けます。

## 装備について

装備はモードごとに **自動で配布** されます。自分で用意した持ち物は使いません（ロビーに入った時点で安全に預かられ、離脱・終了で戻ります）。

| モード | おもな装備 |
|---|---|
| FFA | 鉄フル装備・鉄剣・鉄斧・盾・弓・矢32・パン64 |
| チーム戦 | ダイヤフル装備・ダイヤ剣・鉄斧・盾・弓・矢32・パン64・金リンゴ5 |
| 大将戦 | チーム戦と同じ（ダイヤ装備一式） |

## 成績

キル・デス・勝利・試合数が記録されます。`/pvpbattle stats` で自分の成績を、`/pvpbattle stats <名前>` で他の人の成績を確認できます（読み取り専用）。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/pvpbattle join` | ロビーに参加する（参加看板と同等） |
| `/pvpbattle leave` | ロビーから退出する（退出看板と同等。持ち物が戻る） |
| `/pvpbattle start <ffa\|team\|taisho>` | 指定モードで開始する（開始看板と同等・全員可） |
| `/pvpbattle status` | 設定・現在の状況を確認する（読み取り専用） |
| `/pvpbattle stats [名前]` | 成績（キル／デス／勝利／試合数）を確認する |

!!! note "別名コマンド"
    `/pvpbattle` は `/pvpb` と短く打つこともできます。

## よくある質問

??? question "どのモードで遊ぶかは誰が決めますか？"
    開始したモードで決まります。FFA用・チーム用・大将用の開始看板がそれぞれ用意されていれば、押した看板のモードで始まります。`/pvpbattle start <ffa|team|taisho>` でも指定でき、開始は全員が実行できます。

??? question "自分の持ち物は消えませんか？"
    消えません。ロビーに入った時点で持ち物・装備・体力・経験値が安全に預かられ、退出や試合終了で元どおり戻ります。預けたデータはファイルに保存されるので、サーバーが再起動しても失われません。

??? question "FFAで同点になったらどうなりますか？"
    同率トップが1人ならその人の勝ちです。複数いる場合はサドンデスになり、その人たちだけが残って、次に1キルした人が勝ちます。

??? question "チーム戦で倒されたら復活できますか？"
    そのラウンド中は復活できず、観戦になります。次のラウンドの開始時に全員が復帰します。

??? question "大将戦で勝ち続けると体力は回復しますか？"
    しません。勝った人は体力も持ち物もそのまま次の相手に挑みます。連勝するほど不利になるのが大将戦の特徴です。
