# WindPvP（ウインドチャージPVP） ― 遊び方 { .page-player #windpvp-player }

無限ウインドチャージで相手を吹き飛ばし、場外へ落として撃破する残機制の個人戦です。全員が同じ装備でスタートし、最後の1人を目指します。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | 個人戦（FFA・全員が敵） |
    | 人数 | 2〜12人（サーバー設定により変更されることがあります） |
    | 勝利条件 | 最後の1人として生き残る |
    | 残機 | 既定3。0で脱落 |
    | 参加方法 | ロビーの参加看板、または `/windpvp join`（`/wpvp join`） |

## どんなゲーム？

全員が共通装備でスタートする個人戦です。剣・弓で戦いつつ、**ウインドチャージ**の爆風で相手を吹き飛ばし、**奈落・溶岩・縮小する境界の外**へ落として撃破します。倒されると残機が1減り、数秒後にリスポーン（直後は無敵）。残機が0になると脱落（観戦）し、最後まで残った1人が勝者です。

## 装備（ロードアウト）

開始時・リスポーン時に、次の装備が配られます（サーバー設定で変更されることがあります）。

| スロット | 装備 |
|---|---|
| 1 | 鉄の剣 |
| 2 | 弓 |
| 3 | 無限ウインドチャージ |
| 4 | パン ×32 |
| 5 | 矢 ×32 |
| オフハンド | 盾 |

## ウインドチャージの使い方

**ウインドチャージは投げても減りません（無限）**。ただし連続では撃てず、**クールダウン（既定5秒）** があります。

- 相手の足元に当てると **大きく吹き飛ばせます**。場外際で当てて落とすのが基本の撃破手段です。
- 自分の足元に当てて **移動・緊急回避** にも使えます（爆風で跳ぶ）。
- 剣のノックバックや弓と組み合わせて、相手を境界外・奈落へ追い込みましょう。

## 残機とリスポーン

倒される（または場外・境界外で力尽きる）と残機が1減ります。少し待って（既定5秒）リスポーンし、**直後は一定時間（既定10秒）無敵**です。残機が0になると脱落し、観戦に切り替わります。

## フィールド境界（縮小）

試合が一定時間（既定300秒）経過すると、**フィールドの境界が縮小**し始めます（一定間隔で内側へ）。境界の外にいると継続ダメージを受けるので、狭まるエリアの内側で戦いましょう。境界が設定されていないマップでは、奈落・溶岩などマップ側の即死判定のみで進行します。

## 勝利条件

残機が残っているプレイヤーが **1人だけ** になった時点でゲーム終了、その人の勝利です。

## 参加方法

1. ロビーの **参加看板** をクリック、または `/windpvp join`。
2. 開始看板のクリックまたは `/windpvp start`（全員可）でゲーム開始。
3. 各自のスポーン地点に配置され、戦闘が始まります。

離脱は **離脱看板** か `/windpvp leave` です。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/windpvp join` | ロビーに参加する（参加看板と同等・全員可） |
| `/windpvp leave` | ロビーから離脱する（離脱看板と同等・全員可） |
| `/windpvp start` | ゲームを開始する（開始看板と同等・全員可） |
| `/windpvp status` | 現在の設定・状況を確認する（全員可） |
| `/windpvp stats [名前]` | 成績を確認する（全員可・読み取り専用） |

!!! note "コマンドの短縮形"
    `/windpvp` は `/wpvp`・`/windcharge` と短縮できます。

## よくある質問

??? question "ウインドチャージは何個持てますか？"
    実質無限です。投げても減りませんが、クールダウン（既定5秒）の間は次を撃てません。

??? question "倒されたら終わりですか？"
    いいえ。残機がある限りリスポーンします。残機が0になると脱落（観戦）です。

??? question "どうやって相手を倒すのが効率的？"
    場外・境界際にウインドチャージを当てて落とすのが強力です。剣のノックバックや弓で崩してから吹き飛ばすと決まりやすいです。
