# WindPvP（ウインドチャージPVP） <span class="badge done">公開中</span>

**無限ウインドチャージ** で相手を吹き飛ばし、奈落や縮小する境界の外へ落として撃破する、**残機制の個人戦（FFA）落としあいPvP** です。全員が共通装備でスタートし、剣・弓・盾で戦いつつ、ウインドチャージの爆風で相手の体勢を崩して場外へ。残機が尽きた人から脱落し、最後の1人が勝者です。

!!! note "ゲームの特徴"
    全員が **鉄剣・弓・盾・無限ウインドチャージ** を持ってスタートする個人戦（FFA）です。ウインドチャージは **投げても減らず**、一定クールダウン（既定5秒）で撃てます。爆風で相手を吹き飛ばし、**奈落・溶岩・縮小する境界の外** へ落として撃破します。倒されると残機が減り、少し待ってリスポーン（直後は無敵時間あり）。時間が経つと **フィールド境界が縮小** して逃げ場が狭まり、最後の1人が勝ちます。
