# ブロックフォール（BlockFall） ― OP・運営ガイド { .page-op #blockfall-op }

ブロックフォールの導入・ブース（プリセット）の建て方・看板・管理ツール・config・権限・管理コマンドをまとめます。地点・ブース・看板はコマンド（または管理メニュー）で登録すると即 config に自動保存されます。

## 基本情報

| 項目 | 値 |
|---|---|
| プラグイン名 | BlockFall |
| メインコマンド | `/blockfall`（別名 `/bf`） |
| api-version | 26.1.2 |
| softdepend | `floodgate` / `Geyser-Spigot`（統合版対応） |
| 設定ファイル | `plugins/BlockFall/config.yml` |
| 記録 | `plugins/BlockFall/records.yml` |
| 権限ノード | `blockfall.admin`（既定OP） |

## 導入手順

1. ビルドした `BlockFall-1.0.0.jar` をサーバーの `plugins/` に置き、サーバーを再起動する（config.yml が作られる）。
2. `/bf setstartspawn`・`/bf setlobby` で初期スポーン（離脱時の戻り先）とロビーを設定する。
3. **平らな地面** を用意し、盤面を建てたい方向を向いて、座席にしたい場所に立って `/bf addbooth booth1` を実行する（プリセットが自動で建つ）。
4. 2基目以降は管理メニューの **「右隣に建設」** を押すと、同じ向きで横に並べて建てられる（4基が目安）。
5. 参加・離脱・開始（マラソン／スプリント）の看板を登録する。
6. `/bf testbooth` と管理メニューの「座席へ移動」で、座席から盤面全体が見えるか確認する。
7. `/bf status` で設定状況を確認する。

## ブース（プリセット）

ブースは手で建てる必要はありません。`/bf addbooth` を実行した **立ち位置が座席** になり、**向いていた方向（東西南北に丸める）の先 16 マス** に、枠つきの面（横22×縦22）が自動で建ちます。

| 部分 | 大きさ | 位置 |
|---|---|---|
| 盤面 | 横10×縦20 | 面の中央。一番下の行は地面の1段上 |
| ホールド | 横4×縦2 | 盤面の左（1マス空けて）、上端を盤面にそろえる |
| ネクスト | 横4×縦14（5個分） | 盤面の右（1マス空けて）、上端を盤面にそろえる |
| 枠 | 横22×縦22 | 全体を `frame-block` で囲む |
| 座席 | 1マス | 立ち位置。座ると盤面の方向を向き、25°上を見る |

!!! warning "建てられない場所"
    次の場合は理由を表示して何もしません。
    
    - ほかのブースの面・座席と重なる
    - 建てる範囲にチェストなど中身のあるブロック、登録看板がある
    - 建てる範囲の一部が読み込まれていない（近くまで行ってから実行）
    
    範囲内のそれ以外のブロック（草・花・土など）は上書きします。地面の凹凸は確認しないので、平らに整えてから建ててください。

!!! note "ブースを置くワールド"
    メインのワールドなど、**サーバー起動時に読み込まれるワールド** に置いてください。後から読み込むワールド（Multiverse など）だと、ワールドが無い間は「ワールド未読み込み」になり、割り当てに使われません。

- ブースの面と座席は保護されます。OP 以外は壊す・置くができず、使用中のブースは OP でも触れません。爆発・ピストン・燃焼でも変わりません。
- `frame-block`・`seat-distance` を変えたら、既存のブースは `/bf rebuild` で建て直してください（使用中はできません）。
- `/bf delbooth` は建てたブロックを空気に戻してから削除します。

## セットアップ手順（コマンド）

地点・ブースは **実行した位置** を使い、看板系は看板を **見ながら**（6ブロック以内）実行します。すべて `blockfall.admin` 権限が必要です。

```text title="初期スポーン（離脱・途中抜けの戻り先／その場に立って実行）"
/bf setstartspawn
```

```text title="ロビー（その場に立って実行）"
/bf setlobby
```

```text title="ブースを建てる（平らな地面で、盤面を建てたい方向を向き、座席にしたい場所に立って実行）"
/bf addbooth booth1
```

```text title="見え方を確認する（もう一度で消す）"
/bf testbooth booth1
```

```text title="参加看板を登録（看板を見て実行）"
/bf setsign join
```

```text title="離脱看板を登録（看板を見て実行）"
/bf setsign leave
```

```text title="マラソンの開始看板を登録（看板を見て実行）"
/bf setsign start marathon
```

```text title="スプリントの開始看板を登録（看板を見て実行）"
/bf setsign start sprint
```

```text title="視線先の看板の登録を解除"
/bf setsign delete
```

```text title="ブースを建て直す（枠・距離を変えたあと）"
/bf rebuild booth1
```

```text title="ブースを撤去して削除"
/bf delbooth booth1
```

!!! note "ブース名について"
    ブース名は英数字・`_`・`-` で16文字以内です（`.` と `all`・`marathon`・`sprint` は使えません）。ブースが1つだけのときは `rebuild`・`testbooth`・`stop` でブース名を省略できます。

## 管理ツール（OP専用）

`/bf wand` で管理ツール（ブレイズロッド）を受け取り、右クリック（統合版はタップ/長押し）で管理メニューを開きます。`/bf menu` でも開けます。

- 数値：＋/−ボタンでロビー最大人数・開始カウントダウン・ネクスト表示数・スプリント目標を変更（即保存）
- 地点：ボタンを押すと立ち位置に設定（ロビー／初期スポーン）
- 看板：看板を見ながら（5ブロック以内）押すと参加／離脱／開始看板を登録（開始看板はマラソン・スプリントを選ぶ画面が出ます）、ハサミで登録解除
- ブース：「新規ブース（立ち位置に建設）」「右隣に建設」、ブースのボタンからブースごとの設定画面（建て直し・表示テスト・座席へ移動・強制停止・ブース削除）
- 運用：開始（モードを選んで押した本人が遊ぶ）・設定状況・リロード・強制停止（強制停止とブース削除は5秒以内に2回押し）
- 切り替え：移動キー操作・効果音の ON/OFF、ランキングの表示
- ブロックフォールに参加中は受け取れません（離脱してから実行）。捨てると消えるので再度 `/bf wand` で取得してください
- 統合版：チェストGUIで操作できます。数値は左右クリックに頼らず＋/−の別ボタンで操作します

## config.yml 設定項目

地点・ブース・看板のデータ（`default-spawn`・`lobby-spawn`・`sign`・`leave-sign`・`start-sign`・`booths`）はコマンドで登録すると自動保存されます（手書き不要）。数値の変更は **次のゲームから** 反映されます。

### ロビー・進行

| キー | 既定値 | 説明 |
|---|---|---|
| `max-lobby-players` | 16 | ロビーの定員 |
| `start-countdown-seconds` | 3 | 開始前のカウントダウン（0 ですぐ開始） |
| `result-seconds` | 3 | 結果を表示してからロビーへ戻すまで（秒） |
| `pause-max-seconds` | 300 | 一時停止の上限（秒）。過ぎると「やめる」扱い |

### ルール

| キー | 既定値 | 説明 |
|---|---|---|
| `next-count` | 3 | ネクストの表示数（1〜5） |
| `lock-delay-ticks` | 10 | 床に着いてから固定されるまでの猶予（tick） |
| `lock-reset-limit` | 15 | 床に着いたあと、移動・回転で猶予が戻る最大回数 |
| `lines-per-level` | 10 | レベルが1上がるのに必要なライン数 |
| `sprint-lines` | 40 | スプリントの目標ライン数 |
| `gravity-ticks` | Lv1=20 … Lv15=0.5 | レベルごとの「1マス落ちるまでの tick 数」。表に無いレベルは直前の値。1 未満は 1tick に複数マス |

### 操作

| キー | 既定値 | 説明 |
|---|---|---|
| `movement-input-enabled` | true | 移動キー操作（A/D・S・ジャンプ・スニーク）を使う |
| `das-ticks` | 4 | 左右キーを押しっぱなしにしてから連続移動が始まるまで（tick） |
| `arr-ticks` | 1 | 連続移動の間隔（tick） |
| `soft-drop-ticks` | 1 | S を押しっぱなしにしたときの落下間隔（tick） |
| `bedrock-resend-slot` | true | 統合版はホットバーを押したあと、5番の選択を送り直す |

### ブース・ブロック

| キー | 既定値 | 説明 |
|---|---|---|
| `seat-distance` | 16 | 座席から盤面までのマス数（12〜24）。変えたら `/bf rebuild` |
| `frame-block` | SMOOTH_QUARTZ | 枠のブロック。変えたら `/bf rebuild` |
| `seat-pitch` | 25 | 座ったときに上を向く角度（0〜45） |
| `booth-spacing` | 24 | 「右隣に建設」の間隔（22以上） |
| `colors.I`〜`colors.L` | 水色・黄・紫・黄緑・赤・青・橙のコンクリート | ピースのブロック |
| `empty-block` | BLACK_CONCRETE | 空きマス |
| `ghost-block` | LIGHT_GRAY_STAINED_GLASS | ゴースト（落下先）・使えないときのホールド表示 |

### 音・環境

| キー | 既定値 | 説明 |
|---|---|---|
| `sounds-enabled` | true | 消去・固定・レベルアップの効果音（本人だけに鳴らす） |
| `keep-food` | true | プレイ中は満腹度を減らさない |
| `messages.prefix` | `&8[&bブロックフォール&8] &r` | メッセージの接頭辞 |
| `config-version` | 1 | 設定ファイルの版（変更しない） |

!!! info "config の自動更新"
    プラグインを更新すると、起動時に足りない項目だけが `config.yml` に自動で追加されます（設定済みの値はそのまま。旧ファイルは `config.yml.bak-日時`）。追加した項目はコンソールに「config.yml に N 項目を追加しました」と表示されます。

## 管理コマンド

| コマンド | 説明 |
|---|---|
| `/bf wand` | 管理ツール（ブレイズロッド）を受け取る |
| `/bf menu` | 管理メニュー（GUI）を開く |
| `/bf setstartspawn` | 初期スポーン（離脱時の戻り先）を設定 |
| `/bf setlobby` | ロビー地点を設定 |
| `/bf setsign <join\|leave\|start <marathon\|sprint>\|delete>` | 看板を登録／解除 |
| `/bf addbooth <ブース>` | 立ち位置にプリセットを建ててブースを追加 |
| `/bf delbooth <ブース>` | ブースを撤去して削除（使用中は不可） |
| `/bf rebuild [ブース]` | 枠と空きマスを建て直す（使用中は不可） |
| `/bf testbooth [ブース]` | 表示テスト（左下が白・右上がゴースト。もう一度で消す） |
| `/bf booths` | ブース一覧 |
| `/bf stop [ブース\|all]` | 強制停止（記録なし。プレイヤーはロビーへ戻る・在籍は維持） |
| `/bf reload` | 設定ファイルの再読み込み（プレイ中のゲームは次から反映） |
| `/bf lobbyfix <プレイヤー> [force]` | ロビー前の持ち物の手動復旧（`force` で退避データ破棄） |
| `/bf resetrecord <プレイヤー> [marathon\|sprint]` | 記録の削除（モードを省くと両方） |

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/bf join` | ロビーに参加（参加看板と同じ） |
| `/bf leave` | ロビーから離脱（離脱看板と同じ） |
| `/bf start <marathon\|sprint> [プレイヤー]` | 空いているブースで開始。プレイヤー指定はコンソール・コマンドブロック・OP 用 |
| `/bf status` | 設定・状況を確認（読み取り専用） |
| `/bf top <marathon\|sprint>` | ランキング上位10人 |

## 権限ノード

| 権限ノード | 既定 | 用途 |
|---|---|---|
| `blockfall.admin` | OP | セットアップ・看板・ブースの建設・`wand`・`menu`・`stop`・`reload`・`lobbyfix`・`resetrecord` など管理系すべて |

!!! info "権限不要で全員が使えるコマンド"
    `/bf join`・`/bf leave`・`/bf start`・`/bf status`・`/bf top` は権限チェックがなく、全プレイヤーが使えます。`start` はコンソール・コマンドブロックからも実行できます（`/bf start sprint <プレイヤー>`）。

## 進行のルール

- 人数がそろっても自動では始まりません。開始は開始看板・`/bf start`・管理メニューの開始ボタンだけです。
- ロビーに未参加の人が開始看板を押すと、参加してから始めます。
- ゲームが終わってもロビーには残ります（持ち物は空のまま。離脱すると戻る）。
- プレイ中の離脱・切断はゲームオーバー扱い（マラソンは記録、スプリントは記録なし）。切断した人は再ログイン時に持ち物が戻り、初期地点へ送られます（ゲームには戻りません）。
- 全体へのお知らせは「ロビー参加」と「ランキング1位の更新」だけです。それ以外の表示・効果音は本人だけに出ます。

## 統合版について

- ホットバー操作はキャンセルで5番に残す方式です。統合版はキャンセルだけでは戻らないことがあるため、1tick 後に5番の選択を送り直します（`bedrock-resend-slot`）。
- 移動キー操作（PlayerInputEvent）は統合版から届かないことがあります。届かなくてもホットバー操作だけで全部の操作ができます。
- サイドバーの数字は Java 版では消していますが、統合版では並び順の数字が見えることがあります。
- 座席から盤面全体がスマホの画面に収まるかは、実機で確認してください（`seat-distance`・`seat-pitch` で調整）。
- コントローラー（ゲームパッド）だけで遊ぶ人は、ホットバーを左右に1つずつしか動かせないため、左右移動しかできません。数字キーかタッチ操作が必要です。
- スニーク（ホールド）を押すと、統合版では座席の乗車を送り直して画面とサーバーをそろえます。

## その他の注意

- ほかのプラグイン（保護・アンチチートなど）が座席への乗車を止めると、開始できないか、その場でゲームを止めます（記録なし）。コンソールに警告が出ます。
- 使用中のブースは、`/bf reload` で config を変えても入れ替えません（終わってから再度 `/bf reload`）。
- ロビー・初期スポーンを、起動後に読み込まれるワールドに置いた場合も、ワールドが読み込まれた時点で使われます。

## トラブルシューティング

??? failure "開始看板を押しても始まらない"
    `/bf status` を確認してください。ブースが無い・すべて使用中・ワールドが読み込まれていない場合は始まりません。開始看板の3行目に空きブースの数が出ます。

??? failure "ブースが建てられない"
    表示された理由を確認してください。重なり・チェスト・登録看板・読み込まれていない範囲があると建ちません。隣のブースとは `booth-spacing`（既定24マス）以上離してください。

??? failure "座席から盤面の上（またはネクスト）が見えない"
    `seat-pitch`（上を向く角度）を大きくするか、`seat-distance` を大きくして `/bf rebuild` してください。視野（FOV）が狭い設定の人は見えにくくなります。

??? failure "ロビーに入る前の持ち物が戻らない"
    `/bf lobbyfix <プレイヤー>` で復旧できます。退避データは `plugins/BlockFall/lobby-inventory.yml` に保存され、再起動・クラッシュをまたいでも復元されます。どうしても戻らない場合のみ `force` を付けると退避データを破棄してロックだけ解除します（最終手段）。

??? failure "サーバーが落ちたあと、盤面に色が残っている"
    起動時にすべてのブースの盤面を空きマスに戻します。残っていたら `/bf rebuild <ブース>` を実行してください。

## 全ゲーム共通の改修

- **名前表示** … 参加中はチャット名・Tabリスト名・頭上の名札が「【ブロックフォール】名前」になり、離脱で元に戻ります（`name-tag.display-name` / `name-tag.color`）。プレイ中のサイドバーにも反映されます。
- **参加の全体告知** … 参加時にサーバー全体へ通知します（`name-tag.announce-join`）。
- **同時参加は1ゲームまで** … 他ミニゲームに参加中は参加が拒否されます（スコアボードタグ `minigame_lobby:BlockFall`）。
- **退避データのファイル保存（LobbyInventory）** … ロビー入場時に退避した所持品を `lobby-inventory.yml` に保存し、クラッシュ後の再ログインでも復元します。
- **config の自動追記（ConfigUpdater）** … 起動時に足りない項目を既定値＋コメント付きで追記します（既存の値は変えません）。
- **統合版対応（BedrockCompat）** … 空中タップでも管理ツールを使え、登録看板は蝋引きして編集画面が開かないようにします。

### ロビー・名前表示・統合版の config

| キー | 既定値 | 説明 |
|---|---|---|
| `lobby-inventory.enabled` | true | ロビー入退室時の持ち物退避／復元。**ブロックフォールは true が必須**（false だと持ち物を守れないため参加を断ります） |
| `lobby-inventory.gamemode` | ADVENTURE | ロビー滞在中のゲームモード |
| `lobby-inventory.clear-effects` | true | ロビー入場時にポーション効果を消す |
| `lobby-inventory.reset-health` | true | ロビー入場時に体力・満腹度を全回復 |
| `lobby-inventory.reset-exp` | true | ロビー入場時に経験値・レベルを0に |
| `lobby-inventory.expire-days` | 30 | 未復元の退避データの保持日数 |
| `name-tag.enabled` | true | 参加中の名前表示を付ける |
| `name-tag.display-name` | ブロックフォール | 「【】」に入れる正式名 |
| `name-tag.color` | AQUA | ゲーム名の色 |
| `name-tag.announce-join` | true | サーバー全体への参加通知 |
| `bedrock.wax-signs` | true | 登録看板を蝋引き |
| `bedrock.swing-to-use` | true | 統合版は空中タップでも管理ツールを使える |
| `bedrock.name-prefix` | `.` | Floodgate 未導入時に統合版と見なす名前の接頭辞 |
