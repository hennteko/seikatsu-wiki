# ブロックフォール（BlockFall） ― 遊び方 { .page-player #blockfall-player }

大きな盤面の前に座って、落ちてくるピースを並べ、横一列をそろえて消していく落ち物パズルです。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | 1人用パズル（マラソン／スプリント） |
    | 操作 | ホットバーの **1〜9 番キー**（Java 版は移動キーでも可） |
    | 盤面 | 横10×縦20、ネクスト3個、ホールド1個 |
    | 勝利条件 | マラソン＝高いスコア／スプリント＝40ラインを消すまでのタイム |
    | 参加方法 | 開始看板を押すだけ（参加看板、`/bf join` でも可） |
    | 開始 | 開始看板（マラソン／スプリント）、または `/bf start <marathon\|sprint>` |

## どんなゲーム？

開始看板を押すと **ロビーに参加** し、空いている **ブース** の座席に座ります。カウントダウンのあと、目の前の盤面の上からピースが落ちてきます。

- ピースは **7種類**（I・O・T・S・Z・J・L）。7種類が1回ずつシャッフルされて順に来るので、同じ形ばかり続くことはありません。
- **横一列** がそろうと消えます。一度に消すライン数が多いほど高得点です。
- 床に着いても少しの間（0.5秒）は動かせます。動かしたり回したりすると猶予が延びます（回数に上限あり）。
- ピースが一番上まで積み上がって、新しいピースが出られなくなったら **ゲームオーバー** です。

盤面の左に **ホールド**、右に **ネクスト**（次に来るピース）が表示されます。盤面の中の **薄い灰色のガラス** は、今のピースをそのまま落としたときの位置（ゴースト）です。

## 操作（ホットバー）

!!! tip "基本はホットバーのキーを押すだけ"
    座ると、ホットバーに操作アイテムが配られ、**5番（待機）** が選ばれた状態になります。押したい操作の **番号キー** を押すと、すぐに操作が実行されて 5 番のまま戻ります。同じキーを続けて押せます。

| キー | 操作 | アイテム |
|---|---|---|
| `1` | ホールド（取っておく／入れ替える） | チェスト |
| `2` | 左回転 ⟲ | 時計 |
| `3` | 1マス下へ（ソフトドロップ） | 石の感圧板 |
| `4` | 左へ ← | 矢 |
| `5` | 待機（何もしない） | ガラス板 |
| `6` | 右へ → | 矢 |
| `7` | 右回転 ⟳ | 時計 |
| `8` | 一気に落とす（ハードドロップ） | 金床 |
| `9` | 一時停止 | バリア |

- **Java 版はマウスホイール** を1目盛り回すと左右に動きます（上＝左、下＝右）。
- **同じキーをとても速く連打** すると、5番に戻る前の2回目が届かないことがあります（通信の往復の間）。左右の連続移動はホイールか移動キー（A/D の押しっぱなし）が確実です。
- 統合版のスマホはホットバーをタップ、PC は数字キーで操作します。
- ホールドは、取り出したピースを落とすまでもう一度は使えません（ホールド欄が薄い灰色になっている間は使えません）。
- 壁や床のそばで回せないときは、自動で位置を少しずらして回します。

## 操作（移動キー・Java 版向け）

座ったまま移動キーを押しても操作できます（サーバーの設定で有効なとき）。押しっぱなしにすると連続で動きます。

| キー | 操作 |
|---|---|
| `A` / `D` | 左右に動かす（押しっぱなしで連続） |
| `S` | 1マス下へ（押しっぱなしで連続） |
| ジャンプ | 一気に落とす |
| スニーク | ホールド（座席からは降りません） |

!!! warning "統合版の場合"
    統合版では移動キーの入力がサーバーに届かないことがあります。その場合はホットバー操作で遊んでください（ホットバー操作だけで全部の操作ができます）。

## モード

| モード | 内容 | 記録 |
|---|---|---|
| **マラソン** | 積み上がって負けるまでスコアを伸ばします。10ライン消すごとにレベルが上がり、落ちるのが速くなります | 最高スコア |
| **スプリント** | 40ラインを消すまでのタイムを競います。途中で負けたら記録なし | 最短タイム |

## スコア（マラソン）

| 操作 | 点数 |
|---|---|
| 1ライン消し | 100 × レベル |
| 2ライン消し | 300 × レベル |
| 3ライン消し | 500 × レベル |
| 4ライン消し | 800 × レベル |
| 1マス下へ（ソフトドロップ） | 1マスにつき 1点 |
| 一気に落とす（ハードドロップ） | 1マスにつき 2点 |

スコア・レベル・ライン数・時間は、画面右のサイドバーと画面下（アクションバー）に表示されます。

## 一時停止

`9` を押すと一時停止します。一時停止中は **盤面が隠れ**、スプリントのタイムも止まります。

| キー | 一時停止中の操作 |
|---|---|
| `3` / `5` | 再開（Java 版はホイールをどちらに回しても再開） |
| `9` | やめる（3秒以内にもう一度 `9` で確定） |

- やめた場合、マラソンはそれまでのスコアで記録します。スプリントは記録なしです。
- 一時停止が5分（サーバーの設定）を過ぎると、自動でやめた扱いになります。

## 結果とランキング

ゲームが終わると結果がタイトルとチャットに表示され、少しのあいだ最後の盤面を見られます。そのあと自動でロビーへ戻ります（ロビーには残っているので、すぐに次を遊べます）。

- **自己ベストを更新** すると「自己ベスト更新！」と表示されます。
- **ランキング1位を更新** すると、サーバー全体にお知らせが流れます。
- ランキングは `/bf top marathon`・`/bf top sprint` で見られます（上位10人）。

## 参加・離脱

1. **開始看板**（マラソン／スプリント）を押すと、ロビーへの参加と開始を一度に行います。
2. ロビーだけに入るときは **参加看板** か `/bf join`。
3. 離脱は **離脱看板** か `/bf leave`。元の持ち物が戻り、初期地点へ移動します。

- 空いているブースが無いときは開始できません（開始看板に空きブースの数が出ます）。
- ゲームの途中で離脱・切断すると、その時点でゲームオーバー扱いです（マラソンはスコアを記録、スプリントは記録なし）。
- ロビーに入ると元の持ち物は安全に預かられ、離脱すると元どおり戻ります。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/bf join` | ロビーに参加する（参加看板と同じ） |
| `/bf leave` | ロビーから離脱する（離脱看板と同じ） |
| `/bf start <marathon\|sprint>` | 空いているブースで開始する（モードは省略できません） |
| `/bf status` | 設定・状況を確認する（読み取り専用） |
| `/bf top <marathon\|sprint>` | ランキング上位10人 |

!!! note "コマンドの別名"
    メインコマンドは `/blockfall` ですが、短い `/bf` でも同じように使えます。

## 統合版で見え方・動きが違う点

- 移動キー操作は届かないことがあります（ホットバー操作で遊べます）。
- サイドバーの右側に並び順の数字が見えることがあります（Java 版では消しています）。
- 押したあとに5番へ戻る表示が少し遅れることがあります。
- **コントローラー（ゲームパッド）だけ** で遊ぶ場合、ホットバーは左右に1つずつしか動かせないため、左右移動しかできません（回転・一気に落とす・一時停止ができません）。数字キーやタッチ操作が使える機器で遊んでください。
- 盤面全体が画面に収まらないときは、OP に伝えてください（座席の向き・距離を調整できます）。

## よくある質問

??? question "連続で左右に動かすには？"
    Java 版はマウスホイールを回すか、移動キー（A/D）を押しっぱなしにします。統合版はキーを連打してください。

??? question "自分の道具は使えますか？"
    いいえ。プレイ中に持てるのは配られた操作アイテムだけです。元の持ち物は離脱すると元どおり戻ります。

??? question "座席から降りられません"
    プレイ中は降りられません（スニークはホールドに使います）。やめるときは `9` で一時停止してから、`9` を3秒以内に2回押してください。

??? question "一時停止中に盤面を見て考えられますか？"
    いいえ。一時停止中は盤面が隠れます。
