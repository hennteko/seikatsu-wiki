# スナイパーバトロワ <span class="badge done">公開中</span>

望遠鏡型のスナイパーライフル1本だけで戦い抜く、**狙撃特化のバトルロイヤル**ミニゲームです。プレイヤーはステージにランダムスポーンし、チェストから弾丸やアイテムを集めて撃ち合います。1発ごとにリロードが必要な緊張感のある銃撃戦で、ヘッドショットは即キル。時間経過とともに安全地帯（ワールドボーダー）が縮小し、最後の1人が勝者となります。

!!! note "ゲームの特徴"
    武器は **望遠鏡型のスナイパーライフル1本**。既定ではライフルを持って **左クリックで発砲**、右クリック長押しでズームし、ズーム中は **しゃがみ（Shift）で発砲** します（サーバー設定で切替可）。弾は鉄塊で、チェストから補充。**ヘッドショットは即キル・胴体は3発**で、1発撃つごとに約2秒のリロードが必要です。撃つと銃声で位置がバレるハイリスク・ハイリターンな駆け引きが魅力。**煙幕**で狙撃を遮ったり、**回復・スピード・ジャンプ**の各ポーションで立ち回れます。時間とともに**ワールドボーダー**が縮小し、戦いは中央へ集約されます。

!!! tip "1人でも遊べる：射撃訓練場（ソロモード）"
    動く的・止まった的をすべて撃ち抜くまでのタイムを競う **1人用のタイムアタック** があります。初級・中級・上級の3段階で、自己ベストとランキングが残ります。`/sniper solo` かソロ看板から挑戦できます。

!!! info "バトロワ以外のモードも"
    ステージ単位で **FFA（個人戦）** や **TDM（チームデスマッチ）** に切り替えることもできます。どちらも弾は無限でリスポーンありの撃ち合いです（サーバー設定で選択・既定はバトロワ）。
