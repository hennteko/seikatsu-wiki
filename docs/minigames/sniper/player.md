# スナイパーバトロワ ― 遊び方 { .page-player #sniper-player }

望遠鏡型のスナイパーライフル1本で戦う狙撃バトルロイヤルです。ステージにランダムスポーンし、チェストで弾やアイテムを集め、縮小する安全地帯の中で最後の1人を目指します。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 2〜16人（サーバー設定により変更されることがあります） |
    | 勝利条件 | 最後の1人として生き残る |
    | 武器 | スナイパーライフル（望遠鏡）1本のみ・全員共通 |
    | リスポーン | なし（倒れると観戦モードになります） |
    | 参加方法 | ロビーの参加看板（`[スナイパー]` / `参加`）をクリック、または `/sniper join` |

## どんなゲーム？

ゲームが始まると、参加者はステージ内のランダムな地点にスポーンします。全員が **スナイパーライフル（望遠鏡）** を1本だけ持った状態でスタート。体力は **ハート3個分（頭に当たれば即キル、胴体は3発）** と少なく、一瞬の撃ち合いで勝負が決まります。

ステージ内の **チェスト** には弾丸（鉄塊）や回復ポーション、煙幕などがランダムで入っています。弾を補充しながら他プレイヤーを狙撃しましょう。時間が経つと **ワールドボーダー（安全地帯）が縮小** し、逃げ続けることはできません。倒されると観戦モードになり、最後まで生き残った1人が勝者です。

## 操作方法（重要）

武器の **スナイパーライフル＝望遠鏡** はホットバーの一番左に入っています。捨てたり別スロットへ移動したりはできません。既定では **覗かなくても撃てます**。

1. **撃つ** … ライフルを手に持って **左クリック**（腕を振る動作）で発砲します。
2. **ズームして撃つ** … **右クリック長押しでズーム**（スコープ）。ズーム中はマイクラの仕様で左クリックが効かないため、**しゃがみ（Shiftキー）で発砲** します。
3. **リロード** … 1発撃つごとに **約2秒のリロード**。リロード中は撃てません。
4. **弾** … 弾は **鉄塊**（見た目は鉄塊で「弾丸」と表示）。チェストで拾って補充します（最大32発）。弾切れ時は撃てません。

!!! note "発砲方法はサーバー設定で変わることがあります"
    既定は「左クリックで発砲・ズーム中はしゃがみで発砲」です。サーバーによっては「望遠鏡を覗いている間だけ撃てる」従来方式（`require-scope`）に設定されている場合があります。統合版（Bedrock）では覗きながらの操作が難しいため、左クリック発砲が推奨されています。

!!! tip "狙いのコツ"
    - **ヘッドショットは即キル**、胴体は3発でキルです。頭を狙いましょう。
    - 撃つと **銃声が響いて位置がバレます**。外すとリスクだけ背負うので、確実な場面で撃つのが基本です。
    - **煙幕**の中／煙越しは弾が通りません。煙を張って射線を切ったり、追撃から逃げたりに使えます。

## ルール

- ゲーム開始時、持ち物はスナイパーライフルのみ、体力・満腹度は満タンでサバイバルモードになります。
- 弾・アイテムはステージ内のチェストから集めます。中身は試合ごとにランダムです。
- ワールドボーダーは一定間隔で縮小します（既定では60秒ごとに50ブロックずつ、最小サイズ20で停止）。ボーダーの外にいるとダメージを受けます。
- **近接攻撃は無効**（既定）。決着はすべて狙撃でつけます。
- 満腹度は減りません。自然回復はなく、回復は回復ポーションで行います。
- 倒されると敗北扱いになり、観戦モードになります。
- ゲーム中に切断（ログアウト）すると **敗北扱い** になります。

## 勝利条件

生き残っているプレイヤーが **1人だけ** になった時点でゲーム終了、その人の勝利です。制限時間（既定600秒）に達した場合は、その時点で **キル数が最も多いプレイヤー** が勝者となります（同数の場合は引き分け）。

## ステージのモード（バトロワ以外）

ステージによっては、バトロワ（上で説明した最後の1人を目指す形式）以外の **別モード** でプレイすることがあります。どのモードかはサーバーの設定で決まり、サイドバー（画面右）の見出しで見分けられます。

- **FFA（個人戦）** … 全員が敵の撃ち合い。**弾は無限**で、チェストやワールドボーダーはありません。倒されても **数秒でリスポーン** し、制限時間内に **一番多くキルした人** が勝ちです。
- **TDM（チームデスマッチ）** … **レッド／ブルー** に分かれて戦います。弾は無限で、倒されても数秒でリスポーン。先に **チームで規定キル数** に達したチームの勝利です。リスポーン直後は少しの間 **無敵**（時間が経つか自分が撃つと解除）。味方（同じ色）は撃っても当たりません（サーバー設定による）。

!!! note "モードで変わる点"
    FFA・TDM では **弾薬が無限** で、倒されても **リスポーン** します（バトロワのように一度倒れたら終わり、ではありません）。煙幕・グラップリングフック・ジャンプの羽は開始時とリスポーン時に配られます。

## 拾えるアイテム

| アイテム | 効果 |
|---|---|
| 弾丸（鉄塊） | スナイパーライフルの弾。撃つのに必須（最大32発） |
| 回復ポーション | 体力を回復する |
| スピードポーション | 移動速度アップ |
| ジャンプポーション | ジャンプ力アップ（効果中は落下ダメージ無効） |
| 煙幕（雪玉） | 投げると煙が広がり、狙撃の射線を遮る |
| グラップリングフック（釣り竿） | 右クリックで釣り針を飛ばし、地面（床・屋上）に届いた状態でもう一度右クリックすると、その地点へ引き寄せられて移動。垂直な壁には刺さらない。耐久は減らず、クールダウン（既定5秒）で制限。引き寄せ後は落下ダメージ無効 |
| ジャンプの羽（羽根） | 右クリックで真上へ大ジャンプ（既定15ブロック）。回数は無制限で、クールダウン（既定5秒）で制限。跳んだあとは落下ダメージ無効 |

## 参加方法

1. ロビーに設置された **参加看板**（`[スナイパー]` / `参加` と表示）をクリックします。
2. ロビーに移動して待機します。
3. 開始看板のクリックまたは `/sniper start <ステージ>`（どちらも全員可）でゲームが始まると、自動でステージにスポーンします。

ロビーから抜けたいときは **離脱看板**（`[スナイパー]` / `離脱`）をクリックするか、`/sniper leave` を実行します。参加・退出・開始は **看板** または **コマンド**（いずれも全員可）で行えます。参加・離脱・開始の看板は複数の場所に設置できるので、どの看板からでも操作できます。

!!! note "試合中に参加したとき"
    すでにゲームが進行中の場合（看板に `進行中` と表示）は、ロビーで待機して **次の試合から** 参加になります。ロビー（通常戦の待機）が満員のときは参加できません。

## ゲームの流れ

1. **ロビーに参加** — 参加看板をクリックしてロビーに入ります。
2. **ゲーム開始** — 開始看板のクリックまたは `/sniper start <ステージ>`（全員可）で試合が始まります。
3. **ランダムスポーン＆カウントダウン** — ステージ内のランダム地点にスポーンし、5秒のカウントダウン後に開始。
4. **弾を集める** — チェストから弾丸やアイテムを回収します。
5. **狙撃で戦う** — 左クリックで発砲（ズーム中はしゃがみで発砲）。ヘッドショットを狙います。
6. **ボーダー縮小** — 一定間隔で安全地帯が縮み、戦場が狭まります。
7. **決着** — 最後の1人になれば勝利です。試合が終わるとロビーに戻されます。

## ソロモード（射撃訓練場）

1人で遊べる **タイムアタック** です。射撃訓練場に出てくる的を **すべて撃ち抜くまでのタイム** を競います。自己ベストとランキングが残ります。

1. ソロ看板（`[スナイパー]` / `ソロ` / `射撃訓練場`）をクリック、または次のコマンドを実行します。ロビーに入り、**ソロメニュー** が開きます。

```text title="ソロメニューを開く"
/sniper solo
```

2. ソロメニューで難易度（初級・中級・上級）を選ぶと、射撃位置へ移動して **3秒のカウントダウン** のあとスタートします。
3. 的をすべて当てたらゴール。タイム・自己ベスト・順位が表示されます。
4. ロビーへ戻り、**3秒後にソロメニューがまた開きます**。続けて挑戦できます。
5. やめるときはソロメニューの **ロビー退出**（オークのドア）か `/sniper leave`（持ち物が戻り、元の場所へ）。

- メニューを閉じてもロビーにいるままです。ホットバーの **ネザースター（ソロメニュー）** を右クリック（タップ）すると開き直せます。**ネザースターを持ってしゃがんでも** 開きます。
- メニューを通さずにすぐ始めることもできます（`easy` / `normal` / `hard`）。

```text title="初級をすぐ始める"
/sniper solo easy
```

### 的の種類

| 的 | 見た目 | 説明 |
|---|---|---|
| 止まった的 | ターゲットブロック | 決まった場所にパッと出る。当てると消えて、次の的が別の場所に出る |
| 動く的 | 頭がターゲットブロックのアーマースタンド | 左右（決まった経路）を往復する。体のどこに当てても命中 |

的は **挑戦している人の画面にだけ** 表示されます（ほかの人には見えません）。

### 難易度（既定）

| 難易度 | 的の数 | 同時に出る数 | 的の種類 | 制限時間 | 外したとき |
|---|---|---|---|---|---|
| 初級 | 8個 | 1個 | 止まった的 | 120秒 | ペナルティなし |
| 中級 | 10個 | 2個 | 止まった的＋動く的 | 150秒 | タイム +1秒 |
| 上級 | 12個 | 3個 | 速く動く的 | 180秒 | タイム +2秒 |

※ サーバーの設定で変わることがあります。ソロメニューのボタンの説明が最新です。

### ルール

- 弾は **無限**。1発ごとに約1秒のリロードがあります。
- 撃ち方は通常戦と同じです（左クリック、ズーム中はしゃがみで発砲）。
- タイムは **0.1秒単位** で、「外したとき」のペナルティを足したものが記録になります。
- 射撃位置から離れると戻されます。ダメージは受けません。
- **時間切れ** は失敗（記録なし）。`/sniper leave`・切断・管理者の停止も記録は残りません。
- 射撃訓練場で同時に挑戦できるのは **1人だけ** です。使用中はソロメニューに「○○が挑戦中」と出て、空くと開始ボタンが戻ります。
- 通常戦の試合中でもソロに挑戦できます（射撃訓練場は別の場所のため）。

### 表示

| 場所 | 内容 |
|---|---|
| ボスバー（画面上） | 難易度・経過タイム（ペナルティ）・残りの的・自己ベスト。自己ベストより遅くなると赤 |
| アクションバー | 命中・ハズレ・残りの数 |
| タイトル | カウントダウン・ゴールのタイム・自己ベスト更新・順位 |

クリアするとサーバー全体に1行だけ結果が流れます。

### ソロメニュー

| ボタン | 内容 |
|---|---|
| 本 | 遊び方 |
| 難易度のボタン（中段） | 押すと開始。説明・自己ベスト・順位・クリア回数。始められないときはバリアになり理由を表示 |
| コンクリート（左下） | 射撃訓練場の状況（黄緑＝空き／赤＝○○が挑戦中） |
| 紙 | 前回の結果 |
| 金ブロック | ランキング（難易度ごとの上位3人と自分の順位） |
| 時計 | 自分の自己ベスト一覧 |
| オークのドア | ロビー退出（`/sniper leave` と同じ） |

### ランキング

```text title="全難易度の上位"
/sniper ranking solo
```

```text title="難易度を指定（上位10人と自分の記録）"
/sniper ranking solo hard
```

ランキングの `[BE]` は統合版で出した記録の印です（Java版と同じランキングで比べます）。

!!! info "通常戦とソロの切り替え"
    ソロで入っているときに `/sniper join`（参加看板）を使うと通常戦の待機に、通常戦で待機しているときに `/sniper solo` を使うとソロに切り替わります。ロビーにいるままなので、持ち物は戻りません。

!!! warning "統合版（Bedrock）の注意"
    - ソロメニューはチェスト画面で表示・タップできます。ボタンの説明文の見え方が Java 版と少し違うことがあります。
    - ネザースターは **タップ** か **持ってしゃがむ** で開きます。
    - 動く的は通信の遅れの分だけ、Java 版より少し当てにくいことがあります。記録は同じランキングで比べます。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/sniper join` | ロビーに参加する（参加看板と同等・全員可） |
| `/sniper leave` | ロビーから退出する（離脱看板と同等・全員可） |
| `/sniper start <ステージ>` | ゲームを開始する（開始看板と同等・全員可） |
| `/sniper status` | 現在の設定・状況を確認する（全員可） |
| `/sniper solo` | ソロモード（射撃訓練場）で参加してソロメニューを開く（ソロ看板と同等・全員可） |
| `/sniper solo <難易度>` | メニューを通さず、すぐ挑戦する（`easy` / `normal` / `hard`） |
| `/sniper ranking solo [難易度]` | 射撃訓練場のランキング（全員可） |

!!! note "コマンドの短縮形"
    `/sniper` は `/sn` と短縮できます（例：`/sn join`）。参加・退出・開始・状況確認は権限不要で全員が使えます。

## よくある質問

??? question "うまく撃てません／撃ち方がわかりません"
    既定ではライフルを手に持って **左クリック**で発砲します（覗く必要はありません）。**右クリック長押しでズーム**でき、ズーム中は左クリックが効かないため **しゃがみ（Shift）で発砲** します。1発ごとに約2秒のリロードがあり、その間は撃てません。サーバーが従来方式（`require-scope`）に設定されている場合は、覗いている間だけ撃てます。

??? question "弾が撃てない・弾切れになりました"
    弾は **鉄塊**（「弾丸」と表示）です。チェストから拾って補充してください（最大32発）。弾が0のときは発砲できません。

??? question "倒されたらどうなりますか？"
    敗北となり、観戦モードに切り替わります。試合が終わるまで他プレイヤーの戦いを観戦できます。ただしサーバーが **敗者復活（ゾンビスナイパー）モード** を有効にしている場合は、倒されても一定秒数後に「ゾンビスナイパー」として復活し、通常プレイヤーを1人倒すと完全復活します（このモードはバトロワ系ステージ限定・既定はオフ）。

??? question "ゾンビスナイパーって何ですか？"
    サーバー設定で有効な場合のみ登場する **敗者復活モード** です。倒されると約20秒後にゾンビとして復活し、体力は少なめですが通常プレイヤーを倒すと完全復活できます。ゾンビに倒された通常プレイヤーは復活できません。通常プレイヤーが残り2人になると、残ったゾンビは全員脱落して決着戦になります。ネームタグの `[Z]` 表示とサイドバーのゾンビ人数で見分けられます。

??? question "射撃訓練場の的が見えません／当たりません"
    的は **挑戦している人の画面にだけ** 表示されます。ほかの人の挑戦を見ていても的は見えません。止まった的はターゲットブロック、動く的は頭がターゲットブロックのアーマースタンドです。壁やブロックの向こうにある的には当たりません。

??? question "射撃訓練場が始められません"
    ソロメニューのボタンがバリアになっているときは、説明に理由が出ています。だれかが挑戦中なら、終わると開始ボタンが戻ります。「射撃位置が未設定」「的が未登録」と出るときはOPに設定を頼んでください。

??? question "剣で殴っても倒せませんでした"
    既定では **近接攻撃は無効** です。決着はスナイパーライフルの狙撃でのみつきます。

??? question "煙幕は何に使いますか？"
    投げると煙が広がり、**煙の中・煙越しの狙撃を遮断**します。射線を切って逃げたり、相手の視界を妨げたりに使えます。

??? question "ボーダーの外に出るとどうなりますか？"
    安全地帯の外側にいると継続的にダメージを受けます。縮小していくボーダーの内側に留まりましょう。
