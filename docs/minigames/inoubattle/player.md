# 異能バトル（Inoubattle） ― 遊び方 { .page-player #inoubattle-player }

弓とランダムな異能で戦うバトルロイヤルです。縮小する安全地帯の中で、自分の異能を活かして最後の1人を目指します。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | 個人戦（ソロ・バトルロイヤル） |
    | 人数 | 1〜24人（サーバー設定により変更されることがあります） |
    | 勝利条件 | 最後の1人として生き残る |
    | 体力 | ハート3（弓の被弾は常に固定1ダメージ） |
    | 参加方法 | ロビーの参加看板、または `/inou join` |
    | ソロ | 異能トライアル（`/inou solo`・ソロ看板） |

## どんなゲーム？

全員が弓を持ってスタートし、開始時に **異能が1つランダムで配られます**（選択はありません）。体力はハート3と少なく、弓が当たれば固定1ダメージ。0になると即脱落（観戦）です。時間が経つと **安全地帯が段階的に縮小** し、逃げ場が狭まっていきます。最後まで生き残った1人が勝者です。

## 弓と矢

- **弓** … チャージ量に関わらずダメージは **固定1**。ガラスは矢を通しません（**狙撃** の矢だけは貫通します）。
- **矢** … 最初は最大1本。撃つと **リロード（既定2.5秒）**、命中すれば即リロード完了。**持ち物の矢の本数＝今撃てる数** です（0本の間はリロード中で、弓を引けません。弓に白い帯が出て、残り時間が分かります）。強化の「リロード短縮」は1段階0.5秒です。
- **強化** … 相手に **矢を2ヒットさせるごと** に「リロード短縮」または「矢の最大所持数+1」がランダムで付きます（8ヒットで最大）。
- **コンパス** … 針は常に安全地帯の中心を指します。
- **エリトラ** … 開始時の滑空用です。**着地すると自動で外れます。**
- **食料ゲージ** … 使いません。満腹度は減らないので **いつでも走れます**。そのかわり **満腹度による自然回復もありません**（体力が戻るのはフェーズ切替・ケアパケ・一部の異能だけ。ソロはウェーブ全滅でも回復）。
- **頭上の名前** … 試合中は **全員の頭上の名前が見えません**（壁越しに居場所が分からないように）。Tab・チャットの表示はそのままです。

## 異能（ランダム配布）

開始時に配られる異能はプレイヤーごとに異なります。現在は次の **22種** です（運営が ON/OFF を切り替えている場合があります）。自分の異能は開始時のメッセージと右側の表示で確認できます。

=== "移動系"

    | 異能 | 効果 |
    |---|---|
    | 疾走 | 走り続けると加速する |
    | 隠密 | **5秒しゃがむと8秒間透明化**。弓を撃つ・攻撃を受けると解け、解けてから20秒は使えない |
    | 跳躍 | **空中でもう一度ジャンプ**（ダブルジャンプ）。画面下の「跳躍チャージ」が多いほど高く跳ぶ。チャージは地面にいる間にたまる |
    | 脱出 | **しゃがんでいる間に攻撃を受けると上空へ打ち上がり**、エリトラで滑空して逃げられる（使ったら20秒待つ） |
    | 転移 | **コンパスを右クリックで地点を登録**、もう一度右クリックでそこへ **テレポート**。テレポート先の近く（6m）にいる敵は3秒間盲目になる。テレポート後10秒は使えない |

=== "戦闘系"

    | 異能 | 効果 |
    |---|---|
    | 速射 | 左クリックで引き絞らずに矢を撃てる |
    | 狙撃 | **しゃがみながら最大まで引き絞って撃つ** と、まっすぐ即着弾する矢になる。ガラスはすべて貫通。ただし **36m以上離れた相手にしかダメージにならない** |
    | 跳弾 | 矢が **壁で跳ね返る**（通常1回・しゃがみ撃ちで5回）。跳ね返った矢が着弾すると、周り（半径2）にハート半分のダメージ |
    | 爆弾 | 撃った矢に爆弾が付く。**弓を持って左クリックで爆発**（10秒で自動爆発・同時に3個まで）。周りを吹き飛ばし、敵にハート半分のダメージ。自分は吹き飛ぶだけなので **ロケットジャンプ** にも使える |

=== "索敵系"

    | 異能 | 効果 |
    |---|---|
    | 探知 | 敵の位置を探る |
    | 鑑定 | 相手の情報を見る |
    | 追跡 | **矢を当てる** か **5秒しゃがむ**（100m以内で一番近い敵・使ったら30秒待つ）と追跡開始。画面下に **方向の矢印と距離**、コンパスも相手を指す。追跡中は **いつも足が速い**（32m以上離れるとさらに速い）。追跡された相手には「誰かに追跡されている」と出る |

=== "防御系"

    | 異能 | 効果 |
    |---|---|
    | 強靭 | 打たれ強くなる |
    | 無敵 | **しゃがみを1秒長押しで無敵**（攻撃を受けない）。無敵でいられるのは最大10秒で、使っていない間に回復する。無敵中にもう一度しゃがむと解除。※安全地帯の外のダメージは受ける |
    | 障壁 | **弓を持って左クリック** した先に **ガラスのドーム** を作る（12秒で消える）。使ったら10秒待つ |

=== "特殊系"

    | 異能 | 効果 |
    |---|---|
    | 背水 | 倒されそうになると、1試合に1回だけ **「背水の陣」**（ハート半分で10秒耐える）。その間に **誰かを倒せば体力満タンで復活**、倒せなければ脱落 |
    | 変化 | **60秒ごとにランダムな異能に変わる** |
    | 魔眼 | **見ている敵の足を遅くする**（見られている側には「魔眼に見られている」と出る）。**しゃがみ1秒長押し** で、**目が合っている敵を全員石化**（その場から動けない）。石化の長さは見ていた時間に比例（1〜5秒）。石化後20秒は使えず、その間は足止めも起きない |
    | 複製 | **素手で殴った敵の異能をコピー** して60秒使える（時間が切れると複製に戻る）。同じ相手からまたコピーするには30秒待つ |
    | 閃光 | **弓を持って左クリック** で光の矢（矢を1本使う）。炸裂を **見た人全員**（自分も含む）の視界を3秒奪う。光の矢自体にダメージはない。使ったら12秒待つ |
    | 縮身 | ふだんから **体が少し小さい**。攻撃を受けると6秒間 **さらに小さく・速く** なる。その間は **与えるダメージが半分** |
    | 巨体 | **しゃがみを1.5秒長押し** で15秒間 **巨大化**。吹き飛ばされず、体力が増える（ハート1つ＋近くの敵1人につき1つ・最大+4）。もう一度しゃがむと解除。解除後20秒は使えない |

!!! note "本家との違い"
    チーム戦用の効果（脱出・巨体の「味方を乗せる／背負う」）は、個人戦の異能バトルにはありません。

??? note "統合版（Bedrock）で見え方・操作が違う異能"
    - **跳躍** … ダブルジャンプは空中でもう一度ジャンプボタンを押します。統合版では空中ジャンプが反応しにくい場合があります。
    - **転移** … コンパスはタップ（空中タップ）でも使えます。
    - **爆弾・障壁・閃光** … 「左クリック」は統合版では **弓を持って空中をタップ（攻撃ボタン）** です。
    - **魔眼** … 本家の「見られている相手の画面が白黒になる」はサーバー側で作れないため、**アクションバーの警告** で代わりにしています（Java版も同じ）。石化はその場に固定する方式で、統合版でも同じように動けなくなります。
    - **縮身・巨体** … 体の大きさの変化は統合版でも見えますが、当たり判定の見え方が少し違うことがあります。
    - **閃光** … 視界を奪う演出は「盲目＋画面いっぱいの白い表示」です。

## ケアパケ（物資）

序盤〜中盤（フェーズ1〜3）に、上空から **ケアパケ** が投下されます。1つのケアパケにつき **先着3名** だけが中身（回復ポーションなど）を回収できます。落下地点は激戦区になりやすいので、リスクを見て取りに行きましょう。

ケアパケはゆっくり地面まで降りてきて、着地すると **光の柱** が立ちます（投下時のメッセージに座標も出ます）。**近づくだけで自動で回収** でき、右クリック・タップ・叩くでも回収できます。

## フェーズ（安全地帯の縮小）

安全地帯は複数フェーズで段階的に縮小します（既定：300→300→150→105→63→31→最終10）。**フェーズが切り替わるたびに体力が1回復**します。**最終フェーズは安全地帯の中心が移動** し続けるので、じっとしていられません。安全地帯の外にいると継続的にダメージを受けます。

安全地帯の端が近くなると、**その辺に赤いパーティクルの壁** が見えます（統合版でも見えます）。端の近くでは画面のふちも赤くなります。会場の中では敵（ゾンビ等）は自然に湧きません。

## 勝利条件

残っているプレイヤーが **1人だけ** になった時点でゲーム終了、その人の勝利です。

## 参加方法

1. ロビーの **参加看板** をクリック、または `/inou join`。
2. 開始看板のクリックまたは `/inou start <識別子>`（全員可）でゲーム開始。
3. 異能が配られ、バトルが始まります。

離脱は **離脱看板** か `/inou leave` です。

## 異能トライアル（1人で遊ぶ）

**好きな異能を選んで、Mob のウェーブと戦う** ソロモードです。倒れるまでに到達したウェーブが記録になり、**異能ごと** と **総合** のランキングに残ります。通常戦の前に異能の使い方を練習するのにも使えます。

### 始め方

1. ソロ看板を右クリック、または `/inou solo` → ロビーに入り、**ソロメニュー** が開きます。
2. メニューで使いたい異能（または **おまかせ**）を押すと、3秒後に始まります。ソロ用の会場へ移動します。
3. 終わるとロビーに戻り、数秒後にまたソロメニューが開きます。続けて挑戦できます。

```text title="ソロメニューを開く"
/inou solo
```
```text title="メニューを通さずすぐ始める（例：疾走。random でおまかせ）"
/inou solo sprint
```
```text title="ランキングを見る（総合）"
/inou ranking
```
```text title="異能ごとのランキングを見る（例：速射）"
/inou ranking rapidfire
```

- メニューを閉じてもロビーにいるままです。ホットバーの **ネザースター（ソロメニュー）** を右クリックすると開き直せます。統合版は **タップ** か **ネザースターを持ってスニーク** でも開きます。
- メニューの「ロビー退出」か `/inou leave` で抜けると、持ち物が元に戻ります。
- 会場は1つです。誰かが挑戦中・通常戦の試合中は始められません（メニューに「使用中」と出て、空くと表示が変わります）。
- ソロで入った人は通常戦（`/inou start`）には参加しません。通常戦に出たいときは `/inou join` で切り替えます。

### ルール

- 装備は通常戦と同じ **弓・コンパス・望遠鏡**（エリトラはなし）。ハートも通常戦と同じです。
- **敵の攻撃は1回で1ハート**（矢・近接とも）。連続では当たらず、少しの間は守られます。
- 最初の **10秒** は準備時間。その後 **約40秒ごと** にウェーブが来ます。**全滅させるとハートが1回復し、次のウェーブが早く来ます**。
- 敵の頭上の **[数字] は、あと何発で倒れるか** です。ウェーブが進むと敵は少しずつ硬くなります。
- 敵に矢を当てると **即リロード**、2ヒットごとに **弓が強化** されます（通常戦と同じ）。
- 会場（一辺64ブロック・ソロ用の場所）の外に出ると、少しずつダメージを受けます。
- **ハートが0になった時点で終了**。到達ウェーブが記録です。

| 敵 | 特徴 | 出始め |
|---|---|---|
| 突撃兵（ゾンビ） | まっすぐ殴りに来る。矢2発 | 1ウェーブ目 |
| 射手（スケルトン） | 遠くから矢を撃つ。矢2発 | 2ウェーブ目 |
| 俊足兵（クモ） | 速い・壁を登る。矢1発 | 3ウェーブ目 |
| 重装兵（ヴィンディケーター） | 硬い。矢4発 | 5ウェーブ目 |
| 隊長（ラヴェジャー） | とても硬い。矢10発 | 5ウェーブごと |

### 異能はソロではこう働きます

| 異能 | ソロでの働き |
|---|---|
| 疾走 | 通常戦と同じ（走り続けると加速） |
| 隠密 | 5秒しゃがむと8秒間透明化。**透明の間は敵に狙われない**（撃つ・攻撃を受けると解除。解けてから20秒は使えない） |
| 探知 | 5秒しゃがむと、周りの **敵** の種類と距離が分かる |
| 鑑定 | 見ている敵の種類と **あと何発で倒れるか** が分かる |
| 追跡 | 5秒しゃがむか矢を当てた **敵** を追跡。方向の矢印と距離が出て、追跡中は足が速い |
| 強靭 | 通常戦と同じ（ハート+1・再生。敵に当てると再生が早まる） |
| 速射 | 通常戦と同じ（左クリックで即発射） |
| 跳躍・脱出・転移・跳弾・爆弾・無敵・障壁・縮身・巨体・変化 | 通常戦と同じ（相手が敵 Mob になる） |
| 狙撃 | 通常戦と同じ（36m以上離れた **敵** にだけ命中） |
| 背水 | 倒されそうになると背水の陣。その間に **敵を倒せば** 復活 |
| 魔眼 | 視界の **敵** を遅くする。Mob は見返さないので、**視界に入っている敵** を石化できる |
| 複製 | 敵 Mob を素手で殴ると、**ランダムな異能** をコピーする |
| 閃光 | 炸裂の近くの敵 Mob が盲目・鈍足になる（自分も炸裂を見ると視界を奪われる） |

### 記録とランキング

- **到達ウェーブ → 撃破数 → 時間（短いほど上）** の順で並びます。1人につき異能ごとに1件＋総合1件（一番よい記録）です。
- leave・切断・管理者の強制停止で終わったときは記録されません。
- 統合版で出した記録には **[BE]** の印が付きます（ランキングは同じ）。
- サーバー全体には結果が1行だけ流れます。

??? note "統合版（Bedrock）の場合"
    ソロメニュー（チェスト画面）はタップで操作できます。ネザースターはタップかスニークで開けます。ボスバー（ウェーブ・残り敵・撃破・時間）と会場の範囲（WorldBorder）も表示されます。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/inou join` | ロビーに参加する（参加看板と同等・全員可） |
| `/inou leave` | ロビーから離脱する（離脱看板と同等・全員可） |
| `/inou start <識別子>` | ゲームを開始する（開始看板と同等・全員可） |
| `/inou solo` | 異能トライアル（ソロ）のメニューを開く（ソロ看板と同等・全員可） |
| `/inou solo <異能\|random>` | メニューを通さずソロを始める（全員可） |
| `/inou ranking [異能]` | ソロのランキング（総合／異能ごと）を見る（全員可） |
| `/inou status` | 現在の設定・状況を確認する（全員可） |

## よくある質問

??? question "異能は選べますか？"
    通常戦では選べません。開始時に **ランダムで1つ** 配られます。好きな異能を試したいときは **異能トライアル（`/inou solo`）** で選べます。

??? question "弓のダメージはチャージで変わりますか？"
    変わりません。チャージ量に関わらず **固定1ダメージ** です。ヘッドショットや溜め撃ちで一撃、という仕様ではありません。

??? question "倒されたらどうなりますか？"
    体力0で即脱落し、観戦になります（統合版プレイヤーはゴースト観戦）。リスポーンはありません。
