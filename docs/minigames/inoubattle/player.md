# 異能バトル（Inoubattle） ― 遊び方 { .page-player #inoubattle-player }

弓とランダムな異能で戦うバトルロイヤルです。縮小する安全地帯の中で、自分の異能を活かして最後の1人を目指します。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | 個人戦（ソロ・バトルロイヤル） |
    | 人数 | 1〜24人（サーバー設定により変更されることがあります） |
    | 勝利条件 | 最後の1人として生き残る |
    | 体力 | ハート3（弓の被弾は常に固定1ダメージ） |
    | 参加方法 | ロビーの参加看板、または `/inou join` |
    | ソロ | 異能トライアル（`/inou solo`・ソロ看板） |

## どんなゲーム？

全員が弓を持ってスタートし、開始時に **異能が1つランダムで配られます**（選択はありません）。体力はハート3と少なく、弓が当たれば固定1ダメージ。0になると即脱落（観戦）です。時間が経つと **安全地帯が段階的に縮小** し、逃げ場が狭まっていきます。最後まで生き残った1人が勝者です。

## 弓と矢

- **弓** … チャージ量に関わらずダメージは **固定1**。マップ内のガラスは矢で壊せます。
- **矢** … 最初は最大1本。撃つと **リロード（既定5秒）**、命中すれば即リロード完了。
- **強化** … 相手に **矢を2ヒットさせるごと** に「リロード短縮」または「矢の最大所持数+1」がランダムで付きます（8ヒットで最大）。
- **コンパス** … 針は常に次のセーフエリアの中心を指します。

## 異能（ランダム配布）

開始時に配られる異能はプレイヤーごとに異なります。現在（v1）実装されている異能は次のとおりです。

| 異能 | 効果の系統 |
|---|---|
| 疾走 | 移動系（素早く動ける） |
| 隠密 | 移動系（見つかりにくくなる） |
| 速射 | 戦闘系（矢を速く撃てる） |
| 探知 | 索敵系（敵の位置を探る） |
| 鑑定 | 索敵系（相手の情報を見る） |
| 追跡 | 索敵系（相手を追える） |
| 強靭 | 防御系（打たれ強くなる） |

!!! note "異能は今後増えます"
    現在は上記の異能が有効です。移動・戦闘・防御・特殊のさらに多くの異能が今後のアップデートで追加され、運営がON/OFFを切り替えられます。自分の異能は開始時のメッセージで確認できます。

## ケアパケ（物資）

序盤〜中盤（フェーズ1〜3）に、上空から **ケアパケ** が投下されます。1つのケアパケにつき **先着3名** だけが中身（回復ポーションなど）を回収できます。落下地点は激戦区になりやすいので、リスクを見て取りに行きましょう。

## フェーズ（安全地帯の縮小）

安全地帯は複数フェーズで段階的に縮小します（既定：300→300→150→105→63→31→最終10）。**フェーズが切り替わるたびに体力が1回復**します。**最終フェーズは安全地帯の中心が移動** し続けるので、じっとしていられません。安全地帯の外にいると継続的にダメージを受けます。

## 勝利条件

残っているプレイヤーが **1人だけ** になった時点でゲーム終了、その人の勝利です。

## 参加方法

1. ロビーの **参加看板** をクリック、または `/inou join`。
2. 開始看板のクリックまたは `/inou start <識別子>`（全員可）でゲーム開始。
3. 異能が配られ、バトルが始まります。

離脱は **離脱看板** か `/inou leave` です。

## 異能トライアル（1人で遊ぶ）

**好きな異能を選んで、Mob のウェーブと戦う** ソロモードです。倒れるまでに到達したウェーブが記録になり、**異能ごと** と **総合** のランキングに残ります。通常戦の前に異能の使い方を練習するのにも使えます。

### 始め方

1. ソロ看板を右クリック、または `/inou solo` → ロビーに入り、**ソロメニュー** が開きます。
2. メニューで使いたい異能（または **おまかせ**）を押すと、3秒後に始まります。ソロ用の会場へ移動します。
3. 終わるとロビーに戻り、数秒後にまたソロメニューが開きます。続けて挑戦できます。

```text title="ソロメニューを開く"
/inou solo
```
```text title="メニューを通さずすぐ始める（例：疾走。random でおまかせ）"
/inou solo sprint
```
```text title="ランキングを見る（総合）"
/inou ranking
```
```text title="異能ごとのランキングを見る（例：速射）"
/inou ranking rapidfire
```

- メニューを閉じてもロビーにいるままです。ホットバーの **ネザースター（ソロメニュー）** を右クリックすると開き直せます。統合版は **タップ** か **ネザースターを持ってスニーク** でも開きます。
- メニューの「ロビー退出」か `/inou leave` で抜けると、持ち物が元に戻ります。
- 会場は1つです。誰かが挑戦中・通常戦の試合中は始められません（メニューに「使用中」と出て、空くと表示が変わります）。
- ソロで入った人は通常戦（`/inou start`）には参加しません。通常戦に出たいときは `/inou join` で切り替えます。

### ルール

- 装備は通常戦と同じ **弓・コンパス・望遠鏡**（エリトラはなし）。ハートも通常戦と同じです。
- **敵の攻撃は1回で1ハート**（矢・近接とも）。連続では当たらず、少しの間は守られます。
- 最初の **10秒** は準備時間。その後 **約40秒ごと** にウェーブが来ます。**全滅させるとハートが1回復し、次のウェーブが早く来ます**。
- 敵の頭上の **[数字] は、あと何発で倒れるか** です。ウェーブが進むと敵は少しずつ硬くなります。
- 敵に矢を当てると **即リロード**、2ヒットごとに **弓が強化** されます（通常戦と同じ）。
- 会場（一辺64ブロック・ソロ用の場所）の外に出ると、少しずつダメージを受けます。
- **ハートが0になった時点で終了**。到達ウェーブが記録です。

| 敵 | 特徴 | 出始め |
|---|---|---|
| 突撃兵（ゾンビ） | まっすぐ殴りに来る。矢2発 | 1ウェーブ目 |
| 射手（スケルトン） | 遠くから矢を撃つ。矢2発 | 2ウェーブ目 |
| 俊足兵（クモ） | 速い・壁を登る。矢1発 | 3ウェーブ目 |
| 重装兵（ヴィンディケーター） | 硬い。矢4発 | 5ウェーブ目 |
| 隊長（ラヴェジャー） | とても硬い。矢10発 | 5ウェーブごと |

### 異能はソロではこう働きます

| 異能 | ソロでの働き |
|---|---|
| 疾走 | 通常戦と同じ（走り続けると加速） |
| 隠密 | 5秒しゃがむか敵に当てると透明化。**透明の間は敵に狙われない**（攻撃を受けると解除） |
| 探知 | 5秒しゃがむと、周りの **敵** の種類と距離が分かる |
| 鑑定 | 見ている敵の種類と **あと何発で倒れるか** が分かる |
| 追跡 | 矢を当てた **敵** を追跡し、離れると速く走れる |
| 強靭 | 通常戦と同じ（ハート+1・再生。敵に当てると再生が早まる） |
| 速射 | 通常戦と同じ（左クリックで即発射） |

### 記録とランキング

- **到達ウェーブ → 撃破数 → 時間（短いほど上）** の順で並びます。1人につき異能ごとに1件＋総合1件（一番よい記録）です。
- leave・切断・管理者の強制停止で終わったときは記録されません。
- 統合版で出した記録には **[BE]** の印が付きます（ランキングは同じ）。
- サーバー全体には結果が1行だけ流れます。

??? note "統合版（Bedrock）の場合"
    ソロメニュー（チェスト画面）はタップで操作できます。ネザースターはタップかスニークで開けます。ボスバー（ウェーブ・残り敵・撃破・時間）と会場の範囲（WorldBorder）も表示されます。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/inou join` | ロビーに参加する（参加看板と同等・全員可） |
| `/inou leave` | ロビーから離脱する（離脱看板と同等・全員可） |
| `/inou start <識別子>` | ゲームを開始する（開始看板と同等・全員可） |
| `/inou solo` | 異能トライアル（ソロ）のメニューを開く（ソロ看板と同等・全員可） |
| `/inou solo <異能\|random>` | メニューを通さずソロを始める（全員可） |
| `/inou ranking [異能]` | ソロのランキング（総合／異能ごと）を見る（全員可） |
| `/inou status` | 現在の設定・状況を確認する（全員可） |

## よくある質問

??? question "異能は選べますか？"
    通常戦では選べません。開始時に **ランダムで1つ** 配られます。好きな異能を試したいときは **異能トライアル（`/inou solo`）** で選べます。

??? question "弓のダメージはチャージで変わりますか？"
    変わりません。チャージ量に関わらず **固定1ダメージ** です。ヘッドショットや溜め撃ちで一撃、という仕様ではありません。

??? question "倒されたらどうなりますか？"
    体力0で即脱落し、観戦になります（統合版プレイヤーはゴースト観戦）。リスポーンはありません。
