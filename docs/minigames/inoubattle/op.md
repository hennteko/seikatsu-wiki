# 異能バトル（Inoubattle） ― OP・運営ガイド { .page-op #inoubattle-op }

異能バトルの導入・管理ツール・地点／フェーズ／看板設定・config・権限・管理コマンドをまとめます。地点・看板は管理ツール（`/inou wand`）の管理メニューまたはコマンドで登録すると自動保存されます。

## 基本情報

| 項目 | 値 |
|---|---|
| プラグイン名 | Inoubattle |
| メインコマンド | `/inou` |
| api-version | 26.1.2 |
| 依存プラグイン | なし |
| 設定ファイル | `plugins/Inoubattle/config.yml` |
| 権限ノード | `inou.admin`（既定OP） |

## 導入手順

1. ビルドした `Inoubattle` の jar をサーバーの `plugins/` フォルダに配置する。
2. サーバーを起動すると `config.yml` が自動生成される。
3. `/inou wand` で管理ツールを受け取り、右クリックで開く管理メニューのボタンで初期スポーン・ロビー・フィールド角1/2（立ち位置）を設定する。
4. 参加・離脱・開始の看板を設置する（ステージ識別子ごと）。
5. `/inou status` で設定状況を確認する。

## 管理ツール（OP専用）

`/inou wand` で管理ツール（ブレイズロッド「【異能バトル】管理ツール」）を受け取り、右クリック（統合版はタップ/長押し）で管理メニューを開きます。`/inou menu` でも開けます。設定はすべてメニューのボタンで行います（ツールの左クリック・しゃがみ操作はありません）。

**1ページ目：通常戦**

- ステージ：左右の矢印で切り替え（新しいステージは `/inou setfield <名前> 1`）
- 数値：＋/−ボタンで最低人数・最大人数を変更（即保存）
- 地点：ボタンを押すと立ち位置に設定（初期スポーン・ロビー・フィールド角1・フィールド角2）
- 看板：看板を見ながら（5ブロック以内）押すと参加／離脱／開始看板を登録（ステージが2つ以上なら選択画面）、ハサミで登録解除
- 範囲を10秒表示（橙＝フィールド／水色＝最初の安全地帯／赤＝最終フェーズ）
- フェーズ表（範囲・待機秒・縮小秒・ケアパケ、専用⇔共通、「フィールドに合わせる」）・能力の有効／無効・ランダムイベントON/OFF
- 運用：開始・設定状況・リロード・強制停止（強制停止は5秒以内に2回押し）

**2ページ目：異能トライアル（ソロ）**

- 地点：「ソロの開始地点を立ち位置に」（会場の中心）
- 看板：看板を見ながら押すとソロ看板を登録、ハサミで登録解除
- 会場を10秒表示（紫＝会場／白＝開始地点）
- 切り替え：ソロモード・結果の全体通知
- 数値：＋/−ボタンで会場の一辺・最終ウェーブ・全滅時の回復・最初のウェーブまで・ウェーブの間隔・隊長の出る間隔・1ウェーブ目の敵の数・増える数・同時に出る敵の上限を変更（即保存）
- 運用：挑戦の強制停止・ソロの記録の全消去（どちらも5秒以内に2回押し）・設定状況・リロード

- 異能バトルに参加中（ソロ入場を含む）は受け取れません（離脱してから実行）。捨てると消えるので再度 `/inou wand` で取得してください
- 非OPが使おうとすると消えます。コンテナ・額縁・防具立てには入れられません
- 統合版：チェストGUIで操作できます。数値は左右クリックに頼らず＋/−の別ボタンで操作します

!!! tip "会場づくりのコツ"
    フィールドは **正方形** にし、一辺を **最初の安全地帯（フェーズ0の範囲）と同じ** にします。大きさが違う会場は、管理メニュー →「フェーズ表」→「フィールドに合わせる」で専用のフェーズ表を作ってください。ズレていると角を設定したとき・`/inou status` で警告が出ます。

!!! note "プレイエリア＝WorldBorderの算出元"
    フィールド角1/2で指定した範囲の中心が、各フェーズのWorldBorder（安全地帯）の中心になります。フェーズ表は管理メニューで編集でき、初期値は config の `phases` が使われます。フェーズ表の「最後のフェーズを削除」「共通に戻す」も5秒以内に2回押しです。

## 看板の設置

コマンドでも登録できます（どれも5ブロック以内で見ている看板が対象。管理メニューの看板ボタンと同じ処理です）。

```text title="参加看板を登録（看板を見て実行）"
/inou setsign join
```

```text title="離脱看板を登録"
/inou setsign leave
```

```text title="開始看板を登録（ステージ識別子ごと・複数マップ対応）"
/inou setsign start <識別子>
```

```text title="ソロ看板を登録（異能トライアルの入口）"
/inou setsign solo
```

```text title="視線先の看板の登録を解除"
/inou setsign delete
```

!!! success "看板は複数設置できます"
    参加・離脱・開始の各看板を複数設置できます（開始看板はステージ識別子ごと）。保存形式は `signs.join`/`leave`/`start.<識別子>` のリストです。フェーズ表は **ステージ識別子ごと** に持てるので、マップによって規模を変えられます。

## config.yml 設定項目

### 人数・体力・弓

| キー | 既定値 | 説明 |
|---|---|---|
| `min-players` | 1 | 最低人数（練習用に1人開始可・0のみ拒否） |
| `max-players` | 24 | 最大参加人数 |
| `max-hearts` | 3 | 体力（ハート数。弓の被弾は常に固定1ダメージ） |
| `bow.reload-seconds` | 5 | 矢の初期リロード秒数 |
| `bow.reload-min-seconds` | 3 | 強化後の最短リロード秒数 |
| `bow.max-arrows` | 1 | 初期の矢の最大所持数 |
| `bow.max-arrows-cap` | 3 | 強化後の矢の最大所持数の上限 |
| `bow.hits-per-upgrade` | 2 | 1段階強化に必要なヒット数 |
| `bow.max-upgrade-hits` | 8 | 最大強化になるヒット数 |

### フェーズ・安全地帯

| キー | 既定値 | 説明 |
|---|---|---|
| `phases` | 300/300/150/105/63/31 のリスト | 各フェーズの `size`（一辺m）/`wait`（待機秒）/`shrink`（縮小秒）/`carepkg`（投下オフセット秒のリスト） |
| `final-phase.size` | 10 | 最終フェーズの範囲 |
| `final-phase.drift-amount` | 3 | 最終フェーズで中心が移動する量（m） |
| `final-phase.drift-interval-seconds` | 15 | 中心移動の間隔（秒） |
| `border.outside-damage` | 1.0 | 圏外での1回あたりダメージ |
| `border.outside-damage-interval-seconds` | 1 | 圏外ダメージの間隔（秒） |
| `border.warn-before-seconds` | `[30, 10]` | 縮小の予告タイミング（秒前） |

!!! note "フェーズ切替で全員1回復"
    フェーズが切り替わるたびに全員の体力が1回復します。最終フェーズは中心が `drift-interval-seconds` ごとに `drift-amount` だけランダムに移動します（屋内で即詰みにならないよう移動量に上限あり）。

### ケアパケ・観戦

| キー | 既定値 | 説明 |
|---|---|---|
| `carepackage.claim-limit` | 3 | 1つのケアパケで回収できる人数（先着） |
| `carepackage.item-pool` | 回復スプラッシュ×1 | 中身の抽選プール（`material`/`potion`/`weight`/`min`/`max`。重み方式） |
| `spectator.chat-isolate` | true | 観戦者チャットを観戦者間のみに制限 |

!!! note "観戦方式は `bedrock` ブロックへ移動しました"
    旧 `spectator.mode` は `bedrock.spectator-style`（`AUTO`／`GHOST`／`VANILLA`）に、旧 `spectator.bedrock-name-prefix` は `bedrock.name-prefix` に統合されました。起動時・`/inou reload` 時に旧キーがあれば自動で移行されます（下の「名前表示・統合版対応」を参照）。

### 異能の有効/無効（`abilities`）

`false` にした異能は次の試合の抽選プールから除外されます（進行中の試合には影響しません）。`/inou setability <能力名> <on|off>` でも切り替えられます。

!!! info "v1で有効（実装済み）の異能"
    既定で有効なのは **疾走（sprint）／隠密（stealth）／速射（rapidfire）／探知（detect）／鑑定（appraise）／追跡（track）／強靭（toughness）** の7種です。その他の異能（跳躍・鉤縄・狙撃・無敵・障壁・背水・捕食・閃光・縮身・巨体・変化・複製・反響・魔眼 など）は **未実装（次回以降）** で、config 上は `false` になっています。実装が進んだら `true` にして有効化できます。

### ランダムイベント

| キー | 既定値 | 説明 |
|---|---|---|
| `random-event.enabled` | true | ランダムイベントの自動抽選を有効化 |
| `random-event.interval-seconds` | 90 | 抽選の間隔（秒） |
| `random-event.chance-percent` | 30 | 抽選時に発動する確率（%） |

イベントは `/inou event <名前>`（OP限定）で手動発火もできます。

### ロビー共通インベントリ（`lobby-inventory`）

ロビー入退室時に所持品を退避・復元する共通システムです（`enabled`/`gamemode`（既定 `ADVENTURE`）/`clear-effects`/`reset-health`/`reset-exp`/`expire-days`）。未復元の件数は `/inou status` で確認でき、戻らないときは `/inou lobbyfix <プレイヤー>` で個別復旧します。

### 名前表示・参加通知（`name-tag`）

ミニゲーム共通の表示システムです。参加すると頭上ネームタグ・Tabリスト・チャットの名前が `【ゲーム名】名前` になり、離脱・ログアウト・プラグイン停止で元に戻ります。

| キー | 既定値 | 説明 |
|---|---|---|
| `name-tag.enabled` | true | false で名前表示を付けない |
| `name-tag.display-name` | 異能バトル | `【】` に入れる正式名 |
| `name-tag.color` | GOLD | `【ゲーム名】` の色（GOLD / AQUA / GREEN / RED / YELLOW など） |
| `name-tag.announce-join` | true | false でサーバー全体への参加通知を出さない |

### 統合版対応（`bedrock`）

Geyser / Floodgate 経由の統合版（Bedrock）プレイヤー向けの設定です。

| キー | 既定値 | 説明 |
|---|---|---|
| `bedrock.wax-signs` | true | 登録看板を蝋引きし、統合版でタップしても編集画面が開かないようにする |
| `bedrock.swing-to-use` | true | 統合版の空中タップ（腕振り）でも特殊アイテム（状況表示・ソロメニュー等）を使えるようにする |
| `bedrock.spectator-style` | AUTO | 観戦方式。`AUTO`＝統合版だけゴースト観戦／`GHOST`＝全員ゴースト／`VANILLA`＝全員観戦モード（統合版は観戦モードでHUDが消えるため AUTO 推奨） |
| `bedrock.name-prefix` | `"."` | Floodgate が無いときに統合版と見なす名前の接頭辞 |

!!! note "自動生成される領域（手動編集不要）"
    `default-spawn` / `lobby-spawn` / `stages`（フィールド範囲）/ `signs`（看板）は管理メニュー・コマンドで自動保存されます。

## 異能トライアル（ソロ）の設定

1人で異能を選び、Mob のウェーブと戦うモードです。BedWars のソロ防衛と同じく、**ロビー＋ソロメニュー（GUI）** で遊びます。

### 準備

1. ソロ用の会場の **中心** に立って開始地点を設定します（管理メニュー2ページ目の「ソロの開始地点を立ち位置に」でも可）。ここを中心に一辺64（`solo.area-size`）の正方形が会場になります。通常戦のフィールドの中でも外でも構いません。

```text title="ソロの開始地点（会場の中心）"
/inou setsolospawn
```

2. ロビーにソロ看板を置きます（看板を見て実行）。

```text title="ソロ看板"
/inou setsign solo
```

3. 確認します。`【ソロ（異能トライアル）】` に開始地点・状況・記録の人数が出ます。

```text title="設定の確認"
/inou status
```

!!! warning "会場の条件"
    - 開始地点の **上下8ブロック以内** に、Mob が立てる床があるようにしてください（その高さで敵の出る場所を探します）。屋根の上だけ・水の上だけの会場では敵が出ません。
    - 敵は **体の大きさが丸ごと入る場所** にだけ出ます（壁・天井・フェンス・ガラス板に重なる場所、クモの巣・水・溶岩・マグマブロックの上などには出ません）。隊長（ラヴェジャー）は **幅2・高さ3**、俊足兵（クモ）は **幅2・高さ1** の空間が要ります。狭い通路ばかりの会場では大きい敵が出にくく、5秒探しても見つからなければ開始地点に出すか、その回は省きます（サーバーログに警告が出ます）。
    - 押し込まれて壁に埋まった敵や会場の外へ出た敵は、自動で入れる場所へ移されます。
    - 会場のワールドの難易度が **ピースフル** だと敵が出せません（メニューに理由が出ます）。
    - 通常戦とソロは同時に動きません。どちらかが進行中なら、もう一方は始められません。
    - 選べる異能は「能力の有効／無効」で **有効** にしている実装済みの異能だけです。

### 動き

- 試合中はソロの挑戦者1人だけの試合として動きます。安全地帯（フェーズ）・ケアパケ・ランダムイベントは動きません。
- 会場の範囲は挑戦者にだけ WorldBorder で見えます（ワールドのボーダーは変えません）。時刻も本人にだけ昼に固定します。
- 敵は挑戦者だけを狙い、挑戦者の攻撃でだけ倒れます。他のプレイヤー・他のゲームには作用しません。敵はセーブされず、終了・停止・再起動で消えます。
- `/inou stop` で挑戦を止めると記録せずにロビーへ戻し、ソロメニューを開き直します（カウントダウン中なら開始を中止）。
- 記録は `plugins/Inoubattle/solo-records.yml` に保存されます（ConfigUpdater の対象外）。

```text title="記録を消す（1人・全異能）"
/inou ranking reset <プレイヤー>
```

```text title="記録を消す（1人・特定の異能だけ）"
/inou ranking reset <プレイヤー> <異能>
```

```text title="記録を全部消す"
/inou ranking reset all
```

### config（`solo`）

| キー | 既定 | 内容 |
|---|---|---|
| `enabled` | true | false でソロを無効化 |
| `countdown` / `result-seconds` / `menu-delay` | 3 / 4 / 3 | 開始前・結果表示・メニューを開き直すまでの秒数 |
| `broadcast-result` | true | 結果を全体に1行流す |
| `ranking-size` | 10 | `/inou ranking` の表示人数 |
| `area-size` | 64 | 会場の一辺（開始地点が中心） |
| `area-damage-interval-seconds` | 2 | 会場の外にいると、この秒数ごとに1ハート |
| `first-wave` / `wave-interval` / `wave-clear-delay` | 10 / 40 / 5 | 最初のウェーブまで・ウェーブの間隔・全滅後に次が来るまで（秒） |
| `max-waves` | 0 | このウェーブを全滅させたら「全ウェーブ突破」で終了（0＝終わりなし） |
| `base` / `per-wave` | 3 / 1 | 1ウェーブ目の敵の数・ウェーブごとに増える数 |
| `max-alive` | 20 | 同時に出る敵の上限 |
| `captain-every` | 5 | 何ウェーブごとに隊長（0で出ない） |
| `spawn-min-distance` | 12 | 敵が出る場所の、挑戦者からの最低距離 |
| `arrow-damage` | 2.0 | 挑戦者の矢1発のダメージ（敵の体力＝`hits`×この値） |
| `hp-per-wave` | 0.05 | ウェーブごとの敵の体力の上がり幅（5%） |
| `hurt-cooldown-ms` | 1200 | 敵の攻撃を受けたあとの保護時間 |
| `heal-on-clear` | 1 | ウェーブ全滅で回復するハート数 |
| `mobs.<種類>.from-wave` / `weight` / `hits` | 下表 | 出始めるウェーブ・出現の重み・矢何発で倒れるか |

| 種類（キー） | 見た目 | from-wave | weight | hits |
|---|---|---|---|---|
| 突撃兵（`striker`） | ゾンビ | 1 | 5 | 2 |
| 射手（`archer`） | スケルトン | 2 | 3 | 2 |
| 俊足兵（`runner`） | クモ | 3 | 3 | 1 |
| 重装兵（`brute`） | ヴィンディケーター | 5 | 2 | 4 |
| 隊長（`captain`） | ラヴェジャー | `captain-every` | - | 10 |

!!! info "config は自動で追記されます"
    アップデート後に起動すると、既存の config.yml に `solo` ブロックが自動で追加されます（既存の値は上書きしません。旧ファイルは `config.yml.bak-日時` に退避）。

## 管理コマンド

| コマンド | 説明 |
|---|---|
| `/inou wand` | 管理ツールを受け取る（右クリックで管理メニュー） |
| `/inou menu` | 管理メニューを開く（参加中でも開ける） |
| `/inou setfield [ステージ] <1\|2>` | 立っている位置をフィールドの角にする（ステージ名を付けるとそのステージ。無ければ作成） |
| `/inou setsolospawn` | ソロ（異能トライアル）の開始地点＝会場の中心を設定 |
| `/inou ranking reset <プレイヤー\|all> [異能]` | ソロの記録を消す（コンソール可） |
| `/inou setstartspawn` | 初期スポーンを設定 |
| `/inou setlobby` | ロビーを設定 |
| `/inou setsign <join\|leave\|solo\|start <識別子>\|delete>` | 看板を設定／解除 |
| `/inou setability <能力名> <on\|off>` | 異能の有効／無効を切替 |
| `/inou abilitylist` | 異能の有効／無効一覧を表示 |
| `/inou setmin <人数>` / `setmax <人数>` | 最低／最大人数を設定 |
| `/inou event <名前>` | ランダムイベントを手動発火 |
| `/inou lobbyfix <プレイヤー> [force]` | ロビー入室前の持ち物が戻らないときの手動復旧（`force` で退避データを破棄しロックだけ解除・最終手段。統合版の`.`接頭辞も補完） |
| `/inou stop` | ゲームを強制停止 |
| `/inou reset` | 残留物を完全消去してIDLEへ |
| `/inou reload` | config を再読み込み |
| `/inou status` | 設定状況・現在の状況を確認（全員可） |

フィールド範囲は管理メニューの「フィールド角1/2を立ち位置に」か `/inou setfield [ステージ] <1|2>`、フェーズ表は管理メニューで編集します。

## 権限ノード

| 権限ノード | 既定 | 用途 |
|---|---|---|
| `inou.admin` | OP | 管理ツール・管理メニュー・地点／看板設定・異能ON/OFF・イベント発火・強制停止など管理系すべて |

!!! info "権限不要で全員が使えるコマンド"
    `/inou join`・`/inou leave`・`/inou start <識別子>`・`/inou solo [異能]`・`/inou ranking [異能]`・`/inou status` は権限チェックがなく、全プレイヤーが使えます（`start` はコンソール／コマンドブロックからも可）。

## トラブルシューティング

??? failure "異能トライアルで敵が出ない"
    開始地点の上下8ブロック以内に、敵が立てる床（固いブロックの上に2ブロック分の空間）が会場の中にあるか確認してください。ワールドの難易度がピースフルでないか、他のプラグインが Mob の出現を止めていないかも確認してください。

??? failure "ソロメニューで「使用中」のまま"
    通常戦が進行中か、誰かがソロに挑戦中です。`/inou status` の `【ソロ（異能トライアル）】` で状況を確認できます。止める場合は `/inou stop`。

??? failure "ゲームが開始できない"
    `/inou status` を確認してください。フィールド範囲（管理メニューの角1/2）とロビーが設定され、ロビーに最低人数以上いる必要があります。未設定でもフォールバックしますが警告が出ます。

??? failure "特定の異能が配られない"
    その異能が `abilities` で `false`（未実装含む）になっていないか、`/inou abilitylist` で確認してください。v1で実装済みなのは7種のみです。

??? failure "試合後に残留物がある・異常終了した"
    `/inou reset` を実行してください。障壁などの設置物・WorldBorderを含めて完全消去し、IDLEへ戻します。
