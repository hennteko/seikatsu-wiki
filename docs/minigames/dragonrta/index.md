# DragonRTA（エンドラRTA） <span class="badge done">公開中</span>

チームに分かれて、**どのチームが一番早くエンダードラゴンを倒せるか** を競う協力＆対抗レースです。各チームには **専用のオーバーワールド・ネザー・エンド** が用意され、序盤の資源集めからネザー攻略、要塞探し、エンド突入までを駆け抜けます。他チームの進捗はサーバー全体に実況され、白熱の同時進行RTAになります。

!!! note "ゲームの特徴"
    チーム対抗の **エンドラ討伐RTA** です。各チームは **自分たち専用の3ワールド（オーバーワールド／ネザー／エンド）** でプレイし、他チームと資源やダンジョンを奪い合うことはありません。純粋に攻略速度を競います。**味方の方向はActionBarのコンパス** で分かり、チャットはチーム内（`!`で全体）。「初めての鉄」「ダイヤ」「ネザー到達」「エンド到達」「ドラゴンHP半分」など各チームの節目は **サーバー全体に実況** されます。シードは **プリセット**（草原・砂漠・海・村など）から選べ、ワールドは事前生成されます。降参投票・観戦・途中参加にも対応。
