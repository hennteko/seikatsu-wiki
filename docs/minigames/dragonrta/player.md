# DragonRTA（エンドラRTA） ― 遊び方 { .page-player #dragonrta-player }

チームに分かれて、最速でエンダードラゴンを倒すことを競うレースです。各チーム専用のワールドで、資源集め→ネザー→エンドを駆け抜けましょう。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | チーム対抗（協力＋レース） |
    | チーム数 | 最大8（サーバー設定による） |
    | 勝利条件 | 最初にエンダードラゴンを討伐したチーム |
    | ワールド | チームごとに専用のオーバーワールド／ネザー／エンド |
    | 参加方法 | ロビーの参加看板、または `/drta join`（`/dragonrta join`） |
    | ソロRTA | ソロ看板、または `/drta solo`（1人で走ってタイムを記録） |

## どんなゲーム？

参加者はチームに分かれ、**チームごとに用意された専用の3ワールド**（オーバーワールド・ネザー・エンド）でエンダードラゴン討伐を目指します。他チームとは別々のワールドなので、資源やダンジョンの取り合いは起きません。**攻略の速さそのもの** を競うレースです。最初にドラゴンを倒したチームが勝ちです。

## チーム

- 参加するとチームに割り振られます（`/drta team` でチーム選択・確認）。チーム間の人数差には上限があります。
- チーム内で協力して、鉄→ダイヤ→ネザー→ブレイズロッド→エンダーアイ→要塞→エンドと進めます。
- **チャットはチーム内** に届きます。全体に話したいときは先頭に `!` を付けます。

## 味方コンパス

**ActionBar（画面下の帯）に、味方の方向** が表示されます（`/drta compass` で切替）。広いワールドではぐれても、味方の位置を頼りに合流できます。

## 進捗の実況

各チームが節目を **最初に達成したとき**、サーバー全体に実況が流れます（例：「初めての鉄を入手」「ダイヤモンドを入手」「ネザーに到達」「ブレイズロッドを入手」「エンダーアイを入手」「要塞を発見」「エンドに到達」「ドラゴンのHPを半分まで削った」「エンダークリスタルを全て破壊」など）。今どのチームがリードしているかが分かります。

## 途中参加・再接続

- 試合中の **途中参加** が許可されている場合があります（設定による）。
- 試合中に切断しても、再ログインすれば復帰できます（設定により、味方の近くへ移動して再開）。

## 降参

勝ち目が無いときは **降参投票** ができます（`/drta surrender`）。開始から一定時間（既定5分）は降参できません。投票が可決するとそのチームはリタイアします。

## 勝利条件

いずれかのチームが **エンダードラゴンを討伐** した時点でそのチームの勝利です。チームのオンライン人数が0になると、一定の猶予（既定60秒）ののち脱落します。

## ソロRTA（1人で走ってタイムを記録）

1人でエンドラRTAを走り、撃破タイムを **自己ベスト** として残せます。プリセット（草原・砂漠・ランダムなど）ごとの **ランキング** もあります。

!!! info "ソロ専用のワールド（ストック）について"
    サーバーが **ストック** を使う設定のときは、ソロRTA専用のワールドで走ります。チーム戦の試合中や、ほかの人がソロRTAを走っている間でも、空いているストックがあればすぐ始められます（同時に走れる人数には上限があります）。ストックを使わない設定のときは、チーム戦と同じワールドを1人ずつ使います。

### 流れ

1. ソロ看板をクリック、または `/drta solo` で参加します。持ち物は預かられ、ロビーへ移動して **ソロメニュー** が開きます。
2. ソロメニューの開始ボタンを押すと、カウントダウンの後にスタートします。ストックを使う設定では、ボタンが **プリセットごと**（例：「▶ ランダム で開始」）に並びます。
3. ドラゴンを倒すとタイムが記録され、数秒後にロビーへ戻ってソロメニューがもう一度開きます。
4. やめるときはソロメニューの **ロビー退出**（鉄のドア）か `/drta leave` を使います。持ち物が戻り、元の場所へ移動します。

- ソロメニューは閉じても大丈夫です。ホットバーの **ネザースター（ソロメニュー）** を右クリックすると開き直せます。
- `/drta solo rta [プリセット]` で、メニューを通さずにすぐ始めることもできます（プリセットが1つだけなら省略できます）。
- 走っている途中でやめるときは `/drta surrender`（中断。記録は残りません）。ソロでは開始直後でもやめられます。

### ソロメニュー

ストックを使う設定のとき：

| 場所 | 内容 |
|---|---|
| 1段目 | プリセットごとの開始ボタン（緑＝始められる、灰色＝準備中など。説明文に保管数・自己ベスト・1位） |
| 2段目 | 自己ベスト・ランキング上位3人・全プリセットの自己ベスト |
| 3段目 | 前回の結果・同時に走っている人数・チーム戦の観戦 |
| 4〜5段目 | 走っている人（頭をクリックすると、その人のソロRTAを観戦） |
| 6段目 | 記録の表示を切り替え（プリセット）・ロビー退出 |

ストックを使わない設定のとき：

| 場所 | 内容 |
|---|---|
| 上段左 | ソロRTA開始。始められないときはバリアになり、理由が出ます |
| 上段中央 | 今のプリセットの自己ベスト（タイム・ネザー／要塞／エンドの区間・完走回数） |
| 上段右 | 今のプリセットのランキング上位3人と、自分の順位 |
| 中段左 | 全プリセットの自己ベスト |
| 中段中央 | 前回の結果 |
| 下段左 | 観戦（試合中だけ） |
| 下段右端 | ロビー退出 |

### 走っている間

- 画面上の **ボスバー** に経過タイムと自己ベストが出ます。自己ベストを過ぎると赤くなります。
- ネザー到達・要塞発見・エンド到達のたびに、**自己ベストとの差**（例：`-0:35.2`）がチャットに出ます。
- 進捗のアナウンス（ネザー到達など）は、本人とそのソロRTAの観戦者だけに届きます。撃破したときだけサーバー全体にお知らせが流れます。
- ソロRTAの観戦者のチャットは、同じ人を観戦している人と走っている本人だけに届きます（`[観戦]` 表示）。走っている本人のチャットは通常どおり全体に届きます。
- ソロRTA中は `/drta join`（チーム戦への切り替え）はできません。先に `/drta surrender` で中断してください。
- 切断しても60秒以内に戻れば、自分のワールドで続きから遊べます（タイムは止まりません）。
- ルールは通常の試合と同じです（死んでもリスポーンして続けられます）。

### 記録とランキング

- 記録は **プレイヤー × プリセット** ごとの最速タイムです。タイムは0.1秒まで記録します。
- `/drta ranking solo [プリセット]` で上位10人と自分の自己ベストを表示します。プリセットを省略すると、ソロメニューで表示中のプリセット（ストックを使わない設定では今のワールドのプリセット）を表示します。
- 開始から撃破まで **ずっと1人だったチーム** の撃破が対象です。チーム戦で1人チームとして勝った場合も、ソロの記録に入ります。
- ランダムシードのワールドでは、開始前はシードが表示されません（ランキングには使ったシードが出ます）。

### 始められないとき

ソロメニューの開始ボタンに理由が出ます。

| 表示（ストックを使う設定） | 意味 |
|---|---|
| 準備中（生成 ○%） | そのプリセットのストックを作っています。できあがるとチャットでお知らせします |
| 同時に走れる人数の上限 | 誰かが走り終わるまで待ちます（走っている人は観戦できます） |

| 表示（ストックを使わない設定） | 意味 |
|---|---|
| ワールド未作成／使用済み | OP にワールドの作成・作り直しを頼んでください |
| ワールド生成中 ○% | 生成が終わるまで待ちます |
| ○○がソロRTA中／チーム戦の試合中 | ワールドは1組なので、終わるまで待ちます（観戦はできます） |
| チーム戦の参加者が待機中 | チーム戦を待っている人がいる間は、ソロを始められません |

!!! note "ワールドは1回走るごとに作り直します"
    1回走ったワールドは「使用済み」になります。サーバーの設定によっては試合後に自動で作り直され、作り直しが終わると「ソロRTAを始められます」とお知らせが出ます。

## 参加方法

1. ロビーの参加看板をクリック、または `/drta join`。
2. `/drta team` でチームを確認・選択します。
3. 開始看板のクリックまたは `/drta start`（全員可）でカウントダウン後にスタート。
4. 専用ワールドに転送され、RTA開始です。

離脱は `/drta leave`、観戦は `/drta spectate` です。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/drta join` | ロビーに参加する（参加看板と同等・全員可） |
| `/drta leave` | ロビーから離脱する（全員可） |
| `/drta start` | ゲームを開始する（開始看板と同等・全員可） |
| `/drta team` | チームの選択・確認 |
| `/drta status` | 現在の設定・状況を確認する（全員可） |
| `/drta spectate` | 観戦する |
| `/drta surrender` | 降参投票を行う（ソロRTA中はその場で中断・記録なし） |
| `/drta compass` | 味方コンパス（方向表示）の切替 |
| `/drta records` | 記録（過去のRTAタイムなど）を表示 |
| `/drta solo` | ソロで参加し、ソロメニューを開く（ソロ看板と同じ） |
| `/drta solo rta [プリセット]` | ソロRTAをすぐ始める |
| `/drta ranking solo [プリセット]` | ソロRTAのランキングと自分の自己ベスト |

!!! note "コマンドの短縮形"
    `/dragonrta` は `/drta` と短縮できます。

## 統合版（スマホ・Switch など）で遊ぶ場合

- ソロメニューは普通のチェスト画面として開き、タップで操作できます。
- スマホでネザースターの右クリックが反応しないときは、**ネザースターを持ってスニーク** するとソロメニューが開きます（`/drta solo` でも開けます）。
- アイテムの説明文（自己ベストや区間タイム）は、統合版ではアイテムを長押し／選択したときに表示されます。

## よくある質問

??? question "他のチームと同じワールドで戦うの？"
    いいえ。チームごとに専用のオーバーワールド・ネザー・エンドがあります。資源やダンジョンの奪い合いはなく、攻略の速さを競います。

??? question "味方とはぐれました"
    ActionBarのコンパスが味方の方向を示します。`/drta compass` で表示を切り替えられます。

??? question "途中から参加できますか？"
    サーバーの設定で許可されていれば途中参加できます。切断しても再ログインで復帰できます。

??? question "ソロからチーム戦に移りたい"
    `/drta join` を実行するか、チーム選択でチームを選ぶとチーム戦の参加に切り替わります。逆に `/drta solo` でソロに戻れます。

??? question "ソロRTA中に切断しました"
    60秒以内に戻れば続けられます（タイムは止まりません）。戻れなかった場合は中断になり、記録は残りません。

??? question "ほかの人のソロRTAを見たい"
    ソロメニューの「走っている人」の頭をクリックするか、`/drta spectate` で観戦できます。見られるのはその人のワールドの中だけです。
