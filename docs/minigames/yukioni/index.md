# Yukioni <span class="badge done">公開中</span>

雪ブロックを投げ合って遊ぶ **雪鬼ごっこミニゲーム** です。鬼が雪ブロックを投げて市民を捕まえ、当たった市民は次々と鬼になっていきます。制限時間内に市民が逃げ切るか、全員が鬼になるかで勝敗が決まります。

!!! note "ゲームの特徴"
    最初にランダムで1人が鬼になり、雪ブロックを投げて市民に当てると、その市民も鬼になります。市民は移動速度が速く、鬼から逃げ回ります。ゲーム開始直後は鬼が一定時間動けないので、市民は逃げる準備ができます。参加・退出はロビー看板のクリックで行います。
