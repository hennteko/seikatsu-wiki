# Yukioni ― 遊び方 { .page-player #yukioni-player }

雪ブロックを投げ合う鬼ごっこミニゲームです。鬼から逃げ切れば市民の勝ち、全員が鬼になれば鬼の勝ちです。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 2〜16人（既定） |
    | 1試合の長さ | 7分（既定 420秒） |
    | 勝利条件 | 市民が時間切れまで逃げ切る／全市民が鬼になる |
    | 参加方法 | ロビーの参加看板をクリック、または `/yukioni join` |

## どんなゲーム？

ゲームが始まると、参加者の中からランダムで **鬼** が選ばれ（人数に応じて1〜3人）、残り全員が **市民** になります。少人数（7人以下）なら鬼は1人、8〜13人で2人、14人以上で3人からスタートします。

鬼は雪ブロックを持っており、それを投げて市民に当てると、当たった市民もその場で鬼になります。鬼はどんどん増えていきます。市民は鬼から逃げ回り、制限時間まで生き残ることを目指します。

## ルール

- 開始時の鬼はランダム。参加人数に応じて1〜3人（7人以下=1人、8〜13人=2人、14人以上=3人）。
- 鬼は **雪ブロックを右クリックで投げ**、市民に当てると鬼に変えられます。
- 市民は **移動速度が速く** 設定されているので、走って逃げましょう。
- ゲームエリアの外には出られません。エリア外に出ようとすると押し戻されます。
- ゲーム開始直後は **鬼が一定時間その場から動けません**（既定10秒）。その間に市民は逃げる準備をします。

## 鬼の仕組み

| 仕組み | 内容 |
|---|---|
| 最初の鬼 | 開始時にランダムで鬼になる（人数に応じて1〜3人） |
| 武器 | 雪ブロック1個。右クリックで前方に投げる |
| 投げのクールダウン | 連続では投げられない（既定5秒に1回） |
| 開始直後の足止め | 鬼は最初の一定時間（既定10秒）動けない（落下は可能） |
| 市民を捕まえる | 投げた雪ブロックが市民に当たると、その市民が鬼になる |
| 鬼の移動速度 | 通常速度（市民より遅い） |

!!! tip "鬼になったら"
    雪ブロックは投げてもなくならず、何度でも投げられます。ただしクールダウンがあるので、市民に近づいて確実に当てるのがコツです。当たった市民はすぐに仲間の鬼になります。

## 勝利条件

- **市民チームの勝利** … 制限時間（既定7分）が終わるまで、市民が1人でも残っていれば市民の勝ち。
- **鬼チームの勝利** … 制限時間内に **全員が鬼になった** 時点で鬼の勝ち。

## 参加方法

ゲームへの参加は **ロビーの看板** または **コマンド** で行えます。参加・離脱・開始の看板は複数の場所に設置できるので、どの看板からでも操作できます。

1. ロビーに設置された **参加看板**（`lobby` 看板）をクリック、または **`/yukioni join`** で待機ロビーに入れます。
2. ロビーに入るとアドベンチャーモードになり、持ち物が空になります。
3. やめたいときは **離脱看板**（`leave` 看板）をクリック、または **`/yukioni leave`** でロビーから抜けられます。

!!! note "参加・退出について"
    参加・退出は **看板のクリック** または **`/yukioni join`・`/yukioni leave` コマンド**（全員可）で行えます。ゲーム開始（`/yukioni start` や開始看板）は運営側の操作です。人数が集まると運営が開始します。

## ゲームの流れ

1. **参加する** — ロビーの参加看板をクリックして待機ロビーに入る。
2. **カウントダウン** — 必要人数が集まり開始されると、画面中央にカウントダウンが表示される（既定10秒）。
3. **役職発表** — 「鬼」か「市民」かがタイトルで表示され、ゲームエリア内のランダムな位置にテレポートされる。鬼の人数は参加人数に応じて1〜3人。
4. **鬼の足止め** — 開始直後、鬼は一定時間動けない。市民はこの間に逃げる。
5. **鬼ごっこ開始** — 鬼が動けるようになり、雪ブロックで市民を狙う。当たった市民は鬼になる。
6. **タイマー表示** — 画面下のアクションバーに残り時間・市民の人数・鬼の人数が表示される。
7. **決着** — 時間切れで市民の勝ち、全員が鬼になれば鬼の勝ち。決着後、数秒でロビーに戻る。

## プレイヤー用コマンド

参加・退出は看板のほか、コマンド（全員可）でも行えます。

| 操作 | 方法 |
|---|---|
| ゲームに参加する | ロビーの参加看板をクリック／`/yukioni join` |
| ロビーから離脱する | 離脱看板をクリック／`/yukioni leave` |
| 雪ブロックを投げる（鬼） | 雪ブロックを持って右クリック |
| 設定状況を見る | `/yukioni status`（読み取り専用・全員可） |
| 成績を見る | `/yukioni stats [名前]`（読み取り専用・全員可） |

## よくある質問

??? question "どうやってゲームに参加しますか？"
    ロビーに設置された参加看板をクリック、または `/yukioni join` コマンドで待機ロビーに入れます（どちらも全員可）。

??? question "鬼はどうやって決まりますか？"
    ゲーム開始時に、参加者の中からランダムで鬼が選ばれます。鬼の人数は参加人数に応じて変わり、7人以下で1人、8〜13人で2人、14人以上で3人からスタートします。残り全員は市民です。

??? question "市民が鬼に当てられたらどうなりますか？"
    その市民はその場で鬼になり、雪ブロックを持って他の市民を狙えるようになります。

??? question "ゲーム開始直後、鬼が動けないのはなぜですか？"
    市民が逃げる時間を確保するための仕様です。鬼は最初の一定時間（既定10秒）その場から動けません。落下はできます。

??? question "エリアの外に出られません"
    ゲームエリアの外には出られない仕様です。エリア外に向かうと自動で押し戻され、メッセージが表示されます。

??? question "雪ブロックが連続で投げられません"
    鬼の雪ブロック投げにはクールダウン（既定5秒）があります。クールダウン中はメッセージで残り秒数が表示されます。

??? question "自分の成績は見られますか？"
    `/yukioni stats` で自分の成績（プレイ回数・市民で生存した回数・鬼にされた回数・市民を捕まえた回数）を確認できます。`/yukioni stats <名前>` で他プレイヤーの成績も閲覧できます（どちらも全員可）。
