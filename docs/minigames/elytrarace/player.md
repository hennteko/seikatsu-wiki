# ElytraRace ― 遊び方 { .page-player #elytrarace-player }

エリトラで空を飛び、コース上に光る **リング（チェックポイント）を順番にくぐって** ゴールを目指すタイムアタック／レースです。レース用エリトラとロケット花火は自動で配られ、ロケットは飛んでいる間も一定数まで自動補充されます。クラッシュや落下をしても死なずに直前のチェックポイントへ戻されるので、安心して攻めた飛行を楽しめます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 最低1人〜（サーバー設定の最低人数による・上限なし） |
    | 制限時間 | 対戦レースは既定300秒（サーバー設定による）／ソロは無制限 |
    | 勝利条件 | すべてのリングを順番に通過し、ゴールリングを最速で通過する |
    | 装備 | レース用エリトラ＋ロケット花火（自動配布・自動補充） |
    | クラッシュ・落下時 | 死亡せず、直前のチェックポイントへ自動で戻されます |
    | 参加・離脱 | ロビーの **看板をクリック** または **`/elytrarace join` / `leave`**（どちらも全員可） |

## どんなゲーム？

ElytraRace は「エリトラ飛行タイムアタック」です。参加するとレース用エリトラとロケット花火が配られ、コースには **次にくぐるべきリング** が光って表示されます。リングを順番に通過し、最後の **ゴールリング** をくぐるとクリアで、そのタイムが記録されます。

遊び方は2種類あります。

- **対戦レース** … 複数人が同時にスタートし、順位を競います。ゴールした順に「1位・2位…」と発表されます。
- **ソロ** … 1人でスタートして、ゴースト（過去の走り）と競いながらタイムを詰めます。いつでも遊べます（旧・練習モード）。

どちらもゴールタイムは自動で記録され、**自己ベスト更新** やコース別の **ランキング** に反映されます。

!!! note "クラッシュしても死なない"
    壁への激突・落下・その他の致死ダメージを受けても **死亡しません**。代わりに直前に通過したチェックポイント（最初はスタート地点）へ自動で戻され、リングの方向を向いた状態で再スタートします。アイテムを落としたり経験値を失ったりすることもありません。

## 人数・時間

| 項目 | 内容 |
|---|---|
| 最低人数 | サーバー設定の最低人数（既定1人）に達すると対戦レースを開始できます |
| 上限人数 | 特に制限はありません（ロビーに集まった全員が参加します） |
| 対戦レースの制限時間 | 既定300秒。時間切れになると、まだゴールしていない人はロビーへ戻されレース終了です（0秒設定＝無制限） |
| ソロの時間 | 無制限。自分のペースで何度でも挑戦できます |

## 操作方法（飛行・ブースト）

エリトラ飛行はマインクラフト標準の操作です。難しいコマンドは不要です。

| 操作 | やり方 | 効果 |
|---|---|---|
| 飛行開始（滑空） | 高所からジャンプして落下中に **もう一度ジャンプ**（統合版はジャンプ2回／飛行操作） | エリトラで滑空を始める |
| ブースト | **ロケット花火を右クリック** で使用（ホットバー左端に自動配置） | 前方へ一気に加速する |
| 戻る（チェックポイント選択） | **コンパスを右クリック**（ホットバー内に配布） | 通過済みチェックポイントを選んで戻れる |
| ギブアップ | **バリアブロックを右クリック**（ホットバー右端に配布） | レース／ソロを中断してロビーへ戻る |

!!! tip "ロケット花火は自動で補充される"
    ロケット花火は使っても、飛行中に一定間隔で自動補充され **常に一定数まで回復** します。残弾を気にせずどんどんブーストして構いません（補充される本数や間隔はサーバー設定によります）。

!!! note "戻るアイテム（コンパス）で立て直せる"
    コンパスを右クリックすると **チェックポイント選択メニュー** が開き、スタート地点や通過済みのチェックポイントを選んでその場へ戻れます。ルートを間違えた・大きく外したときの立て直しに便利です。戻ると次のリングの方向を向いた状態になります。

## 画面表示（HUD）

飛行中は次の情報が表示されます。

| 表示先 | 内容 |
|---|---|
| アクションバー（画面下部） | 次のリング（またはゴール）までの距離・通過したCP数／総数・経過タイム |
| サイドバー（対戦レース中） | コース名／現在順位／CP進捗／経過タイム／上位3名 |
| コース上のパーティクル | **次にくぐるリングが光って表示**（チェックポイント＝白い光／ゴール＝炎） |
| タイトル（画面中央） | カウントダウン（3・2・1）、「GO!」、ゴール時の「GOAL!」やタイム、順位など |

!!! tip "次のリングは光の輪が目印"
    自分が次にくぐるべきリングだけがパーティクルの輪で光って見えます（約200ブロック以内）。**白い輪がチェックポイント、炎の輪がゴール** です。順番に輪をくぐっていけば正しいルートを飛べます。

## レースの流れ

1. **参加する** — ロビーの **参加看板（[ElytraRace]）をクリック** するか **`/elytrarace join`** を実行してロビーへ入ります（どちらも全員可）。
2. **開始を待つ** — 対戦レースは、開始看板のクリックまたは `/elytrarace start <コース>` で始まります。開始すると全員がスタート地点へ転送されます。
3. **3・2・1・GO!** — カウントダウン中は移動が固定されます（視点だけ動かせます）。「GO!」で一斉スタート。
4. **飛ぶ** — エリトラで飛び、光るリングを順番にくぐります。ロケット花火で加速しながらルートを走り抜けます。
5. **ゴール** — すべてのリングを通過してゴールリングをくぐるとクリア。タイムと順位が表示され、対戦レースではロビーへ、ソロではソロロビーへ戻ります。
6. **レース終了** — 全員がゴールするか制限時間が過ぎるとレース終了。上位3名が発表されます。終了後もロビーの参加状態は維持されるので、続けて次のレースに参加できます。

## ルール

- **リングは順番に通過** する必要があります。順番を飛ばしても次のリングとしてカウントされません（次に光っているリングだけが有効です）。
- すべてのリングを通過した後、**ゴールリング** をくぐるとクリアです。
- クラッシュ・落下・致死ダメージでは **死亡せず、直前のチェックポイントへ戻されます**。
- カウントダウン中は移動できません（視点変更のみ）。ゴール後は無敵になります。
- レース中はエリトラや専用アイテム（コンパス・バリア・ロケット花火）を **捨てたり付け替えたりできません**。満腹度も減りません。
- 対戦レースは **制限時間（既定300秒）** を超えると、未ゴールの人はロビーへ戻されて終了します。

## 参加・離脱・ランキング

ロビーの **看板** をクリックすれば、コマンドを覚えなくても操作できます。`/elytrarace` コマンドでも同じことができます。

| 看板 | 操作 | 効果 |
|---|---|---|
| 参加看板（[ElytraRace] >> 参加） | クリック | レースに参加してロビーへ（`/elytrarace join` と同じ） |
| 離脱看板（[ElytraRace] << 離脱） | クリック | レースから離脱して初期地点へ（`/elytrarace leave` と同じ） |
| 開始看板（[ElytraRace] >> 開始） | クリック | そのコースの対戦レースを開始（`/elytrarace start` と同じ・全員可） |
| ソロ看板（[ElytraRace] >> ソロ・コース名あり） | クリック | クリックした本人がそのコースをソロですぐ開始（旧・練習看板） |
| ソロ看板（[ElytraRace] >> ソロ・在籍人数） | クリック | ソロロビーへ入りソロメニューを開く（`/elytrarace solo` と同じ） |
| ランキング看板（[ランキング]） | 表示／クリック | そのコースの1位を自動表示。クリックで上位ランキングをチャットに表示 |

参加看板・開始看板の4行目には、現在の参加人数や「試合中」などの状態が自動で表示されます。

## プレイヤー向けコマンド

いずれも権限不要で全員が使えます。

```text title="レースに参加する（ロビーへ移動）"
/elytrarace join
```

```text title="レースから離脱する（初期地点へ）"
/elytrarace leave
```

```text title="指定コースの対戦レースを開始する（参加者がいれば全員可）"
/elytrarace start <コース名>
```

```text title="指定コースをソロですぐ走る（/elytrarace solo <コース名> と同じ・旧練習モード）"
/elytrarace practice <コース名>
```

```text title="指定コースのタイムランキングを表示する"
/elytrarace ranking <コース名>
```

```text title="自分のコース別統計（挑戦回数・クリア回数・ベスト）を表示"
/elytrarace stats
```

```text title="コースや設定の状況を確認する（読み取り専用）"
/elytrarace status
```

!!! note "エイリアス（短縮コマンド）"
    `/elytrarace` は **`/er`** と短く打っても実行できます（例: `/er join`、`/er practice sky1`）。

## ソロモード（ゴースト・区間タイム）

1人でコースに挑戦するモードです（以前の「練習モード」はソロにまとまりました）。

1. **ソロ看板をクリック** するか **`/elytrarace solo`** でソロロビーへ入ると、**ソロメニュー** が開きます。
2. メニューでコースを押すと 3・2・1・GO でスタート。走り終わる（ゴール・ギブアップ）とソロロビーに戻り、数秒後にメニューが開くので続けて挑戦できます。
3. ロビーにいる間はホットバーの **ネザースター（ソロメニュー）** で何度でもメニューを開けます。持ち物は **`/elytrarace leave`** かメニューの「ロビーを出る」で元に戻ります。

| 要素 | 内容 |
|---|---|
| ゴースト | 過去の走りが **自分にだけ見える姿** で一緒に飛びます。種類は **自己ベスト／1位／前回／なし**（メニューの「ゴースト」ボタンか `/elytrarace ghost <best\|top\|last\|off>`）。ゴーストがゴールすると消えます |
| 区間タイム | リング（CP）を通るたびに、比べる相手との差を表示（緑＝速い・赤＝遅い）。ゴール後に区間表と **理論値**（区間ごとの自己最速の合計）を表示 |
| BossBar | 画面上部に「経過タイム / 比べる相手のタイム」。相手より遅れると赤になります |
| リトライ | ホットバーの **時計** を右クリック（または `/elytrarace retry`）でスタートからやり直し（記録なし） |
| 同時プレイ | 同じコースを何人でも同時に走れます。他の人のゴーストは見えません |

- 対戦レース中も、リングを通るたびに **自分の自己ベストとの差** だけは表示されます（ゴーストは出ません）。
- 区間タイムの出し方（チャット＋画面／チャットのみ／表示しない）はメニューで切り替えられます。
- 対戦ロビーに参加している間はソロに入れません（先に `leave`）。

!!! info "統合版（スマホ・Switch など）の場合"
    - ソロメニューは **ネザースターを持ってスニーク** でも開けます（空中の右クリックが届かないことがあるため）。
    - リトライは空中タップでも使えますが、誤操作防止のため **3秒以内に2回タップ** で確定します（`retry` コマンドでも可）。
    - ゴーストは透明な防具立て＋頭の姿で表示されます。発光（光る輪郭）は使っていません。足元のパーティクルは数に上限があるため、遠くでは見えにくいことがあります。

```text title="ソロメニューを開く（ソロロビーへ）"
/elytrarace solo
```

```text title="メニューを通さずにすぐ走る（ゴーストの種類も指定可）"
/elytrarace solo <コース名> [best|top|last|off]
```

```text title="ソロ中にスタートからやり直す（記録なし）"
/elytrarace retry
```

```text title="ゴーストの種類を変える"
/elytrarace ghost <best|top|last|off>
```


## よくある質問

??? question "エリトラの飛び方が分かりません"
    参加すると自動で **レース用エリトラ** が装備されます。高い場所からジャンプして落下中に **もう一度ジャンプ** すると滑空が始まります。あとは **ロケット花火を右クリック** すると前方へ加速できます。スタート地点は飛び出しやすい位置に用意されています。

??? question "ロケット花火が無くなりました"
    飛行中は自動で補充されるので、少し待てば回復します。常に一定数まで自動で戻るため、残弾切れで飛べなくなることは基本的にありません。

??? question "壁にぶつかって死にそうです"
    このゲームでは致死ダメージを受けても **死亡しません**。直前に通過したチェックポイント（最初はスタート地点）へ自動で戻され、次のリングを向いた状態で再開できます。アイテムや経験値も失いません。

??? question "ルートを間違えて大きく外れました"
    配布される **コンパス（戻るアイテム）を右クリック** すると、スタート地点や通過済みチェックポイントを選んで戻れるメニューが開きます。選ぶと次のリング方向を向いた状態でその地点へ戻ります。

??? question "リングを飛ばしてショートカットできますか？"
    リングは **順番に通過する必要** があります。次に光っているリング以外を通ってもカウントされないため、順番どおりにくぐるのが最速ルートです。

??? question "対戦レースとソロの違いは？"
    対戦レースは複数人で同時にスタートし順位を競います（開始看板／`start`）。ソロは1人でいつでも開始でき、ゴーストや区間タイムを見ながら時間無制限でタイムを詰められます（ソロ看板／`solo`。旧・練習モード）。どちらもタイムは記録され、自己ベストやランキングに反映されます。

??? question "途中でやめたいです"
    ホットバー右端の **バリアブロックを右クリック** すると「ギブアップ」でレース／ソロを中断できます。ロビーの **離脱看板** をクリックするか **`/elytrarace leave`** でも離脱できます。

??? question "自分の記録やランキングを見たいです"
    `/elytrarace stats` で自分のコース別の挑戦回数・クリア回数・ベストタイムを確認できます。`/elytrarace ranking <コース名>` またはランキング看板で、コースごとの上位タイムを見られます。
