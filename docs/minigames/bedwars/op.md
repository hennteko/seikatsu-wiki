# BedWarsPlugin ― OP・運営ガイド { .page-op #bedwars-op }

BedWarsPlugin の導入・チーム/ジェネレーター/ショップ/看板の設定・config・権限・管理コマンドをまとめます。

## 基本情報

| 項目 | 値 |
|---|---|
| プラグイン名 | BedWarsPlugin |
| バージョン | 1.0.0 |
| api-version | 26.1.2 |
| メインコマンド | `/bedwars`（エイリアス `/bw`） |
| 依存プラグイン | なし |
| 設定ファイル | `plugins/BedWarsPlugin/config.yml`（設定・地点・看板を一括保存） |

!!! info "仕組み"
    最大8色のチームで対戦します。各チームは **スポーン・ベッド・拠点ジェネレーター** の3点を設定すると「有効チーム」になり、有効チームが2色以上でフィールドが設定されていれば試合を開始できます。拠点ジェネレーターは鉄・金、中央のダイヤ／エメラルドジェネレーターは上位資源を湧かせます。参加者はシャッフルして有効チームへラウンドロビンで振り分けられます。地点・看板・数値設定はすべてコマンドで `config.yml` に **即自動保存** されます。

## 導入手順

1. ビルドした `BedWarsPlugin.jar` をサーバーの `plugins/` フォルダに配置する。
2. サーバーを起動すると `plugins/BedWarsPlugin/config.yml` が自動生成される。
3. 後述の「セットアップ手順」でロビー・フィールド・チーム・ジェネレーター・ショップ・看板を設定する。
4. `/bedwars status` でいつでも設定状態を確認できる。

## セットアップ手順

専用フィールドを用意し、OP権限（`bedwars.admin`）で以下を **その場に立って／対象を見て** 実行します。地点は `config.yml` に即保存されます。

### 設定ツール（wand）でまとめて設定する

コマンドの代わりに、**設定ツール（ブレイズロッド）** とメニューで全部の設定ができます。コマンドもそのまま使えます。

```text title="設定ツールを受け取る（OP限定・BedWars に参加中は受け取れない）"
/bedwars wand
```

| 操作 | 内容 |
|---|---|
| 右クリック（空中）／スニーク＋右クリック | 設定メニューを開く（統合版は空中タップ） |
| メニューの地点ボタン | **今立っている位置（向き込み）** で登録する（初期スポーン・ロビー・各色のスポーン／ベッド／拠点ジェネ・ダイヤ／エメラルド・ショップ・Mob 出現地点） |
| 「近くを解除」ボタン | 5ブロック以内で一番近い共有ジェネレーター／ショップ／Mob 出現地点を解除 |
| フィールド範囲（範囲モード） | ブロックを **左クリック/長押し＝角1**、**右クリック/タップ＝角2**（床の上面をクリックするとその上＝立つ位置が角） |
| 看板（看板モード） | 看板を右クリック/タップで登録。解除モードなら解除。モードなしで看板を右クリックすると何の看板か表示 |
| 設定状況 | `/bedwars status` と同じ内容を表示 |
| 粒子の表示・ツールを回収 | 表示のオン/オフ、ツールをしまう |

- 持っている間、本人にだけ粒子で表示します：フィールド範囲（白）、各色のスポーン・ベッド・拠点ジェネ（チームの色）、ダイヤ（水色）・エメラルド（緑）、アイテムショップ（黄）・アップグレードショップ（橙）、**Mob 出現地点（赤）**、ソロ拠点のベッド（金の円）。
- 選んだモードはツールの表示名に「[フィールド範囲]」のように出ます。
- **試合中（ソロを含む）は地点・範囲を変更できません**（看板の登録・解除はできます）。
- ツールは PDC で識別し、受け取る時・クリック時・メニュー操作時に権限を確かめます。OP 以外が持っていても使えません。ツールを持ってのブロック破壊はできません。

### 共通の地点

```text title="ロビー地点を現在地に設定（参加時のTP先）"
/bedwars setlobby
```
```text title="初期スポーン（離脱・終了後の戻り先）を現在地に設定"
/bedwars setstartspawn
```
```text title="フィールド範囲の角1を現在地に設定"
/bedwars setfield 1
```
```text title="フィールド範囲の角2を現在地に設定"
/bedwars setfield 2
```

!!! tip "フィールド範囲の役割"
    `setfield 1`/`2` の2点で囲んだ直方体が **建築・破壊・特殊アイテムの有効範囲** です。また **フィールド下端-5より下は奈落判定** になり、落ちると死亡します。フィールド未設定でも開始はできますが（範囲無制限扱い）、奈落判定がワールド最低高度になるため、必ず設定することを推奨します。

### チーム設定（スポーン・ベッド・拠点ジェネレーターの3点で有効化）

各色ごとに以下の3点を設定すると、その色が **有効チーム** になります。色は `red` `blue` `green` `yellow` `aqua` `white` `pink` `gray`（日本語名 赤/青/緑/黄/水色/白/桃/灰 も可）。

```text title="チームの試合内スポーンを現在地に設定"
/bedwars setspawn <色>
```
```text title="チームのベッドを登録（対象のベッドを見て実行）"
/bedwars setbed <色>
```
```text title="チームの拠点ジェネレーター（鉄・金）を現在地に設定"
/bedwars setgenerator base <色>
```

!!! warning "有効チームは2色以上必要"
    スポーン・ベッド・拠点ジェネレーターの **3点すべて** が揃った色だけが有効チームです。有効チームが **2色未満だと開始できません**。`/bedwars status` で各色の有効/無効を確認してください。ベッドが未登録・未設置のチームは「ベッドなし」で開始され（最初のデスで即脱落）、警告がログに出ます。

### 共有ジェネレーター（ダイヤ・エメラルド）

フィールド中央などに設置する **全チーム共有** の上位資源ジェネレーターです。複数箇所を登録できます。

```text title="ダイヤジェネレーターを現在地に追加（複数可）"
/bedwars setgenerator diamond
```
```text title="エメラルドジェネレーターを現在地に追加（複数可）"
/bedwars setgenerator emerald
```
```text title="最寄り(5ブロック以内)の共有ジェネレーターを解除"
/bedwars setgenerator delete
```

### ショップNPC（村人）の設置

村人NPCを湧かせる地点を登録します。試合開始時に自動でスポーンし、終了時に消えます。複数箇所を登録できます。

```text title="アイテムショップ地点を現在地に追加（複数可）"
/bedwars setshop item
```
```text title="アップグレードショップ地点を現在地に追加（複数可）"
/bedwars setshop upgrade
```
```text title="最寄り(5ブロック以内)のショップ地点を解除"
/bedwars setshop delete
```

!!! note "ショップNPCは自動生成・自動除去"
    登録地点に試合開始時に村人（AI無効・無敵・押されない）が湧き、終了・リセット時に除去されます。取りこぼしはタグ判定で掃除されるため、手動配置は不要です。

### 数値設定（コマンドで即保存）

```text title="試合の制限時間（秒）を設定"
/bedwars settime <秒>
```
```text title="開始に必要な最低人数を設定"
/bedwars setmin <人数>
```

その他の数値（リスポーン待機・ジェネレーター間隔・イベント時刻など）は `config.yml` を直接編集します（後述）。

### 看板の設置

参加・離脱・開始・ソロの **4種** の看板を登録できます。**いずれの種別も複数拠点に設置可能**です。看板を見ながら（6ブロック以内）以下を実行します。テキストはプラグインが自動で書き込み・更新します（人数・状態を表示）。

```text title="参加看板を登録（複数登録可）"
/bedwars setsign join
```
```text title="離脱看板を登録（複数登録可）"
/bedwars setsign leave
```
```text title="開始看板を登録（複数登録可）"
/bedwars setsign start
```
```text title="ソロ看板を登録（複数登録可。クリックでソロメニュー）"
/bedwars setsign solo
```
```text title="登録済み看板の登録を解除（視線先の看板を自動判別）"
/bedwars setsign delete
```

!!! tip "看板は保存座標で判定"
    クリック判定は登録した座標との一致で行います（手書きテキストでは機能しません）。看板は自動的に施錠（waxed）され、編集UIが開かないようになっています。参加/開始看板には現在の参加人数と状態（待機中/試合中/終了処理中）が表示されます。`setsign` は上書きではなく **追記** され、`setsign delete` は視線先の1枚だけ解除します。既存の看板データは自動で引き継がれるため、**設定のやり直しは不要**です。

### ソロ防衛の設定

通常戦の設定（ロビー・フィールド・有効チーム1色以上）がそろっていれば、追加で必要なのは **Mob の出現地点** と **ソロ看板** だけです。

```text title="（任意）ソロで使う拠点の色を決める（未設定なら有効チームの先頭）"
/bedwars setsoloteam <色>
```
```text title="立っている位置を Mob の出現地点に登録（1か所以上・3〜4か所推奨）"
/bedwars addmobspawn
```
```text title="5ブロック以内で一番近い Mob の出現地点を解除"
/bedwars delmobspawn
```
```text title="視線先の看板をソロ看板に登録"
/bedwars setsign solo
```

!!! warning "出現地点はソロ拠点の島に置く"
    島どうしが奈落で離れているマップでは、他の島に置くと Mob がベッドまで歩いて来られません。**ソロ拠点の島の端（ベッドから15〜25ブロック）** に置いてください。島が小さくて置けない場合は、他の島からソロ拠点まで固定の橋をマップ側に作ってから置きます。
    登録時に「フィールド範囲内か」「足元が固いブロックか」「ソロ拠点のベッドから8ブロック以上離れているか」を確かめ、合わなければ理由を出して断ります。

!!! note "ソロを始められない場合"
    ソロメニューの難易度ボタンがバリアになり、理由が表示されます（ロビー・フィールド未設定／ソロ拠点なし／出現地点0件／ワールドがピースフル／アリーナ使用中）。`/bedwars setsoloteam` で指定した色の3点（スポーン・ベッド・拠点ジェネ）がそろっていない場合は、別の色に勝手に切り替えずに止めます。

### ミニゲームメニューへの登録（ソロ）

本人として実行するボタンなら：

```text title="ソロメニューを開く（本人として実行）"
/bedwars solo
```

コンソールとして実行するボタンなら：

```text title="指定した人にソロメニューを開かせる（コンソール・コマンドブロック・OP）"
/bedwars solo <プレイヤー>
```

`/bedwars solo <プレイヤー> defense [難易度]` にすると、メニューを通さずすぐ始めさせます。`@p` などのセレクターも使えます。

## 設定状況の確認

```text title="設定・進行状況をまとめて確認"
/bedwars status
```

地点設定・チームの有効/無効・ソロの拠点と Mob 出現地点・看板（ソロ看板を含む）・現在の状態（待機中/試合中）・参加人数・試合時間・進行中の経過秒とベッド生存・ソロの状況（空き／挑戦中の人・難易度・ウェーブ・耐久）・ソロ入場の在籍者数・難易度一覧・ソロ記録の件数が確認できます。

## config.yml 主要項目

地点・看板はコマンドで自動保存されるため手動編集は不要です。以下の数値パラメータは調整時のみ編集します。

| キー | 既定値 | 説明 |
|---|---|---|
| `settings.min-players` | 2 | 開始に必要な最低人数（`setmin` でも変更可） |
| `settings.team-size` | 2 | 1チームの目標人数（チーム数＝参加人数÷この値の切り上げ・最大は有効チーム数。例: 2なら6人→3チーム 2vs2vs2） |
| `settings.game-time` | 2400 | 試合の制限時間（秒＝40分・`settime` でも変更可） |
| `settings.respawn-delay` | 5 | リスポーン待機（秒） |
| `settings.build-max-y` | 0 | 建築高度上限（0＝無制限） |
| `settings.generator.iron-interval` | 30 | 鉄の湧き間隔（tick） |
| `settings.generator.gold-interval` | 120 | 金の湧き間隔（tick） |
| `settings.generator.diamond-interval` | `[600, 460, 300]` | ダイヤの湧き間隔（tick）Tier I / II / III |
| `settings.generator.emerald-interval` | `[1200, 900, 600]` | エメラルドの湧き間隔（tick）Tier I / II / III |
| `settings.events.diamond-2` | 360 | ダイヤ Tier II 昇格時刻（開始からの秒） |
| `settings.events.emerald-2` | 720 | エメラルド Tier II 昇格時刻（秒） |
| `settings.events.diamond-3` | 1080 | ダイヤ Tier III 昇格時刻（秒） |
| `settings.events.emerald-3` | 1440 | エメラルド Tier III 昇格時刻（秒） |
| `settings.events.bed-destruction` | 1800 | 全ベッド自動崩壊の時刻（秒＝30分） |
| `settings.events.sudden-death` | 2160 | サドンデス（ドラゴン出現）の時刻（秒＝36分） |

### ソロ防衛（`solo.*`）

| キー | 既定値 | 説明 |
|---|---|---|
| `solo.enabled` | true | false でソロを無効にする |
| `solo.menu-delay` | 3 | 終わってからソロメニューを開き直すまで（秒） |
| `solo.result-seconds` | 5 | 結果を表示してからアリーナを片付けるまで（秒） |
| `solo.default-difficulty` | normal | 難易度を省略したときの難易度 |
| `solo.ranking-size` | 10 | ランキングの表示人数 |
| `solo.broadcast-result` | true | 結果をサーバー全体に流す |
| `solo.defense.bed-health` | 100 | ベッドの耐久 |
| `solo.defense.max-seconds` | 3600 | 上限時間（到達で「完走」。0で上限なし） |
| `solo.defense.first-wave` | 20 | 1波目までの準備時間（秒） |
| `solo.defense.wave-interval` | 40 | 波の間隔（秒。全滅させると残り5秒まで早まる） |
| `solo.defense.base` / `per-wave` | 3 / 1 | 1波目の数と1波ごとに増える数 |
| `solo.defense.max-alive` | 25 | 同時に出る敵の上限 |
| `solo.defense.captain-every` | 5 | 何波ごとに隊長が出るか（0で出ない） |
| `solo.defense.base-radius` | 12 | トラップが効く拠点の半径 |
| `solo.defense.stuck-seconds` | 2 | 掘り屋・破城兵が「詰まった」と判断するまで（秒） |
| `solo.defense.hp-per-wave` / `damage-per-wave` | 0.03 / 0.02 | 1波ごとの敵の体力・攻撃力の上がり幅 |
| `solo.defense.mobs.<種類>.from-wave` / `weight` | 下表 | 出始める波と出現の重み。`breaker.max-alive`（既定2）は破城兵の同時上限 |
| `solo.defense.bed-damage.striker` / `captain` / `bomber` | 2 / 6 / 25 | ベッドへのダメージ（殴りは1秒ごと、爆発は最大値） |
| `solo.defense.dig-seconds.<ブロック>` | 羊毛1・テラコッタ1.5・板材2・エンドストーン3・黒曜石-1 | 掘り屋の破壊秒数（無いブロックは2秒、-1は掘り屋では壊せない） |
| `solo.defense.breaker-dig-multiplier` | 0.5 | 破城兵の破壊秒数の倍率 |
| `solo.defense.breaker-obsidian-seconds` | 6.0 | 破城兵が黒曜石を壊す秒数 |
| `solo.defense.rewards.<種類>.<アイテム>` | 下表 | 撃破報酬（`wave-clear` は波を全滅させたとき） |
| `solo.difficulty.<id>` | easy / normal / hard | 難易度。`display`・`icon`・`mob-multiplier`・`mob-health`・`bed-damage`・`reward`。増減してよい（ID に「.」は使えない） |

| 種類（キー） | 出始める波 | 重み | 報酬 |
|---|---|---|---|
| 突撃兵（striker） | 1 | 5 | 鉄2 |
| 射手（archer） | 3 | 3 | 鉄2 |
| 掘り屋（digger） | 4 | 2 | 金1 |
| 爆弾兵（bomber） | 6 | 2 | 金1 |
| 破城兵（breaker） | 8 | 1 | 金3 |
| 隊長（captain） | captain-every ごと | － | ダイヤ2・エメラルド1 |

- `solo.difficulty`・`solo.defense.dig-seconds`・`solo.defense.rewards` は利用者が増減する設定のため、**既にあれば自動更新で中身を補完しません**（消した難易度が復活しない）。まだ無い場合だけ丸ごと追記します。
- ソロ拠点の色は `arena.solo.team`、出現地点は `arena.solo.mob-spawn`、ソロ看板は `solo-sign` に自動保存されます。記録は `solo-records.yml`（自動更新の対象外）。

座標系（`default-spawn` / `lobby-spawn` / `arena.field.min|max` / `arena.spawn.<色>` / `arena.bed.<色>` / `arena.generator.base.<色>` / `arena.generator.diamond` / `arena.generator.emerald` / `arena.shop.item` / `arena.shop.upgrade`）と看板（`sign` / `leave-sign` / `start-sign.N`）はコマンド実行時に自動保存されます。

!!! warning "既存サーバーを更新する場合（config自動マージなし）"
    本プラグインは `saveDefaultConfig()` のみで、**既存の `config.yml` に新しいキーを自動追記しません**。コード側に既定値があるため未記載でも既定値で動作しますが、**ジェネレーター間隔やイベント時刻を調整したい場合は配布 `config.yml` を参照して手動で追記**してください。地点・看板・`settime`/`setmin` の値はコマンドで都度保存されるため問題ありません。

!!! note "config の反映タイミング"
    `settings.*` の数値（ジェネレーター間隔・イベント時刻・リスポーン待機など）は試合開始時に読み込まれます。手動編集した場合は **次の試合から反映** されます（reloadコマンドはありません。手動編集後はサーバー再起動が確実です）。

    `/bedwars join`・`leave`・`start`・`status`・`solo`・`ranking solo` は権限チェックがなく全プレイヤーが使えます（看板と同等）。設定・管理コマンドのみ `bedwars.admin` が必要です。コマンドレベルの権限は plugin.yml では付与せず、コード側で判定しています。

## トラブルシューティング

??? failure "試合が開始できない"
    次を `/bedwars status` で確認してください。**ロビーとフィールド範囲が設定済み**、**有効チームが2色以上**（各色にスポーン・ベッド・拠点ジェネレーターの3点）、**参加者が最低人数以上**（既定2人）。いずれかが欠けると開始できません。

??? failure "あるチームが最初のデスで脱落してしまう"
    そのチームの **ベッドが未登録／未設置** の可能性があります。`/bedwars setbed <色>` でベッドを見て登録し、実際にベッドが置かれているか確認してください（ベッドなしで開始すると即脱落＝ファイナルキル扱い）。

??? failure "ショップNPCが出ない / 商品が買えない"
    `/bedwars setshop item`（または `upgrade`）で地点を登録しているか確認してください。NPCは試合開始時に湧きます。購入は試合中の参加者のみ可能で、アイテムショップは所持資源（鉄/金/ダイヤ/エメラルド）、アップグレードショップは **ダイヤ** で支払います。

??? failure "資源が湧かない / 湧きすぎて止まる"
    拠点ジェネレーターは `/bedwars setgenerator base <色>`、中央は `setgenerator diamond`/`emerald` で登録が必要です。ジェネレーター周囲に資源が溜まりすぎる（鉄48・金16・ダイヤ8・エメラルド4を超える）と一時的に湧きが止まる仕様です（拾って解消）。

??? failure "config の値を変えても反映されない"
    `settings.*` は試合開始時に読み込まれます。手動編集後は次の試合から反映されます（reloadコマンドはありません。確実に反映するにはサーバー再起動）。既存サーバーでは新しいキーが自動追記されないため、調整したいキーは手動追記が必要です。

??? failure "ソロ防衛で敵が出ない／すぐ次の波が来る"
    Mob の出現地点が登録されているか、ワールドがピースフルでないかを確認してください。WorldGuard などで Mob の湧きを止めている場合は、出現地点の周りで許可してください（止められている間は波を「全滅」扱いにしません）。

??? failure "ソロの敵がベッドまで来ない"
    出現地点が他の島にあると、奈落を渡れず来られません。ソロ拠点の島の端に置き直してください（設定ツールを持つと出現地点が赤い粒子で見えます）。

??? failure "試合終了後にベッドや地形が元に戻らない"
    ベッドや変化したブロックは試合開始時のスナップショットから復元されます。サーバー停止などで中断された場合は復元されないことがあります。`/bedwars stop` で強制終了するとリセット（設置ブロック撤去・ベッド復元・NPC/ドラゴン除去・ドロップ掃除）が実行されます。

## ソロ防衛の仕様メモ（共通ルールとの関係）

- ソロは共通ルール14章（GUIロビー）に従います。通常戦とアリーナを共用し、**同時にどちらか1つだけ** です。ソロ中に `/bedwars start` を打つと理由を出して断り、通常戦の試合中はソロを始められません。
- ソロ中でも `/bedwars join` は受け付けます（ロビーで待ち、ソロが終われば通常戦を始められます）。ソロで入った人は通常戦の参加者に含めません。
- `/bedwars stop`：ソロ中なら中断（記録なし）して挑戦者をロビーへ戻し、ソロメニューを開きます。カウントダウン中なら開始を取りやめます。結果表示中なら記録はそのまま、片付けを早めます。
- leave・切断は「中断」で記録しません（1人なので脱落＝試合の終わり。負けそうで抜けても記録にならないようにするため）。共通ルール12章の例外です。
- 難易度を省略すると既定の難易度（ふつう）で始めます（共通ルール1章の例外。雪合戦・スプラ・エンドラRTA と同じ）。
- ロビー中はソロメニューのネザースターを1つ置きます（共通ルール6章の例外）。PDC で識別し、捨てる・移動・持ち替え・額縁／防具立てへの設置はできません。
- 敵 Mob はプラグインが出したもの（PDC 付き）で、**挑戦者とベッドにしか作用しません**（一般プレイヤー・他の Mob を狙わない・ダメージを与えない）。日光で燃えず、変身せず、アイテムを拾わず、経験値・ドロップは出しません。ゾンビの増援も出しません。セーブされないので再起動で残らず、残っていても読み込み時に消えます。
- 爆弾兵の爆発はプラグインで処理します（`mobGriefing` が false でも効く）。壊すのは設置ブロック（黒曜石以外）だけで、ダメージは挑戦者にだけ入ります。
- 記録の時間はサーバーの tick で数えます（ラグがあっても上限時間・表示とずれません）。

## 全ゲーム共通の改修（2026-09）

全ミニゲーム共通の改修が入り、本ゲームにも適用されています。

- **名前表示** … 参加中はチャット名・Tabリスト名・頭上の名札が「【ゲーム名】名前」になり、離脱で元に戻ります（表示名は config の `display-name`）。
- **参加/離脱の全体告知** … 参加・離脱時にサーバー全体へ「【ゲーム名】名前 が参加しました (N人)」等を通知します。
- **同時参加は1ゲームまで** … 他ゲームに参加中は参加が拒否されます（「【○○】に参加中です」）。異常で参加ロックが残った場合はOPが `/<コマンド> forceunlock <プレイヤー>` で解除できます。
- **退避データのファイル保存** … ロビー入場時に退避した所持品を `plugins/<プラグイン>/vault/<UUID>.yml` に保存し、**サーバークラッシュ後の再ログインでも復元** します（退避・復元は各1回、試合終了時は復元しません）。

### 追加された config キー

| キー | 説明 |
|---|---|
| `display-name` | ゲーム表示名（「【…】」の中身） |
| `messages.join-broadcast` | 参加の全体告知文 |
| `messages.leave-broadcast` | 離脱の全体告知文 |
| `messages.already-in-other-game` | 他ゲーム参加中に拒否したときの文言 |
| `messages.vault-save-failed` | 持ち物のファイル退避に失敗して参加を中止したときの文言 |

!!! note "config は自動で追記されるようになりました"
    起動時（`reload` 対応プラグインは reload 時も）に、`config.yml` へ不足している項目を既定値＋コメント付きで自動追記します（既存の値は変更しません／更新時は `config.yml.bak` を保存）。**このため、当ページ内の「既存サーバーは config が自動追記されません」という旧記載は本改修で解消されています。** 座標・看板・会場・ステージなどのデータ領域は補完対象外です。
