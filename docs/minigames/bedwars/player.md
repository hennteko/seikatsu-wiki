# BedWarsPlugin ― 遊び方 { .page-player #bedwars-player }

Minecraftで **ベッドウォーズ** を再現したチーム対戦です。色ごとのチームに分かれ、自分の **ベッド** を守りながら、湧いてくる資源で装備とチームを強化し、敵チームのベッドを壊して全滅させれば勝利です。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | チーム | 2〜8チーム（有効な色ぶん・参加時に自動振り分け） |
    | 勝利条件 | 敵チームのベッドを壊し、全チームを全滅させる |
    | 復活 | 自分のベッドがある間は復活可（既定5秒後）／ベッド破壊後は次にやられると脱落 |
    | 資源 | 鉄・金（拠点）／ダイヤ・エメラルド（中央） |
    | 通貨 | 鉄・金・ダイヤ・エメラルド（ショップで使用） |

## どんなゲーム？

各チームには **拠点・スポーン地点・ベッド** があります。拠点の **ジェネレーター** から鉄と金が、フィールド中央の **ダイヤ／エメラルドジェネレーター** から上位資源が自動で湧き続けます。これらを集めて **ショップ** で装備やブロック、チーム強化を買いそろえ、敵チームを攻めます。

勝敗の鍵は **ベッド** です。自分のチームのベッドが残っている間は、やられても何度でも復活できます。しかし敵にベッドを壊されると、次にやられたときに **復活できず脱落（ファイナルキル）** します。全メンバーが脱落したチームから敗退し、**最後に生き残ったチームの勝ち** です。

## ゲームの流れ

1. **参加する** — ロビーの参加看板を右クリック（または `/bedwars join`）。退出は離脱看板／`/bedwars leave`。
2. **開始** — 運営またはプレイヤーが開始看板（または `/bedwars start`）で試合開始。チームへ自動で振り分けられ、各スポーンへ飛ばされます。
3. **資源を集める** — 拠点のジェネレーターから鉄・金、中央からダイヤ・エメラルドが湧きます。拾って集めます。
4. **装備を整える** — 自陣の **アイテムショップ**（村人）で剣・防具・ブロック・弓・消耗品などを購入。**アップグレードショップ** ではダイヤでチーム全体を強化します。
5. **ベッドを守り、攻める** — 自陣ベッドの周りをブロックで固めて防衛しつつ、敵陣へ橋を架けて攻め込み、敵のベッドを破壊します。
6. **決着** — 全チームが全滅するか、時間経過イベントで決着。最後に残ったチームが勝ちです。

!!! warning "自分のベッドは絶対に壊されないように！"
    ベッドを壊されると **復活できなくなり**、次にやられたら脱落です。ブロック（羊毛・テラコッタ・エンドストーン・黒曜石など）でベッドの周囲を固めて守りましょう。

## チームと復活

- 参加者はシャッフルされ、有効な各チーム（赤・青・緑・黄・水色・白・桃・灰のうち運営が設定した色）へ **均等に自動振り分け** されます。
- 同じチームの味方には **攻撃が当たりません**（同士討ち無効）。
- やられると一時的に観戦状態になり、**ベッドが残っていれば既定5秒後に自チームスポーンへ復活** します。復活時は木の剣・防具など基本装備が再支給されます。
- **ベッドが破壊された後にやられると脱落（ファイナルキル）** で、以降は復活できません。
- 落下ダメージや空腹はありません。**奈落（フィールド下）に落ちると死亡** 扱いになります。

!!! note "死亡時のペナルティ"
    やられると **所持している資源（鉄・金・ダイヤ・エメラルド）はその場に落ちます**。また購入した **ツルハシ・斧は1段階ダウン** します（防具・ハサミ・チーム強化は維持）。装備（剣・防具）は復活時に再構成されます。

## 資源とジェネレーター

| 資源 | 湧く場所 | 用途 |
|---|---|---|
| 🪙 鉄 | 自陣拠点のジェネレーター | ブロック・剣・ツール・防具など基本の通貨 |
| 🥇 金 | 自陣拠点のジェネレーター | 中位の装備・消耗品 |
| 💎 ダイヤ | フィールド中央のダイヤジェネレーター | 高級装備・**チームアップグレード** の通貨 |
| 💚 エメラルド | フィールド中央のエメラルドジェネレーター | 最高級装備・消耗品 |

中央のダイヤ／エメラルドは時間経過で **Tierが上がり、湧きが速く** なります（既定: ダイヤTierII=6分・III=18分、エメラルドTierII=12分・III=24分）。ジェネレーター付近に資源が溜まりすぎると一時的に湧きが止まります（拾って場所を空けましょう）。

### アップグレードショップ（紫のNPC）― ダイヤで購入・チーム全員に適用

**ダイヤ** を使い、チーム全体に永続効果を付与します。

| 強化 | 効果 | 価格（ダイヤ） |
|---|---|---|
| 鋭い刃 | チーム全員の剣に鋭さI | 8 |
| 防具強化 I〜IV | 防具にプロテクション（最大IV） | 5 / 10 / 20 / 30 |
| 迅速な採掘 I〜II | チーム全員にヘイスト | 4 / 6 |
| 鍛冶場強化 I〜IV | 拠点の湧き速度アップ（Lv4でエメラルドも湧く） | 4 / 8 / 12 / 16 |
| 回復プール | 自陣スポーン周辺で再生効果 | 3 |
| トラップ（4種） | 敵がベッド付近に侵入すると自動発動（最大3個をキュー） | 1 / 2 / 4（購入数で変動） |

!!! note "トラップは4種・先入れ先出し"
    トラップは **盲目トラップ**（侵入者に盲目＋鈍足）／**反撃トラップ**（自陣の味方にスピード＋跳躍）／**警報トラップ**（侵入者を通知＋透明化解除）／**採掘疲労トラップ** の4種。購入した順に3個までキューされ、敵がベッド付近（半径約10ブロック）へ侵入すると **先頭から1つ発動**します。発動後は約2秒のクールダウンがあります。

## 特殊アイテムの使い方

- **ファイヤーボール** … 右クリックで発射。爆発でプレイヤーを吹き飛ばし、**設置ブロックを破壊** します（ベッド・マップ地形は壊れません）。
- **橋の卵** … 右クリックで投げると、卵の軌跡の下に **自チーム色の羊毛の橋** が架かります（空中を渡るのに便利）。
- **TNT** … 設置すると即着火します。設置ブロックの破壊に使えます。

## ルール（建築・破壊）

- 設置できるのは **フィールド範囲内** のみ。ロビー待機中は設置できません。
- **自分（や誰か）が設置したブロックだけ破壊可能**。マップの元々の地形は壊せません。
- **敵チームのベッドだけ破壊可能**。自分のベッドや不参加チームのベッドは壊せません。ベッドは爆発では壊れません（プレイヤーの手作業のみ）。
- 味方への攻撃は無効（同士討ち禁止）。

## 時間経過イベント

試合が長引くと、次の順でイベントが進行します（既定値）。

1. **6分** … ダイヤジェネレーター Tier II
2. **12分** … エメラルドジェネレーター Tier II
3. **18分** … ダイヤジェネレーター Tier III
4. **24分** … エメラルドジェネレーター Tier III
5. **30分** … **全チームのベッドが自動崩壊**（以降リスポーンなし）
6. **36分** … **サドンデス**（フィールド中央にエンダードラゴンが出現）
7. **40分（試合時間）** … 時間切れ（決着していなければ引き分け）

## ソロ防衛（1人で遊ぶ）

1人で **自分のベッドを Mob の波から守る** モードです。ベッドには **耐久（既定100）** があり、0になるまでの時間が記録になります。難易度ごとに自己ベストとランキングが残ります。

### 始め方

1. ソロ看板を右クリック、または `/bedwars solo` → ロビーに入り、**ソロメニュー** が開きます。
2. メニューで難易度（かんたん／ふつう／むずかしい）を押すと、3秒後に始まります。
3. 終わるとロビーに戻り、数秒後にまたソロメニューが開きます。続けて挑戦できます。

```text title="ソロメニューを開く"
/bedwars solo
```
```text title="メニューを通さずすぐ始める（難易度は省略するとふつう）"
/bedwars solo defense hard
```
```text title="ランキングを見る（難易度は省略するとふつう）"
/bedwars ranking solo hard
```

- メニューを閉じてもロビーにいるままです。ホットバーの **ネザースター（ソロメニュー）** を右クリックすると開き直せます。統合版は **ネザースターを持ってスニーク** でも開きます。
- メニューの「ロビー退出」か `/bedwars leave` で抜けると、持ち物が元に戻ります。
- アリーナは通常戦と共用です。誰かがソロ中・通常戦の試合中は始められません（メニューに「使用中」と出て、空くと表示が変わります）。
- ソロで入った人は通常の試合（`/bedwars start`）には参加しません。通常戦に出たいときは `/bedwars join` で切り替えます。

### ルール

- 開始時の装備・ショップ・拠点のジェネレーター・チーム強化は通常戦と同じです。資源を集めて、ブロックでベッドを守りましょう。
- 最初の **20秒** は準備時間です。その後 **約40秒ごと** に敵の波が来ます。前の波が残っていても次の波は来ます。**全滅させると次の波が早まり、ダイヤ2個のボーナス** がもらえます。
- やられても、ベッドが残っていれば通常どおり復活できます。
- **ベッドの耐久が0になった瞬間に終了**。上限時間（既定60分）まで守りきると「完走」です。
- 途中で `leave`・切断した場合は **中断** で、記録は残りません。
- **水バケツは使い捨て** です。置くとバケツが無くなり、すくい直せません。置いた水は **5秒で消えます**。掘り屋・破城兵は近くの水を埋めてきます。落下の受け身や、一時的に敵を押し返すのに使いましょう。

### 敵の種類

| 敵 | 出始める波 | 特徴 | 倒すと |
|---|---|---|---|
| 突撃兵（ゾンビ） | 1 | ベッドへ向かい、隣に着くとベッドを殴る。近くのプレイヤーも狙う | 鉄6 |
| 射手（スケルトン） | 3 | 遠くからプレイヤーを撃つ | 鉄6 |
| 掘り屋（ツルハシのゾンビ） | 4 | 道をふさぐ **設置ブロックを壊す**（黒曜石は壊せない） | 鉄4・金3 |
| 隊長（ラヴェジャー） | 5, 10, 15… | 体力が多い。設置ブロック（黒曜石以外）を踏み壊して進む | ダイヤ4・エメラルド2 |
| 爆弾兵（クリーパー） | 6 | ベッドの近くで爆発。ベッドの耐久と設置ブロックをまとめて削る | 金3 |
| 破城兵（ウィザースケルトン） | 8 | **黒曜石も含めて** 設置ブロックを壊す（同時に2体まで）。ウィザー効果は付かない | 金6・ダイヤ1 |

- 倒した敵の報酬は、その場に落ちます。波が進むほど敵の体力と攻撃力が少しずつ上がります。
- 敵が壊すのはプレイヤーが置いたブロックだけです。マップの地形は壊しません。
- 敵はソロに挑戦している本人とベッドだけを狙います。ほかのプレイヤーには何もしません。
- チームアップグレードのトラップは、拠点（ベッドから約12ブロック）に敵が入ると発動します（盲目トラップ＝敵に鈍足、反撃トラップ＝自分にスピード・跳躍、警報トラップ＝知らせのみ、採掘疲労トラップ＝掘る速さが半分）。

### 表示と記録

- ベッドの耐久は画面上の **ボスバー**（緑→黄→赤）、経過時間・ウェーブ・残りの敵・撃破数・自己ベストは右の **サイドバー** に出ます。
- ベッドが攻撃されるとアクションバーと音で知らせます。耐久が25%を切ると警告が出ます。
- 記録は **プレイヤー × 難易度ごとの最長時間** です。同じ時間なら到達ウェーブが多いほう、それも同じなら先に出したほうが上です。
- 結果はサーバー全体に1行で流れます（自己ベスト・1位のときはそう添えます）。

!!! note "統合版での見え方"
    ソロメニュー（チェスト画面）・ボスバー・サイドバー・敵の頭上の名前（❤の数）は統合版でも表示されます。掘り屋・破城兵がブロックを壊すときの **ひびの表示** は、統合版では出ない場合があります（壊す動作は同じです）。

## 参加方法

参加・退出・開始は **看板** でも **コマンド** でも行えます。

- 参加看板を右クリック／`/bedwars join` → ロビー参加。参加・離脱・開始の看板は複数の場所に設置できるので、どの看板からでも操作できます。
- 離脱看板を右クリック／`/bedwars leave` → 退出。
- 開始看板を右クリック／`/bedwars start` → 試合開始（全員可）。
- `/bedwars status` → 設定・進行状況を確認。
- ソロ看板を右クリック／`/bedwars solo` → ソロ防衛のメニュー（上の「ソロ防衛」）。

!!! note "join / leave / start / status は全員が使えます"
    これらのコマンドは権限不要で全プレイヤーが使えます（看板と同等）。自動開始はなく、開始看板か `start` で始まります。

## よくある質問

??? question "ベッドを壊されるとどうなりますか？"
    復活できなくなります。ベッドが残っている間は何度やられても復活しますが、破壊された後にやられると **脱落（ファイナルキル）** です。チーム全員が脱落すると敗退します。

??? question "資源はどこで湧きますか？"
    鉄と金は **自陣の拠点ジェネレーター**、ダイヤとエメラルドは **フィールド中央のジェネレーター** から自動で湧きます。拾って集めてショップで使います。

??? question "死んだら持ち物はどうなりますか？"
    所持している資源（鉄・金・ダイヤ・エメラルド）はその場に落ちます。ツルハシ・斧は1段階ダウンします。防具・ハサミ・チーム強化は維持され、剣などは復活時に再支給されます。

??? question "チームアップグレードは自分だけの効果ですか？"
    いいえ、**チーム全員に適用** されます。ダイヤで購入し、鋭い刃・防具強化・迅速な採掘・鍛冶場強化・回復プール・トラップから選べます。

??? question "ソロ防衛で黒曜石で囲んだら安全ですか？"
    8波目から出る **破城兵** は黒曜石も壊します。囲むだけでなく、敵を倒して数を減らすことも大切です。

??? question "ソロ防衛の記録を消したい"
    記録の削除は OP にお願いしてください（`/bedwars ranking reset`）。

??? question "味方を攻撃できますか？"
    できません。同じチームのメンバーには攻撃が当たりません（同士討ち無効）。
