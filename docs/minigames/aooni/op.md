# Aooni（青鬼）― OP・運営ガイド { .page-op #aooni-op }

Aooni（青鬼）の導入・会場の設定・config・権限・管理コマンドをまとめます。

## 基本情報

| 項目 | 値 |
|---|---|
| プラグイン名 | Aooni |
| バージョン | 1.0.0 |
| api-version | 26.1.2 |
| 作者 | henry |
| メインコマンド | `/aooni` |
| 依存プラグイン | なし |
| 設定ファイル | `plugins/Aooni/config.yml`（ゲーム設定・メッセージ・看板テキスト） |
| 地点ファイル | `plugins/Aooni/locations.yml`（スポーン・看板・チェスト・隠れ場所。コマンドで自動保存） |

!!! info "ゲームの仕組み（脱出型 × 鍵集め式 × 残機・復帰アスレ）"
    各逃走者は鍵チェストを開けて自分の鍵を集め（既定3本）、脱出ドアに到達すれば個人で脱出成功（観戦になり試合は続行）。青鬼は逃走者を殴って捕まえると残機を1削り、残機0になると鍵を没収して復帰アスレへ送ります（アスレ未設定なら青鬼化）。逃走中の逃走者が全滅した時点で、脱出者がいれば逃走者陣営の勝利、いなければ青鬼の勝利。制限時間（既定6分）に達したときは脱出者がいれば逃走者勝利、いなければ引き分けです。

## 導入手順

1. ビルドした `Aooni` の jar ファイルをサーバーの `plugins/` フォルダに配置する。
2. サーバーを起動・再起動すると `plugins/Aooni/config.yml` が自動生成される（地点を登録すると `locations.yml` も生成されます）。
3. 後述の手順で会場（スポーン・脱出ドア・鍵チェスト・隠れ場所・看板）を設定する。
4. 必要に応じて `config.yml` を編集し、`/aooni reload` で反映する。

!!! note "config の反映について"
    `config.yml`（ゲーム設定・メッセージ）は `/aooni reload` で再読み込みできます。地点系（スポーン・看板・チェスト・隠れ場所）は各セットアップコマンドの実行時に `locations.yml` へ即座に保存され、すぐ反映されます。`/aooni setmax` / `setmin` / `settime` / `setkeys` による数値変更は `config.yml` へ即座に保存されます。

## config.yml 設定項目

### game セクション

| キー | 既定値 | 説明 |
|---|---|---|
| `game.match-duration` | 360 | 試合時間（秒）。到達すると引き分け（既定6分） |
| `game.min-players` | 3 | ゲーム開始に必要な最小プレイヤー数 |
| `game.max-players` | 16 | ロビーの最大人数 |
| `game.countdown-time` | 15 | 開始前のカウントダウン時間（秒） |
| `game.runner-lives` | 3 | 逃走者の残機。捕まると1減り、鍵は維持して逃走者スポーンへ戻る。0で鍵を没収して復帰アスレ送り（アスレ未設定なら青鬼化） |
| `game.respawn-invincible` | 3 | 捕まって戻った直後・アスレ復帰直後の無敵時間（秒。発光で表示） |
| `game.initial-oni` | 1 | 開幕時の青鬼の人数（立候補者を優先し、不足分はランダム指名で補完） |
| `game.keys-required` | 3 | 脱出に必要な鍵の本数（逃走者個人ごと。各逃走者が自分で集める） |
| `game.escape-radius` | 2.0 | 脱出ドア判定の半径（ブロック） |
| `game.chest-reveal` | false | `true` にすると、チェストから鍵を取り出した逃走者を一時発光させ青鬼へ通知する（既定は発光・通知しない） |
| `game.result-seconds` | 10 | 結果発表の表示秒数（この秒数だけ結果を見せてからロビーへ復帰） |
| `game.key-spawn.initial-fill` | true | 試合開始と同時に鍵を一斉配置する（`false` だと最初の補充は `interval` 秒後） |
| `game.key-spawn.interval` | 10 | 鍵の補充判定を行う間隔（秒） |
| `game.key-spawn.chance` | 1.0 | 補充判定1回あたりの実行確率（0.0〜1.0）。1.0で毎回 |
| `game.key-spawn.stock-multiplier` | 2.0 | 必要本数の合計に対して何倍の鍵をチェストに置いておくか（1.0以上） |
| `game.key-spawn.max-per-chest` | 2 | 1チェストに入れる鍵の最大本数 |
| `game.locker-hide-time` | 8 | 隠れ場所で透明になる秒数 |
| `game.locker-cooldown` | 15 | 隠れ場所の再使用クールダウン（秒。透明化時間に加算される） |

!!! info "鍵の出現は「時間補充」方式です"
    鍵は試合開始時に一斉配置され（`key-spawn.initial-fill: true`）、以降も **`key-spawn.interval` 秒（既定10秒）ごとの補充判定**で `key-spawn.chance`（既定1.0＝毎回）の確率で実行されます。チェストに同時に存在する鍵の総数は **「逃走中の各逃走者が あと何本必要か の合計 × `stock-multiplier`（既定2.0）」（切り上げ）** に保たれ、**1チェストにつき `max-per-chest` 本（既定2本）まで**、回収されて空になったチェストには再補充されます（目標数に達していれば何も追加しません）。補充時は全員に「どこかのチェストに鍵が出現した…！」と通知されます。逃走者はチェストを開けて鍵を回収します（チェストは通常どおり開きます）。鍵の供給ペースは `match-duration` と `key-spawn.*` のバランスで決まるため、**逃走者が必要本数を集められるか**を試遊で確認して調整してください。

!!! note "残機と復帰アスレ"
    逃走者は `game.runner-lives`（既定3）の残機を持ちます。青鬼に捕まると残機が1減り、**鍵を持ったまま**逃走者スポーンへ戻されます（`respawn-invincible` 秒の無敵・発光つき）。残機0になると鍵を没収して **復帰アスレ**（後述の `/aooni setparkour` で設定する難易度別3コース）へ送られ、クリアするとコースごとの残機で逃走者に復活します（鍵は0本から）。**復帰アスレを1つも設置していない場合は、残機0で捕まるとそのまま青鬼になります（旧ルール）。**

### parkour セクション（復帰アスレ）

残機0の逃走者が送られる復帰アスレの設定です。スタート地点・ゴールは `/aooni setparkour <easy|normal|hard> <start|goal>`（または `/aooni tool` のGUI）で登録し、`locations.yml` に保存されます。未設置のコースは選択肢に出ません。設置済みが1つだけならGUIを出さずにそのコースへ直行します。

| キー | 既定値 | 説明 |
|---|---|---|
| `parkour.courses.easy.name` / `normal.name` / `hard.name` | `&a初級` / `&e中級` / `&c上級` | コースの表示名（`&` カラーコード可） |
| `parkour.courses.easy.lives` / `normal.lives` / `hard.lives` | 1 / 2 / 3 | そのコースをクリアしたときに復活する残機 |
| `parkour.select-timeout` | 20 | コース選択GUIの制限時間（秒）。過ぎたら一番易しいコースに自動決定（統合版でGUIが出ない場合の保険） |
| `parkour.goal-radius` | 1.5 | ゴール判定の半径（ブロック） |
| `parkour.fall-distance` | 8 | スタート地点よりこのブロック数以上下に落ちたらスタートへ戻す |

### loadout セクション

役職ごとの配布装備をコード直書きせず config で定義します。リスポーン・役職変更時もこの設定から再構築して付与されます。

| キー | 既定値 | 説明 |
|---|---|---|
| `loadout.oni.helmet` / `chestplate` / `leggings` / `boots` | DIAMOND_* | 青鬼の防具マテリアル名（`NONE` または空文字で装備なし） |
| `loadout.oni.speed` | 0.22 | 青鬼の移動速度（標準の歩行速度は0.2。大きいほど速い） |
| `loadout.oni.night-vision` | true | 青鬼に暗視を付与するか |
| `loadout.runner.helmet` / `chestplate` / `leggings` / `boots` | NONE | 逃走者の防具マテリアル名（既定は装備なし） |
| `loadout.runner.speed` | 0.2 | 逃走者の移動速度 |
| `loadout.runner.night-vision` | false | 逃走者に暗視を付与するか |

!!! note "移動速度・暗視は loadout セクションで設定します"
    旧バージョンの `game.oni-speed` は廃止され、移動速度は `loadout.oni.speed` / `loadout.runner.speed`、暗視は `loadout.*.night-vision` で個別に設定する方式になりました。防具マテリアルが不正な場合は「装備なし」にフォールバックします。

### messages / sign セクション

`messages` には各種通知文（`&` カラーコード対応）、`sign` には参加 / 離脱 / 開始 / 立候補看板に書き込まれるテキストが定義されています。プレフィックスは `messages.prefix`（既定 `&b[青鬼] `）です。看板テキストの `%current%` / `%max%` はロビー人数・最大人数に、立候補看板の `%count%` は立候補者数に置換されます。残機・復帰アスレ・個人脱出の導入にともない、`caught`（捕獲＝残機減）・`sent-parkour`（アスレ送り）・`parkour-choose` / `parkour-chosen` / `parkour-clear`（コース選択・クリア）・`escaped` / `escaped-list`（個人脱出）・`escape-need-keys`（鍵不足）・`key-no-share` / `key-enough`（受け渡し不可・必要本数達成）などの通知文も追加されています（`%player%` / `%lives%` / `%course%` / `%have%` / `%required%` 等を置換）。

## セットアップ手順

専用ワールドを用意し、OP権限（`aooni.admin`）で以下のコマンドを **設定したい地点に立って**（または対象ブロックを見ながら）実行します。地点は実行位置・視線先のブロックとして `locations.yml` に保存されます。

```text title="① 初期スポーン（途中抜け・終了時の戻り先）を現在地に設定"
/aooni setstartspawn
```

```text title="② ロビー地点を現在地に設定"
/aooni setlobby
```

```text title="③ 青鬼スポーンを現在地に設定"
/aooni setspawn oni
```

```text title="④ 逃走者スポーンを現在地に設定"
/aooni setspawn runner
```

```text title="⑤ 脱出ドアを設定（脱出ドアにするブロックを見ながら／6ブロック以内）"
/aooni setgoal
```

```text title="⑥ 鍵チェストを登録（チェストを見ながら／6ブロック以内・複数可）"
/aooni addchest
```

```text title="⑦ 隠れ場所を登録（ブロックを見ながら／6ブロック以内・複数可）"
/aooni addlocker
```

復帰アスレ（残機0の逃走者の送り先）を設定する場合は、各コースについて **スタート地点（現在地）** と **ゴール（視線先のブロック）** を登録します。コースは `easy` / `normal` / `hard` の3種です（任意・設置したコースだけが選択肢に出ます）。

```text title="⑧ 復帰アスレ・初級のスタート地点を現在地に設定"
/aooni setparkour easy start
```

```text title="⑨ 復帰アスレ・初級のゴールを視線先のブロックに設定"
/aooni setparkour easy goal
```

同様に `/aooni setparkour normal start|goal`、`/aooni setparkour hard start|goal` で中級・上級も登録できます。

登録の解除も視線先のブロックを見ながら実行できます。

```text title="鍵チェストの登録を解除（視線先のチェスト）"
/aooni removechest
```

```text title="隠れ場所の登録を解除（視線先のブロック）"
/aooni removelocker
```

数値・地点の設定は、OP用設定アイテムのGUIからも行えます（即自動保存）。

```text title="OP用設定アイテムを受け取る（GUIで数値・地点を設定）"
/aooni tool
```

設定の流れは次のとおりです。

1. `/aooni setstartspawn` で初期スポーン（途中抜け・終了時の戻り先）を設定する。
2. ロビーにする場所に立ち `/aooni setlobby` を実行する。
3. 青鬼スポーン・逃走者スポーンをそれぞれの場所で `/aooni setspawn oni` / `/aooni setspawn runner` で設定する。
4. 脱出ドアにするブロックを見ながら `/aooni setgoal` を実行する。
5. 鍵チェスト（チェスト／トラップチェスト）を見ながら `/aooni addchest` を実行する。別のチェストで繰り返すと複数登録できます（解除は `/aooni removechest`）。
6. （任意）隠れ場所にするブロックを見ながら `/aooni addlocker` を実行する。こちらも複数登録できます（解除は `/aooni removelocker`）。
7. （任意・推奨）復帰アスレを各コースで `/aooni setparkour <easy|normal|hard> <start|goal>` で設定する。設置しない場合、残機0の逃走者はその場で青鬼になります（旧ルール）。
8. `/aooni status` で各設定状況を確認する。

!!! warning "ゲーム開始に必須の設定"
    `/aooni start`（開始看板を含む）は、**初期スポーン・ロビー・青鬼スポーン・逃走者スポーン・脱出ドア・鍵チェスト1個以上** がそろっていないと開始できません（「設定が未完了です」と表示）。復帰アスレ・隠れ場所・看板は開始の必須条件ではありません（復帰アスレ未設定なら残機0で青鬼化、参加・離脱・開始はコマンドでも可能なため）。ただし、わかりやすさのため実運用では参加看板の設置を、駆け引きのため復帰アスレの設置を推奨します。

!!! tip "鍵チェストは複数を散らして設置するのがおすすめ"
    鍵は補充判定で **空いている登録チェストのどれか** に補充され、チェスト内の鍵の総数は「逃走中の各逃走者が あと何本必要か の合計 × `stock-multiplier`（既定2.0）」に保たれます（1チェストにつき `max-per-chest` 本まで）。チェストが多くマップ全体に散らばっているほど、鍵を探して動き回る駆け引きが生まれます。逆に少ないと鍵の出現場所が読まれて青鬼に張られやすくなります。目標本数を収容できる数のチェストが必要なため、広いマップに数か所〜十数か所を目安に設置してください。

!!! note "試合の鍵は自動でクリアされます"
    試合中に出現して回収されなかった鍵は、**試合開始時・終了時・強制終了時に自動でクリア**されます（プラグインが付与した「脱出の鍵」のみが対象）。前の試合の鍵が次の試合に持ち越されることはありません。ただし運用上、登録チェストには **他のアイテムを置かない** ことを推奨します。

## 看板の設置

参加・離脱・開始は **看板** か **コマンド**（`/aooni join` / `leave` / `start`）のどちらでも行えます。看板はクリック1つで操作でき、初心者にもわかりやすいため設置を推奨します。看板を設置し、看板を見ながら（5ブロック以内）以下のコマンドを実行してください。テキストはプラグインが自動で書き込みます。

```text title="参加看板を登録（クリックで参加・ロビーへTP・人数表示）"
/aooni setsign join
```

```text title="離脱看板を登録（クリックでロビーから離脱）"
/aooni setsign leave
```

```text title="開始看板を登録（クリックでゲーム開始）"
/aooni setsign start
```

```text title="青鬼立候補看板を登録（クリックで立候補のオン／オフ）"
/aooni setsign oni
```

看板の解除は、解除したい看板を見ながら（5ブロック以内）次のコマンドを実行します。種別は自動判別されます。

```text title="視線先の看板の登録を解除（種別は自動判別）"
/aooni setsign delete
```

!!! tip "青鬼立候補看板について"
    `setsign oni` で立候補看板を設置すると、ロビー在籍中のプレイヤーがクリックして **青鬼への立候補** をオン／オフできます。ゲーム開始時の青鬼（既定1人）は **立候補者を優先**して抽選され、不足分はランダム指名で補完されます。立候補看板の4行目には現在の立候補者数（`%count%`）が表示されます。

!!! note "参加は看板でもコマンドでも可能"
    プレイヤーは **参加看板のクリック** または `/aooni join`（離脱は `/aooni leave`、開始は `/aooni start`）で操作できます。看板操作はイベント経由、コマンドは `aooni.play`（`/aooni` 全体の権限。既定で全員）で利用できます。`/aooni start` も `aooni.play` を持つプレイヤーなら誰でも実行できます。看板は無くても動作しますが、わかりやすさのため参加看板の設置を推奨します。

## ゲームの運営

```text title="ゲームを開始（ロビーに最小人数以上が必要）"
/aooni start
```

```text title="ゲームを強制終了する"
/aooni stop
```

```text title="設定状況（地点・看板・オブジェクト・現在の状態）を確認"
/aooni status
```

```text title="config.yml を再読み込み"
/aooni reload
```

1. プレイヤーが参加看板でロビーに集まるのを待つ（既定で最小3人）。
2. `/aooni start` または開始看板でゲームを開始する。
3. ゲームは「カウントダウン（既定15秒）→ 役割抽選 → 鍵集め＆逃走（捕獲で残機減・残機0で復帰アスレ・個人脱出で観戦化）→ 逃走中の逃走者が全滅して決着」と進行します。
4. 終了から既定10秒後（`result-seconds`）に参加者は自動でロビーへ戻され、参加状態が維持されます。

## コマンド一覧

`join` / `leave` / `start` / `stats` / `status` は **全プレイヤー** が利用でき、それ以外のセットアップ・管理コマンドは `aooni.admin`（既定OP）が必要です。`join` / `leave` にプレイヤー名を付けて他プレイヤーを操作する場合は `aooni.admin` が必要です。

| コマンド | 必要権限 | 説明 |
|---|---|---|
| `/aooni`（引数なし） | 全員 | ヘルプを表示する |
| `/aooni join [名前]` | 全員（名前指定は admin） | ロビーに参加する（参加看板と同じ）。名前指定で他プレイヤーを参加させる |
| `/aooni leave [名前]` | 全員（名前指定は admin） | ロビーから離脱する（離脱看板と同じ）。名前指定で他プレイヤーを離脱させる |
| `/aooni start` | 全員 | ゲームを開始する（開始看板と同じ） |
| `/aooni stats [名前]` | 全員 | 成績を表示する（名前省略で自分） |
| `/aooni status` | 全員 | 設定状況を確認する |
| `/aooni setstartspawn` | aooni.admin | 初期スポーン（戻り先）を現在地に設定する |
| `/aooni setlobby` | aooni.admin | ロビー地点を現在地に設定する |
| `/aooni setspawn <oni\|runner>` | aooni.admin | 青鬼／逃走者スポーンを現在地に設定する |
| `/aooni setgoal` | aooni.admin | 視線先のブロックを脱出ドアに設定する |
| `/aooni setparkour <easy\|normal\|hard> <start\|goal>` | aooni.admin | 復帰アスレのコース別スタート（現在地）／ゴール（視線先）を設定する |

## 権限ノード

`plugin.yml` には `aooni.admin` と `aooni.play` の2つが定義されています。

| 権限 | 既定 | 用途 |
|---|---|---|
| `aooni.admin` | OP | セットアップ・看板登録系・数値設定・他プレイヤーの参加/離脱操作・`stop` / `reload` |
| `aooni.play` | すべてのプレイヤー | ロビーへの参加権限（`join` 実行・参加看板のクリックで判定） |

!!! note "プレイヤー操作について"
    `aooni.play` は既定で **全員に付与** されており、ロビー参加の可否を判定します。プレイヤーは看板の右クリック、または `/aooni join` / `leave` / `start` で操作でき、`stats` / `status` も誰でも実行できます。`/aooni start` は権限チェックを行わないため誰でもゲームを開始できます。参加自体を制限したい場合は権限プラグイン（LuckPerms 等）で `aooni.play` を調整してください（外すと参加できなくなります）。`join` / `leave` に **プレイヤー名を付けて他プレイヤーを操作** する場合のみ `aooni.admin` が必要です。

## 実装状況

!!! info "実装済みの機能"
    - ロビー（看板またはコマンドでの参加・離脱・人数表示・最大人数制限）
    - 開始カウントダウン（既定15秒）と役割の自動抽選（開幕青鬼数は `initial-oni`。立候補看板対応）
    - 青鬼キット（ダイヤ装備・暗視・移動速度UP）／逃走者キット（`loadout` で定義）
    - 鍵の時間補充（`key-spawn.*`、総数は「逃走中の各逃走者が あと何本必要か の合計 × `stock-multiplier`」を維持・開幕一斉配置）と全体通知
    - 鍵の回収（個人制・受け渡し不可・必要本数超過は不可。`chest-reveal: true` の場合のみ取り出し時に発光＋青鬼へ通知。既定は発光しない）
    - 隠れ場所（右クリックで一時透明化・クールダウン）
    - 個人脱出判定（必要本数の鍵を所持して脱出ドアへ接近 → 観戦化・試合は続行）
    - 残機制（捕獲で残機-1・鍵維持・無敵つきで逃走者スポーンへ）と復帰アスレ（残機0で鍵没収・難易度別3コースをGUIで選択・クリアで復活）
    - フォールバック感染（復帰アスレ未設定時のみ、残機0で青鬼化）
    - 残り時間・人数・脱出者数・逃走者の鍵所持数のアクションバー表示、残り時間のチャット通知
    - 勝敗判定（逃走中の逃走者が全滅 → 脱出者ありで逃走者勝利／なしで青鬼勝利、時間切れは脱出者ありで逃走者勝利・なしで引き分け）
    - 食事・落下などのダメージ無効（死亡防止）
    - 終了後の自動ロビー帰還（参加状態を維持）・ログアウト時の戻り処理

!!! warning "注意点・制限"
    - 参加・離脱・開始は **看板** か **コマンド**（`/aooni join` / `leave` / `start`・全プレイヤー可）のどちらでも行えます。`/aooni start` も `aooni.play` で実行できるため、必要なら権限で制限してください。
    - 鍵は時間補充でチェストに出現する方式です。回収されなかった鍵は試合の開始・終了時に自動でクリアされます（プラグインの鍵のみ対象）。登録チェストには他のアイテムを置かないでください。
    - 鍵チェストは青鬼も開けられます（GUIは全員に開きます）。青鬼が鍵を抜き取る妨害が可能な点に留意してください。
    - 復帰アスレを1つも設置していない場合、残機0の逃走者はその場で青鬼になります（旧ルールへのフォールバック）。
    - 会場は1つのみです。複数会場の同時運用には対応していません。
    - `config.yml` の地点系は持たず、地点（スポーン・看板・チェスト・隠れ場所・復帰アスレ）は `locations.yml` で管理されます（地点系コマンドで自動保存）。

## トラブルシューティング

??? failure "「設定が未完了です」と表示されて開始できない"
    初期スポーン・ロビー・青鬼スポーン・逃走者スポーン・脱出ドア・鍵チェスト（1個以上）のいずれかが未設定です。`/aooni status` で「未設定」の項目を確認し、対応するコマンドで設定してください。

??? failure "「プレイヤーが足りません」と表示される"
    ロビーの人数が `game.min-players`（既定3人）に達していません。`/aooni status` でロビー人数を確認してください。

??? failure "参加看板をクリックしても参加できない"
    `/aooni setsign join` で参加看板が登録済みか確認してください（位置で判定するため、看板の手書きでは機能しません）。ゲーム進行中は参加できません。

??? failure "チェストを開けても鍵が入っていない"
    鍵は試合開始時に一斉配置され（`key-spawn.initial-fill`）、以降は `key-spawn.interval` 秒ごとの補充判定で出現します。「どこかのチェストに鍵が出現した…！」の通知が出てから、登録チェストを探してください。なかなか出ない場合は `game.key-spawn.chance` を上げる、`game.key-spawn.interval` を短くする、`game.key-spawn.stock-multiplier` を上げる、登録チェスト数を増やすなどで供給ペースを調整できます（`/aooni reload` で反映）。チェスト内の鍵総数は「逃走中の各逃走者が あと何本必要か の合計 × `stock-multiplier`」が上限のため、チェスト数（収容本数）が少ないと補充しきれないこともあります。

??? failure "逃走者がすぐ脱出できてしまう／誰も脱出できない"
    鍵の供給ペースは `game.keys-required`（必要本数）と `game.key-spawn.*`、`game.match-duration`、`game.runner-lives`（残機）・復帰アスレの難易度、登録チェスト数のバランスで決まります。誰も脱出できない場合は供給を増やし（間隔短縮・確率アップ・在庫倍率アップ・チェスト増設）、簡単すぎる場合は逆に絞ってください。残機や復帰アスレの難易度でも難度を調整できます。`config.yml` を編集したら `/aooni reload` で反映します。

??? failure "config.yml を編集したのに反映されない"
    ゲーム設定・メッセージは `/aooni reload` で反映されます。反映後は新しい試合から有効です（進行中の試合には適用されません）。

## 全ゲーム共通の改修（2026-09）

全ミニゲーム共通の改修が入り、本ゲームにも適用されています。

- **名前表示** … 参加中はチャット名・Tabリスト名・頭上の名札が「【ゲーム名】名前」になり、離脱で元に戻ります（表示名は config の `display-name`）。
- **参加/離脱の全体告知** … 参加・離脱時にサーバー全体へ「【ゲーム名】名前 が参加しました (N人)」等を通知します。
- **同時参加は1ゲームまで** … 他ゲームに参加中は参加が拒否されます（「【○○】に参加中です」）。異常で参加ロックが残った場合はOPが `/<コマンド> forceunlock <プレイヤー>` で解除できます。
- **退避データのファイル保存** … ロビー入場時に退避した所持品を `plugins/<プラグイン>/vault/<UUID>.yml` に保存し、**サーバークラッシュ後の再ログインでも復元** します（退避・復元は各1回、試合終了時は復元しません）。

### 追加された config キー

| キー | 説明 |
|---|---|
| `display-name` | ゲーム表示名（「【…】」の中身） |
| `messages.join-broadcast` | 参加の全体告知文 |
| `messages.leave-broadcast` | 離脱の全体告知文 |
| `messages.already-in-other-game` | 他ゲーム参加中に拒否したときの文言 |
| `messages.vault-save-failed` | 持ち物のファイル退避に失敗して参加を中止したときの文言 |

!!! note "config は自動で追記されるようになりました"
    起動時（`reload` 対応プラグインは reload 時も）に、`config.yml` へ不足している項目を既定値＋コメント付きで自動追記します（既存の値は変更しません／更新時は `config.yml.bak` を保存）。座標・看板・会場・ステージなどのデータ領域は補完対象外です。
