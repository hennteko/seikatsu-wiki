# Aooni（青鬼）― 遊び方 { .page-player #aooni-player }

暗闇のマップで **青鬼** から逃げながら **鍵を集めて脱出** を目指すホラー鬼ごっこです。逃走者は脱出すれば勝ち、青鬼は逃走者を全員捕まえて青鬼に変えれば勝ちです。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 3〜16人 |
    | 1試合の長さ | 既定6分（360秒）＋開始カウントダウン15秒 |
    | 勝利条件 | 逃走者：鍵を集めて脱出する／青鬼：逃走者を全員青鬼にする |
    | 役割分担 | 開始時に1人（既定）が青鬼、残りは逃走者 |
    | 感染 | 青鬼に捕まった逃走者は青鬼になる |

## どんなゲーム？

参加者は開始時に **青鬼** と **逃走者** に自動で振り分けられます。既定では最初の青鬼は1人で、残り全員が逃走者です。

逃走者の視界は **暗闇** に包まれ、近くしか見えません。一方で青鬼は **暗視** を持ち、ダイヤ装備で **少し速く** 動けます。ゲーム中は一定時間ごとに **マップ上の鍵チェストのどこかに鍵が出現** します。逃走者はチェストを開けて鍵を3本（既定）集め、**脱出ドア** にたどり着けば脱出成功です。

青鬼は逃走者を殴って捕まえると、その逃走者を **青鬼に「感染」** させます。逃走者が全員青鬼になれば青鬼の勝利、誰か1人でも脱出すれば逃走者の勝利です。

## ゲームの流れ

1. **参加する** — ロビーに設置された参加看板をクリックしてロビーに入ります。
2. **開始を待つ** — 運営または開始看板でゲームが始まると、15秒のカウントダウンが表示されます。
3. **役割が決まる** — 「あなたは青鬼」「あなたは逃走者」のタイトルが表示され、装備が配られて各スポーンへ移動します。
4. **鍵集め＆逃走** — 一定時間ごとに鍵がどこかのチェストに出現します。逃走者は暗闇の中でチェストを開けて鍵を集め、青鬼から逃げます。
5. **脱出** — 必要な鍵（既定3本）を集めたら脱出ドアへ。ドアに近づくと脱出成功です。
6. **感染** — 青鬼に捕まった逃走者は青鬼になり、青鬼側が増えていきます。
7. **決着** — 誰かが脱出すれば逃走者の勝利、逃走者が全員青鬼になれば青鬼の勝利、時間切れは引き分けです。
8. **ロビーへ帰還** — 終了から5秒後に自動でロビーへ戻り、参加状態が維持されるので続けて遊べます。

## ルール・仕様

!!! info "逃走者は暗闇・青鬼は暗視"
    逃走者には **暗闇（DARKNESS）** がかかり、視界がかなり狭くなります。青鬼は **暗視** を持っているため暗いマップでもよく見えます。耳（音）も頼りに立ち回りましょう。

- ゲーム中は **空腹（満腹度の減少）が無効** で、**ダメージで死ぬこともありません**（青鬼の攻撃は捕獲＝感染として扱われます）。
- 青鬼は **ダイヤ装備** を身につけ、**移動速度が逃走者より少し速い**（既定倍率0.25／逃走者は0.2）です。
- 残り時間・逃走者人数・青鬼人数は画面下の **アクションバー** に表示されます。逃走者には自分の **鍵の本数（x/必要数）** も表示され、必要数に達すると「脱出ドアへ向かえ！」と通知されます。
- 鍵がチェストに出現すると、全員に「どこかのチェストに鍵が出現した…！」と通知され、音が鳴ります。
- 残り60秒・30秒・10秒以下でチャットに残り時間が通知されます。

## 役割と装備

=== "👹 青鬼（オニ）"

    逃走者を捕まえて全員を青鬼に変えるのが役目です。

    | 特徴 | 内容 |
    |---|---|
    | 装備 | ダイヤのヘルメット・チェストプレート・レギンス・ブーツ（フル装備） |
    | 移動速度 | 逃走者より速い（既定倍率0.25） |
    | 暗視 | 常時付与され、暗いマップでもよく見える |
    | 捕獲（感染） | 逃走者を **殴る** と、その相手を青鬼に変える |

    捕まえた逃走者は即座に青鬼になり、味方として一緒に逃走者を追えます。逃走者がチェストから鍵を取り出すと「どこかで鍵が奪われた！」と通知され、取り出した逃走者が一瞬光るので位置の手がかりになります。

=== "🏃 逃走者（ランナー）"

    鍵を集めて脱出するのが役目です。

    | 特徴 | 内容 |
    |---|---|
    | 装備 | なし（手ぶら。回収した「脱出の鍵」がインベントリに入る） |
    | 視界 | 暗闇で狭い |
    | 鍵集め | チェストに出現した鍵を開けて回収（既定3本で脱出可能） |
    | 隠れ場所 | 指定ブロックを右クリックすると一定時間透明になれる |

    青鬼に殴られると青鬼になってしまうので、暗闇と隠れ場所を活かして見つからないように鍵を集めましょう。鍵を持ったまま捕まると、その鍵は失われます。

## 鍵集め・脱出

- **鍵の出現** — ゲーム中は一定時間ごと（既定60秒ごと）に抽選が行われ、当たると **マップ上の鍵チェストのいずれか1つ** に鍵が出現します。出現すると全員に「どこかのチェストに鍵が出現した…！」と通知され、音が鳴ります。どのチェストに出たかは知らされないので、探し回る必要があります。
- **鍵の回収** — 鍵チェストは **普通に開けて**、中の「脱出の鍵」を取り出してインベントリに入れます。鍵はチェストに残っているので、早い者勝ちで回収しましょう。
- **発光のリスク** — チェストから鍵を取り出すと、取り出した逃走者が約5秒間 **発光** し、青鬼全員に「どこかで鍵が奪われた！」と通知されます。青鬼が近くにいるときの回収は危険です。
- **脱出** — 必要な鍵（既定3本）を持った状態で **脱出ドアに近づく**（既定で半径2ブロック以内）と脱出成功となり、逃走者陣営の勝利でゲームが終了します。鍵の所持数はアクションバーで確認できます。

!!! tip "脱出のコツ"
    鍵が揃う前に脱出ドアへ行っても脱出できません。鍵は時間とともに少しずつしか出現しないので、出現通知が来たら素早くチェストを巡回するのが鍵です。鍵を取り出した直後は発光しているので、少し移動・待機して光が消えてから動くと安全です。鍵を持ったまま捕まると鍵を失うので、揃ったら早めに脱出を狙いましょう。

## 隠れ場所

マップ上には **隠れ場所** として登録されたブロックがあります。逃走者が隠れ場所を **右クリック** すると、一定時間（既定8秒）**透明** になって青鬼の目をくらませられます。

- 透明化のあとは **再使用までのクールダウン**（既定で隠れ時間＋15秒）があります。
- クールダウン中は「まだ隠れられない」と表示されます。

!!! tip "隠れ場所の使いどころ"
    青鬼に追われて逃げ切れないときの緊急回避や、鍵を取り出して発光しているときのやり過ごしに有効です。透明化は永続ではないので、隠れている間に距離を取りましょう。

## 勝利条件

!!! tip "勝ち方のポイント"
    - **逃走者** … 暗闇と隠れ場所を活かして鍵を集め、青鬼に捕まる前に脱出ドアへ。1人でも脱出すれば逃走者陣営の勝利です。
    - **青鬼** … 逃走者を次々に感染させて増やし、全員を青鬼にすれば勝ち。チェストの発光通知を頼りに逃走者を追い込みましょう。

| 結果 | 条件 |
|---|---|
| 逃走者の勝利 | 逃走者の誰かが鍵を揃えて脱出した |
| 青鬼の勝利 | 逃走者が全員 青鬼になった |
| 引き分け | 制限時間（既定6分）が切れた |

## 参加方法

参加・離脱は **看板** で行います（参加用のコマンドはありません）。

- **参加看板をクリック** … ロビーに設置された「[青鬼] lobby」看板を右クリックするとロビーに参加できます。
- **離脱看板をクリック** … 「[青鬼] leave」看板を右クリックするとロビーから離脱できます。

参加するとロビー地点へテレポートされます。ゲーム開始を待ちましょう。

!!! note "ゲーム中は参加・離脱できません"
    参加・離脱ができるのは **ロビー待機中のみ** です。ゲーム開始後は参加できません。途中でログアウトすると初期スポーン地点へ戻され、ゲーム／ロビーから外れます。

## よくある質問

??? question "青鬼と逃走者は選べますか？"
    選べません。役割はゲーム開始時にランダムで決まります。既定では最初の青鬼は1人で、残り全員が逃走者です。

??? question "鍵はどうやって手に入りますか？"
    鍵は一定時間ごと（既定60秒ごと）の抽選で、マップ上の鍵チェストのどこかに出現します。「どこかのチェストに鍵が出現した…！」の通知が来たらチェストを巡回し、見つけたチェストを開けて鍵を回収してください。

??? question "鍵は何本必要ですか？"
    既定では3本です（サーバー設定で変更されている場合があります）。所持している鍵の本数はアクションバーに「鍵 x/必要数」と表示され、必要数が揃うと「脱出ドアへ向かえ！」と通知されます。

??? question "鍵を取り出したら青鬼にバレますか？"
    はい。チェストから鍵を取り出すと約5秒間 発光し、青鬼全員に通知が飛びます。青鬼が近くにいないタイミングで回収するのが安全です。

??? question "捕まったらどうなりますか？"
    青鬼に殴られると、その場で青鬼になります（感染）。以降は青鬼として他の逃走者を追う側に回ります。逃走者が全員青鬼になると青鬼の勝利です。

??? question "ゲームが終わったらどうなりますか？"
    終了から5秒後に自動でロビーへ戻され、参加状態が維持されます。続けて次の試合に参加できます。
