# Aooni（青鬼） <span class="badge dev">v1.0 / 新規追加</span>

暗いマップを青鬼から逃げながら鍵を集め、脱出ドアを目指す **脱出型ホラー鬼ごっこ「青鬼（あおおに）」ミニゲーム**。逃走者は隠れ場所をうまく使って鍵を集め（既定3本）、脱出ドアにたどり着けば個人で脱出成功（以降は観戦）。青鬼は逃走者を捕まえて **残機** を削り、逃走中の逃走者を全滅させれば勝ちです。残機が尽きた逃走者は鍵を没収されて **復帰アスレ** に送られ、クリアすれば逃走者として復活できます（復帰アスレ未設定のサーバーでは残機0で青鬼になります）。

!!! success "ゲームの特徴（脱出型 × 鍵集め式 × 残機・復帰アスレ）"
    **脱出型** … 各逃走者は自分で鍵を集めて（既定3本）脱出ドアから脱出します。脱出した人は観戦になり、試合は続行します。鍵は個人で集めるもので、受け渡し（チェストへ入れる）はできません。<br>
    **鍵集め式** … 一定時間ごと（既定10秒ごと）にマップ上の鍵チェストへ鍵が補充され、逃走者がチェストを開けて回収します。サーバー設定（`chest-reveal`）が有効だと取り出し時に一瞬発光します（既定は無効）。<br>
    **残機・復帰アスレ** … 青鬼に捕まると残機が1減り（鍵は維持）逃走者スポーンへ戻ります。残機0になると鍵を没収されて **復帰アスレ**（難易度別3コース）へ送られ、クリアするとコースに応じた残機で復活します（鍵は0本から）。逃走中の逃走者が全滅すると青鬼の勝利です（復帰アスレ未設定なら残機0で青鬼化＝旧ルール）。

!!! info "実装済みの機能"
    ロビー参加（看板またはコマンド）・カウントダウン・役割の自動抽選（青鬼への立候補看板対応）・青鬼の暗視＆移動速度UP・鍵の時間補充＆チェストからの回収・隠れ場所（一時透明化）・個人脱出（観戦化）・残機制と復帰アスレ（コース選択GUI）・残り時間と鍵数のアクションバー・勝敗判定・終了後の自動ロビー帰還までが実装済みです。会場の地点や鍵チェスト・隠れ場所・復帰アスレはすべてコマンド（または `/aooni tool` のGUI）で登録し、`locations.yml` に保存されます。
