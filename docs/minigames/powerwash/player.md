# PowerWash ― 遊び方 { .page-player #powerwash-player }

高圧洗浄機で汚れを落とす協力洗浄ミニゲームです。制限時間内に、みんなで手分けしてステージをピカピカにしましょう。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | 協力（みんなで1つのステージを洗浄） |
    | 勝利条件 | 制限時間内に洗浄率100%を目指す |
    | 洗浄機 | 高圧洗浄機（アイアンクワの見た目） |
    | 参加方法 | `[PowerWash]` 参加看板、または `/pw join` |

## どんなゲーム？

汚れたステージの表面が細かい **セル** に分割されています。**高圧洗浄機** の水流を当てるとセルの汚れが少しずつ落ち、0になるとそのセルがきれいになります。汚れの種類によって落ちにくさが違います。みんなで手分けして、制限時間内に **洗浄率100%** を目指す協力ゲームです。

## 遊び方

1. ロビーの参加看板か `/pw join` で参加します。
2. 開始看板のクリックか `/pw start <識別子> [分]` でゲーム開始（分を省略すると時間選択GUI、`0` で無制限）。
3. 配られた高圧洗浄機を構えて、汚れたセルに水流を当てて洗います。
4. 制限時間内にできるだけ洗浄率を上げましょう。

## 洗浄のしくみ

- 高圧洗浄機を構えて表面に水流を当てると、当たったセルの汚れが減り、0になるときれいになります。
- 洗浄率（きれいになったセルの割合）はステージごとに集計され、`/pw status <識別子>` で確認できます。
- 洗浄機は将来、**ノズル切替（ジェット／ファン）** や **出力・範囲・射程のアップグレード**、**洗剤** などの要素が追加される予定です。

!!! note "今後の予定"
    お金・アップグレードのショップ・洗剤・ヒント（残りの汚れの自動ハイライト）などが今後のフェーズで追加予定です。実装され次第このページを更新します。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/pw join` | ロビーに参加する（参加看板と同等・全員可） |
| `/pw leave` | ロビーから離脱する（全員可） |
| `/pw start <識別子> [分]` | ゲームを開始する（分省略でGUI・`0`で無制限・全員可） |
| `/pw status [識別子]` | 設定・洗浄状況を確認する（全員可） |
| `/pw help` | コマンド一覧（ヘルプ）を表示する（全員可） |

## よくある質問

??? question "汚れが落ちません"
    高圧洗浄機を構えて水流を当て続けてください。汚れの種類によって落ちにくさが違います。当たっているか、洗浄機を持っているかを確認しましょう。

??? question "時間はどのくらい？"
    開始時に選べます（`/pw start <識別子> <分>`、または分を省略して時間選択GUIから選択）。`0` を指定すると無制限になります。
