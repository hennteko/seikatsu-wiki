# PowerWash ― 遊び方 { .page-player #powerwash-player }

高圧洗浄機で汚れを落とす協力洗浄ミニゲームです。

!!! warning "現在開発中（Phase 1）です"
    このゲームは開発中です。現時点では **参加・開始のプレイループ（`/pw join`・`/pw start`）は未実装** で、OP がテスト用に配布する高圧洗浄機で洗浄の動作を確認できる段階です。正式なプレイ方法（参加看板・スコア・ショップなど）は今後のアップデートで追加されます。

## どんなゲーム？（コンセプト）

汚れたステージの表面が細かい **セル** に分割されていて、**高圧洗浄機**（アイアンクワの見た目）の水流を当てるとセルの汚れが少しずつ落ちていきます。汚れの種類によって落ちにくさが変わり、みんなで手分けして **洗浄率100%** を目指す協力ゲームになる予定です。

## 洗浄のしくみ（現状）

- 高圧洗浄機を構えて表面に水流を当てると、当たったセルの汚れHPが減り、0になるとそのセルがきれいになります。
- 洗浄率（きれいになったセルの割合）はステージごとに集計されます。
- 洗浄機には将来、**ノズル切替（ジェット／ファン）** や **出力・範囲・射程のアップグレード**、**洗剤** などの要素が追加される予定です（config に枠が用意されています）。
