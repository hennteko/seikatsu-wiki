# 弓人狼（Yajinro） <span class="badge done">公開中</span>

全員が **一撃必殺の弓** を持って戦う、**戦闘型のマイクラ人狼**ミニゲームです。昼夜・投票・追放はなく、決着はすべて直接戦闘。矢が当たれば誰でも一撃で倒れます。会話と推理で敵を見抜きつつ、撃ち合いで相手陣営を全滅させれば勝ちです。クォーツを集めての強化、マップのボタンで手に入る特殊アイテム、占い・霊媒・騎士の能力など、人狼らしい駆け引きとアクションを両立しています。

!!! note "ゲームの特徴"
    全員が **一撃弓**（矢3本・撃ち切ると2秒で補充）を持ってスタート。**弓・人狼の斧・雷・拡散クロスボウ以外のダメージはすべて無効**で、死因は「撃破」のみです。倒れると観戦になり、持っていた **クォーツと特殊アイテムをその場に落とします**。クォーツを4個集めてクラフトすると、人狼は「人狼の斧」、占い師・霊媒師・騎士は能力回数が増えます。マップ各地の **別々のボタンを5つ** 押すと、早い者勝ち・被りなしの特殊アイテムを入手。会話は **Discord VC（1チャンネル）** で行い、死亡者はサーバーミュートされます（死者同士はゲーム内テキストで会話）。
