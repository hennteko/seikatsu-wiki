# 弓人狼（Yajinro） ― 遊び方 { .page-player #yajinro-player }

全員が一撃必殺の弓を持って戦う、戦闘型のマイクラ人狼です。会話と推理で敵を見抜き、撃ち合いで相手陣営を全滅させれば勝ち。昼夜も投票も追放もありません。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 4〜15人（サーバー設定により変更されることがあります） |
    | 勝利条件 | 相手陣営を全滅させる（村人陣営は人狼＋共犯者を全員倒す） |
    | 武器 | 一撃弓（全員共通）。矢は3本、撃ち切ると約2秒で補充 |
    | リスポーン | なし（倒れると観戦モードになります） |
    | 会話 | Discord VC（1チャンネル）。死亡するとミュートされます |
    | 参加方法 | ロビーの参加看板（`[弓人狼]` / `参加`）をクリック、または `/yj join` |

## どんなゲーム？

全員が **一撃弓** を持ってスタートします。矢が当たれば誰でも一撃で倒れるので、物陰・射線・不意打ちが重要です。倒れると観戦（スペクテイター）になり、持っていた **クォーツと特殊アイテムをその場に落とします**。

**弓・人狼の斧・雷・拡散クロスボウ以外のダメージはすべて無効**です。落下・溺れ・素手・炎・爆発などでは死なず、決着は必ず「撃破」でつきます。

村人陣営（村人・占い師・霊媒師・騎士）と人狼陣営（人狼・共犯者）に分かれ、**相手陣営を全滅** させたほうが勝ちです。

## 操作方法

1. **撃つ** … 一撃弓を **右クリック長押しで引き絞り、離して発射**。当たれば一撃です。
2. **矢** … 最初は3本。撃ち切ると **約2秒後に3本補充** されます（発射した矢は拾えません）。
3. **クォーツを集める** … 開始時に1個所持。倒した相手が落としたクォーツを拾って集めます。
4. **クラフト** … クォーツを **4個、2×2に並べる**（作業台不要）と、役職ごとの強化が発動します。
5. **ボタンを押す** … マップ各地の **別々のボタンを5つ** 押すと、特殊アイテムを1つ入手できます。

!!! note "弓・役職本・矢は手放せません"
    一撃弓・役職本・矢はドロップや預け入れができず、死亡時にも落ちません。クォーツと特殊アイテムだけが死亡時にその場へ落ちます。

## 役職

村人陣営と人狼陣営に分かれます。開始時に配られる **役職本** で自分の役職と能力を確認できます（`/yj role` でも再表示できます）。

| 役職 | 陣営 | 能力 |
|---|---|---|
| 村人 | 村人陣営 | 特殊能力なし。弓で戦う |
| 占い師 | 村人陣営 | `/yj divine <名前>` で相手が「人狼か否か」を自分だけ知る |
| 霊媒師 | 村人陣営 | `/yj seance <名前>` で **死亡済み** プレイヤーの役職を自分だけ知る |
| 騎士 | 村人陣営 | `/yj guard <名前>` で対象に「守り」を1回付与（次の致命傷を1度だけ防ぐ） |
| 人狼 | 人狼陣営 | 開始時に仲間の人狼を知る。クォーツ4個で「人狼の斧」を作れる |
| 共犯者 | 人狼陣営 | 開始時に人狼が誰かを知る（人狼側は共犯者を知らない）。クラフト強化はなし |

!!! tip "能力の回数"
    占い師・霊媒師・騎士の能力は最初 **1回** だけ使えます。クォーツを4個クラフトすると **+1回** 増えます。占い師は自分を占えません。結果は実行した本人にのみ表示され、他の人には一切通知されません。占い結果で「人狼」と出るのは人狼だけで、**共犯者は「人狼ではない」** と表示されます。

## クォーツクラフト（強化）

クォーツを **4個、2×2に並べる** とクラフトできます（手持ちクラフトでOK・作業台不要）。

- **人狼** … 「人狼の斧」を入手。殴ると一撃で倒せますが、**一度攻撃すると壊れます**（守りで防がれても壊れます）。
- **占い師／霊媒師／騎士** … 能力の使用回数が **+1** されます。
- **村人／共犯者** … クラフトできません。

## 特殊アイテム（ボタン報酬）

マップ各地の **別々のボタンを5つ** 押すと、特殊アイテムを1つもらえます（**早い者勝ち・被りなし**。誰かが取ったものは出ません）。主なアイテムは次のとおりです。

| アイテム | 効果 |
|---|---|
| 拡散のクロスボウ | 装填済みで配布。撃つと3方向に矢が飛ぶ（1回使い切り） |
| 瞬間移動トライデント | 投げて着弾地点へワープ（使用回数あり・使い切ると壊れる） |
| かけだし勇者の剣 | 持っている間、移動速度と跳躍力アップ |
| 伝説のつりざお | 右クリックで真上に大きくジャンプ（クールダウンあり） |
| 雷トラップ | 投げて設置。他人が拾うと落雷で即死。自分で拾えば設置し直せる |
| 蜘蛛の巣トラップ | 投げて設置。他人が拾うと周囲が蜘蛛の巣になる（数秒で消える） |
| 場所入れ替え | 使うと自分以外の生存者1人とランダムに位置を交換 |

!!! note "設置したトラップは自分で回収できます"
    雷・蜘蛛の巣トラップは、**設置した本人が拾えば通常アイテムに戻り**、設置し直せます。他人が拾うと発動します。

## 会話ルール（Discord VC）

会話は **Discord のボイスチャット（全員同じ1チャンネル）** で行います。

- 生存者の声は距離に関係なく **全員に聞こえます**。
- 倒れると **サーバーミュート** され、死者は生存者の会話を **聞けますが話せません**。
- 死者同士の相談は **ゲーム内の死者専用テキストチャット**（`[死者]` 表示）で行います。
- 人狼・共犯者は `/yj w <メッセージ>` で **人狼専用チャット**（生存中のみ）が使えます。
- 試合が終わると全員のミュートが解除されます。

## 勝利条件

- **村人陣営の勝利** … 人狼と共犯者が **全員** 倒れる（人狼だけ倒しても共犯者が生きていれば続行）。
- **人狼陣営の勝利** … 村人陣営が全滅する。
- 両陣営が同時に全滅した場合や時間切れ（既定は無制限）は引き分けです。

決着がつくと全員の役職が公開され、結果発表のあとロビーへ戻ります。

## ゲームの流れ

1. **ロビーに参加** — 参加看板をクリック、または `/yj join`。
2. **開始** — 開始看板のクリックまたは `/yj start <ステージ>`（全員可）で試合開始。
3. **カウントダウン（10秒）** — 配役・装備配布のあと、開始直後の約10秒は撃破無効（散開時間）。
4. **戦闘** — 弓で撃ち合い、クォーツを集め、ボタンで特殊アイテムを狙い、能力を使って推理します。
5. **決着** — 相手陣営を全滅させれば勝利。結果発表のあとロビーへ戻ります。

!!! note "コマンドの短縮形"
    `/yajinro` は `/yj` と短縮できます。役職コマンド（divine / seance / guard）は試合中の生存者かつ該当役職のみ使え、回数が残っていないと使えません。

## よくある質問

??? question "矢がなくなりました"
    撃ち切ると **約2秒後に3本補充** されます。少し待てば自動で戻ります。発射した矢は拾えません。

??? question "剣や素手で殴っても倒せません"
    弓・人狼の斧・雷・拡散クロスボウ以外のダメージはすべて無効です。基本は弓で狙撃して倒します。

??? question "倒されたらどうなりますか？"
    観戦（スペクテイター）になります。Discord ではミュートされ、死者同士はゲーム内テキストチャットで会話できます。持っていたクォーツと特殊アイテムはその場に落ちます。

??? question "騎士に守られるとどうなりますか？"
    次に受ける致命傷を **1度だけ** 防ぎます（守りを消費）。防いだことは既定では本人に通知されません。

??? question "共犯者は占いで人狼と出ますか？"
    いいえ。占い結果で「人狼」と出るのは人狼だけで、共犯者は「人狼ではない」と表示されます。
