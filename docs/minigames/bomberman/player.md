# Bomberman（ボンバーマン）― 遊び方 { .page-player #bomberman-player }

爆弾を置いて相手を爆風に巻き込み、最後の1人を目指す対戦ゲームです。被弾は一発で脱落なので、置き引きと逃げの読み合いが勝負です。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 2人〜 |
    | 勝利条件 | 最後の1人になる（0人なら引き分け） |
    | 被弾 | 一発で脱落（観戦モードへ。リスポーンなし） |
    | 配布アイテム | ボム（右クリックで設置） |

## ゲームの流れ

1. **参加する** — ロビーの参加看板をクリック、または `/bomberman join`。ロビーへ移動します。
2. **開始する／待つ** — 必要人数（既定2人・サーバー設定による）がそろったら、開始看板のクリックまたは `/bomberman start` で開始（必要な会場設定が済んでいること）。
3. **配置につく** — 各自のスポーンへ飛ばされ、インベントリがクリアされて **スロット1に「ボム」** が配られます。
4. **爆弾で攻める** — 軟ブロックを壊して道とパワーアップを確保しつつ、相手を爆風に追い込みます。
5. **生き残る** — 爆風やサドンデスのブロックに当たると脱落（観戦）。最後の1人になれば **優勝！**
6. **次のラウンドへ** — 終了から数秒後にロビーへ戻り、参加状態は維持されます。続けて遊べます。

## 操作・爆弾の置き方

- **爆弾の設置** … 「ボム（右クリックで設置）」アイテムを持って **右クリック**。足元の升目にスナップして置かれます。
- 置けない条件 … フィールド外、壁・軟ブロックの上、同じマスに既に爆弾がある、設置数の上限に達している、のいずれか。
- **起爆** … 設置から約2.5秒後（サーバー設定による）に **十字** に爆発。火力のマス数だけ伸び、硬ブロックで止まり、軟ブロックを1枚壊して止まります（貫通を取ると軟ブロックを貫きます）。
- **誘爆** … 爆風が他の爆弾に当たると連鎖して起爆します。自分の爆弾の巻き添えにも注意。
- 移動は通常の移動操作です。ゲーム中は空腹・通常ダメージは無効で、**脱落するのは爆風／サドンデスのブロックに触れたときだけ** です。

## パワーアップ

軟ブロックを壊すと一定確率でパワーアップが出現します。**触れると自動で適用** されます（拾ってインベントリに入るのではなく即時効果）。

| パワーアップ | 見た目 | 効果 |
|---|---|---|
| 火力アップ | ファイアチャージ | 爆風の長さ +1マス |
| ボムアップ | TNT | 同時に置ける爆弾 +1個 |
| スピードアップ | 羽根 | 移動速度アップ（上限あり） |
| 貫通ボム | 光の矢 | 爆風が軟ブロックを貫通する |
| フルファイア | ブレイズロッド | 火力を一気に最大級まで強化 |

## サドンデス

制限時間（既定120秒・無効設定の場合あり）が経過すると、フィールドの **外周から硬ブロックが1リングずつせり上がり**、内側へ詰まっていきます。巻き込まれると脱落するので、時間が経ったら中央付近で決着をつけましょう。中央まで埋まっても決着しなければ引き分けです。

## 参加方法

参加・退出・開始は **看板** または **コマンド** で行えます（いずれも全員可）。

- 参加看板をクリック／`/bomberman join`
- 離脱看板をクリック／`/bomberman leave`
- 開始看板をクリック／`/bomberman start`

`/bomberman` のエイリアスは `/bm`・`/bomber` です。ゲーム進行中・満員時は参加できません。途中でログアウトすると離脱扱いになります。

## よくある質問

??? question "倒されたらどうなりますか？"
    一発で脱落し、観戦モードになります（リスポーンはありません）。試合が終わるとロビーに戻り、次のラウンドにそのまま参加できます。

??? question "爆弾はどうやって置きますか？"
    開始時に配られる「ボム」アイテムを持って **右クリック** すると、足元の升目に設置されます。約2.5秒後に十字に爆発します。

??? question "自分の爆弾でやられますか？"
    やられます。爆風は敵味方・自分を問わず当たり判定があります。置いたら素早く離れましょう。

??? question "強くなるには？"
    軟ブロックを壊して出るパワーアップに触れると、火力・ボム数・スピードなどが上がります。序盤は安全に軟ブロックを壊して強化するのがコツです。
