# Bomberman（ボンバーマン）― 遊び方 { .page-player #bomberman-player }

爆弾を置いて相手を爆風に巻き込み、最後の1人を目指す対戦ゲームです。被弾は一発で脱落なので、置き引きと逃げの読み合いが勝負です。1人で遊べる **ソロモード（CPU対戦・パズル）** もあります。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 2人〜（ソロは1人） |
    | 勝利条件 | 最後の1人になる（0人なら引き分け） |
    | 被弾 | 一発で脱落（観戦モードへ。リスポーンなし） |
    | 配布アイテム | ボム（右クリックで設置） |

## ゲームの流れ

1. **参加する** — ロビーの参加看板をクリック、または `/bomberman join`。ロビーへ移動します。
2. **開始する／待つ** — 必要人数（既定2人・サーバー設定による）がそろったら、開始看板のクリックまたは `/bomberman start` で開始（必要な会場設定が済んでいること）。
3. **配置につく** — 各自のスポーンへ飛ばされ、インベントリがクリアされて **スロット1に「ボム」** が配られます。
4. **爆弾で攻める** — 軟ブロックを壊して道とパワーアップを確保しつつ、相手を爆風に追い込みます。
5. **生き残る** — 爆風やサドンデスのブロックに当たると脱落（観戦）。最後の1人になれば **優勝！**
6. **次のラウンドへ** — 終了から数秒後にロビーへ戻り、参加状態は維持されます。続けて遊べます。

## 操作・爆弾の置き方

- **爆弾の設置** … 「ボム（右クリックで設置）」アイテムを持って **右クリック**。足元の升目にスナップして置かれます。
- 置けない条件 … フィールド外、壁・軟ブロックの上、同じマスに既に爆弾がある、設置数の上限に達している、のいずれか。
- **起爆** … 設置から約2.5秒後（サーバー設定による）に **十字** に爆発。火力のマス数だけ伸び、硬ブロックで止まり、軟ブロックを1枚壊して止まります（貫通を取ると軟ブロックを貫きます）。
- **誘爆** … 爆風が他の爆弾に当たると連鎖して起爆します。自分の爆弾の巻き添えにも注意。
- 移動は通常の移動操作です。ゲーム中は空腹・通常ダメージは無効で、**脱落するのは爆風／サドンデスのブロックに触れたときだけ** です。

!!! note "統合版（スマホ・Switch など）の操作"
    ボムを持って **空中をタップ** するか、**スニーク（しゃがむ）ボタン** でも足元に置けます。

## パワーアップ

軟ブロックを壊すと一定確率でパワーアップが出現します。**アイテムのある升目に入ると自動で適用** されます（拾ってインベントリに入るのではなく即時効果）。隣の升目や、壁の角をはさんだ斜めの升目からは取れません。

| パワーアップ | 見た目 | 効果 |
|---|---|---|
| 火力アップ | ファイアチャージ | 爆風の長さ +1マス |
| ボムアップ | TNT | 同時に置ける爆弾 +1個 |
| スピードアップ | 羽根 | 移動速度アップ（上限あり） |
| 貫通ボム | 光の矢 | 爆風が軟ブロックを貫通する |
| フルファイア | ブレイズロッド | 火力を一気に最大級まで強化 |

## サドンデス

制限時間（既定120秒・無効設定の場合あり）が経過すると、フィールドの **外周から硬ブロックが1リングずつせり上がり**、内側へ詰まっていきます。巻き込まれると脱落するので、時間が経ったら中央付近で決着をつけましょう。中央まで埋まっても決着しなければ引き分けです。

## ソロモード（1人で遊ぶ）

1人で遊べるモードが2つあります。どちらも **クリアまでの時間** が記録になり、自己ベストとランキングが残ります。

| モード | 内容 | クリア | 失敗 |
|---|---|---|---|
| **CPU対戦** | CPU ボマーと1対多で対戦 | CPU を全員倒す | 自分がやられる（相打ちも負け）／サドンデスで中央まで埋まる |
| **パズル** | 決まった数のボムで軟ブロックを全部壊す（詰め将棋型・11章128ステージ） | 軟ブロックを全部壊す | ボムを使い切っても残る／自分の爆風に巻き込まれる／制限時間（既定3分） |

### 始め方

1. ソロ看板を右クリック、または `/bomberman solo` → ロビーに入り、**ソロメニュー** が開きます。
2. 上段の **CPU対戦の難易度** を押すと、3秒後に始まります。パズルは2・3段目の **章** を押してステージ一覧を開き、ステージを押します（**「つづきから」** で次のステージをすぐ始めることもできます）。
3. 終わると結果が出て、ロビーに戻り、数秒後にまたソロメニューが開きます。続けて挑戦できます。

```text title="ソロメニューを開く"
/bomberman solo
```
```text title="メニューを通さず CPU対戦を始める（難易度 easy / normal / hard。省略するとふつう）"
/bomberman solo cpu hard
```
```text title="メニューを通さずパズルを始める（ステージ番号 章-番号 か、ステージ名）"
/bomberman solo puzzle 2-3
```

- メニューを閉じてもロビーにいるままです。ホットバーの **ネザースター（ソロメニュー）** を右クリックすると開き直せます。統合版は **ネザースターを持ってスニーク** か **空中タップ** でも開きます。
- 試合中は、スロット9の **時計（やり直す）** を右クリックすると、記録を残さずに最初からやり直せます（統合版は時計を持って空中タップ）。
- メニューの「ロビー退出」か `/bomberman leave` で抜けると、持ち物が元に戻ります。途中で抜けた・切断した挑戦は **中断** で、記録は残りません。
- アリーナは通常戦と共用です。誰かがソロ中・通常戦の試合中は始められません（メニューに「使用中」と出て、空くと表示が変わります）。
- ソロで入った人は通常の試合（`/bomberman start`）には参加しません。通常戦に出たいときは `/bomberman join` で切り替えます。

### CPU対戦

| 難易度 | CPU の数 | 特徴 |
|---|---|---|
| よわい | 1体 | ゆっくり動き、あまり攻めてこない。パワーアップは拾いに行かない |
| ふつう | 2体 | 普通の速さ。ブロックを壊しながら、ときどき近づいて攻めてくる |
| つよい | 3体 | 速く、積極的に近づいてボムを置く。パワーアップも拾いに行く |

- CPU は色付きの防具を着た **ゾンビの見た目** で、頭上に「CPU赤」などの名前が出ます。ゾンビですが攻撃はしてきません。**爆風に当たったときだけ** 脱落します（自分のボムで自滅することもあります）。
- CPU は爆風が来るマスから逃げ、逃げ道があるときだけボムを置きます。ボムの上は通りません。
- 自分の初期火力・ボム数は通常戦と同じです。パワーアップも出ます（CPU も踏めば拾います）。
- 時間がたつと通常戦と同じく **サドンデス** になります。
- 画面下に「CPU 残り」「経過時間」「自分の火力・ボム数」が出ます。

### パズル

- 盤面は毎回同じです。**ボムの数がちょうど足りるように** 作ってあるので、置く場所と順番を考えましょう（全ステージ、解けることを確認済みです）。
- ボムの数はホットバーのボムの個数でわかります。爆風は硬ブロックで止まり、軟ブロックを **1つ壊して止まります**。
- パワーアップは出ません（ステージに置いてある火力アップは別）。同時に置けるボムは1個です。
- 失敗するとヒントが出ます。スロット9の **時計** でいつでも最初からやり直せます（記録は残りません）。

#### 章と解放

ステージは **11章・128ステージ** です。**前のステージをクリアすると次のステージ** が、**前の章を3ステージクリアすると次の章** が遊べるようになります。ソロメニューの「つづきから」は、遊べる中でまだクリアしていない最初のステージです。

| 章 | ステージ | 出てくるギミック |
|---|---|---|
| 第1章「きほん」 | 1-1〜1-11 | なし（爆風の届く範囲と、置く順番） |
| 第2章「かたいブロックと置けない床」 | 2-1〜2-12 | 硬いブロック・置けない床 |
| 第3章「置きボム」 | 3-1〜3-12 | 置きボム |
| 第4章「火力アップと総仕上げ」 | 4-1〜4-12 | 火力アップ（4-6 は置きボム、最後の 4-12 は全部のギミック） |
| 第5章「組み合わせ」 | 5-1〜5-10 | どのステージもギミックが2種類以上（硬いブロック×置きボム、置きボム×置けない床、火力アップ×置けない床 など） |
| 第6章「大きい盤面」 | 6-1〜6-11 | 11×11 の広い盤面（全部のギミックが登場） |
| 第7章「ひらめき」 | 7-1〜7-14 | 置きボムの連鎖で、1〜3個のボムで全部壊す |
| 第8章「火力ちがい」 | 8-1〜8-13 | 置きボムの火力が自分のボムと違う（強い置きボム・弱い置きボム） |
| 第9章「広い盤面のひらめき」 | 9-1〜9-12 | 11×11 の盤面を、1〜3個のボムと長い連鎖で壊す |
| 第10章「細長い盤面」 | 10-1〜10-12 | 5×11・11×5 などの細長い盤面。逃げ場が少なく、置く順番が決め手 |
| 第11章「最難関」 | 11-1〜11-9 | 全部のギミックと火力ちがい。ボム7〜10個の手数の多いステージ（★4〜★5だけ） |

第1〜10章は ★1（やさしい）〜★5（むずかしい）のステージが入っていて（第11章は ★4〜★5 だけ）、章の中ではだいたい易しい順に並んでいます。

!!! note "最後の1個が置きボムを誘爆させるとき"
    ボムを使い切っても、置きボムの誘爆で残りのブロックが壊れればクリアです（誘爆が全部終わってから判定します）。

#### ギミック

| 見た目 | 名前 | 動き |
|---|---|---|
| レンガ | 硬いブロック | 爆風1回目でひびが入って普通の軟ブロックになり、2回目で壊れる |
| 光るTNT（煙が出る） | 置きボム | 時間では爆発しない。爆風が当たると誘爆して、そこからも十字の爆風が出る。火力はふつう自分のボムと同じですが、第8章などでは違います（メニューと開始時に「置きボム ×2（火力3）」のように出ます） |
| ファイアチャージ | 火力アップ | 拾うと火力が1上がる（そのステージの間だけ） |
| マグマの床 | 置けない床 | この上にはボムを置けない（乗ってもダメージはありません） |

#### ★評価

クリアすると、ステージごとに ★1〜★3 が付きます（一番多く取った数が残ります）。

| ★ | 条件 |
|---|---|
| ★1 | クリア |
| ★2 | 目標タイム以内にクリア（目標タイムはメニューのボタンと開始時に出ます） |
| ★3 | 目標タイム以内に、ヒントを使わずにクリア |

#### ヒント

スロット8の **本（ヒント）** を使うと、**次にボムを置く場所が黄色い光の柱** で示されます（5秒以内に2回使うと出ます）。使ったステージは ★3 が付きません。解答と違う場所に置いた後は使えないので、時計でやり直してから使ってください。統合版は本を持って空中をタップします。

!!! tip "パズルのコツ"
    一度にたくさん壊せる場所から置くと、最後に1個足りなくなるステージがあります。先に道を開けてから、まとめて壊せる交差点を狙いましょう。置きボムは「どこから爆風が出るか」、レンガは「何回当てるか」を数えるのが近道です。

### 記録とランキング

- CPU対戦は **難易度ごと**、パズルは **ステージごと** に、クリアした中で一番速いタイムが自己ベストになります（同じタイムなら先に出したほうが上）。
- パズルには **★の合計** のランキングもあります（同じなら、クリアしたステージ数が多いほう → 合計タイムが短いほうが上）。
- クリアするとサーバー全体に1行で流れます（自己ベスト・1位のときはそう添えます）。
- 統合版で出した記録は、ランキングに `[統]` の印が付きます（ランキングは分けません）。

```text title="ランキング（CPU対戦のふつう と パズルの★の合計）"
/bomberman ranking solo
```
```text title="CPU対戦の難易度ごとのランキング"
/bomberman ranking solo cpu hard
```
```text title="パズルのステージごとのランキング"
/bomberman ranking solo puzzle 2-3
```

!!! note "統合版での見え方"
    ソロメニュー（チェスト画面）・画面下の表示・CPU（ゾンビ）と頭上の名前は統合版でも表示されます。通信の遅れがあるため、CPU の動きが少しカクつくことがあります。

## 参加方法

参加・退出・開始は **看板** または **コマンド** で行えます（いずれも全員可）。

- 参加看板をクリック／`/bomberman join`
- 離脱看板をクリック／`/bomberman leave`
- 開始看板をクリック／`/bomberman start`
- ソロ看板をクリック／`/bomberman solo`

`/bomberman` のエイリアスは `/bm`・`/bomber` です。満員のときは参加できません。**試合中に参加した場合はロビーで待ち、次の試合から参加** します。途中でログアウトすると離脱扱いになります。

## よくある質問

??? question "倒されたらどうなりますか？"
    一発で脱落し、観戦モードになります（リスポーンはありません）。試合が終わるとロビーに戻り、次のラウンドにそのまま参加できます。

??? question "爆弾はどうやって置きますか？"
    開始時に配られる「ボム」アイテムを持って **右クリック** すると、足元の升目に設置されます。約2.5秒後に十字に爆発します。

??? question "自分の爆弾でやられますか？"
    やられます。爆風は敵味方・自分を問わず当たり判定があります。置いたら素早く離れましょう。

??? question "強くなるには？"
    軟ブロックを壊して出るパワーアップに触れると、火力・ボム数・スピードなどが上がります。序盤は安全に軟ブロックを壊して強化するのがコツです。

??? question "1人でも遊べますか？"
    遊べます。`/bomberman solo` でソロメニューを開き、CPU対戦かパズルを選んでください。

??? question "パズルでボムを置く場所を間違えました"
    スロット9の時計（やり直す）で、記録を残さずに最初からやり直せます。

??? question "パズルがどうしても解けません"
    スロット8の本（ヒント）で、次に置く場所が光ります（そのステージは★3が付かなくなります）。

??? question "次の章が選べません"
    前の章を3ステージクリアすると開きます。ソロメニューの章のボタンに、あと何ステージかが出ます。
