# Battleroyale ― 遊び方 { .page-player #battleroyale-player }

最後の1チームになるまで戦い抜くバトルロイヤルです。広いゲームエリアにランダムスポーンし、チェストで装備を集め、縮小する安全地帯（ワールドボーダー）の中で生き残りを賭けて戦います。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 最大16人（サーバー設定により変更されることがあります） |
    | 勝利条件 | 最後の1チーム（または1人）として生き残る |
    | リスポーン | なし（倒れるとスペクテイターになります） |
    | 参加方法 | ロビーの参加看板をクリック、または `/btr join` |

## どんなゲーム？

ゲームが始まると、参加者はゲームエリア内のランダムな地点にスポーンします。スポーン時は体力・満腹度が満タンになり、サバイバルモードで持ち物は空の状態です。

エリア内に設置された **チェスト** にはランダムなアイテムが補充されています。武器や道具を集めて他のプレイヤーと戦いましょう。時間が経つと **ワールドボーダー（安全地帯）が少しずつ縮小** していくため、いつまでも逃げ続けることはできません。

倒されたプレイヤーは敗北となり、スペクテイター（観戦）モードに切り替わります。最後に生き残ったチームが勝者です。

## ルール

- ゲーム開始時、持ち物はすべてクリアされ、体力・満腹度は満タンになります。
- アイテムはエリア内のチェストから集めます。チェストの中身は試合ごとにランダムです。
- ワールドボーダーは一定間隔で縮小します（既定では1回につき2ブロックずつ縮小）。ボーダーの外にいるとダメージを受けるので、内側に留まりましょう。
- 倒されると敗北扱いになり、スペクテイターモードになります。
- ゲーム中に切断（ログアウト）すると **敗北扱い** になります。

## 勝利条件

生き残っているチームが **1チーム（または1人）だけ** になった時点でゲーム終了です。最後まで残ったチームの勝利となり、勝者には花火の演出が打ち上がります。

!!! tip "チームを組むには"
    ロビーに参加したあと `/btr team <チーム名>` を実行すると、同じチーム名のプレイヤー同士が味方になります。チームを組まない場合は、自分1人が1チームとして扱われます。勝敗は「生き残っているチーム」の数で判定されます。

## 参加方法

1. ロビーに設置された **参加看板**（`[BattleRoyale] lobby` と表示）をクリックします。`/btr join` コマンドでも参加できます。
2. ロビーに移動し、アドベンチャーモードで待機します。
3. （任意）`/btr team <チーム名>` で仲間とチームを組みます。
4. OPが `/btr start` でゲームを開始すると、自動でゲームエリアにスポーンします。

ロビーから抜けたいときは **退出看板**（`[BattleRoyale] leave` と表示）をクリックするか、`/btr leave` を実行します。

!!! note "参加できないとき"
    すでにゲームが進行中の場合、ロビーには参加できません。次の試合の開始をお待ちください。ロビーが満員のときも参加できません。

## ゲームの流れ

1. **ロビーに参加** — 参加看板をクリック、または `/btr join` でロビーに入ります。
2. **チーム決め（任意）** — `/btr team <チーム名>` で仲間とチームを組みます。
3. **ゲーム開始** — OPが `/btr start` を実行すると試合が始まります。
4. **ランダムスポーン** — ゲームエリア内のランダムな地点にスポーンします。
5. **装備を集める** — エリア内のチェストからアイテムを回収します。
6. **戦う** — 他のプレイヤーと戦い、生き残りを目指します。
7. **ボーダー縮小** — 一定間隔でワールドボーダーが縮小し、戦場が狭まります。
8. **決着** — 最後の1チームになれば勝利です。試合が終わるとロビーに戻されます。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/btr join` | ロビーに参加する |
| `/btr leave` | ロビーから退出する |
| `/btr team <チーム名>` | 指定したチームに参加する（ロビー参加後・ゲーム開始前のみ） |

!!! note "コマンドのエイリアス"
    `/btr` は `/battleroyale` の短縮形です。どちらでも同じコマンドが使えます。

## よくある質問

??? question "倒されたらどうなりますか？"
    敗北となり、スペクテイター（観戦）モードに切り替わります。試合が終わるまで他のプレイヤーの戦いを観戦できます。

??? question "ゲーム中に落ちてしまいました"
    ゲーム中にログアウトすると **敗北扱い** になります。再接続したときに生存していればサバイバルモードで復帰しますが、すでに敗北扱いになっている場合はスペクテイターになります。

??? question "チームを組まないといけませんか？"
    いいえ。`/btr team` を使わなければ、自分1人が1つのチームとして扱われます。ソロでの参加も可能です。

??? question "ボーダーの外に出るとどうなりますか？"
    ワールドボーダーの外側にいると継続的にダメージを受けます。縮小していく安全地帯の内側に留まりましょう。

??? question "アイテムはどこで手に入りますか？"
    ゲームエリア内に設置されたチェストから入手します。中身は試合ごとにランダムで、開始時に補充されます。
