# Battleroyale ― 遊び方 { .page-player #battleroyale-player }

最後の1チームになるまで戦い抜くバトルロイヤルです。広いゲームエリアにランダムスポーンし、チェストで装備を集め、縮小する安全地帯（ワールドボーダー）の中で生き残りを賭けて戦います。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 最大16人（サーバー設定により変更されることがあります） |
    | 勝利条件 | 最後の1チーム（または1人）として生き残る |
    | リスポーン | なし（倒れるとスペクテイターになります） |
    | 参加方法 | ロビーの参加看板（`[BattleRoyale]` / `lobby` / `クリックで参加` と表示）をクリック |

## どんなゲーム？

ゲームが始まると、参加者はゲームエリア内のランダムな地点にスポーンします。スポーン時は体力・満腹度が満タンになり、サバイバルモードで持ち物は空の状態です。

エリア内に設置された **チェスト** にはランダムなアイテムが補充されています。武器や道具を集めて他のプレイヤーと戦いましょう。時間が経つと **ワールドボーダー（安全地帯）が少しずつ縮小** していくため、いつまでも逃げ続けることはできません。

倒されたプレイヤーは敗北となり、スペクテイター（観戦）モードに切り替わります。最後に生き残ったチームが勝者です。

## ルール

- ゲーム開始時、持ち物はすべてクリアされ、体力・満腹度は満タンになります。
- アイテムはエリア内のチェストから集めます。チェストの中身は試合ごとにランダムです。
- ワールドボーダーは一定間隔で縮小します（既定では60秒ごとに50ブロックずつ縮み、最小サイズ10で停止）。ボーダーの外にいるとダメージを受けるので、内側に留まりましょう。
- 倒されると敗北扱いになり、スペクテイターモードになります。
- ゲーム中に切断（ログアウト）すると **敗北扱い** になります。

## 勝利条件

生き残っているチームが **1チーム（または1人）だけ** になった時点でゲーム終了です。最後まで残ったチームの勝利となり、勝者には花火の演出が打ち上がります。

!!! tip "チームを組むには"
    ロビーに参加したあと `/btr team <チーム名>` を実行すると、同じチーム名のプレイヤー同士が味方になります。チームを組まない場合は、自分1人が1チームとして扱われます。勝敗は「生き残っているチーム」の数で判定されます。

## 参加方法

1. ロビーに設置された **参加看板**（`[BattleRoyale]` / `lobby` / `クリックで参加` と表示）をクリックします。
2. ロビーに移動し、アドベンチャーモードで待機します。
3. （任意）`/btr team <チーム名>` で仲間とチームを組みます。
4. 開始看板のクリックまたは `/btr start`（どちらも全員可）でゲームが始まると、自動でゲームエリアにスポーンします。

ロビーから抜けたいときは **退出看板**（`[BattleRoyale]` / `leave` / `クリックで離脱` と表示）をクリックします。参加・退出は **看板** または **`/btr join`・`/btr leave` コマンド**（どちらも全員使用可）で行えます。

!!! tip "看板は複数の場所にあるかも"
    参加・退出・開始の看板は複数の拠点に設置できるようになりました。ロビーの入口が複数あっても、どの看板からでも参加・退出・開始できます。

!!! note "参加できないとき"
    すでにゲームが進行中の場合、ロビーには参加できません。次の試合の開始をお待ちください。ロビーが満員のときも参加できません。

## ゲームの流れ

1. **ロビーに参加** — 参加看板をクリックしてロビーに入ります。
2. **チーム決め（任意）** — `/btr team <チーム名>` で仲間とチームを組みます。
3. **ゲーム開始** — 開始看板のクリックまたは `/btr start`（どちらも全員可）で試合が始まります。
4. **ランダムスポーン** — ゲームエリア内のランダムな地点にスポーンします。
5. **装備を集める** — エリア内のチェストからアイテムを回収します。
6. **戦う** — 他のプレイヤーと戦い、生き残りを目指します。
7. **ボーダー縮小** — 一定間隔でワールドボーダーが縮小し、戦場が狭まります。
8. **決着** — 最後の1チームになれば勝利です。試合が終わるとロビーに戻されます。

## ソロPvE（1人用）

対戦相手がいないときでも、1人で遊べる **ソロPvE** モードがあります。収縮する範囲の中で敵Mobと戦い、**生き残った時間** を競います。

!!! abstract "はじめかた"
    - ロビーの **ソロ看板** をクリック、または `/btr solo` を実行します。ロビーに入るとソロメニューが開きます。
    - メニューで難易度（**イージー／ノーマル／ハード**）を選ぶと開始します。
    - メニューを閉じても、ホットバーの **「ソロメニュー」（ネザースター）** を右クリック（統合版はタップ）すれば開き直せます。
    - `/btr solo <難易度>` でメニューを通さずにすぐ開始することもできます（例：`/btr solo normal`）。

**ルール**

- フィールドのランダムな場所からスタートし、装備は通常戦と同じく **チェストを漁って** 集めます。
- 少し待つと敵Mobが現れ始めます。時間がたつほど数が増え、体力・攻撃力も上がります。
- 範囲（ボーダー）が一定時間ごとに縮みます。外にいるとダメージを受けます。最小まで縮んだあとは、敵との戦いだけになります。
- 画面上のボスバーに、生存時間・撃破数・次の縮小までの秒数が表示されます。
- **倒れた時点（または制限時間到達時）の生存時間が記録になります。** leave・切断・OPによる停止のときは記録されません。
- 終わるとロビーへ戻り、数秒後にソロメニューが開きます。続けて挑戦できます。

!!! tip "記録とランキング"
    ソロメニューの各難易度ボタンに、自己ベスト・前回の結果・順位・上位3人のランキングが表示されます。統合版の記録も同じランキングに入り、名前の後ろに「(統)」が付きます。難易度の1位を更新すると、サーバー全体にお知らせが流れます。

!!! note "ソロPvE の注意"
    フィールドは通常戦と共用です。通常戦の試合中や、ほかの人がソロに挑戦している間は開始できません（メニューに「使用中」と表示されます）。ソロ中は他のプレイヤーと攻撃し合えず、出てくる敵は挑戦者だけを狙います。敵を倒してもアイテムや経験値は落ちません。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/btr join` | ロビーに参加する（参加看板と同等・全員可） |
| `/btr leave` | ロビーから退出する（退出看板と同等・全員可） |
| `/btr start` | ゲームを開始する（開始看板と同等・全員可） |
| `/btr solo [難易度]` | ソロPvE（1人用）を遊ぶ。引数なしでソロメニュー、難易度指定で即開始（全員可） |
| `/btr status` | 現在の設定・状況を確認する（全員可） |
| `/btr team <チーム名>` | 指定したチームに参加する（ロビー参加後・ゲーム開始前のみ。`battleroyale.play` 権限） |

!!! note "join/leave は全員可／`team` はOP権限が必要"
    ロビーへの参加・退出は **看板のクリック** または **`/btr join`・`/btr leave`**（全員可）で行えます。`/btr team` は既定で `battleroyale.play`（OP）権限が必要なため、一般プレイヤーが使えない場合があります。チーム分けを使う運用では権限プラグインで `battleroyale.play` を付与してください。`/btr` は `/battleroyale` の短縮形です。

## よくある質問

??? question "倒されたらどうなりますか？"
    敗北となり、スペクテイター（観戦）モードに切り替わります。試合が終わるまで他のプレイヤーの戦いを観戦できます。

??? question "ゲーム中に落ちてしまいました"
    ゲーム中にログアウトすると、その時点で **敗北扱い（脱落）** になります。再接続しても試合には復帰できず、「試合中に切断したため脱落しています」と表示されて初期リスポーン地点に戻されます。試合はそのまま残りのプレイヤーで進行し、次の試合からまた参加できます。

??? question "チームを組まないといけませんか？"
    いいえ。`/btr team` を使わなければ、自分1人が1つのチームとして扱われます。ソロでの参加も可能です。

??? question "ボーダーの外に出るとどうなりますか？"
    ワールドボーダーの外側にいると継続的にダメージを受けます。縮小していく安全地帯の内側に留まりましょう。

??? question "アイテムはどこで手に入りますか？"
    ゲームエリア内に設置されたチェストから入手します。中身は試合ごとにランダムで、開始時に補充されます。
