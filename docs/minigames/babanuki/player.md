# ババ抜き（BabaNuki） ― 遊び方 { .page-player #babanuki-player }

トランプ52枚＋ジョーカー1枚を配り、同じ数字のペアを捨てながら手札を減らします。早く上がった順に順位が決まり、最後までジョーカー（ババ）を持っていた人が負けです。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 使うカード | トランプ52枚＋ジョーカー1枚 |
    | 形式 | 対人戦（normal） / CPU練習（cpu） |
    | 人数 | 2〜6人（1人のときは CPU 練習で） |
    | 引く相手 | 次の人（席順で隣）の裏向きの手札から1枚 |
    | 上がり | 手札が0枚になったら上がり（上がった順に順位） |
    | 負け | 最後までジョーカーを持っていた人 |
    | 参加方法 | ロビーの参加看板、または `/baba join` |
    | 画面を開く | 「手札の本」を右クリック／タップ、または `/baba hand` |

## どんなゲーム？

カードが配られると、手札の中の **同じ数字のペアは自動で捨てられます**。あとは順番に、手番の人が **次の人の裏向きの手札から1枚引く** だけ。引いてペアができたら自動で捨て、手札が0枚になった人から **上がり** です。最後に1人だけ残って、その手に **ジョーカー（ババ）** があれば負け。早く上がるほど上位の順位になります。

## 手番の流れ

1. **自分の番** になると、次の人（席順で隣）の裏向きの手札が見えます。並びは毎回シャッフルされているので、位置からジョーカーは分かりません。
2. ホットバーの **「手札の本」**（右クリック／タップ）または `/baba hand` で画面を開き、引きたいカードを1枚選びます。
3. 引いたカードでペアができれば **自動で捨てます**。
4. 次は **引かれた人** が、そのまた次の人から引く番になります（引かれた人がちょうど上がっていれば、その次の人へ）。

!!! note "制限時間"
    既定では手番に **制限時間はありません**（`turn-seconds: 0`）。運営が制限時間を設定している場合は、時間切れになると **ランダムに1枚** 引きます。

## 上がりと順位・ジョーカー

- 手札が0枚になると **上がり**。上がった順に1位・2位…と順位が付きます。
- 引かれて手札が0枚になった人も、そのタイミングで上がれます。
- 最後まで残った1人がジョーカーを持っていれば **負け（ババ）**。ほかの全員が抜けて1人だけ残った場合は不戦勝です。
- 最初の配りでジョーカーを持っていると、画面に知らせが出ます（焦らず、引かれるのを待ちましょう）。

## 形式（対人戦・CPU練習）

| 形式 | 識別子 | 内容 |
|---|---|---|
| 対人戦 | `normal` | 参加者だけで遊ぶ。2人以上必要 |
| CPU練習 | `cpu` | 人数が足りないぶんをCPUで補う。1人でも遊べる |

CPU練習では、人間の出場者が全員抜けると（設定により）CPU同士で続けずに試合を終えます。

## 参加方法

1. ロビーの **参加看板** をクリック、または `/baba join`。
2. 人数がそろったら **開始看板** をクリック、または `/baba start [normal|cpu]`（全員可）で開始。形式を省略するとサーバー既定の形式になります。
3. 自分の番になったら、ホットバーの **「手札の本」**（右クリック／タップ）または `/baba hand` で画面を開いて引きます。

出場できるのは参加順に最大6人まで。あふれた人はロビーで待機し、次の試合から出場できます。離脱は **離脱看板** か `/baba leave` です。試合中に離脱すると、手札は次の人へまとめて渡され、脱落扱いになります。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/baba join` | ロビーに参加する（参加看板と同等） |
| `/baba leave` | ロビーから離脱する（離脱看板と同等。試合中は脱落扱い） |
| `/baba start [normal\|cpu]` | 試合を開始する（開始看板と同等・全員可。省略時は既定の形式） |
| `/baba hand` | 手札の画面を開く（「手札の本」と同じ） |
| `/baba status` | 設定・状況を確認する（全員可） |

## よくある質問

??? question "相手の手札のどこにジョーカーがあるか分かりますか？"
    いいえ。相手の手札は裏向きで、並びは **手番ごとにシャッフル** して見せられます。位置からジョーカーを見分けることはできません。

??? question "1人でも遊べますか？"
    はい。`cpu` で開始すると、人数が足りないぶんを **CPU** が埋めます。対人戦（`normal`）には2人以上が必要です。

??? question "引いた瞬間にペアになったら？"
    **自動で捨てられます**。自分で選んで捨てる操作は不要です。

??? question "途中で抜けたらどうなりますか？"
    その人の手札は **次の人へまとめて渡され**、ペアがあれば自動で捨てられます。本人は脱落扱いになります。
