# 椅子取りゲーム（MusicChair） ― 遊び方 { .page-player #musicchair-player }

音楽が流れている間はステージを歩き、**曲が止まったら椅子に座る** 勝ち抜きゲームです。椅子は毎ラウンド「生存者 − 1脚」。座れなかった人が脱落し、最後に残った1人が優勝です。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | サバイバル勝ち抜き（最後の1人が優勝） |
    | 人数 | 3〜16人（既定。サーバーにより変わります） |
    | ラウンドの流れ | 曲が流れる（既定8〜20秒）→ 曲が止まる → 座る（既定5秒以内） |
    | 椅子の数 | 毎ラウンド「生存者 − 1脚」 |
    | 勝利条件 | 生存者が1人になったら優勝（0人なら引き分け） |
    | 参加方法 | ロビーの参加看板、または `/mchair join` |

## どんなゲーム？

試合が始まると全員がステージに集められ、ラウンドが繰り返されます。各ラウンドは **曲が流れるフェーズ** と、**曲が止まって座るフェーズ** の2つです。

1. 曲が流れている間は、椅子の近くに入れません。ステージを **歩き回って** 待ちます。
2. 曲が **止まった瞬間**、ステージに椅子ブロックが出現します。
3. いちばん近い **椅子の上に乗る** と座れます。椅子は生存者より1脚少ないので、1人だけ座れません。
4. 座れなかった人が **脱落**。生存者が1人になるまで繰り返し、最後の1人が優勝です。

## ラウンドの流れ

1. **曲フェーズ（既定8〜20秒のランダム）** … 曲が流れます。いつ止まるかはわかりません。椅子の近くには入れないので、ステージを歩いて待ちます。
2. **フェイクストップ（引っかけ）** … まれに曲が **一瞬だけ止まってまた流れます**（椅子は出ません）。慌てて座りに行かないように注意。
3. **曲が止まる → 座るフェーズ（既定5秒）** … 椅子ブロックが出ます。残り時間はボスバーで表示されます。制限時間内に座れないと脱落です。
4. **ラウンド間（既定3秒）** … 脱落者を発表し、次のラウンドへ。ラウンドが進むほど **曲のテンポが速く・短く** なっていきます。

!!! tip "座り方のコツ"
    曲が止まったら、出現した **椅子ブロックの真上（または1マス上）に乗る** だけで自動的に座ります。最初に座れた人には「一番乗り！」と表示されます。間違えて座ってしまっても、**スニークで一度降りれば** 制限時間内なら座り直せます（他の椅子が空いていれば移れます）。

## 椅子に近づけない「立入禁止エリア」

曲が流れている間は、**椅子のまわりに立入禁止エリア** ができます。椅子のそばで待ち伏せしようと近づくと、**外側へ弾き飛ばされます**（「椅子に近づきすぎ！」と表示）。エリアの広さは、椅子の配置と設定で決まります。曲が止まるまでは、エリアの外を歩いて待ちましょう。

## 立ち止まり対策

曲の間に **同じ場所でじっとしていると**、まず警告（「立ち止まらずに歩こう！」）が出て、それでも動かないと **弾き飛ばされます**。椅子の近くに陣取って動かない作戦はできません。ちゃんと歩き回ってください（この対策はサーバー設定でオフにもできます）。

!!! note "フィールドの外に出たら"
    ステージに試合範囲（フィールド）が設定されている場合、範囲の外に出ると自動で開始位置へ戻されます。

## 曲について

- 流れる曲は、サーバーが用意した **.nbs（Note Block Studio）ファイル** です。ラウンドごとにランダムに選ばれます。
- ラウンド開始時に **曲名と作者** がアクションバーに表示されます（設定による）。
- ラウンドが進むほど、曲のテンポが少しずつ速くなり、曲が止まるまでの最長時間も短くなっていきます。

## 脱落と観戦

- 座れずに脱落すると、**生存者の視点で観戦** します（「生存者の視点で観戦します」と表示）。
- 観戦中は **スニークで見る人を切り替え** られます。見ていた人が脱落したら、自動で別の生存者に切り替わります。
- 試合が終わると全員ロビーへ戻ります。

## 参加方法

1. ロビーの **参加看板** をクリック、または `/mchair join`。
2. 人数が集まったら **開始看板** のクリック、または `/mchair start`（全員可）でカウントダウン開始。
3. 離脱は **離脱看板** か `/mchair leave`。

試合の進行中に参加した場合は、**次の試合から** 参加になります（ロビーで待機）。試合中に離脱・切断すると脱落扱いになり、戻れません。

!!! note "持ち物について"
    ロビーに入った時点で、元の持ち物は安全に預かられ、離脱すると元どおり戻ります。試合中は手ぶらで、椅子取りに集中できます。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/mchair join` | ロビーに参加する（参加看板と同等・全員可） |
| `/mchair leave` | ロビーから離脱する（離脱看板と同等。試合中は脱落扱い・全員可） |
| `/mchair start [識別子]` | ゲームを開始する（開始看板と同等・全員可） |
| `/mchair status` | 現在の設定・状況を確認する（全員可・読み取り専用） |

!!! tip "コマンドの別名"
    メインコマンドは `/musicchair` ですが、短い `/mchair` でも同じように使えます。

## よくある質問

??? question "曲が一瞬止まったのに椅子が出ませんでした。"
    それは **フェイクストップ** です。曲が一瞬だけ止まってまた流れる引っかけで、椅子は出ません。本当に止まると椅子ブロックが出現し、ボスバーで残り時間が表示されます。

??? question "椅子に近づけず弾かれます。"
    曲が流れている間は、椅子のまわりが立入禁止エリアになっています。曲が止まるまでは、エリアの外を歩いて待ってください。曲が止まれば近づいて座れます。

??? question "間違えて座ってしまいました。座り直せますか？"
    座るフェーズの制限時間内なら、**スニークで一度降りて** から別の椅子へ座り直せます。ただし他の椅子が空いている必要があります。

??? question "自分の装備は使えますか？"
    使いません。ロビーに入ると持ち物は預かられ、試合中は手ぶらです。離脱すると元どおり戻ります。

??? question "誰も座れなかったらどうなりますか？"
    全員が座れなかった（＝全員脱落になる）ラウンドは **やり直し** になります。誰かが脱落するまでラウンドは成立しません。
