# SplatoonPlugin ― 遊び方 { .page-player #splatoon-player }

Minecraftでスプラトゥーンを再現したナワバリバトルです。オレンジチームとブルーチームに分かれ、ブキでフィールドの床を自分のチームの色に塗り合います。制限時間が終わったとき、より広く塗っていたチームの勝ちです。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 2〜8人（オレンジ vs ブルー・既定値） |
    | 1試合の長さ | 3分（180秒・既定値） |
    | 勝利条件 | 制限時間終了時に床をより広く塗っているチームが勝ち |
    | リスポーン | あり（やられると約3秒後に自チームスポーンへ復活） |

## どんなゲーム？

オレンジチームとブルーチームに分かれて戦います。各プレイヤーは6種類のブキを持ち、フィールドの床にインクを塗っていきます。

塗れるのは床の **表面ブロック** で、自分のチームの色（オレンジ／ブルーのコンクリート）に変わります。制限時間（3分）が終わったとき、**塗られた床のうち自チームの色が占める割合が多いほうのチームが勝利** します。両チームの塗り面積が同じ場合は引き分けです。

## ゲームの流れ

1. **参加する** — ロビーにある参加看板を右クリックしてゲームに加わります。退出するには **離脱看板** を右クリックしてください。
2. **カウントダウン** — 2人以上が集まると、ロビーフェーズに入り **30秒** のカウントダウンが始まります。
3. **チーム分け** — オレンジ／ブルーの2チームに自動で振り分けられます（人数はほぼ均等になります）。
4. **試合開始** — 各チームのスポーン地点へ飛ばされ、チームカラーの革防具とブキ一式が配られます。「GO!」の表示で開始。
5. **塗り合う** — 3分間、ブキで床を塗り、敵プレイヤーを倒しながらナワバリを広げます。
6. **リザルト** — 制限時間が終わると塗り面積が集計され、勝敗が表示されます。
7. **ロビーへ復帰** — フィールドが元の状態に復元され、参加していたメンバーはロビーに戻ります。人数が揃っていれば続けて次の試合が始まります。

## ルールと勝利条件

!!! tip "塗った面積の「割合」で勝負"
    勝敗は「塗られた床のうち、どちらの色が多いか」で決まります。未塗りの床は計算から除外されるため、リザルトでは両チームの合計が100%になるように表示されます（例: オレンジ60% / ブルー40%）。

- 試合時間は **3分（180秒・既定値）** です。残り時間は画面のタイトルで定期的に表示されます。
- 床はブキで塗るほか、**自分が歩いた足元も自動で塗られます**。
- 敵チームのインクの上に乗ると移動速度が遅くなります。
- やられても試合からは抜けません。約3秒後に自チームのスポーン地点へ復活します。
- ブキを持って敵に **近接攻撃を当てる** とインクダメージが入ります（ローラーが最も威力が高く、ボム＞シューターと続きます）。

## ブキとインク

試合開始時、ホットバーに6種類のブキとスペシャル発動アイテムが配られます。それぞれ塗り方・射程・クールダウンが異なります。

| スロット | ブキ | 見た目 | 特徴 |
|---|---|---|---|
| 1 | シューター | 弓 | 標準的なブキ。矢を撃って着弾点を塗る。塗り半径1 |
| 2 | スプラッシュボム | 雪玉 | 投げて広範囲（半径3）を塗る。クールダウン長め |
| 3 | チャージャー | 棒 | 右クリックで前方20ブロックへ直線射撃。命中で敵を一撃 |
| 4 | ブラスター | クロスボウ | 爆発系の弾で広範囲（半径3）を塗る |
| 5 | ローラー | 鉄のシャベル | 右クリックで前方の床を塗る。近接ダメージが高い |
| 6 | スロッシャー | バケツ | 左クリックで前方を扇状に塗る。近距離の敵にも当たる |
| 9 | スペシャル発動 | ネザースター | ゲージ100%で右クリック発動（後述） |

!!! note "ブキの使い方"
    - **シューター・ブラスター** … 弓／クロスボウとして発射します。
    - **スプラッシュボム** … 雪玉として投げます。
    - **ローラー・チャージャー** … 右クリックで使用します。
    - **スロッシャー** … 左クリックで使用します。

### インク（ゲージ管理）

- ブキを使うとインクを消費します。インクが切れるとブキが使えません。
- **スニーク（しゃがみ）でイカに変身している間、自チームのインク上にいるとインクが回復** します。
- 残りインク量は経験値バー、スペシャルゲージはレベル表示として画面に出ます。

### イカ変身

自チームのインクで塗られた床の上で **スニーク（しゃがむ）** すると、イカに変身します。

- イカ状態では **自チームのインク上を高速移動** でき、姿が見えにくくなります。
- イカ状態ではブキを使えません。
- 敵チームのインクの上に乗ると、イカ変身が強制的に解除されます。

### スペシャル技

床を塗ったり敵を倒したりするとスペシャルゲージが溜まります。**ゲージが100%になったら、スペシャル発動アイテム（スロット9）を右クリック**、または **Fキー（オフハンド切り替え）** で発動できます。

発動すると「インクバズーカ」が作動し、自分の周囲を一気に塗り広げます。

## チーム

- 参加時に **オレンジ** または **ブルー** のどちらかへ自動で振り分けられます。
- チームカラーの革防具が自動で装備されます（オレンジ＝橙、ブルー＝青）。
- 同じチームのプレイヤーには攻撃が当たりません。

## 参加方法

ゲームへの参加は **ロビーに設置された参加看板** から行います。

- 看板を **右クリック** するとロビーに参加します（参加看板を再クリックしても退出はできません。「既にロビーに参加しています」と表示されます）。
- 退出するにはロビーに設置された **離脱看板** を右クリックしてください。
- 2人以上集まると自動でカウントダウンが始まります。

!!! note "参加はコマンドではなく看板から"
    プレイヤーがゲームに参加するためのコマンドはありません。必ずロビーの参加看板から参加してください。

## プレイヤー用コマンド

SplatoonPlugin のコマンド `/splatoon` は **すべて管理者（OP）専用** で、一般プレイヤーが普段使うコマンドはありません。参加・退出・ブキの使用はすべて看板とブキ操作で行います。

| 操作 | 方法 |
|---|---|
| ゲームに参加 | ロビーの参加看板を右クリック |
| ゲームから退出 | ロビーの離脱看板を右クリック |
| ブキを使う | ブキを持って右クリック／左クリック（ブキにより異なる） |
| イカに変身 | 自チームのインク上でスニーク |
| スペシャル発動 | ゲージ100%でスペシャルアイテムを右クリック、またはFキー |

## よくある質問

??? question "どうやってゲームに参加しますか？"
    ロビーに設置された参加看板を右クリックしてください。2人以上集まると自動でカウントダウンが始まり試合が開始されます。退出する場合は離脱看板を右クリックしてください（参加看板を再クリックしても退出できません）。

??? question "やられたらゲームから抜けてしまいますか？"
    抜けません。やられても約3秒後に自チームのスポーン地点へ復活し、そのまま試合を続けられます。

??? question "イカに変身できません"
    イカ変身は **自分のチームのインクで塗られた床の上** でのみできます。未塗りの床や敵チームのインク上ではスニークしても変身できません。

??? question "ブキが撃てなくなりました"
    インク切れの可能性があります。スニークしてイカ変身し、自チームのインク上にいるとインクが回復します。

??? question "勝敗はどう決まりますか？"
    制限時間（3分）終了時、塗られた床のうち自チームの色が占める割合が多いほうの勝ちです。両チームが同じ割合の場合は引き分けになります。

??? question "敵に近接攻撃しても倒せますか？"
    倒せます。ブキを手に持って敵を殴ると、ブキ種別に応じたインクダメージが入り、相手のインクゲージが0になるとやられた扱いになります。**ローラー** が最も近接ダメージが高く、**スロッシャー** が次点です。なお、イカ変身中は攻撃できません。
