# SplatoonPlugin ― 遊び方 { .page-player #splatoon-player }

Minecraftでスプラトゥーンを再現した塗り合いバトルです。オレンジチームとブルーチームに分かれ、自分で選んだブキで床を塗り、敵を倒しながらルールに沿って勝利を目指します。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 2〜8人（オレンジ vs ブルー・既定値） |
    | 1試合の長さ | 3分（180秒・既定値） |
    | モード | ナワバリ／ガチエリア／ガチホコ／ガチヤグラ（運営が設定） |
    | ブキ編成 | メイン9種・サブ6種・スペシャル5種から選択 |
    | リスポーン | あり（やられると約3秒後に自チームスポーンへ復活） |

## どんなゲーム？

オレンジチームとブルーチームに分かれて戦います。ブキで床にインクを塗り、敵を倒し、モードごとのルールで勝敗を競います。塗れるのは決められた **表面ブロック** で、塗ると自チームの色（オレンジ／ブルー）に変わります。

ブキは試合前に **ブキ選択看板** から自由に編成できます（メイン・サブ・スペシャルを各1つ）。

## ゲームの流れ

1. **参加する** — ロビーの参加看板を右クリック。退出は離脱看板を右クリックします。
2. **ブキを選ぶ** — ロビーの **ブキ選択看板** をクリックしてGUIを開き、メイン・サブ・スペシャルを選びます（選択は次の試合にも引き継がれます）。
3. **カウントダウン** — 2人以上集まると30秒のカウントダウン後に試合開始。
4. **チーム分け** — オレンジ／ブルーに自動で振り分けられ、各スポーンへ飛ばされます。
5. **戦う** — 床を塗り、敵を倒し、モードのルールを進めます。
6. **リザルト** — 制限時間終了かノックアウトで決着。勝敗が表示されます。
7. **ロビーへ復帰** — フィールドが元に戻り、参加状態を維持したままロビーへ。人数が揃えば次の試合へ。

## 対戦モード

運営の設定により、次のいずれかで対戦します。

| モード | 勝ち方 |
|---|---|
| ナワバリ | 制限時間終了時、塗った床の割合が高いチームの勝ち |
| ガチエリア | 2つのエリアを70%以上塗って確保。両方を確保し続けてカウントを先に0にする |
| ガチホコ | 中央のホコを持って敵のゴール台まで運ぶ |
| ガチヤグラ | ヤグラに乗って占有し、敵陣方向へ押し込む |

## ブキ編成

ロビーの **ブキ選択看板** をクリックすると編成GUIが開きます。**上段＝メイン9種・中段＝サブ6種・下段＝スペシャル5種** から、それぞれ1つずつ選びます。選択はサーバー内で保持され、次の試合にも引き継がれます（サーバー再起動でリセットされ、初期はシューター／スプラッシュボム／インクバズーカ）。

=== "メインブキ（9種）"

    | ブキ | 操作 | 特徴 |
    |---|---|---|
    | シューター | 左クリック（弓） | 標準。着弾点の床を塗る |
    | プライムシューター | 左クリック（弓） | 長射程のシューター |
    | ブラスター | 左クリック（クロスボウ） | 爆発系で広めに塗る |
    | ローラー | 右クリック | 前方を薙ぎ塗り。近接が強い・低燃費 |
    | フデ | 右クリック | 細く高速に塗る。最速・低燃費 |
    | チャージャー | 右クリック | 約1秒チャージ後、前方20mへ直線レーザー。直撃で一撃 |
    | スロッシャー | 左クリック | 前方を扇状に塗り、近距離の敵に当たる |
    | スピナー | 右クリック | 6連射で着弾を塗る |
    | マニューバー | 右クリック | 3連射。スニークで前方に回避ロール |

=== "サブウェポン（6種）"

    | サブ | 操作 | 効果 |
    |---|---|---|
    | スプラッシュボム | 右クリックで投げる | 着弾で広範囲を塗る |
    | キューバンボム | 右クリックで投げる | 着弾後に遅れて爆発。範囲塗り＋敵を倒す |
    | カーリングボム | 右クリックで投げる | 床を滑りながら塗り進み、止まると爆発 |
    | ポイントセンサー | 右クリックで投げる | 当たった付近の敵を一定時間 発光させ位置を暴く |
    | トラップ | 右クリックで設置 | 敵が近づくと作動し塗り＋鈍足＋発光 |
    | スプリンクラー | 右クリックで設置 | 一定時間 周囲を継続して塗る |

=== "スペシャル（5種）"

    ゲージ100%で発動。**Fキー（オフハンド切り替え）またはスロット8のアイテムを右クリック** で使います。

    | スペシャル | 効果 |
    |---|---|
    | インクバズーカ | 自分の周囲を大きく塗る |
    | スーパーチャクチ | 周囲を塗りつつ近くの敵を吹き飛ばして倒す |
    | メガホンレーザー | 前方へレーザー。経路の床を塗り敵を倒す |
    | インクアーマー | 味方全員に耐性＋吸収を付与し、インクを全回復 |
    | アメフラシ | 指定地点に一定時間 雨のように塗り続ける |

## ルールと操作

- 床はブキで塗るほか、自分が歩いた足元も塗られます。塗れる床は決まったマテリアルのみです（運営設定のフィールド内）。
- **敵チームのインクの上は移動が遅くなり、イカ変身も解除** されます。
- やられても抜けません。約3秒後に自チームのスポーンへ復活します（一時無敵）。落下ダメージは無効。

### 画面表示（HUD）

試合中は画面に次の情報が表示されます。

- **残り時間バー** … 画面上部のボスバーに残り時間が表示されます。残り60秒で黄色、残り30秒で赤色に変わります。
- **アクションバー（画面中央下）** … モードに応じた状況が出ます。ナワバリは両チームの塗り割合、ガチエリア／ガチホコ／ガチヤグラは両チームの残りカウントと確保・運搬・占有の状況。末尾に自分のスペシャルゲージ（`S:◯%`）も表示されます。
- **経験値バー＝インク残量／レベル表示＝スペシャルゲージ** … 経験値ゲージが現在のインク量、レベル数値がスペシャルゲージ（%）を表します。

!!! note "スペシャルゲージは100%で発動可能"
    塗りや撃破でゲージが溜まります。レベル表示（または アクションバーの `S:◯%`）が100になったら発動できます。

### インク管理

ブキを使うとインクを消費します。**スニーク（しゃがみ）でイカに変身し、自チームのインク上にいるとインクが回復** します。インク切れだと攻撃できません。

### イカ変身

自チームのインクの上で **スニーク** するとイカに変身し、高速移動・透明化・インク回復ができます（攻撃は不可）。敵インクの上では強制解除されます。

## 参加方法

参加・退出・開始は **看板** でも **コマンド** でも行えます（ブキ選択は看板から）。

- 参加看板を右クリック／`/splatoon join` → ロビー参加。
- 離脱看板を右クリック／`/splatoon leave` → 退出。
- ブキ選択看板を右クリック → 編成GUI。
- 開始看板（モード別）を右クリック／`/splatoon start <turf|area|hoko|tower>` → そのモードで試合開始。

!!! note "join / leave / start は全員が使えます"
    これらのコマンドは権限不要で全プレイヤーが使えます。`/splatoon start <モード>` はそのモードに設定して開始します。開始看板はモードごとに用意されている場合があります。

## よくある質問

??? question "ブキはどこで選びますか？"
    ロビーの **ブキ選択看板** をクリックすると編成GUIが開きます。メイン・サブ・スペシャルを各1つ選べます。選択は次の試合にも引き継がれますが、サーバー再起動でリセットされます。

??? question "スペシャルはどう使いますか？"
    塗りや撃破でゲージが溜まり、100%で発動できます。**Fキー**（オフハンド切り替え）か、**スロット8のスペシャルアイテムを右クリック** してください。

??? question "やられたらゲームから抜けてしまいますか？"
    抜けません。約3秒後に自チームのスポーンへ復活します。

??? question "イカに変身できません / ブキが撃てません"
    イカ変身は自チームのインクの上だけで可能です。ブキが撃てないときはインク切れの可能性があるので、イカで自陣インク上に潜って回復してください。

??? question "勝敗はどう決まりますか？"
    モードによります。ナワバリは塗り割合、ガチエリア/ガチホコ/ガチヤグラはカウントを先に0にする（ノックアウト）か、時間切れ時に有利な方が勝ちです。

## サーモンラン（PvE協力モード）

対戦とは別の **協力モード** です。みんなで力を合わせて押し寄せる **シャケ（ゾンビ系の敵）** を倒し、**金イクラ** を集めて **コンテナ** へ納品し、WAVEごとのノルマを達成します。チーム分けはなく、参加者全員が味方です。

!!! abstract "クイック情報（サーモンラン）"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 1人〜（ロビーに集まった人で開始） |
    | 形式 | WAVE制・ノルマ達成型の協力PvE |
    | WAVE数 | 既定3WAVE（ステージ設定で変更可） |
    | ノルマ | 既定 7／12／18個（WAVEごと・設定で変更可） |
    | 制限時間 | 既定100秒／WAVE |
    | やられたとき | ウキワ状態（ダウン）になり、味方が近づくと復活 |

### 流れ

1. **参加する** — サーモンラン用の **参加看板** を右クリック（または `/salmon join`）してロビーへ。
2. **開始** — 運営またはプレイヤーが **開始看板**（または `/salmon start <ステージ>`）でステージを開始。基地スポーンへ飛ばされ、ブキ一式が支給されます。
3. **WAVE開始** — 満潮／干潮どちらかでフィールドが決まり、シャケが湧き始めます。
4. **シャケを倒す** — ブキのインク弾でシャケにダメージを与えて倒します。**オオモノシャケ**（後述）を倒すと **金イクラ** が出現します。
5. **金イクラを納品** — 落ちている金イクラを拾い（運搬中は移動が遅くなります）、**コンテナ** に近づくと自動で納品されます。
6. **ノルマ達成** — 制限時間内にノルマ個数を納品すればWAVEクリア。次のWAVEへ進みます。全WAVEクリアで **CLEAR!**、時間切れでノルマ未達か全員ダウンで **FAILED**。

### オオモノシャケ（3種）

金イクラの主な供給源です。弱点が決まっているので狙い方が重要です。

| オオモノ | 弱点・攻略 |
|---|---|
| バクダン | 頭の **弱点（光る部分）** だけが有効。一定間隔で範囲爆撃してくる |
| テッパン | **正面は装甲で無効**。背後・側面を攻撃する（正面から殴ると弾かれる） |
| タワー | 縦に積まれた段の **最上段だけ** 破壊可能。全段壊すと撃破。遠距離から狙撃してくる |

撃破すると金イクラが複数（既定3個）出現します。

### ダウンと救助

サーモンランでは、致命傷を受けても即離脱にはならず **ウキワ状態（ダウン）** になります。一定時間（既定12秒）以内に **味方が近づく** と復活します。運搬中の金イクラはダウン時にその場へ落ちます。救助されないまま時間切れになると戦線離脱、**全員がダウンするとそのWAVEは失敗** です。

### ブキについて

サーモンランでは開始時に **ブキ一式が自動支給** されます。インク弾（飛び道具）がシャケへのダメージ源になります。チャージャーなどの直線レーザー系は飛び道具を出さないため、現状シャケへのダメージには向きません。

!!! note "対戦（PvP）とは同時に動きません"
    サーモンランと通常の対戦は戦闘システムを共有しているため、**PvP対戦が進行中はサーモンランを開始できません**（逆も同様）。

### サーモンランのコマンド（全員可）

```text title="ロビーに参加"
/salmon join
```
```text title="ロビーから退出"
/salmon leave
```
```text title="ステージを開始（看板でも可）"
/salmon start <ステージ>
```
```text title="設定・進行状況を確認（ステージ名は任意）"
/salmon status [ステージ]
```

??? question "サーモンランは何人から遊べますか？"
    1人から開始できます。ロビーに集まった人数でそのまま始まります。

??? question "金イクラはどうやって集めますか？"
    主にオオモノシャケを倒すと出現します。落ちている金イクラを拾って **コンテナ** へ運び、近づくと自動で納品されます。運搬中は移動が遅くなります。

??? question "やられたら終わりですか？"
    すぐには終わりません。ダウン（ウキワ）状態になり、味方が近づけば復活します。ただし全員が同時にダウンするとそのWAVEは失敗になります。
