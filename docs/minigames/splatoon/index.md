# SplatoonPlugin <span class="badge done">公開中</span>

Minecraft上でスプラトゥーンを再現した **ナワバリバトル風ミニゲーム** です。オレンジとブルーの2チームに分かれ、ブキでフィールドの床にインクを塗り合い、制限時間終了時により広く塗ったチームが勝利します。イカに変身しての高速移動や、6種類のブキ、スペシャル技も実装されています。

!!! note "ゲームの特徴"
    床を塗り合うナワバリバトルです。2〜8人に対応し、参加時にオレンジ／ブルーの2チームへ自動で振り分けられます。参加・退出は専用看板のクリックで行い、制限時間（3分）の終了時にフィールドをより多く塗ったチームが勝ちます。スニークでイカに変身すると自チームのインク上を高速移動でき、6種のブキとスペシャル技を駆使して戦います。
