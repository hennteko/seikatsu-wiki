# SplatoonPlugin <span class="badge done">公開中</span>

Minecraft上でスプラトゥーンを再現した **塗り合いミニゲーム** です。オレンジとブルーの2チームに分かれ、自分で編成したブキで床を塗り合います。**メイン9種・サブ5種・スペシャル5種** から編成でき、**ナワバリ／ガチエリア／ガチホコ／ガチヤグラ** の4モードに対応しています。イカに変身しての高速移動やスペシャル技も実装されています。

!!! success "v2.0.0 の特徴（ブキ刷新＆ガチマッチ）"
    床を塗り合う対戦ゲームです。2〜8人に対応し、参加時にオレンジ／ブルーの2チームへ自動で振り分けられます。参加・退出・ブキ選択・開始は専用看板で行います。**ブキ選択看板からメイン9種・サブ5種・スペシャル5種を自由に編成**でき、対戦は **ナワバリ／ガチエリア／ガチホコ／ガチヤグラ** の4モード（運営が設定）。スニークでイカに変身すると自チームのインク上を高速移動できます。
