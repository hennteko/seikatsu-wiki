# DBD（デッドバイデイライト風）― 遊び方 { .page-player #dbd-player }

**鬼（キラー）** と **逃げ（サバイバー）** に分かれる非対称ホラー鬼ごっこです。逃げは発電機を修理して通電させ、脱出ゲートから逃げ切れば勝ち。鬼は逃げをダウンさせ担いでフック（処刑台）に吊るし、全員を処刑すれば勝ちです。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 2〜20人（最低2人 / 鬼1＋逃げ1〜） |
    | 役割 | 鬼（キラー）／逃げ（サバイバー） |
    | 鬼の数 | 総人数で自動決定（既定：2〜6人=1 / 7〜11人=2 / 12〜16人=3 / 17〜20人=4） |
    | 勝利条件 | 逃げ：発電機を全修理してゲート／ハッチから脱出／鬼：逃げを全員処刑（ダウン放置の出血 or 3回吊り） |
    | 制限時間 | 明確な制限時間なし（決着＝全員脱出／死亡、または運営の強制終了） |

## どんなゲーム？

参加者は開始時に **鬼** と **逃げ** に自動で振り分けられます。鬼の数は総人数で決まり、既定では2〜6人なら鬼1人、7人以上で段階的に増えます。事前に `/dbd killer` で **鬼希望** をONにしておくと、鬼に選ばれやすくなります。

逃げの目的は **発電機（既定で逃げ人数＋1台）をすべて修理して「通電」させ、脱出ゲートを開けて逃げ切る** こと。鬼の目的は **逃げを攻撃してダウンさせ、担いでフックに吊るし、全員を処刑する** ことです。

鬼は移動速度が逃げより速く（既定倍率1.3）、攻撃用の「処刑者の鉈」を持ちます。逃げは板を倒したり窓を乗り越えたりして鬼のチェイス（追跡）を振り切りながら、協力して発電機を回します。

## ゲームの流れ

1. **参加する** — ロビーに設置された参加看板をクリック、または `/dbd join` でロビーに入ります。
2. **（任意）鬼希望を設定** — `/dbd killer` で鬼希望をON/OFFできます。ONだと鬼に選ばれやすくなります。
3. **（任意）パークを選ぶ** — `/dbd perk` でパーク選択GUIを開き、鬼用・逃げ用それぞれ最大4つまで能力を選べます（自動保存）。
4. **開始** — 運営または開始看板でゲームが始まると、役割が抽選され「あなたは 鬼」「あなたは 逃げ」のタイトルが表示され、各スポーンへ移動します。
5. **修理＆チェイス** — 逃げは発電機を修理し、鬼は逃げを追ってダウンを狙います。
6. **通電** — 発電機が全台修理されると通電し、ボスバーが「ゲートを開けて脱出せよ！」に変わります。
7. **脱出** — 逃げは脱出ゲートを開けてその先へ。最後の1人になるとハッチ（脱出口）が開きます。
8. **決着** — 逃げが全員脱出または全員死亡すると試合終了。結果が表示され、しばらくすると自動でロビーへ戻ります。

## ルール・仕様

!!! info "ダメージ・空腹は特殊仕様です"
    試合中は **落下や環境などのダメージが無効** で、**空腹（満腹度の減少）も無効** です。ダメージ・体力の変化は「鬼の攻撃」「負傷」「ダウン」といったゲーム状態としてのみ扱われます。インベントリの操作・アイテムのドロップもできません。

- 逃げの状態は **健康 → 負傷 → ダウン** と段階的に悪化します。鬼の攻撃を受けると、健康なら負傷、負傷ならダウンします。
- **心音** … 鬼が近づくと逃げに心音（ドラム音）が鳴り、距離が近いほど間隔が短くなります（8m以内で最速）。鬼が向いている方向には **赤い光（ステイン）** のパーティクルが表示され、鬼の視線の向きが分かります。
- 発電機の残り台数・通電状況は画面上部の **ボスバー** に表示されます。各アクション（修理・治療・救助・板破壊・乗り越え・もがき等）の進行度は画面下の **アクションバー** に表示されます。
- 途中でログアウトすると初期スポーン地点へ戻され、試合／ロビーから外れます。

## 役割と装備

=== "👹 鬼（キラー）"

    逃げを全員処刑するのが役目です。

    | 特徴 | 内容 |
    |---|---|
    | 装備 | 処刑者の鉈（鉄の剣・耐久無限） |
    | 移動速度 | 逃げより速い（既定倍率1.3・上限あり） |
    | 攻撃 | 逃げを **殴る** と 健康→負傷／負傷→ダウン。攻撃後は硬直＋攻撃クールダウン（既定5秒・処刑者の鉈にゲージ表示）がある |
    | 担ぎ | ダウンした逃げを **右クリック** で担ぎ、フックへ運ぶ |
    | フック | 担いだ状態でフック（処刑台）を **右クリック** で吊るす（3回で処刑） |
    | 発電機蹴り | 修理中でない発電機を **右クリック** で蹴り、進行度を後退させる |
    | 板破壊 | 倒された板を **右クリック** で破壊する（破壊中は動けない） |
    | 窓乗り越え | 窓を **右クリック** で乗り越える（逃げより時間がかかる） |
    | ハッチ | 開いたハッチを **右クリック** で閉じられる（ゲート勝負に持ち込む） |

    逃げに **板を至近で倒される** とスタンし、一定時間動けなくなります。逃げの **スキルチェック失敗** の音で位置の手がかりが得られます。

=== "🏃 逃げ（サバイバー）"

    発電機を修理して脱出するのが役目です。

    | 特徴 | 内容 |
    |---|---|
    | 装備 | 自力脱出アイテム（トリップワイヤーフック・全員に配布）＋選んだ逃げパークのアビリティアイテム |
    | 移動速度 | 標準（既定0.2） |
    | 発電機修理 | 発電機を **右クリック** で修理開始。留まると進行、スキルチェックあり |
    | スキルチェック | 修理中にゲージが出たら **左クリック** で判定（成功で継続、グレイトでボーナス、失敗で後退＆位置バレ） |
    | 板 | 立っている板を **右クリック** で倒す（至近の鬼をスタン） |
    | 窓 | 窓を **右クリック** で乗り越える |
    | 救助・治療 | 仲間を **右クリック**（ダウン救助・フック救助・治療） |
    | もがき | 担がれたら **スニーク連打** で脱出を試みる（成功すると鬼を一定時間スタンさせて逃げられる） |
    | 自力脱出 | フックに吊られている間、**自力脱出アイテム（トリップワイヤーフック）を右クリック** で低確率脱出を試みる（失敗すると吊りカウントが減る） |

    負傷すると **うめき（パーティクル）** が出て位置がバレやすくなります（パーク「鋼の意志」で消せます）。ダウン後は **出血タイマー** が進み、仲間に起こされないまま尽きると死亡します。

## 発電機とスキルチェック

- **修理** — 発電機を右クリックすると修理が始まり、**その場に留まる** 間だけ進行します（既定で1台80秒相当）。複数人で修理すると速くなりますが、2人目以降は効率が下がります。発電機から離れると中断します。
- **スキルチェック** — 修理中、一定確率でゲージが出現します。カーソルが緑ゾーンに来た瞬間に **左クリック** で成功、中央のオレンジ（グレイト）ゾーンなら進行度ボーナス。外すと **失敗** で進行度が後退し、鬼に音と位置（赤柱）が伝わります。
- **通電** — 必要台数（既定で逃げ人数＋1台）をすべて修理すると **通電** し、脱出ゲートが操作可能になります。ボスバーが緑に変わります。

!!! tip "修理のコツ"
    鬼が近い（心音が速い）ときは無理せず離れ、鬼が去ってから修理を再開しましょう。スキルチェックは修理を続けている限り繰り返し来るので、落ち着いて緑ゾーンでクリックを。失敗すると音で鬼を呼び寄せてしまいます。

## チェイス（板・窓・救助）

- **板** — 立っている板（開いたフェンスゲート状）を右クリックで倒すと、至近にいる鬼を **スタン**（既定2秒）できます。倒れた板は鬼が破壊するまで通れなくなり、時間を稼げます。
- **窓** — 窓枠を右クリックで乗り越えます。逃げは素早く（既定6tick）、鬼は遅く（既定34tick）乗り越えるので、窓は逃げに有利なポイントです。
- **救助** — 仲間を右クリックで助けられます。
    - **ダウン救助** … ダウンした仲間を起こして負傷状態に戻す（既定8秒）。
    - **フック救助** … フックに吊られた仲間を救助（既定2秒）。救助された側は一定時間「攻撃を1回防ぐ（我慢／ボロタイ）」効果を得ます。吊られている本人も **自力脱出アイテム（トリップワイヤーフック）を右クリック** で低確率の自力脱出を狙えます（失敗すると吊りカウントが減ります）。
    - **治療** … 負傷した仲間を右クリックで健康に戻す（既定16秒）。パーク「セルフケア」があれば自分も治療できます。

!!! warning "ダウンと出血に注意"
    ダウンすると **出血タイマー**（既定240秒）が進み、仲間に起こされないまま0になると死亡します。担がれてフックに吊られると **3回目で処刑**、または吊り段階（既定60秒×3）が進みきっても死亡します。仲間が吊られたら早めに救助へ向かいましょう。

## 脱出（ゲートとハッチ）

- **脱出ゲート** — 通電後、ゲートのレバー等を右クリックで開放を始めます（その場に留まると進行、既定20秒）。開いたゲートの中心に近づくと **脱出成功** です。
- **ハッチ** — 生存している逃げが **最後の1人** になると、マップのどこかで **ハッチ** が開きます。ハッチに乗ると単独で脱出できます。鬼はハッチを右クリックで **閉じる** ことができ、閉じると通電扱いになってゲート勝負に持ち込まれます。

## パーク

`/dbd perk`、または設置されていれば **パーク看板** をクリックして **パーク選択GUI** を開き、鬼用・逃げ用それぞれ最大4つまで選べます（クリックで選択／解除、自動保存）。選んだパークは自分がその役割になったときに有効です。

## 勝利条件

!!! tip "勝ち方のポイント"
    - **逃げ** … 心音と赤い光で鬼の位置を読み、鬼が離れた隙に発電機を回す。通電したらゲートかハッチで脱出。仲間の救助も忘れずに。1人でも脱出すれば逃げにとっては成果です。
    - **鬼** … 発電機を回されすぎる前に逃げをダウンさせ、担いでフックへ。フック周りを見張って救助のタイミングを潰し、全員を処刑しましょう。

| 結果 | 条件 |
|---|---|
| 逃げの脱出 | 通電後、脱出ゲートまたはハッチから脱出した（脱出者数で成果を表示） |
| 鬼の勝利 | 逃げが全員 死亡した（出血・3回吊り・吊り段階満了） |
| 試合終了 | 逃げが全員 脱出または死亡した時点で終了（鬼が不在になった場合も終了） |

## 参加方法

参加・離脱・開始は **看板** か **コマンド** のどちらでも行えます。どちらも同じ動作です。

- **参加看板をクリック** … ロビーに設置された「参加する」看板を右クリックするとロビーに参加できます。
- **離脱看板をクリック** … 「離脱する」看板を右クリックするとロビーから離脱できます。
- **開始看板をクリック** … 「試合開始」看板を右クリックするとゲームを開始できます。

コマンドでも操作できます（いずれも通常プレイヤーが利用できます）。

```text title="ロビーに参加する（参加看板と同じ）"
/dbd join
```

```text title="ロビーから離脱する（離脱看板と同じ）"
/dbd leave
```

```text title="試合を開始する（開始看板と同じ）"
/dbd start
```

```text title="鬼希望のON/OFFを切り替える"
/dbd killer
```

```text title="パーク選択GUIを開く（鬼用・逃げ用 各4つまで）"
/dbd perk
```

```text title="設定状況・現在の試合状況を確認する"
/dbd status
```

参加するとロビー地点へテレポートされます。試合開始を待ちましょう。

!!! note "試合中の参加について"
    試合中に参加した場合は次の試合から参加できます（進行中の試合には途中参加できません）。途中で離脱・ログアウトすると初期スポーン地点へ戻され、試合／ロビーから外れます。

## よくある質問

??? question "鬼と逃げは選べますか？"
    役割は開始時にランダムで決まります。ただし `/dbd killer` で **鬼希望** をONにしておくと、鬼に優先的に選ばれます。鬼の人数は総人数で自動決定されます（既定：2〜6人=1、7〜11人=2、12〜16人=3、17〜20人=4）。

??? question "発電機は何台修理すればいいですか？"
    既定では「逃げの人数＋1台」（会場の登録数・上限設定が少ない場合はその範囲内）です。全台修理すると通電し、ボスバーが「ゲートを開けて脱出せよ！」に変わります。

??? question "スキルチェックのコツは？"
    ゲージのカーソルが **緑ゾーン** に入った瞬間に **左クリック** で成功、中央の **オレンジ（グレイト）ゾーン** ならボーナス。外すと進行度が後退し、鬼に音と位置が伝わります。焦らず緑を狙いましょう。

??? question "ダウンしたら終わりですか？"
    いいえ。ダウン中は出血タイマーが進みますが、仲間に **右クリックで起こして** もらえば負傷状態で復帰できます。担がれても **スニーク連打（もがき）** で脱出できることがあります（成功すると鬼を一定時間スタンさせられます。パーク「決死の一撃」で必要回数が半分になり、スタンも強化されます）。

??? question "フックに吊られたら？"
    仲間が **右クリックで救助**（既定2秒）してくれれば脱出できます。救助された側は一定時間「攻撃を1回防ぐ」効果（我慢／ボロタイ）を得ます。仲間が来られないときは、**自力脱出アイテム（トリップワイヤーフック）を右クリック** で低確率の自力脱出を狙えます（失敗すると吊りカウントが減ります）。救助されないまま吊り段階が進むと、3回目で処刑されます。

??? question "最後の1人になったら？"
    生存している逃げが1人になると、マップのどこかで **ハッチ** が開きます。ハッチに乗ると単独脱出できます。ただし鬼がハッチを閉じるとゲート勝負になります。

??? question "パークはどこで選びますか？"
    `/dbd perk` でGUIを開き、鬼用・逃げ用それぞれ最大4つまでクリックで選べます（自動保存）。選んだパークは自分がその役割になったときに有効になります。
