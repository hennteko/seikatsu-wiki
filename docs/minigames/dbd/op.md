# DBD（デッドバイデイライト風）― OP・運営ガイド { .page-op #dbd-op }

DBD の導入・会場の設定（スポーン／発電機／フック／板／窓／ゲート／ハッチ）・看板・config・権限・管理コマンドをまとめます。

## 基本情報

| 項目 | 値 |
|---|---|
| プラグイン名 | DBD |
| バージョン | 1.4.0 |
| api-version | 26.1.2（プラグイン内部の宣言は 1.21 系互換） |
| メインコマンド | `/dbd`（エイリアスなし） |
| 依存プラグイン | なし |
| 設定ファイル | `plugins/DBD/config.yml`（ゲーム設定・地点・発電機/フック/板/窓/ゲート/ハッチ・看板・パーク選択をすべて集約） |
| 地点の保存 | 各セットアップコマンド実行時に `config.yml` へ即保存（別ファイルなし） |

!!! info "ゲームの仕組み（非対称 × 発電機修理 × 吊り処刑）"
    逃げ（サバイバー）は発電機を全台修理して通電させ、脱出ゲートまたはハッチから脱出すれば成果。鬼（キラー）は逃げを攻撃してダウンさせ、担いでフックに吊るし（3回で処刑）全員を死亡させれば勝利。逃げが全員 脱出または死亡した時点で試合終了です。鬼の人数は総人数から自動決定されます。

## 導入手順

1. ビルドした `DBD`（`dbd-1.4.0.jar`）をサーバーの `plugins/` フォルダに配置する。
2. サーバーを起動・再起動すると `plugins/DBD/config.yml` が自動生成される（初回のみ）。
3. 後述の手順で会場（スポーン・発電機・フック・板・窓・ゲート・ハッチ・看板）を設定する。
4. 数値を変えたい場合は `config.yml` の `settings` を編集して **サーバー再起動**（またはプラグインリロード）で反映する。

!!! warning "config の反映と自動生成について"
    本プラグインは `saveDefaultConfig()` を使用しており、`config.yml` が **存在しない初回のみ** デフォルトを書き出します。**既存の `config.yml` に新しいキーを自動追記しません**（コード側にすべて既定値があるため、キーが無くても動作はします）。<br>
    地点・発電機・フック・板・窓・ゲート・看板・パーク選択などは、コマンド実行時に `config.yml` へ **即座に保存** されます。<br>
    **`reload` コマンドはありません**。`settings` の数値を変更した場合は、サーバー再起動またはプラグインの再読み込みで反映してください（進行中の試合には適用されません）。

## セットアップ手順

専用ワールドを用意し、OP権限（`dbd.admin`）で以下のコマンドを **設定したい地点に立って**（または対象ブロック・看板を見ながら）実行します。設備系（発電機・フック・ハッチ・窓）は **視線先6ブロック以内のブロック**、板は視線先ブロック＋自分の向き、ゲートは視線先ブロック、看板は視線先の看板で判定されます。

### 地点の設定

```text title="① 初期スポーン（途中抜け・終了時の戻り先）を現在地に設定"
/dbd setstartspawn
```

```text title="② ロビー地点を現在地に設定"
/dbd setlobby
```

```text title="③ 鬼スポーンを現在地に設定"
/dbd setspawn killer
```

```text title="④ 逃げスポーンを現在地に追加（複数登録可）"
/dbd setspawn survivor
```

```text title="逃げスポーンを全消去する"
/dbd setspawn survivor clear
```

```text title="⑤ フィールド範囲の角1を現在地に設定（任意）"
/dbd setfield 1
```

```text title="⑤ フィールド範囲の角2を現在地に設定（任意）"
/dbd setfield 2
```

### 設備の設定（トグル式：同じブロックで再実行すると解除）

```text title="発電機を登録／解除（視線先6ブロック以内のブロック）"
/dbd setgen
```

```text title="フック（処刑台）を登録／解除（視線先6ブロック以内のブロック）"
/dbd sethook
```

```text title="ハッチ候補を登録／解除（視線先6ブロック以内・複数登録可、試合ごとに1つ抽選）"
/dbd sethatch
```

```text title="窓枠を登録／解除（視線先6ブロック以内のブロック）"
/dbd setwindow
```

```text title="板を登録／解除（視線先のブロック＋自分の向きで面を決定）"
/dbd setpallet
```

```text title="脱出ゲート1を設定（レバー等のブロックを見ながら）"
/dbd setgate 1
```

```text title="脱出ゲート2を設定（レバー等のブロックを見ながら／任意）"
/dbd setgate 2
```

設定の流れは次のとおりです。

1. `/dbd setstartspawn` で初期スポーン（途中抜け・終了時の戻り先）を設定する。
2. ロビーにする場所に立ち `/dbd setlobby` を実行する。
3. 鬼スポーンを `/dbd setspawn killer`、逃げスポーンを `/dbd setspawn survivor`（複数箇所で繰り返して登録）で設定する。
4. 発電機・フック・窓・板をそれぞれのブロックを見ながら `/dbd setgen` / `sethook` / `setwindow` / `setpallet` で登録する（同じブロックで再実行すると解除）。
5. 脱出ゲートのレバー等を見ながら `/dbd setgate 1`（必要なら `2`）を設定する。
6. （任意）ハッチ候補を `/dbd sethatch` で登録する（複数登録すると試合ごとにランダムで1つが使われます）。
7. `/dbd status` で各設定状況・現在の設定値を確認する。

!!! note "板の向きについて"
    `/dbd setpallet` は、視線先のブロックを板の位置とし、**実行時の自分の向き**（南／西／北／東の4方向に丸め）を板の面として登録します。試合中は立っている板が **開いたオークのフェンスゲート** として表示され、逃げが倒すと閉じて通行不可になります（鬼が破壊すると空気ブロックに）。試合終了時に元のブロックへ復元されます。

!!! warning "試合開始に必須の設定"
    `/dbd start`（開始看板を含む）は、次の項目がそろっていないと開始できません（不足項目が一覧表示されます）。<br>
    **ロビー・初期スポーン・鬼スポーン・逃げスポーン（1つ以上）・発電機2台以上・フック（1つ以上）・ゲート1**。<br>
    窓・板・ハッチ・ゲート2・フィールド範囲・看板は開始の必須条件ではありません。ただし駆け引きのため、発電機／フック／板／窓／ハッチは複数を散らして設置することを推奨します。

## 看板の設置

参加・離脱・開始は **看板** か **コマンド**（`/dbd join` / `leave` / `start`）のどちらでも行えます。看板はクリック1つで操作でき、初心者にもわかりやすいため設置を推奨します。看板を設置し、看板を見ながら（6ブロック以内）以下のコマンドを実行してください。テキストはプラグインが自動で書き込みます（人数・状態を表示）。

```text title="参加看板を登録（クリックで参加・ロビーへTP・人数表示）"
/dbd setsign join
```

```text title="離脱看板を登録（クリックでロビーから離脱）"
/dbd setsign leave
```

```text title="開始看板を登録（クリックでゲーム開始）"
/dbd setsign start
```

```text title="開始看板を識別子付きで登録（複数マップ運用時の区別用）"
/dbd setsign start <識別子>
```

```text title="パーク看板を登録（クリックでパーク選択GUIを開く）"
/dbd setsign perk
```

看板の解除は、解除したい看板を見ながら（6ブロック以内）次のコマンドを実行します。

```text title="視線先の看板の登録を解除"
/dbd setsign delete
```

!!! note "開始看板の識別子について"
    `/dbd setsign start <識別子>` で登録すると、その開始看板をクリックしたとき `/dbd start <識別子>` 相当で開始します（開始看板の2行目に識別子が表示されます）。識別子は開始看板の区別・表示用のラベルとして扱われます（会場は1つのみのため、演出・運用上の目印として利用してください）。識別子なしでも通常どおり開始できます。

## config.yml 設定項目

`config.yml` には `settings`（数値設定）・`killer-allocation`（鬼の割り振り）のほか、コマンドで登録される地点系（`lobby-spawn` / `default-spawn` / `arena.*` / `generators` / `hooks` / `hatches` / `windows` / `pallets` / `gates.*` / `signs`）と `player-perks.*`（各プレイヤーのパーク選択）が保存されます。ここでは手動編集の対象になる `settings` と `killer-allocation` を掲載します。

### settings セクション

| キー | 既定値 | 説明 |
|---|---|---|
| `settings.min-players` | 2 | 開始に必要な最小人数（内部で最低2人に補正・鬼1＋逃げ1） |
| `settings.max-players` | 20 | ロビーの最大人数 |
| `settings.max-generators` | 8 | 修理が必要な発電機台数の上限（実際の必要数は「逃げ人数＋1」とこの上限・登録数の小さい方） |
| `settings.killer-speed-multiplier` | 1.3 | 鬼の移動速度倍率（標準歩行0.2×倍率。内部上限あり） |
| `settings.repair-seconds` | 80 | 発電機の修理時間（1人あたり秒） |
| `settings.heal-seconds` | 16 | 治療時間（秒。セルフケアは2倍） |
| `settings.revive-seconds` | 8 | ダウン救助（起こす）時間（秒） |
| `settings.rescue-seconds` | 2 | フック救助時間（秒） |
| `settings.bleedout-seconds` | 240 | ダウン後の出血タイマー（秒。0で死亡） |
| `settings.hook-stage-seconds` | 60 | フック各段階の時間（秒。段階満了で次段階／3で処刑） |
| `settings.gate-open-seconds` | 20 | 脱出ゲートの開放時間（秒） |
| `settings.skillcheck-fail-penalty` | 0.10 | スキルチェック失敗時の進行度後退量（0.10＝10%） |
| `settings.skillcheck-chance` | 0.10 | 修理中1秒ごとのスキルチェック発生率 |
| `settings.wiggle-count` | 24 | 担がれた時のもがき脱出に必要なスニーク回数 |
| `settings.pallet-break-seconds` | 2.5 | 鬼の板破壊時間（秒。パーク「野蛮な力」で短縮） |
| `settings.vault-survivor-ticks` | 6 | 逃げの窓乗り越え時間（tick。6tick＝約0.3秒） |
| `settings.vault-killer-ticks` | 34 | 鬼の窓乗り越え時間（tick） |
| `settings.endurance-seconds` | 10 | フック救助後の「攻撃を1回防ぐ」無敵（我慢／ボロタイ）秒数 |
| `settings.stun-seconds` | 2 | 板スタンの秒数 |
| `settings.attack-cooldown-seconds` | 2.0 | 鬼の攻撃間隔（秒。連続ヒット防止のクールダウン） |
| `settings.wiggle-interval-ms` | 500 | もがき1カウントの最小間隔（ミリ秒。スニーク長押し対策） |

### killer-allocation セクション（鬼の人数割り振り）

総人数に応じた鬼の人数を範囲指定で定義します。範囲は `"最小-最大"`（例 `"7-11"`）または単一の数字で指定します。

```yaml
killer-allocation:
  "2-6": 1
  "7-11": 2
  "12-16": 3
  "17-20": 4
```

| 総人数 | 既定の鬼の数 |
|---|---|
| 2〜6人 | 1 |
| 7〜11人 | 2 |
| 12〜16人 | 3 |
| 17〜20人 | 4 |

!!! note "該当範囲がない場合のフォールバック"
    `killer-allocation` に該当する範囲が無い場合は、**鬼:逃げ ≒ 1:5** の比率（`round(総人数 / 5.5)`、最低1人）で自動計算されます。鬼希望（`/dbd killer` でON）のプレイヤーが優先的に鬼に選ばれ、不足分はランダムで補われます。鬼の数は「総人数−1」を超えないよう調整されます（必ず逃げが1人以上残る）。

## ゲームの運営

```text title="試合を開始（ロビーに最小人数以上・必須設定が必要）"
/dbd start
```

```text title="識別子を指定して試合を開始（開始看板の識別子と対応）"
/dbd start <識別子>
```

```text title="試合を強制終了する（コンソールからも実行可）"
/dbd stop
```

```text title="設定状況・設定値・現在の試合状態を確認"
/dbd status
```

1. プレイヤーが参加看板／`/dbd join` でロビーに集まるのを待つ（既定で最小2人）。
2. `/dbd start` または開始看板でゲームを開始する。
3. 役割抽選（鬼希望を優先）→ 各スポーンへ配置 → 修理＆チェイス → 通電 → 脱出、と進行します。
4. 逃げが全員 脱出または死亡した時点で結果を表示し、しばらく（約5秒）後に参加者を自動でロビーへ戻します。

!!! note "試合の状態と自動処理"
    試合状態は **待機中（WAITING）→ 試合中（PLAYING）→ 終了処理中（ENDING）** の3つです。終了時には発電機・板・窓などのブロックが元に戻され、担ぎ・チャネル・パーク効果などの試合固有データはすべてクリアされます。サーバー停止時にも試合は自動で強制終了されます。オフラインの在籍者は試合リセット時に除去されるため、復帰後は再度 `/dbd join` してください。

## コマンド一覧

`join` / `leave` / `start` / `status` / `perk` / `killer` は **全プレイヤー** が利用でき、それ以外のセットアップ・管理コマンドは `dbd.admin`（既定OP）が必要です。地点・設備・看板系のコマンドは **ゲーム内（プレイヤー）** から実行してください（`stop` のみコンソールからも可）。

| コマンド | 必要権限 | 説明 |
|---|---|---|
| `/dbd`（引数なし） | 全員 | ヘルプを表示する |
| `/dbd join` | 全員 | ロビーに参加する（参加看板と同じ） |
| `/dbd leave` | 全員 | ロビーから離脱する（初期スポーンへ／離脱看板と同じ） |
| `/dbd start [識別子]` | 全員 | 試合を開始する（開始看板と同じ） |
| `/dbd status` | 全員 | 設定状況・設定値・現在の試合状態を確認する |
| `/dbd perk` | 全員 | パーク選択GUIを開く（鬼用・逃げ用 各4つまで） |
| `/dbd killer` | 全員 | 鬼希望のON/OFFを切り替える |
| `/dbd setstartspawn` | dbd.admin | 初期スポーン（戻り先）を現在地に設定する |
| `/dbd setlobby` | dbd.admin | ロビー地点を現在地に設定する |
| `/dbd setspawn <killer\|survivor [clear]>` | dbd.admin | 鬼スポーン／逃げスポーン（複数可・clearで全消去）を設定する |
| `/dbd setfield <1\|2>` | dbd.admin | フィールド範囲の角を現在地に設定する |
| `/dbd setgen` | dbd.admin | 視線先のブロックを発電機に登録／解除する |
| `/dbd sethook` | dbd.admin | 視線先のブロックをフックに登録／解除する |
| `/dbd sethatch` | dbd.admin | 視線先のブロックをハッチ候補に登録／解除する（複数可） |
| `/dbd setwindow` | dbd.admin | 視線先のブロックを窓枠に登録／解除する |
| `/dbd setpallet` | dbd.admin | 視線先のブロック＋自分の向きで板を登録／解除する |
| `/dbd setgate <1\|2>` | dbd.admin | 視線先のブロックを脱出ゲートに設定する |
| `/dbd setsign <join\|leave\|start [識別子]\|perk\|delete>` | dbd.admin | 視線先の看板を各種看板（参加／離脱／開始／パーク）に登録／解除する |
| `/dbd stop` | dbd.admin | 試合を強制終了する（コンソール可） |

!!! tip "タブ補完に対応しています"
    `/dbd` の第1引数（サブコマンド）、`setspawn`（`killer` / `survivor`）、`setfield` / `setgate`（`1` / `2`）、`setsign`（`join` / `leave` / `start` / `perk` / `delete`）、`setspawn survivor`（`clear`）はタブ補完に対応しています。管理者用のサブコマンドは `dbd.admin` を持つ場合のみ補完候補に表示されます。

## 権限ノード

`plugin.yml` には `dbd.admin` の1つが定義されています。

| 権限 | 既定 | 用途 |
|---|---|---|
| `dbd.admin` | OP | セットアップ（地点・発電機・フック・板・窓・ゲート・ハッチ）・看板登録系・`stop` |

!!! note "プレイヤー操作について"
    `join` / `leave` / `start` / `status` / `perk` / `killer` は **権限チェックを行わず全員が実行できます**（参加看板・開始看板のクリックも同様）。`/dbd start` も誰でも実行できるため、開始を制限したい場合は運用でカバーするか、権限プラグイン等でコマンド自体を制限してください。セットアップ・`stop` は `dbd.admin`（既定OP）が必要です。

## 実装状況

!!! info "実装済みの機能"
    - ロビー（看板またはコマンドでの参加・離脱・人数表示・最大人数制限）
    - 鬼希望のON/OFF（`/dbd killer`）と役割の自動抽選（鬼希望を優先・鬼数は `killer-allocation`）
    - 発電機の修理（複数人効率減衰）・スキルチェック（成功／グレイト／失敗）・鬼の発電機蹴り（後退）
    - 板の設置（フェンスゲート表示）・倒し（鬼スタン）・鬼の破壊、窓の乗り越え（逃げ／鬼で速度差）
    - 攻撃 → 負傷 → ダウン、担ぎ＆もがき、フック3段階＆救助、我慢（ボロタイ）
    - 治療／セルフケア／ダウン救助／出血タイマー
    - 通電・脱出ゲート開放・ハッチ（最後の1人・鬼が閉鎖可能）
    - 心音（距離連動）・赤い光（ステイン）・負傷のうめき等の演出
    - パーク選択GUI（鬼10種＋逃げ13種・各4つまで・`config.yml` に自動保存）
    - ボスバー（発電機残数／通電）とアクションバー表示
    - 勝敗判定（全脱出／全死亡／鬼不在）・終了後の自動ロビー帰還・ログアウト時の戻り処理
    - 落下・環境などのダメージ無効／空腹無効／インベントリ保護（ドロップ・クリック不可）

!!! warning "注意点・制限"
    - 会場は1つのみです。複数会場の同時運用には対応していません（開始看板の識別子は目印・演出用ラベルです）。
    - `reload` / `stats` コマンドはありません。`settings` の数値変更はサーバー再起動またはプラグイン再読み込みで反映されます（進行中の試合には適用されません）。
    - `config.yml` は初回のみ自動生成され、既存ファイルへの新キー自動追記は行われません（コード側に既定値あり）。
    - 発電機・板・窓など会場のブロックは試合中に見た目が変化し、試合終了時に元へ復元されます。地点・設備の登録はコマンド実行時に `config.yml` へ即保存されます。

## トラブルシューティング

??? failure "「未設定の項目があるため開始できません」と表示される"
    ロビー・初期スポーン・鬼スポーン・逃げスポーン・発電機2台以上・フック・ゲート1 のいずれかが未設定です。表示される不足項目、または `/dbd status` の「未設定」項目を確認し、対応するコマンドで設定してください。

??? failure "「人数が足りません」と表示される"
    ロビーの人数が最小人数（既定2人・内部で最低2人に補正）に達していません。`/dbd status` の「参加人数」を確認してください（鬼1＋逃げ1で最低2人必要です）。

??? failure "看板をクリックしても反応しない"
    看板は `/dbd setsign <種別>` で登録した位置で判定されます（手書きの看板では機能しません）。登録済みか `/dbd status` の「看板設定」で確認してください。看板を見ながら（6ブロック以内）登録・解除を実行します。

??? failure "板・発電機・窓が反応しない／見た目が変わらない"
    それぞれ `/dbd setgen` / `setwindow` / `setpallet` で **登録済みのブロック** のみが機能します。視線先6ブロック以内のブロックを見ながら登録してください（板は自分の向きも面として保存されます）。`/dbd status` の「ゲーム設備」で登録数を確認できます。試合中のみブロックの見た目が変化します。

??? failure "config.yml を編集したのに反映されない"
    本プラグインに `reload` はありません。`settings` の数値を変更した場合は、サーバーを再起動するかプラグインを再読み込みしてください（進行中の試合には適用されません）。また、既存 `config.yml` には新キーが自動追記されないため、追加したいキーは手動で記述してください。

??? failure "鬼が多すぎる／少なすぎる"
    鬼の人数は `killer-allocation` の範囲指定で決まります。範囲に該当しない人数のときは「鬼:逃げ ≒ 1:5」で自動計算されます。狙った人数比にしたい場合は `killer-allocation` を編集してください（変更後は再起動で反映）。
