# TwoDTreasure <span class="badge done">公開中</span>

Terraria風の **2D宝探しミニゲーム** プラグインです。横スクロールゲームのようにZ軸が固定された2D平面でマップを掘り進め、ランダムに埋まった **宝箱を最初に開けた人** が勝者になります。

!!! note "ゲームの特徴"
    Z軸が固定された2D平面で遊ぶ宝探しミニゲームです。マップ生成のたびに宝箱と鉱石がランダムに配置されます。マップ確認タイムにスペクテイターで宝箱を探し、ゲーム開始後はサバイバルモードで地形を掘り進めて宝箱を目指します。参加・退出はロビーの看板クリックで行います。
