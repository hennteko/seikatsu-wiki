# TwoDTreasure ― 遊び方 { .page-player #twodtreasure-player }

Terraria風の2D宝探しミニゲームです。Z軸が固定された横スクロール風のマップを掘り進め、地中にランダムに埋まった **宝箱を最初に開けた人** が勝ちです。

1人で遊べる **ソロ（スコアアタック）** もあります。制限時間内に掘り当てた宝の価値の合計で競います（[スコアアタック](#スコアアタックソロ) を参照）。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 通常戦：最低2人（既定値）から／スコアアタック：1人 |
    | ゲームモード | マップ確認中はスペクテイター、ゲーム中はサバイバル |
    | 勝利条件 | 宝箱を最初に右クリックで開ける |
    | 配布アイテム | 鉄のツルハシ（ゲーム開始時に1本） |
    | 終了後 | 20秒後にロビーへ戻る（参加状態は維持） |

## どんなゲーム？

マップはZ軸が1マスに固定された **2D平面** です。左右（X軸）と上下（Y軸）にだけ移動でき、エリアの外側はバリアブロックで囲まれています。

ゲームが始まるとマップが自動生成され、地中には土・石・鉱石、そしてどこか1か所に **宝箱** が埋まっています。鉄のツルハシで地形を掘り進め、宝箱にいち早くたどり着いて開けた人が勝者です。

## ゲームの流れ

1. **ロビーへ移動** — 初期リスポーン地点からロビーへ向かいます。
2. **参加する** — ロビーにある **[2DT] 参加看板** をクリックしてゲームに参加します。
3. **開始を待つ** — 最低人数（既定2人）が集まり、運営またはコマンドブロックがゲームを開始します。**[2DT] 開始看板** が設置されている場合は、プレイヤー自身が右クリックして始めることもできます。
4. **マップ確認タイム** — マップ生成後、全員がスペクテイターモードでマップ上空へ移動します。**約20秒間**、宝箱の位置を上空から探せます。
5. **ゲームスタート** — カウントダウン後、サバイバルモードでマップ上のランダムな地点にスポーンします。鉄のツルハシが配られます。
6. **掘り進める** — 地形を掘って宝箱を目指します。
7. **宝箱を開ける** — 宝箱を最初に **右クリック** で開けた人が勝利！ 勝者には報酬としてダイヤモンドが配られます。
8. **ロビーへ戻る** — 勝敗が決まると全員スペクテイターになり、約20秒後にロビーへ戻ります。**参加状態は維持される** ので、続けて次のゲームを遊べます。

## ルール

!!! tip "マップ確認タイムを活かそう"
    ゲーム開始前のマップ確認タイムは、宝箱の位置をあらかじめ把握できる重要な時間です。上空からマップ全体をよく観察しましょう。

- 掘れるのは **ゲームエリア内のブロックだけ** です。エリア外のブロックは破壊できません。
- エリアを囲む **バリアブロックは破壊できません**。
- **宝箱はツルハシで壊せません**。必ず右クリックで開けてください。
- ゲーム中はマップに牛・豚・羊・ニワトリなどの動物が定期的にスポーンします。
- ゲーム中にログアウトすると、ゲームから離脱した扱いになります。

## スコアアタック（ソロ）

**制限時間内に掘り当てた宝の価値の合計（スコア）** を競う1人用のモードです。コースは **★1** があります（運営が追加すると増えます）。

1. **ソロ看板** をクリック、または `/2dtreasure solo` → ロビーに入り、**ソロメニュー** が開きます。
2. ソロメニューの **「スコアアタック ★1」** を押すと、マップを作り直して始まります。
3. **マップ確認タイム（10秒）** — 観戦で平面を見て、宝の位置を覚えます。
4. **掘削タイム（120秒）** — 鉄のツルハシで掘り、宝ブロックを壊すと得点が入ります。**宝箱は開けても（右クリック/タップ）** 回収できます。宝はドロップしません。
5. 時間切れで終了します。**宝を全部回収すると、その場で終了して残り時間がボーナス** になります（残り1秒につき5点）。
6. 結果を表示してロビーへ戻り、数秒後にソロメニューがまた開きます。続けて挑戦できます。

### ★1 の宝

| 宝 | 見た目 | 点数 | 数 | 深さ（地表から） |
|---|---|---|---|---|
| 宝箱 | チェスト | 300 | 1 | 50〜70 |
| エメラルドの宝 | エメラルドブロック | 100 | 2 | 35〜65 |
| 金の宝 | 金の原石ブロック | 50 | 4 | 20〜55 |
| 鉄の宝 | 鉄の原石ブロック | 20 | 6 | 8〜35 |
| 銅の宝 | 銅の原石ブロック | 10 | 8 | 3〜20 |

- 満点は **900点（21個）＋全回収ボーナス** です。宝の種類と数は毎回同じで、位置だけが変わります。
- 深いところほど高い宝があります。浅い宝を確実に拾うか、深い宝箱を狙うかが勝負どころです。
- 制限時間・宝の内容は運営が変えることがあります。ソロメニューの「ルール」で今の内容を確認できます。
- 掘削中は残り時間・スコア・回収数がボスバーに出ます。
- 死亡しても得点は残ります（フィールドのどこかにリスポーンし、ツルハシも戻ります）。

### 記録とランキング

- 終わるたびに記録され、**自己ベストを更新するとサーバー全体にお知らせ** が流れます。
- 同じ点数なら、**最後に宝を取った時刻が早い人** が上位です。
- ランキングはソロメニューの金ブロック、または `/2dtreasure ranking` で見られます。
- 統合版で出した記録には `[BE]` が付きます（Java 版と同じランキングです）。

### 途中でやめたとき

| 状況 | 扱い |
|---|---|
| 時間切れ・全回収 | 記録する |
| 挑戦中に `/2dtreasure leave`・切断 | 中止（記録しない）。持ち物が戻り、初期地点へ |
| OP が止めた（`/2dtreasure stop`） | 中止（記録しない）。ロビーに戻り、ソロメニューが開く |

### ソロメニュー

| ボタン | 内容 |
|---|---|
| 鉄のツルハシ（★1） | 挑戦開始（自己ベスト・前回・挑戦回数も表示） |
| 本 | ルールと宝の一覧 |
| 紙 | 前回の結果 |
| 金ブロック | ランキング上位5人と自分の順位 |
| ガラス板 | フィールドの状況（緑＝空き／赤＝使用中） |
| プレイヤーの頭 | あなたの記録（コースごとの自己ベストと挑戦回数） |
| ドア | ロビー退出（持ち物が戻ります） |

- メニューを閉じてもロビーにいるままです。ホットバーの **ネザースター（ソロメニュー）** を右クリック／タップすると開き直せます。
- フィールドは通常戦と共用です。だれかが遊んでいる間は始められません（空くとメニューのボタンが戻ります）。
- ソロで入った人は通常戦には出場しません。通常戦に出るときは `/2dtreasure join`（参加看板）で切り替えます。

!!! info "統合版（スマホ・Switch など）で遊ぶとき"
    - ソロメニューはチェストの画面で表示され、タップで操作できます。
    - ネザースターを持って **空中をタップ** するか、**持ってスニーク** してもメニューが開きます。
    - マップ確認タイムは平面の正面に移動し、土や石がガラスに透けて見えます。**宝ブロックは透けずにそのまま見える** ので、位置を覚えやすくなっています。

## 勝利条件

地中にランダムに埋まっている **宝箱を最初に右クリックで開ける** ことが勝利条件です。

- 宝箱を開けた瞬間にゲームが終了し、勝者の名前が全体にアナウンスされます。
- 勝者には報酬として **ダイヤモンド64個** が贈られます。

## 参加方法

参加・退出は **ロビーの看板** または **コマンド** のどちらでも行えます。看板クリックとコマンドはまったく同じ効果です。

| 操作 | 看板 | コマンド |
|---|---|---|
| ゲームに参加 | **[2DT] 参加看板** を右クリック | `/2dtreasure join` |
| ロビー／ゲームから退出 | **[2DT] 退出看板** を右クリック | `/2dtreasure leave` |
| ゲームを開始 | **[2DT] 開始看板** を右クリック（設置されている場合） | `/2dtreasure start` |
| スコアアタック（ソロ） | **[2DT] ソロ看板** を右クリック | `/2dtreasure solo` |

!!! note "ゲーム中の参加"
    ゲームの進行中に参加すると、ロビーで待って **次のゲームから** 参加します。進行中のゲームには加わりません。

## プレイヤー用コマンド

参加・退出は看板のほか、以下のコマンドでも行えます（`twodtreasure.play` 権限。既定で全員に付与）。

```text title="ロビーに参加する（参加看板クリックと同じ）"
/2dtreasure join
```

```text title="ロビー／ゲームから離脱する（退出看板クリックと同じ）"
/2dtreasure leave
```

```text title="スコアアタック（ソロ）のメニューを開く（ソロ看板クリックと同じ）"
/2dtreasure solo
```

```text title="メニューを通さずにスコアアタック ★1 を始める"
/2dtreasure solo star1
```

```text title="スコアアタックのランキングを見る"
/2dtreasure ranking
```

そのほかの管理系コマンド（地点設定・看板登録・`stop`・`reload` など）は運営（OP）向けです。詳しくは OP向けページをご覧ください。

## よくある質問

??? question "どうやってゲームに参加しますか？"
    ロビーにある **[2DT] と書かれた参加看板** を右クリックするか、`/2dtreasure join` コマンドを実行してください。どちらも同じ効果です。

??? question "宝箱が掘っても壊れません"
    宝箱はツルハシでは破壊できない仕様です。宝箱を見つけたら **右クリック** で開けてください。開けた人が勝者になります。

??? question "ゲームの途中から参加できますか？"
    進行中のゲームには加われません。参加するとロビーで待ち、次のゲームから参加します。

??? question "1人でも遊べますか？"
    遊べます。ソロ看板か `/2dtreasure solo` でスコアアタックを選んでください。

??? question "スコアアタックのボタンが押せません（バリアになっています）"
    フィールドを使用中です（通常戦、またはほかの人のスコアアタック）。空くとボタンが戻ります。

??? question "スコアアタックで掘った宝は持ち帰れますか？"
    持ち帰れません。宝は得点になるだけで、アイテムは落ちません。

??? question "エリアの端が掘れません"
    ゲームエリアの外側はバリアブロックで囲まれています。バリアやエリア外のブロックは破壊できません。エリア内を掘って宝箱を探しましょう。

??? question "ゲーム中に動物が出てきました"
    仕様です。ゲーム中はマップに牛・豚・羊・ニワトリが定期的にスポーンします。
