# 伝言しりとり（DengonShiritori） <span class="badge done">公開中</span>

**建築で伝える伝言ゲーム**と**しりとり**を組み合わせたパーティーゲームです。前の人が決めた「言葉」を区画に建築で表現し、次の人がそれを見て何かを当て、当てた言葉の最後の文字から次の言葉がつながっていく——伝言ゲームの「どこで勘違いが生まれるか」と、しりとりの連鎖が同時に楽しめます。最後は答え合わせで、1列ずつ「どう伝わっていったか」をみんなで見て盛り上がります。

!!! note "ゲームの特徴"
    各プレイヤーには1本の「伝言の列（チェーン）」が割り当てられます。ラウンド1では自分の列の **最初の文字から始まる言葉** を自分で決め、制限時間内に区画へ建築します。ラウンド2以降は、**別の人が作った作品を見て「何を作ったか」を当て**（回答）、その後また自分が新しい言葉を建築します。次の言葉は、前の人の **回答の最後の文字から始まる**（しりとり）ので、伝言としりとりが同時に進みます。全ラウンドが終わると **答え合わせ** で、1列ずつ「本当の言葉 → どう伝わったか」を順に公開。**伝わった回答・伝わった建築に加点**され、最初から最後まで全部伝わった列には **完全伝言ボーナス**、最高得点者が **MVP** になります。
