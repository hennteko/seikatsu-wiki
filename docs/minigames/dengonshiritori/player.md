# 伝言しりとり ― 遊び方 { .page-player #dengonshiritori-player }

前の人が決めた言葉を **建築で表現** し、次の人がそれを見て **何かを当て**、当てた言葉からしりとりでつながっていく——伝言ゲームとしりとりが一度に楽しめるパーティーゲームです。最後の **答え合わせ** で、どこで伝言がズレたかをみんなで見て盛り上がりましょう。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | 得点制のパーティー（3〜8人） |
    | 流れ | 言葉決め → 建築 → （次のラウンドで）回答 → また建築 … → 最後に答え合わせ |
    | 言葉決め | 既定25秒 |
    | 建築 | 既定150秒 |
    | 回答 | 既定40秒 |
    | 勝利条件 | 伝わった数で加点。最高得点者がMVP、全部伝わった列には完全伝言ボーナス |
    | 参加方法 | ロビーの参加看板、または `/dengon join` |

## どんなゲーム？

参加者それぞれに **1本の「伝言の列」** が割り当てられます。列には最初の文字（お題の一文字目）が決まっていて、ゲームはおおまかに次のように進みます。

1. **言葉決め**（最初のラウンド）… 自分の列の **最初の文字から始まる言葉** を、自分で決めます。
2. **建築** … 決めた言葉を、制限時間内に自分の区画へ建築で表現します（文字は書けません）。
3. **回答**（次のラウンド以降）… 席替えのように担当が回り、**別の人が作った作品** を見て「何を作ったか」をチャットで答えます。
4. また自分の番で **新しい言葉を建築**。このとき作る言葉は、**前の人の回答の最後の文字から始まる** 言葉です（しりとり）。
5. これをラウンドの数だけ繰り返し、最後に **答え合わせ** で全列を1つずつ公開します。

つまり「伝言ゲーム（作品 → 回答 → 次の作品…）」と「しりとり（回答の最後の文字が次のお題）」が同時に進むのがこのゲームの肝です。

## ラウンドの流れ

試合が始まると、まず区画が自動で用意され、カウントダウンののち進行します。

| フェーズ | 既定時間 | 内容 |
|---|---|---|
| 言葉決め | 25秒 | 指定された文字から始まる言葉をチャットで入力して決める |
| 建築 | 150秒 | 決めた言葉を自分の区画に建築する |
| 回答 | 40秒 | 割り当てられた作品を見て、何かをチャットで答える |
| 答え合わせ | 1ステップ6秒 | 全ラウンド終了後、列ごとに「本当の言葉 → 各回答」を順に公開 |

- 最初のラウンドは「言葉決め → 建築」、2ラウンド目以降は「**回答 → 言葉決め → 建築**」の順になります。
- 最後のラウンドのあとは **最終回答** と **答え合わせ** が行われます。
- 建築ラウンドの数は参加人数と設定（既定4）の小さい方になります。

!!! tip "言葉決めはチャットで"
    言葉決め・回答はどちらも **チャットに入力** して行います。試合中、参加者どうしのチャットは **他の人に見えないように** なっているので（ネタバレ防止）、安心して入力してください。

## 言葉のルール（しりとり）

- **最初の文字** … 言葉決めのとき、画面に「『◯』から始まる言葉」と表示されます。その文字から始まる言葉を入力してください。
- **文字数** … 既定で **2〜12文字**。ひらがな・カタカナで入力します。
- **「ん」で終わる言葉** … 既定では **使えません**。
- **長音（ー）で終わる言葉** … 既定では **長音の前の文字** が次のお題になります（例：「カレー」→次は「れ」）。
- **濁点・半濁点** … 最初の文字は区別しません（「は」指定なら「ば」「ぱ」で始まる言葉もOK）。
- **同じ列での重複** … 同じ列ですでに使われた言葉は使えません。

!!! note "ヒント機能"
    言葉決めのときは、ホットバーの **ヒント（本）** を使うと、その文字から始まる言葉の候補をいくつか見られます。思いつかないときに活用してください（候補がないこともあります）。

## 建築する

- 建築フェーズに入ると、自分の区画に移動します。区画には建材がひととおり用意され、ブロックを置いて作品を作ります。
- **文字・記号は書けません** … 看板・旗は設定に関係なく常に禁止です。また TNT・コマンドブロック・ピストン・ディスペンサーなど、仕掛けや爆発に使えるブロックも使えません。
- **水** … 既定で水バケツが使えます（流れは区画の外には出ません）。
- 建築が早く終わったら、ホットバーの **建築完了（ライム色の染料）** を押すと「完了」になります。**全員が完了を押すと、残り時間を飛ばして次へ進みます**（もう一度押すと取り消せます）。

## 回答する

- 2ラウンド目以降の最初に **回答フェーズ** があります。割り当てられた作品（前のラウンドで誰かが作ったもの）を見て、**何を作ったと思うか** をチャットで答えます。
- 設定で「最初の文字を教える」が有効なら、回答にも「『◯』から始まる言葉」とヒントが出ます。
- 時間内に答えられなかった列は、その作品は伝わらなかった扱いになります。

## 答え合わせ・得点

全ラウンドが終わると、**答え合わせ** が始まります。列を1つずつ、「本当の言葉 → 各回答」の順にゆっくり公開していくので、どこで伝言がズレたかをみんなで楽しめます。

- **伝わった回答** … 作品の言葉を正しく当てた回答者に加点（既定 +1）。
- **伝わった建築** … 作品が正しく伝わった建築者に加点（既定 +1）。
- **完全伝言ボーナス** … その列が最初から最後まで全部伝わっていたら、**関わった全員** にボーナス（既定 +2）。
- **MVP** … 試合の最高得点者。同点なら複数人がMVPになります。

!!! note "正解判定はゆるめ"
    正解の判定は、小さい文字（ゃゅょっ など）や長音の違いを無視するなど、少しゆるめに設定されています。細かい表記ゆれで「惜しい！」とならないように配慮されています。

- **スキップ** … 答え合わせ中、ホットバーの **スキップ（矢印）** を押せます。全員がスキップを押すと、その列の演出を早送りします。

## 参加方法

1. ロビーの **参加看板** をクリック、または `/dengon join`。
2. 人数が集まったら **開始看板** をクリック、または `/dengon start [会場]` で開始（カウントダウンは既定10秒）。
3. 離脱は **離脱看板** か `/dengon leave`。試合中に離脱すると脱落扱いになります。

開始には最低人数（既定3人）が必要です。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/dengon join` | ロビーに参加する（参加看板と同等） |
| `/dengon leave` | ロビーから離脱する（離脱看板と同等。試合中は脱落扱い） |
| `/dengon start [会場]` | ゲームを開始する（開始看板と同等・全員可） |
| `/dengon status` | 現在の設定・状況を確認する（読み取り専用） |
| `/dengon stats [プレイヤー]` | 自分または指定プレイヤーの記録を見る |
| `/dengon top` | 「伝わった数」ランキングを見る |

## よくある質問

??? question "言葉はどう決めるのですか？"
    言葉決めフェーズで、画面に出る「『◯』から始まる言葉」に合わせて、ひらがな・カタカナの言葉をチャットで入力します。思いつかないときはホットバーのヒント（本）で候補を見られます。

??? question "自分の作品を自分で当てるのですか？"
    いいえ。回答では、**別の人が作った作品** が割り当てられます。伝言ゲームと同じで、人から人へ作品がリレーされていきます。

??? question "しりとりはどこでつながるのですか？"
    次に自分が作る言葉は、**前の人がその列に出した回答の最後の文字** から始まります。だから回答がズレると、しりとりのつながり方も変わっていきます。

??? question "文字や看板で言葉を書いてもいいですか？"
    いいえ。看板・旗は常に使えません。建築（形や色）だけで伝えるのがこのゲームの面白さです。

??? question "表記がちょっと違うと不正解になりますか？"
    正解判定はゆるめで、小さい文字や長音の違いは無視されます。大きく違わなければ「伝わった」と判定されやすくなっています。
