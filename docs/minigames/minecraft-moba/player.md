# MinecraftMOBA ― 遊び方 { .page-player #moba-player }

LOL風のチーム対戦ミニゲームです。仲間と協力してミニオンを進軍させ、敵のタワーを壊し、最後に敵の **コア** を破壊すれば勝ちです。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 最大10人（赤5 vs 青5） |
    | 1試合の長さ | 最長60分（コア破壊で即終了） |
    | 勝利条件 | 敵チームのコアを破壊する |
    | リスポーン | あり（レベルが高いほど復活が遅い） |

## どんなゲーム？

赤チームと青チームに分かれて戦います。マップには両チームの拠点（**コア**）と、それを守る **タワーが5本ずつ** あります。

定期的に湧く **ミニオン**（味方の小型モンスター）と一緒に前線を押し上げ、敵のタワーをすべて壊すと、ようやく敵のコアを攻撃できるようになります。コアを先に破壊したチームの勝利です。

## ゲームの流れ

1. **参加する** — ロビーにある参加看板をクリックしてゲームに加わります。
2. **チーム分け** — 赤／青に自動で振り分けられます（人数は自動で均等化されます）。
3. **カウントダウン** — 規定人数が集まると30秒のカウントダウン後に開始。
4. **戦う** — ミニオンと一緒に進軍し、敵プレイヤー・ミニオン・タワーを攻撃してエメラルドと経験値を稼ぎます。
5. **強くなる** — エメラルドで `/shop` から装備を購入。経験値でレベルアップ（最大Lv18）。
6. **タワーを壊す** — 敵のタワー5本をすべて破壊する。
7. **コアを破壊** — 守りがなくなった敵コア（HP1000）を削り切れば **勝利！**

## 勝ち方のポイント

!!! tip "コアはすぐには壊せません"
    敵コアは **タワーを5本すべて破壊するまで攻撃できません**。まずはタワー攻略を優先しましょう。

- タワーは攻撃力が高く射程15ブロック。**ミニオンを盾にして** 攻めるのが基本です。
- 1人で突っ込まず、ミニオンの波（30秒ごとに出現）に合わせて前進しましょう。
- 中立の **クリープ** を倒すと多めの報酬とバフが手に入ります。

## エメラルドの稼ぎ方

エメラルドはショップでの買い物に使う通貨です。

| 行動 | 獲得エメラルド |
|---|---|
| ミニオン撃破 | 1 |
| プレイヤー撃破 | 5 |
| アシスト | 2 |
| クリープ撃破 | 5 |
| タワー破壊（チーム全員に） | 25 |
| 時間経過（10秒ごと自動） | 5 |
| キルストリーク達成ボーナス | +2 |

!!! danger "デスのペナルティ"
    倒されると、所持エメラルドの **10%** を失います。デス時も装備は保持されます。

## レベルとステータス

経験値を貯めるとレベルが上がり、強くなります（**Lv1 → 最大Lv18**）。

- レベルごとに **最大体力 +2HP**、**攻撃力 +10%**。
- **Lv6・Lv11・Lv16** でスキルが解放されます（スキルは今後実装予定）。
- 経験値は プレイヤー撃破=100、クリープ撃破=50、アシスト=50、ミニオン撃破=10 など。

## ショップ（`/shop`）

`/shop` でショップを開けます（サーバー設定 `SHOP.RANGE_RESTRICTION` が有効な場合は拠点近くでのみ使用可能）。エメラルドで武器・防具・消耗品を購入しましょう。

## 中立クリープ

マップ各所に湧く中立モンスターです。倒すと報酬とバフがもらえます。

| クリープ | 正体 | 報酬 | 特徴 |
|---|---|---|---|
| 通常クリープ | ゾンビ | エメラルド5・経験値50 | 各所に出現、2分で復活 |
| バフクリープ | アイアンゴーレム | エメラルド10・経験値100 | 撃破で **力アップ**（90秒） |
| ボスクリープ | ウィザー | エメラルド25・経験値200 | マップ中央。チームのミニオンを強化 |

## リコール（拠点帰還）

戦線から拠点へ素早く戻れる機能です。

- 詠唱時間 **8秒**。詠唱中に **ダメージを受ける／移動する** と中断されます。
- クールダウンは60秒。安全な場所で使いましょう。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/shop` | ショップを開く |
| `/moba stats` | 自分の統計（キル数など）を表示 |

!!! note "参加・退出について"
    ゲームへの参加は **ロビーの看板** から行います。`/moba join` のようなコマンドでは参加できません。

## よくある質問

??? question "敵のコアが攻撃できません"
    敵の **タワー5本をすべて破壊** するまでコアは攻撃できません。まずタワーを攻略しましょう。

??? question "倒されると装備はなくなりますか？"
    装備は保持されます。ただし所持エメラルドの10%を失います。

??? question "1人だと勝てません"
    MOBAはチームゲームです。ミニオンの進軍に合わせ、仲間と一緒に攻めるのが基本です。

??? question "スキルはどこで使えますか？"
    スキルシステムは今後実装予定です（Phase 2以降）。現在は未対応です。
