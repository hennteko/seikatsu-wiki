# MinecraftMOBA ― 遊び方 { .page-player #moba-player }

LOL風のチーム対戦ミニゲームです。仲間と協力してミニオンを進軍させ、敵のタワーを壊し、最後に敵の **コア** を破壊すれば勝ちです。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 最大10人（赤5 vs 青5） |
    | 1試合の長さ | 最長60分（コア破壊で即終了） |
    | 勝利条件 | 敵チームのコアを破壊する |
    | 役割 | 5チャンピオンから選択（固有スキル3種＋パッシブ） |
    | リスポーン | あり（レベルが高いほど復活が遅い） |

## どんなゲーム？

赤チームと青チームに分かれて戦います。マップには両チームの拠点（**コア**）と、それを守る **タワー** があります（本数はサーバー設定により異なり、既定のARAMマップでは各2基）。

定期的に湧く **ミニオン**（味方の小型モンスター）と一緒に前線を押し上げ、敵のタワーをすべて壊すと、ようやく敵のコアを攻撃できるようになります。コアを先に破壊したチームの勝利です。

## ゲームの流れ

1. **参加する** — ロビーにある参加看板をクリックしてゲームに加わります。
2. **チャンピオンを選ぶ** — チャンピオン選択看板（またはGUI）から5職のいずれかを選びます。選択は試合をまたいで保持されます。
3. **チーム分け** — 赤／青に自動で振り分けられます（人数は自動で均等化されます）。
4. **カウントダウン** — 規定人数が集まると30秒のカウントダウン後に開始。
5. **戦う** — ミニオンと一緒に進軍し、スキルや武器で敵プレイヤー・ミニオン・タワーを攻撃してエメラルドと経験値を稼ぎます。
6. **強くなる** — エメラルドで `/shop` から装備・ルーンを購入。経験値でレベルアップ（最大Lv18）し、スキルが解放・強化されます。
7. **タワーを壊す** — 敵のタワーをすべて破壊する。
8. **コアを破壊** — 守りがなくなった敵コア（HP1000）を削り切れば **勝利！**

## 勝ち方のポイント

!!! tip "コアはすぐには壊せません"
    敵コアは **タワーをすべて破壊するまで攻撃できません**。まずはタワー攻略を優先しましょう。

- タワーは攻撃力が高く射程15ブロック。**ミニオンを盾にして** 攻めるのが基本です。
- 1人で突っ込まず、ミニオンの波（30秒ごとに出現）に合わせて前進しましょう。
- 中立の **クリープ** を倒すと多めの報酬とバフが手に入ります。

## チャンピオンとスキル

試合開始前に **5つのチャンピオン** から1つを選びます。チャンピオンごとに役割・基礎体力・固有武器・常時発動の **パッシブ**・そして固有の **スキル3種** が決まっています。

| チャンピオン | 役割 | 体力傾向 | パッシブ |
|---|---|---|---|
| 戦士 | 前衛・タンク | 硬い（+6HP） | 不屈: 体力を毎秒回復 |
| 魔導士 | 範囲魔法・中衛 | 標準 | 魔力循環: マナ回復が増加 |
| 暗殺者 | 瞬間火力 | 脆い（-2HP） | 俊敏: 常時移動速度上昇 |
| 狙撃手 | 遠距離・継続火力 | 脆い（-2HP） | 戦場の眼: 近くの敵が発光する |
| 支援 | 回復・味方強化 | やや硬い（+2HP） | 治癒の祈り: 近くの味方を毎秒回復 |

### スキルの使い方

- スキルは **手持ちのアイテムを右クリック** で発動します。
- 発動には **マナ** を消費します（基本最大100・毎秒回復。魔導士はパッシブで回復が速い）。スキルごとに **クールダウン** があります。
- 1つ目のスキルは最初から、**2つ目はLv6・3つ目はLv11・（強化）はLv16** で解放されます。
- スキルのダメージは **レベルが上がるほど強化** されます（最大Lv18で約2倍）。

=== "⚔️ 戦士"

    | スキル | CD | 効果 |
    |---|---|---|
    | 突進 | 8秒 | 向いている方向へ飛び込む |
    | 鉄壁 | 14秒 | 4秒間ダメージを大きく軽減 |
    | 強打 | 10秒 | 周囲の敵にダメージとノックバック |

=== "🔮 魔導士"

    | スキル | CD | 効果 |
    |---|---|---|
    | 火球 | 5秒 | 火球を発射する |
    | 氷結 | 12秒 | 周囲の敵を鈍足にしてダメージ |
    | 瞬間移動 | 14秒 | 前方へ瞬間移動する |

=== "🗡️ 暗殺者"

    | スキル | CD | 効果 |
    |---|---|---|
    | 影駆け | 9秒 | 前方へ踏み込み斬りつける |
    | 加速 | 12秒 | 6秒間移動速度が上昇する |
    | 処刑 | 11秒 | 前方の敵に大ダメージ |

=== "🏹 狙撃手"

    | スキル | CD | 効果 |
    |---|---|---|
    | 連射 | 8秒 | 矢を3本同時に放つ |

=== "💚 支援"

    | スキル | CD | 効果 |
    |---|---|---|
    | 回復 | 9秒 | 周囲の味方の体力を回復 |

!!! tip "マナとクールダウン短縮（CDR）"
    マナは時間で回復します。ショップの **賢者のオーブ** で最大マナ＋30、**加速のルーン** でクールダウン短縮（CDR、上限40%）が得られます。火力職はマナ管理、前衛は鉄壁・強打の回し方が鍵です。

## ワード（視界確保）

**ワード（松明）** を設置すると、周囲20ブロックの **敵が発光** して壁越しでも見えるようになります。1人あたり最大3個・180秒持続です。索敵や奇襲の警戒に使いましょう（狙撃手はパッシブでも近くの敵が光ります）。なお現バージョンではワードは **ショップから購入できません**（運営からの配布が必要です）。

## エメラルドの稼ぎ方

エメラルドはショップでの買い物に使う通貨です。

| 行動 | 獲得エメラルド |
|---|---|
| ミニオン撃破 | 1 |
| プレイヤー撃破 | 5 |
| アシスト | 2 |
| クリープ撃破 | 5 |
| タワー破壊（チーム全員に） | 25 |
| 時間経過（10秒ごと自動） | 5 |
| キルストリーク達成ボーナス | +2 |

!!! danger "デスのペナルティ"
    倒されると、所持エメラルドの **10%** を失います。デス時も装備は保持されます。

## レベルとステータス

経験値を貯めるとレベルが上がり、強くなります（**Lv1 → 最大Lv18**）。

- レベルごとに **最大体力 +2HP**、**攻撃力 +10%**。
- **Lv6・Lv11・Lv16** でスキルが順に解放され、スキルのダメージもレベルで強化されます。
- 経験値は プレイヤー撃破=100、クリープ撃破=50、アシスト=50、ミニオン撃破=10 など。

## ショップ（`/shop`）

ショップは **ショップ看板** から開けます（`/shop` コマンドは現バージョンではOP専用です）。エメラルドで武器・防具・金のリンゴ・ルーンを購入できます。現在の店の品揃えは次の **計14品** です。

    |---|---|---|
    | 木の剣 | 50 | 基本の武器 |
    | 石の剣 | 150 | 標準的な武器 |
    | 鉄の剣 | 300 | 鋭さ I |
    | ダイヤの剣 | 600 | 鋭さ II（最強） |
    | 鉄のヘルメット | 100 | ダメージ軽減 I |
    | 鉄の胸当て | 200 | ダメージ軽減 I |
    | 鉄のレギンス | 150 | ダメージ軽減 I |
    | 鉄のブーツ | 100 | ダメージ軽減 I |
    | 金のリンゴ | 100 | 回復＋一時的な防御上昇 |

=== "ルーン（永続強化）"

    買うと試合中ずっと効果が続く強化アイテムです。

    | ルーン | 価格 | 効果 |
    |---|---|---|
    | 攻撃の宝珠 | 150 | 攻撃力 +2 |
    | 守りの宝珠 | 150 | 防御 +3 |

!!! note "店に並ばないアイテムについて"
    弓・矢・各種ポーション・革防具・ワードは `config.yml` には定義がありますが、**現バージョンの店には並びません**（店の品揃えはコード側に固定されているため）。ワードは現状ショップから購入できない点に注意してください。

## 中立クリープ

マップ各所に湧く中立モンスターです。倒すと報酬とバフがもらえます。

| クリープ | 正体 | 報酬 | 特徴 |
|---|---|---|---|
| 通常クリープ | ゾンビ | エメラルド5・経験値50 | 各所に出現、2分で復活 |
| バフクリープ | アイアンゴーレム | エメラルド10・経験値100 | 撃破で **力アップ**（90秒） |
| ボスクリープ | ウィザー | エメラルド25・経験値200 | マップ中央。チームのミニオンを強化 |

## リコール（拠点帰還）

戦線から拠点へ素早く戻れる機能です。

- 詠唱時間 **8秒**。詠唱中に **ダメージを受ける／移動する** と中断されます。
- クールダウンは60秒。安全な場所で使いましょう。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/moba join` / `leave` | ロビーに参加 / 退出する（看板と同等・全員可） |
| `/moba start` | ゲームを開始する（開始看板と同等・全員可） |
| `/moba stats [名前]` | 統計を表示する（自分のものは試合中ならライブ成績、それ以外は通算成績。名前を指定すると相手の通算成績） |
| `/moba status` | 看板・地点・ゲーム状況などの設定状況を確認する（全員可・読み取り専用） |

!!! note "参加・退出・チャンピオン選択について"
    参加・退出・開始は **ロビーの看板** または **`/moba join`・`leave`・`start` コマンド**（全員可）で行えます。各種の看板は複数の場所に設置できるので、どの看板からでも操作できます。チャンピオンは **チャンピオン選択看板** をクリックして開くGUIで選びます。`/shop` コマンドは現バージョンではOP専用のため、ショップは **ショップ看板** から開きます。

!!! warning "AFK（放置）に注意"
    試合中に一定時間（既定5分）動かないと、放置とみなされて自動的に試合から離脱させられます。少人数の試合では離脱で勝敗が決まることもあるので注意してください。

## よくある質問

??? question "敵のコアが攻撃できません"
    敵の **タワーをすべて破壊** するまでコアは攻撃できません。まずタワーを攻略しましょう。

??? question "倒されると装備はなくなりますか？"
    装備は保持されます。ただし所持エメラルドの10%を失います。

??? question "1人だと勝てません"
    MOBAはチームゲームです。ミニオンの進軍に合わせ、仲間と一緒に攻めるのが基本です。

??? question "スキルはどこで使えますか？"
    チャンピオンごとに固有スキルが3種あり、**手持ちのアイテムを右クリック** で発動します。マナを消費し、クールダウンがあります。2つ目以降のスキルはLv6・Lv11・Lv16で解放されます。

??? question "チャンピオンは変更できますか？"
    試合開始前にチャンピオン選択看板から選びます。選択は次の試合にも引き継がれます。試合中の変更はできません。
