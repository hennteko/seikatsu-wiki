# Supermarket ― 遊び方 { .page-player #supermarket-player }

みんなでスーパーを経営する協力ミニゲームです。商品を棚に補充し、客をさばいて売上を伸ばしましょう。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | 協力（全員で1つのお店） |
    | 人数 | 最大8人（サーバー設定により変更されることがあります） |
    | 勝利条件 | 営業日を通して売上（スコア）を伸ばす |
    | 参加方法 | `[Supermarket]` 参加看板、または `/supermarket join` |

## どんなゲーム？

参加者全員で1つのお店を回します。1日の流れは **準備 → 営業 → 精算 → 翌日** の繰り返しです。搬入口に届いた商品を棚に並べ、来店した客が商品を取ってレジで会計する——その回転を止めないのが目標です。売上はチームの資金になり、日が進むと新しい商品が解放されます。

## 営業日の流れ

1. **準備フェーズ（既定60秒）** … 開店前に棚へ商品を補充し、店内を整えます。
2. **営業（既定300秒）** … 客が次々に来店します。棚から商品を取ってレジへ向かうので、補充とレジ対応を分担してさばきます。
3. **精算** … その日の売上が計算され、資金に加算されます。
4. **翌日へ** … 次の日が始まります。日が進むほど客が増え、新商品も解放されます。

## ステーション（設備）

| ステーション | 役割 |
|---|---|
| 搬入口 | 商品（箱）が届く場所。ここから商品を取り出して棚へ運ぶ |
| 棚 | 商品を陳列する場所。客はここから商品を取る（棚ごとに扱う商品が決まっている） |
| レジ | 客の会計を行う |
| ゴミ箱 | いらないもの・傷んだ商品を捨てる |

## 役割分担のコツ

!!! tip "止めないのが大事"
    棚が空だと客は商品を買えず、レジが混むと客は待ちきれずに帰ってしまいます。**補充担当** と **レジ担当** に分かれ、搬入口→棚の補充を切らさないようにしましょう。人数と客足に応じて臨機応変に動くのがハイスコアのコツです。

## 参加方法

1. `[Supermarket]` 参加看板をクリック、または `/supermarket join` でロビーに入ります。
2. `/supermarket ready` で準備完了を切り替えます（参加者が揃ったら開始）。
3. 開始看板のクリックまたは `/supermarket start <識別子>`（全員可）でゲーム開始。
4. 営業日を回して売上を伸ばし、終了後に結果が表示されます。

離脱は `/supermarket leave`（または離脱看板）です。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/supermarket join` | ロビーに参加する（参加看板と同等・全員可） |
| `/supermarket leave` | ロビーから離脱する（離脱看板と同等・全員可） |
| `/supermarket ready` | 準備完了を切り替える |
| `/supermarket start <識別子>` | ゲームを開始する（開始看板と同等・全員可） |
| `/supermarket status` | 現在の設定・状況を確認する（全員可） |

## よくある質問

??? question "客が帰ってしまいます"
    棚が品切れだったり、レジの会計待ちが長いと客は帰ってしまいます。補充とレジを分担し、回転を止めないようにしましょう。

??? question "どの棚に何を並べるの？"
    棚ごとに扱う商品が決まっています（運営が設定）。搬入口に届いた商品を、対応する棚へ運んで補充します。

??? question "何日まであるの？"
    営業日を重ねてスコアを伸ばす形式です。日が進むほど客が増え、新商品が解放されて難しくなります。難易度は運営のプリセット設定によります。
