# Supermarket ― 遊び方 { .page-player #supermarket-player }

みんなでスーパーを経営する協力ミニゲームです。商品を棚に補充し、客をさばいて売上を伸ばしましょう。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 形式 | 協力（全員で1つのお店） |
    | 人数 | 最大8人（サーバー設定により変更されることがあります） |
    | 勝利条件 | 営業日を通して売上（スコア）を伸ばす |
    | 参加方法 | `[Supermarket]` 参加看板、または `/supermarket join` |
    | ソロ営業 | 1人でも遊べる（ロビーのメニューアイテム／ソロ看板／`/supermarket solo`。既定で有効） |

## どんなゲーム？

参加者全員で1つのお店を回します。1日の流れは **準備 → 営業 → 精算 → 翌日** の繰り返しです。搬入口に届いた商品を棚に並べ、来店した客が商品を取ってレジで会計する——その回転を止めないのが目標です。売上はチームの資金になり、日が進むと新しい商品が解放されます。

## 営業日の流れ

1. **準備フェーズ（既定60秒）** … 開店前に搬入口で商品を**発注**し、届いた箱を棚へ補充して店内を整えます。**参加者全員が `/supermarket ready` で準備完了にすると時間を待たずに開店**できます。
2. **営業（既定300秒）** … 客が次々に来店します。客は **買い物かご分（1人1〜数点）** の商品を棚から取ってレジへ並ぶので、補充・レジ会計・発注を分担してさばきます。
3. **精算** … その日の売上が資金に加算され、**1日の固定費が差し引かれます**。資金がマイナスになると**倒産**して営業終了です。その日の★評価は **店の評判** に反映され、翌日の客足が変わります（評判が高いほど客が増える）。
4. **翌日へ** … 次の日が始まります。日が進むほど新商品が解放されます。営業はプリセットで決められた**日数（既定5日）**続き、終了時に**★1〜5の評価**とプリセット別ハイスコアが記録されます。

!!! warning "お金の流れに注意"
    発注も仕入れ代としてチーム資金を消費します。初期資金から発注してお店を回し、毎日の固定費を払いながら売上（資金）を伸ばすのが目標です。資金がマイナスになると倒産します。

## ステーション（設備）と操作

| ステーション | 役割・操作 |
|---|---|
| 搬入口 | **右クリックで発注GUI** を開き、商品を 1箱／5箱 単位で発注。約20秒後に搬入口へ箱が届く（資金を消費） |
| 棚 | 商品を陳列する場所。**箱を持って右クリックで品出し**、**素手で右クリックすると値上げ・スニーク＋右クリックで値下げ**（棚ごとに扱う商品が決まっている） |
| レジ | **右クリックで会計画面** を開き、先頭の客の商品をスキャンして支払い（カード／現金）を処理する。客はここに並ぶ |
| ゴミ箱 | **手に持ったアイテムを右クリックで廃棄**（いらない箱・傷んだ商品を捨てる） |

!!! tip "価格設定と客のタイプ"
    客には「太っ腹／標準／シビア」の価格寛容度タイプがあり、頭上に表示されます。客は棚の前で値段を見て、タイプごとの許容範囲を超えると **そのまま買わずに去ることがあり**（価格の評価が下がる）、会計まで進んでも高すぎると満足度が下がります。値引きすると満足度が上がる場合もあります。価格は入店時の値で会計されます。

## レジでの会計

レジを右クリックすると、列の先頭の客の **会計画面** が開きます（運営が簡易方式に切り替えている場合は右クリックだけで会計が終わります）。

1. **スキャン** … 客のカゴの商品を1つずつタップ（クリック）してスキャンします。合計金額は画面とアクションバーに出ます。全部スキャンすると「お会計へ進む」が押せます。
2. **カード払いの客** … 決済端末の数字ボタンで **請求額をそのまま打ち込んで確定** します。金額を間違えるとやり直しになり、打ち間違いはレジ操作の評価（★）を下げます。
3. **現金払いの客** … お預かり額とおつり額が表示されます。金種ボタン（10〜5000円）で **トレイにおつりを積んで「おつりを渡す」** を押します。おつりが多すぎると店の損に、足りないと客の満足度が下がります。

!!! note "会計は閉じても続きます"
    会計画面を閉じても会計は中断されず、同じレジを右クリックすれば開き直せます（別の人が引き継ぐこともできます）。レジ1台につき会計中の客は1人です。

## 役割分担のコツ

!!! tip "止めないのが大事"
    棚が空だと客は商品を買えず、レジが混むと客は待ちきれずに帰ってしまいます。**補充担当** と **レジ担当** に分かれ、搬入口→棚の補充を切らさないようにしましょう。人数と客足に応じて臨機応変に動くのがハイスコアのコツです。

## ひとりで遊ぶ（ソロ営業）

人数が集まらなくても、1人でお店を切り盛りできる **ソロ営業** があります（運営が無効化していなければ利用可）。

- ロビーに入ると配られる **ソロ営業メニュー（エメラルド・右クリック／タップ）**、**ソロ看板**、または `/supermarket solo` でメニューを開きます。モードを直接指定して `/supermarket solo <モード>` で即開始もできます。
- モードは運営が用意します（既定は **かんたん／ふつう／むずかしい** の3種）。モードごとに営業日数・初期資金・固定費・客の量・箱の中身などが異なります。
- 店舗は通常営業と共用のため、**誰かが営業中はソロ営業を始められません**（メニューに「使用中」と表示されます）。
- モードごとに **自己ベスト（★評価・総売上）** と **前回の結果** が記録され、メニューから確認できます。

!!! tip "ソロでは雇用でレジを任せられます"
    ソロ営業では、1人でも回せるよう **レジ係を雇える** 設定が既定で有効です（下の「雇用」を参照）。

## 雇用（レジ係）

**準備フェーズ中**に搬入口の発注画面から **レジ係を雇える** 場合があります（既定では **ソロ営業で有効／通常の営業では無効**。運営設定によります）。

- 雇うと営業中、**列が一番長いレジの先頭客を一定秒数ごとに自動で会計** してくれます。
- **雇用費は雇ったとき1回**、**日給は閉店時に固定費と一緒に** 資金から引かれます。
- レベルを上げると会計の間隔が短くなります（既定 Lv1＝8秒に1人／Lv2＝5秒に1人）。解雇するとその日から日給はかかりません（雇用費は戻りません）。

## 参加方法

1. `[Supermarket]` 参加看板をクリック、または `/supermarket join` でロビーに入ります。
2. 開始看板のクリックまたは `/supermarket start <識別子>`（全員可）でゲーム開始。
3. 準備フェーズ中に `/supermarket ready` で準備完了を切り替えます（参加者全員が完了すると時間を待たず開店）。
4. 営業日を回して売上を伸ばし、終了後に結果が表示されます。

離脱は `/supermarket leave`（または離脱看板）です。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/supermarket join` | ロビーに参加する（参加看板と同等・全員可） |
| `/supermarket leave` | ロビーから離脱する（離脱看板と同等・全員可） |
| `/supermarket ready` | 準備完了を切り替える（準備フェーズ中のみ・全員完了で早く開店） |
| `/supermarket start <識別子>` | ゲームを開始する（開始看板と同等・全員可） |
| `/supermarket solo [モード]` | ソロ営業メニューを開く（モード指定ですぐ開始・全員可） |
| `/supermarket status` | 現在の設定・状況を確認する（全員可） |

## よくある質問

??? question "客が帰ってしまいます"
    棚が品切れだったり、レジの会計待ちが長いと客は帰ってしまいます。また、値段を高くしすぎると客はそのまま買わずに去ります（特にシビアな客）。補充とレジを分担し、回転と値付けに気をつけましょう。

??? question "レジの会計はどうやるの？"
    レジを右クリックすると会計画面が開きます。客のカゴの商品を1つずつタップしてスキャンし、「お会計へ進む」を押します。カード払いの客は数字ボタンで請求額を打ち込んで確定、現金払いの客は金種ボタンでトレイにおつりを積んで渡します。打ち間違いやおつりの過不足は評価（★）に響きます。

??? question "店の評判って何ですか？"
    1日の営業の★評価が、翌日の **店の評判**（★1.0〜5.0）に少しずつ反映されます。評判が高い日は客が増え、低い日は減ります。良い接客を続けると客足が伸びていきます。

??? question "どの棚に何を並べるの？"
    棚ごとに扱う商品が決まっています（運営が設定）。搬入口に届いた商品を、対応する棚へ運んで補充します。

??? question "何日まであるの？"
    プリセットで決められた日数（既定5日）営業します。毎日の精算で固定費が引かれ、資金がマイナスになるとその時点で倒産して終了です。日が進むほど新商品が解放され、営業終了時に★1〜5の評価とプリセット別ハイスコアが記録されます。難易度・日数・資金は運営のプリセット設定によります。

??? question "商品の仕入れ（補充）はどうするの？"
    搬入口を右クリックして発注GUIを開き、商品を1箱／5箱単位で発注します。約20秒後に搬入口へ箱が届くので、箱を持って対応する棚を右クリックすると品出しできます。発注はチーム資金を消費します。

??? question "値段は変えられる？"
    棚を素手で右クリックすると値上げ、スニーク＋右クリックで値下げできます。客のタイプ（太っ腹／標準／シビア）によって価格への寛容度が異なり、高くしすぎると評価が下がります。

??? question "1人でも遊べる？"
    はい。ロビーで配られる **ソロ営業メニュー（エメラルド）** やソロ看板、`/supermarket solo` からモードを選べば1人で営業できます。店舗は通常営業と共用なので、誰かが営業中は始められません。モード別に自己ベスト（★評価・総売上）と前回の結果が記録されます。ソロ営業ではレジ係を雇って会計を任せることもできます（既定で有効）。
