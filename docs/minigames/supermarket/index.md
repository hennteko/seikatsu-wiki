# Supermarket <span class="badge done">公開中</span>

みんなで力を合わせてお店を切り盛りする、**協力型のスーパーマーケット経営ミニゲーム** です。搬入口に届いた商品を棚に補充し、来店した客が商品を選び、レジで会計——**準備→営業→精算** の営業日サイクルを回して売上を伸ばします。品切れや会計待ちを起こさないよう、役割分担でお店を回しましょう。

!!! note "ゲームの特徴"
    協力してスーパーを経営します。1日の流れは **準備フェーズ（既定60秒）→営業（既定300秒）→精算→翌日**。**搬入口** に届いた商品を **棚** に陳列し、来店した客が棚から商品を取ってカゴに入れ、**レジ** で会計します。品切れ・会計待ちが続くと客が帰ってしまうので、補充とレジをうまく分担するのがコツ。売上はチームの資金になり、日が進むと新しい商品が解放されていきます。難易度や商品構成は **プリセット** で切り替えられ、パーティ別のハイスコアが記録されます。
