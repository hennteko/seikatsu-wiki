# WaJinro（人狼RPG）― 遊び方 { .page-player #wajinro-player }

Minecraft上で人狼を遊ぶミニゲームに、RPGのアクション要素を組み合わせたゲームです。昼は議論で人狼を探り、夜はスケルトンを倒して **エメラルド** を稼ぎます。稼いだエメラルドでショップから武器や特殊能力アイテムを買い、**投票ではなく直接戦闘** で人狼や吸血鬼を討ち取りましょう。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 6〜15人（最低人数は運営が変更可能・テスト時は1人から） |
    | 1試合の長さ | 昼夜サイクル制（初日昼30秒 / 昼・夜 各120秒／設定で変更可） |
    | 勝利条件 | 役職の陣営ごとに異なる（下記参照） |
    | 参加方法 | `/wajinro join` または **参加看板** をクリック |
    | 決着方法 | 投票なし。ショップで買った武器による **直接戦闘（PvP）** |

## どんなゲーム？

参加者にはゲーム開始時に役職が割り振られます。役職は **村人陣営 / 人狼陣営 / 第三陣営（吸血鬼）** に分かれ、それぞれ勝利条件が異なります。

一般的な人狼と違い、**投票による追放はありません**。村人陣営は夜にスケルトンを倒してエメラルドを稼ぎ、ショップで武器や占い・守りのアイテムを買って、**自分の手で人狼を討ち取ります**。人狼は専用武器「人狼の斧」で村人を襲撃します。この「稼ぐ → 買う → 戦う」というRPG的なサイクルが本ゲームの核です。

ゲームは **昼** と **夜** が交互に繰り返される昼夜サイクル制です。

- **初日の昼（既定30秒）** — 短い準備・顔合わせの時間です。
- **昼（既定120秒）** — 議論の時間。発言できます。武器や特殊アイテムは昼夜どちらでも使用できます。
- **夜（既定120秒）** — **発言禁止（チャット・Discord VCともにミュート）** になります。フィールドに「エメラルドの番人」（スケルトン）が出現するので、倒してエメラルドを集めましょう。占い・騎士の祈り・天啓の呪符など、一部の能力は夜のみ使用できます。**吸血鬼は夜の間、聖なる十字架以外の攻撃を受けません**（昼は通常どおりダメージを受けます）。

## 役職と勝敗条件

参加人数に応じて登場する役職が変わります（下の配役表を参照）。

=== "村人陣営"

    | 役職 | 内容 |
    |---|---|
    | 村人 | 特殊能力を持たない基本の役職。ショップアイテムで占い・守り・霊媒などをこなします。 |
    | 狼憑き | 中身は村人陣営（人間）ですが、**占われると「人狼」と判定** されます。自分の役職は開始時「村人」と表示され、本人も自覚がありません。 |

    村人・狼憑き・共犯者は、ショップの「占い師の心」「騎士の祈り」「騎士の加護」「霊媒師の遺灰」などを使うことで、占い師・騎士・霊媒師の役割を自分で担えます。

=== "人狼陣営"

    | 役職 | 内容 |
    |---|---|
    | 人狼 | 仲間の人狼を最初に把握できます。専用武器 **「人狼の斧」** を購入可能。村人陣営を全滅させれば勝利。 |
    | 共犯者 | 人狼陣営ですが、**誰が人狼かは分かりません**。占い結果は「村人」。専用の「共犯者の目」でランダムな人狼を1人知れます。 |

=== "第三陣営"

    | 役職 | 内容 |
    |---|---|
    | 吸血鬼 | 全員の敵。村人陣営か人狼陣営のどちらかが全滅した瞬間に生き残っていれば **単独勝利**。夜の間は聖なる十字架以外の物理ダメージを受けません。 |

!!! info "勝利条件"
    - **村人陣営** … 人狼をすべて討ち取る（人狼を全滅させる）。
    - **人狼陣営** … 村人陣営（村人＋狼憑き）を全滅させる。
    - **吸血鬼** … 村人陣営または人狼陣営が全滅した時点で生存している。

!!! tip "占いの判定結果"
    「占い師の心」で調べると、次のように判定されます。

    - **共犯者** → 「村人」と表示（人狼側だが偽装される）
    - **狼憑き** → 「人狼」と表示（村人陣営だが誤判定される）
    - **吸血鬼** → 「吸血鬼」と表示
    - その他 → 正しい役職が表示される

## RPG要素：エメラルドとショップ

このゲームのRPG要素は、**エメラルドを稼いでショップで戦力を整える** 経済＋戦闘のサイクルです。

### エメラルドの稼ぎ方

エメラルドはショップの通貨です。

- **夜の間**、フィールドに「エメラルドの番人」（スケルトン）が一定間隔で出現します。
- 番人を倒すと **一定確率でエメラルドを1個** 獲得できます（既定で約50%）。
- 夜が明けると番人は消え、ドロップはありません。**夜のうちに稼ぐ** のがポイントです。

!!! note "初期装備"
    開始時は全員 **鈍器**（少し攻撃力の高い棒）と **ステーキ×3** を持ってスタートします。スケルトン狩りやショップでの買い物で戦力を強化していきましょう。

### ショップ

ゲーム中、フィールドに立っている **ショップ（村人NPC）** を右クリックすると、通常の村人取引GUIでアイテムを購入できます。支払いはエメラルドです。

| アイテム | 価格 | 効果 |
|---|---|---|
| 一撃弓 | 2E | チャージ不要で当てた相手を一撃。1回撃つと壊れる。矢が必要。 |
| 矢 | 2E | 一撃弓用の矢。外すと回収できない。 |
| スタングレネード | 2E | 当てた相手を3秒間、盲目＋移動不可に。雪玉のように投げる。 |
| スケ狩り剣 | 4E | スケルトンを一撃で倒す高攻撃力の剣。30回使用可。 |
| 怨念の槍 | 3E | 通算2回攻撃した相手を倒す（別の槍でも累積）。1本につき攻撃1回。 |
| 人狼の斧 | 3E | 殴った相手を一撃で倒し1回で消滅。使用時に大きな音。**人狼のみ購入可**。 |
| ステーキ | 1E | 食料（5個セット）。 |
| 俊敏ポーション | 1E | 飲むと移動速度上昇Iが永続。 |
| 透明化ポーション | 3E | 30秒間透明化する。 |
| 占い師の心 | 5E | 夜に名前看板を右クリックで占う。所持数＝残り占い回数。 |
| 霊媒師の遺灰 | 4E | 死亡したプレイヤー全員の名前を知る。1個につき1回。 |
| 騎士の祈り | 4E | 夜のみ・村人／共犯者のみ有効。攻撃を防ぐ（効果は設定で変化）。 |
| 騎士の加護 | 2E | 名前看板を右クリックで対象に使用。その夜1回、弓／斧の即死を防ぐ（効果は村人・共犯者のみ）。 |
| 共犯者の目 | 4E | ランダムな人狼を1人把握。**共犯者のみ購入可**。 |
| 聖なる十字架 | 2E | 吸血鬼を昼夜問わず一撃で倒す。吸血鬼以外に使うと壊れる。**吸血鬼がいる試合のみ販売**。 |
| プロビデンスの眼光 | 2E | 自分以外の全員を60秒間発光させる。 |
| 天啓の呪符 | 2E | 夜のみ。使った夜に自分が占われると通知が来る。 |

!!! warning "役職専用アイテム"
    「人狼の斧」は人狼、「共犯者の目」は共犯者しか購入できません。役職が違う場合は取引が成立せず、エメラルドも消費されません。価格や一部アイテムの販売有無は運営の設定によって変わることがあります。

!!! tip "占い・加護は名前看板から"
    「占い師の心」「騎士の加護」は、フィールドに設置された **名前看板** に向かって右クリックして対象を指定します。看板には各プレイヤーの名前が登録されています（下記「名前の登録」参照）。占いは夜のみ使用できます。

## ゲームの流れ

1. **参加する** — `/wajinro join` か参加看板でロビーに加わります。
2. **開始を待つ** — 運営がゲームを開始するのを待ちます（既定で最低6人）。
3. **役職が配られる** — 人数に応じて役職が自動で割り振られ、チャットとタイトルに表示されます。人狼は仲間を把握できます。
4. **フィールドへ移動** — 全員がフィールドにテレポートされ、鈍器とステーキを持ってスタートします。
5. **名前を登録する** — 開始したら **名前看板を右クリックして自分の名前を登録** します（占い・加護の対象になるため）。未登録でも初日の夜に自動で割り当てられます。
6. **昼（議論）** — 発言できる時間。誰が人狼か推理します。
7. **夜（エメラルド稼ぎ・行動）** — 発言禁止。スケルトンを倒してエメラルドを集め、占いなど夜限定の能力を使います。
8. **戦闘で決着** — 昼夜を通じて、買った武器で人狼や吸血鬼を討ち取ります。
9. **繰り返し** — いずれかの勝利条件が満たされるまで昼夜を繰り返します。
10. **ゲーム終了** — 勝敗が決まると全員の役職が公開され、約8秒後にロビーへ戻ります。

## 参加と退出

- **参加** … `/wajinro join`、または **参加看板** を右クリック。参加するとロビーへテレポートされます。
- **退出** … `/wajinro leave`、または **離脱看板** を右クリック。参加前の位置に戻ります。

!!! note "テレポートと途中退出について"
    参加すると参加直前の位置・状態が保存され、退出やゲーム終了時に元に戻ります。ゲーム中に退出・切断すると **死亡扱い（脱落）** となり、初期スポーンへ戻されます。

## 名前の登録（占いのしくみ）

このゲームでは、占いや騎士の加護の対象を **名前看板** で指定します。

- ゲームが始まったら、フィールドの **名前看板を右クリックして自分の名前を登録** してください。
- 未登録のまま初日の夜を迎えると、空いている看板へ **自動で登録** されます（占い逃れ防止）。
- 「占い師の心」「騎士の加護」を持って名前看板を右クリックすると、その看板に登録されたプレイヤーが対象になります。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/wajinro join` | ゲーム（ロビー）に参加する（参加看板と同等・全員可） |
| `/wajinro leave` | ロビー／ゲームから離脱する（離脱看板と同等・全員可） |
| `/wajinro start [ステージ]` | ゲームを開始する（開始看板と同等・全員可。ステージが1つなら省略可） |
| `/wajinro status` | 設定状況・進行状況を確認する（全員可） |
| `/wajinro link` / `unlink` | Discordアカウントと連携／解除する（連携が有効な場合のみ） |
| `/wajinro linkcheck` | ロビー参加者のDiscord連携状況（連携済み／未連携）を確認する（全員可） |

エイリアスとして `/wj` も使えます。

!!! note "投票コマンドはありません"
    このゲームに投票の仕組みはありません。人狼の追放は **武器による直接戦闘** で行います。`/wajinro vote` のようなコマンドは存在しません。

## よくある質問

??? question "どうやってゲームに参加しますか？"
    `/wajinro join`（または `/wj join`）を実行するか、ロビーの参加看板を右クリックします。

??? question "どうやって人狼を追放しますか？"
    投票はありません。夜にスケルトンを倒してエメラルドを稼ぎ、ショップで一撃弓・怨念の槍などの武器を買って、人狼を直接倒してください。人狼は「人狼の斧」で村人を襲撃してきます。

??? question "エメラルドが貯まりません"
    エメラルドは **夜の間** に出現する「エメラルドの番人」（スケルトン）を倒すと一定確率で手に入ります。昼の間は出現しません。「スケ狩り剣」を買うと効率よく狩れます。

??? question "占いや守りはどう使いますか？"
    ショップで「占い師の心」「騎士の加護」を買い、フィールドの **名前看板** に向かって右クリックします。占いは夜のみ使用できます。加護は対象がその夜1回、弓・斧の即死を防げます（効果があるのは村人・共犯者のみ）。

??? question "夜に話せないのはなぜ？"
    夜は仕様で発言禁止（チャット・Discord VCともにミュート）です。朝になると再び発言できます。

??? question "ゲーム中に落ちる（切断）とどうなりますか？"
    ゲーム中の切断・退出は **死亡扱い（脱落）** になります。再ログインすると初期スポーンへ戻されます。
