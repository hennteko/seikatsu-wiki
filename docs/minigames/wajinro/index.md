# WaJinro（人狼RPG） <span class="badge dev">v1.0 / 新規追加</span>

Minecraft上で遊べる **人狼＋RPGアクション** のミニゲームプラグインです。昼夜サイクルの人狼をベースに、**夜にスケルトンを倒してエメラルドを稼ぎ、ショップで武器や特殊能力アイテムを購入して戦う** RPG要素を組み合わせています。追放は投票ではなく、購入した武器による **直接戦闘（PvP）** で決着するのが最大の特徴です。

!!! note "ゲームの特徴"
    昼は議論、夜はPvPと特殊能力で動く昼夜サイクル制の人狼です。**投票による追放はなく**、村人陣営は夜に稼いだエメラルドでショップの武器（一撃弓・怨念の槍・聖なる十字架など）や占い・守りのアイテムを買い、直接戦闘で人狼や吸血鬼を討ち取ります。人狼は専用の「人狼の斧」で村人を襲撃します。参加・開始はコマンドまたは看板で行い、占い・加護は各プレイヤーの「名前看板」を介して対象を指定します。
