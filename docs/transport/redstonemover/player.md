# RedstoneMover ― 遊び方 { .page-player #redstonemover-player }

RedstoneMover は、**レッドストーン回路（音ブロックの演奏）の速さに合わせて動く乗り物** に乗って楽しむギミックです。運営が設置した乗り場の **看板やボタンを右クリック** するだけで乗車でき、あとは演奏に合わせて乗り物が経路を進みます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 乗車方法 | 乗り場の **看板・ボタンを右クリック** |
    | 必要権限 | `redstonemover.ride`（既定で全員 true） |
    | 出発まで | 乗車後 既定 **5秒**（もう一度クリックですぐ出発） |
    | 動く仕組み | 回路のクロック、または経路沿いの音ブロック演奏に同期 |
    | 運行中の降車 | 既定で **不可**（スニークで降りられない） |
    | 進み具合 | ボスバーで表示（既定ON） |
    | 定員 | 乗り物ごとに決まった座席数まで |

## どんなギミック？

乗り物（可動体）は、近くの **レッドストーン回路の動き** に同期して進みます。回路が速く動けば乗り物も速く、ゆっくりなら乗り物もゆっくり進みます。演奏される曲に合わせて乗り物が走る「演奏ライド」のようなイメージです。

- **CLOCK 方式** … 回路のクロック（信号のON/OFFの繰り返し）1回ごとに少しずつ進みます。クロックが速いほど高速です。
- **NOTE 方式** … 経路沿いに置かれた **音ブロック** が鳴るたびに、その音の位置まで乗り物が進みます。曲の進行とともに乗り物が経路を進んでいきます。

勝敗や得点はありません。景色や演奏を楽しむための乗り物です。

## 乗り方

1. 乗り場の **看板（`[演奏ライド]` と表示）** か **ボタン** を **右クリック** します。
2. 座席に座り、`乗車しました。○秒後に出発します` と表示されます（既定5秒）。
3. カウントダウンの後、自動で出発します。**もう一度クリックすると、待たずにすぐ出発** できます。
4. 出発すると回路（演奏）が始まり、乗り物が経路に沿って動き出します。進み具合はボスバーに表示されます。

!!! tip "すぐ出発したいとき"
    乗車後の待ち時間中に、もう一度同じ乗り場をクリックすると、カウントダウンを飛ばしてすぐ出発します。

## 運行中の動き

- 乗り物は **回路・演奏の速さに同期** して進みます。演奏がゆっくりになれば乗り物も減速し、速くなれば加速します。
- 運行中は、既定では **スニークで降りられません**（経路の途中で落ちないようにするためです）。
- 経路の終点に着く、または演奏が止まると運行が終わり、`到着しました。ご乗車ありがとうございました` と表示されて **降車位置へ移動** します。

!!! note "演奏が始まらないとき"
    出発しても一定時間（既定8秒）回路の動き・演奏が検知できないと、`演奏が始まらなかったため、運行を終了しました` と表示されて運行が中止されます。演奏の開始を待っている間は「演奏の開始を待っています…」とアクションバーに出ます。

## 乗れないときの表示

| 表示 | 意味 |
|---|---|
| `演奏中です。終わるまでお待ちください` | 回路がすでに動いている最中です。少し待ってからどうぞ |
| `運行中です。戻ってくるまでお待ちください` | 乗り物が運行中です。戻ってくるのを待ちましょう |
| `満席です` | 座席がすべて埋まっています |
| `この乗り物は現在停止中です` | 運営が一時的に無効化しています |
| `この乗り物はまだ準備中です` | 設定が完了していません（運営の作業待ち） |
| `ミニゲーム参加中は乗れません` | 他のミニゲームに参加中は乗車できません |

## よくある質問

??? question "どうやって乗るの？"
    乗り場の看板（`[演奏ライド]`）かボタンを **右クリック** するだけです。コマンドは必要ありません（`/rmover` は運営専用です）。

??? question "乗ったのに動きません"
    乗り物は回路・演奏に同期して動きます。出発後に回路の動き・音ブロックの演奏が始まるまでは待機します。しばらく（既定8秒）経っても演奏が検知できないと、運行は自動で中止されます。設置や回路については運営にお問い合わせください。

??? question "途中で降りたい"
    運行中の降車は既定で無効です（サーバーの設定によっては許可されている場合があります）。基本的には終点の降車位置に着くまでお待ちください。

??? question "乗り物が急に止まった／速くなった"
    仕様です。乗り物は回路・演奏の速さにそのまま同期するため、演奏がゆっくりになれば減速し、速くなれば加速します。

??? question "ログアウトしたら乗り物から落ちませんか？"
    運行中にログアウト・死亡・ワールド移動などがあった場合は、自動的に乗車が解除されます（降車位置へ移される場合があります）。空中に取り残されることはありません。
