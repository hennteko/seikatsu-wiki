# CustomVehicles <span class="badge done">公開中</span>

カスタマイズ可能な車両システム。カタログGUIからエメラルドで **スポーツカー／SUV／バン** を購入し、エンジン・タイヤ・サスペンション・ブースト・カラーなどを段階的にアップグレードしながら、ブースト・ジャンプ・段差登りといった特殊能力で街を駆け抜けられます。

!!! info "CasinoPlugin との連携について"
    CustomVehicles は **CasinoPlugin** を `softdepend`（任意連携）としています。CasinoPlugin が導入されていると、その `EmeraldAPI` を通じて車両の **購入・アップグレード・カラー変更・ブースト/ジャンプの燃料消費** をエメラルド残高で行えます。CasinoPlugin が未導入の場合、エメラルド機能（購入・カスタマイズ・燃料消費）は動作しません。
