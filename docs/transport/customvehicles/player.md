# CustomVehicles ― 遊び方 { .page-player #customvehicles-player }

エメラルドで車両を購入し、自分だけの愛車を **アップグレード・カラー変更・修理** しながら走らせる車両プラグインです。スポーツカーで一人ドライブ、SUV や バン で複数人乗車もできます。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 車種 | スポーツカー（1人乗り）／SUV（2人乗り）／バン（4人乗り） |
    | 通貨 | エメラルド（CasinoPlugin の `EmeraldAPI` 経由） |
    | 購入方法 | 車両カタログ（紙アイテム）を右クリック → 購入GUI |
    | 操作 | WASD（移動）／右クリック（ブースト）／左クリック（ジャンプ）／Shift（降車） |
    | カスタマイズ | エンジン・タイヤ・サスペンション・ブースト・カラー |
    | メインコマンド | `/vehicle`（エイリアス `/v`・`/car`） |

## どんな機能？

CustomVehicles は、カスタマイズ可能な3車種を扱える車両プラグインです。

1. **車両カタログ**（紙アイテム）を右クリックして購入GUIを開く。
2. エメラルドで好きな車種を購入し、所持車両に追加する。
3. `/vehicle spawn <ID>` で召喚し、WASD で運転する。
4. アップグレードGUIで **エンジン／タイヤ／サスペンション／ブースト** を強化し、**カラー** も変更できる。
5. ダメージを受けたら **修理** で耐久値を回復する。

すべての車両は **ブースト・ジャンプ・段差登り** を標準で備えています。

## 車種一覧

| 車種 | 座席数 | カスタム上限 | 速度（カタログ表記） | 価格（既定値） |
|---|---|---|---|---|
| スポーツカー（`sports_car`） | 1人 | Lv.5 | ★★★★★ | 500エメラルド |
| SUV（`suv`） | 2人 | Lv.3 | ★★★☆☆ | 800エメラルド |
| バン（`van`） | 4人 | Lv.2 | ★★☆☆☆ | 1200エメラルド |

!!! note "座席数と乗車処理"
    座席が1の **スポーツカー** は召喚と同時に運転席へ自動着席します。SUV・バンは **座席選択GUI** が開き、乗りたい席を選んで着席します。運転席（座席0）に座ったプレイヤーだけがブースト・ジャンプを発動できます。

## 車両の入手方法（カタログ）

車両は **車両カタログ**（紙アイテム、緑色で「車両カタログ」と表示）から購入します。

### 車両カタログの入手

カタログアイテムは **`customvehicles.catalog` 権限**（既定 OP）が必要です。一般プレイヤーは管理者にカタログを配布してもらうか、サーバー独自の入手手段を確認してください。OP は次のコマンドで自分のインベントリに追加できます。

```text
/vehicle catalog
```

### カタログを使う

1. カタログ（紙アイテム）を手に持って **右クリック** する。
2. **車両購入GUI**（27スロット、タイトル「車両購入」）が開く。
3. スポーツカー（鉄の馬鎧）／SUV（金の馬鎧）／バン（ダイヤの馬鎧）から購入したい車をクリックする。
4. エメラルド残高が足りていれば購入が成立し、所持車両に追加される。

購入GUIの中央下段にはエメラルドアイコンで **現在の残高** が表示されます。残高不足の場合は購入できず、不足分がメッセージで通知されます。

!!! note "支払いは CasinoPlugin 経由"
    車両の購入代金、アップグレード費用、カラー変更費用（50E）、ブースト・ジャンプ時の燃料コスト（既定 2E／1E）は **すべて CasinoPlugin（EmeraldAPI）の残高** から引き落とされます。CasinoPlugin が未導入のサーバーでは購入・カスタマイズ・燃料消費は動作しません。

## 操作方法

車両に乗ったら以下の操作で運転します。

| 操作 | 効果 |
|---|---|
| **WASD** | 移動 |
| **右クリック** | ブースト発動（運転席のみ） |
| **左クリック** | ジャンプ発動（運転席のみ） |
| **Shift** | 降車（運転席で降りると車両が削除されます） |

!!! tip "ブースト・ジャンプを使うコツ"
    - 右クリックは **手にブロック／クラフター系の対話可能アイテムを持っていると無視** されます（誤発動防止）。素手や剣などに持ち替えてから操作してください。
    - ブーストは標準で **3秒間 +(ブーストLv.分の秒数)** 速度倍率が上がります。クールダウン中は発動できません（既定 10秒）。
    - ジャンプも独立したクールダウンを持ちます（既定 5秒）。
    - どちらの能力も **発動ごとにエメラルドを燃料として消費** します（既定 ブースト 2E／ジャンプ 1E）。残高が無いと発動できません。

## アップグレードと修理

`/vehicle upgrade` で **アップグレードGUI**（タイトル「★ 車両アップグレード ★」）を開けます。所持車両の最初の1台を対象に、各種強化と修理ができます。

| 項目 | 効果 | 上限 |
|---|---|---|
| **エンジン** | 最高速度を向上 (+5%/Lv) | 車種のカスタム上限まで |
| **タイヤ** | 加速力を向上 (+6%/Lv) | 同上 |
| **サスペンション** | 段差登り高さが上昇（1.5 + Lv×0.2 ブロック） | 同上 |
| **ブースト** | ブースト継続時間が延長（3秒 + Lv 秒） | 同上 |
| **カラー** | 12色から外装色を変更（費用 50E） | ― |
| **車両修理** | 耐久値を全回復（費用 = 失った耐久 × `repair.cost_per_durability`） | ― |

アップグレード費用は Lv.1→Lv.2 が 100E、以降 200E・400E・800E と倍々で上がります（Lv.4→Lv.5 は 800E）。最大レベルに達した項目は「最大レベル!」と表示され、クリックしてもアップグレードされません。

!!! note "車両ごとのカスタム上限"
    各車種にはアップグレード上限があります。スポーツカーは Lv.5、SUVは Lv.3、バンは Lv.2 までしか上げられません。長期的に強化したいならスポーツカーが有利です。

### カラーカスタマイズ

アップグレードGUIで「カラーカスタマイズ」をクリックすると、**カラーGUI**（タイトル「★ カラーカスタマイズ ★」）が開きます。

選べる色は次の12色です。1回の変更につき **50エメラルド** が必要です。

> 赤・オレンジ・黄・黄緑・緑・水色・青・紫・マゼンタ・ピンク・白・灰

### 修理

アップグレードGUIの「車両修理」アイコン（金床）をクリックすると、耐久値が **全回復** します。費用は失った耐久値1ポイントあたり `repair.cost_per_durability`（既定 1E）です。耐久値が100ならクリックしても費用はかかりません。

!!! warning "コマンド `/vehicle repair` は実装中"
    現状 `/vehicle repair` は「修理機能は実装中です」と表示されるだけです。修理は **アップグレードGUIの修理ボタン** から行ってください。

## 所持車両の管理

### 一覧表示

```text
/vehicle list
```

所持している全車両を「ID・表示名・耐久値・燃料」付きで一覧表示します。1台も持っていない場合は `/vehicle catalog` への案内が出ます。

### 車両情報

```text
/vehicle info <車両ID>
```

指定した車両の **車種・座席数・耐久値・燃料・各アップグレードレベル・カスタム上限・総走行距離・ブースト使用回数** などの詳細を確認できます。

### 召喚

```text
/vehicle spawn <車両ID>
```

指定IDの車両を自分の周囲に召喚します。すでに車両を召喚している場合は「既に車両を召喚しています」と表示され、Shiftで降車すると削除されます。**燃料が0** の車両は召喚できません。

### 削除

```text
/vehicle delete <車両ID>
/vehicle delete <車両ID> confirm
```

`confirm` 無しで実行すると確認メッセージが出ます。`confirm` を付けて再実行すると **車両が完全に削除** されます（取り消し不可）。

## プレイヤー用コマンド一覧

| コマンド | 説明 |
|---|---|
| `/vehicle`（`/v`・`/car`） | ヘルプを表示 |
| `/vehicle catalog` | 車両カタログ（紙アイテム）を入手 ※要 `customvehicles.catalog` 権限 |
| `/vehicle list` | 所持車両の一覧 |
| `/vehicle spawn <ID>` | 車両を召喚 |
| `/vehicle upgrade` | アップグレードGUIを開く（先頭の所持車両が対象） |
| `/vehicle repair` | （実装中）アップグレードGUIの修理ボタンから行ってください |
| `/vehicle info <ID>` | 車両情報を表示 |
| `/vehicle delete <ID> [confirm]` | 車両を削除 |

## よくある質問

??? question "車両カタログが手に入りません"
    `customvehicles.catalog` は既定で OP のみが持つ権限です。サーバー独自の配布手段（ショップ・スタッフ配布など）があるかは運営に確認してください。OPは `/vehicle catalog` で自分のインベントリに追加できます。

??? question "購入できません（エメラルド不足と表示される）"
    支払いは CasinoPlugin の `EmeraldAPI` から行われます。CasinoPlugin 内でのエメラルド残高を確認し、不足分を入金してください。CasinoPlugin が導入されていないサーバーでは購入そのものが動作しません。

??? question "右クリックでブーストできません"
    手に **ブロック** や **対話可能なアイテム**（クラフター系など）を持っていると、誤発動防止のため右クリックが無視されます。素手や剣などに持ち替えてからもう一度試してください。また、運転席（座席0）に座っていない場合もブースト・ジャンプは発動しません。

??? question "ブースト／ジャンプを連発できません"
    クールダウン制です（既定 ブースト10秒・ジャンプ5秒）。クールダウン中は「残り◯秒」のメッセージが出ます。

??? question "燃料が足りないと言われます"
    ブースト・ジャンプは1回ごとに **エメラルドを燃料として消費** します（既定 ブースト2E・ジャンプ1E）。CasinoPlugin の残高を補充してください。

??? question "Shiftで降りたら車が消えました"
    仕様です。運転席でShiftすると車両エンティティ自体が削除されます。再び乗るには `/vehicle spawn <ID>` で召喚し直してください。

??? question "アップグレードしたい車両を切り替えたい"
    現状 `/vehicle upgrade` は **所持車両の先頭（最初に作った1台）** が対象です（複数車両の選択GUIは未実装）。別の車両を強化したい場合は、対象でない車両を `/vehicle delete <ID> confirm` で整理する必要があります。実行は慎重に行ってください。
