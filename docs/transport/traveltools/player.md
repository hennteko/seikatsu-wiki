# TravelTools ― 遊び方 { .page-player #traveltools-player }

TravelTools は、生活鯖の **移動・テレポート系を一括で動かしている統合プラグイン** です。スポーン地点への帰還、プレイヤー追跡コンパス、ポータルの見える化、初めてネザーに入ったときの要塞通知の4つを、1つのプラグインでまとめて提供しています。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | できること | スポーン帰還 / プレイヤー追跡コンパス / ポータルの可視化 / 初回ネザー入場時の要塞通知 |
    | 主なコマンド | `/spawn` / `/compass` / `/compasslist` / `/compassreset` / `/pv` |
    | 必要なもの | 特になし（サーバーに入れば全員が使えます） |
    | 旧プラグインからの変化 | コマンド名・操作方法はそのまま。覚え直し不要 |

## どんなプラグイン？

TravelTools には **4つのモジュール** が入っています。どれもサーバーに入っていればすぐに使えます。

| モジュール | 一言で言うと | 主な操作 |
|---|---|---|
| 🏠 **spawn モジュール** | 現在いるワールドのスポーン地点へ一発で戻れる | `/spawn` |
| 🧭 **compass モジュール** | コンパスで他プレイヤーを追跡できる | `/compass <名前>` / `/compasslist` / `/compassreset` |
| 🌀 **portalvis モジュール** | Multiverse-Portals のポータル枠をパーティクルで見える化 | `/pv toggle` `/pv on` `/pv off` |
| 🔥 **nether モジュール** | 初めてネザーに入ったとき、最寄りのネザー要塞の座標をチャットで通知 | コマンド無し（自動） |

!!! tip "コマンドは旧プラグインのまま"
    TravelTools に統合されたあとも、コマンド名はすべて従来のままです（`/spawn` / `/compass` / `/pv` …）。旧 Spawn・Playercompass・PortalVisualizer・Netherfortress を使っていた人は、何も覚え直さずに今までどおり遊べます。

## モジュール別の使い方

### 🏠 spawn ― スポーン地点へ戻る

`/spawn` を実行すると、**今いるワールドのスポーン地点** へテレポートします。引数はありません。

- ワールドごとにスポーン地点が設定されているため、別ワールドに行くとそのワールドのスポーンへ戻ります。
- コマンドはプレイヤー専用です（コンソールからは実行できません）。
- 成功すると「スポーン地点にテレポートしました。」と緑文字で表示されます。

### 🧭 compass ― プレイヤーを追跡する

1. `/compasslist`（または `/pclist`）でオンラインのプレイヤー一覧を表示します。表示された名前の横の **[クリックして追跡]** をクリックすると、そのまま `/compass <名前>` が実行されます。
2. `/compass <プレイヤー名>` を実行すると、手持ちのコンパスが「追跡コンパス」（水色・太字）に変わります。コンパスを持っていなければ自動で配布されます。
3. 追跡コンパスを **手に持って右クリック** すると、その時点での相手の位置を指すように更新されます。
4. やめたいときは追跡コンパスを手に持ち、`/compassreset`（または `/pcreset`）で通常のコンパスに戻せます。

!!! tip "右クリックで指す位置を更新"
    追跡コンパスは常時リアルタイム追跡ではありません。相手が動いたら、コンパスを手に持って右クリックすると指す方向が更新されます。

### 🌀 portalvis ― ポータルの見える化

Multiverse-Portals で作られた **透明なポータル枠を、パーティクルで光らせて見える化** する機能です。

| コマンド | 説明 |
|---|---|
| `/pv toggle` | 自分の可視化表示を ON / OFF 切り替え |
| `/pv on` | 自分の可視化表示を ON |
| `/pv off` | 自分の可視化表示を OFF |

- ON / OFF はプレイヤー個人ごとに切り替わります。パーティクルが邪魔なら `/pv off` で自分だけ非表示にできます。
- 既定ではログイン時に自動で ON になります（運営側の設定により変更されている場合あり）。
- ポータルから一定距離（既定 30 ブロック）以内に近づいた時だけ描画されます。

### 🔥 nether ― 初回ネザー入場時の要塞通知

ネザーに **生涯で初めて入ったとき** に、最寄りのネザー要塞の座標を自動でチャットに表示します。コマンドや権限の操作は不要です。

- 見つかった場合: 「ネザー到達おめでとう！」とともに `X: ◯, Z: ◯` を金・水色のメッセージで通知。
- 2回目以降の入場では一切メッセージは出ません（仕様）。
- 既に生活鯖でネザーに入ったことのある人は、TravelTools 導入後も **再通知されません**（既存の「初回入場済み」記録がそのまま引き継がれます）。

## コマンド一覧（プレイヤー向け）

| コマンド | エイリアス | 説明 |
|---|---|---|
| `/spawn` | ― | 今いるワールドのスポーン地点へテレポート |
| `/compass <プレイヤー名>` | `/pc` / `/playercompass` | 指定プレイヤーを追跡する「追跡コンパス」を作成・設定 |
| `/compasslist` | `/pclist` | 自分以外のオンラインプレイヤー一覧（クリックで `/compass` 実行） |
| `/compassreset` | `/pcreset` | 手に持っている追跡コンパスを通常のコンパスに戻す |
| `/pv toggle` / `on` / `off` | `/portalvisualizer …` | ポータル可視化の自分用 ON / OFF |

!!! note "プレイヤーのみ実行可能"
    上記のコマンドはすべて **プレイヤーのみ** 実行可能です。コンソール／コマンドブロックからは実行できません。

## よくある質問

??? question "TravelTools 導入後、`/spawn` `/compass` `/pv` のコマンドは変わりますか？"
    変わりません。コマンド名・エイリアス・操作方法はすべて旧プラグインのままです。

??? question "ネザーに初めて入ったときの通知が出ません"
    既に一度でも生活鯖でネザーに入ったことがあるプレイヤーには、TravelTools 導入後も通知は出ません（仕様）。「初回入場済み」の記録が引き継がれているためです。

??? question "`/pv` を打っても何も起きません / 不明なコマンドになります"
    Multiverse-Portals が未導入のサーバーでは `portalvis` モジュールが自動で無効化され、`/pv` コマンドは使えません。`/spawn` `/compass` などの他モジュールは通常どおり動きます。詳細は運営にご確認ください。

??? question "追跡コンパスを右クリックしても位置が変わりません"
    手に持っているのが「追跡コンパス」（表示名が水色の太字「追跡コンパス」）でない可能性があります。`/compass <名前>` をやり直して追跡コンパスを作成してください。

??? question "コマンドを使うのに権限申請は必要ですか？"
    必要ありません。`/spawn` `/compass*` `/pv toggle/on/off` はすべてサーバーに入っていれば全員使えます。
