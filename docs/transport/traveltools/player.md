# TravelTools ― 遊び方 { .page-player #traveltools-player }

TravelTools は、生活鯖の **移動・テレポート系を一括で動かしている統合プラグイン** です。スポーン地点への帰還、プレイヤー追跡コンパス、ポータルの見える化、初めてネザーに入ったときの要塞通知、そして **一括破壊（鉱脈式）** の5つを、1つのプラグインでまとめて提供しています。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | できること | スポーン帰還 / プレイヤー追跡コンパス / ポータルの可視化 / 初回ネザー入場時の要塞通知 / 一括破壊（鉱脈式） |
    | プレイヤー操作 | スポーンは `/spawn` または `[Spawn]` 看板。追跡コンパス・ポータル可視化は **看板** から（`[Compass]` / `[PortalVis]` 看板を右クリック）。一括破壊は **スニークしながら採掘** するだけ |
    | コマンド | `/spawn` は **全員使用可**。`/compass*` / `/pv` は **OP 限定** （`traveltools.admin` が必要） |
    | 旧プラグインからの変化 | 追跡コンパス・ポータル可視化のコマンドは OP 専用に統合（プレイヤーは看板経由）。一括破壊が新機能として追加 |

## どんなプラグイン？

TravelTools には **5つのモジュール** が入っています。`/spawn` は誰でも使え、追跡コンパス・ポータル可視化のプレイヤー操作は **看板** から行います（これらのコマンドは OP 専用）。一括破壊はコマンド不要で発動します。

| モジュール | 一言で言うと | プレイヤー操作 |
|---|---|---|
| 🏠 **spawn モジュール** | 現在いるワールドのスポーン地点へ一発で戻れる | `/spawn` コマンド、または `[Spawn]` 看板を右クリック |
| 🧭 **compass モジュール** | コンパスで他プレイヤーを追跡できる | `[Compass]` 看板を右クリック → 頭一覧 GUI から選択 |
| 🌀 **portalvis モジュール** | Multiverse-Portals のポータル枠をパーティクルで見える化 | `[PortalVis]` 看板を右クリックで個人 ON/OFF |
| 🔥 **nether モジュール** | 初めてネザーに入ったとき、最寄りのネザー要塞の座標をチャットで通知 | 操作不要（自動） |
| ⛏️ **veinmine モジュール** | 原木・鉱石・砂などを **スニークしながら採掘** すると連結した同種ブロックをまとめて破壊 | スニーク（しゃがみ）しながら採掘するだけ |

!!! info "コマンドの権限"
    `/spawn` は **全員が使用可能** です（権限 `traveltools.spawn.use`、既定 true）。一方 `/compass` / `/compasslist` / `/compassreset` / `/pv` のコマンドは `traveltools.admin`（既定 op）が必要で、プレイヤーは運営が設置した **看板** 経由で利用します。看板の設置自体は誰でも可能なので、自宅などに `[Spawn]` `[Compass]` `[PortalVis]` を建てて使うのもアリです。

## モジュール別の使い方

### 🏠 spawn ― スポーン地点へ戻る

`/spawn` コマンドを実行すると、**今いるワールドのスポーン地点** へテレポートします。`/spawn` は誰でも使えます。

```text title="スポーン地点へテレポート（全員使用可）"
/spawn
```

看板でも同じことができます。1行目に `[Spawn]` と書いて看板を設置すると、リスナーが整形して水色の `[Spawn]` 看板になり、**右クリック** でスポーン地点へテレポートします。

- ワールドごとにスポーン地点が設定されているため、別ワールドに行くとそのワールドのスポーンへ戻ります。
- 成功すると「スポーン地点にテレポートしました。」と緑文字で表示されます。

### 🧭 compass ― プレイヤーを追跡する

1. 1行目に `[Compass]` と書いて看板を設置。
2. 看板を **右クリック** すると、オンラインのプレイヤー頭一覧 GUI が開きます。
3. 追跡したいプレイヤーの頭をクリックすると、追跡コンパス（水色・太字「追跡コンパス」）が配布されます。
4. 追跡コンパスは **手に持って右クリック** で、その時点の相手の位置を指す方向に更新されます。

!!! tip "右クリックで指す位置を更新"
    追跡コンパスは常時リアルタイム追跡ではありません。相手が動いたら、コンパスを手に持って右クリックすると指す方向が更新されます。

### 🌀 portalvis ― ポータルの見える化

Multiverse-Portals で作られた **透明なポータル枠を、パーティクルで光らせて見える化** する機能です。

- 1行目 `[PortalVis]` の看板を **右クリック** で自分の可視化を ON / OFF 切り替え。
- ON / OFF はプレイヤー個人ごとに切り替わります。パーティクルが邪魔なら看板を再度クリックして OFF に。
- 既定ではログイン時に自動で ON になります（運営側の `default-enabled` 設定により変更されている場合あり）。
- ポータルから一定距離（既定 30 ブロック）以内に近づいた時だけ描画されます。

### 🔥 nether ― 初回ネザー入場時の要塞通知

ネザーに **生涯で初めて入ったとき** に、最寄りのネザー要塞の座標を自動でチャットに表示します。コマンドや権限の操作は不要です。

- 見つかった場合: 「ネザー到達おめでとう！」とともに `X: ◯, Z: ◯` を金・水色のメッセージで通知。
- 2回目以降の入場では一切メッセージは出ません（仕様）。
- 既に生活鯖でネザーに入ったことのある人は、TravelTools 導入後も **再通知されません**（既存の「初回入場済み」記録がそのまま引き継がれます）。

### ⛏️ veinmine ― 一括破壊（鉱脈式）

原木・鉱石・砂などを、**スニーク（しゃがみ）しながら正しいツールで採掘** すると、連結している **同種ブロックをまとめて破壊** します。コマンドや看板は不要で、しゃがみながら掘るだけで発動します。

- **発動条件**：既定では **スニーク中のみ** 発動します。スニークしていない通常採掘では1ブロックだけ壊れます。
- **正しいツール**：既定では対応ツールを持っているときだけ発動します。
    - 鉱石 → **ツルハシ**
    - 原木 → **斧**
    - 砂 → **シャベル**
- **対象ブロック**：全種類の原木（樺・オーク〜真紅/歪んだ・皮を剥いだもの含む）、各種鉱石（石炭・鉄・銅・金・レッドストーン・ラピス・ダイヤ・エメラルド、ネザー/深層含む）と古代の残骸、砂・赤い砂。
- **一度に壊せる数**：既定で **最大64ブロック**（起点を含む）。連結していても上限を超える分は残ります。
- **耐久消費**：壊したブロックの分だけツールの耐久が減ります（耐久無限エンチャントがあれば軽減）。連鎖の途中でツールが壊れると、その時点で一括破壊は止まり「ツールが壊れたため一括破壊を中断しました。」と表示されます。
- **クリエイティブ**：クリエイティブモードでは発動しません（即時破壊のため対象外）。

!!! tip "斜めもまとめて掘れる"
    既定では斜め方向（上下左右前後＋ナナメの26方向）に連結したブロックも対象です。枝分かれした原木や斜めに伸びる鉱脈もまとめて回収できます。発動条件・対象ブロック・上限などは運営側の設定により変更されている場合があります。

## 看板の設置例

| 看板 | 1行目 | 設置後の効果 |
|---|---|---|
| スポーン帰還 | `[Spawn]` | 右クリックで現在ワールドのスポーン地点へ |
| 追跡コンパス | `[Compass]` | 右クリックで追跡先選択 GUI を表示 |
| ポータル可視化 | `[PortalVis]` | 右クリックで自分のポータル可視化 ON/OFF |

設置時に1行目を `[Spawn]` などと書くと、リスナーが整形して色付きの見出しに変わります。看板の **設置自体には権限不要** です（バニラ建築の延長）。

## よくある質問

??? question "TravelTools 導入後、`/compass` や `/pv` を打ったら『権限がありません』と言われます"
    仕様です。`/compass` 系と `/pv` のコマンドは **OP 専用** に統合されました。一般プレイヤーは運営が設置した `[Compass]` `[PortalVis]` 看板を経由して機能を利用してください。看板は自分で設置することもできます。なお `/spawn` は **全員が使用可能** です（『権限がありません』にはなりません）。

??? question "ネザーに初めて入ったときの通知が出ません"
    既に一度でも生活鯖でネザーに入ったことがあるプレイヤーには、TravelTools 導入後も通知は出ません（仕様）。「初回入場済み」の記録が引き継がれているためです。

??? question "`[PortalVis]` 看板を右クリックしても反応しません"
    Multiverse-Portals が未導入のサーバーでは `portalvis` モジュール自体が自動で無効化され、可視化は動作しません。`[Spawn]` `[Compass]` などの他モジュール看板は通常どおり動きます。詳細は運営にご確認ください。

??? question "追跡コンパスを右クリックしても位置が変わりません"
    手に持っているのが「追跡コンパス」（表示名が水色の太字「追跡コンパス」）でない可能性があります。`[Compass]` 看板から取り直してください。

??? question "看板を建てたいけど OP じゃないので無理ですか？"
    看板は誰でも建てられます。1行目に `[Spawn]` `[Compass]` `[PortalVis]` のいずれかを書けば、TravelTools が自動で整形して機能付き看板になります。

??? question "鉱石や木をまとめて掘りたいのに1ブロックしか壊れません"
    一括破壊（veinmine）は既定で **スニーク（しゃがみ）しながら、対応するツールで** 採掘したときだけ発動します。鉱石はツルハシ、原木は斧、砂はシャベルが必要です。しゃがまずに掘った場合や、素手・別のツールで掘った場合は1ブロックだけ壊れます。また、クリエイティブモードでは発動しません。

??? question "一括破壊が途中で止まりました"
    一度にまとめて壊せるのは既定で **最大64ブロック** までです（運営設定により変動）。また、壊したブロック分の耐久でツールが壊れると、その時点で一括破壊が止まり「ツールが壊れたため一括破壊を中断しました。」と表示されます。
