# CustomRailway ― 遊び方 { .page-player #customrailway-player }

トロッコを **鎖（IRON_CHAIN）** で連結して列車を作り、現在地に **駅** を登録して仲間と共有できる鉄道システムです。線路の下に特定のブロックを置くと、走行中のトロッコの速度が自動で切り替わります。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | プレイヤー操作 | `[Railway]` / `[Station]` 看板を右クリックして駅一覧 GUI を開く |
    | コマンド | `/railway` は **OP 限定**（`customrailway.admin` 必要） |
    | 駅の作成上限 | 既定で 1 人あたり **3 駅** まで（OP が駅を作成） |
    | 駅同士の最小距離 | 既定 **50 ブロック** 以上離す必要あり |
    | 列車の最大連結数 | 既定 **5 両**（先頭含む） |
    | 連結に使う道具 | 鎖（IRON_CHAIN） |
    | 切り離しに使う道具 | ハサミ（SHEARS） |
    | 既定で使える権限 | `customrailway.train.connect`（既定 true、鎖／ハサミ操作） |

## どんな機能？

CustomRailway は次の3つを軸にした鉄道プラグインです。

1. **駅の登録** … 現在地を「駅」として名前付きで登録し、GUIで一覧表示できます。
2. **列車の連結** … 鎖を持ってトロッコを Shift+右クリックで選択 → もう1つのトロッコを右クリックで連結。
3. **線路下ブロックでの速度制御** … 金・鉄・石炭・ダイヤ・エメラルドの各ブロックでトロッコの速度倍率が自動的に変わります。

## 駅の作成と利用

`/railway` コマンドは OP 限定のため、**駅の作成は運営に依頼** してください。OP が `/railway station create <駅名>` を現在地で実行することで駅が登録されます。一度登録された駅は誰でも `[Railway]` / `[Station]` 看板から閲覧できます。

| 失敗ケース（OP が駅を作る際） | 表示されるメッセージ |
|---|---|
| 同じ名前の駅が既にある | `駅の作成に失敗しました` |
| 自分の駅が上限に達している | `駅の作成上限に達しています（最大: 3）` |
| 既存の駅と近すぎる | `駅が近すぎます（{距離}m < 50m、最寄り駅: {駅名}）` |

!!! tip "駅の場所選び"
    最小距離（既定 50 ブロック）は他プレイヤーの駅も含めて判定されます。新規路線を伸ばすときは、人気エリアから少し離して計画しましょう。

### `[Railway]` / `[Station]` 看板から駅一覧を開く

1. 看板の1行目に `[Railway]` または `[Station]` と書いて設置（リスナーが整形して水色見出しに変換）。
2. 看板を **右クリック** すると `駅一覧` GUI が開き、登録されているすべての駅がアイテムとして表示されます。

| アイテム | 操作 |
|---|---|
| RAIL（自分の駅は POWERED_RAIL） | クリックで **駅詳細** を表示 |
| 下段：PLAYER_HEAD「自分の駅のみ表示」 | 自分が作成した駅だけに絞り込み |
| 下段：COMPASS「全ての駅を表示」 | 全駅表示に戻る |
| 下段：BOOK「駅情報」 | 総駅数・自分の駅数を表示 |

駅詳細画面では次の操作ができます。

- **テレポート（ENDER_PEARL）** … `customrailway.admin` 権限保持者のみ表示。
- **駅を削除（BARRIER）** … オーナー本人または管理権限者のみ表示。
- **戻る（ARROW）** … 一覧に戻る。

## 列車（トロッコ連結）

### 連結の手順

1. 線路に複数のトロッコを置く。
2. **鎖（IRON_CHAIN）** を手に持ち、先頭にしたいトロッコを **Shift+右クリック**。
    - `連結するトロッコを選択しました。もう一つのトロッコを右クリックしてください` と表示されます。
3. 続けてもう1つのトロッコを **右クリック** すると連結されます。
    - `列車を連結しました` と表示され、ハートのパーティクルが出ます（既定）。
4. 同じ要領で次の車両を Shift+右クリックで先頭側として選択し、後続を右クリックで増結。

!!! note "連結のルール"
    - 1 編成の最大連結数は **5 両（先頭含む）** です（既定）。
    - 先頭と連結先のトロッコは **10 ブロック以内** にある必要があります。`トロッコが遠すぎます（10ブロック以内）` と出たら近づけて再操作してください。
    - 同じトロッコ同士は連結できません。
    - 既に他の編成に組み込まれているトロッコは再連結できません。

### 切り離し

**ハサミ（SHEARS）** を手に持ってトロッコを右クリックすると、その車両を編成から切り離します。

- 先頭トロッコをハサミで右クリックすると、その編成全体が解散されます。
- 切り離し成功時は `列車を切り離しました` と表示されます。
- ハサミでの切り離しには `customrailway.train.connect` 権限が必要です（既定 true）。

### 列車の挙動

連結中、後続車両は **先頭の進行方向に沿って自動で追従** します（既定の車両間隔 1.5 ブロック）。先頭が停止すると追従ロジックも止まります。先頭が破壊されると編成全体が解散されます。

## 速度制御ブロック

線路の **2 ブロック下**（線路ブロック → その下のブロック → さらに下）に置いたブロック種で、走行中のトロッコの速度倍率が自動的に切り替わります。

| ブロック | 速度倍率（既定） | 用途 |
|---|---|---|
| DIAMOND_BLOCK | 3.0x | 超高速 |
| GOLD_BLOCK | 2.0x | 高速 |
| IRON_BLOCK | 1.0x | 通常 |
| COAL_BLOCK | 0.5x | 低速 |
| EMERALD_BLOCK | 0.0x（停止） | 駅・停止位置 |

最大速度は `train.max-speed-multiplier`（既定 3.0x）でクランプされます。倍率や対象ブロックは `config.yml` で変更できる項目のため、サーバーによって設定が異なる場合があります。

## 看板の設置例

| 看板 | 1行目 | 設置後の効果 |
|---|---|---|
| 駅一覧 GUI | `[Railway]` または `[Station]` | 右クリックで駅一覧 GUI を表示 |

設置時に1行目を `[Railway]` または `[Station]` と書くと、リスナーが整形して水色 `[Railway]` 見出しになります。看板の **設置自体には権限不要** です（バニラ建築の延長）。

## よくある質問

??? question "駅をもっとたくさん作りたい"
    既定では 1 人あたり 3 駅までです（`station.max-per-player`）。駅の作成自体は OP が代行するため、上限の引き上げを希望する場合はサーバー管理者に相談してください。

??? question "連結のときに `まず連結したいトロッコをShift+右クリックで選択してください` と出る"
    最初の手順を踏んでいません。**鎖を持って先頭側のトロッコを Shift+右クリック** してから、もう一方を右クリックしてください。

??? question "連結のときに `トロッコが遠すぎます（10ブロック以内）` と出る"
    選択済みのトロッコと連結先が 10 ブロック以上離れています。近づけてからもう一度右クリックしてください。

??? question "`連結に失敗しました` と表示された"
    既定の最大連結数（5 両）に達しているか、対象のトロッコが既に別の編成に組み込まれています。

??? question "駅GUIでテレポートできない"
    `customrailway.admin` 権限が必要です。一般プレイヤーはGUI上にテレポートボタンが表示されません。

??? question "`/railway` を打ったら『権限がありません』と出る"
    仕様です。`/railway` 系コマンドはすべて **OP 専用**（`customrailway.admin` が必要）。プレイヤーは `[Railway]` / `[Station]` 看板から駅一覧 GUI を開いてください。駅の作成や削除は運営に依頼します。

??? question "`/railway` で `route`（路線）が使えると聞きました"
    `route` サブコマンドは「§eこの機能は今後のアップデートで実装予定です」と返すスタブのみで、現バージョンでは実装されていません。駅データ上は「接続路線」を保持できますが、コマンドからの設定機能は未提供です。
