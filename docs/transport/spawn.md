# Spawn ― OP・運営ガイド { .page-op }

<span class="badge done">自作プラグイン</span>
<span class="badge simple">極小・単機能</span>

`/spawn` コマンドで、実行したプレイヤーを **現在いるワールドのスポーン地点** へテレポートさせるだけの極小プラグインです。設定ファイルや権限ノードを持たず、jar を入れて再起動するだけで動作します。スポーン地点そのものは Minecraft のワールド設定（`/setworldspawn` などで決まる位置）に依存します。

OP・運営側は「スポーン地点をどこに置くか」だけ管理すれば良く、プレイヤー側は `/spawn` と打つだけで戻ってこられます。

| 項目 | 値 |

| 設定ファイル | なし（config.yml は同梱されていません） |

## 導入手順

1. ビルドした `Spawn-1.0.jar`（または相当する jar）を `plugins/` フォルダに配置する。
2. サーバーを再起動する。起動ログに `Spawn plugin has been enabled!` が出れば成功。
3. テレポート先となるスポーン地点をワールド側で設定する（例：行きたい場所に立って `/setworldspawn` を実行）。

!!! tip "スポーン地点はワールドごとに別"
    `/spawn` は **そのプレイヤーが今いるワールドのスポーン地点** へテレポートします。複数ワールド運用の場合、各ワールドで個別にスポーン地点を設定しておく必要があります。

## コマンド一覧

| コマンド | 説明 | 実行可否 |
|---|---|---|
| `/spawn` | 実行したプレイヤーを、現在いるワールドのスポーン地点へテレポートする | プレイヤーのみ |

- `plugin.yml` の `description`：`スポーン地点にテレポートします。`
- `plugin.yml` の `usage`：`/<command>`
- 引数はありません。他プレイヤーをテレポートさせる機能はありません。
- コンソール／コマンドブロックから実行した場合は、`このコマンドはプレイヤーのみが実行できます。` と返されて何もしません。
- 成功時はプレイヤーに `スポーン地点にテレポートしました。` と緑文字で通知されます。

## 権限ノード

このプラグインの `plugin.yml` には **`permissions:` ブロックがありません**。また、コマンド側にも `permission:` 指定はありません。

そのため、

- **OP は当然実行可能**。
- 通常プレイヤーも、Bukkit のデフォルト挙動として `/spawn` を実行できます（コマンド側で権限チェックを行っていないため）。
- 権限管理プラグイン（LuckPerms など）で個別にブロックしたい場合は、コマンドそのものを禁止する形になります（プラグイン側に専用ノードは用意されていません）。

冷却（クールダウン）・遅延・コスト等の制御も実装されていません。実行すると即座にテレポートします。

## 設定

`config.yml` や `messages.yml` は同梱されていません。**プラグイン側に設定項目はありません**。

テレポート先は以下のロジックで決まります（ソースコード `Spawn.java` より）：

```java
player.teleport(player.getWorld().getSpawnLocation());
```

- `player.getWorld()` … コマンドを実行したプレイヤーが現在いるワールド。
- `getSpawnLocation()` … そのワールドに設定されているスポーン地点。

つまり、スポーン地点の管理＝ **ワールド側の `/setworldspawn`（または Multiverse の `/mv setspawn`）** で行います。本プラグイン側で位置を保存・上書きすることはありません。

!!! tip "ワールドごとのスポーンを変えたいとき"
    建築ワールド・資源ワールド・企画ワールドで `/spawn` の戻り先を分けたい場合は、それぞれのワールドで `/setworldspawn` を実行してください。プラグインの再起動は不要です。

## 注意点・トラブルシューティング

??? failure "コンソールから `/spawn` を実行しても動かない"
    仕様です。`/spawn` は **プレイヤー専用** で、コンソール／コマンドブロック／RCON からは実行できません。コンソールには「プレイヤーのみが実行できます」のメッセージが出ます。

??? failure "想定と違う場所にテレポートされる"
    プラグインは「ワールドのスポーン地点」をそのまま使うだけです。位置がおかしい場合は、現在いるワールドで `/setworldspawn` を実行し直してスポーン地点を更新してください。Multiverse 環境では `/mv setspawn` でも設定できます。

??? failure "別ワールドのスポーンに飛びたい"
    本プラグインは現在いるワールド内のスポーンにしか飛びません。ワールド間移動を伴うスポーン帰還が必要なら、Multiverse-Core の `/mv spawn` などを併用してください。

??? failure "クールダウンを掛けたい・コストを取りたい"
    本プラグインには冷却・コスト機能がありません。要件が出てきた場合はソース側に追記する形になります（`onCommand` 内に `teleport` を呼ぶ前後で制御を入れる、`config.yml` を新設するなど）。

??? question "/spawn を一部プレイヤーに使わせたくない"
    本プラグインは権限ノードを定義していないため、権限管理プラグインで `/spawn` コマンド自体の使用可否をコントロールする形になります（Bukkit のコマンド単位のブロック機能、もしくは LuckPerms の `command.spawn` 系の仕組みなど、利用中のプラグインの方式に従ってください）。
