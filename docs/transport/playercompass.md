# Playercompass ― プラグインガイド { .page-player }

<span class="badge done">自作プラグイン</span>

サーバー内の他プレイヤーをコンパスで追跡できる、シンプルな自作プラグインです。`/compass <プレイヤー名>` を実行するだけで、手持ちのコンパスがそのプレイヤーの位置を指すようになります。待ち合わせや合流時に便利です。

## 使い方

1. 追跡したい相手を `/compasslist`（または `/pclist`）で確認する。
2. `/compass <プレイヤー名>` を実行する。
    - 手にコンパスを持っていればそのコンパスが「追跡コンパス」に変化します。
    - 手にコンパスを持っていない場合は、新しいコンパスがインベントリに自動で配布されます。
3. 「追跡コンパス」を **持って右クリック** すると、その時点の相手の位置にコンパスの指す方向が更新されます。
4. リセットしたいときは、追跡コンパスを手に持って `/compassreset`（または `/pcreset`）を実行します。

!!! tip "コンパスは右クリックで更新する"
    追跡コンパスは **常時リアルタイム追跡ではありません**。相手が移動したら、コンパスを手に持って右クリックすることで指す位置が更新されます。アイテムのロア（説明文）にも「※プレイヤーの移動はリアルタイムで追跡されません」と表示されます。

!!! tip "/compasslist のクリックで即追跡"
    `/compasslist` で表示されたプレイヤー名の横の「[クリックして追跡]」をクリックすると、そのまま `/compass <名前>` が実行されます。

### 追跡コンパスの仕様

- アイテム名は「追跡コンパス」（水色・太字）に変わります。
- ロアに「追跡中: <プレイヤー名>」が表示されます。
- 内部的にはバニラのコンパスのロードストーン機能を利用しており、ロードストーンの存在チェックは無効化されています。

## コマンド一覧

| コマンド | エイリアス | 説明 |
|---|---|---|
| `/compass <プレイヤー名>` | `/pc` ／ `/playercompass` | 指定プレイヤーを追跡する「追跡コンパス」を作成・設定する |
| `/compasslist` | `/pclist` | 自分以外のオンラインプレイヤー一覧を表示。各行をクリックするとそのプレイヤーを追跡できる |
| `/compassreset` | `/pcreset` | 手に持っている追跡コンパスを通常のコンパスに戻す |

!!! note "プレイヤーのみ実行可能"
    すべてのコマンドは **プレイヤーのみ実行可能** です。コンソールから実行すると「このコマンドはプレイヤーのみ実行できます。」と表示されます。

### 補足

- 自分自身を追跡対象には指定できません（「自分自身を追跡することはできません。」と表示されます）。
- 指定したプレイヤーがオンラインに存在しない場合は「プレイヤー '<名前>' が見つかりません。」と表示されます。
- `/compasslist` は自分以外にプレイヤーがいない場合「追跡可能なプレイヤーがいません。」と表示します。
- `/compassreset` はコンパスを手に持っていないと「コンパスを手に持ってください。」と表示します。

## 権限ノード

`plugin.yml` に **permissions ブロックは定義されていません**。そのため、3つのコマンドは原則として **全プレイヤーが使用可能** です（Bukkit/Paper のデフォルト動作）。OP 専用にしたい場合は、別途権限管理プラグインで `bukkit.command.compass` 等のコマンド権限を制御してください。

## 注意点・トラブルシューティング

??? failure "右クリックしても「追跡中のプレイヤーがオフラインです。」と表示される"
    追跡コンパスを更新しようとした時点で、対象プレイヤーがログアウトしている状態です。`/compasslist` で再度オンラインのプレイヤーを選び直してください。

??? failure "コンパスを右クリックしても位置が更新されない"
    手に持っているのが「追跡コンパス」（表示名が水色の太字「追跡コンパス」）でない可能性があります。表示名が変わっていない、またはロアに「追跡中: …」が無いコンパスはこのプラグインの対象外です。`/compass <名前>` をやり直して追跡コンパスを作成してください。

??? failure "別ワールドの相手が指せているか分からない"
    プラグインは右クリック時点のターゲットの座標（ワールド含む）を `setLodestone` でコンパスに書き込みます。別ワールドのプレイヤーを指している場合、バニラの仕様上コンパスの針が正しい方向を示さないことがあります。同じワールドにいる相手で挙動を確認してください。

??? failure "/compass を実行したのにコンパスが配布されない"
    インベントリに空きが無いと、新規コンパスを追加できないことがあります。インベントリを整理してから再実行してください。

??? question "追跡を止めたい"
    追跡コンパスを手に持って `/compassreset`（`/pcreset`）を実行すると、表示名が「コンパス」に戻り、ロアも消えて通常のコンパスとして使えるようになります。
