# KartRace <span class="badge done">公開中</span>

マリオカート風の **カートレースミニゲーム**。最大8人でカートに乗り込み、コースを規定周回し、順位を競います。カートの強化・購入や、アイテムによる妨害・加速も楽しめます。

!!! info "サーバーでの稼働形態について"
    生活鯖で実際に稼働しているのは、統合版プラグイン **CasinoPlugin に内包されたカートレースモジュール** です。このページは KartRace 本体の機能を基準に解説しています。CasinoPlugin 側では一部の挙動・コマンド名が異なる場合があります。
