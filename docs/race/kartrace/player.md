# KartRace ― 遊び方 { .page-player #kartrace-player }

マリオカート風のカートレースミニゲームです。カートに乗ってコースを走り、規定の周回数を最速で走り切って上位を目指しましょう。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 最大8人 |
    | 周回数 | 既定3周（コースにより変動） |
    | 制限時間 | 既定5分（時間切れでレース終了） |
    | 通貨 | エメラルド（EmeraldBank連携） |

## どんなゲーム？

待機ロビーに集まったプレイヤーが一斉にスタートし、コースを走って順位を競います。カートはマインカートをベースにした乗り物で、Java版でも統合版（Geyser経由）でも遊べるように作られています。

レースで稼いだエメラルドで **カートを購入** したり、**カートを強化** したり、見た目を **カスタマイズ** したりできます。走るほど自分だけの一台に育てられるのが魅力です。

## レースの流れ

1. **参加する** — ロビーにある `[KartRace]` 看板をクリック、または `/kartrace join` でロビーに入ります。
2. **待機** — 規定の最小人数（既定2人）が集まるとカウントダウン（既定30秒）が始まります。
3. **カートを選ぶ** — カウントダウン中にガレージを開いて使うカートを選べます。
4. **スタート** — カウントダウン後、5・4・3・2・1のスタートカウントを経て「GO!」でレース開始。
5. **走る** — コース上のチェックポイントを順番に通過しながら、規定周回数を走ります。
6. **ゴール** — 規定周回を終えてゴールラインを通過すると順位が確定します。
7. **結果と報酬** — 全員ゴールまたは時間切れで結果発表。順位に応じてエメラルドが支払われます。

!!! tip "チェックポイントは順番どおりに"
    コースにはチェックポイントが設定されています。番号順に通過しないと周回がカウントされません。ショートカットでスキップしないよう注意しましょう。

## ガレージ（`/kartrace garage`）

`/kartrace garage` で **ガレージGUI** を開けます。ガレージは所有しているカートを管理する場所です。

- 複数のカートを **スロット** に保管できます（初期2スロット、最大10スロットまで拡張可能）。
- 使用するカートを選択できます。レースでは選択中のカートで出走します。
- カートごとに **強化レベル** や **見た目（コスメティック）** が個別に保存されます。

!!! note "カートの種類"
    スターターカート（無料）のほか、スピード型・ドリフト型・加速型・重量型などさまざまなカートがあります。性能はカートごとに異なり、得意なコースも変わります。購入はショップから行います。

## ショップ（`/kartrace shop`）

`/kartrace shop` で **ショップGUI** を開けます。エメラルドを使って以下を購入できます。

- **カート本体** — 新しい種類のカートを購入してガレージに追加。
- **カートの強化** — 速度・加速・ハンドリングなど各性能をレベルアップ。
- **見た目のカスタマイズ** — カラー、走行エフェクト（トレイル）、クラクションなど。
- **ガレージスロットの拡張** — 保管できるカートの枠を増やす。

!!! warning "強化は後半ほどリスクあり"
    カートの強化はLv100まで上げられますが、高レベル帯では **強化失敗** によるレベル維持・低下が発生します。さらに最高ランク帯では失敗時の **破壊** リスクもあります。保護アイテムを使うとリスクを抑えられます。

## アイテムボックス

コース上には **アイテムボックス** が設置されています。通過するとランダムでレースアイテムが手に入ります。

- スピードブースト、スターなどの **自分を加速・強化するアイテム**。
- 甲羅やバナナなどの **他のレーサーを妨害するアイテム**。
- 順位が低いほど強力なアイテムが出やすくなる調整が入っています。

!!! info "実装状況について"
    アイテムボックスの設置やアイテムの抽選はプラグインに組み込まれています。CasinoPlugin 版での挙動はサーバーの設定により異なる場合があります。詳細はサーバー運営の案内を確認してください。

## 看板からの参加方法

ロビーに設置された **`[KartRace]` 看板** を右クリックするだけで参加できます。

- 看板には **コース名・参加人数・現在の状態**（待機中／カウントダウン中／レース中など）が表示されます。
- 参加・退出・ガレージ・ショップはそれぞれ専用の看板が用意されています（レース中は退出できません）。

## コマンドについて

`/kartrace`（別名 `/kr`、`/kart`、`/race`）コマンドは **OP専用** です。一般プレイヤーは看板から操作してください。

| コマンド（OP専用） | 説明 |
|---|---|
| `/kartrace join` | レース（ロビー）に参加する |
| `/kartrace leave` | レース（ロビー）から退出する |
| `/kartrace garage` | ガレージGUIを開く |
| `/kartrace shop` | ショップGUIを開く |
| `/kartrace stats` | 自分の統計（総レース数・勝利数など）を表示 |
| `/kartrace help` | コマンド一覧を表示 |

!!! note "一般プレイヤーの操作は看板から"
    参加／退出／ガレージ／ショップはすべて看板の右クリックで操作できます。コマンドを実行すると「このコマンドはOP専用です」と表示されます。

## よくある質問

??? question "周回がカウントされません"
    チェックポイントを **番号順に通過** する必要があります。順番を飛ばすとその周回は無効になります。コースから外れていないかも確認しましょう。

??? question "レース中に退出できますか？"
    レースが始まると退出できません。ロビーの待機中・カウントダウン中であれば退出できます。

??? question "カートを強化したのに弱くなりました"
    高レベル帯の強化は失敗することがあり、レベルが維持・低下する場合があります。安全に強化したいときは保護アイテムの使用を検討してください。

??? question "統合版（スマホ・Switchなど）でも遊べますか？"
    遊べます。KartRace は統合版（Geyser経由）でも動作するように設計されています。生活鯖では CasinoPlugin に内包された形で稼働しています。
