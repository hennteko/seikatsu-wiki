# BoatGP <span class="badge dev">開発中 / Phase 1</span>

マリオカート風の **氷ボートレースミニゲーム**。プラグイン駆動の「カート方式」で常に前進し、ステアリングを操作してチェックポイントを通過しながら規定周回を走り、順位を競います。

!!! warning "開発状況について"
    BoatGP は現在 **Phase 1（レースエンジン）** です。カート物理・路面システム・チェックポイント判定・順位HUD・コース外復帰・簡易報酬までは実装済みですが、**アイテムバトル（バナナ・こうら・スターなど）は Phase 2 で実装予定の未実装機能** です。このWIKIは現在のソースコードに基づくガイドのため、今後のアップデートで内容が変わる場合があります。
