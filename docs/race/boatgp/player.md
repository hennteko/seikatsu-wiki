# BoatGP ― 遊び方 { .page-player #boatgp-player }

マリオカート風の氷ボートレースです。カートは自動で前進するので、プレイヤーは **ステアリング（旋回操作）** と **アイテム** に集中して、チェックポイントを正しく通過しながら規定周回を走り切ってゴールを目指します。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 最少1〜2人（サーバー設定による）/ 最大12人（サーキットのスタートグリッド数で上限が変わります） |
    | 周回数 | 既定3周（サーキットごとに異なります） |
    | 勝利条件 | 規定周回を最も早く走り切る |
    | アイテム | コース上のアイテムボックスで入手。降車ボタンで発動 |
    | コースアウト時 | 直近のチェックポイントへ自動で戻されます |
    | 参加・離脱 | ロビーの **看板をクリック**（`/race` コマンドはOP専用） |

## どんなゲーム？

BoatGP は「カート方式」で動くレースゲームです。レース中、ボート（カート）は **プラグインによって常に前進** します。アクセル操作は不要で、プレイヤーが行うのは **ステアリング（旋回）** と **アイテムの発動** だけです。旋回は **左右移動キー（A/D）** で行い、プラグインが車体を曲げます。

足元のブロックによって「路面」が変わり、最高速とグリップ（曲がりやすさ）が変化します。氷の上は速いけれど滑りやすく、ブーストパッドを踏むと一気に加速します。コース上の **アイテムボックス** を通るとアイテムが手に入り、こうらやバナナで相手を妨害したり、スターやダッシュキノコで一気に追い上げたりできます。

!!! note "Java版・統合版どちらでも同じ操作"
    BoatGP は **入力ベース操舵** を採用しており、ステアリングは **左右移動キー（A/D・統合版は左右の移動操作）** で行います。ボートの旋回をプラグイン側で制御するため、Java版・統合版（スマホ・タブレット含む）どちらのプレイヤーも **まったく同じ操作** でレースに参加できます。アイテムの発動は **降車ボタン** に割り当てられています。

## レースのルール

- カートは **自動で前進** します。減速・停止はできません。
- 操作は **ステアリング（左右移動キー A/D での旋回）** と **アイテム発動（降車ボタン）** だけです。
- **チェックポイントを正しい順序で通過** したラップだけが有効です。ショートカットでチェックポイントを飛ばすと周回が進みません。
- フィニッシュラインを規定周回ぶん通過したらゴールです。
- レース中は **プレイヤーもボートもダメージを受けません**（カートが壊れる心配はありません）。
- レース中・カウントダウン中の降車操作は、それぞれ **アイテム発動** と **ロケットスタート** に割り当てられています。レースを途中でやめたいときは **離脱看板（LEAVE）をクリック** します。

!!! warning "参加・離脱は看板から（コマンドはOP専用）"
    `/race` コマンドは **OP（運営）専用** です。プレイヤーは **ロビーの看板をクリック** して参加・離脱します（参加看板 JOIN／離脱看板 LEAVE）。`/race join` などのコマンドは一般プレイヤーには使えません。

## 操作方法

| 操作 | やり方 | 効果 |
|---|---|---|
| ステアリング（旋回） | **左右移動キー（A/D）** を押す（統合版は左右の移動操作） | 左右に曲がる |
| アイテム発動 | **降車ボタンを単押し**（Java版＝スニーク／統合版＝降車ボタン） | 持っているアイテムを使う |
| ロケットスタート | カウントダウン中に降車ボタンを **良いタイミングで** 単押し | スタート時にダッシュ |
| レース離脱 | ロビーの **離脱看板（LEAVE）をクリック** | レースから抜ける |

!!! tip "アイテムは1ボタンでOK"
    アイテムの「狙う方向」は自動で決まります。攻撃アイテム（こうら）は前方へ、トラップ（バナナ）は後方へ、強化アイテム（ダッシュキノコ・スター・サンダー）は自分や全体へ自動でかかります。降車ボタンを押すだけで使えます。

!!! note "コーナーでは自動で減速"
    左右キー（A/D）で **操舵中は自動で速度が少し落ちる** ので、直線で攻めて、曲がるときだけ旋回入力を入れるとタイムが伸びます。氷路面ではグリップが下がり、減速しても流れやすいので、コーナー手前で早めに向きを作るのがコツです。

## 路面の種類

足元のブロックで走行性能が変わります。

| 路面 | 速度 | グリップ | 特徴 |
|---|---|---|---|
| 標準路面（石・コンクリート・草など） | 標準 | 高い | 通常コース。曲がりやすい |
| 氷路面（青氷・氷塊・氷） | 高速 | 低い | 速いが滑る。上級者ゾーン |
| ブーストパッド（薄水色・黄色コンクリート） | 大幅アップ | 高い | 踏むと一定時間ダッシュ |
| オフロード（砂・ソウルサンド・砂利・小道など） | 低速 | 中 | コース外ペナルティ。遅くなる |
| 危険ブロック（マグマ・マグマブロック・水） | クラッシュ | - | 乗るとチェックポイントへ戻される |

## アイテムバトル

コース上に置かれた **アイテムボックス**（エンドロッドのパーティクルが光る目印）を通過すると、アイテムが1つ自動で抽選されます。手に入れたアイテムは画面上部の **ボスバー** に表示され、**降車ボタンの単押し** で発動します。

!!! note "アイテムボックスのルール"
    - すでにアイテムを持っているときは、アイテムボックスを通っても拾えません（先に使ってから取りに行きましょう）。
    - 取ったアイテムボックスは数秒のクールダウンの後、再び出現します。

### アイテム6種

| アイテム | 種別 | 効果 |
|---|---|---|
| 🍄 ダッシュキノコ | 強化 | 一定時間ダッシュ（自己加速）する |
| 🟢 みどりこうら | 攻撃 | 前方へまっすぐ飛ぶ攻撃弾。当たった相手はスピン |
| 🔴 あかこうら | 攻撃 | 前方の相手を追尾する攻撃弾。近くの相手をホーミング |
| 🍌 バナナ | トラップ | 自分の後ろに置く。踏んだ相手はスピン |
| ⭐ スター | 強化 | 一定時間 無敵＋加速。さらに体当たりで相手をスピンさせる |
| ⚡ サンダー | 妨害 | 自分以外の全員を一定時間減速させる |

!!! tip "順位で出やすいアイテムが変わる（ラバーバンド）"
    アイテムの抽選は **現在の順位** で重み付けされています。**下位のプレイヤーほど強力なアイテム**（スター・サンダー・あかこうら）が出やすく、**上位はバナナ・みどりこうら・ダッシュキノコ** が中心になります。これにより8人以上でも最後まで僅差の混戦になります。

### スピン（クラッシュ）

こうらやバナナが当たったり、スター中の相手に体当たりされたりすると、一定時間 **スピンして停止** します。スピン中は操作できないので、アイテムをうまく避けることが大切です。**スター発動中は無敵** で、こうら・バナナ・体当たりをすべて受けません。

## ロケットスタート

スタート前のカウントダウン（3・2・1）中に、**GOの直前の良いタイミングで降車ボタンを押す** と「ロケットスタート」が成功し、スタートと同時にダッシュできます。

- タイミングが合うと「ロケットスタート!」と表示され、スタート時にブーストがかかります。
- 早すぎると「フライング」扱いになり、ブーストは発生しません。
- 判定は **1回だけ** です。慎重にタイミングを計りましょう。

## ゲームの流れ

1. **参加する** — ロビーの **参加看板（[BoatGP] JOIN）をクリック** してレースに参加します（`/race` コマンドはOP専用のため、プレイヤーは看板を使います）。
2. **待機** — 最少人数が集まると、待機ロビーで開始までのカウントダウン（既定30秒）が始まります。
3. **スタートグリッドへ整列** — カウントが終わると全員がスタートグリッドへ転送され、ボートに乗せられて固定されます。
4. **3・2・1・GO!** — グリッド整列後の3秒カウント。この間に降車ボタンでロケットスタートを狙えます。
5. **走る** — チェックポイントを順番に通過しながら規定周回を走ります。アイテムボックスでアイテムを拾い、降車ボタンで発動します。
6. **ゴール** — フィニッシュラインを規定周回ぶん通過するとゴール。順位とタイムが表示され、報酬を受け取ってロビーへ戻ります。
7. **レース終了** — 全員ゴール、または1位ゴール後の制限時間（既定60秒）が過ぎるとレースが終了し、最終順位が発表されます。終了後はそのまま **ロビーに戻って参加状態が維持** され、人数がそろっていれば次のレースのカウントダウンが自動で始まります（連続プレイ）。

## HUD（画面表示）

レース中は次の情報が画面に表示されます。

| 表示先 | 内容 |
|---|---|
| サイドバー | サーキット名 ／ LAP（現在/総周回数）／ 順位（現在/参加人数）／ 経過タイム |
| ボスバー（画面上部） | 現在持っているアイテム（持っていないときは「なし」） |
| タイトル（画面中央） | 「GO!」「FINISH!」、ロケットスタート成功、スピン時の「クラッシュ!」など |
| チェックポイント表示 | コース上にパーティクルの「ゲート」が見える（**次に通るCP=緑／ゴール=金／その他=水色**・自分だけに表示） |

!!! tip "次に通るチェックポイントは緑のゲート"
    レース中はチェックポイントとゴールラインが光るゲートで表示されます。**緑のゲートが次に通過すべきチェックポイント** です。順番に緑のゲートをくぐっていけば正しい順路を走れます（表示は自分だけで、他の人には見えません）。

## 事故・コースアウト時の救済

高速で走るゲームなので、事故対応が用意されています。

- **コースアウト・危険ブロック・落下** → 直近のチェックポイントへ正しい向きで自動復帰します。
- **スタック（一定時間ほとんど動けない）** → 直近のチェックポイントへ自動復帰します。
- **切断** → レースから除外されます。

## 参加・離脱は看板で

`/race` コマンドは **OP（運営）専用** のため、プレイヤーはロビーに設置された **看板** で操作します。

| 看板 | 操作 | 効果 |
|---|---|---|
| 参加看板（[BoatGP] JOIN） | クリック | レースに参加する |
| 離脱看板（[BoatGP] LEAVE） | クリック | レースから離脱する |
| 開始看板（[BoatGP] START） | クリック | レースを強制開始（**OPのみ有効**） |
| 情報看板（[BoatGP-Info]） | 見るだけ | そのコースの募集状況・参加人数を自動表示（クリック不要） |

!!! note "看板でかんたんに参加・離脱"
    ロビーの **参加看板（JOIN）／離脱看板（LEAVE）** をクリックするだけで参加・離脱できます。コマンドを覚える必要はありません。**開始看板（START）** はOPがクリックしたときだけレースを強制開始します。ロビーの **情報看板（[BoatGP-Info]）** には、そのコースの募集状況と現在の参加人数が自動表示されます。

## よくある質問

??? question "アクセルやブレーキはどう操作しますか？"
    カートは自動で前進するため、アクセル・ブレーキ操作はありません。プレイヤーが操作するのは **ステアリング（旋回）** と **アイテムの発動** だけです。

??? question "どうやって曲がりますか？（ステアリング操作）"
    **左右移動キー（A/D。統合版は左右の移動操作）** で曲がります。ボートの旋回はプラグインが制御する **入力ベース操舵** のため、Java版・統合版（スマホ・タブレット含む）のどちらでも同じ操作です。マウスやカメラの向きでは曲がりません。曲がっている間は自動で少し減速します。

??? question "バナナやこうらなどのアイテムはどうやって使いますか？"
    コース上の **アイテムボックス** を通過するとアイテムが1つ手に入り、画面上部のボスバーに表示されます。**降車ボタンを単押し** すると発動します。狙う方向は自動で決まるので、ボタンを押すだけでOKです。

??? question "アイテムが拾えません"
    すでにアイテムを1つ持っているときは、アイテムボックスを通っても新しく拾えません。先に持っているアイテムを使ってから取りに行ってください。また、取った直後のアイテムボックスは数秒のクールダウン中は出現しません。

??? question "スピンして動けなくなりました"
    こうら・バナナが当たったり、スター中の相手に体当たりされたりすると、一定時間スピンして停止します。少し待てば自動で復帰します。スターを使っている間は無敵で、これらの攻撃を受けません。

??? question "ロケットスタートのコツは？"
    カウントダウン（3・2・1）中、GOの直前の良いタイミングで降車ボタンを押します。早すぎると「フライング」でブーストなし、判定は1回だけです。何度かレースをして感覚をつかみましょう。

??? question "コースアウトしてしまいました"
    危険ブロックに乗ったり、コース外でスタックしたり、落下したりすると、自動的に直近のチェックポイントへ戻されます。慌てずそのまま走り続けてください。

??? question "ショートカットでチェックポイントを飛ばせますか？"
    チェックポイントは **正しい順序で通過する必要** があります。飛ばすと周回がカウントされないため、結果的に不利になります。

??? question "途中でレースをやめたいです"
    ロビーの **離脱看板（LEAVE）をクリック** するとレースから離脱できます。レース中・カウントダウン中の降車操作はアイテム発動／ロケットスタートに割り当てられているので、離脱は看板から行ってください（`/race` コマンドはOP専用です）。
