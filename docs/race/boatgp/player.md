# BoatGP ― 遊び方 { .page-player #boatgp-player }

マリオカート風の氷ボートレースです。カートは自動で前進するので、プレイヤーは **ステアリング（旋回操作）** に集中して、チェックポイントを正しく通過しながら規定周回を走り切ってゴールを目指します。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 最少2人 / 最大12人（サーキットのスタートグリッド数で上限が変わります） |
    | 周回数 | 既定3周（サーキットごとに異なります） |
    | 勝利条件 | 規定周回を最も早く走り切る |
    | コースアウト時 | 直近のチェックポイントへ自動で戻されます |

## どんなゲーム？

BoatGP は「カート方式」で動くレースゲームです。レース中、ボート（カート）は **プラグインによって常に前進** します。アクセル操作は不要で、プレイヤーが行うのは **ボートのパドル左右操作（ステアリング）** だけです。

足元のブロックによって「路面」が変わり、最高速とグリップ（曲がりやすさ）が変化します。氷の上は速いけれど滑りやすく、ブーストパッドを踏むと一気に加速します。

!!! note "Java版・統合版どちらでも同じ操作"
    BoatGP は標準のボート操作で遊べるように設計されています。Java版・統合版（スマホ・タブレット含む）どちらのプレイヤーも同じ操作でレースに参加できます。

## レースのルール

- カートは **自動で前進** します。減速・停止はできません。
- 操作は **ステアリング（パドル左右での旋回）** のみです。
- **チェックポイントを正しい順序で通過** したラップだけが有効です。ショートカットでチェックポイントを飛ばすと周回が進みません。
- フィニッシュラインを規定周回ぶん通過したらゴールです。
- レース中は **プレイヤーもボートもダメージを受けません**（カートが壊れる心配はありません）。
- レース中・カウントダウン中は **降車できません**（誤操作防止のため降車操作はキャンセルされます）。レースを途中でやめたいときは `/race leave` を使います。

## 路面の種類

足元のブロックで走行性能が変わります。

| 路面 | 速度 | グリップ | 特徴 |
|---|---|---|---|
| 標準路面（石・コンクリート・草など） | 標準 | 高い | 通常コース。曲がりやすい |
| 氷路面（青氷・氷塊・氷） | 高速 | 低い | 速いが滑る。上級者ゾーン |
| ブーストパッド（薄水色・黄色コンクリート） | 大幅アップ | 高い | 踏むと一定時間ダッシュ |
| オフロード（砂・ソウルサンド・砂利・小道など） | 低速 | 中 | コース外ペナルティ。遅くなる |
| 危険ブロック（マグマ・マグマブロック・水） | クラッシュ | - | 乗るとチェックポイントへ戻される |

## ゲームの流れ

1. **参加する** — `/race join` でレースに参加します。サーキットを指定する場合は `/race join <サーキット名>` です。
2. **待機** — 最少人数（既定2人）が集まると、待機ロビーで開始までのカウントダウン（既定30秒）が始まります。
3. **スタートグリッドへ整列** — カウントが終わると全員がスタートグリッドへ転送され、ボートに乗せられて固定されます。
4. **3・2・1・GO!** — グリッド整列後の3秒カウントの後、レース開始。
5. **走る** — チェックポイントを順番に通過しながら規定周回を走ります。HUD（サイドバー）にラップ・順位・タイムが表示されます。
6. **ゴール** — フィニッシュラインを規定周回ぶん通過するとゴール。順位とタイムが表示され、報酬を受け取ってロビーへ戻ります。
7. **レース終了** — 全員ゴール、または1位ゴール後の制限時間（既定60秒）が過ぎるとレースが終了し、最終順位が発表されます。

## HUD（画面表示）

レース中は画面サイドバーに次の情報が表示されます。

| 表示 | 内容 |
|---|---|
| サーキット | 走行中のサーキット名 |
| LAP | 現在の周回数 / 総周回数（例 2/3） |
| 順位 | 現在の順位 / 参加人数（例 3/8） |
| タイム | レース開始からの経過タイム |

## 事故・コースアウト時の救済

高速で走るゲームなので、事故対応が用意されています。

- **コースアウト・危険ブロック・落下** → 直近のチェックポイントへ正しい向きで自動復帰します。
- **スタック（一定時間ほとんど動けない）** → 直近のチェックポイントへ自動復帰します。
- **切断** → レースから除外されます。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/race join [サーキット名]` | レースに参加する（サーキット名を省略すると先頭のサーキット） |
| `/race leave` | レースから離脱する |
| `/race list` | サーキットの一覧を表示する |

!!! note "コマンドのエイリアス"
    `/race` は `/boatgp` でも実行できます。

## よくある質問

??? question "アクセルやブレーキはどう操作しますか？"
    カートは自動で前進するため、アクセル・ブレーキ操作はありません。プレイヤーが操作するのは **ステアリング（旋回）** だけです。

??? question "バナナやこうらなどのアイテムは使えますか？"
    アイテムバトルは **Phase 2 で実装予定** の機能で、現在の Phase 1 では未実装です。今は純粋なレースエンジンのみが動いています。

??? question "コースアウトしてしまいました"
    危険ブロックに乗ったり、コース外でスタックしたり、落下したりすると、自動的に直近のチェックポイントへ戻されます。慌てずそのまま走り続けてください。

??? question "ショートカットでチェックポイントを飛ばせますか？"
    チェックポイントは **正しい順序で通過する必要** があります。飛ばすと周回がカウントされないため、結果的に不利になります。

??? question "途中でレースをやめたいです"
    `/race leave` でレースから離脱できます。レース中・カウントダウン中は降車操作ではやめられないので、必ずコマンドを使ってください。
