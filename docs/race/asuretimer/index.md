# AsureTimer <span class="badge done">公開中</span>

1000m アスレチックコースの **タイム計測＆ランキングプラグイン**。ステージのロビーに集まって **一斉スタート** する **マルチモード**（途中参加OK）と、1人ですぐ走り始めて何度も挑戦できる **ソロモード** があります。チェックポイント感圧板による復帰機能、**通過済みチェックポイントへ戻れる「戻るアイテム」**、**ゴースト（自分だけに見える再生）**・**区間タイム**、ドロッパーモードにも対応しています。

!!! info "プラグインについて"
    AsureTimer は単独のプラグイン（jar）です。`plugins/` フォルダに jar を入れる通常の手順で導入できます。看板による参加・一斉スタート・ゴール、感圧板チェックポイント、SQLite によるランキング保存に対応しています。
