# AsureTimer ― 遊び方 { .page-player #asuretimer-player }

AsureTimer は、アスレチックのクリアタイムを計測して順位を競う **タイムアタック** です。みんなで一斉に走る **マルチモード** と、1人で何度も挑戦する **ソロモード** があります。ステージ（コース）には「アスレ」と「ドロッパー」の2種類があります。

!!! abstract "クイック情報"
    | 項目 | マルチモード | ソロモード |
    |---|---|---|
    | 参加 | `/asure join <ステージ>` または参加看板 → ステージのロビーへ | `/asure solo <ステージ>` またはソロ看板 |
    | スタート | `/asure start <ステージ>` または開始看板で **ロビーの全員が一斉にスタート** | 参加するとすぐスタート（カウントダウンの後） |
    | 途中参加 | できる（`/asure join <ステージ>`。タイムは走り出した時点から） | — |
    | ゴール | ゴール看板をクリック → 結果発表のあとロビーへ戻って待機 | ゴール看板をクリック → 結果発表のあと **自動でもう一度スタート** |
    | 終わり方 | `/asure leave` またはギブアップアイテム | `/asure leave` またはギブアップアイテム |
    | 試合の終了 | 走っている人がいなくなったら（全員ゴール・離脱） | — |

## どんなゲーム？

- **アスレ** … ジャンプアクションでゴールを目指す通常のアスレチックです。スタート地点からのZ方向の進行距離（既定で最大1000m）が計測され、クリアタイムが記録されます。
- **ドロッパー** … 高所から落下し、障害物を避けながら下まで落ちきるとクリアです。落下時間（タイム）と死亡回数が記録されます。

参加すると **持ち物はいったん預けられ、インベントリが空になります**。離脱（`/asure leave`・ギブアップ）すると元の持ち物に戻ります。

## マルチモード（みんなで走る）

1. **ロビーに入る** — 参加看板をクリックするか `/asure join <ステージ>` を実行すると、そのステージのロビーへ移動します。待っている間はダメージを受けず、お腹も減りません。
2. **一斉スタート** — 開始看板をクリックするか `/asure start <ステージ>` を実行すると、ロビーにいる全員がスタート地点へ移動し、カウントダウン（既定3秒）のあと一斉にスタートします。カウントダウン中は動けません。開始は誰でもできます。
3. **ゴール** — ゴール看板をクリックするとクリアです。タイムが記録され、ランキングが表示されます。結果発表（既定10秒）のあと **ロビーへ戻って待機** します（参加は続いています）。
4. **試合終了** — 走っている人がいなくなる（全員がゴールした・離脱した）と試合終了です。この試合のゴール順がロビーの全員に表示されます。続けて `/asure start <ステージ>` で次の試合を始められます。

!!! tip "途中参加"
    試合中でも `/asure join <ステージ>`（参加看板）で途中参加できます。途中参加した人は、自分だけのカウントダウンのあとすぐ走り出し、**タイムは走り出した時点から** 計ります。カウントダウン中に参加した場合は、そのまま全員と一緒にスタートします。

!!! note "ステージの指定"
    ステージが1つしかないサーバーでは、`/asure join` `/asure start` のステージ名は省略できます。2つ以上あるときに省略すると、ステージの一覧が表示されます（ロビーに入っている人の `/asure start` は省略すると今いるステージになります）。

## ソロモード（1人で走る）

- ソロ看板をクリックするか `/asure solo <ステージ>` を実行すると、カウントダウン（既定3秒）のあとすぐスタートします。
- ゴールすると結果が表示され、**少し待つと（既定5秒）自動で同じステージをもう一度スタート** します。自己ベストを狙って何度でも挑戦できます。
- やめるときは `/asure leave` かギブアップアイテムを使います（持ち物が戻り、初期スポーンへ移動します）。
- 同じステージを **何人でも同時に** 走れます。ソロの記録もマルチと同じランキングに入ります。

!!! tip "ゴースト（自分だけに見える再生）"
    走っている間、**自己ベスト・ステージ1位・前回の走り** を、人形のような姿で **本人にだけ見えるように** 再生できます（マルチ・ソロ共通）。種類は `/asure ghost <best|top|last|off>`、または `/asure solo <ステージ> <best|top|last|off>` で選べます（`best`=自己ベスト／`top`=1位／`last`=前回／`off`=なし）。ゴーストはワールドには残らず、他のプレイヤーからは見えません。

## 走っている間

!!! tip "計測中の便利な効果"
    - **アスレ** … 満腹度が減らなくなる「満腹度回復」効果がつきます。
    - **ドロッパー** … 暗い場所でも見えるように「暗視」効果がつきます。

### アクションバーの表示

| 状況 | 表示内容 |
|---|---|
| アスレ走行中 | `現在: ○○m / 1000m ｜ 経過タイム` |
| ドロッパー走行中 | `[D] ステージ名 ｜ Time: 経過タイム ｜ Deaths: 死亡回数` |
| マルチのロビーで待機中 | 待っている人数、または試合の状態 |

!!! tip "区間タイムとBossBar"
    アスレなら一定距離ごと（既定100mごと）に **区間タイム** が表示され、画面上部の **BossBar** に「経過タイム／比べる相手のタイム」が出ます。ゴールすると各区間の差分（区間表）も確認できます。出し方は `/asure splits <title|chat|off>` で変えられます（`title`=チャット＋画面／`chat`=チャットのみ／`off`=表示しない）。

### チェックポイントと復帰（アスレ）

- **金の感圧板（軽量用感圧板）** を踏むと、そこがチェックポイントとして記録されます（より遠くまで進んだときだけ更新）。
- 落下などで死亡すると、直近のチェックポイントから再開します（タイム計測はそのまま続きます）。
- 配られる **「前のチェックポイントに戻る」アイテム（既定はリカバリーコンパス）** を右クリックすると、通過済みのチェックポイントを選んでワープできます（何度でも使えます。`/asure back` でも可）。
- ドロッパーは死亡するとスタート地点へ戻り、死亡回数が1つ増えます。

### 配られるアイテム

| アイテム | 使い方 |
|---|---|
| ギブアップ（既定はネザースター） | 右クリックで **ギブアップして離脱**。アスレは到達距離が記録されます（`/asure giveup` でも可） |
| 前のチェックポイントに戻る（アスレのみ） | 右クリックで通過済みチェックポイントを選んでワープ（`/asure back` でも可） |
| リトライ（時計） | 右クリックで今の走りを記録なしで止め、最初からやり直す（`/asure retry` でも可。一斉スタートのカウントダウン中は使えません） |

!!! note "統合版（スマホ・Switch など）"
    空中では右クリックの代わりに **タップ** でアイテムを使えます。ギブアップとリトライは誤操作を防ぐため、**3秒以内に2回タップ** で確定します。

!!! note "ギブアップ／離脱／ログアウトの違い"
    - **ギブアップ**（アイテム・`/asure giveup`）… 走りをやめて **完全に離脱** します（持ち物が戻り、初期スポーンへ）。アスレは **到達距離が記録** されます。
    - **離脱**（`/asure leave`・離脱看板）… 走りをやめて完全に離脱します。**記録は残りません**。ロビーで待っている間も使えます。
    - **ログアウト** … 離脱扱い（記録なし）になり、再接続すると初期スポーンへ戻ります。試合には戻りません。

## ランキングの見方

ゴールするとランキングが表示されます。`/asure ranking [ステージ] [time|distance]` でいつでも確認できます。

| ランキング | 内容 |
|---|---|
| クリアタイムランキング | ステージを速くクリアした順（上位10名） |
| 到達距離ランキング | アスレでギブアップした地点の到達距離が長い順（上位10名） |

記録はプレイヤーごとに **ベスト記録のみ** が保存されます。ステージの近くにある **ランキング看板** には1位のプレイヤー名とベスト記録が表示され、定期的に更新されます。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/asure join [ステージ]` | マルチ：ステージのロビーへ入る（試合中なら途中参加） |
| `/asure start [ステージ]` | マルチ：ロビーにいる全員で一斉スタート |
| `/asure solo [ステージ] [best\|top\|last\|off]` | ソロ：すぐスタート（ゴール後は自動で再スタート） |
| `/asure leave` | 離脱する（記録なし・持ち物が戻って初期スポーンへ） |
| `/asure giveup` | ギブアップして離脱する（ギブアップアイテムと同じ） |
| `/asure back` | 通過済みチェックポイントの選択メニューを開く（アスレ走行中のみ） |
| `/asure retry` | 今の走りを記録なしで止め、最初からやり直す |
| `/asure ghost <best\|top\|last\|off>` | ゴーストの種類を切り替える |
| `/asure splits <title\|chat\|off>` | 区間タイムの出し方を切り替える |
| `/asure status [ステージ]` | 設定状況・試合の状況を見る |
| `/asure ranking [ステージ] [time\|distance]` | ランキングを表示する |
| `/asure stats [ステージ]` | 自分の統計（挑戦回数・クリア数・ベストタイム・最大到達距離）を表示 |

!!! note "コマンドは誰でも使えます"
    上の表のコマンドは権限なしで使えます。他プレイヤーの統計を見る `/asure stats <プレイヤー>` や、看板・ステージの登録、強制停止（`/asure stop`）などは管理者（OP）専用です。

## よくある質問

??? question "みんなで走るにはどうすればいいですか？"
    全員が参加看板（または `/asure join <ステージ>`）でロビーに入ったら、誰か1人が開始看板をクリック（または `/asure start <ステージ>`）します。ロビーにいる全員が一斉にスタートします。

??? question "試合が始まった後に来ました"
    そのまま `/asure join <ステージ>`（参加看板）で途中参加できます。タイムは自分が走り出した時点から計るので、記録は普通にランキングに入ります。

??? question "ゴールしたのにクリアになりません"
    クリアの確定は **ゴール看板のクリック** で行われます。走っているステージと違うステージのゴール看板ではクリアになりません。カウントダウン中にクリックしても記録されません。

??? question "ソロをやめたいのに、また始まってしまいます"
    ソロはゴールすると自動で再スタートします。やめるときは `/asure leave` かギブアップアイテムを使ってください。

??? question "記録が更新されません"
    記録はプレイヤーごとに **ベスト記録のみ** 保存されます。前回より遅いタイム・短い距離だった場合は更新されません。

??? question "アクションバーの距離表示が止まって見えます"
    アスレの距離は、スタート地点からの **Z方向の進行距離** で計算されます。ステージの進行方向によっては数値が増えにくく見えることがありますが、ゴール看板のクリックでクリアは正しく確定します。
