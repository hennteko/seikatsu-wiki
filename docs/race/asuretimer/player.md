# AsureTimer ― 遊び方 { .page-player #asuretimer-player }

AsureTimer は、アスレチックコースのクリアタイムを計測して順位を競う **タイムアタック** プラグインです。スタート看板をクリックして計測を開始し、ゴール看板までの時間を競います。コースには「アスレ」と「ドロッパー」の2種類があります。

!!! abstract "クイック情報"
    | 項目 | 内容 |
    |---|---|
    | 人数 | 1人（個人タイムアタック） |
    | 参加方法 | スタート看板をクリック |
    | 計測の開始 | スタート看板クリックと同時に計測開始 |
    | 計測の終了 | ゴール看板クリックでクリア（タイム確定） |
    | コースの種類 | アスレ（既定1000m）／ドロッパー |
    | 記録 | アスレ＝クリアタイム＆到達距離 ／ ドロッパー＝クリアタイム |

## どんなゲーム？

AsureTimer には2種類のコースがあります。

- **アスレコース** … ジャンプアクションでゴールを目指す通常のアスレチックです。スタート地点からのZ方向の進行距離（既定で最大1000m）が計測され、クリアタイムが記録されます。
- **ドロッパーコース** … 高所から落下し、障害物を避けながら下まで落ちきるとクリアです。落下時間（タイム）と死亡回数が記録されます。

どちらも **スタート看板をクリックすると計測が始まり**、専用のスタート地点へテレポートします。

## 計測の開始とゴール

1. **スタート看板をクリック** — コースのスタート看板をクリックすると、スタート地点にテレポートされ、その瞬間からタイム計測が始まります。
2. **コースを走る** — アスレならジャンプして進み、ドロッパーなら下を目指して落ちます。画面下のアクションバーに現在のタイムが表示されます。
3. **ゴール看板をクリック** — ゴール（クリア）看板をクリックするとクリア扱いになり、クリアタイムが確定・記録されます。直後にランキングが表示されます。

!!! tip "計測中の便利な効果"
    計測を開始すると、コースの種類に応じて補助効果がつきます。

    - **アスレ** … 満腹度が減らなくなる「満腹度回復」効果がつきます。
    - **ドロッパー** … 暗い場所でも見えるように「暗視」効果がつきます。

## アクションバーの表示

計測中は画面下のアクションバーに進捗が表示されます。

| コース | 表示内容 |
|---|---|
| アスレ | `現在: ○○m / 1000m ｜ 経過タイム` |
| ドロッパー | `⬇ コース名 ｜ Time: 経過タイム ｜ Deaths: 死亡回数` |

## チェックポイントと復帰（アスレ）

アスレコースには **金の感圧板（軽量用感圧板）** のチェックポイントが置かれていることがあります。

- 金の感圧板を踏むと、そこがチェックポイントとして記録され、`チェックポイント通過！` と表示されます。
- アスレ計測中に **落下などで死亡した場合、直近のチェックポイントから再開** できます（タイム計測はそのまま継続します）。
- チェックポイントは「より遠くまで進んだとき」だけ更新されます。

!!! tip "戻るアイテムで好きなチェックポイントへ"
    アスレ計測を始めると、ギブアップアイテムと一緒に **「前のチェックポイントに戻る」アイテム（既定はリカバリーコンパス）** が配られます。**右クリックで通過済みチェックポイントの選択メニューが開き**、スタート地点や任意の通過済みCPへワープできます。何度でも使え、消費されません。難所をやり直したいときに便利です（**戻ってもタイム計測・到達距離の記録は減りません**）。ドロッパーコースでは配られません。

!!! note "ドロッパーは死亡してもスタート地点へ"
    ドロッパーコースでは、死亡すると **スタート地点へ自動でリスポーン** し、死亡回数が1つ増えます。チェックポイント・戻るアイテムはありません。

## ギブアップ

計測を始めると、インベントリに **「ギブアップ」アイテム（既定はネザースター）** が配られます。

- ギブアップアイテムを **右クリック** すると計測を中止し、ロビー（スポーン地点）へ戻ります。
- ギブアップするとタイム計測は終了します。アスレの場合、ギブアップ時点の **到達距離が記録** されます。
- ログアウトした場合もギブアップ扱いになります。
- ギブアップ後、アイテムは自動的にインベントリから取り除かれます（プラグイン配布のアイテムのみ削除されるため、同素材の他アイテムには影響しません）。

## ランキングの見方

クリアまたはギブアップすると、自動でランキングが表示されます。`/asure ranking` コマンドでもいつでも確認できます。

| ランキング | 内容 |
|---|---|
| クリアタイムランキング | コースを速くクリアした順（上位10名） |
| 到達距離ランキング | アスレでギブアップした地点の到達距離が長い順（上位10名） |

クリアタイムランキングでは、リストの下に **あなた自身の順位とベストタイム** も表示されます。記録はプレイヤーごとに **ベスト記録のみ** が保存されます（タイムは速い記録、距離は長い記録で上書き）。

!!! tip "ランキング看板"
    コースの近くに **ランキング看板** が設置されていることがあります。看板には1位のプレイヤー名とベスト記録が表示され、定期的に自動更新されます。

## プレイヤー用コマンド

| コマンド | 説明 |
|---|---|
| `/asure join [コースID]` | コースに参加して計測を開始する（スタート看板クリックと同じ。省略時は既定コース） |
| `/asure ranking [コースID] [time\|distance]` | ランキングを表示する（省略時は既定コースのタイムランキング） |
| `/asure stats` | 自分の全コース統計（挑戦回数・クリア数・クリア率・ベストタイム・最大到達距離）を表示 |
| `/asure stats <コースID>` | 自分の指定コース統計を表示 |

!!! note "コマンドは誰でも使えます"
    `/asure ranking` / `/asure stats`（自分） / `/asure stats <コースID>`（自分） は権限チェックなしで実行できます。他プレイヤーの統計を見る `/asure stats <プレイヤー>` だけは `asuretimer.admin` 権限（既定 OP）が必要です。コース・看板の登録系（`setup` / `course` / `reload`）も管理者権限が必要なため、見当たらない場合は運営にご相談ください。

!!! info "看板での参加が基本です"
    コース計測の開始・ゴールは **看板のクリック** が基本です。コース付近のスタート看板を探してクリックしてください。なお `/asure join [コースID]` でも看板クリックと同じようにコースへ参加して計測を開始できます（ゴール＝クリア確定はゴール看板のクリックで行います）。

## よくある質問

??? question "どうやってタイム計測を始めますか？"
    コースのスタート看板（緑色の `▶ START ▶` などと表示された看板）をクリックします。クリックするとスタート地点にテレポートし、その瞬間から計測が始まります。

??? question "ゴールしたのにクリアになりません"
    クリアの確定は **ゴール看板のクリック** で行われます。ゴール地点まで到達したら、`★ GOAL ★` と表示された看板をクリックしてください。プレイ中のコースと違うコースのゴール看板をクリックした場合はクリアになりません。

??? question "落下して死んでしまいました"
    アスレコースなら、直近で踏んだ金の感圧板（チェックポイント）から再開できます。チェックポイントを踏んでいない場合はスタート地点からの再開になります。ドロッパーコースは死亡するとスタート地点へ戻り、死亡回数が1つ増えます。いずれもタイム計測は止まりません。

??? question "途中でやめたいときは？"
    インベントリに配られる「ギブアップ」アイテム（既定はネザースター）を右クリックすると計測を中止し、ロビーへ戻れます。アスレではギブアップ時点の到達距離が記録されます。

??? question "記録が更新されません"
    記録はプレイヤーごとに **ベスト記録のみ** 保存されます。前回より遅いタイム・短い距離だった場合は更新されません。前回を上回る記録を出すと自動で更新されます。

??? question "アクションバーの距離表示が止まって見えます"
    アスレの距離は、スタート地点からの **Z方向の進行距離** で計算されます。コースの進行方向によっては数値が増えにくく見えることがありますが、ゴール看板のクリックでクリアは正しく確定します。
